Figma

This content was generated with the assistance of AI and should be verified against the official documentation before being relied on in production.

Figma is a browser-based, multiplayer design platform. This sub-section is a practical, heavily illustrated guide to learning Figma and using it across the whole UI / UX process: the interface and file organisation, design fundamentals, auto layout, components, styles and variables, design systems, prototyping and animation, the UX process, collaboration, handoff to developers, Figma’s AI products and the developer platform. It belongs to the UI / UX section. Every page was checked against the official documentation on 2026-10-30 and describes the UI3 interface.

Scope

  • In scope: every area of the official Figma documentation listed in the coverage map, explained with original schematic figures, numbered procedures on one running scenario and a link to the official article each procedure derives from.

  • Also in scope: the concepts taught by four published Figma books (see the bibliography). The books were used only to decide which concepts to cover and in what order. Every procedure is written against the current official documentation, and where a book is out of date the page says so in prose with dates, collected on What Changed Since Older Guides. No book text, figure or screenshot is reproduced.

  • Out of scope: prices (pages name plans and seats, never amounts), the unannounced "Content seat" (it appears on no current official page, so it is not documented), and any third-party tool beyond a short, labelled ecosystem mention.

  • Figures: all figures are original generic schematic drawings. They contain no Figma logo, icon or help-centre image.

Running example

Every example designs Bookshelf, a book catalogue and reading-list app. It is the same domain as the Express, Node.js, NestJS, FastAPI and Next.js sections of this site, so the design side meets the code side. Across the pages the scenario grows in this order:

  1. A FigJam research board with goals, stickies, affinity clusters, a persona (Lena, a book-club organiser), a journey map and a user flow for "find a book and leave a review".

  2. Low-fidelity wireframes of the mobile app and the web catalogue.

  3. A Bookshelf Design System library: colour, spacing, radius and typography variables with light and dark modes, text and effect styles, and components (button, input, rating stars, book card with a slot, top bar, tab bar, dialog).

  4. High-fidelity responsive screens (catalogue grid, book detail, review form) for mobile, tablet and desktop.

  5. Prototypes: navigation flows, a filter overlay, a favourite toggle, a "rate this book" microinteraction and a reading-list cart driven by variables.

  6. A Figma Motion loading animation exported as Lottie.

  7. Dev Mode handoff with annotations, Code Connect to a React Button and the MCP server driving a coding agent.

  8. A Make prototype, a Sites landing page, a Buzz social card and a small contrast-audit plugin.
