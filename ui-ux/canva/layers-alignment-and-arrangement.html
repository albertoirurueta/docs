Layers, Alignment and Arrangement

This content was generated with the assistance of AI and should be verified against the official documentation before being relied on in production.

This page was checked against the official Canva Help Center on 2026-11-07. It covers the controls that decide where every element sits in a design and what covers what: the layers panel, the Arrange and Align controls of the Position panel, grouping, locking, transparency, flip and rotate, and copying a style. These features belong to the Canva editor on the web, in the desktop app and in the mobile apps, and they are generally available. They work on the Free, Pro, Business, Enterprise, Education and Nonprofits plans, and none of them draws on the Canva AI allowance (the Standard, Premium and Ultra tiers are explained on Plans, Pricing and AI Allowance). Prices are published at https://www.canva.com/pricing/ and are not repeated here. Two limits matter: locking is not available in Canva Docs, and grouping does not cover sheet elements or content created by third-party apps from the Apps tab.

The running example is Bookshelf, the book catalogue and reading-list app designed in the Figma sub-section. Its print flyer was assembled quickly from loose pieces and now needs a tidy-up before it goes to print. The same controls apply to every design type, so the lessons transfer to posts, presentations and posters. The principles behind a tidy layout, alignment and proximity, are covered on Design Principles in Canva; this page is about the controls that implement them.

Layers: what covers what

Every element you add to a design lives in its own layer. Front layers sit on top of back layers, so a photo placed after a title can hide that title. The Help Center states the model in one sentence: elements are in layers, the front layers are on top of the layers at the back. Alignment is a separate idea: it moves an element to a place you choose with respect to the design page, or with respect to the other selected elements.

Figure 1. A page seen as a stack of layers and the matching rows of the layers panel

Where the controls live

In the current editor the layer controls sit behind the Position button on the toolbar above the editor (the quick actions toolbar of the redesigned editor described on Editor Tour). Select the page, its background or an element, choose Position, and a panel opens at the side. If you do not see Position, select the button that expands the toolbar first. The panel has an Arrange tab with the layer and alignment options and a Layers tab that lists everything on the current page. The keyboard shortcut for showing layers is Option + 1 on macOS.

Figure 2. The Position panel with Arrange, Align to page and the Advanced fields

  1. The selected element on the canvas; Position is a button of the toolbar above the editor.

  2. Arrange: Forward, Backward, To front and To back. The options offered depend on where the element already is in the stack.

  3. Align to page: six buttons that use the design page as the reference.

  4. Advanced: exact X and Y values and a Rotate value.

The layers panel

The Layers tab lists the layers of the current page. A layer that holds grouped elements shows a grouped icon, and the page background shows a background icon. Selecting a row selects that element on the page, which is the reliable way to reach an element that is hidden behind another one. On desktop, hovering a row shows a more options icon with editing choices. To change the stack, press and hold a row and drag it up or down; a line shows where it will be inserted, and you drop it into position. You can rearrange several layers at once: hold Shift on the keyboard and click rows to select them.

Source: Canva Help Center: Finding and arranging layers in your design

Forward, backward, to front and to back

The Arrange options move a selected element through the stack one step at a time or all the way. Forward and Backward move it one layer; To front and To back send it to the top or the bottom. Not every option appears every time: an element that is already at the front has no use for Forward or To front. To select several elements, hold Shift and click each one before choosing a layer option.

Align elements

Alignment has two modes, and the number of selected elements decides which one you get. With a single element selected, the options are called Align to page and use the design page as the point of reference: for example Left, Center, Right, Top, Middle and Bottom. With more than one element selected, the options are called Align elements and use the positions of all the selected elements as the basis for alignment. The first mode places an element on the page; the second lines elements up with each other.

Figure 3. Aligning one element to the page and several elements to each other

A third helper is the Tidy up elements shortcut, Option + Shift + T on macOS, listed in the Help Center keyboard shortcuts article with no dedicated explanation. The Position panel and the shortcuts article do not describe a separate "space evenly" command, so use Align elements for edges and centres and the arrow keys or exact coordinates for spacing. The book terms "space evenly" and "distribute" are covered here by those controls.

Source: Canva Help Center: Group, layer, and align elements

Move elements and set exact positions

Drag an element to move it, hold Shift and click to select several elements and move them together, and use the arrow keys for small movements. Shift + an arrow key moves the selection a larger step. To move elements to another page, open the pages view from the editor, select the elements and drag them onto the thumbnail of the new page. For exact placement, open Position and use the Advanced section: X and Y values measure, in pixels, the distance from the top-left corner of the canvas, with X for horizontal placement and Y for vertical placement. Entering the same values on every page is the quickest way to keep a logo in the same place across a carousel.

If an element will not move, it is probably locked, part of a group, or both. Select it and choose Unlock or Ungroup on the floating toolbar. Text boxes on templates are usually part of a group, so ungroup them before moving a single text box.

Source: Canva Help Center: Move elements in your design

Group and ungroup

Grouping binds several elements so that they move, scale and rotate as one. To group, drag a selection box over the elements, or hold Shift and click several, then select Group on the floating toolbar; Command + G groups on macOS and Ctrl + G on Windows, and Command + Shift + G ungroups on macOS. To edit one element inside a group, click the group and then click the element: corner handles resize it, the rotate handle rotates it and dragging moves it, while the group stays intact. To ungroup all elements, select the whole group and choose Ungroup; to remove a single element, select that element and choose Ungroup.

You can group every element type, including charts, tables and grids, except sheet elements. Content created by third-party apps from the Apps tab cannot be grouped with other elements. The Help Center workaround is to right-click the content, choose Download selection, save a PNG or JPG, upload the file again and add it to the design, where it behaves as a regular image. On the layers panel a group is a single row with a grouped icon, so a group is also a way to keep a long layer list readable.

Source: Canva Help Center: Group, layer, and align elements

Lock and unlock

Locking prevents an element or a page from being moved, resized or edited, so that you do not change it by accident while working on something else. There are two lock modes: Lock completely locks position, style and content, and Lock position only locks position and style and leaves only the content editable. You can lock individual elements such as text boxes, images and graphics, or entire pages; locking a page affects every element and the background on it. Anyone with edit access to the design can lock or unlock its elements. Locking is not available in Canva Docs.

Figure 4. Group, lock and lock position only compared

Elements and pages follow a few rules. You cannot unlock an element while its page is locked; unlock the page first. Unlocking a page does not unlock its elements, because each element must be unlocked separately; this is called lock inheritance. A copy or a duplicate of a page keeps every lock state from the original. A page can also be in a position-locked state in which the page options menu shows Lock page instead of Unlock page; press Option + Shift + L on macOS or Alt + Shift + L on Windows to cycle through the lock states, or open the page options and toggle Lock page until Unlock page appears. If you see only a lock icon where an element should be, select the icon and toggle the options until it unlocks. For templates, the Help Center advice is to use a position lock on the text boxes and frames that people should fill in, and a full lock on everything else.

In Canva for Education, an element locked by a teacher (a brand admin or brand designer) cannot be unlocked by students, even those with edit access; elements locked by a student or by another editor can be unlocked.

Source: Canva Help Center: Lock and unlock pages or elements

Transparency, flip and rotate

Transparency makes an element see-through, which lets you layer a tinted shape over a photo and keep text readable. Select the element, or hold Shift to select several, choose Transparency on the toolbar and drag the slider or type a value. It works on backgrounds, text, elements, photos and videos. When transparency is available for a solid fill, the colour selector also has a Transparency slider.

Flip mirrors an element. Select it, choose Flip on the toolbar, then Flip horizontal to flip it sideways or Flip vertical to turn it upside down. You cannot flip text, charts, empty grids, frames, shapes or grouped elements, and rotating elements is not available in Canva Docs. To rotate, drag the rotate handle outside the border of the selected element or group left or right, or open Position and type an angle under Rotate. For an image inside a grid or a frame, choose Crop on the toolbar and drag the Rotate slider. The macOS shortcuts Option + , and Option + . rotate a small step, and adding Shift makes the step larger.

Source: Canva Help Center: Adjust element transparency

Source: Canva Help Center: Flip and rotate elements

Copy style

Copy style applies the look of one element to another, which keeps a family of badges or captions consistent without repeating every setting. Select the element or text in the style you want, choose the copy style button on the floating toolbar (it is also in the More menu as Copy style), then select the element or text to receive the style. The style includes colour, transparency and image filter for elements; chart colours, text colour and formatting and transparency for charts; background colour and background image filter for pages; and font style, font size, colour and alignment for text. You can only copy the style of a recent design inside the same account or team. For graphic elements, Canva also documents Style Match, which copies the visual style of graphics in the design.

Source: Canva Help Center: Copy style and format

Desktop and mobile

Every article this page draws on gives separate Desktop and Mobile instructions, because the controls are laid out differently on a phone. The concepts are the same: layers stack front to back, alignment depends on how many elements are selected, locks and groups protect the layout. The keyboard shortcuts in this page are desktop shortcuts. On a phone, check the Mobile tab of the linked article for the exact gestures, since icons and menu names move between app releases.

Procedures on the Bookshelf scenario

Tidy the cluttered Bookshelf flyer

The flyer has a book cover photo that hides the title, text lines that do not share a left edge, and a header block that slips when somebody nudges it.

  1. Open the flyer and select the cover photo, then hold Shift and click the other pieces that are stacked on top of each other, so that you can see what is overlapping.

  2. Select the cover photo, choose Position, open the Layers tab and drag the photo’s row below the Title row. A line shows the drop position; drop the row there. The title now reads over the photo.

  3. Select the three text lines by holding Shift and clicking each, choose Position and, under Align elements, select Left. All three share one left edge.

  4. Select the header pieces (the photo, the title and the button), press Command + G on macOS or Ctrl + G on Windows to group them, and check that the layers panel shows one grouped row.

  5. Select the page background, choose the lock control on the floating toolbar and select Lock, so that nobody drags the background by accident.

  6. Choose the Layers tab one last time and read the order from top to bottom; it should read like the visual order of the flyer.

Place the logo in the same spot on every page

  1. Select the Bookshelf logo on page 1 and choose Position.

  2. Under Advanced, enter the X and Y values you want, for example the same distance from the top-left corner on every page of the carousel.

  3. Select the logo on page 2 and enter the same X and Y values; repeat for each page.

  4. If an element refuses to move, check whether it is locked or grouped, and unlock or ungroup it first.

Source: Canva Help Center: Move elements in your design

Common pitfalls

  • Selecting the wrong layer. When an element is hidden, select it in the layers panel instead of clicking the canvas.

  • Expecting Align to page when several elements are selected. With more than one element the reference becomes the selection, so the whole group stays in place and the elements line up with each other.

  • Locking the page and then wondering why elements stay locked after unlocking. Unlocking a page does not unlock its elements.

  • Grouping template text without realising it. Text on templates is usually already grouped, so ungroup before editing individual parts.

  • Trying to flip text or grouped elements. These cannot be flipped; ungroup and flip a single element, or mirror an image before you place it.

  • Third-party app content refusing to group. Download the selection, upload it again, and add it as a regular image.

Alt text and reading order are an accessibility matter that depends on the layer order, which the page Accessibility in Canva explains. For the effect of Magic Layers, which turns a flat image into separate editable layers, see AI Photo Tools.
