Animation and Transitions

This content was generated with the assistance of AI and should be verified against the official documentation before being relied on in production.

This page was checked against the official Canva Help Center on 2026-11-07. It covers motion in Canva designs: animations on pages, elements and text, the one-click Magic Animate, page transitions, the element timing view, shader animations for video clips, the Reduce motion setting and exporting animated designs. Animations and transitions can be added in any design type except Docs, on Canva Free, Pro, Business, Enterprise, Education and Nonprofits. The Help Center states that more animations and transitions are available to paid, Education and Nonprofits accounts and are tagged in the options; its article names Canva Pro, Canva Teams, Canva Education and Canva for Nonprofits, so check the tags in your own account. Prices are not repeated here; see https://www.canva.com/pricing/.

The running example is Bookshelf, the book catalogue app from the Figma sub-section. Here the "Book of the week" Instagram post gets a short, restrained motion pass and is exported as a video for the launch campaign.

Where animation lives in the editor

Motion is controlled by the Animate button on the toolbar above the editor. Select a page or element, choose Animate, and an animation panel opens in the side panel. Its tabs depend on what you selected: Page for the current page, Element for selected elements and Text for a selected text box. Hover an option to preview it and click to apply it. The available styles depend on whether you selected text, a graphic, a shape, a photo or a video. Transitions live elsewhere: they are set between page thumbnails (see Page transitions).

The animation options in detail

Option What it does

Page, Element and Text tabs

Animate the current page, the selected elements or a selected text box

General and Suggested animations

Ready-made styles; the list changes with the type of the selected element

Add-on effects

Extra effects you can combine with General or Suggested animations to see which mix suits the design

Speed presets

Slow, Medium and Fast, or precise intro and outro durations through the duration controls for selected animations

Appear on click

Elements appear when you click during a presentation; Click order under Presentation settings sets the sequence

Create an Animation

Draw a custom movement path by dragging the element; adjust Movement Style, Presentation settings and Add-on effects, then select Done (or Delete path)

Remove animation

Clears the animation or motion effect from the selection

Limits stated in the Help Center: each animation can be at most 10 seconds long, and a design can contain at most 50 animations that you created yourself. No keyboard shortcut for animation is documented in the article, so on macOS and Windows alike you reach it through the Animate button.

Fade a video clip in or out

Select the video clip, choose Animate, and under General select Fade, then choose On enter, On exit or Both and adjust the speed. This fades the picture only; to fade the sound use Audio tools and set Fade in or Fade out.

Source: Canva Help Center: Apply, change, or remove animations

Magic Animate

Magic Animate uses AI to choose an animation for the whole design in a few seconds. On the toolbar select Animate, open the Page tab, choose Magic Animate and pick a style under Recommended style; the Alternative styles offer other looks, and Remove Magic Animation clears it from the entire design. It works best on a computer but is also available on mobile. If you subscribe to a premium plan and cannot see it, check the design type: it is offered only for presentation, social media and video designs. Because the result is applied to every element at once, review the timing afterwards (see Element timing and click order) and prefer manual animation when you need a specific reading order.

Source: Canva Help Center: Apply animations instantly

Element timing and click order

Animations on a page play in a sequence, and the order and length can be changed in two ways.

  • Show element timing. Select an animated element, choose More in the floating toolbar, then Show element timing. Timing tiles appear in the thumbnail area below the editor. Drag the tiles to change which element appears first, and drag the handles left or right to change each duration in seconds.

  • Click order. If you turned on Appear on click, open Presentation settings, choose Click order and drag the elements into the order in which they should appear on each click.

Page transitions

A page transition animates the change from one page to the next in a presentation, video or exported animated design. Show page thumbnails with the Pages button at the bottom of the editor, hover between two thumbnails (or choose More on a thumbnail) and select Add transition. Hover a transition to preview it, click to apply it, then adjust the Duration (seconds) slider or number field, which accepts values from 0.1 to 2.5 seconds, and the direction where the style offers one. To change a transition later, click the icon between the two pages. In video designs the procedure differs: you add transitions between clips on the main track of the timeline, and the article notes that transitions are not available in page mode for video designs.

The styles in the figure are generic sketches of the idea; the names and the exact set in your account differ and change over time.

Source: Canva Help Center: Use page transitions

Shader animations for video

For video clips, the Animate panel has a Featured section with shader animations that add glowing, moving or textured effects. Examples listed by the Help Center are Shake Zoom (intensity slider), Whip Slide (speed slider), Old TV and Chroma Wave. Choose where to apply it, On enter, On exit or Both, and use Remove animation to undo. They need a supported MP4 file and the latest Canva version.

Source: Canva Help Center: Shader animations for videos

Reduce motion and accessibility

Reduce motion limits animation when designs are viewed or presented, which helps people with motion sensitivities or vestibular disorders. When it is on, animations are reduced, and transitions, background animations, masks and overlays are removed. You can turn it on in three places:

  • for all designs, from the homepage profile icon, then Settings, Accessibility and the Reduce motion when you view and present designs dropdown (Reduce motion on or Use my system preferences)

  • for one editor session, from File, Accessibility, Reduce motion

  • from a public view link, by hovering at the bottom of the page, choosing More and then Reduce motion

It is a per-account setting and does not affect collaborators. It affects playback only, not editing or exporting, so animations may still appear in downloaded video files. Design with that in mind: keep motion short, avoid flashing and give essential information a static form.

Source: Canva Help Center: Reduce motion settings for animations and transitions

Exporting animated designs

Animated designs download as video or GIF, can be shared directly to social media or scheduled. Select Share, then Download, and choose a file type.

On Free, changing the MP4 quality or resolution from the default shows an upgrade prompt; keep the default to download without upgrading. If you used premium or paid audio, verify its license when downloading before posting. The broader download options are on Downloading and File Formats, and full video editing on Video Editor, Audio and Captions.

Desktop and mobile

The Animate panel, Magic Animate and Create an Animation have desktop and mobile instructions in the Help Center, and Magic Animate is described as best on a computer. Precise tools such as element timing tiles and click-order dragging are easier with a pointer. The 4K MP4 option is desktop only.

Procedure: animate the Bookshelf launch post

  1. Open the "Book of the week" post and select the book cover.

  2. Choose Animate, hover the styles on the Element tab to preview them, apply one subtle style and pick the Medium speed.

  3. Select the title and apply a text animation from the Text tab; select the call-to-action pill and apply an animation with Appear on click if it should wait for a presenter.

  4. Choose Show element timing and drag the tiles so that the cover appears first, then the title, tagline and pill; shorten any bar that lasts too long.

  5. Check the result with Preview, add a transition if the post has several pages, then select Share, Download, choose MP4 video or GIF and download.

Common pitfalls

  • Animating everything at once makes the reading order unclear; animate the one thing that should be seen first.

  • A Magic Animate style is applied to the whole design; review timing afterwards.

  • Transitions are not offered in Docs, and in video designs they are set on the timeline.

  • Reduce motion does not change exports, so a viewer may still receive motion in a downloaded video.

  • A single animation cannot exceed 10 seconds.
