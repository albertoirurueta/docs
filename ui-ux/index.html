UI / UX

This content was generated with the assistance of AI and should be verified against the official documentation before being relied on in production.

User interface (UI) design is the craft of the surface people see and touch: layout, typography, colour, components, icons and motion. User experience (UX) design is wider: it covers who the users are, which tasks they want to finish, how the product is structured, how it behaves and whether it actually helps. UI is therefore a part of UX, and a beautiful interface can still deliver a poor experience if the flow behind it is wrong.

The overview compares UI and UX design, walks through the UX process from discovery to iteration and surveys the design tools landscape.

Sections

  • Overview — UI versus UX, the UX process at a glance and the design tools landscape.

  • Figma — frames, auto layout, components, variables, prototyping, Dev Mode, collaboration, plugins and the REST API, taught through one running scenario, the Bookshelf app.

  • Canva — the editor, templates, Visual Suite products, Canva AI, brand kits, collaboration, accessibility and the developer platform, taught through the launch campaign of the Bookshelf app.

Further tools may be added later as sibling subsections next to Figma and Canva.
