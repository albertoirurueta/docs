What’s new

This documentation was generated with the assistance of AI. Please report any inaccuracies.

1.1.8

  • 📝 New documentation site, with usage guides and code examples.

  • 👷 Gitflow development model: develop integration branch with snapshot publishing, release workflow on main, automatic version sync after each release, and security scans.

  • ⬆️ Updated irurueta-android-glutils to 1.1.13 and irurueta-android-test-utils to 1.3.3. JVM unit tests that use this library (including Robolectric) now need a JDK 21 runtime, because a transitive dependency of irurueta-android-glutils is compiled for Java 21; the library itself still targets JVM 17.

1.1.7

  • ⬆️ Built with Android Gradle Plugin 9.0.1, Gradle 9.4.0 and Kotlin 2.3.10.

  • ⬆️ Updated irurueta-android-glutils to 1.1.11 and other dependencies.

1.1.6

  • ♻️ Minimum SDK raised from 24 to 26.

  • ⬆️ Updated Kotlin to 2.3.0, irurueta-android-glutils to 1.1.10 and other dependencies.

1.1.5

  • ⬆️ Updated Android Gradle Plugin to 8.13.0, Kotlin to 2.2.20, irurueta-android-glutils to 1.1.9 and other dependencies.
