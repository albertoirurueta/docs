Configuration reference

This documentation was generated with the assistance of AI. Please report any inaccuracies.

All properties belong to com.irurueta.android.gl.cube.CubeTextureView. Every setter requests a new frame. "Needs surface" means that the property can only be set once the OpenGL surface exists (see Waiting for the surface); otherwise IllegalStateException is thrown.

OpenGL configuration

The view always creates an OpenGL ES 2.0 context with an RGBA 8888 configuration, a 16 bit depth buffer and no stencil buffer, sets isOpaque = false so the background is transparent, and renders in RENDER_MODE_WHEN_DIRTY.
