Installation

This documentation was generated with the assistance of AI. Please report any inaccuracies.

The library is published to Maven Central as an Android library (AAR).

Group ID

com.irurueta

Artifact ID

irurueta-android-test-utils

Latest release

1.3.3

License

Apache License 2.0

Requirements

  • Android minSdk 26 (Android 8.0) or later.

  • JUnit 4: ConditionalIgnoreRule is a JUnit 4 MethodRule.

  • The library is compiled against SDK 36 with Java/Kotlin JVM target 17. It depends on kotlin-reflect and androidx.test.espresso:espresso-core, which Gradle resolves transitively.

Gradle (Kotlin DSL)

Make sure mavenCentral() is among your repositories (in settings.gradle.kts):

dependencyResolutionManagement {
    repositories {
        google()
        mavenCentral()
    }
}

Then add the dependency to the test source sets of your module’s build.gradle.kts. The reflection helpers work in local unit tests; the conditional-ignore rule and the gesture helpers are meant for instrumented tests:

dependencies {
    // reflection helpers in local unit tests
    testImplementation("com.irurueta:irurueta-android-test-utils:1.3.3")

    // every utility in instrumented tests
    androidTestImplementation("com.irurueta:irurueta-android-test-utils:1.3.3")
}

Gradle (Groovy DSL)

dependencies {
    testImplementation 'com.irurueta:irurueta-android-test-utils:1.3.3'
    androidTestImplementation 'com.irurueta:irurueta-android-test-utils:1.3.3'
}

Version catalog

[versions]
iruruetaTestUtils = "1.3.3"

[libraries]
irurueta-test-utils = { module = "com.irurueta:irurueta-android-test-utils", version.ref = "iruruetaTestUtils" }
dependencies {
    testImplementation(libs.irurueta.test.utils)
    androidTestImplementation(libs.irurueta.test.utils)
}

Building from source

To use the library from source instead, clone the repository and include the lib module in your build, or publish it to your local Maven repository. See Building, testing and contributing.
