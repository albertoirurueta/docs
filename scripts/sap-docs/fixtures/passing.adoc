= Internal Tables
:description: How a program keeps a list of rows in memory.
:keywords: ABAP, internal table

include::partial$ai-disclaimer.adoc[]

An internal table is the list a program builds in memory while it runs. Think of a spreadsheet that only exists for as long as
the program does: every row has the same columns, and the program can add, read and remove rows. This page shows how to
declare one and how to fill it.

== Before you read

You should know what a variable is.

== Key terms

* xref:glossary.adoc#internal-table[Internal table]: a table in memory.
* xref:glossary.adoc#work-area[Work area]: one row of a table.

== Declaring a table

[source,abap]
----
== not a heading, it is inside a listing
DATA items TYPE STANDARD TABLE OF string WITH EMPTY KEY.
----

== Summary

An internal table keeps rows in memory; a work area holds one row.
