What’s Changed & Migration

This content was generated with the assistance of AI and should be verified against the official documentation before being relied on in production.

This page is written against FastAPI 0.142.2 (released 2026-09-30), Pydantic 2.13 and Starlette 1.7, checked on 2026-10-02. FastAPI supports Python 3.10 through 3.14; every current-style Python example on this page was executed on Python 3.13 with TestClient or plain execution, and every deprecated or removed form is shown only as the old way and was not run as a recommendation. FastAPI is still a 0.x project, so almost every release can contain a visible change, and a large part of the material on the web (tutorials, blog posts, and the reference book listed in the section bibliography) was written before many of those releases. This page is the map between that older material and today’s documentation: which release changed what, on which date, what the old code looked like, what to write now, which page of this section covers it, and where the official release notes say it.

How to Read the Tables

Each row has the FastAPI version that introduced the change, the release date, the old way you will meet in older code, the new way, a link to the page of this section that covers it, and a link to the official release notes. The version links use the anchor form of the release notes page, which is the version without dots followed by the release date. Where a change belongs to a library or to Python rather than to a numbered FastAPI release, the version column says so and the last column links the official page that documents it instead.

Two rules of thumb make migrations safe. Pin FastAPI to an exact version in pyproject.toml or in a lock file, as the official versions page advises for a 0.x project, and read the release notes entries marked as breaking before every upgrade. Run the test suite (it prints a deprecation warning from Starlette about httpx and httpx2 with the current TestClient; see Testing) after each upgrade: most of the changes below fail loudly at import time or on the first request, not silently in production.

Startup and Shutdown: From on_event to lifespan

Older code registers startup and shutdown handlers with a decorator that is now deprecated:

Old way (deprecated, not recommended; not run)
from fastapi import FastAPI

app = FastAPI()
resources: dict[str, str] = {}


@app.on_event("startup")
async def startup() -> None:
    resources["db"] = "connected"


@app.on_event("shutdown")
async def shutdown() -> None:
    resources.clear()

Source: FastAPI: Lifespan Events, Alternative Events (deprecated)

The replacement is one async context manager: everything before yield is startup, everything after is shutdown, and the two halves can share local variables. The with TestClient(app) block runs the lifespan; without the with, it does not run.

Current: lifespan context manager
from collections.abc import AsyncIterator
from contextlib import asynccontextmanager

from fastapi import FastAPI
from fastapi.testclient import TestClient

resources: dict[str, str] = {}


@asynccontextmanager
async def lifespan(app: FastAPI) -> AsyncIterator[None]:
    resources["db"] = "connected"      # startup
    yield
    resources.clear()                  # shutdown


app = FastAPI(lifespan=lifespan)


@app.get("/status")
def status() -> dict[str, str]:
    return resources


with TestClient(app) as client:
    print(client.get("/status").json())
print("after shutdown:", resources)

from typing import Annotated

from pydantic import BaseModel, ConfigDict, Field, ValidationError, field_validator


class Book(BaseModel):

Annotated Instead of Default-Value Metadata

The older style is still accepted, so you will meet it in existing code. New code uses Annotated, because the default value stays a real default (and works for plain Python calls) and the metadata can be shared through an alias.

Old way (still accepted, not recommended; not run)
from fastapi import Depends, FastAPI, Query

app = FastAPI()


def pagination(limit: int = Query(default=10, ge=1, le=100)) -> int:
    return limit


@app.get("/books")
def list_books(q: str | None = Query(default=None, max_length=50), limit: int = Depends(pagination)):
    return {"q": q, "limit": limit}

Source: FastAPI: Query Parameters and String Validations

Current: Annotated with a reusable alias
from typing import Annotated

from fastapi import Depends, FastAPI, Query
from fastapi.testclient import TestClient

app = FastAPI()


def pagination(limit: Annotated[int, Query(ge=1, le=100)] = 10) -> int:
    return limit


Limit = Annotated[int, Depends(pagination)]       # reusable alias


@app.get("/books")
def list_books(limit: Limit, q: Annotated[str | None, Query(max_length=50)] = None) -> dict:
    return {"q": q, "limit": limit}


client = TestClient(app)
print(client.get("/books", params={"q": "dune", "limit": 5}).json())
print(client.get("/books", params={"limit": 500}).status_code)

Security Fundamentals and OAuth2 Scopes & Authorization

0.122.0

A related misunderstanding in older material is treating the password flow and the authorization code flow as one thing. They are different OAuth2 flows: the password flow sends credentials to your own token endpoint, while the authorization code flow redirects the user to an identity provider. The current form of the password flow is shown below.

Old way (python-jose, passlib, utcnow; not run)
import os
from datetime import datetime, timedelta

from jose import jwt
from passlib.context import CryptContext

SECRET_KEY = os.environ["SECRET_KEY"]          # never hardcode a key
pwd = CryptContext(schemes=["bcrypt"])
token = jwt.encode({"sub": "ana", "exp": datetime.utcnow() + timedelta(minutes=30)}, SECRET_KEY)

Source: FastAPI: OAuth2 with Password (and hashing), Bearer with JWT tokens

The current example reads the signing key from the environment (generate one with openssl rand -hex 32 and keep it in your secret store), uses PyJWT and pwdlib, and shows that a missing token now answers 401.

Current: PyJWT, pwdlib, timezone-aware expiry, 401 without credentials
import os
import secrets
from datetime import datetime, timedelta, timezone
from typing import Annotated

import jwt
from fastapi import Depends, FastAPI
from fastapi.security import OAuth2PasswordBearer
from fastapi.testclient import TestClient
from pwdlib import PasswordHash

# In a real app this comes from settings (openssl rand -hex 32); a random value keeps the demo self-contained.
SECRET_KEY = os.environ.get("BOOKSHELF_SECRET_KEY") or secrets.token_hex(32)
ALGORITHM = "HS256"

password_hash = PasswordHash.recommended()          # Argon2
oauth2_scheme = OAuth2PasswordBearer(tokenUrl="token")
app = FastAPI()


def create_token(subject: str) -> str:
    expire = datetime.now(timezone.utc) + timedelta(minutes=30)
    return jwt.encode({"sub": subject, "exp": expire}, SECRET_KEY, algorithm=ALGORITHM)


@app.get("/me")
def me(token: Annotated[str, Depends(oauth2_scheme)]) -> dict[str, str]:
    payload = jwt.decode(token, SECRET_KEY, algorithms=[ALGORITHM])
    return {"user": payload["sub"]}


hashed = password_hash.hash("a-test-password")
print(password_hash.verify("a-test-password", hashed))

client = TestClient(app)
print(client.get("/me").status_code)
print(client.get("/me", headers={"Authorization": f"Bearer {create_token('ana')}"}).json())

Dependency Injection

0.123.5
Current: settings, a yield dependency with scope, an override and a partial
from collections.abc import Iterator
from functools import cache, partial
from typing import Annotated

from fastapi import Depends, FastAPI
from fastapi.testclient import TestClient
from pydantic_settings import BaseSettings, SettingsConfigDict


class Settings(BaseSettings):
    model_config = SettingsConfigDict(env_prefix="BOOKSHELF_")
    database_url: str = "sqlite:///./bookshelf.db"


@cache
def get_settings() -> Settings:
    return Settings()


events: list[str] = []


def get_session(settings: Annotated[Settings, Depends(get_settings)]) -> Iterator[str]:
    events.append("open " + settings.database_url)
    try:
        yield "session"
    finally:
        events.append("close")


def greeting(prefix: str) -> str:
    return prefix + "!"


app = FastAPI()


@app.get("/books")
def books(session: Annotated[str, Depends(get_session, scope="function")]) -> dict[str, str]:
    return {"using": session}


@app.get("/hello")
def hello(text: Annotated[str, Depends(partial(greeting, "hello"))]) -> str:
    return text


client = TestClient(app)
print(client.get("/books").json(), events)
print(client.get("/hello").json())

app.dependency_overrides[get_session] = lambda: "fake-session"
print(client.get("/books").json())

Testing and Templates

Older material often tests by calling path functions directly, which skips validation, dependencies and serialization. The documentation now tests through the application: TestClient, dependency_overrides, with TestClient(app) to run the lifespan, WebSocket sessions, and async tests with pytest.mark.anyio and httpx.AsyncClient over ASGITransport. The TestClient shown elsewhere on this page is the synchronous form; the async form is below. See Testing for the full treatment.

Current: async test client over ASGITransport
import anyio
import httpx
from fastapi import FastAPI

app = FastAPI()


@app.get("/")
async def root() -> dict[str, str]:
    return {"message": "Tomato"}


async def main() -> None:
    async with httpx.AsyncClient(transport=httpx.ASGITransport(app=app), base_url="http://test") as client:
        response = await client.get("/")
    print(response.status_code, response.json())


anyio.run(main)

A form is a POST body, never a GET: older tutorials sometimes declare Form() on a GET endpoint, which a browser form cannot meaningfully use. The current form models:

Current: Pydantic models for Form and Query parameters
from typing import Annotated, Literal

from fastapi import FastAPI, Form, Query
from fastapi.testclient import TestClient
from pydantic import BaseModel, Field

app = FastAPI()


class BookForm(BaseModel):
    model_config = {"extra": "forbid"}
    title: str
    year: int


class Filters(BaseModel):
    model_config = {"extra": "forbid"}
    limit: int = Field(100, gt=0, le=100)
    order_by: Literal["title", "year"] = "title"


@app.post("/books")
def create(form: Annotated[BookForm, Form()]) -> BookForm:
    return form


@app.get("/books")
def search(filters: Annotated[Filters, Query()]) -> Filters:
    return filters


client = TestClient(app)
print(client.post("/books", data={"title": "Dune", "year": "1965"}).json())
print(client.get("/books", params={"order_by": "year"}).json())
print(client.get("/books", params={"unknown": "x"}).status_code)

from collections.abc import AsyncIterable

from fastapi import FastAPI
from fastapi.sse import EventSourceResponse
from fastapi.testclient import TestClient
from pydantic import BaseModel

app = FastAPI()


class Book(BaseModel):
    title: str


@app.get("/books/stream")
async def stream_books() -> AsyncIterable[Book]:
    yield Book(title="Dune")
    yield Book(title="Emma")


@app.get("/books/events", response_class=EventSourceResponse)
async def book_events() -> AsyncIterable[Book]:
    yield Book(title="Dune")

lines = client.get("/books/stream")

events = client.get("/books/events")
print(events.headers["content-type"], events.text.strip().splitlines())

Customization is the telemetry argument of FastAPI(…​). This example sends spans to an in-memory exporter so it can run without a collector:

Current: telemetry argument with an in-memory exporter
from fastapi import FastAPI
from fastapi.testclient import TestClient
from opentelemetry.sdk.trace import TracerProvider
from opentelemetry.sdk.trace.export import SimpleSpanProcessor
from opentelemetry.sdk.trace.export.in_memory_span_exporter import InMemorySpanExporter

exporter = InMemorySpanExporter()
provider = TracerProvider()
provider.add_span_processor(SimpleSpanProcessor(exporter))

app = FastAPI(telemetry={"tracer_provider": provider})


@app.get("/books/{book_id}")
def read_book(book_id: int) -> dict[str, int]:
    return {"book_id": book_id}


TestClient(app).get("/books/1")
print(sorted({span.name for span in exporter.get_finished_spans()}))

Corrected Forms for Frequent Mistakes

Printed books and tutorials contain code that never worked, and mistakes copy easily from one source to another. These are the correct forms of the most frequent ones, so you can recognise and fix them in older code:

  • Types come from typing or the standard library, and models from pydantic; str is the built-in string type, and BaseModel is the base class for models.

  • Table metadata comes from SQLModel or SQLAlchemy as documented on SQL Databases with SQLModel.

  • Streaming a large file means yielding it in chunks (see Streaming, JSON Lines & SSE), not reading the whole file into memory first.

  • Every import should be checked against the official reference, and every example should run before it is trusted, which is how the examples on this page were prepared.

Upgrade Checklist

  • Pin FastAPI and read the release notes between your current and target versions, concentrating on entries marked breaking (0.106.0, 0.132.0, 0.137.0 among those listed above).

  • Move to fastapi[standard] and the fastapi command; drop fastapi-slim.

  • Remove Pydantic v1 code before upgrading past 0.126.0, using the Pydantic migration guide and bump-pydantic.

  • Replace on_event with lifespan, python-jose and passlib with PyJWT and pwdlib, and utcnow() with datetime.now(timezone.utc).

  • Check tests that expected 403 for missing credentials, and clients that send JSON without a JSON Content-Type.

  • Move Query() and Depends() defaults to Annotated gradually; both styles keep working.

  • Re-run your tests with a warning filter set to error to find deprecated calls such as ORJSONResponse early.
