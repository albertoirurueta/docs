Backend Development

This content was generated with the assistance of AI and should be verified against the official documentation before being relied on in production.

A growing collection of backend-development references — practical, example-driven documentation on the core technologies of server-side application development, from the Java language itself to the Spring Boot framework. To choose between frameworks, start with the Backend Frameworks Comparison.

  • FastAPI — building HTTP APIs with FastAPI on Starlette and Pydantic v2 through one running Bookshelf API: path operations and parameters validated with Annotated, request bodies and response models, errors, streaming (JSON Lines and Server-Sent Events), dependency injection with yield, OAuth2/JWT security with PyJWT and pwdlib, SQLModel and other data stores, settings and lifespan, APIRouter project structure, OpenAPI and Swagger UI, WebSockets, static files and templates, testing with TestClient, and deployment with the fastapi CLI, Docker and Kubernetes, plus a downloadable cheat sheet.

  • Flask — building web applications and JSON APIs with Flask 3.1 on Werkzeug and Jinja through one running Bookshelf application: the application factory and blueprints, routing, requests and responses, templates, sessions and forms, Flask-SQLAlchemy and Flask-Migrate, Flask-Login and JWT authentication, flask-smorest and OpenAPI, caching, Celery jobs, async with gevent and Quart, testing, and deployment behind Gunicorn and nginx, in Docker and on Kubernetes, plus a downloadable cheat sheet.

  • Tornado — the asynchronous Python web framework and networking library through one running Bookshelf Live application: the event loop and coroutines on asyncio, request handlers and routing, templates and UI modules, signed cookies and XSRF protection, WebSockets and server-sent events, AsyncHTTPClient, async database drivers, testing with tornado.testing, and running and deploying, plus a downloadable cheat sheet.

  • Pyramid — the small, configurable WSGI framework through one running Bookshelf Shelves application: the Configurator and two-phase configuration, URL dispatch and traversal, views and renderers, security policies and ACL authorization, CSRF protection, Deform and Colander forms, SQLAlchemy with pyramid_tm, events and tweens, testing with WebTest, and deployment, plus a downloadable cheat sheet.

  • Django (in Web Development) — the batteries-included Python web framework, including REST APIs with Django REST framework and Django Ninja.

  • PHP and Laravel (in Web Development) — the full-stack PHP framework, including REST/JSON:API backends with Sanctum and Passport.
