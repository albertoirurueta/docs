Hands-on Lab

This content was generated with the assistance of AI and should be verified against the official documentation before being relied on in production.

Checked on 2026-11-09 against Grafana 13.3.x and Kibana 9.5.x. Tested with Grafana Enterprise 13.3.0 (the free image, no licence key) and with Elasticsearch and Kibana 9.5.6 on Docker Desktop with 8 GB of memory.

Every other page in this section ends with a "Verify it in the lab" step. This page is the lab: a single Compose project that starts the same application, the same traffic and the same notification receiver in front of either monitoring stack, so that a dashboard or an alert built in Grafana can be compared line by line with the one built in Kibana. Nothing here is specific to a cloud account, a licence key or an outbound network connection once the images are pulled.

What the lab contains

Service Role Profile and port

bookshelf

A small stand-in for the Bookshelf Spring Boot service (see the note below). Serves /api/books, /api/books/{id}, /api/loans and /api/search, exposes Micrometer-style metrics at /actuator/prometheus, writes JSON log lines to a file and to stdout, and exports traces and logs over OTLP.

both; 8080

loadgen

Sends about ten requests per second. A control endpoint switches the traffic between normal, failing, slow, log-errors and stop.

both; 8090

webhook-receiver

Accepts any POST, prints it as one WEBHOOK line and keeps the last 50 deliveries, which any GET returns as JSON. Grafana posts to /grafana, Kibana to /kibana. Inside the network it also answers to the name webhook.lab, because the webhook connector form of Kibana 9.5 rejects a host name without a dot.

both; 8081 on the host, 8080 inside the network

postgres

Holds the placeholder tables book and loan that the Grafana data source pages query.

grafana

alloy

Grafana Alloy: receives OTLP traces and forwards them to Tempo, and tails the JSON log file into Loki with the label application="bookshelf".

grafana; 12345 for its own UI

prometheus

Scrapes bookshelf:8080/actuator/prometheus every 15 seconds. Started with --web.enable-remote-write-receiver, so Tempo’s span metrics and recording rules can be written to it.

grafana; 9090

loki, tempo

Single-binary log and trace stores on local disk. Tempo’s metrics generator writes span metrics to Prometheus.

grafana; 3100 and 3200

grafana

Grafana Enterprise 13.3.0 image (it runs as the open-source edition without a licence). Data sources, the dashboard and the alerting resources are provisioned from files. Alert state history is stored in Loki.

grafana; 3000

edot-collector

The Elastic Distribution of OpenTelemetry Collector in gateway mode: OTLP in, the elasticapm components for the APM views, Elasticsearch out.

kibana

elasticsearch, kibana-setup, kibana

Elasticsearch 9.5.6 with security on and a self-generated trial licence, a one-shot service that sets the kibana_system password, and Kibana 9.5.6.

kibana; 9200 and 5601

The Bookshelf service in the lab is a stand-in written in about 150 lines of Python with no dependencies, not the Spring Boot application. It produces what the monitoring pages need: the metric names and labels that Micrometer publishes (http_server_requests_seconds_count, _sum and _bucket with application, method, outcome, status and uri, plus hikaricp_connections_active, hikaricp_connections_max and jvm_memory_used_bytes), JSON log lines with level, message, uri, status, trace_id and span_id, and one OTLP trace span per request with the OpenTelemetry HTTP attributes. Its failures are on demand and repeatable, which a real application’s are not. For the real setup of Spring Boot see Metrics and Observability, Logging and the other Bookshelf pages linked from there.

Source: Docker: Using profiles with Compose (services with a profiles list start only when a profile is selected; a service without one always starts), Grafana: Run Grafana Docker image and Elastic: Install Kibana with Docker.

Requirements

  • Docker with the Compose plugin (version 2.20 or later). The files were run with Docker Desktop 29.9 and Compose v2.

  • Memory: the grafana profile used about 1 GB in total; the kibana profile needs 4 GB or more (Elasticsearch alone is capped at 2 GB). Give Docker Desktop at least 6 GB if you run the Kibana profile. Start one profile at a time; they are built to be alternatives.

  • Free host ports 3000, 3100, 3200, 5601, 8080, 8081, 8090, 9090, 9200 and 12345.

  • Images are pulled on the first start: roughly 3 GB for the grafana profile and 4 GB for the kibana profile.

  • The tools curl and jq on the host for the verification commands.

Bookshelf, the load generator and the webhook receiver

bookshelf/app.py is the stand-in service. The X-Fault request header (set by the load generator) chooses the fault: error answers 70 percent of the requests with a 500 and logs an ERROR line for each, slow adds 0.7 to 1.5 seconds, and log-errors keeps the answers at 200 but logs an ERROR line per request.

bookshelf/app.py 
"""Bookshelf stand-in: a small HTTP service that exposes the telemetry of the Bookshelf Spring Boot application."""
import json, math, os, queue, random, threading, time, urllib.request
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer

APP = "bookshelf"
ENV = os.environ.get("DEPLOYMENT_ENVIRONMENT", "lab")
OTLP = os.environ.get("OTEL_EXPORTER_OTLP_ENDPOINT", "")
OTLP_LOGS = os.environ.get("OTEL_LOGS_EXPORTER", "none") == "otlp"
LOG_FILE = os.environ.get("LOG_FILE", "")
BUCKETS = [0.05, 0.1, 0.25, 0.5, 1.0, 2.5, 5.0]
ROUTES = ["/api/books", "/api/books/{id}", "/api/loans", "/api/search"]

lock = threading.Lock()
counts, sums, buckets = {}, {}, {}
active = 0
export_q = queue.Queue(maxsize=10000)
started = time.time()


def now_ns():
    return str(time.time_ns())


def attrs(d):
    out = []
    for k, v in d.items():
        if isinstance(v, bool):
            out.append({"key": k, "value": {"boolValue": v}})
        elif isinstance(v, int):
            out.append({"key": k, "value": {"intValue": str(v)}})
        else:
            out.append({"key": k, "value": {"stringValue": str(v)}})
    return out


RESOURCE = {"attributes": attrs({"service.name": APP, "deployment.environment.name": ENV,
                                 "service.version": "1.0.0"})}


def log(level, message, **extra):
    rec = {"timestamp": time.strftime("%Y-%m-%dT%H:%M:%S", time.gmtime()) + ".%03dZ" % (time.time() * 1000 % 1000),
           "level": level, "logger": "com.irurueta.bookshelf", "message": message, "application": APP}
    rec.update(extra)
    line = json.dumps(rec)
    print(line, flush=True)
    if LOG_FILE:
        with open(LOG_FILE, "a") as f:
            f.write(line + "\n")
    if OTLP and OTLP_LOGS:
        sev = {"INFO": 9, "WARN": 13, "ERROR": 17}[level]
        export_q.put(("logs", {"timeUnixNano": now_ns(), "severityNumber": sev, "severityText": level,
                               "body": {"stringValue": message},
                               "traceId": extra.get("trace_id", ""), "spanId": extra.get("span_id", ""),
                               "attributes": attrs({k: v for k, v in extra.items() if k not in ("trace_id", "span_id")})}))


def exporter():
    spans, logs = [], []
    last = time.time()
    while True:
        try:
            kind, item = export_q.get(timeout=1)
            (spans if kind == "spans" else logs).append(item)
        except queue.Empty:
            pass
        if time.time() - last >= 1 and (spans or logs):
            last = time.time()
            if spans:
                post("/v1/traces", {"resourceSpans": [{"resource": RESOURCE, "scopeSpans": [
                    {"scope": {"name": "bookshelf"}, "spans": spans}]}]})
                spans = []
            if logs:
                post("/v1/logs", {"resourceLogs": [{"resource": RESOURCE, "scopeLogs": [
                    {"scope": {"name": "bookshelf"}, "logRecords": logs}]}]})
                logs = []


def post(path, body):
    try:
        req = urllib.request.Request(OTLP + path, json.dumps(body).encode(), {"Content-Type": "application/json"})
        urllib.request.urlopen(req, timeout=5).read()
    except Exception as e:  # collector down: drop the batch
        print("otlp export failed:", e, flush=True)


def record(uri, method, status, seconds):
    outcome = "SUCCESS" if status < 400 else ("CLIENT_ERROR" if status < 500 else "SERVER_ERROR")
    key = (uri, method, str(status), outcome)
    with lock:
        counts[key] = counts.get(key, 0) + 1
        sums[key] = sums.get(key, 0.0) + seconds
        b = buckets.setdefault(key, [0] * (len(BUCKETS) + 1))
        for i, le in enumerate(BUCKETS):
            if seconds <= le:
                b[i] += 1
        b[-1] += 1


def metrics_text():
    out = ["# TYPE http_server_requests_seconds histogram"]
    with lock:
        for key in sorted(counts):
            uri, method, status, outcome = key
            lab = 'application="%s",method="%s",outcome="%s",status="%s",uri="%s"' % (APP, method, outcome, status, uri)
            for i, le in enumerate(BUCKETS):
                out.append('http_server_requests_seconds_bucket{%s,le="%s"} %d' % (lab, le, buckets[key][i]))
            out.append('http_server_requests_seconds_bucket{%s,le="+Inf"} %d' % (lab, buckets[key][-1]))
            out.append('http_server_requests_seconds_count{%s} %d' % (lab, counts[key]))
            out.append('http_server_requests_seconds_sum{%s} %.6f' % (lab, sums[key]))
        act = active
    out += ["# TYPE hikaricp_connections_active gauge",
            'hikaricp_connections_active{application="%s",pool="HikariPool-1"} %d' % (APP, min(10, act)),
            "# TYPE hikaricp_connections_max gauge",
            'hikaricp_connections_max{application="%s",pool="HikariPool-1"} 10' % APP,
            "# TYPE jvm_memory_used_bytes gauge",
            'jvm_memory_used_bytes{application="%s",area="heap"} %d' % (APP, 180e6 + 20e6 * math.sin(time.time() / 60)),
            "# TYPE process_uptime_seconds gauge",
            'process_uptime_seconds{application="%s"} %.1f' % (APP, time.time() - started)]
    return "\n".join(out) + "\n"


class Handler(BaseHTTPRequestHandler):
    protocol_version = "HTTP/1.1"

    def log_message(self, *a):
        pass

    def send(self, status, body, ctype="application/json"):
        data = body.encode()
        self.send_response(status)
        self.send_header("Content-Type", ctype)
        self.send_header("Content-Length", str(len(data)))
        self.end_headers()
        self.wfile.write(data)

    def do_GET(self):
        global active
        path = self.path.split("?")[0]
        if path == "/actuator/prometheus":
            return self.send(200, metrics_text(), "text/plain; version=0.0.4")
        if path == "/actuator/health":
            return self.send(200, '{"status":"UP"}')
        if not path.startswith("/api/"):
            return self.send(404, '{"error":"not found"}')
        route = "/api/books/{id}" if path.startswith("/api/books/") else path
        if route not in ROUTES:
            return self.send(404, '{"error":"not found"}')
        fault = self.headers.get("X-Fault", "")
        trace_id, span_id = "%032x" % random.getrandbits(128), "%016x" % random.getrandbits(64)
        start = time.time()
        start_ns = time.time_ns()
        with lock:
            active += 1
        try:
            delay = random.lognormvariate(math.log(0.08), 0.5)
            if fault == "slow":
                delay = random.uniform(0.7, 1.5)
            time.sleep(delay)
            status = 200
            if fault == "error" and random.random() < 0.7:
                status = 500
            elif route == "/api/books/{id}" and random.random() < 0.02:
                status = 404
            if status == 500:
                log("ERROR", "Unhandled exception while serving " + route, uri=route, status=status,
                    trace_id=trace_id, span_id=span_id)
            elif fault == "log-errors":
                log("ERROR", "Loan reminder job failed, retry scheduled", uri=route, status=status,
                    trace_id=trace_id, span_id=span_id)
            elif random.random() < 0.05:
                log("INFO", "Served " + route, uri=route, status=status, trace_id=trace_id, span_id=span_id)
            self.send(status, json.dumps({"route": route, "status": status}))
        finally:
            with lock:
                active -= 1
        seconds = time.time() - start
        record(route, "GET", status, seconds)
        if OTLP:
            export_q.put(("spans", {
                "traceId": trace_id, "spanId": span_id, "name": "GET " + route, "kind": 2,
                "startTimeUnixNano": str(start_ns), "endTimeUnixNano": str(time.time_ns()),
                "attributes": attrs({"http.request.method": "GET", "url.path": path, "http.route": route,
                                     "http.response.status_code": status}),
                "status": {"code": 2 if status >= 500 else 0}}))


if __name__ == "__main__":
    if OTLP:
        threading.Thread(target=exporter, daemon=True).start()
    log("INFO", "Bookshelf started")

"""Load generator with a control endpoint: POST /mode/<normal|failing|slow|log-errors|stop> on port 8090."""
import os, random, threading, time, urllib.request
from http.server import BaseHTTPRequestHandler, HTTPServer

TARGET = os.environ.get("TARGET", "http://bookshelf:8080")
RATE = float(os.environ.get("RATE", "10"))
FAULTS = {"normal": "", "failing": "error", "slow": "slow", "log-errors": "log-errors"}
state = {"mode": "normal"}
URIS = ["/api/books", "/api/books/42", "/api/loans", "/api/search"]


def worker():
    while True:
        mode = state["mode"]
        if mode != "stop":
            req = urllib.request.Request(TARGET + random.choice(URIS), headers={"X-Fault": FAULTS[mode]})
            try:
                urllib.request.urlopen(req, timeout=10).read()
            except Exception:
                pass
        time.sleep(random.expovariate(RATE / 4))  # 4 workers share the rate


class Control(BaseHTTPRequestHandler):
    def log_message(self, *a):
        pass

    def reply(self, text):
        self.send_response(200)
        self.send_header("Content-Length", str(len(text)))
        self.end_headers()
        self.wfile.write(text.encode())

    def do_POST(self):
        name = self.path.rsplit("/", 1)[-1]
        if self.path.startswith("/mode/") and (name in FAULTS or name == "stop"):
            state["mode"] = name
        self.reply("mode=%s\n" % state["mode"])

    def do_GET(self):
        self.reply("mode=%s\n" % state["mode"])


for _ in range(4):
    threading.Thread(target=worker, daemon=True).start()
HTTPServer(("0.0.0.0", 8090), Control).serve_forever()

"""Webhook receiver: logs every POST (path and body) to stdout and keeps them for GET /received."""
import json, time
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer

received = []


class H(BaseHTTPRequestHandler):
    def log_message(self, *a):
        pass

    def do_POST(self):
        body = self.rfile.read(int(self.headers.get("Content-Length", 0))).decode(errors="replace")
        entry = {"time": time.strftime("%H:%M:%S"), "path": self.path, "body": body[:20000]}
        received.append(entry)
        print("WEBHOOK", json.dumps(entry), flush=True)
        self.send_response(200)
        self.send_header("Content-Length", "2")
        self.end_headers()
        self.wfile.write(b"ok")

    def do_GET(self):
        data = json.dumps(received[-50:], indent=1).encode()
        self.send_response(200)
        self.send_header("Content-Type", "application/json")
        self.send_header("Content-Length", str(len(data)))
        self.end_headers()
        self.wfile.write(data)


ThreadingHTTPServer(("0.0.0.0", 8080), H).serve_forever()

Start the kibana profile

Stop the other profile first (docker compose --profile grafana down), then:

docker compose --profile kibana up -d
until curl -fsS http://localhost:5601/api/status >/dev/null; do sleep 5; done

The one-shot kibana-setup service exits after setting the kibana_system password; docker compose ps -a shows it as exited with code 0. Kibana takes one to two minutes to become ready. Log in at http://localhost:5601 as elastic with the password from .env. The self-generated trial licence is requested by xpack.license.self_generated.type=trial: webhook connectors need a Gold or higher licence and maintenance windows need Platinum, so on a Basic licence those two features are unavailable. Check it with curl -s -u elastic:lab-elastic-password http://localhost:9200/_license | jq .license.type, which prints trial. The trial lasts 30 days from the first start.

Once the load generator has run for a minute or two, create the Kibana objects (the space bookshelf, the data views, the webhook connector, the five rules, the SLO, the maintenance window and the dashboard) with kibana/setup.sh. It needs curl and jq, and reads ELASTIC_PASSWORD (default lab-elastic-password) and KIBANA_URL (default http://localhost:5601), so export the values from .env first:

set -a; . ./.env; set +a
bash kibana/setup.sh

Stop and clean up

docker compose --profile grafana --profile kibana down -v
docker ps -a

down -v removes the containers, the network and the named volumes (grafana-data, esdata and the log volume), which is what you want after an experiment: Elasticsearch data and the trial licence start from zero on the next start. Without -v the volumes survive, so provisioned files that you changed are not applied to an existing Grafana database as new resources unless their uid is new.

What can go wrong

  • The kibana profile restarts or exits with code 137. Elasticsearch ran out of memory: raise the Docker Desktop memory or lower the load.

  • Kibana answers 503 for a while. It waits for Elasticsearch to be healthy and then migrates saved objects; check docker compose logs kibana and wait.

  • Both profiles started together. Both define the alias otel-gateway, so Bookshelf’s OTLP traffic would go to either one; always start one profile at a time.

  • The Alloy container exits on start. Components marked experimental are refused by default; the lab configuration uses only generally available components.

  • Rules exist but never fire. Check Alerting, Alert rules for the evaluation state and for health errors; a query error is shown on the rule, and the Prometheus data source must have uid prometheus.

  • Webhook deliveries are missing. Read docker compose logs webhook-receiver first; then the contact point or connector test; a request that never arrives usually means a typo in the host name (webhook-receiver, port 8080, paths /grafana and /kibana).

  • Changing .env has no effect on Elasticsearch passwords. The elastic password is set on the first start with an empty esdata volume; run docker compose down -v to reset it.

  • Dashboards that were edited in the UI revert. The provider has allowUiUpdates: false; edit the JSON file instead.
