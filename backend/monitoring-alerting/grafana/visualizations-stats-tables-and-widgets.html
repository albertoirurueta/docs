Grafana Stats, Tables and Widgets

This content was generated with the assistance of AI and should be verified against the official documentation before being relied on in production.

Checked on 2026-11-09 against Grafana 13.3.x.

To do this by hand, follow Stat, Gauge and Bar Gauge and Tables.

The graphs of a dashboard show how things change; the panels on this page show what is true now, give exact values or help the reader navigate. They are the top row of a service dashboard (the numbers you read first), the drill-down tables (the values you copy into a ticket) and the furniture (a purpose note, the list of firing alerts, links to other dashboards). Chart types are covered in Graphs and Charts, the less common panels in Logs, Traces and Special Panels, and the options that all of them share (unit, thresholds, mappings, overrides, data links) in Field Configuration. How a status row fits an overview to detail hierarchy is explained in Dashboard Design Principles.

flowchart TD A{"What does the reader need?"} -->|"One number, now"| B{"Does position in a range matter?"} B -->|"No"| S["Stat, with sparkline"] B -->|"Yes: one value"| G["Gauge"] B -->|"Yes: several values, same range"| BG["Bar gauge"] A -->|"Exact values, many dimensions"| T["Table"] A -->|"Explain or link"| X["Text, Dashboard list, News"] A -->|"What is firing, what changed"| L["Alert list, Annotations list"]

Source: Grafana: Visualizations.

Stat

Source: Grafana: Stat.

What and when. The Stat panel shows one large number per series (or per row), with optional colour and sparkline. Use it to monitor key metrics at a glance, to display an aggregated value such as an average, and to highlight values that cross a threshold. It replaces the Singlestat panel of older Grafana versions.

Options.

Option Behaviour

Show

Calculate reduces each series with a reducer (Last, Mean, Max and so on, set in Calculation) to one value; All values shows one stat per row, with a Limit (default 25, at most 5,000).

Orientation, text mode, wide layout

Auto, Horizontal or Vertical. Text mode is Auto, Value, Value and name, Name or None (Auto shows name and value when there are several series). Wide layout (on by default) applies to Value and name.

Color mode

None, Value, Background Gradient or Background Solid. The colour comes from the thresholds or the colour scheme.

Graph mode

None or Area; Area draws a sparkline and needs a time column in the query. The sparkline hides itself when the panel is too small.

Text alignment, text size

Auto or Center; separate sizes for the title, the value and the percent change.

Show percent change

Off by default; with Calculate it shows the change over the series and has a colour mode (Standard, Inverted, Same as Value) so that a rise can be shown as bad for latency and good for throughput.

Bookshelf example. The top row of "Bookshelf service health" is four stats: request rate, 5xx ratio, p95 latency and availability. The 5xx stat uses the unit Percent (0.0-1.0), thresholds at 0.025 and 0.05 (the red value is the threshold of the matching alert), color mode Background and a sparkline; the p95 stat uses the unit seconds and inverted percent change.

histogram_quantile(0.95, sum by (le) (rate(http_server_requests_seconds_bucket{application="bookshelf"}[$__rate_interval])))

Reference: Grafana: Stat. The ready-made options are explained in Field Configuration.

What can go wrong. Calculate: Last of a series that has stopped being scraped shows the last known value as if it were current, so set a No value text and pair the stat with a "no data" alert (see Designing Actionable Alerts). A stat colour is only as good as its thresholds: a green stat with a wrong unit is worse than no stat.

Gauge

Source: Grafana: Gauge.

What and when. A gauge shows where a single value falls inside a minimum and maximum: an SLO, CPU consumption from 0 to 100 percent, a connection pool, latency against a limit. It needs at least one numeric field; repeat options can show one gauge per series. The gauge was revamped in Grafana 13: the release notes describe the new gauge visualization as generally available in 13.0 after a public preview from January 2026, so older descriptions (and screenshots) of the options do not apply.

Options in 13.3.

  • Style: Circle (fills clockwise from twelve o’clock) or Arc.

  • Bar width factor (0.1 to 1), Segments (1 to 100 equal segments, fully filled each), Bar style (Flat or Rounded; rounded only when there is one segment) and Segment spacing.

  • Neutral value: the starting point of the fill, blank for the minimum. It is the right tool for values that go negative (a network balance, a temperature delta), where zero, not the minimum, is the baseline.

  • Show sparkline (on by default), Show thresholds (a band outside the value band), Show labels (threshold and neutral labels), Endpoint marker (Point, Glow or None; Glow only in dark mode with rounded bars) and the effects Gradient (on by default), Bar glow and Center glow.

  • Orientation, Gauge size (Auto or Manual, with minimum width or height), Text mode, Show (Calculate or All values with a limit of 25 by default) and text sizes.

Use a gauge only when the range is meaningful and fixed. When you would put one gauge per route, a bar gauge is more compact; when the range adds nothing, a stat takes less space. Bookshelf example: HikariCP pool utilisation hikaricp_connections_active / hikaricp_connections_max with the unit Percent (0.0-1.0), min 0 and max 1, thresholds at 0.7 and 0.9.

Bar gauge

Source: Grafana: Bar gauge.

A bar gauge reduces each field to one value and draws it as a bar between a minimum and maximum, which makes it the compact way to compare several values on one scale: KPIs, completion rates, the utilisation of each pod. The data needs at least one numeric field, and text or time fields can supply labels.

Options: Show (Calculate by default, or All values with a limit of 25), Calculation, Orientation, Display mode (Basic, Retro LCD or Gradient), Value display (Value color, Text color, Hidden), Name placement (Auto, Top, Left or Hidden; vertical bars allow only Auto or Hidden), Show unfilled area (not for Retro LCD), Bar size (Auto or Manual, with minimum width, minimum height and maximum height) and text sizes. Bookshelf example: the JVM heap used per instance against its maximum, which fills a row of bars and turns red on the instance that is about to run out of memory.

Table

Source: Grafana: Table.

What and when. The table is the preferred panel for column and row data: results of a SQL query, a list of firing alerts as a table, the slowest routes, the series of an instant query. Every cell needs a value; if cells are missing the table may display none of the data, so hide or drop columns with transformations, overrides or a query that returns only the necessary columns.

Table options. Show the header, frozen columns, cell height (Small, Medium, Large), maximum row height (with Wrap text), pagination, minimum column width (default 150 pixels), column width, alignment (Auto, Left, Center, Right), column filter and wrap header text. With several queries a dataset selector appears at the bottom, in edit mode only.

Cell types (set per column, usually with an override):

Type Use

Auto

Plain text or number.

Colored text, Colored background

Colour by thresholds, mappings or the colour scheme; background has Basic or Gradient mode and can apply to the entire row.

Gauge

A bar inside the cell (Basic, Gradient or Retro LCD): utilisation per row.

Sparkline

A time series drawn inline; use the "Time series to table" transformation to build it from several series.

JSON view, Pill

Values formatted as code; comma-separated values or JSON arrays shown as coloured blocks (labels, tags).

Markdown + HTML

GitHub-flavoured Markdown; HTML is sanitised unless disable_sanitize_html is set.

Image, Data links, Actions

Image URLs or base64 images; the titles of the data links; a button that makes a basic, unauthenticated API call.

Cell options add an "Inspect value" drawer, a tooltip taken from another field, and styling taken from another field (CSS properties in JSON). Footer: choose one or several calculations (min, max, first, last, total and so on) for all fields, or limit them with an override; math functions show nothing on non-numeric fields. Filtering and sorting: the column filter adds a funnel to each header with operators Contains (regular expression, the default), Expression (where $ is the value) and the comparisons; hovering a cell allows cross-filtering. Clicking a header sorts, and holding Cmd or Ctrl sorts by several columns. Nested tables come from the "Group to nested tables" transformation, styled with an override that targets nested fields.

Bookshelf example. The "Slowest routes" table: route, request rate, p95 and error ratio as four instant queries merged with the "Join by field" and "Organize fields" transformations (see Transformations and Expressions), the p95 column as a coloured background with the thresholds of the SLO, the error column as a gauge cell, a footer with the total of the rate column, and a data link on the route that opens the logs dashboard (see data links).

What can go wrong. A table built from range queries shows one row per sample, so use instant queries for "now" tables. A column with the wrong unit sorts correctly but reads wrongly, and a column filter whose operator is the default (Contains, a regular expression) can match more than intended, so test it on realistic values.

Text

Source: Grafana: Text.

The Text panel carries instructions for the reader: what the dashboard is for, how to interpret a panel, a link to the runbook, an announcement of scheduled maintenance. It has three modes: Markdown, HTML (sanitised by default; the disable_sanitize_html setting lets you enter HTML directly) and Code (a read-only code editor with language, line numbers and mini map options). Dashboard variables in the content are interpolated, and embedding an iframe needs allow_embedding = true in the server configuration.

A short Markdown block that takes the selected route from a dashboard variable called route shows the idea:

## Bookshelf service health

Runbook: [5xx ratio above 1 percent](https://runbooks.example.com/bookshelf/5xx)
Selected route: `$route`

Data-driven text (13.3, public preview). Grafana 13.3 adds an updated Text visualization that connects the text to the query data. It is in public preview: Grafana Labs offers limited support and breaking changes may occur before general availability. The documented way to turn it on is the grafana.newTextPanel and text.newFeatures feature toggles. The content can use macros for the query result (${__value}, ${__field}, ${__series} and ${__data}) and Handlebars templating ({{#each}} to repeat a block per row, {{#if}} for conditions); the render mode is "Once" (the whole result) or "Per row", you can pick the data frame, and in per-row mode with 100 or more rows a page size of 1 to 1,000 rows is available. When the panel has query data its content renders in an isolated frame: scripts, access to the Grafana session, API calls and form submissions are blocked, HTML is always sanitised, and external images, stylesheets, fonts, media and iframes load only after you approve the source (an approval allows the whole website, not only the listed URLs, so request URLs can expose dashboard data). Use it for a status banner built from a query result, not for anything that needs scripts.

Reference: Grafana: Text (next version documentation) and Grafana: What’s new in 13.3.

Alert list

Source: Grafana: Alert list.

The Alert list shows currently active alerts and their state (firing, pending, normal). It refreshes on every dashboard load, shows only current alerts and ignores the dashboard time range. Options: View mode (List or Stat), Group mode (Default grouping by alert rule, or Custom grouping by chosen labels), Max items (default 20, default grouping only), Sort order (alphabetical, importance, or time) and Alerts linked to this dashboard. Filters: alert name, alert instance label matchers (for example {severity="critical"}), data source (choosing a data source excludes Grafana-managed rules; "Grafana" or empty includes them), folder (the alert rule folder, not the dashboard folder), and Show alerts with 0 instances. The state filter chooses among Alerting, Pending, No Data, Recovering, Normal and Error.

On an incident dashboard, a Stat-mode alert list filtered to application="bookshelf" is the quickest "is anything firing" indicator. The states themselves are explained in Rule Evaluation, States and Missing Data.

Dashboard list

Source: Grafana: Dashboard list.

The Dashboard list shows links to dashboards and refreshes on every dashboard load. Sections: Starred, Recently viewed and Search (query, folder and tags, all of which must match; the tags are case-sensitive and do not autocomplete). Further options are Include current time range and Include current template variable values (which pass the time range and the variables to the linked dashboards), Show headings, Show folder names and Max items (per section). Use a search on the tag bookshelf to build the navigation panel of the Bookshelf dashboards; the tagging scheme is in Dashboard Design Principles.

Annotations list

Source: Grafana: Annotations list (the slug of the page is annotations).

The Annotations list shows annotations so the reader can jump to the annotated data. Query options: Query filter (All dashboards or This dashboard), Time range (None or This dashboard), Tags and Limit (default 10). Display options are Show user, Show time and Show tags, and the link behaviour is Link target (Panel by default, or Dashboard) with Time before and Time after (10 minutes each by default). Annotations that mark deployments and incidents (see Annotations and Links) become a change log next to the graphs, which is the first place to look when "it started at 14:05".

News

Source: Grafana: News.

The News panel displays an RSS or Atom feed (by default the Grafana Labs blog) and accepts no other query. The feed must be served with CORS headers, because the browser fetches it; the "Use proxy" option was removed in Grafana 8.5, so a feed without them may not load (workarounds are a re-host, a CORS proxy or a community data source). It loads with the dashboard and on every refresh. In an internal Bookshelf dashboard a feed of the platform status page or release notes is the sensible use.

Verify it in the lab

In the lab (Hands-on Lab, profile grafana):

  1. Build the four stats of the top row, then stop Bookshelf and check that every stat reaches its "no value" state, not a stale green.

  2. Replace the pool utilisation stat with a gauge, set the neutral value and segments, and compare the readability.

  3. Build the "Slowest routes" table with a gauge cell and a footer, and sort by p95.

  4. Add an Alert list filtered on application="bookshelf" and trigger the high 5xx alert with the load generator.

  5. Add a Dashboard list searching the tag bookshelf.

In the books

Salituro (Learn Grafana 10.x) builds stat panels with thresholds, mappings and a sparkline, plus bar gauges and tables, on Grafana 10 screens; McCollam (Getting Started with Grafana, Grafana 8) covers the table panel and the Dashboard list and presents data links and drill-down workflows; Hernandez (Building IoT Visualizations using Grafana) still refers to the Singlestat panel, which no longer exists and whose features are now options of the Stat panel. Since those books the gauge was rebuilt (generally available in 13.0), the table gained cell types such as pill, Markdown and actions, the Annotations list moved to the slug annotations, and the Text panel can use query data (public preview in 13.3).
