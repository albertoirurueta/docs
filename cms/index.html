CMS (Content Management System)

This content was generated with the assistance of AI and should be verified against the official documentation before being relied on in production.

A content management system (CMS) is an application that lets people who do not write code create, organise, review and publish content, while developers decide how that content is structured, stored and presented. This section explains the ideas that every CMS shares and then documents individual products in their own sub-sections. The first one is WordPress, written against WordPress 7.1.3 (released 2026-10-06, PHP 7.4 minimum and 8.3 or later recommended; 7.1.4, a security release of 2026-10-28, is the version to run in production), with WordPress 7.2 in beta and planned for 2026-12-08. The second is Webflow, a SaaS visual website builder with a built-in CMS, hosting and developer APIs. The third is Drupal, a content-management framework for structured content, multilingual sites and headless delivery, and the fourth is Joomla, a CMS with its own extension model and Web Services API. The CMS Comparison sets them against twelve other systems with dated metrics, charts and recommendations by purpose. For running WordPress as stateless containers on several Kubernetes nodes with a managed database, start with Cloud Reference Architecture. The version numbers and links on this page were checked on 2026-10-28.

The overview explains what a CMS is made of, the traditional, headless and hybrid architectures, open source and SaaS products, and when a CMS is the right tool and when a web framework is.

WordPress

WordPress 7.1 for site owners, administrators, theme developers and plugin and block developers: installation and hosting, the block editor and Site Editor, administration and security, block themes and theme.json, plugins, hooks and custom blocks, the Interactivity API, the REST API, WP-CLI, testing and deployment, headless front ends, and the Abilities API, MCP Adapter and AI Client. Webflow

Webflow for designers, content editors, site owners and developers: the Designer, classes and layout, components, variables and shared libraries, interactions with GSAP, the CMS and collection pages, publishing, localization, ecommerce, custom code, the Data API and webhooks, apps and Designer Extensions, DevLink, code components, Webflow Cloud and the MCP server. It follows one running example, the fictitious nursery Fernbrook Gardens, and ends with a guide to outdated advice, a comparison and decision guide, and a printable cheat sheet.

Drupal

Drupal 11 for site builders, administrators, themers, module developers and teams building decoupled front ends: installation with Composer and DDEV, content types and fields, Views, Layout Builder and Canvas, users and permissions, configuration management, Twig theming and Single Directory Components, modules, services, plugins and OOP hooks, the Entity, Form, Migrate and Database APIs, JSON:API and headless delivery, Drush, testing and deployment, upgrades to Drupal 11 and 12, and the AI module and MCP server. It follows one running example, the fictitious Meridian Museum, and ends with a guide to outdated advice in older books and tutorials, a comparison and decision guide, and a printable cheat sheet.

Joomla

Joomla 6 for site builders, administrators, template designers, extension developers and teams building decoupled front ends: installation and the public folder, articles, categories and custom fields, menus and modules, users and access levels, Cassiopeia and child templates, the Web Asset Manager, components, modules and plugins, the Web Services API, scheduled tasks, the command line, packaging and update servers, upgrades from Joomla 3, 4 and 5, and the AI and MCP roadmap. It follows one running example, the fictitious Tallpine Hiking Club, and ends with a guide to outdated advice, a comparison and decision guide, and a printable cheat sheet.

Comparison

A side-by-side comparison of WordPress, Webflow, Drupal, Joomla and twelve other CMSs (TYPO3, Craft CMS, Wix, Squarespace, Contentful, Strapi, Sanity, Payload, Adobe Experience Manager, Umbraco, Wagtail and Ghost): dated and cited metrics for popularity, performance, security and cost, charts, scores on twelve axes, a decision flowchart and a summary of which CMS to choose for what.
