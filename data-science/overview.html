Data Science Overview

This content was generated with the assistance of AI and should be verified against the official documentation before being relied on in production.

This page holds the conceptual material of the Data Science section: the versions every page targets, how the pages fit together, the reading order and the map from concepts to pages. The general pages (for example What Is Data Science? and The Data Science Workflow) stay at the section level and are linked from the sections below.

Targeted versions

All pages target the following versions. Examples target Python 3.13 or 3.14 and were run on Python 3.13, with the library versions below; the version numbers and links were checked in October 2026.

Component Version Notes

Python

3.13 or 3.14

Examples were run on Python 3.13. NumPy 2.5 needs Python 3.12 or later, and pandas 3.1 and scikit-learn 1.9 need 3.11 or later.

NumPy

2.5

The NumPy 2 line; see NumPy 2 Migration if you come from 1.x code.

pandas

3.1

The pandas 3 line, with the string dtype and copy-on-write as defaults.

scikit-learn

1.9

Estimator API, pipelines, metadata routing and the current model-persistence guidance.

How the pages fit together

The general pages follow the life of a project and are written to be read on their own. The three library sub-sections are reference-style guides that the general pages link to whenever they need detail.

flowchart TD G1[What is data science, workflow, ethics] --> G2[Environment, notebooks, scientific stack] G2 --> G3[Data acquisition, cleaning, EDA, visualisation] G3 --> G4[Statistics, feature engineering, machine learning, evaluation] G4 --> G5[Reproducibility and MLOps basics] G5 --> G6[Choosing tools, ecosystem beyond the core] G2 -.-> N[NumPy sub-section] G3 -.-> P[pandas sub-section] G4 -.-> S[scikit-learn sub-section] N --> P P --> S CS[Cheat sheet] -.-> N CS -.-> P CS -.-> S

Reading order

  1. Read What Is Data Science? and The Data Science Workflow to learn the vocabulary and the phases of a project.

  2. Set up your tools with Setting Up a Data Science Environment and Jupyter Notebooks & JupyterLab.

  3. Learn the array and table foundations in the NumPy and pandas sub-sections, with The Scientific Python Stack as the map of how libraries relate.

  4. Work through acquisition, cleaning, exploration and visualisation, then Statistics Fundamentals.

  5. Move on to Feature Engineering, Machine Learning Fundamentals and Model Evaluation & Validation, using the scikit-learn sub-section for detail.

  6. Finish with ethics, reproducibility and tool choice, and keep the Data Science Cheat Sheet open while you work.
