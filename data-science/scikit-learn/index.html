scikit-learn

This content was generated with the assistance of AI and should be verified against the official documentation before being relied on in production.

scikit-learn is the general-purpose machine-learning library of the scientific Python ecosystem. It offers a uniform interface for classification, regression, clustering, dimensionality reduction, preprocessing, model selection and evaluation, built on NumPy, SciPy and joblib. This sub-section belongs to the Data Science section and explains the library page by page, from installation and the estimator API to pipelines, validation, inspection and deployment concerns such as model persistence. This is the general library tour; the models and practices specific to machine learning (neural-network wrappers, Gaussian processes, imbalanced data, out-of-core learning) are in the ML scikit-learn sub-section. For a one-page summary of the most used calls, see the scikit-learn part of the cheat sheet.

What the names mean

The same project appears under three spellings, and each one refers to something different.

Name Meaning

scikit-learn

The project and its distribution (package) name. It is what you install: pip install scikit-learn. The FAQ gives this as the correct spelling, not "scikit", "SciKit" or "sci-kit learn".

scikit

A short form of "SciPy toolkit". There are several scikits, which are scientific toolboxes built around SciPy. Besides scikit-learn, a popular one is scikit-image. Earlier versions of the project were called scikits.learn and scikits-learn, names that are no longer used.

sklearn

The import name of the Python package: import sklearn, or from sklearn.linear_model import LogisticRegression. The distribution name and the import name differ, so a package called sklearn on PyPI is not the library.

The FAQ pronounces the name "sy-kit learn", where "sci" stands for science. The installation steps, including the difference between the distribution name and the import name, are on Installing scikit-learn.

Source: scikit-learn FAQ.

Where scikit-learn sits in the stack

scikit-learn works on in-memory arrays and DataFrames and does not train deep neural networks. Arrays come from NumPy, tabular data usually from pandas, and plotting from Matplotlib. For the surrounding workflow see Data Science, and for libraries that complement it see the pages linked from there.
