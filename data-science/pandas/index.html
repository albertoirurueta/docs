pandas

This content was generated with the assistance of AI and should be verified against the official documentation before being relied on in production.

pandas is the Python library for labelled, tabular and time-series data. This sub-section of the Data Science section explains pandas from installation to large-data techniques, with runnable examples and a link to the official documentation page each example derives from. It is written against pandas 3.1 with NumPy 2.5, and the versions, behaviour and links were checked in October 2026. Examples target Python 3.13 or 3.14 and were run on Python 3.13; pandas 3.1 itself needs Python 3.11 or later. The pandas entries of the Data Science cheat sheet give the shortest summary of the same material.

Suggested learning path

  1. Install a supported environment with Installing pandas and Understanding Its Versions, then follow 10 Minutes to pandas.

  2. Learn the structures: Series, DataFrame and Index Objects.

  3. Practise selection with Indexing and Selecting and the semantics in Copy-on-Write.

  4. Load real data through the input and output pages, starting with CSV & Text Files.

  5. Clean it with Missing Data in pandas, Duplicate Labels and Rows in pandas and Text Data & the str Dtype in pandas.

  6. Summarise and reshape with Group By: Split-Apply-Combine, Merge & Join in pandas and Pivot & Pivot Tables in pandas.

  7. Add time with Time Series and Dates and Resampling and Frequencies.

  8. Scale up with Enhancing Performance and Scaling to Large Datasets.
