Data Science

This content was generated with the assistance of AI and should be verified against the official documentation before being relied on in production.

Data science turns data into decisions: it combines programming, statistics, domain knowledge and communication to ask a question, obtain and clean data, explore it, build and evaluate models and report what was found. This section documents the Python route through that work. It starts with the ideas and tooling that apply to every project, then goes deep into the three libraries most data science code is built on: NumPy for arrays, pandas for tables and scikit-learn for machine learning.

The overview gives the targeted versions, shows how the pages fit together, suggests a reading order and maps every concept to the page that covers it.
