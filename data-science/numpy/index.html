NumPy

This content was generated with the assistance of AI and should be verified against the official documentation before being relied on in production.

NumPy is the array library that the rest of the Python scientific stack builds on: pandas, SciPy, scikit-learn and Matplotlib all store and exchange their numbers as NumPy arrays. This sub-section is a practical reference to the library, from the first ndarray to memory layout, threading and the C API. It belongs to the Data Science section, which also holds the pandas and scikit-learn sub-sections, and a condensed summary of the commands most used day to day is on the NumPy part of the cheat sheet.

Version baseline

Every page targets NumPy 2.5, and the facts were checked against the official documentation in October 2026. Examples target Python 3.13 or 3.14 and were run on Python 3.13. NumPy 2.5 itself needs Python 3.12 or later. Code written for NumPy 1.x often needs small changes; the Migrating to NumPy 2.x page lists them, and What’s New in NumPy 2.1 to 2.5 follows the releases one by one.

How to read this sub-section

  • New to NumPy: read The Absolute Basics of NumPy, then array creation, basic indexing, broadcasting and reductions, in that order.

  • Coming from NumPy 1.x: start with Migrating to NumPy 2.x, Type Promotion (NEP 50) and Strings, Bytes and StringDType.

  • Chasing speed or surprising results: the memory layout, copies and views, floating-point and threading pages explain most of them.
