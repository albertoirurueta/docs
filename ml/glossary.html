ML & Deep Learning Glossary

This content was generated with the assistance of AI and should be verified against the official documentation before being relied on in production.

This glossary defines the terms used across this section in plain language, with a link to the page that treats each one in depth. The wording follows the conventions of PyTorch 2.15, TensorFlow 2.21 with Keras 3.15 and scikit-learn 1.9, and was checked on 2026-10-30. Terms are listed alphabetically.

For wider coverage see the Google Machine Learning Glossary and the scikit-learn glossary, both linked under References. The scikit-learn glossary of API conventions is also available in this documentation as scikit-learn Glossary.

A to C

Activation function

A non-linear function applied to a neuron’s weighted sum, such as ReLU, GELU, sigmoid, tanh or softmax. Without it a stack of linear layers collapses into a single linear map. See Neural Network Fundamentals.

Adam / AdamW

Adaptive optimisers that keep running averages of the gradient and its square. AdamW applies weight decay separately from the gradient update and is the usual default for transformers. See Optimizers & Learning Rate Schedules.

Attention

A mechanism that lets each position of a sequence compute a weighted average of the values at all positions, with weights from the similarity of queries and keys. See Attention & Transformers.

Autodiff (automatic differentiation)

Computing exact derivatives of a program by applying the chain rule to its recorded operations. Reverse mode gives all gradients of a scalar loss in one backward pass. See Backpropagation & Autodiff.

Autoencoder

A network trained to reconstruct its input through a narrow bottleneck, so the bottleneck learns a compact representation. See Generative Models.

Backpropagation

The algorithm that computes the gradient of the loss with respect to every weight by passing error signals backwards through the network. See Backpropagation & Autodiff.

Batch / mini-batch

The group of examples processed in one forward and backward pass. The batch size trades gradient noise against hardware efficiency. See Gradient Descent & Optimization.

Batch normalisation

A layer that normalises activations using the mean and variance of the current mini-batch, then rescales them with learned parameters. It behaves differently in training and evaluation mode. See Training Deep Networks.

Bias (model)

Error from a model that is too simple to capture the true pattern. Not to be confused with the bias parameter (an additive constant in a layer) or with societal bias. See Generalization & Regularization.

Bias-variance trade-off

The tension between a model that is too rigid (high bias) and one that follows noise (high variance). See Generalization & Regularization.

Calibration

The property that predicted probabilities match observed frequencies: among cases scored 0.8, about 80 per cent are positive. See Probability Calibration.

Checkpoint

A saved snapshot of model weights, optimiser state and training progress, used to resume or to keep the best model. See Training Deep Networks.

Classification

Predicting a discrete label (binary, multiclass or multilabel). See Types of Learning.

Clustering

Grouping examples by similarity without labels, as in k-means. See Classic Algorithms Overview.

Convolution

A sliding weighted sum with a small shared kernel, which gives translation-equivariant feature detection with few parameters. See Convolutional Neural Networks.

Cross-entropy

The standard loss for classification, the negative log probability the model assigns to the true class. See Information Theory & Losses.

Cross-validation

Estimating generalisation by training and scoring on several train/validation splits and averaging. See Model Evaluation & Validation.

D to G

Data augmentation

Creating label-preserving variations of training examples (flips, crops, noise) to reduce overfitting. See Training Deep Networks.

Data leakage

Information from outside the training data, such as test rows or future values, influencing the model, which inflates evaluation scores. See Common Pitfalls: Leakage & Randomness.

DataLoader

The PyTorch utility that batches, shuffles and loads a dataset in parallel worker processes. TensorFlow’s counterpart is the tf.data pipeline. See Training Deep Networks.

Diffusion model

A generative model trained to remove noise step by step, so sampling starts from noise and denoises into data. See Generative Models.

Distributed training

Training one model across several devices or machines using data, tensor, pipeline or sharded parallelism, for example FSDP2 in PyTorch. See Distributed Training.

Dropout

Randomly zeroing a fraction of activations during training to regularise the network. It is disabled in evaluation mode. See Generalization & Regularization.

Early stopping

Ending training when the validation metric stops improving, usually keeping the best checkpoint. See Training Deep Networks.

Embedding

A dense vector representing a discrete item (word, user, image) such that similar items are close together. See Embeddings & Representation Learning and Embeddings in the database section.

Epoch

One full pass of the training algorithm over the entire training set.

Estimator

In scikit-learn, an object with fit that learns from data; predictors add predict and transformers add transform. See The Estimator API.

F1 score

The harmonic mean of precision and recall. See Model Evaluation & Validation.

Feature

An input variable used by a model. Feature engineering builds better ones; deep networks learn features from raw data. See Feature Engineering.

Fine-tuning

Continuing to train a pre-trained model on a smaller task-specific dataset, all or part of its weights. See Transfer Learning & Foundation Models.

Foundation model

A large model pre-trained on broad data, usually by self-supervision, and adapted to many tasks. See Transfer Learning & Foundation Models.

GAN (generative adversarial network)

Two networks trained against each other: a generator makes samples and a discriminator tries to tell them from real ones. See Generative Models.

Generalisation

Performance on new data from the same distribution as the training data. See Generalization & Regularization.

GNN (graph neural network)

A network whose layers pass messages along the edges of a graph. See Graph Neural Networks.

Gradient

The vector of partial derivatives of the loss with respect to the parameters; it points in the direction of steepest increase. See Math for Machine Learning.

Gradient boosting

An ensemble that adds shallow trees one at a time, each fitted to the errors of the previous ones. It usually beats deep learning on tabular data. See Tabular Data & Gradient Boosting.

Gradient clipping

Rescaling the gradient when its norm exceeds a threshold, to avoid exploding updates. See Training Deep Networks.

Gradient descent

Iteratively moving parameters against the gradient of the loss. The variants differ in how many examples are used per step. See Gradient Descent & Optimization.

H to M

Hyperparameter

A setting chosen before training, such as learning rate, depth or batch size, as opposed to a parameter learned from data. See Deep Learning Tuning Playbook.

Inference

Using a trained model to make predictions, with gradients disabled (torch.inference_mode() in PyTorch). See Deploying & Serving Models.

Initialisation

The starting values of the weights. Xavier and He schemes keep activation variance stable across layers. See Training Deep Networks.

Interpretability

How well a person can understand why a model made a prediction, through inherently simple models or post-hoc methods. See Interpretability & Explainability.

Keras

The high-level neural-network API. Keras 3 runs on TensorFlow, JAX or PyTorch backends and is the default tf.keras since TensorFlow 2.16. See Choosing a Framework.

KL divergence

A measure of how one probability distribution differs from another; the quantity behind cross-entropy and the VAE loss. See Information Theory & Losses.

Label

The target value attached to a training example in supervised learning.

Layer normalisation

Normalising across the features of each example, independent of batch size; standard in transformers. See Training Deep Networks.

Learning rate

The step size of an optimiser; usually the most important hyperparameter. See Optimizers & Learning Rate Schedules.

Logits

The raw, unnormalised outputs of a classifier before softmax or sigmoid. Loss functions such as PyTorch CrossEntropyLoss expect logits, not probabilities. See Information Theory & Losses.

Loss function

The scalar that measures how wrong the predictions are and that training minimises. See Information Theory & Losses.

LSTM / GRU

Recurrent cells with gates that control what to remember and forget, easing vanishing gradients. See Recurrent Networks & Sequences.

MLOps

The practices for building, deploying, monitoring and retraining models reliably. See Experiment Tracking & MLOps.

Mixed precision

Computing in float16 or bfloat16 while keeping master weights and sensitive operations in float32, for speed and memory. See Hardware & Mixed Precision.

Momentum

Accumulating a moving average of past gradients so updates keep direction through noisy or flat regions. See Gradient Descent & Optimization.

N to R

Neural network

A parametrised function built from layers of simple units and trained with gradient descent. See Neural Network Fundamentals.

ONNX

An open interchange format for models, executed by runtimes such as ONNX Runtime. See ONNX & Interoperability.

Optimiser

The algorithm that updates parameters from gradients (SGD, Adam, AdamW). See Optimizers & Learning Rate Schedules.

Overfitting

Fitting noise in the training data so training error is low and validation error is high. See Generalization & Regularization.

Parameter

A value learned during training, such as a weight or bias. Counted in "7 billion parameters" for a language model.

Pipeline

In scikit-learn, a chain of transformers and a final estimator treated as one estimator, which keeps preprocessing inside each cross-validation fold. See Pipelines.

Pooling

Downsampling feature maps by taking the maximum or average of small windows. See Convolutional Neural Networks.

Precision and recall

Precision is the share of predicted positives that are correct; recall is the share of actual positives that are found. See Model Evaluation & Validation.

Pre-training

Training a model on a large generic task before adapting it. See Transfer Learning & Foundation Models.

Quantisation

Storing weights, and sometimes activations, in lower precision such as int8 or 4 bits to reduce size and latency. See Model Compression.

Recurrent neural network (RNN)

A network that processes a sequence step by step while carrying a hidden state. See Recurrent Networks & Sequences.

Regression

Predicting a continuous value. See Types of Learning.

Regularisation

Any technique that discourages overfitting: L1 and L2 penalties, weight decay, dropout, early stopping, augmentation. See Generalization & Regularization.

Reinforcement learning

Learning a policy by interacting with an environment and maximising cumulative reward. See Reinforcement Learning.

Residual connection

A shortcut that adds a layer’s input to its output, which lets very deep networks train. See Training Deep Networks.

S to Z

Self-attention

Attention in which queries, keys and values all come from the same sequence. See Attention & Transformers.

Self-supervised learning

Learning from labels derived from the data itself, such as predicting masked words or the next token. See Types of Learning.

Softmax

A function that turns a vector of logits into probabilities that sum to one. See Information Theory & Losses.

Stochastic gradient descent (SGD)

Gradient descent using one example or a mini-batch per step, noisy but cheap. See Gradient Descent & Optimization.

Supervised learning

Learning a mapping from inputs to known labels. See Types of Learning.

Tensor

A multi-dimensional array with a shape and data type, the basic data structure of PyTorch (torch.Tensor) and TensorFlow (tf.Tensor). See Math for Machine Learning.

Test set

Data held out until the end to estimate final performance once, after all decisions are made. See Model Evaluation & Validation.

Token

The unit a language model reads, often a word piece. See Tokens & Tokenization.

Transfer learning

Reusing knowledge from one task or dataset to improve another. See Transfer Learning & Foundation Models.

Transformer

An architecture built from self-attention, feed-forward layers, residual connections and normalisation; the basis of modern language, vision and multimodal models. See Attention & Transformers and Transformer Architecture.

Underfitting

A model too simple to fit even the training data. See Generalization & Regularization.

Unsupervised learning

Finding structure in unlabelled data: clustering, dimensionality reduction, density estimation. See Types of Learning.

Validation set

Data used to choose models and hyperparameters, kept separate from the test set. See Model Evaluation & Validation.

VAE (variational autoencoder)

An autoencoder whose latent code is a probability distribution, trained with a reconstruction term plus a KL divergence term. See Generative Models.

Vanishing and exploding gradients

Gradients that shrink towards zero or grow without bound as they pass through many layers. See Training Deep Networks.

Weight decay

Shrinking weights a little at each step. Equivalent to L2 regularisation for plain SGD, but different for Adam, which is why AdamW exists. See Generalization & Regularization.

Weights

The learned parameters that scale the inputs of each unit.

Zero-shot and few-shot

Performing a task with no examples or only a few, given in the prompt or through the model’s pre-training. See Transfer Learning & Foundation Models.
