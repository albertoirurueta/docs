TensorFlow

This content was generated with the assistance of AI and should be verified against the official documentation before being relied on in production.

TensorFlow is Google’s machine-learning platform: tensors and automatic differentiation in TensorFlow Core, the Keras high-level API, the tf.data input pipeline, SavedModel for saving and serving, and a set of deployment tools. This sub-section of the ML (Machine Learning) section documents it page by page, with most of the weight on Keras 3, which is how most people use it today.

Version baseline and the 2026 maintenance focus

Item Value checked on 2026-10-30

TensorFlow

2.21.0. All pages target this release.

TensorFlow 2.22

Upcoming. It is mentioned only where the project has announced a change, and is labelled upcoming each time.

Keras

3.15.1, installed as the separate keras package.

Python

3.13. Examples were run on Python 3.13 with TensorFlow 2.21 and Keras 3.15 on CPU (macOS arm64) on 2026-10-31. Examples that need a GPU, a TPU, several machines, a TensorFlow Serving container, a browser or a mobile device were not executed, and each page says which.

In 2026 TensorFlow is in a maintenance-focused phase: releases concentrate on stability, security fixes and compatibility rather than new high-level features, new research code is more often written in PyTorch or JAX, and several former companions are archived, renamed or moved (TensorFlow Lite is now LiteRT, TensorFlow Addons is archived and TF Hub moved to Kaggle Models). The page Ecosystem & Project Status gives the current status of each component, and Migrating from TensorFlow 1 lists what is outdated in older books.

Keras inside TensorFlow

Keras 3 is a multi-backend library that can run on TensorFlow, JAX or PyTorch. With the TensorFlow backend it is the standard high-level API of TensorFlow: models are built with Sequential, Functional or subclassed APIs, trained with compile and fit, and saved in the .keras format or exported as a SavedModel. Since TensorFlow 2.16, tf.keras is Keras 3 too; only the separate tf_keras package, selected by setting TF_USE_LEGACY_KERAS=1 before TensorFlow is imported, keeps Keras 2 behaviour for old code, and the two cannot be mixed in one process. The pages Keras 3 Overview: keras, tf.keras & tf_keras, Keras Multi-Backend and Migrating from Keras 2 to Keras 3 explain how the pieces relate.
