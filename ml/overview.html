ML Overview

This content was generated with the assistance of AI and should be verified against the official documentation before being relied on in production.

This page holds the conceptual material of the ML (Machine Learning) section: its scope, the versions every page targets, the learning path and reading order, and the map from concepts to pages. The general concept pages (for example What Is Machine Learning? and Neural Network Fundamentals) stay at the section level and are linked from the learning path and the concept-to-page map below.

Scope and neighbouring sections

The section stops where other sections of this site take over.

  • Data Science covers the project workflow around a model: acquisition, cleaning, exploration, statistics, feature engineering, evaluation and reproducibility, with NumPy, pandas and scikit-learn sub-sections. This section builds on those pages and links back to them instead of repeating them. The scikit-learn sub-section here holds only the material that goes beyond them.

  • Artificial Intelligence covers model-centred and application topics such as large language models, agents, retrieval, Hugging Face and LangChain. The bridge page Attention & Transformers: the Bridge to LLMs ends where those pages begin.

  • Databases, deployment infrastructure and other engineering topics live in their own sections.

Targeted versions

The pages target the versions below, checked on 2026-10-30. Examples on the general pages were run on 2026-11-01 on Python 3.13 with these library versions on a CPU-only machine; each page says which of its examples need hardware or services (GPUs, several machines, Docker, large downloads) and were therefore not run. Anything labelled upcoming is not yet released and is described from the project’s own announcements.

Component Version Notes

Python

3.13

3.13 is the newest Python that every library here supports: TensorFlow 2.21 ships wheels for Python 3.10 to 3.13 only, while PyTorch 2.15, scikit-learn 1.9 and Keras 3.15 require Python 3.11 or later (PyTorch 2.14 was the last release with Python 3.10 wheels). On Python 3.10, pip silently resolves older releases instead, for example Keras 3.12.4, the newest Keras whose metadata still allows 3.10.

PyTorch

2.15.0

Released on 2026-10-28. See PyTorch.

TensorFlow

2.21.0

The 2026 line is in maintenance focus; 2.22 is upcoming. See TensorFlow.

Keras

3.15.1

Keras 3 runs on JAX, PyTorch and TensorFlow; see Keras 3 Overview.

scikit-learn

1.9.1

See scikit-learn.

JAX

0.12.0.1

Used for short comparisons and as a Keras 3 backend.

ONNX

1.23.2

See ONNX & Model Interoperability.

ONNX Runtime

1.31.1

The runtime used to check exported models.

Learning path

The general pages can be read in order. Each framework sub-section is a reference that the general pages link to when they need detail, and each can also be read from start to finish.

flowchart TD A[What is ML, types of learning, problem framing] --> B[Math, losses, gradient descent, generalisation] B --> C[Classic algorithms, tabular data, scikit-learn] B --> D[Neural networks, backpropagation, training] D --> E[CNNs, sequences, attention, embeddings] E --> F[Generative models, graphs, reinforcement learning, transfer learning] D --> G[PyTorch] D --> H[TensorFlow and Keras 3] C --> I[scikit-learn sub-section] F --> J[Hardware, distributed training, compression] J --> K[ONNX, deployment, MLOps] K --> L[Interpretability, fairness] M[Choosing a framework] -.-> G M -.-> H M -.-> I

Reading order

  1. Start with What Is Machine Learning? AI vs ML vs DL, Types of Learning and Problem Framing & the ML Project Lifecycle.

  2. Learn the foundations in Math for ML, Loss Functions & Information Theory, Gradient Descent & Optimization and Generalization, Bias–Variance & Regularization.

  3. Survey the non-deep methods in Classic ML Algorithms at a Glance and Tabular Data: Gradient Boosting vs Deep Learning.

  4. Move to neural networks with Neural Network Fundamentals, Backpropagation & Automatic Differentiation and Training Deep Networks, then the architecture pages.

  5. Pick a framework with Choosing a Framework and work through the PyTorch, TensorFlow or scikit-learn sub-section.

  6. Finish with hardware, distributed training, compression, deployment, interpretability and fairness, and keep the glossary and the ML Cheat Sheet open while you work.
