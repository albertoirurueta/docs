PyTorch

This content was generated with the assistance of AI and should be verified against the official documentation before being relied on in production.

PyTorch is a Python deep-learning framework built around tensors, automatic differentiation and a define-by-run style: the code you write is the computation that runs. This sub-section of the ML (Machine Learning) section documents it page by page, from installation and tensors to compiling, exporting and distributing models. The general pages of the section explain the ideas; these pages show how PyTorch implements them.

Version baseline

Item Value checked on 2026-10-30

PyTorch

2.15.0, released on 2026-10-28. All pages target this release.

Python

Examples were run on Python 3.13 with PyTorch 2.15 on 2026-10-31, on a CPU-only machine (macOS arm64, where Apple MPS is the accelerator). Distributed examples ran as CPU processes under torchrun with the Gloo back end. Examples that need a CUDA GPU, FFmpeg or a mobile toolchain say so on their page and were not executed. PyTorch 2.15 no longer ships Python 3.10 wheels.

torchvision

0.29.2, the release that matches PyTorch 2.15; see torchvision.

Installation

pip is the supported route; conda is no longer an official channel. See Installation & Versions.

Library status

The PyTorch ecosystem changed a lot between older books and 2.15. This table summarises the status of the pieces most often met in older material; the details are on Legacy APIs & Migration and Ecosystem.

Component Status What to use instead

TorchServe

Archived

Serve exported models with a general-purpose server, or ONNX Runtime; see Deploying & Serving ML Models.

torchtext

Archived

Hugging Face tokenizers and datasets, or your own data pipeline.

TorchScript

Deprecated

torch.export, AOTInductor and the ONNX exporter; see torch.export.

torchaudio

Maintenance

Audio decoding and encoding moved to TorchCodec; see torchaudio (Maintenance) & TorchCodec.

ExecuTorch

Part of PyTorch Core

The route to phones and embedded boards; see ExecuTorch for Mobile & Edge.

conda channel

Deprecated

Install with pip; see Installation & Versions.
