Groovy IDEs & Tools

This content was generated with the assistance of AI and should be verified against the official documentation before being relied on in production.

This page lists the IDEs and editors commonly used for Groovy, with a link to each product’s official page. Groovy runs on the JVM, so the Java IDEs are the natural choice, while an editor with Groovy support is enough for scripts.

IDEs

  • IntelliJ IDEA — the JetBrains IDE, with Groovy support for highlighting, completion and refactoring.

  • Groovy-Eclipse — the Groovy plugin for the Eclipse IDE.

  • Apache NetBeans — an open-source IDE with Groovy support.

Editors with extensions

  • Visual Studio Code — a general-purpose editor with Groovy extensions.

Tools

  • Apache Groovy — the language’s official site, with downloads, documentation and the IDE integration overview.
