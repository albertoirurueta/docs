A short worked example that combines several of the idioms above: a collection literal, findAll and collect with closures, groupBy, and GString interpolation.

def words = ['north', 'south', 'east', 'west']
def big = words.findAll { it.size() > 4 }.collect { it.toUpperCase() }
println "${big.size()} long words: ${big.join(', ')}"
println words.groupBy { it.size() }
2 long words: NORTH, SOUTH
[5:[north, south], 4:[east, west]]
