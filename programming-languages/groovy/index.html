Groovy Reference

This content was generated with the assistance of AI and should be verified against the official documentation before being relied on in production.

Welcome to the Groovy reference. Apache Groovy is a dynamic, optionally typed language for the Java platform. It compiles to JVM bytecode, calls any Java library directly, and adds concise syntax on top of Java: closures, string interpolation, collection and map literals, properties, operators that map to methods, builders and domain specific languages. The same source can be a one-line script, a build file, a test, or a statically compiled library. Groovy’s standard library extensions, the Groovy Development Kit (GDK), add hundreds of methods to JDK classes such as String, File, List and Map, which is where much of its day-to-day productivity comes from.

History

Groovy was started by James Strachan in 2003 and developed at Codehaus, with a first 1.0 release in January 2007 and a specification request, JSR 241, that has been dormant since 2012. Pivotal (earlier SpringSource and VMware) sponsored its development until March 2015; Groovy then entered the Apache Incubator in March 2015 and graduated to an Apache top-level project in November 2015. Along the way the language gained annotations and generics (1.5), AST transformations and Grape (1.6), static type checking and compilation and extension modules (2.0), traits (2.3), the Parrot parser with lambdas and var (3.0), the org.apache.groovy coordinates, records, sealed types and GINQ (4.0), JDK 11 and the new groovysh (5.0), and native async/await, val, module imports and many new modules (6.0). Every release is listed with its date in What’s New and Migrating from Older Versions.

Version baseline

This section documents Apache Groovy 6.0 (6.0.0, released 2026-09-22; JDK 17 or newer), checked on 2026-10-14. Features that are newer than Groovy 4.0 are marked with the release that introduced them, and features that the official documentation labels incubating are labelled as such. On the check date the maintained lines were 6.0.0 (2026-09-22), 5.1.3 (2026-09-19), 5.0.8 (2026-07-29), 4.0.33 (2026-07-29) and 3.0.25 (2025-05-24, the last release of the 3.0 line). Frameworks and tools built on Groovy, such as Gradle, Grails, Spock, Geb, Micronaut and Jenkins pipelines, are not documented here; they are listed with a brief description and links on Ecosystem & Groovy in Other Tools, and Spock and Geb get a single page only because the official Groovy testing guide covers them.

The greenhouse scenario

The examples share one small, original domain: a greenhouse toolkit that monitors and waters a hobby greenhouse. It suits Groovy’s strengths — scripting, data processing, DSLs and Java interoperability — and grows page by page: a Plant class with properties, a Reading record, a sealed Zone hierarchy with Bench, HangingBasket and Bed, traits for watering and alerting, a small watering DSL, sensor logs in CSV, plant data in JSON, a seed catalogue in XML, TOML and YAML configuration, an in-memory H2 database queried with groovy.sql.Sql and GINQ, a report rendered with a template engine, asynchronous sensor polling and tests. A page whose concept fits the scenario poorly uses a minimal standalone example instead. Every example on these pages was run with Groovy 6.0.0 on JDK 26, and the output shown is the real output of that run (examples that use third-party tools and were not run are labelled as such on their page).

How the book was used

A copy of the first edition of Groovy in Action (Dierk König with Andrew Glover, Paul King, Guillaume Laforge and Jon Skeet, Manning Publications, 2007), which describes Groovy 1.0, was consulted as a reference for concept coverage and structure. It is not the source of any example: every example is written against the current official Groovy 6.0 documentation, the official documentation wins wherever the two differ, and no text, code listing or figure is copied from the book. Its core-language and classic-library chapters are still conceptually sound; its chapters on tooling, GroovyTestCase, Scriptom, early Grails and XML-RPC or SOAP are outdated or out of scope. Each page states in prose where older material is outdated for the concepts it touches, and What’s New and Migrating from Older Versions collects the legacy-to-modern replacements. The book’s second edition (Manning, 2015, Groovy 2.4) is the current edition; it was not used as a source.
