Poetry

This content was generated with the assistance of AI and should be verified against the official documentation before being relied on in production.

Poetry is a tool for dependency management and packaging: it declares a project’s dependencies in pyproject.toml, resolves them for every Python and platform the project supports into a poetry.lock, manages a virtual environment per project, and builds and publishes the project. Since 2.0 it uses the standard [project] table, its build backend poetry-core is a standard PEP 517 backend, and its lock file can be exported to pylock.toml; Poetry-specific configuration lives under [tool.poetry].

The pages are written against Poetry 2.5.1 (2026-09-20) with poetry-core 2.5.0. Poetry itself needs Python 3.10 or newer; the projects it manages can target any Python range, independent of the interpreter Poetry runs on. Poetry’s versions are major.minor.micro and, by its own FAQ, not semantic versioning: a minor release may remove features deprecated in an earlier minor release, so read the changelog before upgrading and pin Poetry in CI. History and the 2.0 changes are on Versions & Release History and Migrating to Poetry 2.

Projects that want to show they use Poetry can add the badge the community page provides to their README.

Source: Poetry: Introduction, Poetry: System requirements, Poetry FAQ: versioning scheme, Poetry FAQ: why not semantic versioning, Poetry: Community: badge.
