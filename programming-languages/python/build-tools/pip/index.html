pip

This content was generated with the assistance of AI and should be verified against the official documentation before being relied on in production.

pip is the package installer for Python: it resolves requirements against an index, downloads or builds wheels and installs them into the environment of the Python that runs it. It is bundled with CPython through ensurepip, which is why python -m pip works in every new virtual environment. pip is deliberately not a workflow tool: "pip is not a workflow management tool", in its own documentation’s words. It does not create environments, track a project’s dependencies in pyproject.toml, bump versions or publish; it works with venv, build, twine and requirements or lock files, which these pages cover alongside it.

The pages are written against pip 26.2.2 (2026-10-20). Only the latest pip is supported; it runs on CPython 3.10 to 3.15 and PyPy, and new versions come out quarterly, numbered YY.N (26.0 in January 2026, 26.2 in July). History and policies are on Versions & Release History.

Source: pip documentation, pip is not a workflow management tool, The role of ensurepip, pip: Compatibility, pip: Release cadence, Supported versions, Python support policy.
