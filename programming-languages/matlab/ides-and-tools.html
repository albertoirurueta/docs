MATLAB IDEs & Tools

This content was generated with the assistance of AI and should be verified against the official documentation before being relied on in production.

This page lists the environments commonly used to write and run MATLAB code. Use the desktop for full local work, MATLAB Online for a zero-install start, and the VS Code extension if you prefer that editor.

IDEs

  • MATLAB Desktop — the standard environment, with the editor, Command Window, workspace browser and debugger.

  • Live Editor — an interactive document format that combines code, output and formatted text.

Editors with extensions

  • VS Code MATLAB extension — syntax highlighting, navigation and code analysis for MATLAB files in Visual Studio Code.

Online and notebook tools

  • MATLAB Online — MATLAB in a web browser, with nothing to install.
