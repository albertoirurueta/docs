JavaScript IDEs & Tools

This content was generated with the assistance of AI and should be verified against the official documentation before being relied on in production.

This page lists the IDEs and editors most commonly used to write JavaScript, with a link to each product’s official page. Most of them work with the same language tooling, so choose by how much built-in integration you want versus how light and fast you want the editor to be.

IDEs

  • WebStorm — JetBrains' IDE for JavaScript and TypeScript, with refactoring, debugging and framework support built in.

Editors with extensions

  • Visual Studio Code — the most widely used editor for web development, extensible through a large extension marketplace.

  • Sublime Text — a fast, lightweight commercial text editor with a package ecosystem.

  • Zed — a fast, collaborative code editor with built-in language server support.
