What’s New in COBOL

This content was generated with the assistance of AI and should be verified against the official documentation before being relied on in production.

This page is written against ISO/IEC 1989:2023 (edition 3, January 2023; an upcoming 4th edition is in ballot), against IBM Enterprise COBOL for z/OS 6.5 (generally available 13 June 2025, PTFs through September 2026) on z/OS 3.2, and against GnuCOBOL 3.2 (28 July 2023, the latest release). The release facts were checked against the vendors' pages on 2026-10-20, the GnuCOBOL statements marked "tried" were compiled with cobc -x -Wall and run on that date, and the items that could not be read in full are worded without naming a release. z/OS items are labelled "z/OS; not run here".

The page answers three questions: what does each edition of the language add (and where in this guide is it taught), what do the compilers I will actually use support today, and which statements in the book this guide consulted have been overtaken. It is a map; the detail is on the page each row links to. For the history before 2002 see History and Standards; for the compilers and dialects see Compilers and Dialects.

The standard

The standard is ISO/IEC 1989. Edition 3 was published in 2023 and replaced the 2014 edition; the 2014 and 2002 editions are withdrawn. A 4th edition is in preparation and is mentioned here only as upcoming: no feature of it is described, and no date is given because the ISO catalogue page could not be read when this page was checked. The standard itself is sold by ISO and INCITS, so the details below are taken from INCITS announcements and from the IBM and GnuCOBOL documentation.

GnuCOBOL 3.2 and the status of 4.0

GnuCOBOL 3.2 was released on 28 July 2023 and is still the release the project’s home page offers; the SourceForge file area lists 3.2 and, after it, only nightly snapshots. There is no 4.0 release: version 4.0 exists as development snapshots, so treat it as unreleased and do not recommend a distribution package named gnucobol4, which is an old snapshot. (The 4.0 status could be confirmed only partly: the home page does not mention it, and the SourceForge folder has no 4.0 release.)

Book errata

Besides outdated versions, the book has errors of fact or of code in the chapters this guide consulted. The correct rule is stated here and the faulty code is never reproduced.

Chapter Correct rule Where covered

4

A REDEFINES item must not have a stray PIC in the clause that names the base item, and its size has to agree with what it redefines (a $ZZ9.99 edited field has seven characters, not six). Binary integers are exact: COMP is not "not good for math because of rounding". The real hazards are truncation under TRUNC and decimal scaling.

REDEFINES, RENAMES and TYPEDEF, USAGE and Numeric Representation

5

The statement is OPEN INPUT, not "OPEN READ". The FILE STATUS field is declared in WORKING-STORAGE, not inside the record. A PC-style ASSIGN TO "name.dat" with LINE SEQUENTIAL does not belong with z/OS JCL: Enterprise COBOL supports LINE SEQUENTIAL only for z/OS UNIX files.

Sequential Files, File Status Codes

7

CALL passes its arguments with USING, and BY REFERENCE, BY CONTENT and BY VALUE are different contracts. The "copy library" step is not IEBCOPY: the compile step’s SYSLIB DD is what resolves COPY.

Subprograms: CALL and Linkage, Copybooks and REPLACE

8

EXEC SQL INCLUDE member brings in a DCLGEN member at precompile time, not "the table from the Db2 database". Use INCLUDE SQLCA instead of a hand-coded SQLCA. A cursor is opened and fetched under the name it was declared with. Program preparation (precompile or coprocessor, BIND, packages and plans) is part of the job.

Embedded SQL and Db2

Common mistakes

  • Reading a feature’s presence in the standard as support in your compiler. Check the table in Compilers and Dialects; GnuCOBOL 3.2 rejects or only stubs several 2023 features.

  • Quoting a version from a 2022 book or blog as current. Use the table above and the vendor’s page.

  • Recommending the gnucobol4 package. It is an old snapshot, not a 4.0 release.

  • Confusing a PTF with a release. The September 2026 items are PTFs to 6.5; check the PTF level of the compiler you have (see Compiling, Linking and Language Environment).
