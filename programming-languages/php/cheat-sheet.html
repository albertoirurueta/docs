Worked example

The example combines a backed enum, match, array_map() and an arrow function.

<?php

declare(strict_types=1);

enum Status: string
{
    case Open = 'open';
    case Closed = 'closed';
}

function label(Status $status): string
{
    return match ($status) {
        Status::Open => 'Open for loans',
        Status::Closed => 'Closed',
    };
}

$titles = ['Solaris', 'Kindred', 'Dawn'];
$lengths = array_map(fn (string $title): int => strlen($title), $titles);

echo label(Status::from('open')), "\n";
echo implode(', ', $lengths), "\n";
Open for loans
7, 7, 4

Status::from() turns the string into an enum case, match returns a value and throws if no arm fits, and the arrow function captures nothing from the outer scope.
