PHP IDEs & Tools

This content was generated with the assistance of AI and should be verified against the official documentation before being relied on in production.

This page lists the IDEs commonly used to write, run and debug PHP code. A dedicated PHP IDE gives the deepest framework and debugging support, while an open-source option keeps costs down.

IDEs

  • PhpStorm — a PHP-specific IDE with code analysis, refactoring, Xdebug integration and framework support.

  • Eclipse PDT — the PHP Development Tools project, which brings PHP editing and debugging to the Eclipse platform.

  • Apache NetBeans — the Apache Software Foundation’s open source IDE, with PHP editing, Xdebug debugging and PHPUnit support.

Editors with extensions

  • PHP Intelephense for VS Code — a PHP language server for Visual Studio Code with completion, diagnostics, go-to-definition and formatting; see PHP in Visual Studio Code for setting up debugging with Xdebug.
