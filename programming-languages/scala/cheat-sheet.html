A short program that combines an enum, pattern matching, an extension method and collection operations, run with Scala CLI:

//> using scala 3.10.0
enum Shape:
  case Circle(r: Double)
  case Rect(w: Double, h: Double)

def area(s: Shape): Double = s match
  case Shape.Circle(r)  => math.Pi * r * r
  case Shape.Rect(w, h) => w * h

extension (s: Shape) def isBig: Boolean = area(s) > 5

@main def tour(): Unit =
  val shapes = List(Shape.Circle(1.0), Shape.Rect(2.0, 3.0))
  println(f"total area: ${shapes.map(area).sum}%.2f")
  println(shapes.filter(_.isBig))

The total is the circle (about 3.14) plus the rectangle (6), and only the rectangle passes the isBig test:

total area: 9.14
List(Rect(2.0,3.0))
