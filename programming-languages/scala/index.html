Scala Reference

This content was generated with the assistance of AI and should be verified against the official documentation before being relied on in production.

Welcome to the Scala reference. Scala is a statically typed language that fuses object-oriented and functional programming on the Java Virtual Machine, and also targets JavaScript through Scala.js and native code through Scala Native. It combines a concise, indentation-friendly syntax and strong type inference with traits, case classes and enums, pattern matching, immutable collections, higher-order functions and a type system that includes union, intersection, opaque and match types. Scala 3 redesigned the Scala 2 implicits into intent-based constructs (given, using, extension methods and context bounds), added metaprogramming through inline, quotes and splices, and ships a single scala command, Scala CLI, that runs, tests and packages programs without a build file.

History

Scala was designed by Martin Odersky and his group at the Programming Methods Laboratory (LAMP) of EPFL in Lausanne, with a first public release in 2003 and the major redesign Scala 2.0 in 2006. The research compiler Dotty, started at EPFL, became Scala 3.0 in 2021; the Scala Center at EPFL, VirtusLab and other companies take part in its development and the Scala Improvement Process (SIP) governs language changes. Since Scala 3.1.0 (21 October 2021) the language has evolved in minor releases with a long-term support (LTS) line next to the latest "Scala Next" line. Every release with its date and what changed is listed in Release History & What’s New; how the process works, and which features are experimental or in preview, is explained in Language Evolution: SIPs, Preview & Experimental.

Version baseline

This section documents Scala 3.10 (3.10.0, the current Scala Next release, announced on 12 October 2026; JDK 17 or newer since Scala 3.8), checked on 2026-10-16. Every page also states what differs on the 3.9 LTS line (3.9.0, announced on 3 September 2026), which the official download page advises for publishing libraries. Features newer than the 3.3 LTS (3.3.8) are marked with the release that introduced or stabilised them, for example named tuples (stable in 3.7), the new given syntax (3.6), into (stable in 3.9) and the removal of A with B types (an error in 3.10). Features that the official documentation labels experimental or preview are labelled as such: Scala 3.10 introduces the preview label, which is reached with the -preview compiler flag (for instance SIP-74, partial function literals with parentheses, which is a preview feature in 3.10). Scala 2.13 appears only as "the Scala 2 form" in comparisons and on the migration pages. Frameworks and libraries built on Scala, such as Typelevel, ZIO, Apache Pekko, Akka, Play, Apache Spark and Ox, are not documented here; they are listed with a brief description and links on Ecosystem. The exception is the official Scala Toolkit (MUnit, OS-Lib, uPickle, sttp and Cask), which belongs to the official documentation and has its own pages. The tools used throughout are Scala CLI 1.18.0 (its 1.17.1 release is the one bundled with the 3.10.0 distribution and used for the examples), sbt 2.0.10 and Toolkit 0.9.2.

The trailhead scenario

The examples share one small, original domain: trailhead, a toolkit that plans hikes on a network of mountain trails. It suits Scala’s strengths — domain modelling with algebraic data types, type-safe APIs, collection pipelines, type classes and JSON and HTTP through the Toolkit — and grows page by page: a Trail case class, a Difficulty enum, a Segment hierarchy, opaque Km, Metres and Minutes types, a Route processed with collection pipelines, Show, Codec and Ordering type classes, a Planner that validates with Either and Option, a WeatherService served by a local Cask server and called with sttp, a small route DSL, an inline check of a grade literal and tests with MUnit and ScalaCheck. A page whose concept fits the scenario poorly uses a minimal standalone example instead. Every example on these pages was run with Scala 3.10.0 on JDK 26, or with the version named on the page, and the output shown is the real output of that run (examples that could not be run are labelled "not run here" on their page).

How the books were used

Three books were consulted as references for concept coverage and structure: Dean Wampler’s Programming Scala (third edition, O’Reilly, 2021), which describes Scala 3.0, Slava Schmidt’s Learn Scala Programming (Packt, 2018), which is written for Scala 2.13 milestones, and Mads Hartmann and Ruslan Shevchenko’s Professional Scala (Packt, 2018), which is written for Scala 2.12. None of them is the source of any example: every example is written against the current official Scala 3.10 documentation, the official documentation wins wherever they differ, and no text, code listing or figure is copied from a book. Each page states in prose where the books are outdated for the concepts it touches (implicits instead of givens, extends App, A with B, Stream, the Scala 2 macros and Akka actors before Pekko, among others), and Release History & What’s New and Incompatibilities & Dropped Features collect the legacy-to-modern replacements.
