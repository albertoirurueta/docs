Scala IDEs & Tools

This content was generated with the assistance of AI and should be verified against the official documentation before being relied on in production.

This page lists the IDEs, editors and command-line tools commonly used for Scala, with a link to each product’s official page. Choose IntelliJ IDEA with the Scala plugin for a full IDE, or an editor backed by the Metals language server for a lighter setup.

IDEs

  • IntelliJ IDEA — the JetBrains IDE, the usual host for the Scala plugin.

  • IntelliJ Scala plugin — adds Scala support to IntelliJ IDEA, including sbt import, worksheets, debugging and refactoring.

Editors with extensions

  • Metals — the Scala language server, which brings completion, navigation, diagnostics and a debugger to VS Code, Neovim, Sublime Text, Zed and other editors.

  • Visual Studio Code — a general-purpose editor, the most common client for Metals.

Command-line tools

  • Scala CLI — a command-line tool to compile, run, test and package Scala code without a build file.
