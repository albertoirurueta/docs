A small program that ties several of the sheet’s pieces together — a record hierarchy, a collection expression, a switch expression and LINQ — written as top-level statements:

Shape[] shapes = [new Square(2), new Rectangle(3, 4)];

foreach (var shape in shapes)
{
    Console.WriteLine($"{shape} has area {Area(shape)}");
}

Console.WriteLine($"Total area: {shapes.Sum(s => Area(s))}");

static int Area(Shape shape) => shape switch
{
    Square s => s.Side * s.Side,
    Rectangle r => r.Width * r.Height,
    _ => throw new ArgumentOutOfRangeException(nameof(shape))
};

abstract record Shape;
record Square(int Side) : Shape;
record Rectangle(int Width, int Height) : Shape;

Running it prints one line per shape, produced by the record’s generated ToString, followed by the total:

Square { Side = 2 } has area 4
Rectangle { Width = 3, Height = 4 } has area 12
Total area: 16
