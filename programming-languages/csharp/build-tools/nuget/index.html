NuGet

This content was generated with the assistance of AI and should be verified against the official documentation before being relied on in production.

NuGet is the package manager of .NET: a package format (.nupkg, a ZIP with a manifest), a protocol for feeds, the public registry nuget.org, and the client built into the dotnet CLI, MSBuild, Visual Studio and nuget.exe. This group covers the consuming side — how packages are found, versioned, resolved, restored, configured, audited and trusted — at NuGet 7.9.0, the version in .NET SDK 10.0.400 and 10.0.402 (and in nuget.exe 7.9.0). Producing and publishing packages is the Publishing and Distributing Libraries group; the C# Reference’s introduction is Namespaces, Assemblies and Projects — NuGet Packages.

A package declares its dependencies; a consuming project records only the packages it uses directly (PackageReference); restore computes the full graph and downloads what is missing, so packages are never committed to source control.

Source: What is NuGet: The flow of packages, Managing dependencies, Tracking references and restoring packages.

The client tools

Client Use

dotnet CLI

dotnet restore, dotnet package …, dotnet nuget …, dotnet pack — every platform, all SDK-style projects (dotnet package and nuget Commands).

MSBuild

msbuild -t:restore, -t:pack — the same NuGet code as the CLI (Package Restore).

Visual Studio

Package manager UI and Package Manager Console, Windows (nuget.exe, Visual Studio and packages.config).

nuget.exe

Standalone CLI, needed mainly for packages.config projects.

Support follows the host: the NuGet inside an SDK is supported as long as that SDK, the NuGet in Visual Studio as long as that Visual Studio; for nuget.exe only the latest version is fully supported, patched versions are released only for critical security fixes for LTS releases, and out-of-support or vulnerable versions are removed from the tools.json feed. Not every feature is in every client — packages.config restore, for example, needs nuget.exe or MSBuild, not dotnet — and the "feature availability" table in the documentation lists which client version brought what.

Source: Install NuGet client tools: Tools overview, Support policy, Patch releases, nuget.exe unlisting, .NET SDK, Feature availability, What is NuGet: NuGet tools.

nuget.org

nuget.org is the default source — https://api.nuget.org/v3/index.json, the V3 service index (NuGet Server API). It repository-signs every package, publishes vulnerability data, reserves ID prefixes for verified owners, and never deletes a published version (it can only be unlisted). Accounts, API keys and Trusted Publishing are covered in the publishing group.

Source: nuget.org overview: API endpoint.
