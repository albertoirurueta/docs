Go Reference

This content was generated with the assistance of AI and should be verified against the official documentation before being relied on in production.

This section is written against Go 1.27 (the current stable release is go1.27.2), checked on 2026-10-18. Go ships a major release about every six months and supports the two newest ones, here Go 1.27 and Go 1.26; Go 1.28 is not released yet (it is expected around February 2027), so nothing here depends on it. Features newer than the oldest supported release are marked with the version that introduced them, for example WaitGroup.Go (1.25), b.Loop (1.24), range over functions (1.23), per-iteration loop variables and the enhanced ServeMux (1.22), generics (1.18), and in 1.27 generic methods and encoding/json/v2. Every go.mod shown declares go 1.27, and every example was compiled, vetted and run with go1.27.2.

What Go is

Go is a compiled, statically typed, garbage-collected language designed at Google by Robert Griesemer, Rob Pike and Ken Thompson and released as open source in 2009. It aims at software that is easy to read, fast to build and simple to deploy: a small language specification, a fast compiler that produces a single static binary, implicit interfaces and composition instead of inheritance, errors as ordinary values, and first-class concurrency with goroutines, channels and select. Around the language sits one official toolchain — the go command with its module system, gofmt, go vet, go test with benchmarks and fuzzing, go doc and the profilers — and a large standard library that covers HTTP, JSON, cryptography, templates and databases without third-party code. Go powers cloud infrastructure (Docker, Kubernetes, Prometheus and Terraform are written in it), network services, command-line tools and, with WebAssembly, code that runs in browsers and WASI hosts.

Running example

The examples across the section share one small, original domain: shelf, a Go module (example.com/shelf, go 1.27) for a library catalogue. It is deliberately the same domain as the Rust Reference, so you can compare the two languages on the same types.

  • The catalog package holds Book, Author, ISBN (a validated defined type with a String method), Loan and LoanState (an iota enumeration) types, a Store interface and an in-memory implementation guarded by a mutex.

  • An internal/ package holds helpers that are not part of the public API.

  • cmd/shelf is a command-line program that searches, lends and returns books and imports and exports JSON.

  • cmd/shelfd is an HTTP service that exposes the catalogue as JSON with net/http, log/slog and database/sql.

  • Tests, benchmarks, a fuzz test for ISBN parsing and a testable example grow alongside the code.

The pages build on each other, and the cheat sheet summarises them.

golang.org/x repositories

The golang.org/x repositories are maintained by the Go team but sit outside the standard library and have looser compatibility guarantees; they are labelled as such where used.

  • x/sync — errgroup and semaphore

  • x/tools — goimports, stringer, deadcode and the analysis passes (modernize, shadow, fieldalignment)

  • x/vuln — the vulnerability database client and govulncheck

  • x/exp — experimental packages such as apidiff and gorelease

  • x/sys, x/text and x/crypto

  • benchstat and pkgsite
