Collections

This content was generated with the assistance of AI and should be verified against the official documentation before being relied on in production.

This page is written against Visual Basic 17.13 on .NET 10 (SDK 10.0.402) and was checked on 2026-10-19. Every example is a complete console program that starts with Option Strict On, was built with warnings treated as errors and was run in the .NET 10 SDK container (Linux); the output shown is real output. Examples that are meant to fail say so and show the compiler messages. The project-level imports that the SDK adds (System, System.Collections.Generic, System.Linq, System.Threading.Tasks and others) are why List(Of T), Dictionary(Of TKey, TValue), Queue(Of T) and the LINQ methods need no Imports line. Types from other namespaces (System.Collections.ObjectModel, System.Collections.Concurrent, System.Collections.Immutable, System.Collections.Frozen, System.ComponentModel) are imported in the examples that use them.

A collection holds a variable number of elements and offers operations that arrays do not: adding, removing, searching by key, keeping order, or giving first-in-first-out access. The choice among the .NET collection types is a choice of data structure, and the rest of this page follows it: List(Of T) for an ordered, growable sequence; Dictionary(Of TKey, TValue) for lookup by key; sets for membership and uniqueness; queue, stack, linked list and priority queue for specific access orders. Fixed-size sequences are covered by Arrays; the loops that walk collections by Control Flow; the query operators that transform them by LINQ Query Expressions; writing your own sequences with Yield by Iterators and Yield; and the generic syntax (Of, constraints, variance) by Generics. The C# counterpart is Collections and Iterators (C#).

List(Of T)

List(Of T) is the workhorse. It stores its elements in an internal array that doubles when it is full, so appending is cheap on average and indexing is as fast as for an array. Count is the number of elements; Capacity is the size of the internal array. The indexer list(i) is the default property; it throws ArgumentOutOfRangeException (not IndexOutOfRangeException) when i is outside 0 to Count - 1.

Option Strict On

Module Program
    Sub Main()
        Dim titles As New List(Of String)
        titles.Add("Refactoring")
        titles.AddRange({"Clean Code", "Domain-Driven Design"})
        titles.Insert(0, "The Pragmatic Programmer")
        Console.WriteLine("Count = " & titles.Count & ", first = " & titles(0) & ", last = " & titles(titles.Count - 1))

        ' Count is the number of elements, Capacity the size of the internal array
        Dim sized As New List(Of Integer)(100)
        Console.WriteLine("new list with capacity: Count = " & sized.Count & ", Capacity = " & sized.Capacity)
        Dim growing As New List(Of Integer)
        Dim capacities As New List(Of Integer)
        For i = 1 To 20
            growing.Add(i)
            If Not capacities.Contains(growing.Capacity) Then capacities.Add(growing.Capacity)
        Next
        Console.WriteLine("capacity steps while adding 20 items: " & String.Join(" -> ", capacities))

        ' Searching
        Console.WriteLine("IndexOf Clean Code = " & titles.IndexOf("Clean Code"))
        Console.WriteLine("Contains missing    = " & titles.Contains("Missing"))
        Console.WriteLine("Find > 15 chars     = " & titles.Find(Function(t) t.Length > 15))
        Console.WriteLine("FindAll short       = " & String.Join(",", titles.FindAll(Function(t) t.Length < 12)))
        Console.WriteLine("Exists Refactoring  = " & titles.Exists(Function(t) t = "Refactoring"))

        ' Removing
        titles.Remove("Refactoring")
        titles.RemoveAt(0)
        Console.WriteLine("after removals: " & String.Join(" | ", titles))
        Console.WriteLine("Remove returns False when nothing matched: " & titles.Remove("Missing"))

        Dim numbers As New List(Of Integer) From {5, 3, 8, 1, 9, 2}
        Dim removed = numbers.RemoveAll(Function(n) n Mod 2 = 0)
        Console.WriteLine("RemoveAll removed " & removed & ", left: " & String.Join(",", numbers))

        ' Sorting, reversing, ranges, conversion
        numbers.Sort()
        Console.WriteLine("Sort:    " & String.Join(",", numbers))
        Console.WriteLine("BinarySearch(5) on the sorted list: " & numbers.BinarySearch(5) & ", for 4: " & numbers.BinarySearch(4))
        numbers.Sort(Function(left, right) right.CompareTo(left))
        Console.WriteLine("Sort desc: " & String.Join(",", numbers))
        numbers.Reverse()
        Console.WriteLine("Reverse: " & String.Join(",", numbers))
        Console.WriteLine("GetRange(1, 2): " & String.Join(",", numbers.GetRange(1, 2)))
        Dim asArray As Integer() = numbers.ToArray()
        Console.WriteLine("ToArray length: " & asArray.Length)

        ' Index errors
        Try
            Console.WriteLine(numbers(numbers.Count))
        Catch ex As ArgumentOutOfRangeException
            Console.WriteLine(ex.GetType().Name & ": " & ex.ParamName)
        End Try

        ' Modifying while iterating
        Try
            For Each n In numbers
                If n = 5 Then numbers.Remove(n)
            Next
        Catch ex As InvalidOperationException
            Console.WriteLine(ex.GetType().Name & ": " & ex.Message)
        End Try

        titles.Clear()
        titles.TrimExcess()
        Console.WriteLine("after Clear and TrimExcess: Count = " & titles.Count & ", Capacity = " & titles.Capacity)
    End Sub
End Module

Highlights of the output:

  • The capacity went 4 -> 8 -> 16 -> 32 while 20 items were added (the first Add allocates 4). Pass the expected size to the constructor (New List(Of Integer)(100)) when you know it, or call EnsureCapacity, to avoid the re-allocations. TrimExcess gives memory back.

  • Remove(item) returns False when nothing matched; RemoveAll(predicate) returns the number removed and is the safe way to filter a list in place (see Iterating and modifying).

  • BinarySearch needs a list that is already sorted by the same comparer; it returns the index, or the bitwise complement of the insertion point (-3 means "insert at index 2") when the item is absent.

  • Sort is unstable; use OrderBy (stable, returns a new sequence) when equal elements must keep their order.

  • Looking something up in a List(Of T) with Contains, IndexOf or Find is a linear scan. If you do that in a loop over a large list, use a HashSet or a Dictionary.

List(Of T) implements IList(Of T), IReadOnlyList(Of T) and IEnumerable(Of T). Parameters that only read should use the interface; return types should say what the caller may do with the result.

Collection initializers

A collection initializer fills a new collection with From followed by braces. The compiler translates each element into a call to an Add method of the object. The type must therefore implement IEnumerable and have an accessible Add; the extension method Add from any imported namespace counts too. For a Dictionary, each entry is its own pair of braces, because Add(key, value) takes two arguments: {"a", 1}. A braced group with several values is passed to one Add call with several arguments, which lets you pick the overload.

Option Strict On

Imports System.Runtime.CompilerServices

' A type with an instance Add method works with From
Public Class Tags
    Implements IEnumerable(Of String)

    Private ReadOnly _items As New List(Of String)

    Public Sub Add(tag As String)
        _items.Add(tag.ToLowerInvariant())
    End Sub

    Public Sub Add(first As String, second As String)       ' Add overloads are picked by the number of items in the braces
        Add(first)
        Add(second)
    End Sub

    Public Function GetEnumerator() As IEnumerator(Of String) Implements IEnumerable(Of String).GetEnumerator
        Return _items.GetEnumerator()
    End Function

    Private Function GetEnumeratorNonGeneric() As Collections.IEnumerator Implements Collections.IEnumerable.GetEnumerator
        Return GetEnumerator()
    End Function
End Class

Module QueueExtensions
    ' An extension Add makes From work for types you do not own
    <Extension>
    Public Sub Add(Of T)(queue As Queue(Of T), item As T)
        queue.Enqueue(item)
    End Sub
End Module

    Sub Main()

        Dim sameThing As List(Of Integer) = New List(Of Integer) From {2, 3, 5, 7}
        Console.WriteLine(primes.Count & " " & sameThing.Count)

        ' Dictionary: one pair of braces per entry
        Dim stock As New Dictionary(Of String, Integer) From {
            {"9780132350884", 3},
            {"9780134494166", 1}
        }
        Console.WriteLine("stock: " & stock.Count & " entries, first = " & stock("9780132350884"))

        ' A dictionary can also be built from a sequence of pairs
        Dim fromPairs = New Dictionary(Of String, Integer)(
            {New KeyValuePair(Of String, Integer)("a", 1), New KeyValuePair(Of String, Integer)("b", 2)})
        Console.WriteLine("from pairs: " & fromPairs.Count)

        ' Custom Add: the compiler calls Add once per brace group
        Dim tags As New Tags From {"Refactoring", {"Design", "TESTING"}}
        Console.WriteLine("tags: " & String.Join(",", tags))

        ' Extension Add
        Dim line As New Queue(Of String) From {"first", "second", "third"}
        Console.WriteLine("queue: " & String.Join(",", line) & ", Peek = " & line.Peek())

        ' Object initializer and collection initializer together
        Dim rack As New Rack With {
            .Name = "Software",
            .Books = New List(Of String) From {"Refactoring", "Clean Code"}
        }
        Console.WriteLine(rack.Name & ": " & String.Join(" and ", rack.Books))

        ' A property that already holds a list can be filled after construction
        Dim spare As New Rack With {.Name = "Spare"}
        spare.Books.AddRange({"X", "Y"})
        Console.WriteLine(spare.Name & " has " & spare.Books.Count & " books")

        ' Nested collections
        Dim byAuthor As New Dictionary(Of String, List(Of String)) From {
            {"Fowler", New List(Of String) From {"Refactoring"}},
            {"Martin", New List(Of String) From {"Clean Code", "Clean Architecture"}}
        }
        For Each pair In byAuthor
            Console.WriteLine(pair.Key & ": " & pair.Value.Count)
        Next
    End Sub

Rules:

  • From is the Visual Basic 10 syntax (Visual Studio 2010). Building at LangVersion 9 gives BC36716, "Visual Basic 9.0 does not support collection initializers."

  • From may be combined with an object initializer: New Rack With {.Name = "x", .Books = New List(Of String) From {"a"}}.

  • New List(Of Integer)(100) From {1, 2} is legal: the constructor argument is the capacity (the list ends up with Count 2 and Capacity 100), not the first item.

  • The initializer calls Add; if Add throws (for example a duplicate dictionary key) the whole expression throws.

  • Visual Basic has no index initializer ({["a"] = 1} in C#) and no collection expression ([1, 2, 3] in C# 12): both are syntax errors. The old {1, 2, 3} brace list is an array literal when there is no From.

  • An existing list in a property that is not assigned can be filled after construction with AddRange or Add, as the Spare rack in the example shows.

Dictionary(Of TKey, TValue)

Dictionary maps unique keys to values using a hash table. Lookup, insertion and removal are O(1) on average. The class relies on two members of the key type, GetHashCode and Equals (or the IEqualityComparer(Of TKey) you pass to the constructor); a key whose hash code changes while it is in the dictionary can never be found again, so use immutable keys (strings, integers, structures with read-only fields, Isbn in the shelf scenario).

Option Strict On

Module Program
    Sub Main()
        Dim stock As New Dictionary(Of String, Integer)
        stock.Add("Refactoring", 3)
        stock("Clean Code") = 1               ' the indexer adds or replaces
        stock("Refactoring") = 4              ' replaced, no exception
        Console.WriteLine("Count = " & stock.Count & ", Refactoring = " & stock("Refactoring"))

        Try
            stock.Add("Clean Code", 9)
        Catch ex As ArgumentException
            Console.WriteLine(ex.GetType().Name & ": " & ex.Message)
        End Try

        Try
            Console.WriteLine(stock("Missing"))
        Catch ex As KeyNotFoundException
            Console.WriteLine(ex.GetType().Name & ": " & ex.Message)
        End Try

        Dim copies As Integer
        If stock.TryGetValue("Clean Code", copies) Then
            Console.WriteLine("TryGetValue found " & copies)
        End If
        If Not stock.TryGetValue("Missing", copies) Then
            Console.WriteLine("TryGetValue left copies = " & copies & " when the key was absent")
        End If

        Console.WriteLine("GetValueOrDefault: " & stock.GetValueOrDefault("Missing", -1))
        Console.WriteLine("TryAdd existing: " & stock.TryAdd("Clean Code", 5) & ", TryAdd new: " & stock.TryAdd("Domain-Driven Design", 2))
        Console.WriteLine("ContainsKey: " & stock.ContainsKey("Clean Code") & ", ContainsValue(2): " & stock.ContainsValue(2))
        Console.WriteLine("Remove: " & stock.Remove("Clean Code") & ", again: " & stock.Remove("Clean Code"))

        ' The bang operator is shorthand for the indexer with a literal String key
        Console.WriteLine("stock!Refactoring = " & stock!Refactoring)

        ' Enumerating gives KeyValuePair(Of TKey, TValue)
        For Each entry In stock
            Console.WriteLine("  " & entry.Key & " -> " & entry.Value)
        Next
        Console.WriteLine("Keys: " & String.Join(", ", stock.Keys) & "; Values: " & String.Join(", ", stock.Values))

        ' Key comparison is part of the dictionary
        Dim loose As New Dictionary(Of String, Integer)(StringComparer.OrdinalIgnoreCase)
        loose("ISBN") = 1
        Console.WriteLine("case-insensitive lookup: " & loose("isbn"))
        Dim strict As New Dictionary(Of String, Integer)
        strict("ISBN") = 1
        Console.WriteLine("default comparer finds isbn: " & strict.ContainsKey("isbn"))

        ' Nothing is not a valid key
        Try
            Dim nothingKey As String = Nothing
            stock(nothingKey) = 1
        Catch ex As ArgumentNullException
            Console.WriteLine(ex.GetType().Name & ": " & ex.ParamName)
        End Try

        ' Counting words: the classic dictionary exercise
        Dim words = "the cat and the hat and the bat".Split(" "c)
        Dim counts As New Dictionary(Of String, Integer)
        For Each word In words
            Dim n As Integer
            counts.TryGetValue(word, n)
            counts(word) = n + 1
        Next
        For Each pair In counts.OrderByDescending(Function(p) p.Value).ThenBy(Function(p) p.Key)
            Console.WriteLine(pair.Key & "=" & pair.Value)
        Next
    End Sub

Operation Behaviour

d(key) = v

adds the pair or replaces the value; never throws for an existing key

d.Add(key, v)

throws ArgumentException for an existing key

d(key) (read)

throws KeyNotFoundException when the key is absent

d.TryGetValue(key, value)

returns Boolean; the ByRef argument is set to Default(TValue) when absent. In Visual Basic declare the variable first: Dim copies As Integer and then d.TryGetValue(key, copies); there is no out var.

d.TryAdd(key, v)

adds only if absent; returns whether it did (.NET Core 2.0 and later)

d.GetValueOrDefault(key, fallback)

extension method from System.Collections.Generic.CollectionExtensions; returns the fallback when absent

d.Remove(key)

returns True if the key was present

d.ContainsKey(key), d.ContainsValue(v)

O(1) and O(n)

Nothing as a key

ArgumentNullException for reference-type keys

For Each pair In d

gives KeyValuePair(Of TKey, TValue) with Key and Value; the iteration order is not part of the contract (in practice it follows insertion order until something is removed)

The bang operator d!key is shorthand for d("key") when the default property takes a String; it exists for VB6 compatibility and works with Dictionary(Of String, T). It is documented on Properties and Default Properties. Applied to a collection whose default property takes an Integer, such as List(Of T), it is a type error (BC30512):

Counting words with TryGetValue and an indexer, as at the end of the example, is the standard idiom; it looks the key up twice, once to read and once to write. Where that matters, Dictionary has CollectionsMarshal.GetValueRefOrAddDefault, but its ByRef return cannot be used from Visual Basic, so use TryGetValue plus the indexer, or ConcurrentDictionary.AddOrUpdate for shared counters.

Visual Basic has no tuple deconstruction in For Each: C# foreach (var (key, value) in d) has no counterpart. Declare the pair variable and read pair.Key and pair.Value:

Option Strict On

Module Program
    Sub Main()
        Dim list As New List(Of Integer)

Iterating and modifying

For Each over a collection uses an enumerator that remembers the version of the collection when it started. If the collection is structurally changed during the loop (Add, Remove, Insert, Clear, or setting an item through a List(Of T) indexer), the next step throws InvalidOperationException ("Collection was modified; enumeration operation may not execute"). The first failing loop in the example below also leaves the list half-changed, because the item was already removed when the exception came.

Some further rules for loops over collections:

  • The loop variable of For Each has the element type. For a Dictionary it is KeyValuePair(Of TKey, TValue); for the old ArrayList and the VB Collection it is Object, which under Option Strict On requires For Each item As Object In ... and an explicit conversion afterwards.

Equality, ordering and comparers

Collections rely on three contracts. Hash-based collections (Dictionary, HashSet) need Equals and a matching GetHashCode, or an IEqualityComparer(Of T). For a structure used as a key, implement IEquatable(Of T) (avoids boxing) and override Equals(Object) and GetHashCode together; see Operator Overloading and Equality.

Non-generic collections

System.Collections contains the .NET 1.x collections: ArrayList, Hashtable, SortedList, Queue, Stack. They store Object, so value types are boxed and every read needs a conversion; type errors appear at run time (InvalidCastException) instead of compile time. They are still in the framework but should not be used in new code. ArrayList is not marked obsolete, but the documentation recommends List(Of T). Two LINQ methods bridge old and new: Cast(Of T)() (throws on a wrong element) and OfType(Of T)() (skips wrong elements).

Collections for UI binding and keyed lists

Three types in System.Collections.ObjectModel and System.ComponentModel exist to be bound to user interfaces or to be derived from:

  • ObservableCollection(Of T) raises CollectionChanged when items are added, removed, moved, replaced or the list is cleared. WPF data binding listens to it. It does not raise anything when a property of an item changes: items implement INotifyPropertyChanged for that.

  • BindingList(Of T) (Windows Forms binding) raises ListChanged. It reports ItemChanged for property changes only if the items implement INotifyPropertyChanged; the plain Book class in the example does not, which is why the property change shows no event.

  • KeyedCollection(Of TKey, TItem) is an abstract list that also offers lookup by a key extracted from the item, which you define by overriding GetKeyForItem. It keeps list order and rejects duplicate keys. Collection(Of T) is the base class for your own collections: override InsertItem, RemoveItem, SetItem and ClearItems to react to changes.

Thread-safe collections

The collections above are not safe for several threads where at least one writes. System.Collections.Concurrent provides ConcurrentDictionary, ConcurrentQueue, ConcurrentStack, ConcurrentBag and BlockingCollection(Of T) (a bounded producer-consumer queue). This page only shows the idioms; synchronisation in general (SyncLock, Interlocked, Task) is covered on Threads, Parallelism and Synchronization.

Option Strict On

Imports System.Collections.Concurrent
Imports System.Threading

Module Program
    Sub Main()
        ' A plain Dictionary is not safe for concurrent writers; ConcurrentDictionary is
        Dim counts As New ConcurrentDictionary(Of String, Integer)
        Parallel.For(0, 1000, Sub(i As Integer)
                                  counts.AddOrUpdate("loans", 1, Function(key, current) current + 1)
                              End Sub)
        Console.WriteLine("loans counted: " & counts("loans"))

        Dim cache As New ConcurrentDictionary(Of Integer, String)
        Dim created = 0
        Dim factory As Func(Of Integer, String) = Function(key As Integer)
                                                      Interlocked.Increment(created)
                                                      Return "value " & key
                                                  End Function
        Parallel.For(0, 100, Sub(i As Integer)
                                 Dim ignored = cache.GetOrAdd(i Mod 5, factory)
                             End Sub)
        Console.WriteLine("cache entries: " & cache.Count & " (the factory may run more than once per key: " & (created >= 5) & ")")

        Dim work As New ConcurrentQueue(Of Integer)
        For i = 1 To 5
            work.Enqueue(i)
        Next
        Dim item As Integer
        Dim total = 0
        Do While work.TryDequeue(item)
            total += item
        Loop
        Console.WriteLine("queue total = " & total)

        Dim bag As New ConcurrentBag(Of Integer)
        Parallel.For(0, 100, Sub(i As Integer) bag.Add(i))
        Console.WriteLine("bag count = " & bag.Count)

        ' BlockingCollection: a bounded producer-consumer queue
        Dim pipe As New BlockingCollection(Of String)(boundedCapacity:=2)
        Dim producer = Task.Run(Sub()
                                    For Each name In {"a", "b", "c", "d"}
                                        pipe.Add(name)
                                    Next
                                    pipe.CompleteAdding()
                                End Sub)
        Dim seen As New List(Of String)
        For Each name In pipe.GetConsumingEnumerable()
            seen.Add(name)
        Next
        producer.Wait()
        Console.WriteLine("consumed in order: " & String.Join(",", seen))
    End Sub
End Module

The factory passed to GetOrAdd may run more than once for the same key when threads race; only one result is stored. Do not put side effects in it, or wrap the value in Lazy(Of T). A missing Imports System.Threading for Interlocked inside a lambda that is an argument of GetOrAdd made the compiler report only the overload failure BC30518 ("Overload resolution failed because no accessible 'GetOrAdd' can be called with these arguments") while this example was written, not the undeclared name; when an overload failure appears next to a lambda, look for an error inside the lambda body first (for instance by moving the lambda to a named local, which then reports BC30451).

A shelf example

The catalogue of the reference scenario combines several collections, each doing the job it is best at: a Dictionary to find a book by ISBN, a dictionary of lists (with a case-insensitive comparer) to find the books of an author, a HashSet of ISBNs on loan, a Queue per title for readers who are waiting, and a Stack as a journal for undo.

Option Strict On

Public Class Book
    Public ReadOnly Property Isbn As String
    Public ReadOnly Property Title As String
    Public ReadOnly Property Author As String

    Public Sub New(isbn As String, title As String, author As String)
        Me.Isbn = isbn
        Me.Title = title
        Me.Author = author
    End Sub
End Class

Public Class Catalog
    Private ReadOnly _byIsbn As New Dictionary(Of String, Book)
    Private ReadOnly _byAuthor As New Dictionary(Of String, List(Of Book))(StringComparer.OrdinalIgnoreCase)
    Private ReadOnly _loans As New Dictionary(Of String, Queue(Of String))      ' ISBN -> readers waiting
    Private ReadOnly _onLoan As New HashSet(Of String)
    Private ReadOnly _journal As New Stack(Of String)

    Public Sub Add(book As Book)
        _byIsbn.Add(book.Isbn, book)                       ' throws on a duplicate ISBN
        Dim list As List(Of Book) = Nothing
        If Not _byAuthor.TryGetValue(book.Author, list) Then
            list = New List(Of Book)
            _byAuthor.Add(book.Author, list)
        End If
        list.Add(book)
        _journal.Push("add " & book.Title)
    End Sub

    Public Function ByAuthor(author As String) As IReadOnlyList(Of Book)
        Dim list As List(Of Book) = Nothing
        Return If(_byAuthor.TryGetValue(author, list), list, New List(Of Book))
    End Function

    Public Function Lend(isbn As String, reader As String) As Boolean
        Dim book = _byIsbn(isbn)
        If _onLoan.Add(isbn) Then
            _journal.Push("lend " & book.Title & " to " & reader)
            Return True
        End If
        Dim waiting As Queue(Of String) = Nothing
        If Not _loans.TryGetValue(isbn, waiting) Then
            waiting = New Queue(Of String)
            _loans.Add(isbn, waiting)
        End If
        waiting.Enqueue(reader)
        Return False                        ' queued instead
    End Function

    Public Function GiveBack(isbn As String) As String
        _onLoan.Remove(isbn)
        Dim waiting As Queue(Of String) = Nothing
        Dim nextReader As String = Nothing
        If _loans.TryGetValue(isbn, waiting) AndAlso waiting.TryDequeue(nextReader) Then
            _onLoan.Add(isbn)
            Return nextReader
        End If
        Return Nothing
    End Function

    Public Function Undo() As String
        Return If(_journal.Count > 0, _journal.Pop(), "nothing to undo")
    End Function
End Class

Where older material is wrong

  • The Visual Basic textbooks behind this reference introduce Scripting.Dictionary (a COM object from scrrun.dll with Exists, Item, Keys) and the VB6 Collection as the dictionary and list of the language. In .NET use Dictionary(Of TKey, TValue) and List(Of T): they are typed, fast, work on Linux and macOS, and do not need COM. The Scripting.Dictionary is treated only as legacy code, on the VB family page.

  • Older .NET material builds lists of Object with ArrayList and casts every read; the generic collections replaced them in .NET 2.0.

  • The common "word counter" exercises build a dictionary with If d.ContainsKey(w) Then d(w) += 1 Else d.Add(w, 1): correct, but it looks the key up twice or three times; TryGetValue or GetValueOrDefault with the indexer shows the intention better.

  • Material that says "a For Each over a collection cannot be changed" or "list indexes start at 1" mixes the VB Collection object (one-based) with every other collection (zero-based).

Pitfalls checklist

  • Collection (Microsoft.VisualBasic) is one-based and untyped; Collection(Of T) is a different, zero-based class that needs Imports System.Collections.ObjectModel.

  • Never modify a list inside For Each over it; use RemoveAll, a backwards loop, or iterate over ToList().

  • List(Of T) is not thread-safe, Dictionary is not thread-safe; reading while another thread writes can corrupt the table or loop forever.

  • Mutable keys: changing the hash code of an item that is a dictionary key or set member loses it.

  • List.Sort and Array.Sort are unstable; OrderBy is stable.

  • IReadOnlyList(Of T) is a view, not a copy; a caller can still cast back to List(Of T).

  • The Dictionary indexer throws for a missing key; Hashtable and the VB Collection do not behave alike.

  • An enumeration value concatenated with & prints its number; call ToString().

  • Dim pair As KeyValuePair(Of ...): Value is read-only; write through the dictionary indexer.

  • The default string comparison of a Dictionary(Of String, T) is ordinal and case-sensitive; sorted collections of strings use the current culture. Pass a StringComparer explicitly.

  • FrozenDictionary indexer and ref-returning members cannot be used from Visual Basic 17.13; use TryGetValue.

  • A lambda parameter that has the name of a local variable of the enclosing method is BC36641; a missing Imports inside a lambda can give a misleading overload failure (BC30518).
