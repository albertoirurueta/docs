Arrays

This content was generated with the assistance of AI and should be verified against the official documentation before being relied on in production.

This page is written against Visual Basic 17.13 on .NET 10 (SDK 10.0.402) and was checked on 2026-10-19. Every example is a complete console program that starts with Option Strict On, was built with warnings treated as errors and was run in the .NET 10 SDK container (Linux); the output shown is real output. Examples that are meant to fail say so and show the messages the compiler printed. The project root namespace of the scratch project was Shelf; the SDK adds the project-level imports (System, System.Collections.Generic, System.Linq and others), which is why Console, List(Of T) and Enumerable methods such as Skip need no Imports line.

An array is a fixed-size, ordered block of elements of one type, stored contiguously and reached by an integer index. In .NET every array is an object whose type derives from System.Array, so an array variable holds a reference, its elements are allocated on the heap, and the usual tools of the framework (Length, Clone, GetEnumerator, the static Array.Sort and friends, LINQ) apply to it. Visual Basic adds a small set of its own syntax on top: the declaration by upper bound, ReDim, Erase, ParamArray, and the runtime functions UBound and LBound. The single most important sentence of this page is the first rule of the table below.

Rule Consequence

Dim a(4) As Integer gives the upper bound

The array has 5 elements, indexed 0 to 4. C# new int[4] has 4. Length is always upper bound plus one.

The lower bound is always 0

Dim a(0 To 4) is accepted; Dim a(1 To 5) is BC32059. Option Base does not exist in Visual Basic .NET.

Arrays are reference types

Assignment and parameter passing copy the reference; Clone, Array.Copy and ToArray copy elements.

An array has a fixed size

ReDim and Array.Resize allocate a new array and copy; other variables keep pointing at the old one. Use List(Of T) for a collection that grows.

The rank (number of dimensions) is part of the type

Integer() is one dimension, Integer(,) two, Integer()() is an array of arrays. ReDim cannot change the rank (BC30415).

Covariance for reference types

Book() converts to CatalogItem(); storing the wrong subtype fails at run time with ArrayTypeMismatchException.

Elements start as the default value

0, False, Nothing (for references and String), or a zeroed structure.

For collections that grow, shrink or are searched by key see Collections; for For Each and the other loops see Control Flow; for how ParamArray fits among the other parameter kinds see Procedures: Sub and Function; for generic variance, which also governs the array interfaces, see Generics. The C# counterpart is part of Collections and Iterators (C#).

Declaring arrays

A declaration names the variable and either the upper bound in parentheses or the array type with empty parentheses. The parentheses can follow the variable (Dim a(4) As Integer, Dim names() As String) or the type (Dim names As String()); both are the same type, and the second is the style that reads best because the type stays in one piece. The bound may be any Integer expression that is known at run time, not only a constant. Elements are initialised to the default value of the element type.

An initializer lists the elements in braces. Three spellings are equivalent: Dim a As Integer() = {10, 20, 30}, the same with New Integer() {10, 20, 30}, and the inferred form Dim a = {10, 20, 30}, whose element type is the dominant type of the elements (the one type to which all elements convert). The inferred form is the one used most in new code; it needs no repetition of the type, and with Option Strict On it stays type-safe. Array literals and local type inference arrived together in Visual Basic 9 (Visual Studio 2008); the compiler accepts them at LangVersion 9.

Option Strict On

Module Program
    Sub Main()
        ' The number in parentheses is the UPPER BOUND, not the length
        Dim shelves(4) As Integer
        Console.WriteLine("Length = " & shelves.Length)
        Console.WriteLine("LBound = " & LBound(shelves) & ", UBound = " & UBound(shelves))
        Console.WriteLine("GetLowerBound(0) = " & shelves.GetLowerBound(0) & ", GetUpperBound(0) = " & shelves.GetUpperBound(0))

        ' Elements start with the default value of the element type
        Dim titles(2) As String
        Dim flags(1) As Boolean
        Console.WriteLine("titles(0) Is Nothing: " & (titles(0) Is Nothing))
        Console.WriteLine("flags(1) = " & flags(1))

        ' Several equivalent ways to say "these three numbers"
        Dim a As Integer() = {10, 20, 30}
        Dim b() As Integer = {10, 20, 30}
        Dim c As Integer() = New Integer() {10, 20, 30}
        Dim d As Integer() = New Integer(2) {10, 20, 30}
        Dim e = {10, 20, 30}
        Console.WriteLine(a.Length & " " & b.Length & " " & c.Length & " " & d.Length & " " & e.Length)
        Console.WriteLine("e is " & e.GetType().Name)

        ' Array literal inference picks the dominant type
        Dim mixed = {1, 2.5, 3}
        Dim wide = {1, 2L, 3}
        Console.WriteLine(mixed.GetType().Name & " " & wide.GetType().Name)

        ' An empty array is not Nothing
        Dim none(-1) As String

        Dim copyRef = a

What to take from the output:

  • Length is 5 for Dim shelves(4), UBound is 4, LBound is 0. GetUpperBound(0) takes the dimension number, which is zero-based; the runtime function UBound(array, dimension) takes a one-based dimension number. Mixing the two conventions is a classic slip.

  • {1, 2.5, 3} is a Double() and {1, 2L, 3} an Int64() (Long() in Visual Basic): each element converts widening to the dominant type.

  • Dim none(-1) As String is a valid empty array (upper bound -1, length 0); so is {} with a declared type. Neither is Nothing. An array variable that is declared without a size, or set to Nothing, holds no array at all and Length on it throws NullReferenceException. Prefer Array.Empty(Of T)(), which returns one shared empty array and allocates nothing.

  • Dim copyRef = a is a second name for the same array, which is why changing a(0) shows through copyRef. Clone returns Object, so CType (or DirectCast) back to the array type is needed under Option Strict On.

Two further facts about declarations are worth knowing. First, Dim a(n) As Integer with a non-constant n compiles; the check happens when the line runs (a negative n other than -1 throws OverflowException, see Failure modes and exceptions). Second, the runtime cost of an array is its elements only: there is no per-element object, so Integer() of a million elements is 4 MB, whereas a List(Of Object) of boxed integers is several times larger.

Indexing and iterating

Elements are reached with parentheses, a(i), never square brackets: a[0] is a syntax error (BC30203) because [ begins an escaped identifier in Visual Basic. Parentheses are also used for method calls and for indexers, which is why a(i) and f(i) look the same; the compiler resolves the meaning from the declaration. Three loops cover almost every need:

Option Strict On

Module Program
    Sub Main()
        Dim isbns As String() = {"9780132350884", "9780134494166", "9781491950357"}

        For i = 0 To isbns.Length - 1
            Console.WriteLine(i & ": " & isbns(i))
        Next

        For i = LBound(isbns) To UBound(isbns)
            Console.Write(isbns(i).Substring(0, 3) & " ")
        Next
        Console.WriteLine()

        For Each isbn In isbns
            Console.Write(isbn.Length & " ")
        Next
        Console.WriteLine()

        ' Backwards
        For i = isbns.Length - 1 To 0 Step -1
            Console.Write(isbns(i).Substring(10) & " ")
        Next
        Console.WriteLine()

        ' Off by one: the loop bound is the upper bound, not the length
        Try
            For i = 0 To isbns.Length
                Console.Write(i & " ")
            Next
            Console.WriteLine()
            Dim last = isbns(isbns.Length)
            Console.WriteLine(last)
        Catch ex As IndexOutOfRangeException
            Console.WriteLine(ex.GetType().Name & ": " & ex.Message)
        End Try

        ' For Each over a literal
        Dim total = 0
        For Each n In {1, 2, 3, 4}
            total += n
        Next
        Console.WriteLine("total = " & total)

        ' There is no negative index and no range syntax: use arithmetic, Array.Copy or LINQ
        Console.WriteLine("last = " & isbns(isbns.Length - 1))
        Console.WriteLine("last = " & isbns.Last())
        Console.WriteLine("middle = " & String.Join(",", isbns.Skip(1).Take(1)))
    End Sub
End Module

  • A counted For loop runs to isbns.Length - 1 or to UBound(isbns); the loop bound is the upper bound, so To isbns.Length is one step too far. The loop in the example printed 0 1 2 3 for a three-element array and only the following read, isbns(isbns.Length), threw IndexOutOfRangeException.

  • For Each needs no index and no bound, so it cannot go off by one. It reads the elements in index order, and for a multidimensional array in row-major order (last index fastest).

  • Backwards iteration uses Step -1. When elements are removed while walking an array-like structure, walk backwards.

The type of the For Each variable can be inferred (For Each isbn In isbns gives String) or declared (For Each isbn As String In isbns). Declare it when the sequence is weakly typed, for example Object().

Arrays have no negative indexes and no range or "index from end" syntax. C# a[^1] and a[1..3] have no counterpart: the compiler stops with BC30201 and BC30203.

The For Each variable is a copy

Assigning to the loop variable of For Each compiles in Visual Basic (C# rejects it with CS1656), and does what you would expect: it changes the variable, not the array. For an array of structures that is a trap, because the loop variable holds a copy of the element and a write to one of its fields is lost.

Option Strict On

Module Program
    Structure Counter
        Public Value As Integer
    End Structure

    Sub Main()
        Dim numbers = {1, 2, 3}
        For Each n In numbers
            n = n * 2                       ' compiles: changes the loop variable only
        Next
        Console.WriteLine(String.Join(",", numbers))

        For Each c In counters
            c.Value = 1                     ' compiles: changes a copy

Use an index loop, counters(i).Value += 1, when you need to change array elements in place. An array element is a variable, so unlike list(0).Value = 5 on a List(Of Counter) (BC30068, "Expression is a value and therefore cannot be the target of an assignment") the assignment to a field of counters(0) compiles and works. For arrays of structures that are updated often, this is a real advantage over List(Of T); see Structures and Value Types.

ReDim, ReDim Preserve and Erase

An array does not change size. ReDim creates a new array of the requested bounds and stores the reference in the variable; without Preserve the new array is empty (all default values), with Preserve the compiler emits a copy of the old elements into it. A shorter array loses the elements above the new bound. Because it is a new array, everything that still refers to the old array keeps seeing the old contents.

Option Strict On

Module Program
    Sub Show(label As String, values As Integer())
        If values Is Nothing Then
            Console.WriteLine(label & ": Nothing")
        Else
            Console.WriteLine(label & ": [" & String.Join(", ", values) & "] (UBound " & UBound(values) & ")")
        End If
    End Sub

    Sub Main()
        Dim counts(2) As Integer
        counts(0) = 1 : counts(1) = 2 : counts(2) = 3
        Dim before = counts

        ReDim counts(4)                 ' new empty array: the old values are lost
        Show("after ReDim", counts)

        counts(0) = 7 : counts(1) = 8
        ReDim Preserve counts(5)        ' copies the old elements into a new, larger array
        Show("after ReDim Preserve (grow)", counts)

        ReDim Preserve counts(1)        ' shrinking drops the elements above the new bound
        Show("after ReDim Preserve (shrink)", counts)

        Show("the array another variable still refers to", before)
        Console.WriteLine("same object: " & Object.ReferenceEquals(before, counts))

        ' Array.Resize does the same through a ByRef parameter and also allocates a new array
        Dim viaResize = counts
        Array.Resize(counts, 4)
        Show("after Array.Resize", counts)
        Show("viaResize (old array)", viaResize)

        ' Erase sets the variable to Nothing
        Erase counts
        Show("after Erase", counts)

        ' A multidimensional array can change only its last dimension with Preserve
        Dim grid(1, 1) As Integer
        grid(1, 1) = 5
        ReDim Preserve grid(1, 3)
        Console.WriteLine("grid(1, 1) = " & grid(1, 1) & ", GetLength(1) = " & grid.GetLength(1))
        Try
            ReDim Preserve grid(3, 3)
        Catch ex As ArrayTypeMismatchException
            Console.WriteLine(ex.GetType().Name & ": " & ex.Message)
        End Try

        ' ReDim cannot change the rank
        Dim resizable() As Integer
        ReDim resizable(3)
        Console.WriteLine("resizable: " & resizable.Length)
    End Sub

The rules, all of which the example above exercises:

Statement Rule

ReDim a(n)

Allocates a new array with upper bound n; old elements are lost. The variable must already be declared as an array (Dim a() As Integer).

ReDim Preserve a(n)

Allocates a new array and copies Math.Min(old.Length, new.Length) elements. Cost is proportional to the length; calling it once per added element makes a loop quadratic.

ReDim Preserve m(i, j)

Only the last dimension may change. Changing another dimension throws ArrayTypeMismatchException when the statement runs (not a compile error).

ReDim with As

Not allowed: ReDim data(n) As Byte is BC30811. Declare the variable first, then ReDim it.

ReDim changing the rank

BC30415. ReDim a(1, 2) on a one-dimensional variable does not compile.

Array.Resize(a, n)

The framework equivalent with a length (not an upper bound) as argument, taking the variable ByRef. It also allocates a new array and copies. Array.Resize(a, 0) gives an empty array.

Erase a

Sets the array variable to Nothing; the elements become garbage when nothing else refers to the array. It does not zero the elements of an array that other variables still use; use Array.Clear for that. On a non-array variable it is BC30049.

Note the unit difference between the two ways to resize: ReDim Preserve counts(5) produces six elements and Array.Resize(counts, 4) produces four. Erase rarely matters in .NET: the garbage collector reclaims arrays that are no longer referenced, and setting a local variable to Nothing does not make that happen earlier in release builds.

Multidimensional and jagged arrays

Visual Basic has two ways to model a table. A rectangular array, Dim m(2, 3) As Integer, is a single object with a fixed number of rows and columns; its type is Integer(,). A jagged array, Dim j(2)() As Integer, is an array whose elements are themselves arrays, each of which can have a different length; its type is Integer()(). Both declarations list upper bounds: m(2, 3) is 3 rows by 4 columns.

Option Strict On

Module Program
    Sub Main()
        ' Rectangular: (2, 3) means 3 rows by 4 columns
        Dim matrix(2, 3) As Integer
        For r = 0 To matrix.GetUpperBound(0)
            For c = 0 To matrix.GetUpperBound(1)
                matrix(r, c) = r * 10 + c
            Next
        Next
        Console.WriteLine("Rank = " & matrix.Rank & ", Length = " & matrix.Length)
        Console.WriteLine("GetLength(0) = " & matrix.GetLength(0) & ", GetLength(1) = " & matrix.GetLength(1))
        Console.WriteLine("UBound(matrix, 1) = " & UBound(matrix, 1) & ", UBound(matrix, 2) = " & UBound(matrix, 2))

        ' For Each visits a rectangular array in row-major order
        For Each v In matrix
            Console.Write(v & " ")
        Next
        Console.WriteLine()

        ' Initializers nest braces, one level per dimension
        Dim table As Integer(,) = {{1, 2, 3}, {4, 5, 6}}
        Console.WriteLine("table(1, 2) = " & table(1, 2))

        ' Jagged: an array whose elements are arrays, each with its own length
        Dim jagged(2)() As Integer

        jagged(1) = New Integer() {1, 2, 3}
        jagged(2) = Array.Empty(Of Integer)()

            Console.WriteLine("row " & i & " has " & jagged(i).Length & " elements: " & String.Join(",", jagged(i)))

Passing arrays and ParamArray

An array parameter receives a copy of the reference. The callee can change elements, which the caller sees; the callee can re-point its own parameter at a different array, which the caller does not see unless the parameter is ByRef. This is the same rule as for every reference type (see Procedures: Sub and Function). Returning an array hands the caller a reference too; if the array is the internal state of an object, return a copy (Clone/ToArray) or a read-only wrapper (Array.AsReadOnly, IReadOnlyList(Of T), ImmutableArray(Of T)), otherwise callers can change your object from outside.

ParamArray lets callers pass the elements as separate arguments; inside the procedure the parameter is an ordinary array. The compiler packs the arguments into a new array on every call (allocation), and passing an existing array hands it over unchanged.

Option Strict On

Module Program
    Sub DoubleAll(values As Integer())      ' ByVal: the reference is copied, the elements are shared
        For i = 0 To values.Length - 1
            values(i) *= 2
        Next
    End Sub

    Sub Replace(ByRef values As Integer())  ' ByRef: the caller's variable can be re-pointed
        values = New Integer() {0, 0}
    End Sub

    Sub Rebind(values As Integer())         ' ByVal: re-pointing the parameter is invisible to the caller
        values = New Integer() {0, 0}
    End Sub

    Function Sum(ParamArray numbers As Integer()) As Integer
        Dim total = 0
        For Each n In numbers
            total += n
        Next
        Return total
    End Function

    Function Describe(label As String, ParamArray parts As String()) As String
        If parts Is Nothing Then Return label & ": Nothing"
        Return label & ": " & parts.Length & " part(s)"
    End Function

    Function Squares(count As Integer) As Integer()
        Dim result(count - 1) As Integer
        For i = 0 To count - 1
            result(i) = i * i
        Next
        Return result
    End Function

An array of a reference type converts implicitly to an array of any base type (array covariance, present since .NET 1.0). Rules to remember:

  • Covariance applies only to reference types: Integer() is not an Object() (the output shows False), though String() is.

  • Every store into an array of a reference type costs a type check because of this. Declare arrays of sealed types (such as String) or use List(Of T) where the cost matters.

Non-zero bounds and VB6

Visual Basic 6 and VBA allowed Dim a(1 To 5) and Option Base 1, so that the first element had any index. Visual Basic .NET removed both (array lower bounds were fixed at zero from version 7 so that arrays are the same in all .NET languages). The compiler keeps accepting 0 To n as a compatibility spelling and rejects other lower bounds with BC32059. Option Base is a syntax error (BC30206, "Option must be followed by Compare, Explicit, Infer, or Strict"):

Option Strict On
Option Base 1

    Sub Main()
    End Sub
End Module

The framework can still create an array with a non-zero lower bound through Array.CreateInstance, because other languages and COM interop need them. Such an array is not an Integer() or String() in the Visual Basic sense: its type name is String[*], it cannot be cast to String() (InvalidCastException), and it has to be accessed with GetValue/SetValue:

Option Strict On

Module Program

        Console.WriteLine("fine: " & fine.Length)

        Dim lengths As Integer() = {3}
        Dim lowers As Integer() = {1}

            oneBased.SetValue("zero", 0)

A shelf example

The reference scenario of this section is a library catalogue; the example below keeps books in an array, spreads them over a rectangular array of shelf levels and slots, groups them into a jagged array by size and sorts a copy so that the caller’s order is untouched. Note the root-namespace trap that the first draft of this program hit: the project root namespace was Shelf, and because Visual Basic is case-insensitive a local variable named shelf (or Shelf) is BC30112, "is a namespace and cannot be used as an expression"; the loop variables are called level and slot.

Option Strict On

Public Class Book
    Public ReadOnly Property Title As String
    Public ReadOnly Property Pages As Integer

    Public Sub New(title As String, pages As Integer)
        Me.Title = title
        Me.Pages = pages
    End Sub

    Public Overrides Function ToString() As String
        Return Title & " (" & Pages & " pages)"
    End Function
End Class

Module Program
    Const LevelCount As Integer = 3
    Const SlotsPerLevel As Integer = 4

    ' Returns a new array; the caller owns it
    Function ByLength(books As Book()) As Book()
        Dim sorted = CType(books.Clone(), Book())
        Array.Sort(sorted, Function(left, right) left.Pages.CompareTo(right.Pages))
        Return sorted
    End Function

    Sub Main()
        Dim books As Book() = {
            New Book("Refactoring", 448),
            New Book("Clean Code", 464),
            New Book("The Pragmatic Programmer", 352),
            New Book("Domain-Driven Design", 560),
            New Book("Working Effectively with Legacy Code", 456)
        }

        ' Number of elements is Length; the last valid index is Length - 1
        Console.WriteLine(books.Length & " books, last index " & (books.Length - 1))

        ' A rectangular array: levels by slots (the declaration gives UPPER bounds)
        Dim slots(LevelCount - 1, SlotsPerLevel - 1) As Book
        Dim nextBook = 0
        For level = 0 To slots.GetUpperBound(0)
            For slot = 0 To slots.GetUpperBound(1)
                If nextBook < books.Length Then
                    slots(level, slot) = books(nextBook)
                    nextBook += 1
                End If
            Next
        Next

        For level = 0 To slots.GetLength(0) - 1
            Dim used = 0
            For slot = 0 To slots.GetLength(1) - 1
                If slots(level, slot) IsNot Nothing Then used += 1
            Next
            Console.WriteLine("level " & level & ": " & used & " of " & slots.GetLength(1) & " slots used")
        Next

        ' A jagged array: books grouped by size class, each group with its own length
        Dim groups(2)() As Book
        groups(0) = Array.FindAll(books, Function(b) b.Pages < 400)
        groups(1) = Array.FindAll(books, Function(b) b.Pages >= 400 AndAlso b.Pages < 500)
        groups(2) = Array.FindAll(books, Function(b) b.Pages >= 500)
        For i = 0 To groups.Length - 1
            Console.WriteLine("group " & i & ": " & groups(i).Length & " book(s)")
        Next

        For Each book In ByLength(books)
            Console.WriteLine(book)
        Next
        Console.WriteLine("original first: " & books(0).Title)

        ' The total uses a variable declared before the loop; a Sum call would do the same
        Dim totalPages = 0
        For Each book In books
            totalPages += book.Pages
        Next
        Console.WriteLine("average pages = " & (totalPages / books.Length).ToString("0.0"))
    End Sub
End Module

Where older material is wrong

Teaching material written for VB6, or quickly for VB.NET, repeats a handful of mistakes that this page’s examples are meant to correct. Each is checked here against the compiler.

  • "`Dim a(10) As Integer` has 10 elements." It has 11; the number is the upper bound. Likewise Dim m(5, 10) is 6 by 11. For a fixed number n of elements write Dim a(n - 1) As Integer, or Dim a(Count - 1) with a named constant.

  • "`UBound(m, 1)` is the number of columns." It is the upper bound of the first dimension (rows); the column dimension is 2, and a bound is never a length. Use GetLength when you want a count.

  • “ReDim data(n) As Byte” does not compile in Visual Basic .NET (BC30811). Declare Dim data() As Byte or Dim data(n) As Byte once and ReDim data(n) later, or write data = New Byte(n) {}.

  • "Arrays can start at 1 (Option Base 1, 1 To 5)." True for VB6/VBA only (see Non-zero bounds and VB6).

  • "Use ReDim Preserve to build a list while reading input." It works, but it copies the array on every call; List(Of T) is the right tool and has ToArray() for the end.

  • "`+` joins array elements into text." Use String.Join(", ", a) and & (see Strings and Text).

Pitfalls checklist

  • Upper bound versus length: Dim a(n) has n + 1 elements; a loop For i = 0 To a.Length is one too many.

  • A declared-but-unsized array (Dim a() As Integer) is Nothing, not empty. Initialise it or use Array.Empty(Of T)().

  • ReDim and ReDim Preserve create a new array: other references keep the old one; parameters passed ByVal do not see the new array.

  • ReDim Preserve on a multidimensional array fails at run time unless only the last dimension changes.

  • For Each gives a copy of structure elements; to modify them in place, loop over indexes.

  • Rank is part of the type: Integer(), Integer(,) and Integer()() are three unrelated types. A jagged row can be Nothing.

  • = does not compare arrays; Is compares identity; SequenceEqual compares contents.

  • Covariance makes Book() convertible to CatalogItem(); storing a Magazine then throws at run time.

  • Array.Sort is unstable and culture-sensitive for strings; pass a comparer when the order must be reproducible.

  • Array.IndexOf returns -1 for "not found"; BinarySearch returns a negative complement and requires sorted input.

  • Lambda parameter names must not collide with any local of the enclosing method, even one declared below the lambda (BC36641).

  • A local named like the root namespace or a type (shelf, text, name) can give BC30112 or silently refer to something else.

  • Const cannot be an array (BC30424); ReadOnly freezes the variable but not the elements.

  • Public properties that return an internal array let callers change your object: return a copy or IReadOnlyList(Of T).

  • Spans and ranges are unavailable: use ArraySegment, Memory(Of T), Array.Copy or LINQ.
