Structures and Value Types

This content was generated with the assistance of AI and should be verified against the official documentation before being relied on in production.

This page is written against Visual Basic 17.13 on .NET 10 (SDK 10.0.402) and was checked on 2026-10-19. Every example is a complete console program that starts with Option Strict On, was built with warnings treated as errors (except the ones that are meant to fail, which say so) and was run in the .NET 10 SDK container (Linux); the output shown is real output. The root namespace of the scratch projects is Shelf, which is why runtime messages mention Shelf.Cursor.

A structure is a value type that you declare yourself: a bundle of fields, properties, methods and operators whose variables contain the data instead of pointing at it. Date, Decimal, Integer, Guid, TimeSpan, KeyValuePair(Of TKey, TValue) and the tuples written (Integer, String) are all structures, and so is the Isbn type of the shelf library catalogue used throughout this reference. Visual Basic has had Structure since the first .NET release, where it replaced the VB6 Type ... End Type user-defined type (see The VB Family: VB6, VBA and VBScript). Structures are the right tool for small, immutable, value-like data and the wrong tool for almost everything else, and the language makes the wrong choice easy to make by accident: several errors that C# programmers know are silent in Visual Basic.

Declaring a structure

[<attributes>] [accessmodifier] [Shadows] [Partial] Structure Name [(Of typeparameters)]
    [Implements interface]
    ' fields, constants, properties, methods, operators, events, nested types
End Structure

  • A structure can be declared at namespace level or inside a class, structure, module or interface. Without an access modifier a top-level structure is Friend and a nested one is Public, as for other types.

  • Members are Public by default, unlike a class, where a Dim field is Private. The example below shows it by reflection. Writing Dim Field As Integer in a structure exposes a public field.

  • A structure may be generic (Structure Pair(Of T)) and may be Partial. It cannot be MustInherit, NotInheritable or ReadOnly: a structure is implicitly sealed, and Visual Basic has no ReadOnly Structure (error BC30395).

  • A structure implicitly inherits System.ValueType and cannot name any other base class. It can implement any number of interfaces with Implements.

  • The fields are laid out in declaration order (sequential layout) unless a StructLayout attribute says otherwise (see Memory layout).

Error Rule Why and what to do

BC31049

No instance field initializers

Public Pages As Integer = 100 is rejected: only Shared members and constants may have an initializer. Assign values in a constructor or, for a default other than zero, expose a factory method or a property that interprets zero. C# 10 added field initializers to structures that declare a constructor; Visual Basic did not follow.

BC30629

No parameterless instance Sub New

Every structure has an implicit parameterless constructor that sets every field to its zero value, and you cannot replace it. Code such as Dim a As New PageRange(), Dim a As PageRange and Nothing all give that zero value, so a structure can never guarantee that a constructor ran. C# 10 allows a parameterless constructor in a structure; Visual Basic does not.

BC30628

No Inherits

A structure derives from System.ValueType and nothing else. Reuse behaviour through interfaces, composition and extension methods.

BC30435

No Overridable, MustOverride or Protected members

Nothing can derive from a structure, so those modifiers have no meaning. You can still override ToString, Equals and GetHashCode, which are inherited from Object and ValueType.

BC30294

No field of the structure’s own type

Public Inner As Recursive would need infinite size. Use a reference type in between: a class, an array or a List(Of T). The same message is given for a field of type Recursive?, because Nullable(Of T) is itself a structure that contains the value.

BC31043

No array field with a declared size

Public Items(3) As Integer is rejected. Declare Public Items() As Integer and allocate in a constructor (a reference to an array copies as a reference; see Arrays).

BC30480

Shared Sub New cannot have an access modifier

The static constructor of a class has the same rule. Write Shared Sub New(), not Public Shared Sub New().

BC30395

No ReadOnly Structure

There is no readonly structure in Visual Basic. See Immutable structures.

Two rules that the Language Reference lists are not enforced by the 17.13 compiler on SDK 10.0.402, which is why the table does not claim them as errors: an empty Structure with no members compiles, and so does a structure that contains only Shared members. The Learn page for structures and classes still states the older limit (a structure must have at least one non-shared variable or event), which is an example of the text lagging the compiler.

Value semantics: assignment copies

A variable of a structure type holds the fields themselves. Assignment, argument passing by value, return values, boxing and storing in a collection all copy the bits; a change to the copy never affects the original. The program below shows the copy on assignment, on a ByVal call, and the ways of getting a change back to the caller (ByRef, or returning the new value).

Option Strict On

Public Structure PageRange
    Public First As Integer
    Public Last As Integer

    Public Sub New(first As Integer, last As Integer)
        Me.First = first
        Me.Last = last
    End Sub

    Public ReadOnly Property Count As Integer
        Get
            Return Last - First + 1
        End Get
    End Property

    Public Overrides Function ToString() As String
        Return First & "-" & Last
    End Function
End Structure

Module Program
    Sub Extend(range As PageRange)
        range.Last += 10
        Console.WriteLine("inside Extend:  " & range.ToString())
    End Sub

    Sub ExtendInPlace(ByRef range As PageRange)
        range.Last += 10
    End Sub

    Sub Main()
        Dim a As New PageRange(1, 20)
        Dim b As PageRange = a            ' copies every field
        b.Last = 99
        Console.WriteLine("a = " & a.ToString() & ", b = " & b.ToString())

        Extend(a)                         ' ByVal: the callee gets a copy
        Console.WriteLine("after Extend: " & a.ToString())
        ExtendInPlace(a)
        Console.WriteLine("after ByRef:  " & a.ToString())

        Dim blank As PageRange            ' all fields are zero
        Dim viaNew As New PageRange()     ' the implicit parameterless New does the same
        Console.WriteLine("blank = " & blank.ToString() & ", viaNew = " & viaNew.ToString() & ", Count = " & blank.Count)

        Dim reset As PageRange = a
        reset = Nothing                   ' Nothing for a structure means default(PageRange)
        Console.WriteLine("reset = " & reset.ToString())
        Console.WriteLine("a is value type: " & GetType(PageRange).IsValueType)
    End Sub
End Module

Notes on the listing:

  • Dim b As PageRange = a is a copy, not an alias, so b.Last = 99 does not touch a. For a class the same two lines would make two names for one object.

  • Extend(a) passes a copy. The method’s range.Last += 10 changes only that copy. ExtendInPlace(ByRef range ...) receives a reference to the caller’s variable and changes it. The VB6 default of ByRef is gone: a parameter is ByVal unless you say otherwise (see Procedures: Sub and Function).

  • Dim blank As PageRange, Dim viaNew As New PageRange() and reset = Nothing all give the same all-zero value. For a structure, Nothing means "the default value of the type" (it is not a null reference; see Nothing and Nullable Value Types). Is Nothing on a structure does not compile (BC30020, below).

  • Count is a computed property: the structure has no state beyond its two fields.

Where the storage is

The common statement that "structures live on the stack" is a simplification. The storage of a value type is where the variable is:

The variable is A structure value is stored

a local variable or parameter

in the method’s frame (stack or CPU register, at the JIT’s discretion)

a field of a class

inline in the heap object of that class

a field of another structure

inline in the enclosing structure

an element of an array

inline in the array’s heap block, so Dim a(999) As PageRange is one allocation of contiguous memory

boxed into an Object or an interface variable

in a separate heap object (a box), subject to garbage collection

captured by a lambda or an Async method

in a heap object that the compiler generates (a closure or state machine)

The garbage collector never runs a finalizer for a structure, and an array of structures that contain no references costs it almost nothing to scan; those are the benefits. The cost is the copy on every assignment and call, which grows with the size of the structure.

Default values and constructors

Every structure has an implicit parameterless New that zeroes all fields, so New PageRange() is always legal even when you declare only constructors with parameters. That has a consequence for any invariant you try to protect: a validating constructor is simply bypassed by Dim x As Isbn, by Nothing, by an array of the type and by Activator.CreateInstance. The shelf Isbn shows the usual defence: make the constructor Private, offer Parse and TryParse, and give the zero value an explicit meaning (IsEmpty).

Option Strict On

Public Structure Isbn
    Implements IEquatable(Of Isbn)

    Public ReadOnly Property Value As String

    Private Sub New(value As String)
        Me.Value = value
    End Sub

    Public ReadOnly Property IsEmpty As Boolean
        Get
            Return Value Is Nothing
        End Get
    End Property

    Public Shared Function TryParse(text As String, ByRef result As Isbn) As Boolean
        Dim digits = New String(If(text, "").Where(AddressOf Char.IsLetterOrDigit).ToArray())
        If digits.Length = 13 AndAlso digits.All(AddressOf Char.IsDigit) AndAlso HasValidCheckDigit(digits) Then
            result = New Isbn(digits)
            Return True
        End If
        Return False
    End Function

    Public Shared Function Parse(text As String) As Isbn
        Dim result As Isbn = Nothing                  ' initialised: passing an unassigned structure ByRef is BC42108
        If Not TryParse(text, result) Then
            Throw New FormatException("'" & text & "' is not a valid ISBN-13.")
        End If
        Return result
    End Function

    Private Shared Function HasValidCheckDigit(digits As String) As Boolean
        Dim sum = 0
        For i = 0 To 12
            Dim d = AscW(digits(i)) - AscW("0"c)
            sum += If(i Mod 2 = 0, d, d * 3)
        Next
        Return sum Mod 10 = 0
    End Function

    Public Overloads Function Equals(other As Isbn) As Boolean Implements IEquatable(Of Isbn).Equals
        Return Value = other.Value
    End Function

    Public Overrides Function Equals(obj As Object) As Boolean
        Return TypeOf obj Is Isbn AndAlso Equals(DirectCast(obj, Isbn))
    End Function

    Public Overrides Function GetHashCode() As Integer
        Return If(Value, "").GetHashCode()
    End Function

    Public Overrides Function ToString() As String
        Return If(Value, "(empty)")
    End Function
End Structure

Module Program
    Sub Main()
        Dim good = Isbn.Parse("978-0-13-468599-1")
        Console.WriteLine("parsed: " & good.ToString() & ", IsEmpty " & good.IsEmpty)

        Dim blank As New Isbn()                        ' the default value skips the private constructor
        Console.WriteLine("default: " & blank.ToString() & ", IsEmpty " & blank.IsEmpty)
        Console.WriteLine("good = blank: " & good.Equals(blank))

        Dim parsed As Isbn = Nothing
        Console.WriteLine("TryParse bad:  " & Isbn.TryParse("123", parsed) & " -> " & parsed.ToString())
        Console.WriteLine("TryParse good: " & Isbn.TryParse("9780134685991", parsed) & " -> " & parsed.ToString())

        Dim maybe As Isbn? = Nothing                    ' Nullable(Of Isbn) says "no ISBN" explicitly
        Console.WriteLine("maybe.HasValue: " & maybe.HasValue)
        maybe = good
        Console.WriteLine("maybe.Value: " & maybe.Value.ToString())

        Dim shelf(2) As Isbn                            ' array elements are default structures, not Nothing
        shelf(1) = good
        For i = 0 To shelf.Length - 1
            Console.WriteLine("shelf(" & i & ") = " & shelf(i).ToString())
        Next

        Try
            Isbn.Parse("978-0-13-468599-2")
        Catch ex As FormatException
            Console.WriteLine("FormatException: " & ex.Message)
        End Try
    End Sub
End Module

Details worth keeping:

  • The private constructor takes a parameter, so it is not the forbidden parameterless one. The implicit parameterless constructor stays Public: you cannot hide it. That is why blank exists at all.

  • A constructor need not assign every field. Unlike C# before version 11, there is no "all fields must be assigned" rule and no definite-assignment error; unassigned fields are zero.

  • A reference-type field of a structure is Nothing in the zero value. Use If(Value, "") or a property that substitutes a safe default, as ToString does above.

  • Unassigned variables. A structure that contains a reference-type member gets the flow-analysis warnings that a reference variable gets. Passing Dim p As P by ByRef before assigning it is BC42108 ("Variable 'p' is passed by reference before it has been assigned a value. A null reference exception could result at runtime. Make sure the structure or all the reference members are initialized before use"), and reading a field of such a variable can be BC42109. Initialising the variable with = Nothing or New silences them, which is why Parse assigns result = Nothing before calling TryParse, and why the project has TreatWarningsAsErrors: a program that left out the initialiser would not build.

  • Dim shelf(2) As Isbn creates three zero values, not three Nothing references. shelf(0).Value Is Nothing is True.

Constants, shared members and operators in a structure

A structure may hold constants, Shared fields, a Shared Sub New (no access modifier), properties (including auto-implemented properties), methods, operators, conversion operators and nested types. The program below combines them in a Dimensions structure for the physical size of a book, and also shows Me.New(...) chaining, an Optional constructor parameter, IComparable(Of T), an object initializer and a With block on a local structure variable.

Option Strict On

Public Structure Dimensions
    Implements IComparable(Of Dimensions)

    Public Const Unit As String = "cm"
    Public Shared ReadOnly Empty As Dimensions
    Public Shared ReadOnly A5 As New Dimensions(14.8, 21.0)
    Private Shared _created As Integer

    Public Property Width As Double
    Public Property Height As Double
    Public Property Depth As Double

    Shared Sub New()
        Console.WriteLine("Shared constructor runs once, before first use")
    End Sub

    Public Sub New(width As Double, height As Double, Optional depth As Double = 1.0)
        Me.Width = width
        Me.Height = height
        Me.Depth = depth
        _created += 1
    End Sub

    Public Sub New(side As Double)
        Me.New(side, side)                       ' constructor chaining uses Me.New
    End Sub

    Public Shared ReadOnly Property CreatedCount As Integer
        Get
            Return _created
        End Get
    End Property

    Public ReadOnly Property Volume As Double
        Get
            Return Width * Height * Depth
        End Get
    End Property

    Public Function CompareTo(other As Dimensions) As Integer Implements IComparable(Of Dimensions).CompareTo
        Return Volume.CompareTo(other.Volume)
    End Function

    Public Overrides Function ToString() As String
        Return String.Format("{0} x {1} x {2} {3}", Width, Height, Depth, Unit)
    End Function

    Public Shared Operator +(left As Dimensions, right As Dimensions) As Dimensions
        Return New Dimensions(Math.Max(left.Width, right.Width), Math.Max(left.Height, right.Height), left.Depth + right.Depth)
    End Operator

    Public Shared Widening Operator CType(side As Double) As Dimensions
        Return New Dimensions(side)
    End Operator
End Structure

Module Program
    Sub Main()
        Console.WriteLine("Main starts")
        Console.WriteLine("Empty = " & Dimensions.Empty.ToString())
        Console.WriteLine("A5 = " & Dimensions.A5.ToString() & ", volume " & Dimensions.A5.Volume)

        Dim cube As New Dimensions(2.5)
        Dim initialised As New Dimensions With {.Width = 10, .Height = 15, .Depth = 2}
        Console.WriteLine("cube = " & cube.ToString())
        Console.WriteLine("initialised = " & initialised.ToString())

        Dim stack As Dimensions = cube + cube
        Console.WriteLine("stack = " & stack.ToString())

        Dim widened As Dimensions = 4.0              ' Widening CType: implicit under Option Strict On
        Console.WriteLine("widened = " & widened.ToString())

        Dim sorted As New List(Of Dimensions) From {stack, cube, initialised, Dimensions.A5}
        sorted.Sort()
        For Each d In sorted
            Console.WriteLine("  " & d.ToString() & " -> " & d.Volume)
        Next

        With initialised
            .Depth = 3                               ' With on a local variable changes the variable
        End With
        Console.WriteLine("after With: " & initialised.ToString())
        Console.WriteLine("constructor calls with arguments: " & Dimensions.CreatedCount)
    End Sub
End Module

Observations:

  • The Shared field initializers run before the Shared Sub New body, and both run lazily, before the first use of the structure (Dimensions.Empty in this program), not at program start. Pay attention to the output order: "Main starts" appears first.

  • New Dimensions With {.Width = 10} calls the implicit parameterless constructor and then sets the properties. It is the usual way to create a structure that has public settable members, and it bypasses every constructor you wrote: the constructor count at the end is 4 (A5, cube, stack and widened) and does not include initialised.

  • Shared ReadOnly Empty As Dimensions is allowed although a field of the structure’s own type is not (BC30294 applies to instance fields only).

  • Dim widened As Dimensions = 4.0 works because Widening Operator CType is implicit even under Option Strict On; make a conversion Narrowing when information can be lost (see Operator Overloading and Equality).

  • With initialised ... End With on a local variable changes that variable. The same block on an expression that returns a copy (With list(0)) is rejected when it assigns (.V = 5 is BC30068); see the next section.

Mutable structures and the lost update

The most common error in programs that use structures is changing a copy. Visual Basic makes a different part of the problem loud than C# does. The table summarises what happens when you change a structure that you reached through each kind of expression.

You write Result Why

local.Value = 1

works

a local variable is a variable

obj.Field.Value = 1 (public field)

works

a field is a variable

array(0).Value = 1

works

an array element is a variable

BC30068

same

The assignment rows are errors; the method-call and For Each rows are silent. The messages below come from this program, which fails to build on purpose:

Option Strict On

Public Structure Counter
    Public Value As Integer
End Structure

Public Class Holder
    Public Property AsProperty As Counter
    Public ReadOnly AsReadOnlyField As Counter
End Class

Module Program
    Sub Main()
        Dim list As New List(Of Counter) From {New Counter()}
        list(0).Value = 5

        Dim h As New Holder()
        h.AsProperty.Value = 5
        h.AsReadOnlyField.Value = 5

        Dim a As New Counter()

Immutable structures

Because a mutable structure is so easy to misuse, the guidance for structures in .NET is to make them immutable: all fields ReadOnly, no setters, "mutation" methods that return a new value. Visual Basic has no ReadOnly Structure and no readonly member keyword, so the discipline is by convention:

  • declare fields Public ReadOnly (or Private ReadOnly behind ReadOnly Property), and initialise them in the constructor;

  • declare auto-implemented properties as Public ReadOnly Property X As Integer, assigned in the constructor;

  • return a new value from every "change" (Public Function WithLast(last As Integer) As PageRange);

  • the PageRange structure in the equality example below is built that way.

A consequence is that the compiler does not mark a Visual Basic structure as readonly in metadata, so a C# compiler calling a method on one through an in parameter or a readonly field must make defensive copies. For a hot path that C# code consumes, build the structure in C# as a readonly struct and reference it from the Visual Basic project; see the end of this page.

Equality: Equals, GetHashCode and operators

A structure that declares nothing gets Equals(Object) and GetHashCode from System.ValueType: two values are equal when all their fields are equal. The inherited Equals can use reflection, and the inherited GetHashCode may not mix every field into the result, so for anything that is used as a dictionary key or in a hot loop you should override both. The operators = and <> do not exist for a structure unless you define them (BC30452 earlier), and Is is not allowed at all, because a structure has no reference identity (BC30020).

Option Strict On

' No overrides: Equals comes from System.ValueType and compares field by field.
Public Structure ShelfSlot
    Public Row As Integer
    Public Position As Integer
End Structure

Public Structure PageRange
    Implements IEquatable(Of PageRange)

    Public ReadOnly First As Integer
    Public ReadOnly Last As Integer

    Public Sub New(first As Integer, last As Integer)
        Me.First = first
        Me.Last = last
    End Sub

    Public Overloads Function Equals(other As PageRange) As Boolean Implements IEquatable(Of PageRange).Equals
        Return First = other.First AndAlso Last = other.Last
    End Function

    Public Overrides Function Equals(obj As Object) As Boolean
        Return TypeOf obj Is PageRange AndAlso Equals(DirectCast(obj, PageRange))
    End Function

    Public Overrides Function GetHashCode() As Integer
        Return HashCode.Combine(First, Last)
    End Function

    Public Shared Operator =(left As PageRange, right As PageRange) As Boolean
        Return left.Equals(right)
    End Operator

    Public Shared Operator <>(left As PageRange, right As PageRange) As Boolean
        Return Not left.Equals(right)
    End Operator

    Public Overrides Function ToString() As String

    End Function
End Structure

The complete recipe, which is also the one the shelf Isbn uses:

  1. Implement IEquatable(Of T) and write Equals(other As T) with the Overloads keyword. It avoids boxing in Dictionary, HashSet, List.Contains and Array.IndexOf, which all use EqualityComparer(Of T).Default.

  2. Override Equals(Object): TypeOf obj Is PageRange AndAlso Equals(DirectCast(obj, PageRange)). The TypeOf ... Is test on a value type checks the box’s type; DirectCast then unboxes it. C# 7 pattern matching does this in one line; Visual Basic needs the two steps.

  3. Override GetHashCode with the same fields, using HashCode.Combine(a, b, ...) (up to eight values). Equal values must have equal hash codes. Do not use a field that can change if the value is stored in a hash-based collection.

  4. Define Shared Operator = and Shared Operator <> together (the compiler requires a matching pair, as for < and >).

  5. Add IComparable(Of T) and the four ordering operators if the type has a natural order (the Dimensions example above).

Nullable(Of T) lifts the operators: nullable = a compiles, and nullable Is Nothing is the way to ask whether the nullable has no value (see Operator Overloading and Equality for the full treatment, including the three-valued logic of lifted comparisons).

Boxing, interfaces and generics

Converting a structure to Object, to ValueType, or to an interface it implements boxes it: the runtime allocates an object on the heap and copies the value into it. Unboxing (DirectCast(o, Cursor)) copies it out again. The box is a reference type, so several variables of the interface type can share one box, and mutation through the interface changes the box and not the original variable. The Cursor structure below makes the three effects visible: a call through an interface parameter, a generic method with a Structure and interface constraint (which does not box), and a shared box.

Option Strict On

Public Interface IStepper
    Sub [Step]()
    ReadOnly Property Position As Integer
End Interface

Public Structure Cursor
    Implements IStepper

    Private _position As Integer

    Public Sub [Step]() Implements IStepper.Step
        _position += 1
    End Sub

    Public ReadOnly Property Position As Integer Implements IStepper.Position
        Get
            Return _position
        End Get
    End Property
End Structure

Module Program
    Sub StepTwice(Of T As {Structure, IStepper})(ByRef stepper As T)
        stepper.Step()                         ' constrained call: no boxing, the caller's variable changes
        stepper.Step()
    End Sub

    Sub StepTwiceBoxed(stepper As IStepper)
        stepper.Step()                         ' the argument is a boxed copy
        stepper.Step()
    End Sub

    Sub Main()
        Dim cursor As New Cursor()
        cursor.Step()
        Console.WriteLine("direct call:         " & cursor.Position)

        StepTwiceBoxed(cursor)                 ' boxes a copy
        Console.WriteLine("after interface arg: " & cursor.Position)

        StepTwice(cursor)                      ' generic constraint, ByRef
        Console.WriteLine("after generic call:  " & cursor.Position)

        Dim box As IStepper = cursor           ' one box, shared through the interface
        Dim alias2 As IStepper = box
        box.Step()
        Console.WriteLine("box = " & box.Position & ", alias = " & alias2.Position & ", cursor = " & cursor.Position)

        Dim o As Object = cursor
        Dim unboxed = DirectCast(o, Cursor)    ' unboxing copies again
        unboxed.Step()
        Console.WriteLine("object = " & DirectCast(o, Cursor).Position & ", unboxed = " & unboxed.Position)

        Console.WriteLine("is interface: " & (TypeOf o Is IStepper) & ", same box: " & ReferenceEquals(box, alias2))

        Try
            Dim notBoxed As Object = "text"
            Dim c As Cursor = DirectCast(notBoxed, Cursor)
            Console.WriteLine(c.Position)
        Catch ex As InvalidCastException
            Console.WriteLine("InvalidCastException: " & ex.Message)
        End Try

        Try
            Dim nothingObject As Object = Nothing
            Dim c As Cursor = DirectCast(nothingObject, Cursor)
            Console.WriteLine("unboxing Nothing gives default: " & c.Position)
        Catch ex As NullReferenceException
            Console.WriteLine("NullReferenceException")
        End Try
    End Sub
End Module

  • StepTwiceBoxed(cursor) boxes a copy, so the caller’s cursor.Position stays 1.

  • StepTwice(Of T As {Structure, IStepper})(ByRef stepper As T) is the allocation-free way to call interface members on a structure: the JIT specialises the method for the structure type and calls the member on the caller’s variable (3). Without ByRef the generic method would work on a copy.

  • box and alias2 are the same object (ReferenceEquals is True), so box.Step() is seen through both, while cursor is unchanged.

  • DirectCast to the wrong type throws InvalidCastException; unboxing a null Object into a non-nullable structure throws NullReferenceException. Test with TypeOf o Is Cursor first. TryCast cannot be used for a value type (TryCast(o, Cursor?) is BC30792 "operand must be reference type").

  • A Structure constraint (T As Structure) means "any non-nullable value type": the generic code can use T? and cannot use Nothing as an unset reference (see Generics).

Typical places where boxing happens without being visible: passing a structure to a parameter of type Object, ValueType or an interface; String.Format("{0}", value) and Console.WriteLine("{0}", value) (the ParamArray Object); using the non-generic collections (ArrayList, Hashtable); calling the inherited GetType or the non-overridden GetHashCode on a structure that does not override it; and late binding (Object variables, see Early and Late Binding).

Memory layout

Fields of a structure are stored in declaration order with the padding the processor needs (sequential layout, which both the Visual Basic and C# compilers emit by default). A structure that contains a reference-type field is laid out automatically by the CLR, which is free to reorder; the layout of a structure that contains only blittable fields is the one you declare. Native interop, binary file formats and sensor data need a fixed layout, which System.Runtime.InteropServices.StructLayoutAttribute and FieldOffsetAttribute give. Class or structure?

Visual Basic unifies the syntax for structures and classes (constructors, methods, properties, events, interfaces, Shared members, operators and nested types are available to both), so the choice is not about syntax. The Framework Design Guidelines, reprinted by Microsoft and dated 2008, say to prefer a class unless the type represents a single value, is small (the guidance gives 16 bytes), is immutable and is not boxed often. Nullable structures

A structure cannot be Nothing, so "no value" needs either a sentinel (Isbn.IsEmpty) or Nullable(Of T), written T?. The value of Dim maybe As Isbn? = Nothing has HasValue = False, and maybe.Value throws InvalidOperationException when it has no value. The Isbn? form is itself a structure, which means a Nullable(Of T) of a large structure copies both the value and a flag. The full treatment (lifted operators, If(a, b), GetValueOrDefault) is on Nothing and Nullable Value Types; the equality example above and the Isbn example show the common uses.

Related value types

  • Enum is a structure-like value type with named constants: Enumerations.

  • Tuples, (Integer, String), are System.ValueTuple structures with mutable public fields; a tuple element in a List(Of T) has the same lost-update problem as any structure: Tuples and Anonymous Types.

  • Collections of structures avoid one allocation per element but copy on every read through an indexer: Collections.

  • Resource wrappers that must be disposed are normally classes: Object Lifetime and Disposal.

Consuming C# readonly struct, ref struct and Span(Of T)

Visual Basic cannot declare a readonly struct, a ref struct, a readonly member, a record struct, an in parameter or a ref return, but it can use the first two when a C# or BCL API gives them to it, with two classes of restriction.

readonly struct, in parameters

A C# readonly struct is an ordinary structure to Visual Basic: construct it with New, read its members and call its methods. A method with in parameters is called with ordinary arguments. A ref readonly return, in contrast, is not supported (see below). The solution that follows has two projects. The C# library:

using System;
namespace ShelfInterop;

public readonly struct Price
{
    public Price(decimal amount, string currency) { Amount = amount; Currency = currency; }
    public decimal Amount { get; }
    public string Currency { get; }
    public Price Plus(Price other) => new(Amount + other.Amount, Currency);
    public override string ToString() => $"{Amount:F2} {Currency}";
}

public ref struct Tokenizer
{
    private ReadOnlySpan<char> _rest;
    public Tokenizer(string text) { _rest = text; Current = ""; }
    public string Current { get; private set; }
    public bool MoveNext()
    {
        if (_rest.IsEmpty) return false;
        int i = _rest.IndexOf(' ');
        if (i < 0) { Current = _rest.ToString(); _rest = default; }
        else { Current = _rest[..i].ToString(); _rest = _rest[(i + 1)..]; }
        return true;
    }
}

public static class Pricing
{
    public static decimal Total(in Price a, in Price b) => a.Amount + b.Amount;
    public static ref readonly Price Cheaper(in Price a, in Price b) => ref (a.Amount <= b.Amount ? ref a : ref b);
    public static Tokenizer Tokenize(string text) => new(text);
    public static int CountWords(ReadOnlySpan<char> text) => text.Count(' ') + 1;
    public static void Fill(Span<int> target, int value) => target.Fill(value);
}

Span(Of T) and other ref structs: local use only

Span(Of T) and ReadOnlySpan(Of T) are ref struct types: they may only live on the stack, because they can point into the stack, into native memory or into the middle of an array. The C# compiler enforces that statically. The Visual Basic compiler does not understand the rule. What it does instead is hide the types: naming a ref struct in a declaration (a field, a local, a parameter or a return type) is error BC30668 ("'Span(Of Integer)' is obsolete: 'Types with embedded references are not supported in this version of your compiler.'"), because the types carry an ObsoleteAttribute that the Visual Basic compiler treats as an error. Inferred locals and chained calls are not named, so they compile. The conclusion for a Visual Basic programmer is that spans are available only through inference and method chains:

Option Strict On

Module Program
    ' A Span(Of T) parameter cannot be declared in Visual Basic: naming the type is BC30668.
    ' Spans are therefore used only through inferred locals and chained calls.
    Sub Main()
        Dim pages = New Integer() {10, 20, 30, 40, 50}

        Dim middle = pages.AsSpan().Slice(1, 3)       ' a view over the same memory, no copy
        middle(0) = 99                                ' writes through to the array
        Console.WriteLine("array after write: " & String.Join(",", pages))
        Console.WriteLine("view length: " & middle.Length & ", copy: " & String.Join(",", middle.ToArray()))

        Dim text = "978-0-13-468599-1".AsSpan()      ' ReadOnlySpan(Of Char): no substring allocation
        Dim dash = text.IndexOf("-"c)
        Console.WriteLine("prefix: " & text.Slice(0, dash).ToString())
        Console.WriteLine("parsed without Substring: " & Integer.Parse(text.Slice(0, dash)))

        Dim total = 0
        Dim view = pages.AsSpan()
        For i = 0 To view.Length - 1                  ' index the view
            total += view(i)
        Next
        Console.WriteLine("total: " & total)

        Dim read = pages.AsSpan(2).Length             ' chained use ends in the expression
        Console.WriteLine("tail length: " & read)
    End Sub

            Dim o As Object = s
            Console.WriteLine(o)
        Catch ex As Exception
            Console.WriteLine(ex.GetType().Name & ": " & ex.Message)
        End Try
    End Sub
End Module
Unhandled exception. System.InvalidProgramException: Common Language Runtime detected an invalid program.
   at Shelf.Program.Main()

The exceptions are thrown while the method is being prepared for execution, before its first line runs, so a Try ... Catch inside the same method cannot catch them (a Try in Main around the boxing line was tried and did not catch it). The restrictions to keep in mind when you use a span in Visual Basic are therefore:

  • never assign a span to an Object, an interface variable or a field, never use one as a generic type argument, and never put one in an array;

  • never capture a span in a lambda, and do not use a span local in an Async or Iterator method that crosses an Await or Yield;

  • do not store one in a Structure; a Visual Basic structure is not a ref struct, and naming the type is BC30668 anyway;

  • if you need stackalloc, a Memory(Of T) slice, an array pool or a span-returning API in your own code, write that code in C# and expose an ordinary (array, string or Memory(Of T)) interface to the Visual Basic caller.

Other C# features for ref structs (ref fields from C# 11, allows ref struct from C# 13, ref readonly returns) are likewise beyond Visual Basic as a consumer. Microsoft’s language strategy for Visual Basic is to keep it stable and to consume, but not extend, new runtime features (see History, Versions and Language Strategy), and these gaps are what that looks like in practice. For the other side of C# interop see Interop with C# and Other .NET Languages.

Older material you may meet

Books and tutorials written for VB6, VBA and the first .NET versions teach structures in ways that no longer apply:

  • The VB6 Type ... End Type becomes Structure ... End Structure; fixed-length strings (Name As String * 20) become a String with <VBFixedString(20)> for file I/O or a MarshalAs(UnmanagedType.ByValTStr) field for interop; Dim a(10) As Integer inside a Type is rejected (BC31043) and is allocated in a constructor instead. See Migrating Legacy Visual Basic.

  • Old samples keep structures in an ArrayList and change an element in place. Unboxing always produced a copy, so the pattern was never right; read the element into a variable, change it and write it back, as the lost-update example does for List(Of T).

  • Samples use Dim s As Structure1 = Nothing to mean "a null structure". In VB.NET it is the all-zero value, and a test for Is Nothing is a compile-time error, not a runtime one.

  • Sample "serialization" of structures with BinaryFormatter no longer works in .NET 9 and later. Use System.Text.Json; see Serialization: JSON and XML.

  • A structure that "inherits" behaviour in old samples is almost always a class in disguise: use a class, or an interface and an extension method.

  • The Language Reference for Structure still lists the older limits (an empty structure is an error); the 17.13 compiler accepts such a structure.

Pitfalls checklist

  • Mutating a structure obtained from a property, an indexer, a ReadOnly field or a For Each variable changes a copy and gives no diagnostic when the change is a method call.

  • Dim x As T, Nothing, New T(), an array element and Activator.CreateInstance all give an all-zero value that has never run your constructor.

  • Passing a structure to Object, ValueType, an interface or a ParamArray Object boxes it, and mutating through the interface changes only the box.

  • The default Equals and GetHashCode of ValueType may be slow or poor; override them, implement IEquatable(Of T) and define = and <> as a pair.

  • Is Nothing, IsNot Nothing and Is between structures are errors (BC30020); use Nullable(Of T) and HasValue.

  • A structure cannot have a parameterless constructor, a field initializer, an array field with a size, an Inherits or a Protected member; the error numbers are in the table above.

  • There is no ReadOnly Structure; immutability is by convention, and C# callers cannot rely on it.

  • Never name Span(Of T) or any ref struct; never capture one, box one or keep one across Await; write such code in C# and expose arrays or Memory(Of T).

  • Len(value) on a structure sums field sizes without padding; Marshal.SizeOf gives the interop size.

  • Large structures (more than a few fields) lose to a class once copies dominate; measure before choosing.
