R IDEs & Tools

This content was generated with the assistance of AI and should be verified against the official documentation before being relied on in production.

This page lists the IDEs and editors commonly used for R, with a link to each product’s official page. RStudio is the long-established R-focused IDE, Positron is its newer multi-language successor, and VS Code is an alternative for those who already use it.

IDEs

  • RStudio — the Posit IDE for R, with a console, script editor, plots, environment viewer and package tools.

  • Positron — Posit’s next-generation data science IDE for R and Python, built on the VS Code foundation.

Editors with extensions

  • R extension for VS Code — adds R syntax, a console, a data viewer and language-server features to VS Code.
