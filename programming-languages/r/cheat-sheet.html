Worked example

The example builds a small data frame, filters it with subset() and with the native pipe, and summarises a column.

books <- data.frame(
  title = c("Dune", "Emma", "Ulysses"),
  pages = c(412, 474, 730)
)

long <- subset(books, pages > 450)
long$title
#> [1] "Emma"    "Ulysses"

books |> subset(pages > 450) |> nrow()
#> [1] 2

round(mean(books$pages), 1)
#> [1] 538.7

subset() evaluates pages > 450 inside the data frame, so the column name needs no books$ prefix; the pipe passes books as the first argument of each call. The output shown was worked out by hand and not run in this environment.
