Rust IDEs & Tools

This content was generated with the assistance of AI and should be verified against the official documentation before being relied on in production.

This page lists the IDEs, editors and language tooling commonly used to write and debug Rust code. Most editors get their Rust features from rust-analyzer, so the choice is largely about workflow and preference.

IDEs

  • RustRover — a Rust-specific IDE with its own analysis, refactoring, debugging and Cargo integration.

  • CLion — JetBrains' C and C++ IDE, which supports Rust through the Rust plugin; useful for mixed Rust and C/C++ projects.

Editors with extensions

  • rust-analyzer for VS Code — the rust-analyzer extension for Visual Studio Code, providing completion, inline errors and refactorings.

  • Zed — a fast, open source editor with built-in Rust support through rust-analyzer; see Rust in Zed.

Language tooling

  • rust-analyzer — the official Rust language server that powers IDE features in most editors.
