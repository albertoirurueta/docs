====
This section documents **Bootstrap 5.x as implemented by https://getbootstrap.com/[the official Bootstrap
project]**. No specific patch version is pinned. Unlike the other reference sections on this site, no single
reference book underpins it: the content was generated with the assistance of AI from general knowledge of
Bootstrap, and should be verified against the current official documentation at
https://getbootstrap.com/docs/[getbootstrap.com/docs] before relying on it in production. Notably, Bootstrap 5
dropped the jQuery dependency present in earlier major versions in favor of vanilla JavaScript, using
https://popper.js.org/[Popper.js] for the positioning of dropdowns, tooltips, and popovers -- behaviour
described here reflects that vanilla-JS baseline and may lag the release you are actually running.
