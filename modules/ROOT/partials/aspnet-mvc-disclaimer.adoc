This section documents **ASP.NET MVC 5.3.x, ASP.NET Web API 2.2, ASP.NET Web Pages 3, OWIN/Katana, SignalR 2,
and ASP.NET Identity 2 -- all running on .NET Framework 4.8.1** -- the `System.Web`-hosted MVC framework, its

as described by the official documentation at https://learn.microsoft.com/en-us/aspnet/mvc/[Microsoft Learn]

https://learn.microsoft.com/en-us/aspnet/identity/[Identity]), which are the reference these pages are written
and verified against.

functionally frozen and receives only security fixes. For the current, cross-platform MVC framework see
xref:web/aspnet/core/mvc-controllers-and-views.adoc[MVC Controllers and Views] under
