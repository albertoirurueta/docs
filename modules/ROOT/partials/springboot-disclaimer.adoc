described by https://docs.spring.io/spring-boot/reference/index.html[the official Spring Boot reference

Nine local books are listed in this section's bibliography and were consulted while preparing these pages: Dinesh
Rajput's _Mastering Spring Boot 2.0_ and _Spring 5 Design Patterns_, Greg L. Turnquist's _Learning Spring Boot

Boot 1.x/2.0 or Spring 4/5), so on any discrepancy the official documentation at
https://docs.spring.io/spring-boot/reference/index.html[docs.spring.io] and each sub-project's own site wins.
