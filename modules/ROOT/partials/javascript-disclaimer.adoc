This section documents **modern ECMAScript and core browser JavaScript APIs** -- it is not tied to any specific
framework or library (React, Vue, Angular, etc.). This content was built primarily from the book
_"JavaScript: The Definitive Guide"_ (7th ed., David Flanagan, O'Reilly), supplemented with general/official
documentation knowledge where the book did not cover a topic the way this section needs. In particular, WebGL,
Three.js, the Geolocation API, WebRTC, the Video APIs, and the developer-tooling pages (ESLint, Prettier, Jest,
Babel, npm) draw primarily on general/official documentation rather than the book, since the book gives them
little to no dedicated coverage. This content was generated with the assistance of AI and should be verified
against the current https://tc39.es/ecma262/[ECMAScript specification] and
https://developer.mozilla.org/[MDN] documentation before relying on it in production, since JavaScript language
features and browser API support continue to evolve.
