[IMPORTANT]
====
This page documents general **Cross-Origin Resource Sharing (CORS)** behavior as specified by the
https://fetch.spec.whatwg.org/[WHATWG Fetch Standard]. Unlike the other reference sections on this site, no
single reference book underpins it: the content was generated with the assistance of AI from general knowledge,
and should be verified against https://fetch.spec.whatwg.org/#http-cors-protocol[the Fetch Standard's CORS
protocol section] and https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/CORS[MDN's CORS guide] before
relying on it in production. Backend framework-specific CORS configuration (e.g. Express, Django, Spring) is out
of scope for this page and left to each framework's own documentation.
====
