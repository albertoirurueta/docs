This section documents **modern, standalone Angular** -- signals, the built-in `@if` / `@for` / `@switch`
control flow, `@defer`, typed reactive forms, `provideHttpClient`, functional guards and interceptors, and
server-side rendering with hydration -- as described by the official documentation at
https://angular.dev[angular.dev], which is the reference these pages are written and verified against.

This content was generated with the assistance of AI and should be verified against
https://angular.dev[angular.dev] before being relied on in production. Angular ships a major release roughly
every six months and its APIs continue to evolve: the examples here target the current major release, while
the book referenced below targets approximately Angular 18. Where the book and the current documentation
disagree, the documentation wins and the difference is noted.

_Learning Angular_ (Aristeidis Bampakos, 5th edition, Packt Publishing, 2024) is one of the works listed in
this section's bibliography and was consulted while preparing these pages; https://angular.dev[angular.dev]
remains the primary source throughout.
