This section documents **the current Vaadin release line** -- Vaadin 24 LTS / 25.x, Java 17+, Spring Boot 3 /
Jakarta EE 10 -- as published at https://vaadin.com/docs/latest/[the official Vaadin documentation], **which is
the reference these pages are written and verified against**. No specific patch version is pinned. **Flow
(server-side Java) is the authoring style used throughout**, with Hilla / React shown where it differs; Vaadin 7
and the pre-Flow architecture appear only as migration contrast.

This content was generated with the assistance of AI and should be verified against
https://vaadin.com/docs/latest/[the official documentation] before being relied on in production, since Vaadin
ships major releases roughly twice a year and its ecosystem iterates.

_Practical Vaadin_ (Alejandro Duarte, Apress, 2021), _Learning Vaadin 7_, 2nd ed. (Nicolas Fränkel, Packt,
2013) and _Vaadin 7 UI Design By Example_ (Alejandro Duarte, Packt, 2013) are listed in this section's
bibliography and were consulted while preparing these pages. None of them is the primary or main reference for
the section: _Practical Vaadin_ predates the current Vaadin 24/25 line, and the two 2013 books document the
obsolete Vaadin 7 API -- so on any discrepancy the official documentation at
https://vaadin.com/docs/latest/[vaadin.com/docs] wins, and the difference is noted.
