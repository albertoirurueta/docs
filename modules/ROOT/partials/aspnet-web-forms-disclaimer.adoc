This section documents **ASP.NET Web Forms on .NET Framework 4.8.1**, the last and permanent version of Web
Forms -- the page life cycle and postback model, ViewState and control state, server controls, validation
controls, master pages and themes, data-bound controls, and the provider-based security model -- as described
by the official documentation at https://learn.microsoft.com/en-us/aspnet/web-forms/[Microsoft Learn] and the
https://learn.microsoft.com/en-us/previous-versions/aspnet/[ASP.NET previous-versions archive], which are the
reference these pages are written and verified against.

**Web Forms receives security fixes only and has no forward path onto modern .NET** (.NET Framework 4.8.1 is
Microsoft's last version of .NET Framework; Web Forms itself never shipped on .NET Core/.NET 5+). It remains
supported for existing applications running on Windows but is not recommended for new development -- see
xref:web/aspnet/choosing-a-framework.adoc[Choosing an ASP.NET Framework] and
xref:web/aspnet/web-forms/migrating-to-modern-aspnet.adoc[Migrating to Modern ASP.NET] for what that means in
practice.
