up to Java 8, and _Modern Java in Action_ covers up to Java 11 -- with no coverage of records, sealed classes,
pattern matching, text blocks, `switch` expressions, `var`, virtual threads, the module system, or the modern
`HttpClient`/NIO.2, so on any discrepancy, or wherever a book is simply silent on a modern feature, the official
documentation wins.
