= Cheat Sheet (PDF)
:description: A single-page, printable A4 quick reference for building command-line and terminal (TUI) applications on Windows, macOS and Linux -- kinds of terminal program and the stack chooser, the terminal stack, escape sequences and colour environment variables, POSIX and Windows console essentials, platform differences, argument parsing per language, TUI loops and libraries, a Ratatui skeleton and tests, prompts and progress libraries, completions and services, cross-compilation, signing and packaging commands, PTY and snapshot testing and accessibility rules -- with links to every detailed page in this section.

A single A4 page that summarises the CLI section for quick memorization or as a printable desk reference. It contains:

* *Choosing* -- the kinds of terminal program and the "which stack?" table (language by startup, size, cross-compilation
  and TUI library).
* *Terminal mechanics* -- the terminal stack (emulator, PTY, line discipline), canonical versus raw mode, the key
  escape sequences (SGR colours, cursor, alternate screen, mouse, bracketed paste, synchronized output, OSC 8) and the
  `TERM`, `COLORTERM`, `NO_COLOR` and `FORCE_COLOR` policy.
* *Platforms* -- POSIX process essentials, Windows console essentials and the platform-differences table.
* *Languages* -- argument parsing per language, and prompt, line-editing and progress libraries.
* *TUIs* -- the TUI loop skeleton, the library comparison row, a Ratatui skeleton with its `TestBackend` test, and short
  skeletons for Bubble Tea, Textual, Terminal.Gui, ncurses and FTXUI.
* *Integration and shipping* -- completions per shell, service one-liners (systemd, launchd, Windows services),
  cross-compilation commands, signing and notarization commands, packaging channels, PTY and snapshot testing tools and
  the accessibility rules.

For the full explanation, every option and additional examples, see the dedicated pages. The section overview, the
reading order and the bibliography are on the xref:apps/cli/index.adoc[CLI] page.
