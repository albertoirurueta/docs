Welcome to the CLI reference. It teaches how to build *command-line and terminal applications for Windows, macOS and
Linux*: what a terminal really is, how a program talks to it through POSIX and Win32 interfaces, how to write native
command-line programs in C, C++, Swift, Objective-C, .NET, Go, Rust and on the JVM and Kotlin, how to build
full-screen *terminal user interfaces (TUIs)* with Ratatui (in depth), Bubble Tea, Textual, Terminal.Gui, ncurses,
FTXUI and other libraries, how to handle prompts, progress output, shells, completions and services, and how to ship
the result as signed native binaries and packages. Each of the 33 concept pages explains one idea in detail, with
tables of every option, platform differences, pitfalls, examples and a link to the official page each example derives
from. The printable xref:apps/cli/cheat-sheet.adoc[Cheat Sheet (PDF)] summarises every concept on one A4 page.

== The shelf scenario

Every example belongs to one tool, *shelf*, a command-line client for the Bookshelf domain used in other sections of
this site. It grows with the section:

* `shelf list`, `shelf add`, `shelf loan` and `shelf return` are one-shot subcommands, written in each language.
* `shelf repl` is an interactive prompt with history and completion.
* `shelf tui` is a full-screen catalogue browser with a list of books, a details pane, a loans table and a search box.
  It is implemented with Ratatui in depth and, more briefly, with Bubble Tea, Textual, Terminal.Gui, ncurses and FTXUI,
  so the libraries can be compared on the same screen.
* `shelfd` is a background service with a local IPC socket, used by the services page.

The scenario is original and not copied from any tutorial.
