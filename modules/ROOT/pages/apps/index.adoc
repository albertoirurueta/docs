= Apps
:description: Landing page for the Apps reference section, linking to the Android guide and its Kotlin Reference documentation, and to the React Native cross-platform guide.
:keywords: apps, application development, Android, Kotlin, Kotlin 2.4, React Native, React Native 0.87, Expo, cross-platform mobile, iOS, Hermes, Fabric, Turbo Native Modules, React Navigation, apps reference

A growing collection of application-development references -- practical, example-driven documentation for
building apps on specific platforms -- natively on Android, and cross-platform on Android and iOS with React
Native.

== Sections

* xref:apps/android/index.adoc[Android] -- the Android platform, starting with the Kotlin language itself:
  language fundamentals, null safety, coroutines and flows, and Kotlin on Android, plus a downloadable cheat
  sheet.
* xref:apps/react-native/index.adoc[React Native] -- building Android and iOS apps from one TypeScript codebase
  with React: the core components, styling and Flexbox layout, navigation, state and networking, storage,
  offline and security, debugging, testing and performance, native modules, and shipping to the stores, plus a
  downloadable cheat sheet.
