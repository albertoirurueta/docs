= Apps
:description: Landing page for the Apps reference section, linking to the Android guide and its Kotlin Reference documentation, to the Kotlin Multiplatform guide for sharing Kotlin code and Compose Multiplatform UI across Android, iOS, desktop and the web, to the Apple Platforms guide for native iOS, iPadOS, macOS, watchOS and visionOS apps, and to the React Native cross-platform guide, and the Media Optimization guide for image and video loading, caching and uploads in native and cross-platform apps.

A growing collection of application-development references -- practical, example-driven documentation for
building apps on specific platforms -- natively on Android and on Apple platforms (iOS, iPadOS, macOS, watchOS
and visionOS), and cross-platform on Android and iOS with Kotlin Multiplatform and React Native.

== Sections

* xref:apps/android/index.adoc[Android] -- native Android development end to end, starting with the Kotlin
  language itself: project setup and Gradle, the classic View/Fragment UI toolkit, Jetpack Compose, recommended
  app architecture and the migration path from Views to Compose, data and networking (Room, DataStore, Retrofit,
  Ktor, Coil/Glide, Hilt), system integration (background work, notifications, permissions, camera/location/
  sensors), testing and debugging, and building, signing and publishing to Google Play and Maven Central, plus a
  downloadable cheat sheet.
* xref:apps/kotlin-multiplatform/index.adoc[Kotlin Multiplatform] -- sharing Kotlin code between Android, iOS, desktop and the web with Kotlin 2.4 and Compose
  Multiplatform: project structure and source sets, the AGP 9 Android plugin, `expect`/`actual`, coroutines and
  shared view models, Ktor, SQLDelight, Room 3 and Koin, integrating with Swift and SwiftUI, sharing the UI with
  Compose Multiplatform on every platform, testing, publishing libraries and apps, CI, and adopting KMP in
  existing apps, plus a book cross-check and a downloadable cheat sheet.
* xref:apps/apple/index.adoc[Apple Platforms (iOS, iPadOS, macOS, watchOS, visionOS)] -- building native apps
  for every Apple device with Swift, SwiftUI and Xcode: projects and tooling, SwiftUI and design, data and
  system integration, platform-specific features, testing and performance, and shipping to the App Store, plus
  downloadable cheat sheets.
* xref:apps/react-native/index.adoc[React Native] -- building Android and iOS apps from one TypeScript codebase
  with React: the core components, styling and Flexbox layout, navigation, state and networking, storage,
  offline and security, debugging, testing and performance, native modules, and shipping to the stores, plus a
  downloadable cheat sheet.
* xref:apps/media-optimization/index.adoc[Media Optimization] -- images and video in apps: Coil, Glide and Media3 on
  Android, Kingfisher, Nuke and AVFoundation on iOS, `expo-image` and react-native-video, Kotlin Multiplatform and
  Flutter, BlurHash placeholders, and device-side compression and background uploads, plus a downloadable cheat sheet.
