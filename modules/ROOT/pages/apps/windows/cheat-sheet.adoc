A single A4 page that summarises the Windows Apps section for quick memorization or as a printable desk reference. It
contains:

* *Stacks and versions* -- the stack chooser, the version baseline (.NET 10 LTS, C# 14, Visual Studio 2026, Windows App
  SDK 2.5.1, CommunityToolkit.Mvvm 8.4.2), the `dotnet new` templates and the `.csproj` essentials.
* *XAML* -- the `x:` directives, markup extensions, `clr-namespace:` mapping, resource lookup and `StaticResource`
  versus `DynamicResource`.
* *WPF* -- panels and layout rules, a dependency property and attached property snippet with value precedence, routed
  events and command types, the anatomy of a `Binding` (modes, `UpdateSourceTrigger`, `RelativeSource`, `ElementName`),
  converters, collection views and templates, validation, styles, templates and triggers, the Fluent `ThemeMode`, and
  the Dispatcher and async rules.
* *MVVM* -- the layers diagram, the toolkit snippet (partial-property `[ObservableProperty]`, `[RelayCommand]`, the
  messenger) and the Generic Host startup snippet.
* *Other stacks* -- the WinUI 3 deltas (`x:Bind`, `NavigationView`, `AppWindow`) and the Windows Forms deltas (dark
  mode, async APIs), one line each.
* *Shipping* -- the publish matrix (framework-dependent, self-contained, single-file, ReadyToRun, trimming and Native
  AOT per stack), MSIX and signing essentials, the distribution-channel table, the `dotnet publish` and `wingetcreate`
  commands, the CI/CD steps and the .NET Framework migration checklist.

reading order and the bibliography are on the xref:apps/windows/index.adoc[Windows Apps] page.
