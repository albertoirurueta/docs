This page lists the IDEs and tools most commonly used to build native apps for Apple platforms, with a link to each product's official page. Xcode is required to build, sign and submit apps, so other editors are used alongside it rather than instead of it.

== IDEs

[cols="1,1,1",frame=none,grid=none]
|===
a|
image::ide-xcode.svg["Xcode",link="https://developer.apple.com/xcode/"]

a|

a|

|===

* https://developer.apple.com/xcode/[*Xcode*] -- Apple's IDE for iOS, iPadOS, macOS, watchOS, tvOS and visionOS, with the interface editor, SwiftUI previews, the debugger and the SDKs.

|===

* https://developer.apple.com/documentation/xcode/running-your-app-on-simulated-or-physical-devices[*Simulator*] -- runs simulated Apple devices on a Mac for testing apps without physical hardware.
* https://help.apple.com/instruments/mac/current/[*Instruments*] -- Apple's profiling tool for time, memory, energy and network analysis.
* https://developer.apple.com/xcode-cloud/[*Xcode Cloud*] -- Apple's continuous integration and delivery service, built into Xcode and App Store Connect.
* https://developer.apple.com/testflight/[*TestFlight*] -- distributes beta builds to internal and external testers.

== Discontinued products

* *AppCode* -- JetBrains' IDE for Swift and Objective-C, now discontinued; Xcode is the recommended replacement.
