= Hybrid Apps: IDEs & Tools
:description: The editors, native toolchains, emulators and framework tools commonly used for hybrid and cross-platform app development with React Native and Ionic, with links to each product's official page.
:keywords: React Native, Ionic, Capacitor, Expo, IDE, editor, tools, VS Code, WebStorm, Android Studio, Xcode, emulator, simulator

include::partial$ai-disclaimer.adoc[]

This page lists the editors and tools most commonly used to build React Native and Ionic apps, with a link to each product's official page. Hybrid projects are written in an editor of choice, but running on a device or emulator still needs the native toolchains: Android Studio for Android and Xcode for iOS. This site has a dedicated section for React Native; Ionic has no dedicated section on this site yet.

== Native toolchains

[cols="1,1,1",frame=none,grid=none]
|===
a|
image::ide-android-studio.svg["Android Studio",link="https://developer.android.com/studio"]

a|
image::ide-xcode.svg["Xcode",link="https://developer.apple.com/xcode/"]

a|
image::ide-android-emulator.svg["Android Emulator",link="https://developer.android.com/studio/run/emulator"]

a|
image::ide-react-native-setup.svg["React Native environment setup",link="https://reactnative.dev/docs/set-up-your-environment"]

a|

a|

|===

* https://developer.android.com/studio[*Android Studio*] -- provides the Android SDK, emulator and build tools needed to run hybrid apps on Android.
* https://developer.apple.com/xcode/[*Xcode*] -- provides the iOS SDK, Simulator and signing tools needed to run hybrid apps on Apple devices; it requires a Mac.
* https://developer.android.com/studio/run/emulator[*Android Emulator*] -- runs virtual Android devices for testing.
* https://reactnative.dev/docs/set-up-your-environment[*React Native environment setup*] -- the official guide to installing the native toolchains and simulators for React Native.

== React Native and Expo tooling

[cols="1,1,1",frame=none,grid=none]
|===
a|
image::ide-expo.svg["Expo",link="https://docs.expo.dev/"]

a|

a|

|===

* https://docs.expo.dev/[*Expo*] -- the framework and toolchain recommended for new React Native projects.
* https://expo.dev/go[*Expo Go*] -- a sandbox app for running Expo projects on a physical device without a native build.
* https://docs.expo.dev/develop/development-builds/introduction/[*Expo Dev Client*] -- a custom development build that includes your own native code.
