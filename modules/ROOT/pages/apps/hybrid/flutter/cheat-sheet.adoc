== CLI Commands

[cols="2,3",options="header"]
|===
| Command | Purpose

| `flutter doctor`
| Check the toolchain and report missing pieces.

| `flutter create trailhead`
| Create a new project.

| `flutter pub add dio`
| Add a dependency (use `dev:` prefix for dev dependencies).

| `flutter pub get`
| Fetch dependencies listed in `pubspec.yaml`.

| `flutter run -d <device-id>`
| Run on a device; press `r` for hot reload and `R` for hot restart.

| `flutter devices`
| List connected devices and emulators.

| `flutter analyze`
| Static analysis.

| `dart format .`
| Format all Dart files.

| `dart run build_runner build`
| Run code generators (json_serializable, drift).
|===

== Dart Syntax

[cols="2,3",options="header"]
|===
| Concept | Example

| Variables
| +final name = 'Ridge'; var count = 0; const pi = 3.14;+

| Null safety
| +String? note; note?.length; note ?? 'none'; note!+

| Functions
| +int add(int a, int b) => a + b;+

| Named parameters
| +void log({required String id, int level = 0}) {}+

| Collections
| +[1, 2]; {'a': 1}; {1, 2}+

| Collection if and for
| +[for (final t in trails) t.name, if (admin) 'all']+

| String interpolation
| +'${trail.name}: $count'+

| Classes
| +class Trail { const Trail(this.id); final String id; }+

| Async
| +Future<int> f() async { return await g(); }+

| Sealed and switch
| +switch (r) { Success(:final value) => value, Failure() => null }+

| Records
| +(String, int) pair = ('a', 1);+
|===

== Layout

[cols="1,3",options="header"]
|===
| Widget | Behaviour

| `Row`, `Column`
| Lay children along an axis; use `mainAxisAlignment` and `crossAxisAlignment`.

| `Expanded`, `Flexible`
| Share the remaining space inside a `Row` or `Column`.

| `Stack`, `Positioned`
| Overlay children.

| `Padding`, `SizedBox`, `Center`, `Align`
| Spacing and alignment.

| `Container`, `DecoratedBox`
| Size, colour, border and shadow.

| `SingleChildScrollView`, `SafeArea`
| Scroll one child; avoid notches and system bars.
|===

Constraints go down, sizes go up, parents set positions.

== Routing with go_router

[cols="2,3",options="header"]
|===
| Call | Meaning

| +context.go('/trails/42')+
| Navigate to a location, replacing the stack.

| +context.push('/log')+
| Push on the stack.

| `context.pop()`
| Go back.

| `state.pathParameters`, `state.uri.queryParameters`
| Read path and query values inside a route builder.

| `redirect`
| Guard that returns a new location or `null`.

| `StatefulShellRoute.indexedStack`
| Bottom tabs that each keep their own stack.
|===

== Build and Release

[cols="2,3",options="header"]
|===
| Command | Purpose

| `flutter build apk --release`
| Release APK.

| `flutter build appbundle --release`
| Android App Bundle for Google Play.

| `flutter build ipa --release`
| iOS archive for App Store Connect.

| `--dart-define=KEY=value`, `--dart-define-from-file=file.json`
| Compile-time configuration.

| `--obfuscate --split-debug-info=build/symbols`
| Obfuscate Dart code and keep symbols.

| `--analyze-size`
| Produce a size analysis.

| `version: 1.4.0+27`
| Version name and build number in `pubspec.yaml`.
