https://flutter.dev/[Flutter] is Google's UI toolkit for building Android, iOS, web and desktop apps from a single
Dart codebase. Unlike a WebView hybrid framework or a framework that drives native views, Flutter draws every pixel
itself with its own renderer, so an app looks and behaves the same on every platform and OS version. This
subsection is a reference for developers who know another stack, such as Kotlin, Swift, Java or TypeScript, and want
to build a production Flutter app: it covers the Dart language first, then the framework, then the engineering
topics around it (testing, platform code, release).

== Running example

Every page builds *Trailhead*, a hiking journal: a searchable trail list loaded from a REST API
(`+https://api.example.com/v1+`), a trail detail screen, favourites, a "log a hike" flow that attaches a camera photo
and a GPS position, and an offline cache of the trails. The state layer uses Riverpod and routing uses go_router. The
same app is built with Ionic and Capacitor in xref:apps/hybrid/ionic/index.adoc[Ionic and Capacitor], so the two
approaches can be compared on one problem.
