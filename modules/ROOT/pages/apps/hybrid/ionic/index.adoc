= Ionic and Capacitor
:description: Landing page for the Ionic and Capacitor reference under Hybrid Apps -- getting started, the native bridge, Ionic components and theming, navigation, Capacitor plugins, data and networking, platform integration, testing, building and releasing, a cheat sheet, and the Trailhead running example in Angular.
:keywords: Ionic, Ionic 9, Capacitor, Capacitor 8, Angular, WebView, hybrid app, Capacitor plugins, native bridge, Ionic CLI, cap sync, Playwright, Trailhead

include::partial$ai-disclaimer.adoc[]

https://ionicframework.com/[Ionic Framework] is a UI component library for mobile-first web apps, and
https://capacitorjs.com/[Capacitor] is the native runtime that wraps a web app in an Android or iOS project and
exposes device features through plugins. Together they let a web team ship a store app from a normal Angular, React
or Vue codebase: the UI runs in the platform WebView and calls native code over a bridge. This subsection is a
reference for web developers moving to mobile and for mobile developers evaluating the approach. The examples use
Angular with standalone components and signals.

Capacitor 8 requires Node.js 22 or later, Xcode 26.0 or later and Android Studio Otter (2025.2.1) or later. It
targets iOS 15.0 and later, and Android with minSdk 24 and compileSdk and targetSdk 36. New iOS projects use Swift
Package Manager by default. On any discrepancy the current official documentation is the authority.

== Running example

Every page builds *Trailhead*, a hiking journal: a searchable trail list loaded from a REST API
(`+https://api.example.com/v1+`), a trail detail page, favourites, a "log a hike" flow that attaches a camera photo
and a GPS position, and an offline cache of the trails. The app id is `+com.example.trailhead+`. The same app is
built with Flutter in xref:apps/hybrid/flutter/index.adoc[Flutter and Dart].
