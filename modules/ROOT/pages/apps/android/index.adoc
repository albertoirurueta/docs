= Android
:description: Landing page for the Android guide, starting with the Kotlin Reference documentation.
:keywords: Android, Kotlin, Kotlin 2.4, Jetpack, Android development

A growing collection of Android-development references, starting with the language Google has recommended as
Android's preferred choice since 2019: Kotlin.

To build for Android and iOS from a single TypeScript codebase instead of natively per platform, see
xref:apps/react-native/index.adoc[React Native], the cross-platform alternative documented alongside this
guide. For the native counterpart on Apple devices, see xref:apps/apple/index.adoc[Apple Platforms], which covers
iOS, iPadOS, macOS, watchOS and visionOS apps built with Swift and SwiftUI.

== Sections

  fundamentals, object-oriented and functional programming, the type system and null safety, collections,
  coroutines and flows, and Kotlin on Android, plus a downloadable cheat sheet.
