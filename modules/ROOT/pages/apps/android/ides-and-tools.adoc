This page lists the IDEs and tools most commonly used to build native Android apps, with a link to each product's official page. Android Studio is the default choice because it bundles the SDK manager, emulator and profilers; the command-line tools suit CI and editor-based workflows.

== IDEs

* https://developer.android.com/studio[*Android Studio*] -- Google's official IDE for Android, built on the IntelliJ platform, with the layout and Compose tooling, the SDK manager, the emulator and the profilers built in.
* https://www.jetbrains.com/idea/[*IntelliJ IDEA*] -- JetBrains' IDE, which supports Kotlin and Android projects through its Android plugin and is the base of Android Studio.

== Devices and emulators

* https://developer.android.com/studio/run/emulator[*Android Emulator*] -- runs virtual Android devices of many form factors and API levels for testing without physical hardware.

== Command-line tools

* https://developer.android.com/tools[*Android SDK command-line tools*] -- `sdkmanager`, `avdmanager` and the other SDK tools for installing platforms, creating virtual devices and building without the IDE, for example in CI.
