accessibility), the recommended app architecture and the Views-to-Compose migration path, the data and
networking libraries (DataStore, Room, Retrofit/OkHttp/Ktor, Coil/Glide, Hilt/Koin), system integration
(background work, notifications, permissions, device features, graphics), quality (unit and instrumented
