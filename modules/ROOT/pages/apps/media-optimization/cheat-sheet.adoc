xref:apps/media-optimization/index.adoc[sub-section index].

The xref:attachment$media-optimization-apps-cheat-sheet.pdf[downloadable PDF] is a separate, single A4 page meant for printing.
It states the baseline date (2026-10-07) and covers:

* choosing a variant by pixel size and platform format support (WebP, AVIF, HEIC);
* Android: Coil 3 cache configuration and the network artifact, Glide cache strategies, BlurHash placeholders and Media3
  (ExoPlayer, `SimpleCache`, Transformer);
* iOS: the limits of `AsyncImage`, Kingfisher, Nuke and SDWebImage, plus AVFoundation for HLS, cover frames, export and
  background uploads;
* React Native and Expo: `expo-image` props, react-native-blurhash, react-native-fast-image status and react-native-video;
* Kotlin Multiplatform and Flutter equivalents; and
* compression on the device and upload practice (background, resumable, retries).
