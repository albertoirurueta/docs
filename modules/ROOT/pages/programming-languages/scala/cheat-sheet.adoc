= Scala Cheat Sheet
:description: A single-page, colour-coded summary of the Scala 3 language and tools covered by this reference -- running code, basics, control flow and pattern matching, data modelling, functions, the type system, contextual abstractions, collections, errors and concurrency, metaprogramming, tooling, the Scala Toolkit and a Scala 2 to Scala 3 strip.
:keywords: scala cheat sheet, quick reference, printable scala reference, scala 3.10, scala 3 syntax, given, using, extension, enum, case class, match, for comprehension, opaque type, union type, match types, inline, scala cli, sbt, munit, os-lib, upickle, sttp, cask, scala 2 to scala 3

include::partial$scala-disclaimer.adoc[]

A single-page, colour-coded summary of the Scala language, written against Scala 3.10 (3.10.0, announced on 12 October
2026; JDK 17 or newer, with the differences on the 3.9 LTS line named where they matter) and checked on 2026-10-16, with
additions after Scala 3.3 labelled by release -- running code with Scala CLI and sbt, basics and literals, string
interpolation, methods and their parameter kinds, optional braces and `end` markers, control flow and pattern matching,
tuples, classes, objects, traits, case classes, enums and the modifiers `sealed`, `open` and `final`, functions and currying,
the type system (bounds, variance, union and intersection types, opaque types, type lambdas and match types), givens,
`using` clauses, context bounds, extension methods, type classes and `derives`, the collection operations used most,
`Option`, `Either`, `Try` and `Future`, `inline` and macros, compiler flags, the Scala Toolkit libraries (MUnit, OS-Lib,
uPickle, sttp and Cask), and a strip of Scala 2 forms and their Scala 3 replacements -- handy for quick memorization or as a
xref:attachment$scala-cheat-sheet.pdf[downloadable PDF] desk reference.
