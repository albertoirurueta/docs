This page lists the IDEs, editors and command-line tools commonly used for Scala, with a link to each product's official page. Choose IntelliJ IDEA with the Scala plugin for a full IDE, or an editor backed by the Metals language server for a lighter setup.

== IDEs

* https://www.jetbrains.com/idea/[*IntelliJ IDEA*] -- the JetBrains IDE, the usual host for the Scala plugin.
* https://plugins.jetbrains.com/plugin/1347-scala[*IntelliJ Scala plugin*] -- adds Scala support to IntelliJ IDEA, including sbt import, worksheets, debugging and refactoring.

== Editors with extensions

* https://scalameta.org/metals/[*Metals*] -- the Scala language server, which brings completion, navigation, diagnostics and a debugger to VS Code, Neovim, Sublime Text, Zed and other editors.
* https://code.visualstudio.com/[*Visual Studio Code*] -- a general-purpose editor, the most common client for Metals.

== Command-line tools

* https://scala-cli.virtuslab.org/[*Scala CLI*] -- a command-line tool to compile, run, test and package Scala code without a build file.
