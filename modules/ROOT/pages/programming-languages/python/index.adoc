Welcome to the Python reference. https://www.python.org/[Python] is a *high-level, dynamically-typed,
multi-paradigm language* -- it supports procedural, object-oriented, and functional styles, is interpreted
(compiled to bytecode and run on the Python Virtual Machine), and favours readable, indentation-based syntax
over explicit braces. This section documents the current Python release line, framework-agnostic, written and
verified against https://docs.python.org/3/[the official Python documentation].

If you are new to Python, read xref:programming-languages/python/getting-started.adoc[Getting Started with Python] first, then
xref:programming-languages/python/lexical-structure-and-style.adoc[Lexical Structure and Style] and
xref:programming-languages/python/variables-and-dynamic-typing.adoc[Variables and Dynamic Typing], followed by
xref:programming-languages/python/control-flow.adoc[Control Flow] -- from there the core-language pages build on each other
through functions, iteration, modules, files, and exceptions, and the later pages cover object-oriented Python,
modern standard-library features, and testing.

Where Python is used on this site: xref:backend/fastapi/index.adoc[Python FastAPI] builds HTTP APIs on top of
this language reference, and the GraphQL section's xref:backend/graphql/python-getting-started.adoc[Python pages]
serve GraphQL from Python, and xref:web/django/index.adoc[Django] (in Web Development) builds full web
applications and APIs with the batteries-included Python web framework. The Backend Development section also covers
xref:backend/flask/index.adoc[Python Flask] (the WSGI micro-framework), xref:backend/tornado/index.adoc[Python Tornado]
(asynchronous networking and non-blocking web servers) and xref:backend/pyramid/index.adoc[Python Pyramid]
(configurable WSGI applications with URL dispatch and traversal).

=== Core language

* xref:programming-languages/python/lexical-structure-and-style.adoc[Lexical Structure and Style] -- indentation-based blocks,
  comments and statement separators, PEP 8 naming and style, and the Zen of Python.
* xref:programming-languages/python/variables-and-dynamic-typing.adoc[Variables and Dynamic Typing] -- names bound to objects,
  mutability, shared references and `is` vs. `==`, and the built-in type hierarchy.
* xref:programming-languages/python/numbers.adoc[Numbers] -- `int`/`float`/`complex`, numeric operators, `decimal`/`fractions`
  for exact arithmetic, and the built-in numeric tools.
* xref:programming-languages/python/strings-and-text.adoc[Strings and Text] -- string literals and slicing, common string
  methods, f-strings and other formatting, and `str` vs. `bytes`.
* xref:programming-languages/python/collections.adoc[Collections] -- lists, tuples, sets, and dictionaries, their comprehensions,
  and when to choose each.
* xref:programming-languages/python/control-flow.adoc[Control Flow] -- `if`/`elif`/`else` and truthiness, `while`/`for` loops,
  and the `match` statement.
* xref:programming-languages/python/functions.adoc[Functions] -- parameters and return values, `*args`/`**kwargs` and
  positional-/keyword-only markers, the LEGB scope rule, and `lambda`.
* xref:programming-languages/python/iterators-generators-comprehensions.adoc[Iterators, Generators and Comprehensions] -- the
  iterator protocol, generator functions and expressions, and comprehensions revisited as sugar over iteration.
* xref:programming-languages/python/modules-and-packages.adoc[Modules and Packages] -- `import` forms, the
  `__name__ == "__main__"` pattern, packages, and the module search path.
* xref:programming-languages/python/files-and-context-managers.adoc[Files and Context Managers] -- `open()` and the `with`
  statement, and `pathlib.Path` as the modern alternative to `os.path`.
* xref:programming-languages/python/exceptions.adoc[Exceptions] -- `try`/`except`/`else`/`finally`, exception chaining, custom
  exception hierarchies, and exception groups.

=== Object-oriented programming

* xref:programming-languages/python/classes-and-objects.adoc[Classes and Objects] -- `class` basics, instance vs. class
  attributes, `@staticmethod`/`@classmethod`, and inheritance with `super()`.
* xref:programming-languages/python/operator-overloading.adoc[Operator Overloading] -- the common dunder methods for display,
  comparison, container behaviour, calling, context management, and arithmetic.
* xref:programming-languages/python/advanced-oop-design.adoc[Advanced OOP Design] -- composition vs. inheritance, mixins and
  multiple inheritance, the Method Resolution Order, and delegation.
* xref:programming-languages/python/managed-attributes.adoc[Managed Attributes] -- `@property`, the descriptor protocol, and
  `__getattr__` vs. `__getattribute__`.
* xref:programming-languages/python/decorators-and-metaclasses.adoc[Decorators and Metaclasses] -- function decorators,
  decorator factories and stacking, and a brief, cautious look at metaclasses.
