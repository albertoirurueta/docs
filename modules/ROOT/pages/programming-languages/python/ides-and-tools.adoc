This page lists the IDEs, editors and interactive tools commonly used to write, run and debug Python code. Choose a full IDE for large projects and refactoring, an editor with extensions for a lighter setup, or a notebook tool for exploratory and data work.

== IDEs

* https://www.jetbrains.com/pycharm/[*PyCharm*] -- a Python-specific IDE with refactoring, debugging, testing and virtual-environment support built in.
* https://www.spyder-ide.org/[*Spyder*] -- a scientific IDE with a variable explorer and an interactive console, aimed at data analysis.
* https://thonny.org/[*Thonny*] -- a small, beginner-friendly IDE with a simple debugger.

== Editors with extensions

* https://marketplace.visualstudio.com/items?itemName=ms-python.python[*VS Code Python extension*] -- adds IntelliSense, linting, debugging and environment selection to Visual Studio Code.

== Online and notebook tools

* https://jupyter.org/[*JupyterLab*] -- a web-based environment for notebooks, code and data, widely used for exploration and teaching.
