Python ships "batteries included": the modules on this page cover filesystem access, structured data, text
patterns, math, and command-line tooling without installing anything. The tutorial's
https://docs.python.org/3/tutorial/stdlib.html[Brief Tour of the Standard Library] and
https://docs.python.org/3/tutorial/stdlib2.html[Brief Tour, Part II] introduce many of these modules in
context; the full, authoritative catalogue of every module is
https://docs.python.org/3/library/index.html[the Python Standard Library reference].

== Filesystem and OS

=== `os` and `sys`

`os` exposes the operating system's process and filesystem interface; `sys` exposes interpreter state,
including the command-line arguments and the process exit code:

[source,python]
----
import os
import sys

print(os.getcwd())                      # current working directory
print(os.environ.get("HOME", ""))       # environment variable, with a default

if len(sys.argv) < 2:
    print("usage: script.py <name>", file=sys.stderr)
    sys.exit(1)                          # nonzero exit code signals failure to the calling shell

name = sys.argv[1]                       # sys.argv[0] is the script name itself
print(f"hello, {name}")
sys.exit(0)                              # 0 signals success
----

Full references: https://docs.python.org/3/library/os.html[the `os` module] and
https://docs.python.org/3/library/sys.html[the `sys` module].

=== `pathlib`

`pathlib.Path` is the modern, object-oriented alternative to building paths from `os.path` strings. Opening,
reading, writing, and joining paths with `Path` -- plus the `+__enter__+`/`+__exit__+` protocol behind `with` --
are covered in depth on xref:programming-languages/python/files-and-context-managers.adoc[]; this page only adds the piece that
belongs alongside `glob` below, directory-tree pattern matching:

[source,python]
----
from pathlib import Path

for csv_path in Path("data").glob("*.csv"):        # non-recursive, like glob.glob()
    print(csv_path)

for csv_path in Path("data").rglob("*.csv"):        # recursive, like glob.glob(..., recursive=True)
    print(csv_path)
----

Reference: https://docs.python.org/3/library/pathlib.html[the `pathlib` module].

=== `glob`

`glob` matches filesystem paths against shell-style wildcards (`+*+`, `?`, `+[...]+`) and predates `pathlib`:

[source,python]
----
import glob

for path in glob.glob("data/*.csv"):
    print(path)

for path in glob.glob("data/**/*.csv", recursive=True):   # ** descends into subdirectories
    print(path)
----

Reference: https://docs.python.org/3/library/glob.html[the `glob` module].

=== `shutil`

`shutil` provides the higher-level file operations `os` does not: copying, moving, and recursively deleting
whole trees:

[source,python]
----
import shutil

shutil.copy("notes.txt", "backup/notes.txt")   # copy one file (metadata included with copy2)
shutil.copytree("data", "data_backup")          # recursively copy a directory tree
shutil.rmtree("data_backup")                    # recursively delete a directory tree
----

Reference: https://docs.python.org/3/library/shutil.html[the `shutil` module].

== Data: Dates, JSON, Patterns, and Collections

=== `datetime`

[source,python]
----
from datetime import datetime, timedelta

now = datetime.now()
tomorrow = now + timedelta(days=1)
print(now.strftime("%Y-%m-%d"))              # formatted string, e.g. '2026-09-05'

parsed = datetime.strptime("2026-01-15", "%Y-%m-%d")   # parse a string back into a datetime
print(parsed.year, parsed.month, parsed.day)
----

Reference: https://docs.python.org/3/library/datetime.html[the `datetime` module].

=== `json`

`json.dumps()` serializes Python objects (dicts, lists, strings, numbers, booleans, `None`) to a JSON string;
`json.loads()` parses one back:

[source,python]
----
import json

data = {"name": "Ada", "languages": ["python", "ocaml"]}
text = json.dumps(data, indent=2)   # dict -> JSON string
print(text)

restored = json.loads(text)         # JSON string -> dict
assert restored == data
----

Reference: https://docs.python.org/3/library/json.html[the `json` module].

=== `re`

`re` implements Perl-style regular expressions: `search()` finds the first match anywhere in the string,
`findall()` returns every match, and `sub()` replaces matches. Quantifiers such as `+{3}+` (exactly three
repeats) or `+{2,4}+` (two to four) and groups written with `+(...)+` are the essentials for most patterns:

[source,python]
----
import re

text = "Call 555-1234 or 555-5678"
pattern = r"\d{3}-\d{4}"

print(re.findall(pattern, text))            # ['555-1234', '555-5678']

match = re.search(r"(\d{3})-(\d{4})", text)
if match:
    print(match.group(1), match.group(2))   # '555' '1234'

print(re.sub(pattern, "REDACTED", text))    # 'Call REDACTED or REDACTED'
----

Reference: https://docs.python.org/3/library/re.html[the `re` module].

=== `collections`

Beyond the built-in `list`/`dict`/`set`/`tuple` covered on xref:programming-languages/python/collections.adoc[], the
`collections` module adds specialized container types. `Counter` tallies items, `defaultdict` supplies a
default value instead of raising `KeyError` on a missing key, and `namedtuple` gives tuple elements names:

[source,python]
----
from collections import Counter, defaultdict, namedtuple

words = ["a", "b", "a", "c", "b", "a"]

counts = Counter(words)
print(counts)                     # Counter({'a': 3, 'b': 2, 'c': 1})
print(counts.most_common(1))      # [('a', 3)]

groups = defaultdict(list)
for word in words:
    groups[word[0]].append(word)  # no KeyError the first time a key is seen
print(dict(groups))

Point = namedtuple("Point", ["x", "y"])
p = Point(1, 2)
print(p.x, p.y)                   # 1 2 -- plus regular tuple behavior: p[0], unpacking, etc.
----

Reference: https://docs.python.org/3/library/collections.html[the `collections` module].

=== `itertools`

`itertools` builds lazy iterators for combinatorics and infinite/composite sequences -- see
xref:programming-languages/python/iterators-generators-comprehensions.adoc[] for the iterator protocol these are built on:

[source,python]
----
import itertools

for a, b in itertools.product([1, 2], ["x", "y"]):
    print(a, b)                                            # (1,x) (1,y) (2,x) (2,y)

print(list(itertools.chain([1, 2], [3, 4])))               # [1, 2, 3, 4]
print(list(itertools.islice(itertools.count(10), 3)))      # [10, 11, 12] -- lazy infinite counter, sliced
----

Reference: https://docs.python.org/3/library/itertools.html[the `itertools` module].

=== `functools`

`reduce()` folds an iterable down to a single value, `lru_cache` memoizes a function's results, and
`partial()` freezes some of a function's arguments ahead of time:

[source,python]
----
from functools import reduce, lru_cache, partial

total = reduce(lambda acc, x: acc + x, [1, 2, 3, 4], 0)   # 10 (sum() is clearer for this specific case)

@lru_cache(maxsize=None)
def fib(n):
    return n if n < 2 else fib(n - 1) + fib(n - 2)

print(fib(30))                      # cached: repeat calls with the same n cost O(1) after the first

add_ten = partial(lambda x, y: x + y, 10)   # first argument frozen to 10
print(add_ten(5))                   # 15
----

Reference: https://docs.python.org/3/library/functools.html[the `functools` module].

== Math and Random

=== `math`

[source,python]
----
import math

print(math.sqrt(2))                      # 1.4142135623730951
print(math.floor(3.7), math.ceil(3.2))   # 3 4
print(math.gcd(12, 18))                  # 6
print(math.pi)                           # 3.141592653589793
----

Reference: https://docs.python.org/3/library/math.html[the `math` module].

=== `random`

[source,python]
----
import random

random.seed(42)                         # fixes the sequence -- useful for reproducible tests
print(random.randint(1, 6))             # random int in [1, 6], both ends inclusive
print(random.choice(["a", "b", "c"]))   # one random element

sample = list(range(10))
random.shuffle(sample)                  # shuffles in place, returns None
print(random.sample(range(100), 5))     # 5 unique values, no repeats
----

Reference: https://docs.python.org/3/library/random.html[the `random` module].

=== `statistics`

[source,python]

import statistics

data = [2, 4, 4, 4, 5, 5, 7, 9]
print(statistics.mean(data))      # 5
print(statistics.median(data))    # 4.5
print(statistics.stdev(data))     # sample standard deviation
----

Reference: https://docs.python.org/3/library/statistics.html[the `statistics` module].

== CLI and Observability

=== `argparse`

`argparse` replaces hand-parsing `sys.argv`: declare positional and optional arguments once, and it builds
the parsing, type conversion, defaults, and `--help` text for free:

[source,python]
----
import argparse

parser = argparse.ArgumentParser(description="Greet someone")
parser.add_argument("name")                            # positional, required
parser.add_argument("--shout", action="store_true")     # optional boolean flag
parser.add_argument("--times", type=int, default=1)      # optional value, converted to int

args = parser.parse_args()          # reads sys.argv by default

greeting = f"hello, {args.name}"
if args.shout:
    greeting = greeting.upper()
for _ in range(args.times):
    print(greeting)
----

A script built this way is typically installed and run as a console-script entry point inside its own
virtual environment -- see xref:programming-languages/python/virtual-environments-and-packaging.adoc[] for packaging a CLI tool
so it can be installed and invoked by name.

Reference: https://docs.python.org/3/library/argparse.html[the `argparse` module].

=== `logging`

`logging` is the leveled, configurable alternative to scattering and later deleting `print()` calls. Levels
run `DEBUG < INFO < WARNING < ERROR < CRITICAL`; only messages at or above the configured level are emitted:

[source,python]
----
import logging

logging.basicConfig(level=logging.INFO, format="%(asctime)s %(levelname)s %(message)s")
logger = logging.getLogger(__name__)

logger.debug("won't show at INFO level")
logger.info("starting job")
logger.warning("disk space low")
try:
    1 / 0
except ZeroDivisionError:
    logger.error("division failed", exc_info=True)   # exc_info=True attaches the traceback
----

Because the level is set in one place (`basicConfig`, or a config file), a whole codebase's verbosity can be
turned up or down without touching a single call site -- something `print()`-debugging cannot offer.

Reference: https://docs.python.org/3/library/logging.html[the `logging` module].

== Standard Library Patterns That Prevent Bugs

The modules in the tour above are small in surface and deep in corners. This section picks the ones where a wrong mental
model causes real defects (time zones, serialisation, regular expressions and logging) and shows the behaviour with
runnable code. The reference for each module is the https://docs.python.org/3/library/index.html[library documentation].

=== Dates, times, and JSON round trips

`datetime` objects are either *naive* (no time zone: "some wall-clock time") or *aware* (a `tzinfo`). They cannot be
compared or subtracted with each other, which is a `TypeError` by design because the answer would be a guess. The sound
rule is to store and compute in UTC with aware values, convert to a local zone only for display (`astimezone`), and use ISO
8601 text (`isoformat`, `fromisoformat`) on the wire. `timedelta` arithmetic is on elapsed time, so adding a day across a
daylight-saving change needs a zone-aware library (`zoneinfo`, 3.9+) to match civil-time expectations.

`json` maps only a few types: `dict` (with string keys: other keys are converted), `list` and `tuple`, `str`, numbers,
booleans and `None`. Anything else (`datetime`, `set`, dataclasses, `Decimal`) raises `TypeError` until you provide a
`default=` function or a `JSONEncoder` subclass for output, and an `object_hook` for input. Decoding returns lists
where you encoded tuples, so a round trip is not an identity.

[source,python]
----
import json
from dataclasses import dataclass, asdict
from datetime import date, datetime, timedelta, timezone

# naive vs aware datetimes: never mix them
naive = datetime(2026, 3, 29, 1, 30)
aware = naive.replace(tzinfo=timezone.utc)
try:
    naive < aware
except TypeError as exc:
    print("TypeError:", exc)
due = aware + timedelta(days=14)
print(due.isoformat(), due.astimezone(timezone(timedelta(hours=2))).isoformat())
print(datetime.fromisoformat("2026-03-29T01:30:00+00:00") == aware, (date(2026, 3, 1) - date(2026, 2, 1)).days)
print(datetime.strptime("29/03/2026", "%d/%m/%Y").date(), aware.strftime("%a %d %b %Y %H:%M %Z"))


@dataclass
class Loan:
    title: str
    due: datetime


class Encoder(json.JSONEncoder):
    def default(self, o):                         # only called for types json cannot handle
        if isinstance(o, datetime):
            return o.isoformat()
        if hasattr(o, "__dataclass_fields__"):
            return asdict(o)
        return super().default(o)


text = json.dumps([Loan("Dune", due)], cls=Encoder, indent=2)
print(text)
data = json.loads(text, object_hook=lambda d: {**d, "due": datetime.fromisoformat(d["due"])} if "due" in d else d)
print(type(data[0]["due"]).__name__)
print(json.dumps({"b": 1, "a": (1, 2), "n": None, "é": True}, sort_keys=True, ensure_ascii=False))
try:
    json.dumps({"x": {1, 2}})
except TypeError as exc:
    print("TypeError:", exc)
print(json.loads("[1, 2.0, \"3\", null]"), json.dumps({1: "int key becomes a string"}))
----

=== Regular expressions without surprises

Always write patterns as raw strings (`+r"..."+`), because in a normal string `"\b"` is a backspace character, not a word
boundary. Compile a pattern you use repeatedly (`re.compile`), name groups (`+(?P<name>...)+`) so code does not depend on
positions, and use `re.VERBOSE` to lay a long pattern out with comments. Quantifiers are *greedy* by default and match as
much as possible; add `?` to make them lazy. `match` anchors at the start, `search` finds anywhere, `fullmatch` requires
the whole string, and `finditer` yields match objects lazily. Avoid parsing nested or recursive formats (HTML, JSON,
source code) with regular expressions, and beware of patterns with nested quantifiers on untrusted input, which can
backtrack catastrophically.

[source,python]
----
import re

line = "2026-03-09 ERROR [catalog] Missing title: Dune (isbn=9780441172719)"

pattern = re.compile(r"""
    (?P<date>\d{4}-\d{2}-\d{2}) \s+
    (?P<level>[A-Z]+)           \s+
    \[(?P<module>\w+)\]         \s+
    (?P<message>.*)
""", re.VERBOSE)

m = pattern.match(line)
print(m.groupdict()["level"], m["module"], m.span("date"))
print(re.findall(r"isbn=(\d{13})", line), re.search(r"\d+", line).group())

# greedy vs lazy, and anchors
html = "<b>Dune</b> and <b>Emma</b>"
print(re.findall(r"<b>.*</b>", html), re.findall(r"<b>.*?</b>", html))
print(re.sub(r"(?P<y>\d{4})-(?P<m>\d{2})-(?P<d>\d{2})", r"\g<d>/\g<m>/\g<y>", "due 2026-03-09"))
print(re.sub(r"\s+", " ", "  too   many \n spaces ").strip(), re.split(r"[,;]\s*", "a, b;c"))
print(bool(re.fullmatch(r"\d{13}", "9780441172719")), bool(re.fullmatch(r"\d{13}", "97804411727190")))
print([m.group(1) for m in re.finditer(r"(?<=\[)(\w+)(?=\])", line)])

# raw strings matter: "\b" in a normal string is a backspace character
print(len("\b"), len(r"\b"), bool(re.search(r"\bDune\b", line)))
print(re.escape("a.b*c"))
----

=== The logging tree

`logging` is a tree of named loggers (`bookshelf`, `bookshelf.catalog`) with handlers attached at any level. A record
created by `+catalog.warning(...)+` is checked against the logger's *effective level* (its own, or the nearest ancestor's),
and then offered to its handlers and, if `propagate` is true, to every ancestor's handlers. Libraries should create loggers
with `+logging.getLogger(__name__)+` and add no handlers; only the application configures handlers and levels, once, at
start-up (`logging.basicConfig` or `logging.config.dictConfig`).

[mermaid]
....
flowchart TD
    A["catalog.warning('low stock')"] --> B{"Level at or above the\neffective level?"}
    B -- No --> X["Dropped"]
    B -- Yes --> C["Create LogRecord"]
    C --> D["Handlers on bookshelf.catalog"]
    D --> E{"propagate is True?"}
    E -- Yes --> F["Handlers on bookshelf, then root"]
    E -- No --> G["Stop"]
    F --> H["Each handler applies its own\nlevel, filters and formatter"]
....

Pass message arguments separately (`log.info("loaded %d rows", n)`) so formatting only happens if the record is emitted, use
`+log.exception(...)+` inside an `except` block to include the traceback, and never log secrets. The `NullHandler` in the
sample prevents Python's "last resort" stderr handler from printing a record that has nowhere else to go.

[source,python]
----
import io
import logging

stream = io.StringIO()
handler = logging.StreamHandler(stream)
handler.setFormatter(logging.Formatter("%(levelname)-7s %(name)s: %(message)s"))

root = logging.getLogger()
root.addHandler(handler)
root.setLevel(logging.WARNING)                      # root default: WARNING and above

app = logging.getLogger("bookshelf")                 # loggers form a tree by dotted name
catalog = logging.getLogger("bookshelf.catalog")
print(catalog.parent is app, app.parent is root, catalog.getEffectiveLevel() == logging.WARNING)

catalog.info("not shown: below the effective level")
catalog.warning("low stock for %s (%d left)", "Dune", 1)   # lazy %-style arguments
app.setLevel(logging.DEBUG)
catalog.debug("shown now: the level is inherited from 'bookshelf'")

try:
    1 / 0
except ZeroDivisionError:
    catalog.exception("import failed")                # logs ERROR plus the traceback

catalog.propagate = False                             # stop records reaching root's handlers
catalog.addHandler(logging.NullHandler())             # without any handler, the last-resort handler prints to stderr
catalog.error("never printed by root's handler")
print(stream.getvalue().replace("\n\n", "\n").splitlines()[:2])
print(stream.getvalue().count("Traceback"), "never printed" in stream.getvalue())
----

Output:

[source,text]
----
True True True
['WARNING bookshelf.catalog: low stock for Dune (1 left)', "DEBUG   bookshelf.catalog: shown now: the level is inherited from 'bookshelf'"]
1 False
----
