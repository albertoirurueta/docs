= pip
:description: Landing page for the pip pages -- what pip is (the standard installer, bundled through ensurepip) and what it is not (a workflow manager), the pip 26.2.2 baseline, the support policy (only the latest release, CPython 3.10 to 3.15 and PyPy), the quarterly YY.N release cadence, and a map of the pip pages from installing pip to locks and troubleshooting.
:keywords: pip, pip 26.2.2, Python installer, ensurepip, pip is not a workflow management tool, support policy, YY.N, release cadence, pip pages

include::partial$python-build-tools-disclaimer.adoc[]

pip is the package installer for Python: it resolves requirements against an index, downloads or builds wheels and installs them
into the environment of the Python that runs it. It is bundled with CPython through `ensurepip`, which is why `python -m pip`
works in every new virtual environment. pip is deliberately *not* a workflow tool: "pip is not a workflow management tool", in
its own documentation's words. It does not create environments, track a project's dependencies in `pyproject.toml`, bump
versions or publish; it works with `venv`, build, twine and requirements or lock files, which these pages cover alongside it.

The pages are written against *pip 26.2.2* (2026-10-20). Only the latest pip is supported; it runs on CPython 3.10 to 3.15 and
PyPy, and new versions come out quarterly, numbered `YY.N` (26.0 in January 2026, 26.2 in July). History and policies are on
xref:programming-languages/python/build-tools/pip/versions-and-release-history.adoc[Versions & Release History].
