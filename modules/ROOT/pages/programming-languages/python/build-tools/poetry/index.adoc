= Poetry
:description: Landing page for the Poetry pages -- what Poetry is (dependency management, packaging and publishing in one tool, built on the standards), the Poetry 2.5.1 and poetry-core 2.5.0 baseline, Python 3.10+ to run it and any Python range for projects, Poetry's own major.minor.micro versioning that deliberately is not semantic versioning, and a map of the Poetry pages from installation to migration and troubleshooting.
:keywords: Poetry, Poetry 2.5.1, poetry-core 2.5.0, dependency management, packaging, publishing, poetry.lock, pyproject.toml, system requirements, versioning scheme, semantic versioning, Poetry pages

include::partial$python-build-tools-disclaimer.adoc[]

https://python-poetry.org/[Poetry] is a tool for dependency management and packaging: it declares a project's dependencies in
`pyproject.toml`, resolves them for every Python and platform the project supports into a `poetry.lock`, manages a virtual
environment per project, and builds and publishes the project. Since 2.0 it uses the standard `[project]` table, its build
backend poetry-core is a standard PEP 517 backend, and its lock file can be exported to `pylock.toml`; Poetry-specific
configuration lives under `[tool.poetry]`.

The pages are written against *Poetry 2.5.1* (2026-09-20) with *poetry-core 2.5.0*. Poetry itself needs Python 3.10 or newer;
the projects it manages can target any Python range, independent of the interpreter Poetry runs on. Poetry's versions are
`major.minor.micro` and, by its own FAQ, *not* semantic versioning: a minor release may remove features deprecated in an earlier
minor release, so read the changelog before upgrading and pin Poetry in CI. History and the 2.0 changes are on
xref:programming-languages/python/build-tools/poetry/versions-and-release-history.adoc[Versions & Release History] and
xref:programming-languages/python/build-tools/poetry/migrating-to-poetry-2.adoc[Migrating to Poetry 2].

Projects that want to show they use Poetry can add the badge the community page provides to their README.
