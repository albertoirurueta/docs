This page lists the projects around pip and Poetry that the other pages of this section mention. *Nothing here is documented
further*: each row has a one-sentence description, the version current on 2026-10-22 (checked against the PyPI JSON API or the
project's Git tags) and links to the official site and documentation. Projects not maintained by the PyPA, the Poetry project or the
PSF are third-party.

*Selection criterion.* A project is listed if the Python Packaging User Guide, the pip documentation, the Poetry documentation or
the PyPI documentation links it, or if it is an index server named in the Packaging User Guide's "hosting your own index" guide.

== Workflow tools and installers

[cols="2,5,1,3",options="header"]
|===
| Project | What it is | Version | Links

| uv (third party)
| A fast resolver and installer written in Rust, with a pip-compatible `uv pip` interface, its own project workflow and `uv.lock`, and Python version management.
| 0.13.5
| https://docs.astral.sh/uv/[Documentation], https://docs.astral.sh/uv/pip/[uv pip interface]

| PDM (third party)
| A standards-first project and dependency manager that writes PEP 621 metadata and `pylock.toml`.
| 2.29.3
| https://pdm-project.org/en/latest/[Documentation]

| Hatch
| The PyPA's project manager around the hatchling backend: environments, scripts, versioning, building and publishing.
| 1.18.1
| https://hatch.pypa.io/latest/[Documentation]

| Pipenv
| An application dependency manager with `Pipfile` and `Pipfile.lock`.
| 2026.10.2
| https://pipenv.pypa.io/[Documentation]

| pip-tools
| `pip-compile` turns `requirements.in` into a pinned, optionally hashed `requirements.txt`; `pip-sync` makes an environment match it.
| 7.6.2
| https://pip-tools.pypa.io/en/latest/[Documentation]

| pipx
| Installs Python command-line applications, such as Poetry or twine, each in its own virtual environment.
| 1.18.4
| https://pipx.pypa.io/stable/[Documentation]

| virtualenv
| A faster, more configurable creator of virtual environments than the standard library's `venv`; Poetry uses it internally.
| 21.14.12
| https://virtualenv.pypa.io/en/latest/[Documentation]

| conda and conda-forge (third party)
| A cross-language package and environment manager with its own package format, and the community channel that builds Python packages for it.
| —
| https://conda-forge.org/docs/[conda-forge documentation]
|===

One-line install for any of the Python tools above, kept out of your project environments: `pipx install <name>`.
