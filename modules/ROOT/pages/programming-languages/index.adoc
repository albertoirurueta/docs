A cross-reference of the general-purpose programming languages documented across this site, gathered here in one
place (and compared side by side in the xref:programming-languages/comparative.adoc[Programming Languages Comparative]) for readers who arrive by language rather than by topic -- most references below also remain listed under
their own topic area (Web Development, Backend Development, Apps -> Android) for readers who arrive that way
instead; C, {cpp}, Objective-C, C#, Swift, PHP, Groovy, Scala, Go, Ruby, Fortran, COBOL, Visual Basic, R, MATLAB and the JVM build tools have no such secondary home and live only here (the PHP and
Laravel section under Web Development covers web applications and links back to the PHP Reference).
