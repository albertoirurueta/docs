A cross-reference of the general-purpose programming languages documented across this site, gathered here in one
place for readers who arrive by language rather than by topic -- most references below also remain listed under
their own topic area (Web Development, Backend Development, Apps -> Android) for readers who arrive that way
instead; C, {cpp}, Objective-C, C#, Swift, PHP, Groovy, Scala, Go, Ruby, Fortran and the JVM build tools have no such secondary home and live only here (the PHP and
Laravel section under Web Development covers web applications and links back to the PHP Reference).
