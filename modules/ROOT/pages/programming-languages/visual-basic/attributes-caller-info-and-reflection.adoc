This page is written against Visual Basic 17.13 on .NET 10 (SDK 10.0.402) and was checked on 2026-10-20. The examples are complete console programs that
start with `Option Strict On`; they were built with warnings treated as errors (except where the page says the opposite) and run in the .NET 10 SDK
container (Linux, arm64). The CLR and compiler messages include the project's root namespace, which is `ShelfApp` for every single-file example
(the assembly is named `App`); the plugin example is a three-project solution. Where an example is meant to fail, the messages shown are the ones the
SDK printed.

Three features share this page because they share one mechanism: *metadata*. The compiler writes information about your code into the assembly, and a running program can read it
back. An *attribute* is metadata that you add; *caller information* is metadata the compiler fills in for you at each call; *reflection* is the API that reads it all, and that can
also act on what it finds, by creating objects and calling members whose names it learned at run time. Calling members through an `Object` variable under `Option Strict Off` is a related but different mechanism, late binding, and has its own page: xref:programming-languages/visual-basic/early-and-late-binding.adoc[Early and Late Binding].
The C# counterpart is on xref:programming-languages/csharp/attributes-and-reflection.adoc[Attributes and Reflection (C#)].

== Attributes

An attribute is a class that derives from `System.Attribute`, applied to a declaration with angle brackets. It does nothing by itself: the compiler stores it in the assembly,
and some other code (the compiler, a tool, the runtime, your program) reads it and acts on it. Visual Basic puts the attribute list *before* the declaration, inside `<` and `>`:

[source,vbnet]
----
<Attribute1(positionalArgument, NamedProperty:=value)>
<Attribute2>
Public Class Example
----

The syntax is regular:

* The class name may omit the *Attribute* suffix: `<Obsolete>` is `ObsoleteAttribute`.
* *Positional* arguments come first and select a constructor. *Named* arguments follow and set a public field or property with `:=` (C# uses `=`), in any order.
* Parentheses are optional when there are no arguments (`<Serializable>`).
* Several attributes can share one list, separated by commas (`<Description("a"), Category("b")>`), or be written as separate lists. A list may be broken over lines after a comma; a
  closing `>` may sit on the next line after a line-continuation underscore.
* The list is part of the declaration, not a separate statement, so there is *no attribute syntax for local variables* or statements.

The program below applies attributes to every kind of target Visual Basic allows and then reads each one back by reflection. It exercises the target list in the next table.

[source,vbnet]
----
Option Strict On

Imports System.ComponentModel
Imports System.Diagnostics
Imports System.Reflection

<Assembly: AssemblyMetadata("Catalogue", "Shelf")>
<Module: Description("The catalogue module")>

<Description("A book in the catalogue"), DebuggerDisplay("{Title,nq} ({Year})")>
Public Class Book
    <DefaultValue(1990)>
    Public Property Year As Integer

    Public Property Title As String = ""

    <Obsolete("Use Title instead", False)>
    Public Property Name As String = ""

    <Description("Copies on the shelf")>
    Public CopiesOnShelf As Integer

    <Description("Raised when a copy is lent")>
    Public Event Borrowed As EventHandler

    <Description("Pages of one edition")>
    Public Function Pages(<Description("Edition number")> edition As Integer) As <Description("The number of pages")> Integer
        Return 100 * edition
    End Function
End Class

<Description("One loan")>
Public Structure Loan
    Public Days As Integer
End Structure

<Description("A shelf")>
Public Interface IShelf
End Interface

<Description("Called when a book changes")>
Public Delegate Sub BookChanged(title As String)

Public Enum Shelfmark
    <Description("Fiction")> Fiction = 1
    <Description("Reference")> Reference = 2
End Enum

Module Program
    Function Member(found As MemberInfo) As MemberInfo
        If found Is Nothing Then Throw New InvalidOperationException("Member not found")
        Return found
    End Function

    Sub Show(label As String, attributes As IEnumerable(Of Attribute))
        For Each attribute As Attribute In attributes
            Console.WriteLine(label.PadRight(22) & attribute.GetType().Name)
        Next
    End Sub

    Sub Main()
        Dim bookType As Type = GetType(Book)
        Show("class", bookType.GetCustomAttributes(False).Cast(Of Attribute)())
        Show("property Year", Member(bookType.GetProperty("Year")).GetCustomAttributes(False).Cast(Of Attribute)())
        Show("property Name", Member(bookType.GetProperty("Name")).GetCustomAttributes(False).Cast(Of Attribute)())
        Show("event", Member(bookType.GetEvent("Borrowed")).GetCustomAttributes(False).Cast(Of Attribute)())
        Show("structure", GetType(Loan).GetCustomAttributes(False).Cast(Of Attribute)())
        Show("interface", GetType(IShelf).GetCustomAttributes(False).Cast(Of Attribute)())
        Show("delegate", GetType(BookChanged).GetCustomAttributes(False).Cast(Of Attribute)())
        Show("field", Member(bookType.GetField("CopiesOnShelf")).GetCustomAttributes(False).Cast(Of Attribute)())
        Dim pages As MethodInfo = CType(Member(bookType.GetMethod("Pages")), MethodInfo)
        Show("method", pages.GetCustomAttributes(False).Cast(Of Attribute)())
        Show("return value", pages.ReturnTypeCustomAttributes.GetCustomAttributes(False).Cast(Of Attribute)())
        Show("parameter", pages.GetParameters()(0).GetCustomAttributes(False).Cast(Of Attribute)())
        Show("enum member", Member(GetType(Shelfmark).GetField("Fiction")).GetCustomAttributes(False).Cast(Of Attribute)())
        Show("assembly", Assembly.GetExecutingAssembly().GetCustomAttributes(GetType(AssemblyMetadataAttribute)).Cast(Of Attribute)())
        Show("module", bookType.Module.GetCustomAttributes(False).Cast(Of Attribute)())
    End Sub
End Module
----

|Target |How to write it in Visual Basic |Seen in the program
|Class, structure, interface, delegate, enum |the list before the declaration |`Description` and `DebuggerDisplay` on `Book`; `Description` on `Loan`, `IShelf` and `BookChanged`

|Module |`+<Module: Attribute(...)>+`, same placement |`Description`
|===

The things that Visual Basic does *not* offer follow from that table. An attribute written before an auto-implemented property always goes on the *property*; the C# `[field: NonSerialized]` target that
puts it on the compiler-generated backing field does not exist. The `<Return:` prefix is rejected as shown below. And attributes on lambdas (C# 10) and on local variables do not exist.

=== Assembly and module attributes, and the generated file

`+<Assembly: ...>+` and `+<Module: ...>+` apply to the whole assembly or module and are written outside any type, after the `Imports` statements and before the first declaration. Placing one after a declaration fails:

[source,vbnet]
----
Option Strict On

Imports System.ComponentModel

Public Class Early
End Class

<Assembly: System.Reflection.AssemblyMetadata("k", "v")>

Module Program
    Sub Main()
    End Sub
End Module
----

[source,text]
----
Program.vb(8,1): error BC30637: Assembly or Module attribute statements must precede any declarations in a file.
----

Source: https://learn.microsoft.com/dotnet/visual-basic/programming-guide/concepts/attributes/[Attributes overview (Visual Basic)]

Most assembly attributes need not be written by hand. The SDK generates a file, `obj/<configuration>/<framework>/<AssemblyName>.AssemblyInfo.vb`, from the project's properties. I built a project that
sets `Version`, `AssemblyVersion`, `Authors`, `Company`, `Product`, `Description`, `Copyright` and `SourceRevisionId` in the project file:

[source,xml]
----
<Version>2.1.0-beta.1</Version>
<AssemblyVersion>2.1.0.0</AssemblyVersion>
<Authors>Shelf team</Authors>
<Company>Shelf</Company>
<Product>Shelf catalogue</Product>
<Description>Library catalogue</Description>
<Copyright>Shelf</Copyright>
<SourceRevisionId>abc1234</SourceRevisionId>
----

and listed the assembly's attributes at run time:

[source,vbnet]
----
Option Strict On

Imports System.Reflection
Imports System.Runtime.CompilerServices

Module Program
    Sub Main()
        Dim assembly As Assembly = GetType(Program).Assembly
        Console.WriteLine("AssemblyName.Version: " & assembly.GetName().Version.ToString())
        For Each data As CustomAttributeData In assembly.CustomAttributes.OrderBy(Function(d) d.AttributeType.Name)
            Dim arguments As String = String.Join(", ", data.ConstructorArguments.Select(Function(a) a.Value.ToString()))
            Console.WriteLine($"{data.AttributeType.Name,-40}{arguments}")
        Next
    End Sub
End Module
----

The mapping to remember: `Version` becomes the informational version (the semantic version, with the source revision appended after a `pass:c[+]`) and, unless overridden, the file version (without the pre-release suffix) and the assembly version;
`AssemblyVersion` sets the assembly's identity; `Company`, `Product`, `Description` and `Copyright` become the attributes of those names, `AssemblyTitle` defaults to the assembly name, and `Authors` is
a NuGet package property that did not produce an attribute here. `TargetFramework`, `Debuggable` and `CompilationRelaxations` come from the compiler.

Because the SDK already writes `AssemblyTitle` and `AssemblyVersion`, writing the same attribute yourself is a duplicate:

[source,vbnet]
----
Option Strict On

Imports System.Reflection

<Assembly: AssemblyTitle("Shelf catalogue")>
<Assembly: AssemblyVersion("1.2.3.0")>

Module Program
    Sub Main()
        Console.WriteLine("built")
    End Sub
End Module
----

[source,text]
----
obj/Debug/net10.0/App.AssemblyInfo.vb(20,2): error BC30663: Attribute 'AssemblyTitleAttribute' cannot be applied multiple times.
obj/Debug/net10.0/App.AssemblyInfo.vb(21,2): error BC30663: Attribute 'AssemblyVersionAttribute' cannot be applied multiple times.
----

Source: https://learn.microsoft.com/dotnet/core/project-sdk/msbuild-props[MSBuild properties for Microsoft.NET.Sdk]

There are two fixes. Set the matching project property (the right one for almost every project), or turn the generator off with `<GenerateAssemblyInfo>false</GenerateAssemblyInfo>`, which makes your file the only source; the same
program with that property built and printed `built`. Some assembly attributes have an item form: `<InternalsVisibleTo Include="Shelf.Tests" />` in the project file
generates `<Assembly: InternalsVisibleTo("Shelf.Tests")>` for you.

=== Custom attributes

A custom attribute is a class that derives from `Attribute`. Its constructor parameters become the positional arguments and its public read/write fields and properties become the named ones. `AttributeUsage`,
itself an attribute, controls where it may be applied:

[cols="3,6",options="header"]
|===
|`AttributeUsage` setting |Meaning
|`ValidOn` (first, positional argument) |the `AttributeTargets` values the attribute may be applied to, combined with `Or`; the default is `All`
|`AllowMultiple:=True` |the attribute may appear more than once on the same declaration; the default is `False`
|`Inherited:=True` |derived classes, and overriding members of derived classes, see the attribute through the inheritance-aware reading APIs; the default is `True`
|===

Source: https://learn.microsoft.com/dotnet/visual-basic/programming-guide/concepts/attributes/creating-custom-attributes[Creating custom attributes (Visual Basic)]

The program defines a `CatalogRule` attribute with a constructor argument, properties of five types (`String`, an enum, an `Integer`, a `String()` array and a `Type`), and
`AllowMultiple` and `Inherited` set. It applies it to `CatalogItem` and its members, reads the rules back, and shows what inheritance does:

[source,vbnet]
----
Option Strict On

Imports System.Reflection

Public Enum Audience
    Everyone
    Staff
    Admin
End Enum

<AttributeUsage(AttributeTargets.Class Or AttributeTargets.Method Or AttributeTargets.Property,
                AllowMultiple:=True, Inherited:=True)>
Public NotInheritable Class CatalogRuleAttribute
    Inherits Attribute

    Public ReadOnly Property Name As String
    Public Property Audience As Audience = Audience.Everyone
    Public Property Priority As Integer
    Public Property Tags As String()
    Public Property Handler As Type

    Public Sub New(name As String)
        Me.Name = name
    End Sub
End Class

<CatalogRule("NoDuplicates", Priority:=2, Audience:=Audience.Staff)>
<CatalogRule("MaxLoans", Tags:=New String() {"loans", "limits"}, Handler:=GetType(String))>
Public Class CatalogItem
    <CatalogRule("TitleRequired")>
    Public Overridable Property Title As String = ""

    <CatalogRule("OnlyAdmins", Audience:=Audience.Admin)>
    Public Overridable Sub Remove()
    End Sub
End Class

Public Class Magazine
    Inherits CatalogItem

    Public Overrides Sub Remove()
    End Sub

    Public Overrides Property Title As String
End Class

Module Program
    Sub Describe(label As String, rule As CatalogRuleAttribute)
        Dim tags As String = If(rule.Tags Is Nothing, "-", String.Join("/", rule.Tags))
        Dim handler As String = If(rule.Handler Is Nothing, "-", rule.Handler.Name)
        Console.WriteLine($"{label,-26}{rule.Name,-14}audience={rule.Audience,-9}priority={rule.Priority} tags={tags} handler={handler}")
    End Sub

    Sub Main()
        For Each rule As CatalogRuleAttribute In GetType(CatalogItem).GetCustomAttributes(GetType(CatalogRuleAttribute), False)
            Describe("CatalogItem", rule)
        Next
        For Each rule As CatalogRuleAttribute In GetType(Magazine).GetCustomAttributes(GetType(CatalogRuleAttribute), True)
            Describe("Magazine (inherit)", rule)
        Next
        Console.WriteLine("Magazine IsDefined (inherit False): " & GetType(Magazine).IsDefined(GetType(CatalogRuleAttribute), False))
        Console.WriteLine("Magazine IsDefined (inherit True):  " & GetType(Magazine).IsDefined(GetType(CatalogRuleAttribute), True))

        Dim removeDerived As MethodInfo = GetType(Magazine).GetMethod("Remove")
        Dim titleDerived As PropertyInfo = GetType(Magazine).GetProperty("Title")
        Console.WriteLine("Overriding method,   MemberInfo:       " & removeDerived.GetCustomAttributes(GetType(CatalogRuleAttribute), True).Length)
        Console.WriteLine("Overriding method,   Attribute class:  " & Attribute.GetCustomAttributes(removeDerived, GetType(CatalogRuleAttribute), True).Length)
        Console.WriteLine("Overriding property, MemberInfo:       " & titleDerived.GetCustomAttributes(GetType(CatalogRuleAttribute), True).Length)
        Console.WriteLine("Overriding property, Attribute class:  " & Attribute.GetCustomAttributes(titleDerived, GetType(CatalogRuleAttribute), True).Length)

        Dim titleRule As CatalogRuleAttribute = GetType(CatalogItem).GetProperty("Title").GetCustomAttribute(Of CatalogRuleAttribute)()
        Console.WriteLine("GetCustomAttribute(Of T): " & titleRule.Name)
        Try
            Dim ambiguous As CatalogRuleAttribute = GetType(CatalogItem).GetCustomAttribute(Of CatalogRuleAttribute)()
            Console.WriteLine(ambiguous.Name)
        Catch ex As AmbiguousMatchException
            Console.WriteLine("Two rules on one class: " & ex.GetType().Name)
        End Try
    End Sub
End Module
----

What the output teaches:

* *Argument types are limited to what a constant can express*: numbers, strings, `Boolean`, enum values, a `Type` (`GetType(String)`) and one-dimensional arrays of those (`+New String() {"loans", "limits"}+`). The program used a `String`, an enum, an `Integer`, a `String()` and a `Type`.
* *Reading a missing named argument gives the property's default*: `Audience` is `Everyone` and `Priority` is 0 for the second rule, which set neither.
* *`GetCustomAttribute(Of T)` is for a single attribute.* With `AllowMultiple:=True` and two attributes present it throws `AmbiguousMatchException`; use `GetCustomAttributes` for lists.
* *The `inherit` flag is honoured for classes and methods but not for properties and events when you read through `MemberInfo`.* The overriding `Magazine.Title` reported 0 rules through
  `MemberInfo.GetCustomAttributes(type, True)` and 1 through `Attribute.GetCustomAttributes(member, type, True)`. If you must support inherited property attributes, use the `Attribute` class methods
  (or the `CustomAttributeExtensions` ones, which call them).
* `IsDefined` does not create an attribute instance. It is the cheap way to test for presence, because *reading* an attribute runs its constructor.

=== What arguments are allowed

An attribute argument must be a constant the compiler can evaluate: a literal, a `Const`, a concatenation of constants, `+NameOf(...)+`, an enum value, `+GetType(...)+`, or an array of those. A value only known at run time, including
a `Shared ReadOnly` field and a method call, is rejected. The program below uses one example of each:

[source,vbnet]
----
Option Strict On

Imports System.ComponentModel

Public Class Computed
    Private Const Fixed As String = "fixed"
    Private Shared ReadOnly Dynamic As String = "dynamic"

    <Description(Fixed)>
    Public Property A As String

    <Description(Dynamic)>
    Public Property B As String

    <Description(String.Concat("a", "b"))>
    Public Property C As String

    <Description("a" & "b")>
    Public Property D As String

    <Description(NameOf(A))>
    Public Property E As String
End Class

Module Program
    Sub Main()
    End Sub
End Module
----

[source,text]
----
Program.vb(12,18): error BC30059: Constant expression is required.
Program.vb(15,18): error BC30059: Constant expression is required.
----

Source: https://learn.microsoft.com/dotnet/visual-basic/programming-guide/concepts/attributes/[Attributes overview (Visual Basic)]

`Fixed` (a `Const`), the concatenation `"a" & "b"` and `NameOf(A)` compile; the `Shared ReadOnly` field and `String.Concat` do not. The shared helpers for the following failing programs live in one file, `Rules.vb`. It declares
`RuleAttribute` (valid on classes only, one required constructor argument, a read-only `Name` and a writable `Priority`), `AnyRuleAttribute` and a plain class `Plain` that is *not* an attribute:

Public NotInheritable Class AnyRuleAttribute
    Inherits Attribute
End Class

Public Class Plain
End Class

=== The common attributes

[cols="3,3,6",options="header"]

== Caller information

Caller information lets a method learn where it was called from without the caller passing anything. A method declares *optional parameters* with default values and decorates them with attributes from
`System.Runtime.CompilerServices`. When a caller omits the argument, the *compiler* writes the value into the call at compile time. Visual Basic 11 (Visual Studio 2012) introduced the first three; `CallerArgumentExpression` arrived with
Visual Basic 17.0 (Visual Studio 2022 17.0, .NET 6).

[cols="3,2,5",options="header"]
|===
|Attribute |Parameter type |Value supplied
|`CallerMemberName` |`String` |the name of the calling member (see the table of special names below)
|`CallerFilePath` |`String` |the full path of the caller's source file *at compile time*
|`CallerLineNumber` |`Integer` |the line number of the call in that file
|`CallerArgumentExpression("parameterName")` |`String` |the source text of the argument passed to the *other* parameter named in the attribute
|===

Source: https://learn.microsoft.com/dotnet/visual-basic/programming-guide/concepts/caller-information[Caller information (Visual Basic)]

The first program defines a logging helper that takes all three of the older attributes and calls it from every kind of member, so you can see exactly what the compiler writes:

=== The attribute is advisory

Visual Basic does not check that a caller-information attribute is on a suitable parameter, and when it is not, the attribute is silently ignored:

        Console.WriteLine("String parameter received: " & line)
    End Sub

    End Sub

=== CallerArgumentExpression

`CallerArgumentExpression("name")` gives a helper the *source text* of the argument that the caller wrote for another parameter. It exists for guard clauses and test assertions that want to say "this condition failed" with the
condition itself. The program defines `Require` and `Describe`, and also uses the framework's own users of the attribute, `ArgumentNullException.ThrowIfNull` and `ArgumentException.ThrowIfNullOrEmpty`:

[source,vbnet]
----
Option Strict On

Imports System.Runtime.CompilerServices

Public Class RuleViolationException
    Inherits Exception

    Public ReadOnly Property Expression As String

    Public Sub New(message As String, expression As String)
        MyBase.New(message)
        Me.Expression = expression
    End Sub
End Class

Module Guard
    Sub Require(condition As Boolean,
                <CallerArgumentExpression("condition")> Optional expression As String = Nothing)
        If Not condition Then
            Throw New RuleViolationException("Rule failed: " & expression, expression)
        End If
    End Sub

    Function Describe(value As Object,
                      <CallerArgumentExpression("value")> Optional expression As String = Nothing) As String
        Return $"{expression} = {value}"
    End Function
End Module

Module Program
    Sub Main()
        Dim copies As Integer = 3
        Dim title As String = "Dune"
        Console.WriteLine(Describe(copies))
        Console.WriteLine(Describe(copies * 2 + 1))
        Console.WriteLine(Describe(title.ToUpperInvariant()))
        Console.WriteLine(Describe(  copies   +   1  ))
        Console.WriteLine(Describe(
            copies))

        Try
            Require(copies > 5)
        Catch ex As RuleViolationException
            Console.WriteLine(ex.Message)
        End Try

        Try
            Require(title.Length = 0 OrElse copies < 0)
        Catch ex As RuleViolationException
            Console.WriteLine(ex.Message)
        End Try

        Try
            Dim missing As String = Nothing
            ArgumentNullException.ThrowIfNull(missing)
        Catch ex As ArgumentNullException
            Console.WriteLine(ex.Message.Replace(Environment.NewLine, " "))
        End Try

        Try
            ArgumentNullException.ThrowIfNull(Nothing, "explicit name")
        Catch ex As ArgumentNullException
            Console.WriteLine(ex.Message.Replace(Environment.NewLine, " "))
        End Try

        Try
            ArgumentException.ThrowIfNullOrEmpty(Nothing)
        Catch ex As ArgumentException
            Console.WriteLine(ex.GetType().Name & ": " & ex.Message.Replace(Environment.NewLine, " "))
        End Try
    End Sub
End Module
----

[source,text]
----
copies = 3
copies * 2 + 1 = 7
title.ToUpperInvariant() = DUNE
copies   +   1 = 4
copies = 3
Rule failed: copies > 5
Rule failed: title.Length = 0 OrElse copies < 0
Value cannot be null. (Parameter 'missing')
Value cannot be null. (Parameter 'explicit name')
ArgumentNullException: Value cannot be null. (Parameter 'Nothing')
----

Source: https://learn.microsoft.com/dotnet/api/system.runtime.compilerservices.callerargumentexpressionattribute[CallerArgumentExpressionAttribute]

Notes on the output:

* The text is the argument as written, trimmed at both ends but *not* normalised inside: `pass:c[copies   +   1]` kept its spaces. An argument spread over two lines gave just `copies`, the text between the parentheses with the leading newline removed.
* The BCL guard helpers work from Visual Basic, because the attribute is honoured at the call site: `ThrowIfNull(missing)` said `+Parameter 'missing'+`, and an argument that is the literal `Nothing` produced the parameter name `Nothing`.
* A name that is not a parameter is a *warning*, not an error, and the attribute then has no effect:

[source,text]
----
Program.vb(12,45): warning BC42505: The CallerArgumentExpressionAttribute applied to parameter 'text' will have no effect. It is applied with an invalid parameter name.
----

* The expression is source text copied at compile time; it is not evaluated again. Your identifiers end up in the compiled binary, so do not use it for messages meant for users.

== NameOf

`NameOf` (Visual Basic 14, Visual Studio 2015) turns a name in code into a string at compile time. The string is a constant; it is what you use for parameter names in exceptions, for
`PropertyChanged` notifications, for log messages, and for attribute arguments. When the member is renamed, the string follows it.

[source,vbnet]
----
Option Strict On

Imports System.Collections.Generic
Imports System.IO

Namespace Shelf
    Public Class Book
        Public Property Title As String = ""
        Public Shared Property Count As Integer
        Public Sub Rename(newTitle As String)
            Title = newTitle
        End Sub
        Public Sub Rename(newTitle As String, force As Boolean)
            Title = newTitle
        End Sub
    End Class
End Namespace

Public Class Holder
    Public Property Title As String = ""
    Public Property Name As String = ""

    Public Function Names() As String()
        Return {NameOf(Title), NameOf(Me.Name), NameOf(Holder.Title), NameOf(Holder)}
    End Function
End Class

Module Program
    Private Const TitleName As String = NameOf(Shelf.Book.Title)

    Sub Show(code As String, value As String)
        Console.WriteLine(code.PadRight(36) & value)
    End Sub

    Sub Main()
        Dim copies As Integer = 3
        Dim parts As New List(Of String)()

        Show("NameOf(copies)", NameOf(copies))
        Show("NameOf(parts)", NameOf(parts))
        Show("NameOf(Shelf.Book)", NameOf(Shelf.Book))
        Show("NameOf(Shelf.Book.Title)", NameOf(Shelf.Book.Title))
        Show("NameOf(Shelf.Book.Count)", NameOf(Shelf.Book.Count))
        Show("NameOf(Shelf.Book.Rename)", NameOf(Shelf.Book.Rename))
        Show("NameOf(Shelf)", NameOf(Shelf))
        Show("NameOf(System.IO)", NameOf(System.IO))
        Show("NameOf(System.Console.WriteLine)", NameOf(System.Console.WriteLine))
        Show("NameOf(List(Of String))", NameOf(List(Of String)))
        Show("NameOf(List(Of String).Count)", NameOf(List(Of String).Count))
        Show("NameOf(Program)", NameOf(Program))
        Show("NameOf(Main)", NameOf(Main))
        Show("Const TitleName", TitleName)
        Show("NameOf(copies) in a Select Case", Describe(NameOf(copies)))
        Show("Holder.Names()", String.Join(",", New Holder().Names()))
        Show("NameOf(parts).Length", NameOf(parts).Length.ToString())
    End Sub

    Function Describe(name As String) As String
        Select Case name
            Case NameOf(Describe)
                Return "the function itself"
            Case "copies"
                Return "copies matched as a constant"
            Case Else
                Return "other"
        End Select
    End Function
End Module

== Reflection

Reflection is the API of `System.Reflection` and `System.Type` that describes types, members and assemblies and lets you act on that description. The entry point is the `Type` object.

=== Getting a Type

The program below gets a `Type` three ways (the `GetType` operator, the `GetType()` method, and `+TypeOf ... Is+` as the type test) and lets the `Type` answer questions about itself. In Visual Basic `GetType(X)` is the *operator* (C# `typeof`) and `obj.GetType()` is the *method*
(the same name, different things; the operator needs a type name, the method needs an object):

=== Creating objects and calling members

`Activator.CreateInstance` and `ConstructorInfo.Invoke` create objects; `MethodInfo.Invoke`, `PropertyInfo.GetValue`/`SetValue` and `FieldInfo.GetValue`/`SetValue` use their members. The program creates a `Book` and drives it entirely by reflection,
and triggers each of the failures a reflection caller must expect:

[source,vbnet]
----
Option Strict On

Imports System.Reflection

Public Class Book
    Private _isbn As String = "978-0-00-000000-2"
    Public Property Title As String
    Public Shared Property Created As Integer

    Public Sub New(title As String)
        Me.Title = title
        Created += 1
    End Sub

    Public Sub Rename(newTitle As String)
        If String.IsNullOrWhiteSpace(newTitle) Then Throw New ArgumentException("Title is empty", NameOf(newTitle))
        Title = newTitle
    End Sub

    Public Sub Rename(newTitle As String, upperCase As Boolean)
        Title = If(upperCase, newTitle.ToUpperInvariant(), newTitle)
    End Sub

    Public Function Wrap(Of T)(value As T) As String
        Return "[" & value.ToString() & "]"
    End Function
End Class

Module Program
    Sub Main()
        Dim bookType As Type = GetType(Book)

        Console.WriteLine("-- looking types up by name")
        Console.WriteLine("Type.GetType(""Book"")          = " & If(Type.GetType("Book") Is Nothing, "Nothing", "found"))
        Console.WriteLine("Type.GetType(""ShelfApp.Book"") = " & If(Type.GetType("ShelfApp.Book") Is Nothing, "Nothing", "found"))
        Console.WriteLine("FullName                       = " & bookType.FullName)

        Console.WriteLine("-- creating objects")
        Dim book As Book = CType(Activator.CreateInstance(bookType, "Dune"), Book)
        Dim constructor As ConstructorInfo = bookType.GetConstructor(New Type() {GetType(String)})
        Dim second As Book = CType(constructor.Invoke(New Object() {"Emma"}), Book)
        Console.WriteLine($"{book.Title}, {second.Title}, created={Book.Created}")
        Try
            Dim noDefault As Object = Activator.CreateInstance(bookType)
        Catch ex As MissingMethodException
            Console.WriteLine("No parameterless constructor: " & ex.GetType().Name)
        End Try

        Console.WriteLine("-- invoking members")
        Try
            bookType.GetMethod("Rename")
        Catch ex As AmbiguousMatchException
            Console.WriteLine("GetMethod(""Rename"") with two overloads: " & ex.GetType().Name)
        End Try
        Dim rename1 As MethodInfo = bookType.GetMethod("Rename", New Type() {GetType(String)})
        Dim rename2 As MethodInfo = bookType.GetMethod("Rename", New Type() {GetType(String), GetType(Boolean)})
        rename1.Invoke(book, New Object() {"Dune Messiah"})
        rename2.Invoke(book, New Object() {"children of dune", True})
        Console.WriteLine("Title now " & book.Title)

        Dim titleProperty As PropertyInfo = bookType.GetProperty("Title")
        titleProperty.SetValue(book, "God Emperor")
        Console.WriteLine("Property read: " & CStr(titleProperty.GetValue(book)))

        Dim isbnField As FieldInfo = bookType.GetField("_isbn", BindingFlags.Instance Or BindingFlags.NonPublic)
        Console.WriteLine("Private field: " & CStr(isbnField.GetValue(book)))
        Console.WriteLine("Shared property: " & CInt(bookType.GetProperty("Created").GetValue(Nothing)))

        Try
            rename1.Invoke(book, New Object() {" "})
        Catch ex As TargetInvocationException
            Console.WriteLine("Wrapped: " & ex.GetType().Name & " -> " & ex.InnerException.GetType().Name)
        End Try
        Try
            rename1.Invoke(book, New Object() {42})
        Catch ex As ArgumentException
            Console.WriteLine("Wrong argument type: " & ex.GetType().Name)
        End Try

        Console.WriteLine("-- generics")

        Console.WriteLine(listType.ToString())

        listType.GetMethod("Add").Invoke(list, New Object() {book})
        Console.WriteLine("Count = " & CInt(listType.GetProperty("Count").GetValue(list)))

        Console.WriteLine(CStr(wrap.Invoke(book, New Object() {42})))

        Console.WriteLine("-- a delegate removes the per-call cost")
        Dim getTitle As Func(Of Book, String) = CType(titleProperty.GetGetMethod().CreateDelegate(GetType(Func(Of Book, String))), Func(Of Book, String))
        Console.WriteLine(getTitle(book))
    End Sub

What the run shows:

* *The type name includes the project's root namespace.* `Type.GetType("Book")` is `Nothing` — there is no exception — and `Type.GetType("ShelfApp.Book")` finds the type. `Type.GetType(name, throwOnError:=True)` is the variant that fails loudly.
* *`GetMethod` with an overloaded name throws `AmbiguousMatchException`* unless you give the parameter types; the same happens with overloaded properties such as indexers.
* *An exception inside the invoked method arrives wrapped in `TargetInvocationException`;* read `InnerException`. A wrong argument type arrives as `ArgumentException` before the method runs.
* *Private members are reachable* with `BindingFlags.NonPublic`, which is why reflection over a library you do not own is fragile and why it is a security-sensitive feature in sandboxed code.
* *A shared member needs `Nothing` as the target* (`GetValue(Nothing)`).
* *Generic types and methods are closed with `MakeGenericType` and `MakeGenericMethod`;* the open type is written `GetType(List(Of ))`.
* *Reflection is slower than a direct call.* When a reflected call sits in a loop, create a delegate once (the last lines of the program: `CreateDelegate(GetType(Func(Of Book, String)))`) and call that; measure with BenchmarkDotNet before deciding anything.

=== Loading a plugin assembly

The reflection feature that matters most in real applications is finding implementations in an assembly that was not known when the host was compiled. The solution below has three projects: `Contracts` (an interface `IExporter` and an
attribute `ExporterAttribute`), `Plugin` (four classes) and `Host`, which references `Contracts` only and loads `Plugin.dll` from a `plugins` folder at run time. The host builds the plugin first through a
`ProjectReference` with `ReferenceOutputAssembly="false"` and copies the DLL into its output folder.

[source,vbnet]
----
Option Strict On

Public Interface IExporter
    Function Export(titles As IEnumerable(Of String)) As String
End Interface

<AttributeUsage(AttributeTargets.Class, AllowMultiple:=False)>
Public NotInheritable Class ExporterAttribute
    Inherits Attribute

    Public ReadOnly Property Format As String

    Public Sub New(format As String)
        Me.Format = format
    End Sub
End Class
----

[source,vbnet]
----
Option Strict On

Imports Shelf.Contracts

<Exporter("csv")>
Public Class CsvExporter
    Implements IExporter

    Public Function Export(titles As IEnumerable(Of String)) As String Implements IExporter.Export
        Return String.Join(",", titles)
    End Function
End Class

<Exporter("lines")>
Public Class LineExporter
    Implements IExporter

    Public Function Export(titles As IEnumerable(Of String)) As String Implements IExporter.Export
        Return String.Join(" | ", titles.Select(Function(t, i) $"{i + 1}. {t}"))
    End Function
End Class

Public Class NotAnExporter
End Class

Friend Class HiddenExporter
    Implements IExporter

    Public Function Export(titles As IEnumerable(Of String)) As String Implements IExporter.Export
        Return "hidden"
    End Function

Imports System.IO
Imports System.Reflection
Imports System.Runtime.CompilerServices
Imports System.Runtime.Loader
Imports Shelf.Contracts

Module Program
    <MethodImpl(MethodImplOptions.NoInlining)>
    Function RunPlugin(path As String) As WeakReference
        Dim context As New AssemblyLoadContext("plugins", isCollectible:=True)
        Dim assembly As Assembly = context.LoadFromAssemblyPath(path)
        Console.WriteLine("Loaded " & assembly.GetName().Name & " into context " & context.Name)

        Dim titles As String() = {"Dune", "Emma", "Ulysses"}
        For Each type As Type In assembly.GetTypes().OrderBy(Function(t) t.Name)
            Dim implementsExporter As Boolean = GetType(IExporter).IsAssignableFrom(type)
            Dim attribute As ExporterAttribute = type.GetCustomAttribute(Of ExporterAttribute)()
            Console.WriteLine($"{type.Name,-14} IExporter={implementsExporter,-5} public={type.IsPublic,-5} attribute={If(attribute Is Nothing, "none", attribute.Format)}")
            If implementsExporter AndAlso attribute IsNot Nothing Then
                Dim exporter As IExporter = CType(Activator.CreateInstance(type), IExporter)
                Console.WriteLine("   -> " & exporter.Export(titles))
            End If
        Next

        Dim weak As New WeakReference(context)
        context.Unload()
        Return weak
    End Function

    Sub Main()
        Dim path As String = System.IO.Path.Combine(AppContext.BaseDirectory, "plugins", "Plugin.dll")
        Console.WriteLine("Plugin file exists: " & File.Exists(path))
        Dim weak As WeakReference = RunPlugin(path)
        For attempt As Integer = 1 To 10
            If Not weak.IsAlive Then Exit For
            GC.Collect()
            GC.WaitForPendingFinalizers()
        Next
        Console.WriteLine("Context collected after unload: " & Not weak.IsAlive)
    End Sub
End Module

The design decisions in the host:

* The shared contract lives in a third assembly that *both* sides reference; the host loads the plugin into a *separate* `AssemblyLoadContext`, whose fallback to the default context resolves `Contracts` to the host's copy, so `IExporter` is the same type on both sides.
  Without a shared contract the plugin's `IExporter` would be a different type from the host's.
* The test `GetType(IExporter).IsAssignableFrom(type)` finds the implementations; `HiddenExporter` implements the interface but is `Friend`, so a host that wanted only public plugins would also test `IsPublic`. The compiler's `+_Closure$__+` class turns up in
  `GetTypes()` and is filtered out because it does not implement the interface.
* The attribute carries the *name* the plugin wants to be known by. Reading the attribute does not require creating the plugin.
* `isCollectible:=True` and `Unload()` let the runtime free the plugin assembly, but only when nothing references it: the loading code is in a `NoInlining` method so that no local from the plugin survives in the caller, and the test collects with `WeakReference` and `GC.Collect`
  in a loop. The last line shows the context was collected. A stray reference (a static event handler, a running thread, a cached `Type`) can keep it alive, and the line then reads `False`.
* A real host must not trust arbitrary DLLs; a plugin is code that runs with the host's rights.

=== Reflection, trimming and Native AOT

Trimming (`PublishTrimmed`) and Native AOT (`PublishAot`) remove code the linker thinks is unused. Reflection reaches code by *name* at run time, so the linker cannot see it: a type that is only created through `Type.GetType(name)` may be gone from the published application.
The annotations that tell the tools what reflection needs are the attributes `DynamicallyAccessedMembers` (on a `Type` parameter, naming the members that will be reflected on), `RequiresUnreferencedCode` and `RequiresDynamicCode` (on a method that cannot work when trimmed). They are
ordinary attributes, so they work in Visual Basic. The program below has one method of each kind:

[source,vbnet]
----
Option Strict On

Imports System.Diagnostics.CodeAnalysis

Public Class CsvExporter
    Public Function Export() As String
        Return "csv"
    End Function
End Class

Module Program
    <RequiresUnreferencedCode("Creates a type from its name")>
    Function CreateByName(name As String) As Object
        Return Activator.CreateInstance(Type.GetType(name))
    End Function

    Function CreateKnown(<DynamicallyAccessedMembers(DynamicallyAccessedMemberTypes.PublicParameterlessConstructor)> type As Type) As Object
        Return Activator.CreateInstance(type)
    End Function

    Function CreateUnannotated(type As Type) As Object
        Return Activator.CreateInstance(type)
    End Function

    Sub Main()
        Dim known As Object = CreateKnown(GetType(CsvExporter))
        Dim byName As Object = CreateByName("ShelfApp.CsvExporter")
        Dim unannotated As Object = CreateUnannotated(GetType(CsvExporter))
        Console.WriteLine(known.GetType().Name & " " & byName.GetType().Name & " " & unannotated.GetType().Name)
    End Sub
End Module
----

== Pitfalls checklist

* An `<Assembly:` attribute that the SDK also generates is a duplicate (BC30663); set the project property instead or switch off `GenerateAssemblyInfo`.
* The reflection name of a type includes the root namespace: `Type.GetType("Book")` returns `Nothing`; use the `FullName`.
* `GetCustomAttribute(Of T)` throws `AmbiguousMatchException` when the attribute allows multiples and appears more than once.
* `MemberInfo.GetCustomAttributes(inherit:=True)` does not look at the base member of a property or event; use `Attribute.GetCustomAttributes`.
* Reading an attribute runs its constructor; use `IsDefined` or `CustomAttributeData` when you only need to know it is there.
* Caller-information attributes need an `Optional` parameter of the right type; Visual Basic does not warn when they are wasted.
* `CallerFilePath` embeds the build machine's path; use `PathMap` for shipped binaries.
* `MethodInfo.Invoke` wraps exceptions in `TargetInvocationException`; unwrap `InnerException`.
* Reflection finds the compiler's own types and members (`+_Closure$__+`, `_Title`, `+$STATIC$...+`); filter by `IsSpecialName` and `CompilerGeneratedAttribute`.
* A name used only through reflection can be trimmed away; annotate it with `DynamicallyAccessedMembers` or keep it with a root descriptor. The Visual Basic build printed no trimming diagnostics here, so run the publish with trim warnings as errors in CI.
* A collectible `AssemblyLoadContext` is unloaded only when nothing references it; keep the loading code in a separate non-inlined method and test it.
* Never load or run code from a path supplied by users.
