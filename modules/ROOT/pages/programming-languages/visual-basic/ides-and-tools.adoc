This page lists the IDEs and editors commonly used for Visual Basic, with a link to each product's official page. Visual Studio on Windows offers the fullest Visual Basic experience; other editors provide basic editing next to the `dotnet` command line.

== IDEs

* https://visualstudio.microsoft.com/[*Visual Studio*] -- the Microsoft IDE with the complete Visual Basic experience on Windows, including designers and the debugger.
* https://www.jetbrains.com/rider/[*JetBrains Rider*] -- a cross-platform .NET IDE with Visual Basic support.

== Editors with extensions

* https://code.visualstudio.com/[*Visual Studio Code*] -- a general-purpose editor that highlights Visual Basic files and works with the `dotnet` command line.

== Discontinued products

* *Visual Studio for Mac* -- retired by Microsoft; see https://learn.microsoft.com/en-us/visualstudio/mac/what-happened-to-vs-for-mac[What happened to Visual Studio for Mac] for the details and alternatives.
