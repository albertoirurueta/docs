This page lists the IDEs and editors most commonly used to write Java, with a link to each product's official page. A full IDE gives you incremental compilation, a debugger and refactoring out of the box, while an editor with extensions is lighter and suits small projects and quick edits.

== IDEs

* https://www.jetbrains.com/idea/[*IntelliJ IDEA*] -- JetBrains' IDE for Java and other JVM languages, with deep code analysis, refactoring and built-in Maven and Gradle support.
* https://eclipseide.org/[*Eclipse IDE*] -- the open source, plugin-based IDE with its own incremental Java compiler.
* https://netbeans.apache.org/[*Apache NetBeans*] -- the Apache Software Foundation's open source IDE, with first-class Maven and Gradle support.
* https://bluej.org/[*BlueJ*] -- a lightweight IDE designed for teaching and learning object-oriented Java.

== Editors with extensions

* https://marketplace.visualstudio.com/items?itemName=vscjava.vscode-java-pack[*VS Code Extension Pack for Java*] -- turns Visual Studio Code into a Java environment with language support, debugging, testing and project management.
