Welcome to the Java reference. https://dev.java/[Java] is a *statically-typed, class-based, object-oriented
language* -- it compiles to platform-neutral bytecode that runs on the Java Virtual Machine ("write once, run
anywhere"), favours explicit types and clear structure, and ships a large standard library. This section
documents the *current Java release line*, with *Java 25 LTS* as the reference point (no specific patch version
pinned), framework-agnostic (not Spring, Jakarta EE, or JavaFX), written and verified against
https://dev.java/[dev.java], the https://docs.oracle.com/javase/tutorial/[Java Tutorials], and the
https://docs.oracle.com/en/java/javase/25/docs/api/[Java SE 25 API specification].

If you are new to Java, read xref:programming-languages/java/getting-started.adoc[Getting Started] first, then the
*Language fundamentals* pages in order, followed by *Object-oriented programming* -- from there the remaining
groups (modern language features, the core library APIs, concurrency, modularity and tooling, and testing) can
be read in any order as you need them. For the sibling framework reference, see
xref:backend/springboot/index.adoc[SpringBoot Reference].

=== Language fundamentals

* xref:programming-languages/java/primitive-types-and-variables.adoc[Primitive Types & Variables] -- the eight primitives and
  their ranges, literals, `final` constants, `var` local-variable type inference, widening/narrowing
  conversions, and integer overflow.
* xref:programming-languages/java/operators-and-expressions.adoc[Operators & Expressions] -- arithmetic, relational, logical
  (short-circuit), bitwise and shift operators, the conditional operator, `instanceof`, and operator
  precedence.
* xref:programming-languages/java/strings-and-text.adoc[Strings & Text] -- `String` immutability and the string pool, `==`
  vs. `equals`, the common methods, `StringBuilder`, text blocks, and string formatting.
* xref:programming-languages/java/control-flow.adoc[Control Flow] -- `if`/`else`, the loop forms, `break`/`continue` and
  labels, `switch` statements, and arrow-form `switch` expressions.
* xref:programming-languages/java/arrays.adoc[Arrays] -- declaration and allocation, iteration, multidimensional and jagged
  arrays, `java.util.Arrays`, and varargs.

  interfaces, `Comparable` vs. `Comparator`, and default-method resolution.
* xref:programming-languages/java/records-and-sealed-classes.adoc[Records & Sealed Classes] -- record components and the
  compact constructor, generated members, and `sealed`/`permits`/`non-sealed` hierarchies.
* xref:programming-languages/java/enums.adoc[Enums] -- enum constants, fields and methods, constant-specific bodies, and

* xref:programming-languages/java/streams-and-collectors.adoc[Streams & Collectors] -- the lazy pipeline, the intermediate

* xref:programming-languages/java/functional-programming.adoc[Functional Programming] -- the `java.util.function` interfaces,
  composition, higher-order functions and currying, and refactoring imperative loops.
* xref:programming-languages/java/numbers-and-math.adoc[Numbers & Math] -- wrapper classes and autoboxing pitfalls, `Math`,

* xref:programming-languages/java/dates-and-times.adoc[Dates & Times] -- the `java.time` types, `Duration`/`Period`,

* xref:programming-languages/java/regular-expressions.adoc[Regular Expressions] -- `Pattern` and `Matcher`, groups and named
