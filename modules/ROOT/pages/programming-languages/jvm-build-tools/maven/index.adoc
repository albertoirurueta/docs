= Apache Maven
:description: Landing page for Apache Maven 3.10.0 -- what Maven is and is not, the support policy and the Java needed per line, the Maven 4.0.0-rc-7 release candidate, a recommended reading path and the list of every Maven page in this section grouped by topic.
:keywords: Maven, Apache Maven, Maven 3.10.0, Maven 3.9.16, Maven 4, Maven 4.0.0-rc-7, pom.xml, lifecycle, plugins, dependency management, JVM build tools, reading path

include::partial$jvm-build-tools-disclaimer.adoc[]

https://maven.apache.org/what-is-maven.html[Apache Maven] is a build, dependency management and project information tool.
A project describes itself in a Project Object Model (`pom.xml`): its coordinates (`groupId`, `artifactId`, `version`), its
dependencies, and the plugins that act on it. Maven applies conventions (sources in `src/main/java`, tests in `src/test/java`,
output in `target`) and a fixed build lifecycle made of phases such as `compile`, `test`, `package` and `deploy`; plugins attach
goals to those phases. Because the layout and the lifecycle are the same everywhere, a developer who knows one Maven project can
build another.

Maven is not a general scripting tool. Behaviour that does not fit the lifecycle is added by configuring or writing a plugin
rather than by writing build logic in the POM, and the project's own documentation states what Maven is and is not on its
https://maven.apache.org/what-is-maven.html[What is Maven?] page. The trade is the opposite of Ant's: less freedom in exchange
for a build that is short, declarative and familiar. The comparison with Ant and Gradle is on
xref:programming-languages/jvm-build-tools/comparing-ant-maven-and-gradle.adoc[Comparing Ant, Maven & Gradle].

== Release baseline

The pages in this subsection are written against these releases, checked on 2026-10-16, and every example marked as run was
executed on JDK 26:

[cols="2,2,3"]
|===
|Release |Status |Notes

|Maven 3.10.0
|Current stable (27 September 2026)
|Needs Java 8 or later to run.

|Maven 3.9.16
|Previous stable minor (13 May 2026)
|Still maintained. Where it differs from 3.10, the page says so.

|Maven 4.0.0-rc-7
|Release candidate (September 2026)
|Not a final release. It needs Java 17 or later to run and is covered in its own group of pages.
|===

Maven's support policy is that the last version of the last two series is supported, which today means 3.10.0 and 3.9.16 (see
the https://maven.apache.org/docs/history.html[release history]). The full table, the end-of-life lines and an upgrade
checklist from 3.9 to 3.10 are on
xref:programming-languages/jvm-build-tools/maven/versions-and-release-history.adoc[Maven: Versions & Release History].
