This page is the only place in the section that talks about tools and services built _around_ Ant, Maven and Gradle. It
describes each of them in one line, says whether it is maintained, and gives its official site and documentation. None of
them is documented further here. The section itself covers Apache Ant 1.10.18 (with Ivy 2.6.0 and the Maven Resolver Ant
Tasks 2.0.0), Apache Maven 3.10.0 (3.9.16 where it differs, and 4.0.0-rc-7, a release candidate) and Gradle 9.8.1 (8.14.6
where it differs). Every link below was requested on 2026-10-16 and answered; where an address now redirects to a new home,
the new address is the one shown. Nothing on the page is run: the tools are described from their own sites and release pages,
and the status cells are a snapshot of that day.

== How the page was assembled

* *Selection criterion.* A project is listed when the official Ant, Maven or Gradle documentation links to it, or when it is
  one of the most common plugins, services or tools in its area. The page does not rank projects and does not quote
  popularity statistics, download counts or star counts. The order inside a table groups related projects and is not a
  ranking.
* *Status.* The status cell says what the project's own release page, repository or site showed on 2026-10-16: the latest
  release (version and date) when the project publishes numbered releases, or "retired", "archived" or "moved" when the
  project says so itself. "Rolling" means the project publishes no numbered releases.
* *Third-party.* Everything except Apache Ant, Apache Maven, Gradle and their own sites and plugins is third-party. Third-party
  tools are not endorsed by this section, and each has its own license and support terms.
* *Examples.* The page contains no program. The only identifiers shown are the group and plugin coordinates that a project's
  own documentation shows.

three main tools side by side, and
xref:programming-languages/jvm-build-tools/migrating-between-tools.adoc[Migrating Between Tools] covers moving between them.

== Repository managers and Maven Central

tool-neutral explanation is on

xref:programming-languages/jvm-build-tools/maven/publishing-to-maven-central.adoc[Publishing to Maven Central].
