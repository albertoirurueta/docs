Welcome to the C reference. https://en.cppreference.com/w/c[C] is a *small, statically-typed, compiled systems
language*: a handful of built-in types, explicit control over memory, and a thin standard library that maps
closely onto what the machine and the operating system actually do. Designed by Dennis Ritchie at Bell Labs in
the early 1970s to write Unix, it has been an ISO standard since 1989 and remains the language whose ABI
virtually every other language uses to talk to the outside world. This section documents *C23 (ISO/IEC
9899:2024)*, written and verified against WG14's freely available working draft
https://www.open-std.org/jtc1/sc22/wg14/www/docs/n3220.pdf[N3220], and flags C23-only features together with
their C17/C11 fallbacks.

If you are new to C, read xref:programming-languages/c/getting-started.adoc[Getting Started] and
xref:programming-languages/c/program-structure.adoc[Program Structure] first, then the *Language fundamentals*
pages in order, followed by *Pointers and memory* -- those two groups are what C is. From there the remaining
groups (the preprocessor and generic programming, the standard library, robustness and performance,
concurrency, and tooling and standards) can be read in any order as you need them. Every code example in this
section compiles cleanly with `clang -std=c23 -Wall -Wextra`.

This site also documents {cpp}, which began as "C with Classes" and still shares C's declaration syntax, type
model and standard library -- while being neither a strict superset of C nor standardized by the same
committee. Each page below links to its nearest {cpp} counterpart under *See Also*; for the relationship in
one place, including a page-by-page map and the list of valid C that {cpp} rejects, see
xref:programming-languages/cpp/index.adoc#_c_and_cpp[C and {cpp}] on the
xref:programming-languages/cpp/index.adoc[{cpp} Reference] landing page.

=== Language fundamentals

* xref:programming-languages/c/lexical-structure-and-style.adoc[Lexical Structure and Style] -- character sets,

  the formatting conventions.

* xref:programming-languages/c/constants-enumerations-and-initialization.adoc[Constants, Enumerations and
  Initialization] -- `const`, `enum` with C23 fixed underlying types, macros vs. `constexpr`, compound

* xref:programming-languages/c/operators-and-expressions.adoc[Operators and Expressions] -- arithmetic,
  integer division, bitwise and shift operators, the precedence table, lvalues, and evaluation order and
  sequencing.
* xref:programming-languages/c/control-flow.adoc[Control Flow] -- `if`/`else`, `switch` and fall-through, the

* xref:programming-languages/c/arrays-and-strings.adoc[Arrays and Strings] -- array length and `sizeof`,
  multidimensional and variable-length arrays, array-to-pointer decay, string literals, and the `<string.h>`

* xref:programming-languages/c/structures-unions-and-type-aliases.adoc[Structures, Unions and Type Aliases] --

== Bibliography

* https://www.iso.org/standard/82075.html[ISO/IEC 9899:2024 -- Programming languages -- C] -- the published C23
  standard, and the normative reference for this section (the ISO text itself is a paid document).
* https://www.open-std.org/jtc1/sc22/wg14/www/docs/n3220.pdf[WG14 N3220 -- the C23 working draft] -- the
  freely available near-final draft, which WG14 documents as differing from the published standard only
  editorially. This is the document every page in this section was written and verified against.
* https://www.open-std.org/jtc1/sc22/wg14/[ISO/IEC JTC1/SC22/WG14] -- the C standards committee, and the
  source for its papers, defect reports and meeting documents.
* https://en.cppreference.com/w/c[cppreference.com -- C reference] -- the community reference used throughout
  to cross-check library signatures and semantics, together with its
  https://en.cppreference.com/w/c/23[C23 feature page].
* https://gcc.gnu.org/onlinedocs/gcc/[The GCC manual] and https://gcc.gnu.org/c99status.html[GCC's C standards
  status page] -- the primary sources for GCC-specific behavior, extensions and the C23 support matrix.
* https://clang.llvm.org/docs/UsersManual.html[The Clang User's Manual] and
  https://clang.llvm.org/c_status.html[Clang's C language status page] -- the same for Clang, which is the
  compiler used to verify every example here.
* https://www.gnu.org/software/libc/manual/[The GNU C Library Reference Manual] -- the primary source wherever
  a page discusses libc-specific behavior beyond what the standard specifies.
* Gustedt, Jens. _Modern C_, 3rd ed. Manning Publications, 2025. ISBN 9781633437777. Consulted as a reference
  while preparing these pages -- see https://www.manning.com/books/modern-c-third-edition[the publisher's book
  page], https://www.manning.com/[manning.com], and the author's freely available manuscript and code archive
  at https://gustedt.gitlabpages.inria.fr/modern-c/[gustedt.gitlabpages.inria.fr/modern-c].

The book above is a consulted reference, not the primary source for this section; on any discrepancy, or
wherever it is silent on a feature introduced after it was written, the official ISO/IEC 9899:2024 standard and
its N3220 working draft win.
