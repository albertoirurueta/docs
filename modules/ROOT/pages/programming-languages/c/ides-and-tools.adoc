This page lists the IDEs and editors most commonly used to write C, with a link to each product's official page. Most of them drive a compiler such as GCC, Clang or MSVC and a build system such as CMake or Make, so choose by platform and by how much integration you want.

== IDEs

* https://www.jetbrains.com/clion/[*CLion*] -- JetBrains' cross-platform IDE for C and C++, with CMake integration and a built-in debugger.
* https://visualstudio.microsoft.com/[*Visual Studio*] -- Microsoft's IDE for Windows, with the MSVC toolchain and a full debugger.
* https://projects.eclipse.org/projects/tools.cdt[*Eclipse CDT*] -- the C/C++ Development Tooling for the Eclipse IDE.
* https://www.qt.io/development/tools[*Qt Creator*] -- a cross-platform IDE with good CMake support, suited to C and C++ projects.
* https://www.codeblocks.org/[*Code::Blocks*] -- a free, lightweight, cross-platform IDE for C and C++.
* https://developer.apple.com/xcode/[*Xcode*] -- Apple's IDE for macOS and iOS development, with the Clang toolchain.

== Editors with extensions

* https://marketplace.visualstudio.com/items?itemName=ms-vscode.cpptools[*VS Code C/C++ extension*] -- adds IntelliSense, debugging and code navigation for C and C++ to Visual Studio Code.
