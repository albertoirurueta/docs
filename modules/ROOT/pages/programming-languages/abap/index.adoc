ABAP (Advanced Business Application Programming) is the programming language in which SAP writes its business software and the language in which customers and partners extend it. This section is a detailed reference for learning ABAP, from a first program and the classic reports that still run in many companies to ABAP Cloud, ABAP CDS and the ABAP RESTful Application Programming Model (RAP). No SAP knowledge is assumed: the first group of pages explains the programming ideas, the tools and the vocabulary, and the hands-on guides run on your own computer without an SAP system or an account.

ABAP comes in two flavors that the pages keep apart. Standard ABAP is the full language as it runs on an SAP S/4HANA on-premise or Private Edition system, including classic features such as reports, dynpros and `WRITE` output. ABAP for Cloud Development, used together with released APIs and called ABAP Cloud, is a smaller language set that can call only interfaces that SAP has released. A page that describes something available only in Standard ABAP says so near its start.

== Version baseline

|===
|Area |Baseline used on the pages

|Standard ABAP
|Release 8.16, as described in the release news of the ABAP Keyword Documentation for Standard ABAP.

|ABAP for Cloud Development
|Release 9.20 (2608), the ABAP release of the SAP BTP ABAP environment and of SAP S/4HANA Cloud Public Edition 2608. The documentation lists later releases as planned; the pages do not describe them.

|SAP S/4HANA
|2025 FPS02 on premise and Private Edition; Cloud Public Edition 2608.

|ABAP Development Tools (ADT)
|The Eclipse release that SAP recommends on its ADT update site at the time you install. The page xref:programming-languages/abap/adt-eclipse-setup.adoc[ABAP Development Tools (ADT)] shows where to read it.

|===

Where an individual page and this baseline ever disagree after a later update, the baseline is the one to trust. Books and articles written before release 7.40 (2013) describe an older style of ABAP; each page that touches a changed feature says what is different today, and xref:programming-languages/abap/obsolete-language-elements.adoc[Obsolete Language Elements] collects the elements that should no longer be used.

== Running example

Most pages use one small application, *Expense claims*, so that a reader meets the same objects again and again. All names are examples made for this site; they are not SAP-delivered objects.

[cols="2,3,3",options=header]
|===
|Piece |What it is |Where it is built

|`ZEXP_CLAIM`
|The claim header table: client, claim number, employee, status, currency, total amount and an included audit structure.
|xref:programming-languages/abap/ddic-tables-and-structures.adoc[Database Tables and Structures]

|`ZEXP_ITEM`
|The item table of a claim, linked to the header by a foreign key.
|xref:programming-languages/abap/ddic-foreign-keys-and-indexes.adoc[Foreign Keys, Check Tables and Indexes]

|Claim items in memory
|Internal tables filled with `VALUE`, read with table expressions and totalled with `REDUCE`.
|xref:programming-languages/abap/internal-tables.adoc[Internal Tables] and xref:programming-languages/abap/constructor-expressions.adoc[Constructor Expressions]

|`ZI_ExpClaim`
|The CDS interface view entity on the claim tables, with associations to the items.
|xref:programming-languages/abap/cds-view-entities.adoc[CDS View Entities] and xref:programming-languages/abap/cds-associations.adoc[CDS Associations and Compositions]

|`ZC_ExpClaim`
|The projection view with the annotations that a Fiori elements app reads.
|xref:programming-languages/abap/cds-annotations-and-metadata-extensions.adoc[CDS Annotations and Metadata Extensions] and xref:programming-languages/abap/rap-services-and-odata-v4.adoc[Projections, Service Definitions and OData V4 Bindings]

|Claim business object
|The behavior definition with the alias `Claim` and its behavior pool `zbp_i_expclaim`.
|xref:programming-languages/abap/rap-behavior-definitions.adoc[Behavior Definitions and Implementations]

|`ZSD_ExpClaim` and `ZUI_ExpClaim_O4`
|The service definition and the OData V4 service binding that publish the projection.
|xref:programming-languages/abap/rap-services-and-odata-v4.adoc[Projections, Service Definitions and OData V4 Bindings]
|===
