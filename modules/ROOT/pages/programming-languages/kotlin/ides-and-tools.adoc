This page lists the IDEs and editors most commonly used to write Kotlin, with a link to each product's official page. IntelliJ IDEA and Android Studio offer the most complete Kotlin support, since Kotlin is developed by JetBrains, while the editor-based options cover lighter workflows.

== IDEs

* https://www.jetbrains.com/idea/[*IntelliJ IDEA*] -- JetBrains' IDE, which bundles Kotlin support, refactoring and a Java-to-Kotlin converter.
* https://developer.android.com/studio[*Android Studio*] -- Google's official IDE for Android, built on the IntelliJ platform with Kotlin as the default language.
* https://marketplace.eclipse.org/content/kotlin-plugin-eclipse[*Eclipse Kotlin plugin*] -- adds Kotlin editing and compilation to the Eclipse IDE.

== Editors with extensions

* https://marketplace.visualstudio.com/items?itemName=fwcd.kotlin[*VS Code Kotlin extension*] -- Kotlin language support for Visual Studio Code, powered by a language server.
