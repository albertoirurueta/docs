This page lists the IDEs and editors most commonly used to write TypeScript, with a link to each product's official page. Most of them work with the same language tooling, so choose by how much built-in integration you want versus how light and fast you want the editor to be.

== IDEs

* https://www.jetbrains.com/webstorm/[*WebStorm*] -- JetBrains' IDE for JavaScript and TypeScript, with refactoring, debugging and framework support built in.

== Editors with extensions

* https://code.visualstudio.com/[*Visual Studio Code*] -- the most widely used editor for web development, extensible through a large extension marketplace.
* https://www.sublimetext.com/[*Sublime Text*] -- a fast, lightweight commercial text editor with a package ecosystem.
* https://zed.dev/[*Zed*] -- a fast, collaborative code editor with built-in language server support.
