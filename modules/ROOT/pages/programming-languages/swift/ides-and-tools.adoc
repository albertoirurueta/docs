= Swift IDEs & Tools
:description: The IDEs and editors commonly used for Swift development, grouped by category, including the discontinued AppCode.
:keywords: Swift, IDE, editor, tools, Xcode, VS Code, AppCode

include::partial$swift-disclaimer.adoc[]

This page lists the IDEs and editors commonly used to write and debug Swift code. Use Xcode for Apple-platform apps, and an editor with the Swift extension for cross-platform packages and server-side work.

== IDEs

* https://developer.apple.com/xcode/[*Xcode*] -- Apple's IDE, bundling a Swift toolchain, SwiftUI and UIKit previews, the debugger, Instruments and the simulators.

== Editors with extensions

* https://marketplace.visualstudio.com/items?itemName=swiftlang.swift-vscode[*VS Code Swift extension*] -- completion, diagnostics and debugging for Swift packages in Visual Studio Code, built on SourceKit-LSP.

== Discontinued products

* *AppCode* -- the JetBrains IDE for Swift and Objective-C is discontinued; Xcode is the recommended environment.
