Welcome to the Swift reference. https://www.swift.org/[Swift] is a *safe, fast and expressive* general-purpose
language built around value semantics, optionals that make the absence of a value explicit, protocol-oriented
design, and -- since Swift 6 -- a strict, compiler-enforced concurrency model built on structured concurrency
and actors. First released by Apple in 2014 and open-sourced in 2015, it reached ABI stability at Swift 5,
introduced the opt-in Swift 6 language mode's strict concurrency checking with Swift 6, and has kept growing
through 6.1-6.3 (`some` shorthand generics, typed throws, `InlineArray`/`Span`, integer generic parameters,
implicit conformances, default actor isolation, `package` access) with a 6.4 beta already previewing further
additions. It runs on Apple's platforms, Linux, Windows, WebAssembly, Android and in embedded contexts. This
section documents *the Swift 6 language mode as shipped by Swift 6.3 (6.3.2)*, written and verified against
https://docs.swift.org/swift-book/documentation/the-swift-programming-language/[The Swift Programming Language]
(TSPL); features introduced in 6.1-6.3 are labelled with the version that brought them, and *6.4-beta-only*
material appears only inside clearly marked subsections. Apple-only frameworks -- SwiftUI, UIKit, Combine,
CoreML, ARKit, Swift Charts -- are out of scope for a language reference; Foundation, Dispatch and XCTest
appear only where the language pages need them.

New here? Read xref:programming-languages/swift/getting-started.adoc[Getting Started] and
xref:programming-languages/swift/lexical-structure-and-style.adoc[Lexical Structure and Style] first, then the
rest of *Language fundamentals* in order, followed by *Types and object modelling* -- those three groups are
the language's core. From there the remaining groups (errors, safety and memory; concurrency; advanced language
features; the standard library and Foundation; interoperability; and tooling and testing) can be read in any
order as you need them. Every example in this section, 6.4-beta snippets excepted, is written and verified in
intent against the Swift 6.3 toolchain in Swift 6 language mode (`swiftc -swift-version 6` / `swift run`) on
macOS and Linux.

Working across languages? The xref:programming-languages/c/index.adoc[C Reference] and
xref:programming-languages/cpp/index.adoc[{cpp} Reference] cover the languages Swift interoperates with at the
lowest level through the Clang importer and `-cxx-interoperability-mode`, and the
xref:programming-languages/objective-c/index.adoc[Objective-C Reference] documents Apple's other native
language, whose frameworks and APIs Swift bridges to directly. Rather than repeating that material,
xref:programming-languages/swift/interoperability-with-c-objective-c-and-cpp.adoc[Interoperability with C,
Objective-C and {cpp}] cross-references all three.

=== Getting started

* xref:programming-languages/swift/getting-started.adoc[Getting Started] -- what Swift is, a short history from

=== Language fundamentals

* xref:programming-languages/swift/basics-constants-variables-and-types.adoc[Basics: Constants, Variables and
  Types] -- `let`/`var`, type annotations and inference, printing and interpolation, the integer and
  floating-point types, numeric literals and conversions, type aliases, `Bool`, tuples, and
  assertions/preconditions/`fatalError`.
* xref:programming-languages/swift/optionals.adoc[Optionals] -- `nil` and the `Optional` enum, optional binding,
  the nil-coalescing operator, forced unwrapping, implicitly unwrapped optionals, optional chaining, the
  optional pattern, and `map`/`flatMap` on optionals.
* xref:programming-languages/swift/operators.adoc[Operators] -- assignment, arithmetic, comparison, the ternary
  operator, nil-coalescing, ranges, logical operators and short-circuiting, and the full precedence table.
* xref:programming-languages/swift/strings-and-characters.adoc[Strings and Characters] -- string literals,
  value semantics, concatenation and interpolation, Unicode scalars versus extended grapheme clusters,
  `String.Index`, `Substring` and slicing, comparison, and the UTF-8/UTF-16/scalar views.
* xref:programming-languages/swift/collections.adoc[Collections] -- `Array`, `Set` and `Dictionary`, slices and
  ranges as collections, the `Sequence`/`Collection` protocol family, the higher-order essentials, `lazy`,
  `zip`, `stride`, and the Swift 6.2 `InlineArray` and `Span` types.
* xref:programming-languages/swift/control-flow.adoc[Control Flow] -- `for-in`, `while`/`repeat-while`,
  `if`/`switch` as statements and expressions, exhaustiveness and value binding, `continue`/`break`/
  `fallthrough`, `guard`, `defer`, and `#available`/`#unavailable`.
* xref:programming-languages/swift/pattern-matching.adoc[Pattern Matching] -- the eight pattern kinds and where
  each may appear, nested destructuring, custom `~=` overloads, and matching against ranges and regular
  expressions.
* xref:programming-languages/swift/functions.adoc[Functions] -- parameters and return values, argument labels,
  default and variadic parameters, `inout` and the copy-in copy-out model, `borrowing`/`consuming`, function
  types, nested functions, `@discardableResult`, and overloading.
* xref:programming-languages/swift/closures.adoc[Closures] -- closure expressions and shorthand syntax,
  trailing closures, capturing values, escaping versus non-escaping, autoclosures, capture lists, and
  `@Sendable` closures.

=== Types and object modelling

* xref:programming-languages/swift/enumerations.adoc[Enumerations] -- enum syntax and matching with `switch`,
  `CaseIterable`, associated values, raw values, recursive enums with `indirect`, `OptionSet`, and enums as
  state machines.
* xref:programming-languages/swift/structures-and-classes.adoc[Structures and Classes] -- definition syntax,
  memberwise initializers, value versus reference types, identity operators, copy-on-write, and noncopyable
  types (`~Copyable`).
* xref:programming-languages/swift/properties.adoc[Properties] -- stored and `lazy` properties, computed
  properties, property observers, property wrappers, type properties, and the `Observation` module's
  `@Observable`.
* xref:programming-languages/swift/methods-and-subscripts.adoc[Methods and Subscripts] -- instance and type
  methods, `mutating` methods, subscript syntax and variants, `callAsFunction`, and `@dynamicCallable`.
* xref:programming-languages/swift/inheritance.adoc[Inheritance] -- base classes, subclassing, overriding and
  `super`, `final`, dynamic dispatch and polymorphism, and when to subclass versus compose or use protocols.
* xref:programming-languages/swift/initialization-and-deinitialization.adoc[Initialization and
  Deinitialization] -- initializer parameters, default and memberwise initializers, designated versus
  convenience initializers, two-phase initialization, `required` and failable initializers, and `deinit`.
* xref:programming-languages/swift/extensions-and-nested-types.adoc[Extensions and Nested Types] -- extension
  syntax, adding computed properties/initializers/methods/subscripts, retroactive conformance, and nested
  types for namespacing.
* xref:programming-languages/swift/protocols.adoc[Protocols] -- requirements, protocols as types (`any P`),
  conformance via extensions and conditional conformance, synthesized conformances, protocol inheritance and
  composition, and protocol-oriented design.
* xref:programming-languages/swift/generics.adoc[Generics] -- generic functions and types, constraints,
  associated types, generic `where` clauses, integer generic parameters, and `some P` as lightweight
  generic-parameter syntax.
* xref:programming-languages/swift/opaque-and-boxed-protocol-types.adoc[Opaque and Boxed Protocol Types] --
  returning `some P`, boxed protocol (existential) types `any P` and their runtime cost, opaque parameter
  types, implicitly opened existentials, and choosing between `some`, `any` and explicit generics.
* xref:programming-languages/swift/type-casting-and-reflection.adoc[Type Casting and Reflection] -- `is`,
  `as?`, `as!`, `Any` versus `AnyObject`, metatypes, bridging casts to Foundation types, and reflection with
  `Mirror`.

=== Errors, safety and memory

* xref:programming-languages/swift/error-handling.adoc[Error Handling] -- the `Error` protocol, `throw`, the
  four ways to handle errors, typed throws, `rethrows`, `Result<Success, Failure>`, and `defer`.
* xref:programming-languages/swift/automatic-reference-counting.adoc[Automatic Reference Counting] -- how ARC
  works, strong reference cycles between class instances and in closures, resolving them with `weak` and
  `unowned`, and diagnosing leaks.
* xref:programming-languages/swift/memory-safety-and-unsafe-pointers.adoc[Memory Safety and Unsafe Pointers] --
  the exclusivity rules for `inout` parameters and mutating methods, and the unsafe pointer layer together with
  the safe non-owning `Span`/`RawSpan` alternatives.
* xref:programming-languages/swift/access-control.adoc[Access Control] -- the six access levels, the guiding
  principle and defaults, and access levels for custom types, properties, initializers, protocols and generics.

=== Concurrency
