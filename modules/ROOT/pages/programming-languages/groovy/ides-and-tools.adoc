This page lists the IDEs and editors commonly used for Groovy, with a link to each product's official page. Groovy runs on the JVM, so the Java IDEs are the natural choice, while an editor with Groovy support is enough for scripts.

== IDEs

* https://www.jetbrains.com/idea/[*IntelliJ IDEA*] -- the JetBrains IDE, with Groovy support for highlighting, completion and refactoring.
* https://github.com/groovy/groovy-eclipse[*Groovy-Eclipse*] -- the Groovy plugin for the Eclipse IDE.
* https://netbeans.apache.org/[*Apache NetBeans*] -- an open-source IDE with Groovy support.

== Editors with extensions

* https://code.visualstudio.com/[*Visual Studio Code*] -- a general-purpose editor with Groovy extensions.

== Tools

* https://groovy-lang.org/[*Apache Groovy*] -- the language's official site, with downloads, documentation and the IDE integration overview.
