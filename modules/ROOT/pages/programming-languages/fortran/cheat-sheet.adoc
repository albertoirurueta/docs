A single-page, colour-coded summary of modern Fortran and its toolchain, written against Fortran 2023 (ISO/IEC 1539-1:2023, J3/23-007r1; checked 2026-10-19 with GNU Fortran 16.2 and LLVM Flang 23) -- the toolchain map with the strict and debug flags and an `fpm.toml` skeleton, the program skeleton and free-form rules, the five intrinsic types with kinds and the numeric model, operators and precedence, control flow with `do concurrent`, procedures with `intent`, `optional`, `pure` and `elemental`, arrays (declarations, sections, constructors, `where`, reductions, column-major order, `allocate` and `move_alloc`), strings, derived types and object-oriented programming, pointers, input/output with the main edit descriptors and namelist, the intrinsic modules, coarrays, OpenMP and MPI, interoperability one-liners for C, f2py and MEX, best practices and gotchas, and a strip of legacy features and their modern replacements -- handy for quick memorization or as a xref:attachment$fortran-cheat-sheet.pdf[downloadable PDF] desk reference.
