This page lists the IDEs, editors and tools commonly used for Fortran, with a link to each product's official page. Fortran sources are plain text, so any editor works; an editor with a Fortran language-server extension is the common lightweight choice.

== IDEs

* https://projects.eclipse.org/projects/tools.photran[*Eclipse Photran*] -- the Fortran development tools for the Eclipse IDE.

== Editors with extensions

* https://marketplace.visualstudio.com/items?itemName=fortran-lang.linter-gfortran[*Modern Fortran for VS Code*] -- the extension with linting, language-server features and debugging support for Fortran.

== Compilers and build tools

* https://www.intel.com/content/www/us/en/developer/tools/oneapi/oneapi-toolkit.html[*Intel oneAPI toolkits*] -- Intel's toolkits, which include the ifx Fortran compiler and performance tools.
* https://fpm.fortran-lang.org/[*fpm*] -- the Fortran Package Manager and build tool.
