== What Ruby is

Ruby is a dynamic, interpreted, garbage-collected and purely object-oriented language designed by Yukihiro "Matz" Matsumoto, who released it in 1995 with the goal of programmer happiness. Every value is an object, blocks and mixins replace most inheritance hierarchies and callbacks, classes are open, and metaprogramming is a normal tool rather than a trick. The reference implementation, CRuby, parses source with Prism, compiles it to YARV bytecode, runs it on a virtual machine with a global VM lock, and can compile hot methods to machine code with YJIT or the newer ZJIT. Around the language sit the `ruby`, `irb`, `ri`, `gem`, `bundle` and `rake` commands, a large standard library split into default and bundled gems, and a package ecosystem on RubyGems. Ruby powers web back ends, scripts and automation, and developer tools such as Homebrew, CocoaPods and fastlane.

== The shelf scenario

The examples across the section share one small, original domain: *shelf*, a Ruby gem for a library catalogue. It is deliberately the same domain as the xref:programming-languages/rust/index.adoc[Rust Reference] and the xref:programming-languages/go/index.adoc[Go Reference], so you can compare the languages on the same types.

* The `Shelf` namespace holds `Book`, `Author`, `Isbn` (a validated value object), `Loan` and loan states, a catalogue interface with an in-memory implementation, and domain errors under `Shelf::Error`.
* `exe/shelf` is a command-line program that searches, lends and returns books and imports and exports JSON.
* A gemspec, a `Gemfile`, a `Rakefile`, Minitest and RSpec tests, RBS signatures and a RuboCop configuration grow alongside the code.

The pages build on each other, and the xref:programming-languages/ruby/cheat-sheet.adoc[cheat sheet] summarises them.

== The shelf gem source

These listings are the whole library that the examples load with `require "shelf"`. To run an example, recreate the gem:

. Make a `shelf` directory and save each listing below in it, at the path in the listing's title (`lib/shelf/isbn.rb` goes in `shelf/lib/shelf/`).
. Save the example in the same `shelf` directory, for instance as `example.rb`.
. From that directory, run `ruby -Ilib example.rb` (add `-w` to see warnings, as the pages do). `-Ilib` puts `lib/` on the load path, so `require "shelf"` loads `lib/shelf.rb`, which loads the rest.

The library needs only Ruby 4.0 and its standard library; nothing has to be installed to run the examples. The gemspec and the `Gemfile` are needed only for `bundle install`, the tests, RuboCop and building the gem, and the gemspec also lists the `exe/shelf` command shown in xref:programming-languages/ruby/getting-started.adoc#_the_shelf_scenario[Getting Started]. Examples that reopen one of these classes, or that define classes of their own, run unchanged on top of it. xref:programming-languages/ruby/application-architecture-in-plain-ruby.adoc[Application Architecture in Plain Ruby] and xref:programming-languages/ruby/command-line-programs.adoc[Command-Line Programs] add further files under `lib/shelf/`, and each page shows them.

=== Entry point and version

`lib/shelf.rb` loads every file of the library, defines the `Shelf::Error` base class and holds the global configuration (a store and a loan period). `lib/shelf/version.rb` is a file of its own so that the gemspec can read the version without loading the library.

[source,ruby]
.lib/shelf.rb
----
# frozen_string_literal: true

require_relative "shelf/version"
require_relative "shelf/isbn"
require_relative "shelf/author"
require_relative "shelf/book"
require_relative "shelf/loan"
require_relative "shelf/store/memory"
require_relative "shelf/catalog"
require_relative "shelf/refinements/title_case"

# A small library catalogue used as the running example.
module Shelf
  class Error < StandardError; end

  Config = Struct.new(:store, :loan_days)

  def self.config
    @config ||= Config.new(Store::Memory.new, 14)
  end

  def self.configure
    yield config
    config
  end
end
----

=== Value objects

`Isbn`, `Author` and `Book` are immutable `Data` classes. `Isbn` removes hyphens and checks the ISBN-13 check digit in `initialize`, so an invalid ISBN never exists. All three accept positional or keyword arguments (`Shelf::Isbn.new("978-0-306-40615-7")` or `Shelf::Isbn.new(digits: "9780306406157")`).

[source,ruby]
.lib/shelf/isbn.rb
----
# frozen_string_literal: true

module Shelf
  # An ISBN-13 value object.
  Isbn = Data.define(:digits) do
    def initialize(digits:)
      cleaned = digits.to_s.delete("-")
      raise ArgumentError, "invalid ISBN: #{digits}" unless valid?(cleaned)

      super(digits: cleaned)
    end

    def to_s = digits

    private

    def valid?(value)
      return false unless value.match?(/\A\d{13}\z/)

      sum = value.chars.map(&:to_i).each_with_index.sum { |d, i| i.even? ? d : d * 3 }
      (sum % 10).zero?
    end
  end
end
----

[source,ruby]
.lib/shelf/author.rb
----

module Shelf

end
----

=== Loans

A `Loan` pairs a book with one of four states and describes itself with a `case`/`in` pattern match.

[source,ruby]
.lib/shelf/loan.rb
----
# frozen_string_literal: true

module Shelf
  # A loan of a book, with a state driven by pattern matching.
  class Loan
    STATES = %i[available lent overdue returned].freeze

    attr_reader :book, :state

    def initialize(book, state: :available)
      raise ArgumentError, "unknown state: #{state}" unless STATES.include?(state)

      @book = book
      @state = state
    end

    def describe
      case { state:, book: }
      in { state: :available } then "#{book.title} is on the shelf"
      in { state: :lent | :overdue => s } then "#{book.title} is #{s}"
      in { state: :returned } then "#{book.title} came back"
      end
    end
  end
end
----

Source: https://docs.ruby-lang.org/en/4.0/syntax/pattern_matching_rdoc.html[Ruby 4.0 documentation: Pattern matching]

=== Catalogue and store

`Catalog` is `Enumerable` over the books of a store and guards the store with a mutex. A store is any object with `all` and `add`; `Store::Memory`, an array in memory, is the default one, taken from `Shelf.config`.

[source,ruby]
.lib/shelf/catalog.rb
----
# frozen_string_literal: true

module Shelf
  # The catalogue, guarded by a mutex.
  class Catalog
    include Enumerable

    def initialize(store: Shelf.config.store)
      @store = store
      @mutex = Thread::Mutex.new
    end

    def add(book)
      @mutex.synchronize { @store.add(book) }
      self
    end

    def each(&)
      return enum_for(:each) unless block_given?

      @mutex.synchronize { @store.all }.each(&)
    end
  end
end
----

[source,ruby]
.lib/shelf/store/memory.rb
----
# frozen_string_literal: true

module Shelf
  module Store
    # In-memory adapter, duck-typed with #all and #add.
    class Memory
      def initialize = @books = []

      def all = @books.dup

      def add(book)
        @books << book
        self
      end
    end
  end
end
----

Source: https://docs.ruby-lang.org/en/4.0/Enumerable.html[Ruby 4.0 documentation: Enumerable] and https://docs.ruby-lang.org/en/4.0/Thread/Mutex.html[Thread::Mutex]

=== Refinement

The gem ships one refinement, `String#title_case`, which is active only in files that say `using Shelf::Refinements::TitleCase`.

[source,ruby]
.lib/shelf/refinements/title_case.rb
----
# frozen_string_literal: true

module Shelf
  module Refinements
    # Refines String instead of monkey patching it.
    module TitleCase
      refine String do
        def title_case = split.map(&:capitalize).join(" ")
      end
    end
  end
end
----

Source: https://docs.ruby-lang.org/en/4.0/syntax/refinements_rdoc.html[Ruby 4.0 documentation: Refinements]

Ruby on Rails is out of scope for this section: it covers the Ruby language, core classes and standard library, and plain-Ruby application design (see xref:programming-languages/ruby/application-architecture-in-plain-ruby.adoc[Application Architecture in Plain Ruby]), without any framework.
