This page lists the IDEs and editors commonly used to write Ruby, with a link to each product's official page. Ruby needs no IDE: a plain editor and a terminal are enough, so choose a full IDE for integrated refactoring and debugging, or an editor with the Ruby LSP language server for a lighter setup.

== IDEs

* https://www.jetbrains.com/ruby/[*RubyMine*] -- the JetBrains IDE for Ruby and Rails, with code insight, refactoring, a debugger and test runners.

== Editors with extensions

* https://code.visualstudio.com/[*Visual Studio Code*] -- a general-purpose editor that becomes a Ruby environment with the Ruby LSP extension.
* https://marketplace.visualstudio.com/items?itemName=Shopify.ruby-lsp[*Ruby LSP for VS Code*] -- the extension for the Ruby LSP language server, adding completion, navigation, diagnostics and formatting.
* https://zed.dev/[*Zed*] -- a fast editor with built-in Ruby support through language servers.
* https://neovim.io/[*Neovim*] -- a terminal editor that talks to Ruby language servers through its LSP client.
