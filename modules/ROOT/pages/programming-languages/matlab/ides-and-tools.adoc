This page lists the environments commonly used to write and run MATLAB code. Use the desktop for full local work, MATLAB Online for a zero-install start, and the VS Code extension if you prefer that editor.

== IDEs

* https://www.mathworks.com/products/matlab.html[*MATLAB Desktop*] -- the standard environment, with the editor, Command Window, workspace browser and debugger.
* https://www.mathworks.com/products/matlab/live-editor.html[*Live Editor*] -- an interactive document format that combines code, output and formatted text.

== Editors with extensions

* https://marketplace.visualstudio.com/items?itemName=MathWorks.language-matlab[*VS Code MATLAB extension*] -- syntax highlighting, navigation and code analysis for MATLAB files in Visual Studio Code.

== Online and notebook tools

* https://www.mathworks.com/products/matlab-online.html[*MATLAB Online*] -- MATLAB in a web browser, with nothing to install.
