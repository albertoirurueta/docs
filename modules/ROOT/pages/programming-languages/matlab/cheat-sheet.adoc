A single-page, colour-coded summary of MATLAB, written against MATLAB R2026b (announced 2026-09-28) and checked on 2026-10-22, when the release notes listed no newer release -- the environment commands (`help`, `doc`, `which -all`, `whos`, `clear`, `format`, `save` and `load`, `addpath`, `startup.m` and `matlab -batch`), syntax (comments, continuation, sections, command and function syntax), arrays and a column-major diagram, an indexing grid for `()`, `+{}+` and `.` across arrays, cells, structures and tables, operators with the precedence ladder and the implicit-expansion rules, the table of types (`double` to `uint64`, `logical`, `char`, `string`, `cell`, `struct`, `table`, `timetable`, `datetime`, `categorical`, `dictionary`), text and regular expressions, control flow, functions (local, nested and anonymous, `arguments` blocks with validators and `Name=Value`), errors and `onCleanup`, `classdef` (value and handle classes, events, enumerations, namespaces), graphics, data input and output, the core mathematics (linear algebra, `sparse`, polynomials, `integral`, `ode45`, `fft`), performance, testing and `buildtool`, Python, C and Java interfaces, live scripts, App Designer, projects and the package manager, and a strip of what changed from older tutorials to R2026b -- handy for quick memorization or as a xref:attachment$matlab-cheat-sheet.pdf[downloadable PDF] desk reference.
