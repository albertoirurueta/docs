== What an add-on product is

MATLAB is sold as the base product plus a large family of separately licensed products. Most of them are called *toolboxes* (Statistics and Machine Learning Toolbox, Signal Processing Toolbox); a few have other names (Simulink, Stateflow, Simscape, MATLAB Compiler, MATLAB Coder). They install on top of MATLAB, add functions, classes, apps and Simulink blocks, and need a licence per product. Base MATLAB neither contains them nor lists them as errors: a call to a function that belongs to a product you do not have fails with an "undefined function" error, or with a licence-checkout error when the product is installed but not licensed.

Why the section does not document them: a toolbox is a product with its own documentation, versioning and licence, and MathWorks maintains that documentation. Teaching the language does not need it. Where an example in this section could be written more easily with a toolbox function, the page uses the base function and says so in prose.

=== The word "toolbox" has two meanings

[cols="1,3",options="header"]
|===
|Meaning |Notes

|A MathWorks add-on *product*
|Statistics and Machine Learning Toolbox, Deep Learning Toolbox and so on. This is what this page lists. The word has not changed.

|A shareable bundle of *user* code (a `.mltbx` file)
|Called a toolbox file before R2026b. Since R2026b the documentation calls such files *package files*, and the bundles *packages*. See xref:programming-languages/matlab/index.adoc#_package_and_toolbox[the package and toolbox table] and xref:programming-languages/matlab/packages-and-the-matlab-package-manager.adoc[Packages and the MATLAB Package Manager].
|===

So "install a toolbox" can mean two different things. Installing the product is done with the installer or the Add-On Explorer; installing a package of shared code is done with `mpminstall` or from File Exchange.

== Listing what is installed

[source,matlab]
----
ver                                  % MATLAB, Simulink and every installed product, with versions
v = ver("matlab");                   % version information for one product
addons = matlab.addons.installedAddons   % a table of installed add-ons
----

`ver` prints the release and the installed products. `matlab.addons.installedAddons` returns a table with one row for each installed add-on; its reference page is the place to check the columns your release returns. These commands were not run here: R2026b is not installed on the machine that produced these pages, and Octave 11.3.0 has no `matlab.addons` namespace.

Source: https://www.mathworks.com/help/matlab/ref/ver.html[MATLAB documentation: ver], https://www.mathworks.com/help/matlab/ref/matlab.addons.installedaddons.html[MATLAB documentation: matlab.addons.installedAddons]

== Getting products and packages

* *The installer and the Add-On Explorer.* Products are installed with the MathWorks installer; the Add-On Explorer, opened from the desktop, installs add-ons, support packages and packages from File Exchange and other sources. It is described in https://www.mathworks.com/help/matlab/add-ons.html[Add-Ons].
* *`mpminstall`.* Installs a MATLAB Package Manager package from a folder or from a repository. Since R2026b File Exchange is a default package repository. Packages are shared user code, not MathWorks products.
* *File Exchange.* The community repository at https://www.mathworks.com/matlabcentral/fileexchange/[mathworks.com/matlabcentral/fileexchange]. Its contents are contributed by users and are not checked by MathWorks; read the licence and the code before using it.
* *MATLAB Online.* https://www.mathworks.com/products/matlab-online.html[MATLAB Online] runs MATLAB in a browser with a set of products available, depending on the licence.

Source: https://www.mathworks.com/help/matlab/add-ons.html[MATLAB documentation: Add-Ons]

== Popular products

The table below is the "popular products" list. The selection criterion is stated plainly: the products that are featured on MathWorks' https://www.mathworks.com/products.html[products page] and that appear most often among the tags of questions on MATLAB Answers. No download or usage figures are given, and none were measured; "popular" is an editorial grouping, not a ranking. The full list is on the products page, and it is longer than this one.

Each row has the product name, a one-line description written for this page, the official product page (`https://www.mathworks.com/products/<name>.html`) and the documentation hub (`https://www.mathworks.com/help/<short>/`). Product page and documentation names do not always match (the System Identification Toolbox page is `sysid` and its documentation `ident`), so the links were each opened, not derived.

== Renames and new products

Some names in older material have changed or may mislead.

* *OPC Toolbox is now the Industrial Communication Toolbox.* The rename is reported as having happened in R2022a; this was not re-checked against the release notes. The product page is served at https://www.mathworks.com/products/industrial-communication.html and also at the older address https://www.mathworks.com/products/opc.html.
* *Lidar Toolbox is now served as Point Cloud Toolbox.* The page https://www.mathworks.com/products/lidar.html, whose address still says lidar, is titled "Point Cloud Toolbox", and so is the documentation at https://www.mathworks.com/help/lidar/. Whether this is a rename of the product or a change in the product line is not stated on the pages; if a release note matters to you, check it.
* *New products.* The page https://www.mathworks.com/products/new_products/latest_features.html[R2026b - Updates to the MATLAB and Simulink product families] lists the Visual Inspection Toolbox (https://www.mathworks.com/products/visual-inspection.html[product page], https://www.mathworks.com/help/visual-inspection/[documentation]) and the Simulink Variant Manager (https://www.mathworks.com/products/simulink-variant-manager.html[product page], https://www.mathworks.com/help/simulink-variant-manager/[documentation]) among the additions. They are mentioned here for completeness and are not in the table.
* *MATLAB Copilot* (R2025a) is an assistant sold separately; it is a product, not a language feature.

== Free alternatives

GNU Octave has its own package system, separate from MATLAB's add-ons: the `pkg` command and the packages published at https://packages.octave.org/[packages.octave.org] (Octave Forge). They cover some of the same ground as the toolboxes (signal processing, statistics, image processing, optimisation) with different function names and behaviour. This is third-party software, unrelated to MathWorks; see xref:programming-languages/matlab/gnu-octave-compatibility.adoc[GNU Octave Compatibility]. Within MATLAB, File Exchange and the MATLAB Package Manager give access to community code in a different way.

== Pitfalls

* *Assuming a function is in base MATLAB.* The documentation hub that holds the function's reference page names the product it belongs to, and `which -all name` shows the file that MATLAB would run. If the name is not found, you may not have the product.
* *Reading examples from the web that use a toolbox without saying so.* The examples in this section need only base MATLAB.
* *Treating File Exchange as a MathWorks product.* It is user-contributed.
* *Mixing the two senses of "toolbox"* (see above).

== Where older books differ

The older books predate most of the current product line, so any product list in them is out of date, and their names for products have changed (see the renames above). The mathematics volume mentions symbolic mathematics as if it came from Maple, which has not been true since R2008b; today symbolic computation is the Symbolic Math Toolbox, a separate product, and is outside this section.
