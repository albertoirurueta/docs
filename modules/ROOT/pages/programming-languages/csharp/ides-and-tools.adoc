This page lists the IDEs and editors most commonly used to write C#, with a link to each product's official page. They all build on the same compiler and analyzers, so choose by platform and by how much tooling you want around debugging, refactoring and profiling.

== IDEs

* https://visualstudio.microsoft.com/[*Visual Studio*] -- Microsoft's full-featured IDE for Windows, with designers, profilers and deep debugging.
* https://www.jetbrains.com/rider/[*JetBrains Rider*] -- JetBrains' cross-platform .NET IDE, with strong refactoring and its own analysis engine.

== Editors with extensions

* https://marketplace.visualstudio.com/items?itemName=ms-dotnettools.csdevkit[*VS Code C# Dev Kit*] -- adds solution management, testing and debugging for C# to Visual Studio Code on any platform.

== Discontinued products

* *Visual Studio for Mac* -- retired by Microsoft; see https://learn.microsoft.com/en-us/visualstudio/mac/what-happened-to-vs-for-mac[what happened to Visual Studio for Mac] for the details and the recommended alternatives.
