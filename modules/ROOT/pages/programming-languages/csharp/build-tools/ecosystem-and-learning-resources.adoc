This is the only page of the section about tools that are not part of MSBuild, the .NET SDK or NuGet. Each entry has a
one-line description, its official site and documentation, and at most a one-line install command; none is documented
further here. Three of them appear in one worked example each elsewhere, because the pages that use them need a concrete
tool: MinVer and Nerdbank.GitVersioning on
xref:programming-languages/csharp/build-tools/publishing/versioning-and-prerelease-packages.adoc[Versioning and Prerelease Packages],
and BaGetter (the local feed server used throughout the publishing examples) on
xref:programming-languages/csharp/build-tools/publishing/private-feeds.adoc[Private Feeds].

**Selection criterion.** A project is listed if it had a release in the 12 months before 2026-10-23, or is a Microsoft or
dotnet-organisation project. Entries marked *third-party* are maintained outside Microsoft. Versions and dates were
checked on 2026-10-23 against nuget.org, the projects' repositories and Docker Hub.

== Build orchestration in C#

Scripts that drive `dotnet` commands with C# or F# code instead of shell or YAML. They do not replace MSBuild; they call it.

[cols="1,3,2,2",options="header"]
|===
| Project | What it is | Links | Install

| Cake (third-party)
| A cross-platform build automation system with a C# DSL; 6.3.0 (2026-09-14).
| https://cakebuild.net/[cakebuild.net], https://cakebuild.net/docs/[documentation]
| `dotnet tool install Cake.Tool`

| NUKE (third-party)
| A build system where the build is a C# console project with typed targets and CI generation; 10.1.0 (2025-12-02).
| https://nuke.build/[nuke.build] (site not re-verified from this environment), https://www.nuget.org/packages/Nuke.Common[Nuke.Common on nuget.org]
| `dotnet tool install Nuke.GlobalTool --global`

| FAKE (third-party)
| "F# Make", a build automation system with an F# DSL; fake-cli 6.2.0 (2026-10-11).
| https://fake.build/[fake.build], https://fake.build/guide/getting-started.html[getting started]
| `dotnet tool install fake-cli`

| Bullseye (third-party)
| A small .NET library for describing and running a target dependency graph from a console app; 6.3.0 (2026-10-05).
| https://github.com/adamralph/bullseye[GitHub repository and README]
| `dotnet package add Bullseye`
|===

== MSBuild SDKs and helpers

[cols="1,3,2,2",options="header"]
|===
| Project | What it is | Links | Install

| microsoft/MSBuildSdks (Microsoft)
| A collection of MSBuild project SDKs: Traversal (4.1.82) to build a tree of projects from one `.proj`, NoTargets
(3.7.134) for projects that compile nothing, CentralPackageVersions (superseded by NuGet's Central Package Management)
and others.
| https://github.com/microsoft/MSBuildSdks[GitHub repository]
| `<Project Sdk="Microsoft.Build.Traversal/4.1.82">`

| MSBuild Structured Log Viewer (third-party)
| A viewer for MSBuild binary logs (`.binlog`): search, timeline, property and item history; v2.3.246 (2026-08-20).
Its site warns that a binary log exposes every environment variable of the build machine.
| https://msbuildlog.com/[msbuildlog.com] (download and instructions for Windows and Mac)
| download from the site
|===

== Versioning

Tools that compute the package version from Git, so it is never edited by hand.

[cols="1,3,2,2",options="header"]
|===
| Project | What it is | Links | Install

| MinVer (third-party)
| Sets `Version` from the latest Git tag and the height since it; 8.0.0 stable (8.1.0-alpha.1 on 2026-09-29).
| https://github.com/adamralph/minver[GitHub repository and README]
| `dotnet package add MinVer`

| Nerdbank.GitVersioning (dotnet organisation)
| Versions from a `version.json` plus the Git height; 3.10.94 stable (2026-08-28), 3.11 in beta.
| https://github.com/dotnet/Nerdbank.GitVersioning[GitHub repository and documentation]
| `dotnet tool install nbgv`

| GitVersion (third-party)
| Semantic versions from the branch model (GitFlow, GitHub Flow, trunk-based); 6.8.2 (2026-07-10).
| https://gitversion.net/[gitversion.net], https://gitversion.net/docs/[documentation]
| `dotnet tool install GitVersion.Tool`
|===

== Feeds and servers

Self-hosted servers and hosted services that speak the NuGet protocol. The hosted products are those listed on the NuGet
documentation's hosting overview, with their own NuGet documentation; AWS CodeArtifact, which the overview does not list,
is included because it is a common choice.

[cols="1,3,2,2",options="header"]
|===
| Project | What it is | Links | Install

| BaGetter (third-party)
| A lightweight, open-source NuGet and symbol server (a maintained fork of BaGet); 1.6.5 (2025-12-07). The local feed in
this section's publishing examples.
| https://www.bagetter.com/[bagetter.com], https://www.bagetter.com/docs[documentation], https://github.com/bagetter/BaGetter[GitHub]
| `docker run -p 5555:8080 bagetter/bagetter:1.6.5`

| Sleet (third-party)
| A static NuGet feed generator for file shares, Azure Storage and Amazon S3, with no server process; 7.2.0
(2026-07-13).

== Package inspection and quality

[cols="1,3,2,2",options="header"]
|===
| Project | What it is | Links | Install

| NuGet Package Explorer (third-party)
| A desktop app (and web viewer) to open a `.nupkg`, inspect its files, metadata, symbols and Source Link status;
v7.0.7 (2025-12-17).
| https://github.com/NuGetPackageExplorer/NuGetPackageExplorer[GitHub repository]
| from the Microsoft Store or the repository's releases

| dotnet-validate (third-party)
| A tool that checks a package for the nuget.org quality signals (Source Link, deterministic build, symbols); still
`0.0.1-preview` (0.0.1-preview.582, 2026-02-12).
| https://www.nuget.org/packages/dotnet-validate[dotnet-validate on nuget.org]
| `dotnet tool install dotnet-validate --version 0.0.1-preview.582`

| dotnet-outdated (third-party)
| Reports (and optionally upgrades) outdated package references; 4.8.1 (2026-06-11).
| https://github.com/dotnet-outdated/dotnet-outdated[GitHub repository and README]
| `dotnet tool install dotnet-outdated-tool`

| sign (dotnet organisation)
| Microsoft's code-signing tool for packages and binaries with cloud-held keys (Azure Key Vault, Trusted Signing); still a
beta, 0.9.1-beta.26475.3 (2026-09-26). The `sign` ID's version list also shows unlisted 1.x versions from another
author; use the registration API or the repository to see the real releases.
| https://github.com/dotnet/sign[GitHub repository]
| `dotnet tool install sign --version 0.9.1-beta.26475.3`
|===

== IDEs

All three build with MSBuild and the installed SDK
(xref:programming-languages/csharp/build-tools/how-a-dotnet-build-works.adoc#_ides_drive_the_same_pipeline[How a .NET Build Works]).

[cols="1,3,2",options="header"]
|===
| IDE | Build integration | Links

| Visual Studio 2026 (Microsoft)
| Runs its own .NET Framework MSBuild (18.11 in 18.11.1) and a NuGet client that can be newer than the SDK's (NuGet 7.10
shipped only in Visual Studio 18.10); Package Manager UI and Console; design-time builds for IntelliSense.
| https://visualstudio.microsoft.com/vs/[visualstudio.microsoft.com]

| JetBrains Rider (third-party)
| Uses the installed .NET SDK's MSBuild (or a chosen `msbuild.exe`); its own NuGet tool window.
| https://www.jetbrains.com/rider/[jetbrains.com/rider]

| VS Code with C# Dev Kit (Microsoft)
| Solution Explorer and test integration on top of the `dotnet` CLI and MSBuild.
| https://code.visualstudio.com/docs/csharp/get-started[Getting started with C# in VS Code]
|===
