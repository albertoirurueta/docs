= SDK MSBuild Properties Reference
:description: A curated, grouped reference of the .NET SDK MSBuild properties and items with their defaults as evaluated on .NET SDK 10.0.402 -- framework, build and compiler (Nullable, LangVersion, Deterministic, ContinuousIntegrationBuild, GenerateDocumentationFile, EnablePreviewFeatures), default item inclusion, code analysis, references (ManagePackageVersionsCentrally, DisableTransitiveProjectReferences), restore and NuGet audit, run, SDK, testing (MTP and VSTest), generated files, publish, trimming, runtime configuration, package and package validation, and the PackageReference, FrameworkReference, Using, InternalsVisibleTo and AssemblyMetadata items -- each linked to its documentation anchor.

include::partial$csharp-build-tools-disclaimer.adoc[]

The .NET SDK reads hundreds of MSBuild properties; this page lists the ones a project or `Directory.Build.props`
typically sets, grouped as in the official reference, each with its **default** and a link to its documentation. The
defaults in the tables were read with `dotnet msbuild -getProperty:…` from a fresh `dotnet new console` project
targeting `net10.0` with **.NET SDK 10.0.402** (Debug unless noted); "(empty)" means the property is not set and the SDK
behaves as described. Properties of the C# compiler are documented with the compiler options, not on the SDK page; they
are linked there.

[source,bash]
----
dotnet msbuild -getProperty:LangVersion -getProperty:Deterministic -getProperty:NuGetAuditMode -getProperty:PublishRelease
----

[source,text]
----
{
  "Properties": {
    "LangVersion": "14.0",
    "Deterministic": "true",
    "NuGetAuditMode": "all",
    "PublishRelease": "true"
  }
}
----

Source: https://learn.microsoft.com/en-us/dotnet/core/project-sdk/msbuild-props[MSBuild reference for .NET SDK projects].

== Common mistakes

* *Believing `Nullable` and `ImplicitUsings` are SDK defaults* -- the templates set them; an empty project has neither.
* *Setting `TargetFramework` and `TargetFrameworks` together* -- the singular wins for the outer build, with confusing results.
* *Changing `DefaultItemExcludes` without the `+$(DefaultItemExcludes);+` prefix* -- `bin` and `obj` get compiled.
* *Looking for compiler options on the SDK page* -- `LangVersion`, `Nullable`, `Deterministic` live in the C# compiler
  options reference.
