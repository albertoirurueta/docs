A .NET **runtime** version (`10.0.13`) and a .NET **SDK** version (`10.0.402`) are released together but numbered
differently, and several SDKs ship for each runtime patch. This page explains the numbering, the support dates as of
**2026-10-23**, and collects the SDK changes that the other pages of this group cite. The baseline is **.NET SDK
10.0.402** (2026-10-13, runtime 10.0.13).

== Runtime and SDK versions

An SDK version is `major.minor.Fpp`: `F` is the **feature band** (hundreds digit) and `pp` the patch within it. The
runtime it carries is the matching `major.minor.patch`. The release metadata lists, for every runtime patch, the SDKs
released with it:

[source,bash]
----
curl -s https://builds.dotnet.microsoft.com/dotnet/release-metadata/10.0/releases.json | python3 -c '
import json, sys
for r in json.load(sys.stdin)["releases"]:
    print(r["release-version"], r["release-date"], ", ".join(s["version"] for s in r.get("sdks", [])))'
----

The pattern:

* **A new feature band about every three months** -- 2xx in March, 3xx in May, 4xx in August -- each bringing a newer
  MSBuild, NuGet and Roslyn and the features listed below. Each band is released with a runtime patch, so SDK
  `10.0.402` and `10.0.113` both carry runtime 10.0.13.
* **The 1xx band was patched in every release**, alongside the newest band.
* **A superseded band gets one overlap release** (10.0.303 in August, 10.0.204 in May) and then no more patches.
  `global.json` with `rollForward: latestPatch` on an old band therefore stops receiving security fixes; `latestFeature`
  moves with the bands
  (xref:programming-languages/csharp/build-tools/dotnet-cli/installing-and-selecting-sdks.adoc[Installing and Selecting SDKs]).

== Support

The release index on 2026-10-23:

[source,text]
----
11.0  11.0.0-rc.2  2026-10-13  11.0.100-rc.2.26504.105  sts  go-live
10.0  10.0.13      2026-10-13  10.0.402                 lts  active       EOL 2028-11-14
9.0   9.0.21       2026-10-13  9.0.319                  sts  maintenance  EOL 2026-11-10
8.0   8.0.32       2026-10-13  8.0.426                  lts  maintenance  EOL 2026-11-10
7.0   7.0.20       2024-05-28  7.0.410                  sts  eol          EOL 2024-05-14
6.0   6.0.36       2024-11-12  6.0.428                  lts  eol          EOL 2024-11-12
----

* **LTS** (even majors) releases are supported for three years, **STS** (odd majors) for two -- so .NET 8 (LTS,
  November 2023) and .NET 9 (STS, November 2024) end on the **same day, 2026-11-10**, three weeks after this page's date.
* **.NET 10** is the current LTS, supported until 2028-11-14.
* **.NET 11** is at release candidate 2, a **go-live** release: supported in production by Microsoft, but not final.
* Building for an out-of-support framework warns NETSDK1138
  (xref:programming-languages/csharp/build-tools/target-frameworks-and-runtime-identifiers.adoc[Target Frameworks and Runtime Identifiers]).

Source: https://dotnet.microsoft.com/platform/support/policy/dotnet-core[.NET and .NET Core support policy].

== Common mistakes

* *Pinning an old feature band with `latestPatch`* -- the band stops receiving patches.
* *Confusing the SDK and runtime versions in bug reports* -- include `dotnet --info`.
* *Staying on .NET 8 or 9 after 2026-11-10* -- no more security fixes; .NET 10 is the LTS.
* *Treating a go-live RC as final* -- supported, but APIs and defaults can still change before GA.
