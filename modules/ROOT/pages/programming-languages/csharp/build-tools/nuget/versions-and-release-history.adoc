The NuGet client ships inside every .NET SDK, inside Visual Studio and as `nuget.exe`, each on its own schedule. This page
shows how to find the version in use, maps NuGet versions to the SDKs and Visual Studio releases that carry them, and
collects the release history the other NuGet pages cite. The baseline is **NuGet 7.9.0**, in .NET SDK 10.0.400 and
10.0.402.

== Finding the version

[source,bash]
----
dotnet nuget --version
----

[source,text]
----
7.9.0-rc.611+a8dd0577c5c13f43a2f57fe33b4ff11b90f6371e.a8dd0577c5c13f43a2f57fe33b4ff11b90f6371e
----

The SDK carries a build labelled as a release candidate of 7.9.0 -- the SDK's internal dependency label; the
functionality is that of NuGet 7.9.0. The commit after `+` is the SDK's. In Visual Studio, *Help > About* lists the NuGet
Package Manager version; `nuget.exe help` prints its own.

`nuget.exe` releases are listed in a JSON feed:

[source,bash]
----
curl -s https://dist.nuget.org/tools.json | jq -r '."nuget.exe"[:4][] | "\(.version) \(.stage) \(.uploaded[:10])"'
----

[source,text]
----
7.9.0 ReleasedAndBlessed 2026-08-11
7.6.0 ReleasedAndBlessed 2026-05-12
7.3.1 ReleasedAndBlessed 2026-04-14
7.3.0 ReleasedAndBlessed 2026-02-10
----

Source: https://learn.microsoft.com/en-us/nuget/install-nuget-client-tools#support-policy[Install NuGet client tools: Support policy],
https://dist.nuget.org/tools.json[NuGet tools release feed].

Since NuGet 7, versions that ship with an SDK band alternate with **Visual Studio-only** releases, whose release-notes
pages say so and list "N/A" for the SDK. There are no release-notes pages for 7.1 and 7.2 (the URLs return 404), and
no page for 8.0 yet. A repository built with both Visual Studio 18.10 (NuGet 7.10) and SDK 10.0.402 (NuGet 7.9) can
therefore see slightly different restore behaviour in the IDE and on the command line.

== Common mistakes

* *Assuming the IDE and the CLI run the same NuGet* -- Visual Studio-only releases are newer.
* *Reading the `-rc` label as a preview* -- it is the SDK's build label for the release.
* *Downloading `nuget.exe` without checking the stage* -- prefer "ReleasedAndBlessed" versions from `tools.json`.
