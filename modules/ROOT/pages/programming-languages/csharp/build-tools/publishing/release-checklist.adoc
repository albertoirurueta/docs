= Release Checklist
:description: A printable checklist for releasing a C# library on NuGet, built from the publishing group -- design (target frameworks, dependency ranges, breaking changes), metadata (ID, description, README, icon, licence, repository), build (version, Source Link, symbols, deterministic CI build), checks (package validation, a test feed, a clean consumer), publish (Trusted Publishing, a tag, two CI jobs) and after release (monitoring audits, deprecating, unlisting), each item linked to the page that explains it.
:keywords: NuGet release checklist, library release, package checklist, target frameworks, dependency ranges, package metadata, README, icon, license, SemVer, Source Link, symbol package, ContinuousIntegrationBuild, package validation, test feed, Trusted Publishing, release tag, NuGetAudit, deprecate, unlist

include::partial$csharp-build-tools-disclaimer.adoc[]

This checklist condenses the publishing group into the questions to answer before every release of a library such as
`Ledgerline`. It assumes **.NET SDK 10.0.402** (NuGet 7.9.0) or later; each item links to the page that explains it and
shows the commands. The first release needs all of it; later releases mostly the *Build*, *Checks* and *Publish*
sections.

== Design

* [ ] Target frameworks chosen: a `net8.0`-or-later target, `netstandard2.0` only for reach, `net462` only if .NET
  Framework users need it; no `netstandard1.x`
  (xref:programming-languages/csharp/build-tools/publishing/designing-a-library-for-nuget.adoc#_choosing_target_frameworks[Choosing target frameworks]).
* [ ] The same public API on every compatible framework
  (xref:programming-languages/csharp/build-tools/publishing/designing-a-library-for-nuget.adoc#_the_package_compatibility_rules[Compatibility rules]).
* [ ] Dependencies reviewed: few, with minimum versions only -- no exact versions, no upper bounds; polyfills only on
  older frameworks; build-time packages `PrivateAssets="all"`
  (xref:programming-languages/csharp/build-tools/publishing/designing-a-library-for-nuget.adoc#_dependencies[Dependencies]).
* [ ] Breaking changes classified (source, behaviour, binary) and reflected in the version
  (xref:programming-languages/csharp/build-tools/publishing/designing-a-library-for-nuget.adoc#_breaking_changes[Breaking changes]).
* [ ] Strong naming decided once -- and the key never changed
  (xref:programming-languages/csharp/build-tools/publishing/designing-a-library-for-nuget.adoc#_strong_naming[Strong naming]).

== Metadata

* [ ] `PackageId` unique, at most 100 characters, under a reserved prefix if possible
  (xref:programming-languages/csharp/build-tools/publishing/publishing-to-nuget-org.adoc#_id_prefix_reservation[ID prefix reservation]).
* [ ] `Authors`, `Description`, `Copyright`, `PackageProjectUrl`, `PackageTags` and `PackageReleaseNotes` set -- not
  the defaults (xref:programming-languages/csharp/build-tools/publishing/package-metadata-readme-icon-and-license.adoc#_the_properties[The properties]).
* [ ] README packed (`PackageReadmeFile`), images only from allowed domains
  (xref:programming-languages/csharp/build-tools/publishing/package-metadata-readme-icon-and-license.adoc#_the_readme[The README]).
* [ ] Icon embedded (`PackageIcon`, PNG or JPEG, 128×128, under 1 MB)
  (xref:programming-languages/csharp/build-tools/publishing/package-metadata-readme-icon-and-license.adoc#_the_icon[The icon]).
* [ ] Licence as an SPDX expression or a packed file -- never `PackageLicenseUrl`
  (xref:programming-languages/csharp/build-tools/publishing/package-metadata-readme-icon-and-license.adoc#_the_licence[The licence]).

== Build

* [ ] Version chosen by SemVer; prerelease label for anything not stable; no stable package depending on a prerelease
  (NU5104) (xref:programming-languages/csharp/build-tools/publishing/versioning-and-prerelease-packages.adoc[Versioning and Prerelease Packages]).
* [ ] `AssemblyVersion` policy applied consistently; `InformationalVersion` left to the SDK.
* [ ] Source Link working (`sourcelink.json` in the PDB, `+<repository commit=...>+` in the `.nuspec`); no extra Source
  Link package on SDK 8+ (xref:programming-languages/csharp/build-tools/publishing/symbols-source-link-and-deterministic-packages.adoc#_source_link[Source Link]).
* [ ] Symbols shipped: `.snupkg` or embedded PDBs
  (xref:programming-languages/csharp/build-tools/publishing/symbols-source-link-and-deterministic-packages.adoc#_symbol_packages_snupkg[Symbol packages]).
* [ ] Built in CI with `ContinuousIntegrationBuild=true`, a locked restore and the SDK from `global.json`
  (xref:programming-languages/csharp/build-tools/publishing/ci-release-workflows.adoc[CI Release Workflows]).

== Checks

* [ ] `EnablePackageValidation` with `PackageValidationBaselineVersion` set to the last release; any suppression
  reviewed (xref:programming-languages/csharp/build-tools/publishing/package-validation-and-api-compatibility.adoc[Package Validation and API Compatibility]).
* [ ] Package contents inspected: `lib/` folders and dependency groups match; no stray files; no `NU5xxx` warnings
  left unexplained (xref:programming-languages/csharp/build-tools/publishing/pack-and-push-errors.adoc[Pack and Push Errors]).
* [ ] `dotnet-validate package local` reports Source Link, determinism and compiler flags as valid.
* [ ] Installed from a **test feed** (a folder or BaGetter) into a clean consumer for each supported framework family,
  restored with `--no-http-cache`
  (xref:programming-languages/csharp/build-tools/publishing/package-layout-and-multi-targeting.adoc#_multi_targeted_packages[Multi-targeted packages]).
* [ ] Optionally pushed to int.nugettest.org to see nuget.org's validation and rendering
  (xref:programming-languages/csharp/build-tools/publishing/publishing-to-nuget-org.adoc#_testing_on_the_integration_gallery_not_run_here[Integration gallery]).

== Publish

* [ ] Trusted Publishing policy on nuget.org for the repository, workflow file and environment -- or, failing that, a
  scoped API key that expires within 30 days
  (xref:programming-languages/csharp/build-tools/publishing/trusted-publishing.adoc[Trusted Publishing],
  xref:programming-languages/csharp/build-tools/publishing/nuget-org-accounts-organizations-and-api-keys.adoc#_scoped_api_keys[Scoped API keys]).
* [ ] Release started by a **tag**; build and push in separate jobs; only the push job has `id-token: write`.
* [ ] `--skip-duplicate` on the push so a re-run is safe.
* [ ] If the account registered a signing certificate: packages author-signed and timestamped
  (xref:programming-languages/csharp/build-tools/publishing/signing-packages.adoc[Signing Packages]).
* [ ] Validation and indexing finished (usually under 15 minutes); the package page shows the README, icon, licence and
  repository link.

== After the release

* [ ] Release notes and documentation updated; e-mail notifications for new versions enabled on the account.
* [ ] Dependencies watched: NuGetAudit warnings in CI, updates of vulnerable transitive packages
  (xref:programming-languages/csharp/build-tools/nuget/auditing-packages-for-vulnerabilities.adoc[Auditing Packages for Vulnerabilities]).
* [ ] A broken or vulnerable version **deprecated** (with an alternative) and **unlisted**; a vulnerability reported to
  the GitHub Advisory Database once the fix is out
  (xref:programming-languages/csharp/build-tools/publishing/managing-published-packages.adoc[Managing Published Packages]).
* [ ] Package validation baseline moved to the new version, and old suppressions removed.
