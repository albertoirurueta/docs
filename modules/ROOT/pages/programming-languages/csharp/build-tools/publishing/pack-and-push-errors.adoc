= Pack and Push Errors
:description: A grouped reference of the errors and warnings met when producing and publishing NuGet packages, with the real messages printed by .NET SDK 10.0.402 and BaGetter -- metadata (NU5030 to NU5052, NU5124, NU5125), contents and layout (NU5017, NU5026, NU5100, NU5101, NU5104, NU5118, NU5119, NU5123, NU5127 to NU5131, NU5501, NU5049), validation (CP0001, CP0002, CP0003, PKV006), tools (NETSDK1047, NETSDK1235), signing (NU3002, NU3018, NU3027, NU3042, NU3034) and the push HTTP status codes 401, 403, 409 and 413.
:keywords: NuGet pack errors, NuGet push errors, NU5017, NU5026, NU5030, NU5032, NU5033, NU5035, NU5038, NU5039, NU5040, NU5045, NU5046, NU5047, NU5048, NU5049, NU5051, NU5052, NU5100, NU5104, NU5118, NU5119, NU5123, NU5124, NU5125, NU5127, NU5128, NU5129, NU5131, NU5501, CP0002, PKV006, NETSDK1047, NETSDK1235, NU3018, NU3027, 401 Unauthorized, 403 Forbidden, 409 Conflict, 413 Request Entity Too Large

This page collects the diagnostics from the publishing group in one place. Messages marked *(run)* were produced in
this section with **.NET SDK 10.0.402** (NuGet 7.9.0), from one-file projects or the `Ledgerline` scenario, and are
quoted as printed (paths shortened, the `[project]` suffix removed); the others are quoted from their reference page
and say so. Each code links to its NuGet reference page. Consumer-side codes (restore, audit, sources) are on
xref:programming-languages/csharp/build-tools/nuget/troubleshooting-errors-and-warnings.adoc[Troubleshooting NuGet Errors and Warnings].

== Push

[cols="1,4,3",options="header"]
|===
| Status | Message | Cause

| 401 | `error: Response status code does not indicate success: 401 (Unauthorized).` (run, BaGetter, wrong or missing key) | Wrong, expired or missing API key; on nuget.org also a key from another owner.
| 403 | Not reproduced. Documented causes: Azure Artifacts without the *Feed Publisher (Contributor)* role; GitHub Packages intermittently during restore without source mapping. | Grant the role; add source mapping.
| 409 | `+Conflict ... To skip already published packages, use the option --skip-duplicate+` / `error: Response status code does not indicate success: 409 (Conflict).` (run, BaGetter) | The version exists; publish a new one or use `--skip-duplicate`.
| 413 | `error: Response status code does not indicate success: 413 (The package file exceeds the size limit. Please try again.).` (documented, nuget.org) | Packages over about 250 MB; split them.
|===

nuget.org's own wording for `409` and for a key whose **scope** doesn't cover the package is not documented; the codes
are the same, the messages above come from BaGetter.
