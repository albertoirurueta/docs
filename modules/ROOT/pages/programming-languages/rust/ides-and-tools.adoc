= Rust IDEs & Tools
:description: The IDEs, editors and language tooling commonly used for Rust development, grouped by category.
:keywords: Rust, IDE, editor, tools, RustRover, CLion, VS Code, Zed, rust-analyzer

include::partial$rust-disclaimer.adoc[]

This page lists the IDEs, editors and language tooling commonly used to write and debug Rust code. Most editors get their Rust features from rust-analyzer, so the choice is largely about workflow and preference.

== IDEs

* https://www.jetbrains.com/rust/[*RustRover*] -- a Rust-specific IDE with its own analysis, refactoring, debugging and Cargo integration.
* https://www.jetbrains.com/clion/[*CLion*] -- JetBrains' C and {cpp} IDE, which supports Rust through the https://plugins.jetbrains.com/plugin/22407-rust[Rust plugin]; useful for mixed Rust and C/{cpp} projects.

== Editors with extensions

* https://marketplace.visualstudio.com/items?itemName=rust-lang.rust-analyzer[*rust-analyzer for VS Code*] -- the rust-analyzer extension for Visual Studio Code, providing completion, inline errors and refactorings.
* https://zed.dev/[*Zed*] -- a fast, open source editor with built-in Rust support through rust-analyzer; see https://zed.dev/docs/languages/rust[Rust in Zed].

== Language tooling

* https://rust-analyzer.github.io/[*rust-analyzer*] -- the official Rust language server that powers IDE features in most editors.
