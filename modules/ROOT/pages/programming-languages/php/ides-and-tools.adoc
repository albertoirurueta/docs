This page lists the IDEs commonly used to write, run and debug PHP code. A dedicated PHP IDE gives the deepest framework and debugging support, while an open-source option keeps costs down.

== IDEs

* https://www.jetbrains.com/phpstorm/[*PhpStorm*] -- a PHP-specific IDE with code analysis, refactoring, Xdebug integration and framework support.
* https://projects.eclipse.org/projects/tools.pdt[*Eclipse PDT*] -- the PHP Development Tools project, which brings PHP editing and debugging to the Eclipse platform.
* https://netbeans.apache.org/[*Apache NetBeans*] -- the Apache Software Foundation's open source IDE, with PHP editing, Xdebug debugging and PHPUnit support.

== Editors with extensions

* https://marketplace.visualstudio.com/items?itemName=bmewburn.vscode-intelephense-client[*PHP Intelephense for VS Code*] -- a PHP language server for Visual Studio Code with completion, diagnostics, go-to-definition and formatting; see https://code.visualstudio.com/docs/languages/php[PHP in Visual Studio Code] for setting up debugging with Xdebug.
