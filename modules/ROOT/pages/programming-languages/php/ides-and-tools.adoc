This page lists the IDEs commonly used to write, run and debug PHP code. A dedicated PHP IDE gives the deepest framework and debugging support, while an open-source option keeps costs down.

== IDEs

* https://www.jetbrains.com/phpstorm/[*PhpStorm*] -- a PHP-specific IDE with code analysis, refactoring, Xdebug integration and framework support.
* https://projects.eclipse.org/projects/tools.pdt[*Eclipse PDT*] -- the PHP Development Tools project, which brings PHP editing and debugging to the Eclipse platform.
