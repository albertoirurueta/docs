== Release by release

Each release has a migration guide in the PHP Manual listing new features, backward-incompatible changes and
deprecations. Read the guides of *every* version between the one you run and the one you move to.

|===
| Release | GA | Headline changes

| https://www.php.net/manual/en/migration70.php[7.0] | 2015-12-03 | New engine (about twice as fast as 5.6, much less memory); scalar and return type declarations; `??` and `+<=>+`; anonymous classes; `Throwable` with `Error` for most fatal errors; CSPRNG `random_bytes()`/`random_int()`. Removed: `+mysql_*+`, `ereg`, ASP and script tags
| https://www.php.net/manual/en/migration71.php[7.1] | 2016-12-01 | Nullable types (`?int`), `void`, `iterable`; `+[$a, $b] = ...+` destructuring with keys; class constant visibility; multi-catch; negative string offsets

== Support timeline

Each release gets *two years of active support* (bug and security fixes), then *two years of security fixes only*.
Since a 2024 policy change, both periods end on 31 December, which also extended 8.1 to the end of 2025. After that a
branch is *end of life*: it receives no fixes at all, including for actively exploited vulnerabilities.

| 8.0 | 2020-11-26 | 2022-11-26 | 2023-11-26 | End of life
| 8.1 | 2021-11-25 | 2023-11-25 | 2025-12-31 | End of life

== Deprecations and removals

PHP removes features in two steps. A minor release *deprecates* a feature: it still works, but emits an
`E_DEPRECATED` notice (a *soft deprecation* is documented only, with no notice). The next major release (8.0, then
9.0) *removes* it. The table lists the deprecations that most often appear in real code.

[cols="1,4,3",options="header"]
|===
| Version | Deprecated | Removed

| 7.0 | PHP 4-style constructors; static calls to non-static methods | `+mysql_*+`, `+ereg*+`, ASP tags `<%`, `<script language="php">`, `call_user_method()`
| 7.1 | `mcrypt`; the `e` modifier of `mb_ereg_replace()` | --
| 7.2 | `each()`, `create_function()`, `+__autoload()+`, the `(unset)` cast, `assert()` with a string, `$php_errormsg`, `parse_str()` without a result argument | `mcrypt` (moved to PECL)
| 7.3 | Case-insensitive constants; non-string needles in `strpos()` and friends; `fgetss()` | --
| 7.4 | Unparenthesised nested ternaries; `+$str{0}+` offsets; the `(real)` cast; `money_format()`; `get_magic_quotes_gpc()`; `allow_url_include`; `implode()` with reversed arguments | `ext/wddx`, `ext/interbase`, `ext/recode` (unbundled)
| 8.0 | Optional parameters before required ones; `libxml_disable_entity_loader()` | *Everything deprecated in 7.x*: `each()`, `create_function()`, `money_format()`, `(unset)`, `+__autoload()+`, `+$str{0}+`, PHP 4 constructors, `fgetss()`, string `assert()`, `get_magic_quotes_gpc()`; unquoted array keys (`$a[key]`)
| 8.1 | Passing `null` to non-nullable internal parameters; `Serializable` without `+__serialize()+`; `strftime()`/`gmstrftime()`; `FILTER_SANITIZE_STRING`; `+mhash*()+`; autovivification on `false`; implicit lossy float-to-int conversion; `date_sunrise()`/`date_sunset()` | --
| 8.2 | Dynamic properties; `+"${var}"+` interpolation; `utf8_encode()`/`utf8_decode()`; partially supported callables (`"self::method"`); mbstring `QPrint`, `Base64`, `Uuencode` and `HTML-ENTITIES` | --
| 8.3 | `assert_options()`; `get_class()` without arguments; `pass:c[++]` on empty or non-alphanumeric strings and `+--+` on empty or non-numeric strings; `MT_RAND_PHP` | --
| 8.4 | Implicitly nullable parameters (`string $s = null`); `trigger_error()` with `E_USER_ERROR`; `+_+` as a class name; `lcg_value()`; `mysqli_ping()`; session `sid_length`/`sid_bits_per_character`; `E_STRICT` | `ext/imap`, `ext/oci8`, `ext/pdo_oci`, `ext/pspell` (unbundled, now in PECL)
| 8.5 | The backtick operator; non-canonical casts `(integer)`, `(boolean)`, `(double)`, `(binary)`; `case` ended with `;`; `null` as an array offset; `pass:c[++]` on non-numeric strings; `curl_close()`, `imagedestroy()`, `finfo_close()`, `xml_parser_free()` (no-ops); `+__sleep()+`/`+__wakeup()+` (soft); `register_argc_argv` for web SAPIs; `SplObjectStorage::attach()`/`detach()`/`contains()` | --
| 8.6 (upcoming) | `return` inside `finally`; `let` and `is` as class names, `readonly` as a function name; values returned from `+__construct()+`; `spl_object_hash()`; `is_long()`, `is_integer()`, `is_double()`, `doubleval()`; `metaphone()`; `strcoll()` | --
|===

Source: https://www.php.net/manual/en/migration85.deprecated.php[PHP 8.5 -- Deprecated features], https://www.php.net/manual/en/migration84.deprecated.php[8.4], https://www.php.net/manual/en/migration83.deprecated.php[8.3], https://www.php.net/manual/en/migration82.deprecated.php[8.2], https://www.php.net/manual/en/migration81.deprecated.php[8.1], https://www.php.net/manual/en/migration80.incompatible.php[8.0 -- Backward incompatible changes] and https://www.php.net/manual/en/migration74.deprecated.php[7.4]

Contrary to some upgrade guides, `list()` is *not* deprecated: it still works without a notice in 8.5 and in
8.6.0RC2, although `[]` (7.1) is the usual syntax.

This script runs on PHP 8.5, but every marked line produces a deprecation. Deprecations found at compile time are
reported before the script starts; the rest go through the error handler as the lines run:

[source,php]
----
<?php
error_reporting(E_ALL);
set_error_handler(function (int $level, string $message, string $file, int $line): bool {
    echo "line $line: $message\n";
    return true;
});

class Member
{
    public function rename(string $name = null): void {}    // implicitly nullable parameter (8.4)
}

$member = new Member();
$member->nickname = 'ada';                                   // dynamic property (8.2)

$name = 'Ada';
echo "Hello ${name}\n";                                      // ${} interpolation (8.2)

$count = (integer) '3';                                      // non-canonical cast name (8.5)
$version = 'a9';
$version++;                                                  // increment of a non-numeric string (8.5)
var_dump(strftime('%Y'));                                    // strftime (8.1)
----

[source,text]
----
Deprecated: Non-canonical cast (integer) is deprecated, use the (int) cast instead in legacy.php on line 19
Deprecated: Member::rename(): Implicitly marking parameter $name as nullable is deprecated, the explicit nullable type must be used instead in legacy.php on line 10
Deprecated: Using ${var} in strings is deprecated, use {$var} instead in legacy.php on line 17
line 14: Creation of dynamic property Member::$nickname is deprecated
Hello Ada
line 21: Increment on non-numeric string is deprecated, use str_increment() instead
line 22: Function strftime() is deprecated since 8.1, use IntlDateFormatter::format() instead
string(4) "2026"

Source: https://www.php.net/manual/en/errorfunc.constants.php[PHP Manual -- Error constants (E_DEPRECATED)] and https://www.php.net/manual/en/function.set-error-handler.php[set_error_handler]

The fixes are mechanical: `?string $name = null`, a declared property (or `+#[\AllowDynamicProperties]+` as a stopgap),
`+{$name}+`, `(int)`, `str_increment($version)` and `IntlDateFormatter`.

== PHP 9

No release date is set for PHP 9.0, but several RFCs have already been accepted for it. *Undefined variables* will
throw an `Error` instead of a warning. *`+"${var}"+` interpolation* will be removed. *Autovivification on `false`*
(`$x = false; $x[] = 1;`, which silently turns `$x` into an array) will throw. In general, every feature deprecated
during the 8.x series is a candidate for removal in 9.0, so code that runs on 8.5 without deprecation notices is
the best preparation.

Source: https://wiki.php.net/rfc/undefined_variable_error_promotion[RFC: Undefined variable error promotion], https://wiki.php.net/rfc/deprecate_dollar_brace_string_interpolation[RFC: Deprecate ${} string interpolation] and https://wiki.php.net/rfc/autovivification_false[RFC: Deprecate autovivification on false]

== How to upgrade

. *Read the migration guides* for every version you skip, especially the backward-incompatible changes.
. *Make deprecations visible.* Run the test suite and staging with `error_reporting=E_ALL` and log
  `E_DEPRECATED`; PHPUnit's `failOnDeprecation="true"` and `displayDetailsOnTestsThatTriggerDeprecations="true"`
  turn them into test failures (see
  xref:programming-languages/php/testing-with-phpunit-and-pest.adoc[Testing with PHPUnit and Pest]).
. *Check compatibility statically.* PHPStan reports calls to deprecated functions with its deprecation-rules
  extension, and the https://github.com/PHPCompatibility/PHPCompatibility[PHPCompatibility] sniffs for PHP_CodeSniffer
  report syntax and functions that do not exist or are removed in a target version.
. *Rewrite automatically.* Rector's PHP sets apply each version's upgrades (constructor promotion, `match`,
  readonly, explicit nullable types, ...). Review the diff like any other change; see
  xref:programming-languages/php/static-analysis-and-refactoring.adoc[Static Analysis and Refactoring].
. *Upgrade dependencies* with Composer, raising the `"php"` constraint last.
. *Run the new version in CI* alongside the old one before switching production.

[source,php]
----
<?php
// rector.php -- upgrade a code base to PHP 8.5 syntax
use Rector\Config\RectorConfig;

return RectorConfig::configure()
    ->withPaths([__DIR__ . '/src', __DIR__ . '/tests'])
    ->withPhpSets(php85: true);    // or withPhpSets() to follow composer.json's "php" constraint
----

Source: https://getrector.com/documentation[Rector -- Documentation] and https://github.com/PHPCompatibility/PHPCompatibility[PHPCompatibility]

[source,bash]
----
vendor/bin/rector process --dry-run      # show the changes as a diff
vendor/bin/rector process                # apply them
vendor/bin/phpcs -p src --standard=PHPCompatibility --runtime-set testVersion 8.5-
----

== Where older books and tutorials are outdated

The PHP books this section draws on were written for PHP 5.2 to 7.3 (see the bibliography on the
xref:programming-languages/php/index.adoc[PHP Reference] home page). Each page in this section has its own "outdated"
section; this table collects every book statement about the language that is no longer true, with the version where
it changed.

[cols="3,2,1,3",options="header"]
|===
| What the book says or does | Where | Changed in | Current approach

| `mysql_connect()` and the `+mysql_*+` functions | Wiley ch. 8, Beak ch. 12 (quiz) | removed in 7.0 | mysqli or PDO with prepared statements
| `ereg()`, `eregi()`, `split()` POSIX regular expressions | Kromann, Nixon | removed in 7.0 | `+preg_*+` (xref:programming-languages/php/regular-expressions.adoc[Regular Expressions])
| PHP 4-style constructors (a method named like the class) | Beak ch. 5 | deprecated 7.0, ignored since 8.0 | `+__construct()+` (xref:programming-languages/php/classes-and-objects.adoc[Classes and Objects])
| mcrypt for encryption | Beak ch. 1, 6 and 8 | deprecated 7.1, removed 7.2 | sodium, or OpenSSL with AES-GCM (xref:programming-languages/php/cryptography-hashing-and-passwords.adoc[Cryptography])
| `+while (list($k, $v) = each($a))+` | Beak ch. 4, Nixon ch. 6 | removed in 8.0 | `foreach` (xref:programming-languages/php/arrays.adoc[Arrays])
| `create_function()` | Beak ch. 2, Kromann ch. 4 | removed in 8.0 | closures and arrow functions (xref:programming-languages/php/closures-and-callables.adoc[Closures])
| `+__autoload()+` | Kromann ch. 6 | removed in 8.0 | Composer's PSR-4 autoloader (xref:programming-languages/php/namespaces-and-autoloading.adoc[Namespaces and Autoloading])
| `money_format()` | Beak ch. 3, Kromann ch. 12 | removed in 8.0 | `NumberFormatter::formatCurrency()` (xref:programming-languages/php/strings.adoc[Strings])
| The `(unset)` cast | Beak ch. 1 | removed in 8.0 | `unset()` or assigning `null`
| `fgetss()` | Kromann ch. 9-10 | removed in 8.0 | escape on output (xref:programming-languages/php/files-streams-and-io.adoc[Files and Streams])
| `get_magic_quotes_gpc()` checks | Nixon ch. 10, 27 | removed in 8.0 | nothing: magic quotes were removed in 5.4; use prepared statements
| Bareword array keys `+$_POST[email]+` | Kromann ch. 14 | fatal `Error` since 8.0 | quoted keys `+$_POST['email']+`
| `+"12 o'clock" == 12+` is `true` | Beak ch. 1 | false since 8.0 | `===`, and the 8.0 comparison rules (xref:programming-languages/php/type-juggling-and-comparisons.adoc[Type Juggling])
| Arithmetic on non-numeric strings gives a warning and `0` | Powers ch. 4 | `TypeError` since 8.0 | validate and cast input first
| Internal functions return `false`/`null` with a warning on bad arguments | Beak ch. 11 | `TypeError`/`ValueError` since 8.0 | catch the exceptions (xref:programming-languages/php/errors-and-exceptions.adoc[Errors and Exceptions])
| PDO throws exceptions by default (said of PHP 7, whose default was silent) | Kromann ch. 28 | true only since 8.0 | rely on `ERRMODE_EXCEPTION` on 8.x
| Checking `connect_error` after every mysqli call | Powers ch. 13, Kromann ch. 27 | mysqli throws since 8.1 | rely on `mysqli_sql_exception`
| `strftime()` with `setlocale()` | Beak ch. 3, Powers ch. 16, Kromann ch. 12 | deprecated 8.1 | `IntlDateFormatter` (xref:programming-languages/php/date-and-time.adoc[Date and Time])
| `FILTER_SANITIZE_STRING` as an XSS defence | Beak ch. 6 and 12, Kromann ch. 13 | deprecated 8.1 | escape for the output context with `htmlspecialchars()`
| `Serializable` | Beak ch. 5 | deprecated 8.1 | `+__serialize()+`/`+__unserialize()+` (xref:programming-languages/php/magic-methods-and-overloading.adoc[Magic Methods])
| `setAccessible(true)` before reading private members | Beak ch. 5 | no-op since 8.1 | omit it (xref:programming-languages/php/reflection.adoc[Reflection])
| Resources (`finfo`, GD images, cURL handles) closed with `+*_close()+` | the books' cURL, GD and fileinfo examples | objects since 8.0-8.1, close functions deprecated 8.5 | let the object go out of scope
| Assigning undeclared (dynamic) properties on objects | all books (written before 8.2) | deprecated 8.2 | declare properties
| `json_last_error()` after every call | Beak ch. 8 | `JSON_THROW_ON_ERROR` since 7.3 | the flag, and `json_validate()` (8.3) (xref:programming-languages/php/json-xml-and-serialization.adoc[JSON, XML and Serialization])
| `func_get_args()` for variable argument lists | Beak ch. 2, Kromann | `+...$args+` since 5.6 | variadic parameters (xref:programming-languages/php/functions.adoc[Functions])
| `SplObjectStorage::attach()`/`detach()`/`contains()` | Beak ch. 10 | deprecated 8.5 | `offsetSet()`/`offsetUnset()`/`offsetExists()`, or `WeakMap` (xref:programming-languages/php/spl-data-structures.adoc[SPL])
| `+__sleep()+`/`+__wakeup()+` | Beak ch. 5 | soft-deprecated 8.5 | `+__serialize()+`/`+__unserialize()+`
| The backtick operator and `exec()` with concatenated strings | Kromann ch. 9, Nixon ch. 7 | backticks deprecated 8.5 | `proc_open()` with an argument array (xref:programming-languages/php/command-line-php.adoc[Command-Line PHP])
| OPcache as an extension to install and load | Beak ch. 1 | always built in since 8.5 | configure it, nothing to install (xref:programming-languages/php/opcache-jit-and-performance.adoc[OPcache and JIT])
| References to avoid copying arrays; PHP 5 zval diagrams | Beak ch. 1 | copy-on-write and the PHP 7 zval | pass by value (xref:programming-languages/php/references-and-memory-management.adoc[References and Memory])
| `md5()`/`sha1()` password hashes, `+md5(uniqid(rand()))+` tokens | Wiley ch. 8 and 15, Kromann ch. 14 | `password_hash()` since 5.5, `random_bytes()` since 7.0 | `password_hash()`, `+bin2hex(random_bytes(32))+`
| PEAR packages; no Composer | Kromann ch. 7, Wiley, all other books | Composer since 2012; PECL to PIE (2025) | Composer and PIE (xref:programming-languages/php/composer-and-packages.adoc[Composer and Packages])
| PSR-0 and underscore pseudo-namespaces (`Zend_Db_Table`) | Wiley | PSR-0 deprecated 2014 | namespaces and PSR-4
| PSR-2 coding style | Kromann ch. 21 | deprecated 2019 | PER Coding Style 3.0 (xref:programming-languages/php/psr-standards-and-coding-style.adoc[PSR Standards])
| `display_errors` on to debug | Powers ch. 1-5 | -- | log errors in production; fatal errors include backtraces since 8.5 (xref:programming-languages/php/debugging-and-profiling.adoc[Debugging])
|===

Beyond these corrections, none of the books covers the language added since PHP 7.4: typed properties, arrow
functions, attributes, named arguments, `match`, enums, readonly properties and classes, fibers, first-class callable
