Welcome to the PHP reference. https://www.php.net/[PHP] is a general-purpose scripting language best known for the
web: it runs a large share of the world's websites, from WordPress and Drupal to applications built with Laravel and
Symfony, and it is just as usable for command-line tools, workers and services. Created by Rasmus Lerdorf in 1994,
it is developed in the open: the language changes through public RFC votes, and the
https://thephp.foundation/[PHP Foundation] funds core developers. Modern PHP is a very different language from the
PHP of older books and tutorials: since 7.0 it has gained a fast engine, scalar and return types, `match`, enums,
readonly properties and classes, fibers, attributes, property hooks, asymmetric visibility and the pipe operator.

This section documents *PHP 8.5* (latest patch 8.5.11, 2026-09-24), checked on 2026-10-05. Each feature added in a
recent version is labelled with that version, so readers on 8.3 or 8.4 can see what they have. *PHP 8.6* is
upcoming (release candidate on that date, general availability scheduled for 2026-11-19); its additions appear only
where marked "upcoming in 8.6". Each PHP release is supported for four years: two years of active support with bug
and security fixes, then two years of security fixes only, both ending on 31 December. On 2026-10-05, 8.4 and 8.5
are in active support, 8.2 and 8.3 receive security fixes only, and 8.1 and older are end of life (see
xref:programming-languages/php/whats-new-and-migration.adoc[What's New and Migration] for the full timeline).

The examples share one small, original domain: a library catalogue of books, authors and loans, run from the
command line. Every example on these pages was run with PHP 8.5.11 (upcoming-8.6 examples with 8.6.0RC2), and the
tool output shown comes from the versions named on each page.

== What's covered

=== Getting started

* xref:programming-languages/php/getting-started.adoc[Getting Started] -- what PHP is and can do, a short history
  from PHP/FI to 8.5, the PHP Foundation and the RFC process, installing PHP on Linux, macOS, Windows and Docker,
  the CLI, the built-in web server, and how a script runs from source to opcodes.
* xref:programming-languages/php/configuration-and-extensions.adoc[Configuration and Extensions] -- `php.ini` and
  its search order, `.user.ini`, `ini_set()` and the changeable modes, the core directives, loading extensions,
  PECL versus PIE, `phpinfo()` and the SAPIs.
* xref:programming-languages/php/basic-syntax-and-style.adoc[Basic Syntax and Style] -- tags, escaping from HTML,
  statements and comments, reserved words, naming, PSR-1 and PER Coding Style 3, and PHPDoc.

=== Types and values

* xref:programming-languages/php/types-and-the-type-system.adoc[Types and the Type System] -- every type, union,
  intersection and DNF types, nullable types, `never` and `void`, and `strict_types`.
* xref:programming-languages/php/type-juggling-and-comparisons.adoc[Type Juggling and Comparisons] -- conversion
  rules and casts, the PHP 8 string-to-number comparison change, `==` versus `===`, and the comparison tables.
* xref:programming-languages/php/variables-scope-and-constants.adoc[Variables, Scope and Constants] -- assignment,
  scope, `global` and `static`, superglobals, `isset()`/`empty()`/`unset()`, constants and magic constants.
* xref:programming-languages/php/operators-and-expressions.adoc[Operators and Expressions] -- every operator with
  precedence, including `??`, `??=`, `<=>`, `?->`, the pipe operator `|>` (8.5) and the spread operator.
* xref:programming-languages/php/control-structures.adoc[Control Structures] -- `if`, loops, `foreach` by
  reference, `switch` versus `match`, `declare`, and `include`/`require`.

=== Strings, arrays and functions

* xref:programming-languages/php/strings.adoc[Strings] -- quoting, interpolation, heredoc and nowdoc, and the
  string API by family.
* xref:programming-languages/php/unicode-mbstring-and-intl.adoc[Unicode, mbstring and intl] -- bytes, code points
  and graphemes, mbstring, and locale-aware formatting with intl.
* xref:programming-languages/php/regular-expressions.adoc[Regular Expressions] -- PCRE2 syntax and modifiers, the
  `preg_*` functions, Unicode matching and ReDoS.
* xref:programming-languages/php/arrays.adoc[Arrays] -- the ordered-map model, key casting, destructuring, and the
  array API including `array_find()` (8.4) and `array_first()` (8.5).
* xref:programming-languages/php/functions.adoc[Functions] -- arguments by value and by reference, defaults,
  variadics, named arguments, return types and recursion.
* xref:programming-languages/php/closures-and-callables.adoc[Closures and Callables] -- closures and `use`, arrow
  functions, the `Closure` class, first-class callable syntax and every callable form.

=== Object-oriented programming

* xref:programming-languages/php/classes-and-objects.adoc[Classes and Objects] -- properties, constants,
  constructors and promotion, static members, anonymous classes and object comparison.
* xref:programming-languages/php/visibility-readonly-and-asymmetric-visibility.adoc[Visibility, Readonly and
  Asymmetric Visibility] -- `public`/`protected`/`private`, readonly properties and classes, and
  `public private(set)` (8.4).
* xref:programming-languages/php/property-hooks.adoc[Property Hooks] -- `get` and `set` hooks (8.4), backed and
  virtual properties, and hooks in interfaces.
* xref:programming-languages/php/inheritance-interfaces-and-abstract-classes.adoc[Inheritance, Interfaces and
  Abstract Classes] -- `extends`, overriding and signature rules, `final`, abstract classes, interfaces,
  `#[\Override]` and variance.
* xref:programming-languages/php/traits.adoc[Traits] -- using traits, conflict resolution, abstract and static
  members, and when to prefer composition.
* xref:programming-languages/php/enumerations.adoc[Enumerations] -- pure and backed enums (8.1), methods,
  interfaces, constants and serialisation.
* xref:programming-languages/php/magic-methods-and-overloading.adoc[Magic Methods and Overloading] -- every magic
  method, property and method overloading, and the serialisation hooks.
* xref:programming-languages/php/cloning-late-static-binding-and-object-lifecycle.adoc[Cloning, Late Static Binding
  and Object Lifecycle] -- `clone` and `clone()` with properties (8.5), `static::`, weak references and lazy
  objects (8.4).
* xref:programming-languages/php/namespaces-and-autoloading.adoc[Namespaces and Autoloading] -- namespaces, `use`
  and name resolution, `spl_autoload_register()` and PSR-4.
* xref:programming-languages/php/attributes.adoc[Attributes] -- syntax, custom attribute classes, reading them
  with Reflection, and every predefined attribute.
* xref:programming-languages/php/reflection.adoc[Reflection] -- the Reflection API for classes, methods,
  properties, types, enums and attributes.

=== Errors, iteration and concurrency

* xref:programming-languages/php/errors-and-exceptions.adoc[Errors and Exceptions] -- the `Throwable` hierarchy,
  `try`/`catch`/`finally`, custom exceptions, error levels and handlers.
* xref:programming-languages/php/iterators-and-generators.adoc[Iterators and Generators] -- the iterator
  interfaces, the SPL iterators, and generators with keys, `send()` and `yield from`.
* xref:programming-languages/php/fibers-and-asynchronous-php.adoc[Fibers and Asynchronous PHP] -- fibers (8.1), a

* xref:programming-languages/php/references-and-memory-management.adoc[References and Memory Management] --
  references, zvals and copy-on-write, and the cycle garbage collector.

=== Standard library

* xref:programming-languages/php/spl-data-structures.adoc[SPL Data Structures] -- stacks, queues, heaps, fixed
  arrays, object storage and when a plain array is better.
* xref:programming-languages/php/date-and-time.adoc[Date and Time] -- `DateTimeImmutable`, parsing and formatting,
  intervals and periods, time zones, and testable clocks.
* xref:programming-languages/php/math-numbers-and-randomness.adoc[Math, Numbers and Randomness] -- the maths

* xref:programming-languages/php/files-streams-and-io.adoc[Files, Streams and I/O] -- reading and writing files,
  CSV, locking, directories, stream wrappers, filters and contexts.
* xref:programming-languages/php/json-xml-and-serialization.adoc[JSON, XML and Serialization] -- JSON with
  exceptions, `serialize()` safety, SimpleXML, DOM and the HTML5 parser, XMLReader/XMLWriter and XSL.
* xref:programming-languages/php/cryptography-hashing-and-passwords.adoc[Cryptography, Hashing and Passwords] --
  hashing, HMAC, `password_hash()`, sodium, OpenSSL and secure randomness.
* xref:programming-languages/php/command-line-php.adoc[Command-Line PHP] -- the CLI SAPI, arguments and options,
  streams and exit codes, running programs safely, signals, and Symfony Console.

== PHP for the web

This section covers the *language*: syntax, types, objects, the standard library and the tools around them. How PHP
serves HTTP requests (the request model, PHP-FPM and web servers, superglobals, forms, sessions, uploads, PDO and
web security) and how to build applications with the Laravel framework are covered in the *PHP and Laravel* section
under Web Development, which builds on the pages here and links back to them.
