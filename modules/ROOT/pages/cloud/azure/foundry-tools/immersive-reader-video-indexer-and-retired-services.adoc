== Immersive Reader

**Azure AI Immersive Reader** is an embeddable reading experience. Your web page launches it in a full-screen iframe
with the text to read, and it offers:

* **read aloud** with word highlighting, in many voices and speeds
* **translation** of the whole text or single words into 100+ languages
* **parts of speech** coloring (nouns, verbs, adjectives) and **syllable** splitting
* a **picture dictionary** for single words
* line focus, text spacing and theme options that help readers with dyslexia

Immersive Reader needs its own single-service resource (`--kind ImmersiveReader`) with a custom subdomain and Entra
ID authentication. Your backend gets a token for the scope `https://cognitiveservices.azure.com/.default` and hands it
to the page, together with the subdomain; the page never sees a secret.

=== Token flow

[source,python]
----
# catalog-api endpoint: GET /immersive-reader/token
from azure.identity import DefaultAzureCredential

credential = DefaultAzureCredential()

def immersive_reader_token():
    token = credential.get_token("https://cognitiveservices.azure.com/.default")
    return {"token": token.token, "subdomain": "reader-bookshelf"}
----

Source: https://learn.microsoft.com/azure/ai-services/immersive-reader/how-to-create-immersive-reader[Create an Immersive Reader resource and configure Entra authentication]

[source,csharp]
----
using Azure.Core;
using Azure.Identity;

app.MapGet("/immersive-reader/token", async () =>
{
    AccessToken token = await new DefaultAzureCredential().GetTokenAsync(
        new TokenRequestContext(new[] { "https://cognitiveservices.azure.com/.default" }));
    return Results.Ok(new { token = token.Token, subdomain = "reader-bookshelf" });
});
----

Source: https://learn.microsoft.com/azure/ai-services/immersive-reader/quickstarts/client-libraries?pivots=programming-language-csharp[Immersive Reader quickstart (C#)]

The page launches the reader with the SDK:

[source,javascript]
----
import { launchAsync } from "@microsoft/immersive-reader-sdk";

const { token, subdomain } = await (await fetch("/immersive-reader/token")).json();
const content = {
  title: "Sample chapter: The Lighthouse Keeper",
  chunks: [{ content: document.querySelector("#sample-chapter").innerText, lang: "en", mimeType: "text/plain" }],
};
await launchAsync(token, subdomain, content, { uiZIndex: 2000 });
----

Source: https://learn.microsoft.com/azure/ai-services/immersive-reader/reference[Immersive Reader SDK reference]

Testing the token endpoint with `curl`:

[source,bash]
----
curl -s https://catalog.bookshelf.example/immersive-reader/token | jq '{subdomain, token: (.token | .[0:16])}'
----

Source: https://learn.microsoft.com/azure/ai-services/immersive-reader/how-to-create-immersive-reader[Create an Immersive Reader resource]

=== Provisioning

==== In the Azure portal

. Create a resource of type *Immersive Reader* named `reader-bookshelf` in `rg-bookshelf`, with custom subdomain
  `reader-bookshelf`.
. On its *Access control (IAM)* blade, assign `Cognitive Services Immersive Reader User` to `id-catalog-api`.

==== With the Azure CLI

[source,bash]
----
az cognitiveservices account create \
  --name reader-bookshelf --resource-group "$RG" --location "$LOCATION" \
  --kind ImmersiveReader --sku S0 --custom-domain reader-bookshelf --yes

az role assignment create \
  --assignee "$(az identity show --name id-catalog-api --resource-group "$RG" --query principalId -o tsv)" \
  --role "Cognitive Services Immersive Reader User" \
  --scope "$(az cognitiveservices account show --name reader-bookshelf --resource-group "$RG" --query id -o tsv)"
----

Source: https://learn.microsoft.com/azure/ai-services/immersive-reader/how-to-create-immersive-reader[Create an Immersive Reader resource]

=== Use cases

[cols="2,2,3,3", options="header"]
|===
| Scenario | Feature | Why this feature | Example input → output

| **Bookshelf:** sample chapters
| Read aloud, translation, line focus
| Readers try a chapter in their own way before buying.
| Sample chapter → reader with highlighting and Spanish translation

| Education
| Parts of speech, syllables, picture dictionary
| Early readers and language learners.
| Lesson text → colored parts of speech

| Accessibility
| Read aloud, text spacing, themes
| Low-vision and dyslexic readers.
| Article → high-contrast spaced view with audio

| Dyslexia support
| Line focus, syllables
| Reduces visual crowding.
| Homework text → one line at a time
|===

=== When not to use it

* When you only need audio, call text to speech directly
  (xref:cloud/azure/foundry-tools/text-to-speech-and-avatars.adoc[]).
* When the reading UI must be fully custom, build it with text to speech and Translator; Immersive Reader's UI is
  fixed. See xref:cloud/azure/foundry-tools/choosing-a-foundry-tool.adoc[].

== Azure AI Video Indexer

**Azure AI Video Indexer** analyzes video and audio (transcripts, faces, labels, topics, scenes, brands) with its own
portal, widgets and API. It is a **separate service** built on Azure AI capabilities, **not** part of the Foundry
Tools catalog.

* Choose **Video Indexer** for a media library with a ready-made portal, embeddable player widgets and
  media-specific insights.
* Choose **Content Understanding** video analyzers (xref:cloud/azure/foundry-tools/content-understanding.adoc[])
  when you want your own fields, chapters and summaries as JSON inside a pipeline, next to document and audio
  analyzers.

Source: https://learn.microsoft.com/azure/azure-video-indexer/video-indexer-overview[What is Azure AI Video Indexer?]
