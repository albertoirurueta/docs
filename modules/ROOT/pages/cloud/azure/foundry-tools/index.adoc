== What Foundry Tools are

**Foundry Tools** are Microsoft's prebuilt, task-specific AI services: speech recognition and synthesis,
translation, text analytics, image analysis, document extraction, multimodal content analysis, content moderation
and search. Each has its own REST API and SDKs, and most run on one **Foundry resource**
(`Microsoft.CognitiveServices/accounts` with `--kind AIServices`). Official product names follow the pattern
*Azure Speech in Foundry Tools*, *Azure Language in Foundry Tools* and so on; Content Safety is still titled *Azure
AI Content Safety*.

The catalog has been renamed twice:

[cols="2,2,3", options="header"]
|===
| Old name | New name | Note

| Cognitive Services
| Azure AI services
| Renamed in 2023.

| Azure AI services
| Foundry Tools
| Renamed in 2025, with the move to Microsoft Foundry.

| Azure AI Studio, Azure AI Foundry
| Microsoft Foundry (`https://ai.azure.com`)
| The portal and platform that hosts projects, models, agents and tools.

| Form Recognizer
| Document Intelligence
| Resource kind is still `FormRecognizer`.

| Computer Vision
| Azure Vision
| Resource kind is still `ComputerVision`.
|===

=== Two meanings of "tools"

. **Foundry Tools**, the product catalog documented here.
. **Agent tools**, what a Foundry agent can call: function calling, MCP servers, code interpreter, file search,
  Azure AI Search and the managed MCP servers and connectors of the **Foundry Tools Catalog**. They overlap only
  where a Foundry Tool is exposed to an agent, covered on
  xref:cloud/azure/foundry-tools/foundry-tools-in-agents.adoc[].

**Azure OpenAI is not a Foundry Tool.** It is *Azure OpenAI in Foundry Models*, part of the Foundry **Models**
catalog. It shares the Foundry resource's endpoint family and keys, and several tools call model deployments
(Translator LLM translation, Content Understanding, agentic retrieval), but this sub-section doesn't document models
or the Foundry Agent Service themselves.

== Bookshelf additions

The Azure section's running example, *Bookshelf*, gains these resources in this sub-section:

[cols="2,2,3", options="header"]
|===
| Concern | Name | Used for

| Foundry resource (`AIServices`, custom subdomain)
| `foundry-bookshelf`
| Every tool page; keyless access from `catalog-api` and `orders-api`

| Foundry project
| `proj-bookshelf`
| Agents, connections and the Foundry SDK

| Azure AI Search service
| `search-bookshelf`
| Catalog index and the support knowledge base

| Blob containers in `stbookshelf`
| `media`, `invoices`
| Podcast and video files, audio previews; supplier invoices

| Model deployments
| `gpt-4.1-mini`, `text-embedding-3-large`
| LLM translation, Content Understanding, agentic retrieval
|===
