A single-page index of quick back-links to every page in the Foundry Tools sub-section, grouped the same way as the
xref:cloud/azure/foundry-tools/index.adoc[sub-section index] -- handy for jumping straight to the tool you need.

The xref:attachment$azure-foundry-tools-cheat-sheet.pdf[downloadable PDF] is a separate, single A4 page meant for
printing. It states the version baseline date (2026-10-06, Azure CLI 2.90.0) and covers:

* the catalog of tools with their status and a use-case finder ("use it to...");
* resource kinds (`AIServices`, legacy `CognitiveServices`, single-service kinds), the tool, project, model, Speech
  and Translator endpoints, and the authentication headers and roles;
* the key CLI commands (`account create --kind AIServices`, `project create`, `keys list`, `list-usage`,
  `list-kinds`, role assignment and model deployment);
* per tool, the REST path with its api-version and the Python and .NET packages;
* limits highlights (rate limits, file sizes, characters per request) and network, container and monitoring
  essentials; and
* a retirements timeline strip from 2025 to 2029.
