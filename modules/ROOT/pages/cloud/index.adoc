A growing collection of cloud-provider references -- practical, example-driven documentation on using public
cloud providers from the portal/console and CLI to provision and operate compute, storage, databases, networking
and security.

== Sections

* xref:cloud/comparing-cloud-providers.adoc[Comparing Cloud Providers] -- a side-by-side comparison of AWS, Azure
  and Google Cloud covering market share, adoption, global footprint, services and pricing models.
* xref:cloud/azure/index.adoc[Azure] -- a practical guide to Microsoft Azure: portal and CLI walkthroughs
  covering compute, storage, databases, networking and security, plus a downloadable one-page cheat sheet. Media
  processing is in xref:cloud/azure/media-optimization.adoc[Media Optimization].
* xref:cloud/aws/index.adoc[AWS (Amazon Web Services)] -- a practical guide to Amazon Web Services: Management
  Console and AWS CLI walkthroughs covering compute, storage, databases, networking and security, plus a
  downloadable one-page cheat sheet. Media processing is in
  xref:cloud/aws/media-optimization/index.adoc[Media Optimization].
* xref:cloud/google-cloud/index.adoc[Google Cloud] -- a practical guide to Google Cloud: Google Cloud console and
  gcloud CLI walkthroughs covering compute, storage, databases, networking and security, plus a downloadable
  one-page cheat sheet. Media processing is in xref:cloud/google-cloud/media-optimization.adoc[Media Optimization].

Other cloud providers may be added to this area over time.
