= Media Optimization on AWS
:description: Media processing on AWS: Elemental MediaConvert for video transcoding with HLS, DASH and CMAF output, frame capture and BlurHash covers, S3 and Lambda image processing with Dynamic Image Transformation for Amazon CloudFront, signed-cookie delivery with CloudFront and MediaPackage, and a Video on Demand pipeline with Step Functions.
:keywords: AWS, MediaConvert, Elastic Transcoder, frame capture, Lambda, S3, CloudFront, signed cookies, MediaPackage, MediaLive, IVS, Step Functions, EventBridge, Video on Demand on AWS, Dynamic Image Transformation, bibliography, cheat sheet

include::partial$media-optimization-aws-disclaimer.adoc[]

This sub-section covers image processing, video transcoding, covers and thumbnails, and streaming on AWS, with examples for the
AWS CLI, Python, Node.js, Java and .NET. It uses the Bookshelf names of the
xref:cloud/aws/index.adoc[AWS section] (region `us-east-1`, account `111122223333` and the `bookshelf-uploads` bucket as
placeholders) and is current as of 2026-10-07. The concepts and the self-hosted alternative are in
xref:backend/media-optimization/index.adoc[Media Optimization for the backend].
