= SQL Reference

include::partial$sql-disclaimer.adoc[]

Welcome to the standard SQL reference. This section is organized by statement family and function category so
you can jump straight to what you need, or work through it top to bottom as a refresher.

== What's covered

* xref:sql/ddl.adoc[Data Definition Language (DDL)] -- `CREATE`, `ALTER`, `DROP`, and the standard constraint
  clauses used to define schemas, tables, views, and indexes.
* xref:sql/relations.adoc[Relations] -- the standard relation types (1:1, 1:N, N:1, N:N), how each is modeled,
  and example join queries for each.
* xref:sql/dml-queries.adoc[Querying data (SELECT)] -- the `SELECT` clause order, `DISTINCT`, `GROUP BY`/
  `HAVING`, `WHERE` predicates, and every standard join type.
* xref:sql/dml-modifications.adoc[Modifying data] -- `INSERT`, `UPDATE`, `DELETE`, `MERGE`, and `TRUNCATE`.
* xref:sql/transactions.adoc[Transactions] -- transaction control statements and standard isolation levels.
* xref:sql/dcl.adoc[Data Control Language (DCL)] -- `GRANT`, `REVOKE`, and `SET`.
* xref:sql/functions.adoc[Built-in scalar functions] -- string, numeric, date/time, and type-conversion
  functions.
* xref:sql/aggregate-window-functions.adoc[Aggregate and window functions] -- `COUNT`/`SUM`/`AVG`/`MIN`/`MAX`
  and window functions such as `ROW_NUMBER`, `RANK`, and `LAG`/`LEAD`.
* xref:sql/json-xml-functions.adoc[JSON and XML functions] -- the standard SQL:2016+ JSON functions and the
  standard XML functions.
* xref:sql/triggers-procedures.adoc[Triggers and stored procedures] -- `CREATE TRIGGER`, `CREATE PROCEDURE`,
  and `CREATE FUNCTION` (SQL/PSM).
* xref:sql/cheat-sheet.adoc[Cheat sheet] -- a one-page, downloadable PDF summary of the statements above for
  quick memorization.
