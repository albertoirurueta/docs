*Webflow* is a hosted visual website builder: you design pages in a browser-based *Designer* that writes real HTML, CSS and
JavaScript, you model and edit content in a built-in *CMS*, and Webflow publishes and hosts the result. It also has an
ecommerce engine, localization, forms, an analytics and optimization add-on, AI features, and a *developer platform*
(a REST *Data API*, a command-line interface, Apps, Designer Extensions, DevLink, code components, Webflow Cloud and a
Model Context Protocol server) for people who want to extend or automate it. This sub-section explains all of it, from
the first click in the Designer to a Node.js script that imports plants into the CMS.

== Who this sub-section is for

* *Site owners and project managers* choosing plans, seats and roles, and deciding what Webflow can and cannot do.
* *Designers* who build layouts, design systems and animations visually and want to know the HTML and CSS behind every
  panel.
* *Content editors and marketers* who run collections, publish and schedule content, and manage SEO, forms, redirects
  and localization.
* *Developers* who customize sites with custom code, automate them with the Data API, build Apps and Designer Extensions,
  export React components with DevLink, host server code on Webflow Cloud, or use Webflow as a headless CMS.

== The running example: Fernbrook Gardens

Every page uses one fictitious scenario, *Fernbrook Gardens*, a botanical garden whose site is built step by step. The
site has Home, Visit, Plants, Events, Shop, *Garden Journal*, About and 404 pages and a password-protected *Volunteers*
area. Its design system holds a `brand` variable collection with Day and Night modes, utility classes and the
`PlantCard`, `EventBanner` and `SiteHeader` components. Its CMS holds *Plants*, *Zones*, *Events*, *Journal* and *Staff*.
Operations add a group-visit enquiry form, Spanish and German locales, redirects from an old site and a seed shop. The
developer work adds `fernbrook-sync`, a Node.js and TypeScript script (with a Python variant) that imports plants from a
fictitious nursery feed, a webhook receiver, and *Plant Label Kit*, a Designer Extension that grows into a hybrid app.
No real names, tokens or credentials appear anywhere; secrets are always placeholders.
