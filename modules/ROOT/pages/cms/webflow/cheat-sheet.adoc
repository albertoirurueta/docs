= Webflow Cheat Sheet
:description: A single-page, printable quick reference for Webflow as checked on 2026-10-28 with webflow-api 3.3.4, the Webflow CLI 2.15.0, the Python webflow SDK 2.0.0 and GSAP 3.15.0 -- plans and seats, Designer panels and the box model, breakpoints and selectors, variables and components, interactions, the 16 CMS field types and limits, forms, SEO, redirects, backups, code export, custom code, Data API endpoints, tokens and rate limits, webhooks, CLI commands, DevLink, code components, Webflow Cloud and MCP -- with a downloadable PDF version.

A single-page, colour-coded summary of the Webflow sub-section: the platform (plans, seats and roles, sunset products), the
Designer (panels, the breakpoint cascade, the Style panel and the selector table, flex versus grid, variables, components
and libraries), interactions, the CMS (the 16 field types, limits, Collection lists, template pages, CSV rules and item
states), operations (forms, SEO, redirects, backups, code export, localization, accessibility, performance and a launch
checklist), custom code, the Data API (base URLs, tokens and scopes, rate limits, error codes, the main endpoints, the
item create and publish flow, the Content Delivery API rule and the webhook signature formula), tooling (the CLI,
`webflow.json` skeletons, `declareComponent`, `wrangler.json` bindings and the MCP setup) and a strip of what changed since
older tutorials. It reflects Webflow as checked on 2026-10-28 and the pinned developer tools `webflow-api` 3.3.4,
`@webflow/webflow-cli` 2.15.0 (Node.js 22.13 or later), the Python `webflow` SDK 2.0.0 and GSAP 3.15.0, and is available as
a xref:attachment$cms-webflow-cheat-sheet.pdf[downloadable PDF].
