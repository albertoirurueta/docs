= Where Older Books and Tutorials Are Outdated
:description: A dated list of what older Webflow books, tutorials and forum answers got wrong or no longer match -- plan names and limits, the Designer interface, breakpoints, swatches, Symbols, Classic Interactions, the Editor, code export, fonts, the v1 Data API, devlink sync, the MCP /sse endpoint, Logic and User Accounts -- each as "older advice, current state, source", grouped by area.
:keywords: Webflow outdated tutorials, Webflow by Example, Webflow changes, legacy Editor, Symbols to Components, Variables, swatches, Data API v1, devlink sync, MCP SSE, Logic sunset, User Accounts sunset, Webflow plans, custom code limits, Webflow checked 2026-10-28

include::partial$cms-webflow-disclaimer.adoc[]

Webflow is a hosted product with no version numbers, so a book or tutorial that was correct when it was written can describe
a screen, a plan or an endpoint that no longer exists. This page was checked on 2026-10-28 and lists, area by area, what
older material says, what is true now and where the official source for the current state is. It covers the
book by Ali Rushdan Tariq, _Webflow by Example: Design, build, and publish modern websites without writing
code_ (Packt, 2021), which targets Webflow as it was in 2021, and the advice that recurs in tutorials, community answers
and snippets from 2022 to 2025. The book is cited here only to show where it differs from current documentation; none of
its text is reproduced, and its concepts remain a good introduction. Where any older source and the official
documentation disagree, the official documentation wins. The dated timeline behind most rows is on
xref:cms/webflow/product-changes-and-deprecations.adoc[Product Changes and Deprecations].

== Plans, workspaces and seats

[cols="3,4,3",options=header]
|===
|Older advice |Current state |Where it is explained

|Account plans Lite, Pro and Team and site plans Basic, CMS and Business, with 2,000 or 10,000 items and a 100-page cap.
|The plans were reorganised in May 2026. New purchases from 2026-05-13 use the new tiers (Starter, Basic, Premium, Team and Enterprise, plus the Ecommerce tiers); the former CMS and Business plans were merged into Premium, with 20,000 CMS items and 40 Collections. Existing sites migrate at their next renewal or billable change after 2026-06-29, and sites in Freelancer and Agency Workspaces from 2026-11-16.
|xref:cms/webflow/plans-workspaces-seats-and-roles.adoc[Plans, Workspaces, Seats and Roles] and xref:cms/webflow/cms-limits-and-scaling.adoc[CMS Limits and Scaling]

|Collaborators and clients are added through the CMS plan and edit through the Editor.
|People are assigned seats (Full, Limited, Free, Client) and roles (Owner, Admin, Site manager, Designer, Marketer, Content editor, Reviewer). Three roles were renamed: Site admin is now Site manager, Can edit is now Content editor, and Commenter is now Reviewer. Client seats exist only in Freelancer and Agency Workspaces.
|xref:cms/webflow/plans-workspaces-seats-and-roles.adoc[Plans, Workspaces, Seats and Roles]

|Code export belongs to the Lite plan (one page of the book) or to a paid site plan (another page), which contradict each other.
|Code export is a Workspace feature of paid Workspace plans and is disabled on Developer workspaces. It exports static HTML, CSS and JavaScript and drops the CMS, ecommerce, forms, search, localization and code components.
|xref:cms/webflow/code-export-and-portability.adoc[Code Export and Portability]

|Page branching, approvals and releases do not exist; duplicate a page and rename it.
|Page branching, the publishing workflow and Releases exist on the Team and Enterprise tiers; older articles that say Enterprise only are outdated. A branch carries conflict detection and a review gate.
|xref:cms/webflow/page-branching-releases-and-approvals.adoc[Page Branching, Releases and Approvals]

|"Webflow has no native user accounts."
|Memberships and User Accounts later shipped and were then sunset (User Accounts on 2026-01-29), so the statement is true again, for a different reason. A tutorial that builds a member area with them no longer works.
|xref:cms/webflow/product-changes-and-deprecations.adoc[Product Changes and Deprecations]
|===

== Designer interface and vocabulary

[cols="3,4,3",options=header]
|===
|Older advice |Current state |Where it is explained

|The pre-2023 Designer layout, panel names and click paths.
|The Designer was redesigned on 2023-10-05. Panels were renamed and moved, so a click path from an older source rarely matches the screen.
|xref:cms/webflow/designer-tour.adoc[Designer Tour]

|A site is a "project" and has Project Settings.
|Webflow says site and Site settings.
|xref:cms/webflow/first-site-and-the-dashboard.adoc[First Site and the Dashboard]

|Reusable elements are Symbols.
|Symbols were renamed Components in November 2022, and Components gained properties, slots and variants.
|xref:cms/webflow/components-props-slots-and-variants.adoc[Components, Props, Slots and Variants]

|Colours are swatches; a style guide is built by copying classes.
|Design tokens are variables (colour, size, number, font and percentage) in collections that can have modes such as Day and Night, and Shared Libraries distribute them between sites.
|xref:cms/webflow/variables-and-modes.adoc[Variables and Modes] and xref:cms/webflow/shared-libraries.adoc[Shared Libraries]

|Type class names in Title Case without dashes, such as `Visit Card`.
|The Designer normalises the name into a hyphenated selector, and modern naming systems rely on separators and prefixes such as `is-` and `u-`.
|xref:cms/webflow/class-naming-systems.adoc[Class Naming Systems]

|Design on a 1440 px Desktop canvas; the base breakpoint is 1440.
|The base Desktop breakpoint has no fixed width, and 1440 px is an optional larger breakpoint that, once added, cannot be removed. Design on the base and add 1440 only when wide screens need different values.
|xref:cms/webflow/responsive-design-and-breakpoints.adoc[Responsive Design and Breakpoints]

|Layout is Flexbox or floats; Grid is basic.
|The rule of Flexbox for one dimension and Grid for two still holds, and Grid now has auto-fit, grid areas, line-number positioning and Quick Stack exists for fast flex layouts.
|xref:cms/webflow/flexbox-and-grid-layouts.adoc[Flexbox and Grid Layouts]

|Overlays, clipped text and gradients need extra elements, images or code.
|Gradients, images and overlays can be background styles, including background clipping on text.
|xref:cms/webflow/backgrounds-borders-and-effects.adoc[Backgrounds, Borders and Effects]
|===

== Interactions

[cols="3,4,3",options=header]
|===
|Older advice |Current state |Where it is explained

|The Interactions panel is the Classic panel only.
|Interactions with GSAP launched in July 2025 and GSAP itself became free on 2025-04-30. Classic Interactions still exist and are still needed for some behaviours, but new work normally starts with GSAP-powered interactions.
|xref:cms/webflow/interactions-with-gsap.adoc[Interactions with GSAP] and xref:cms/webflow/classic-interactions.adoc[Classic Interactions]

|Parallax, hide-on-scroll navbar and back-to-top are built with Classic Interactions.
|The method (initial state, final state, transition) is still valid and the recipes can be rebuilt with GSAP-powered interactions; the click paths differ.
|xref:cms/webflow/scroll-and-page-animations.adoc[Scroll and Page Animations]

|Animation is limited to what the panel offers.
|Lottie, Spline and Rive can be added, and variables can be animated.
|xref:cms/webflow/lottie-spline-rive-and-video.adoc[Lottie, Spline, Rive and Video]
|===

== CMS and content

[cols="3,4,3",options=header]
|===
|Older advice |Current state |Where it is explained

|A Collection holds at most 30 fields.
|The limit was raised to 60 fields per Collection in July 2024.
|xref:cms/webflow/cms-concepts-and-content-modeling.adoc[CMS Concepts and Content Modeling] and xref:cms/webflow/collections-and-field-types.adoc[Collections and Field Types]

|Collection lists show a handful of items and nest once or twice.
|A Collection list shows 100 items unless pagination is on, a page can hold 20 lists (up to 40 on Enterprise and the next-generation CMS), and the next-generation CMS allows up to ten nested lists three layers deep.
|xref:cms/webflow/cms-limits-and-scaling.adoc[CMS Limits and Scaling] and xref:cms/webflow/collection-lists.adoc[Collection Lists]

|Edit content by adding `/?edit` to the published site and signing in to the Editor.
|The legacy Editor became unavailable on 2026-08-04 and was fully deprecated on 2026-10-05, when the `?edit` URL stopped working. Content is edited on the canvas with a role on a seat.
|xref:cms/webflow/content-editing-on-the-canvas.adoc[Content Editing on the Canvas]

|Conditional visibility covers "is set" and switch cases.
|Option fields are supported, and an Advanced setting keeps hidden elements in the HTML.
|xref:cms/webflow/conditional-visibility-and-dynamic-embeds.adoc[Conditional Visibility and Dynamic Embeds]

|CSV import loads plain fields only.
|CSV import supports reference and multi-reference columns and updates through the Item ID, within the documented size limit.
|xref:cms/webflow/csv-import-and-export.adoc[CSV Import and Export]

|A backup restore returns the site exactly as it was.
|Restoring a backup made before 2024-03-25 resets Collection and item IDs; later backups keep them. Reference and multi-reference relationships and integrations that store IDs are affected.
|xref:cms/webflow/backups-and-recovery.adoc[Backups and Recovery]

|`isDraft: true` through the API unpublishes a live item.
|Since 2025-07-07 setting `isDraft: true` on a live item through the API no longer unpublishes it.
|xref:cms/webflow/data-api-cms.adoc[Data API: CMS]
|===

== Images, fonts and assets

[cols="3,4,3",options=header]
|===
|Older advice |Current state |Where it is explained

|There is no image optimization; convert images yourself.
|The Assets panel can convert images to AVIF or WebP (since 2024-07-31), and new images lazy-load by default.
|xref:cms/webflow/images-and-assets.adoc[Images and Assets] and xref:cms/webflow/performance-optimization.adoc[Performance Optimization]

|Add Google Fonts in the project settings.
|Google Fonts load from Google's servers, which raises a privacy question for European audiences; upload the font files to self-host. Variable fonts and font variables are available.
|xref:cms/webflow/typography-and-fonts.adoc[Typography and Fonts]

|Alt text is optional or added later.
|Alt text can be set at upload, in a CMS alt-text field and decoratively; the Audit panel checks it before publishing.
|xref:cms/webflow/accessibility.adoc[Accessibility in Webflow]
|===

== Custom code and hosting

[cols="3,4,3",options=header]
|===
|Older advice |Current state |Where it is explained

|The head and footer boxes hold 10,000 characters for the site and 20,000 for a page.
|The limit is 50,000 characters per head and footer box and per Code Embed.
|xref:cms/webflow/custom-code-head-footer-and-embeds.adoc[Custom Code: Head, Footer and Embeds]

|Custom code is a page-settings tab only; script with jQuery.
|Custom code lives in Site settings, Page settings and embeds. Webflow still ships jQuery, but plain JavaScript is the normal choice and the JavaScript is minified by default.
|xref:cms/webflow/custom-attributes-and-javascript.adoc[Custom Attributes and JavaScript]

|Forms use reCAPTCHA only and Logic flows react to submissions.
|Cloudflare Turnstile and honeypots complement reCAPTCHA, and Logic was sunset on 2025-06-27.
|xref:cms/webflow/forms.adoc[Forms]

|"Showcase" lists published sites.
|The gallery is Made in Webflow, and sharing needs a paid plan.
|xref:cms/webflow/first-site-and-the-dashboard.adoc[First Site and the Dashboard]

|Webflow University has the lessons.
|Much of the user documentation moved to the Help Center; University remains for lessons and the glossary.
|xref:cms/webflow/index.adoc#_bibliography[Bibliography]
|===

== Developer platform

[cols="3,4,3",options=header]
|===
|Older advice |Current state |Where it is explained

|Call `https://api.webflow.com/sites` and other v1 endpoints.
|The v1 API is unsupported since 2025-03-31 and apps that used it were de-listed from 2024-08-01. Use v2 at `https://api.webflow.com/v2` with a token that has the right scopes.
|xref:cms/webflow/data-api-authentication-and-scopes.adoc[Data API Authentication and Scopes] and xref:cms/webflow/data-api-sdks-limits-and-errors.adoc[Data API: SDKs, Limits and Errors]

|Run `webflow devlink sync` to pull components into a React app.
|`devlink sync` was removed in CLI 2.9.0; use `webflow devlink export`.
|xref:cms/webflow/devlink-export.adoc[DevLink Export]

|Point an MCP client at the `/sse` URL.
|The `/sse` endpoint was retired on 2025-11-24; the remote server is reached at `https://mcp.webflow.com/mcp`.
|xref:cms/webflow/mcp-server-and-ai-agents.adoc[Webflow MCP Server and AI Agents]

|A site token or API key is enough for every integration.
|Choose between site tokens, Workspace tokens and OAuth Data Client apps, each with its own scopes and rate limits.
|xref:cms/webflow/data-api-authentication-and-scopes.adoc[Data API Authentication and Scopes]

|A webhook payload can be trusted.
|Verify `x-webflow-signature` and `x-webflow-timestamp` before acting.
|xref:cms/webflow/webhooks.adoc[Webhooks]

|Server-side logic needs a separate host.
|Webflow Cloud runs Next.js, Astro and Vite apps with SQLite, key-value and object storage; storage became generally available on 2025-11-06.
|xref:cms/webflow/webflow-cloud.adoc[Webflow Cloud]

|AI is a chat helper.
|AI site building, the AI Assistant, AI code components and credits are plan features, with credit limits enforced since 2026-06-29.
|xref:cms/webflow/ai-features-and-credits.adoc[AI Features and Credits]
|===

== Generic warning signs in older tutorials

A tutorial is probably out of date when it:

* shows a Designer screen with a "project" menu, a Symbols panel, swatches or only the Classic Interactions panel;
* quotes a plan name from before May 2026, a price, an item count of 2,000 or 10,000 or a custom-code limit of 10,000 or 20,000 characters;
* tells you to edit content through `/?edit` or to invite someone as a "Can edit" collaborator;
* calls a v1 endpoint, installs an old SDK or uses `devlink sync` or an MCP `/sse` address;
* builds a member area, a Logic flow or a form automation that depends on features sunset in 2025 and 2026;
* relies on an undocumented call such as `Webflow.push` or `+Webflow.require('ix2')+` without saying that it is unofficial (see
  xref:cms/webflow/custom-attributes-and-javascript.adoc[Custom Attributes and JavaScript]).

When in doubt, check the date of the source against the timeline on
xref:cms/webflow/product-changes-and-deprecations.adoc[Product Changes and Deprecations] and confirm the fact in the
official documentation below.
