= Drupal Cheat Sheet
:description: A single-page, printable quick reference for Drupal as checked on 2026-10-30 with Drupal 11.4.x, Drush 13 and 14, PHP 8.3 or later and the scheduled Drupal 12.0.0 and Drupal 10 end-of-life dates -- request lifecycle, entity bundle field model, install commands, site building, settings.php keys, drush deploy, recipes, theming skeletons, module skeletons, JSON:API URL patterns, Drush commands, testing and static analysis, upgrade checklist, AI module and MCP Server, with a downloadable PDF version.
:keywords: Drupal cheat sheet, Drupal quick reference, Drupal 11, Drupal 12, Drush commands, settings.php, drush deploy, Drupal recipes, Single Directory Components, Twig, OOP hooks, JSON:API, Drupal Canvas, Drupal CMS, PHPStan, Upgrade Status, Drupal AI module, MCP Server, printable reference

A single-page, colour-coded summary of the Drupal sub-section. The platform block gives the request lifecycle in one line, the
entity, bundle and field model, the difference between configuration, content and state, the version and support dates
(Drupal 11.4, the scheduled Drupal 12.0.0 and the Drupal 10 end of life) and the requirements and project tree for each major
version. The install block lists the `composer create-project`, DDEV and `drush site:install` commands and the Drupal CMS
templates. Site building covers the content type, fields, displays and Views path, the core field types, text formats,
Layout Builder versus Canvas, roles and permissions, moderation states, the multilingual modules and the modules that move to
contributed projects in Drupal 12. Administration collects the `settings.php` keys (`trusted_host_patterns`, `hash_salt`,
`config_sync_directory`, `file_private_path` and the reverse proxy settings) with safe values, the `drush deploy` steps, the
Composer update routine, the security release days, the recipe skeleton, the cache layers, cron and a hardening checklist.
Theming holds the `+*.info.yml+` and `+*.libraries.yml+` skeletons, the Twig filters and functions, template suggestion naming, the
Starterkit command, the Single Directory Component skeleton with its `include` and `embed` calls, breakpoints and Twig debug.
Module development holds the `+*.info.yml+`, `+*.routing.yml+` and `+*.services.yml+` skeletons, a controller, an object-oriented
hook class, an event subscriber, a `ConfigFormBase` form, a block plugin with attributes, an entity query with `accessCheck()`,
`+#cache+` keys, `AccessResult` one-liners, a queue worker and the difference between `hook_update_N` and post-update functions.
The remaining blocks cover the JSON:API URL patterns, a REST, JSON:API and GraphQL comparison and the OAuth grants, the 20 most
useful Drush commands, the test types and base classes, the PHPCS, PHPStan, Upgrade Status and Rector commands, the Drupal 10
to 11 to 12 upgrade checklist with minimum versions, the AI module and MCP Server one-liners, and a strip of what changed
since older tutorials (attributes instead of annotations, OOP hooks, Single Directory Components, recipes, Drupal CMS, Canvas,
Drush 13, PHPUnit attributes, the removal of UI installs and updates, Navigation and Default Admin, argon2id and the removal of
IIS support).

It reflects Drupal as checked on 2026-10-30 with Drupal 11.4.x, Drush 13 and 14 and PHP 8.3 or later, and is available as a
xref:attachment$cms-drupal-cheat-sheet.pdf[downloadable PDF].
