A single-page, colour-coded summary of every topic of this sub-section: the platform (request lifecycle, core
directories, the twelve core tables, version numbering and requirements), using WordPress (settings screens, roles,
post statuses, editor shortcuts and media formats), administration (`wp-config.php` production values, Apache 2.4 and
nginx rules, permissions, auto-updates, hardening, caching layers, cron, debugging and Multisite), block and classic
themes, plugin and block development, the APIs, tooling and delivery, headless and AI, and a strip of what changed since
older books and tutorials. It reflects WordPress 7.1.3 (examples tested; WordPress 7.1.4, released on 2026-10-28, is
the current security release and should be used in production; 7.2 is planned for 2026-12-08), PHP 7.4 minimum with 8.3 or later recommended,
`theme.json` version 3, Gutenberg 24.2.0, `@wordpress/scripts` 37.0.0, `@wordpress/create-block` 5.0.0,
`@wordpress/env` 12.0.0, WP-CLI 2.12.0 and WPCS 3.4.1, checked on 2026-10-28, and is available as a
xref:attachment$cms-wordpress-cheat-sheet.pdf[downloadable PDF].
