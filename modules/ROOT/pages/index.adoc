== Guides & References
Beyond the projects above, this site also hosts a few standalone guides and references that don't belong to any
single project:

* xref:database/index.adoc[Database Development] -- a growing collection of database-development references,
  starting with SQL.
** xref:database/sql/index.adoc[SQL Reference] -- a standard SQL reference covering DDL, DML, DCL, functions,
  and triggers/stored procedures, plus a downloadable one-page cheat sheet.
* xref:web/index.adoc[Web Development] -- a growing collection of web-development references, starting
  with HTML & CSS.
** xref:web/html-css/index.adoc[HTML & CSS Reference] -- structure, layout, styling, forms, performance,
  and a downloadable cheat sheet.
** xref:web/sass/index.adoc[Sass Reference] -- the SASS/SCSS CSS preprocessor: syntax, variables, nesting,
  mixins, functions, and modules, plus a downloadable cheat sheet.
** xref:web/javascript/index.adoc[JavaScript Development] -- modern ECMAScript, core browser APIs, and the
  surrounding tooling ecosystem (ESLint, Jest, Babel, npm), plus a downloadable cheat sheet.
** xref:web/bootstrap/index.adoc[Bootstrap Reference] -- the Bootstrap 5 CSS/JS framework: the grid system,
  components, utilities and the Utility API, customization, and JavaScript behavior, plus a downloadable cheat
  sheet.
** xref:web/jquery/index.adoc[jQuery Reference] -- DOM traversal/manipulation, events, effects, and AJAX with
  jQuery 3.x, when to prefer native APIs, plus a downloadable cheat sheet and a self-test questionnaire with
  verified answers.
** xref:web/react/index.adoc[React Reference] -- components and Hooks, state, effects, Suspense, forms and
  Actions, data fetching, SSR/SSG/RSC, and build and deployment with React 19, plus a downloadable cheat
  sheet.

== About me
I'm Alberto Irurueta Carro, a software engineer with a soft spot for turning equations into working
code. Most of my time goes into building the open-source Java libraries documented on this very site --
covering everything from linear algebra, statistics, sorting and numerical methods, to more applied work
in computer vision, 3D reconstruction and augmented reality.

When I'm not chasing eigenvalues or wrangling point clouds, you'll find me tinkering with things like
indoor Wi-Fi based navigation or an AR app that estimates shoe size from a photo -- proof that geometry
is good for more than homework. I care about code that is well tested, well documented and genuinely
useful, which is, not entirely by coincidence, why this documentation site exists in the first place.

You can find more about me, and all these projects, on
https://github.com/albertoirurueta/albertoirurueta[Github].
