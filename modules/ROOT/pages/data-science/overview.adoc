All pages target the following versions. Examples target Python 3.13 or 3.14 and were run on Python 3.13, with the
library versions below; the version numbers and links were checked in October 2026.

|Component |Version |Notes

|2.5

== Reading order

. Read xref:data-science/what-is-data-science.adoc[What Is Data Science?] and
  xref:data-science/data-science-workflow.adoc[The Data Science Workflow] to learn the vocabulary and the phases of a
  project.
. Set up your tools with xref:data-science/environment-setup.adoc[Setting Up a Data Science Environment] and
  xref:data-science/jupyter-notebooks.adoc[Jupyter Notebooks & JupyterLab].
. Learn the array and table foundations in the xref:data-science/numpy/index.adoc[NumPy] and
  xref:data-science/pandas/index.adoc[pandas] sub-sections, with
  xref:data-science/python-scientific-stack.adoc[The Scientific Python Stack] as the map of how libraries relate.
. Work through acquisition, cleaning, exploration and visualisation, then
  xref:data-science/statistics-fundamentals.adoc[Statistics Fundamentals].
. Move on to xref:data-science/feature-engineering.adoc[Feature Engineering],
  xref:data-science/machine-learning-fundamentals.adoc[Machine Learning Fundamentals] and
  xref:data-science/model-evaluation.adoc[Model Evaluation & Validation], using the
  xref:data-science/scikit-learn/index.adoc[scikit-learn] sub-section for detail.
. Finish with ethics, reproducibility and tool choice, and keep the
  xref:data-science/cheat-sheet.adoc[Data Science Cheat Sheet] open while you work.
