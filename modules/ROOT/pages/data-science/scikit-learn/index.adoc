*scikit-learn* is the general-purpose machine-learning library of the scientific Python ecosystem. It offers a uniform
interface for classification, regression, clustering, dimensionality reduction, preprocessing, model selection and
evaluation, built on NumPy, SciPy and joblib. This sub-section belongs to the xref:data-science/index.adoc[Data Science]
section and explains the library page by page, from installation and the estimator API to pipelines, validation,
inspection and deployment concerns such as model persistence. For a one-page summary of the most used calls, see the
xref:data-science/cheat-sheet.adoc#_scikit_learn[scikit-learn part of the cheat sheet].

== What the names mean

The same project appears under three spellings, and each one refers to something different.

[cols="2,4",options="header"]
|===
|Name |Meaning

|scikit-learn
|The project and its distribution (package) name. It is what you install: `pip install scikit-learn`. The FAQ gives
this as the correct spelling, not "scikit", "SciKit" or "sci-kit learn".

|scikit
|A short form of "SciPy toolkit". There are several scikits, which are scientific toolboxes built around SciPy. Besides
scikit-learn, a popular one is scikit-image. Earlier versions of the project were called `scikits.learn` and
`scikits-learn`, names that are no longer used.

|sklearn
|The import name of the Python package: `import sklearn`, or `from sklearn.linear_model import LogisticRegression`.
The distribution name and the import name differ, so a package called `sklearn` on PyPI is not the library.
|===

The FAQ pronounces the name "sy-kit learn", where "sci" stands for science. The installation steps, including the
difference between the distribution name and the import name, are on
xref:data-science/scikit-learn/installation.adoc[Installing scikit-learn].

Source: https://scikit-learn.org/stable/faq.html[scikit-learn FAQ].

== Where scikit-learn sits in the stack

scikit-learn works on in-memory arrays and DataFrames and does not train deep neural networks. Arrays come from
NumPy, tabular data usually from pandas, and plotting from Matplotlib. For the surrounding workflow see
xref:data-science/index.adoc[Data Science], and for libraries that complement it see the pages linked from there.
