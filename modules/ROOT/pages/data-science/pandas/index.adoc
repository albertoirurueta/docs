:description: Landing page for the pandas reference -- the version baseline (pandas 3.1, Python 3.12 or later, NumPy 2.5, checked October 2026), a concept-to-page map covering every pandas page, a suggested learning path and a bibliography of official sources and books.
:keywords: pandas, DataFrame, Series, Index, MultiIndex, groupby, merge, join, concat, pivot, reshape, time series, resampling, rolling windows, missing data, nullable dtypes, categorical, PyArrow, copy-on-write, pd.col, read_csv, Parquet, performance, pandas 3, pandas 3.1

include::partial$data-science-pandas-disclaimer.adoc[]

*pandas* is the Python library for labelled, tabular and time-series data. This sub-section of the
xref:data-science/index.adoc[Data Science] section explains pandas from installation to large-data techniques, with
runnable examples and a link to the official documentation page each example derives from. It is written against
*pandas 3.1* on *Python 3.12 or later* with *NumPy 2.5*, and the versions, behaviour and links were checked in
October 2026. The pandas entries of the xref:data-science/cheat-sheet.adoc#_pandas[Data Science cheat sheet] give the
shortest summary of the same material.

prose with versions and dates. The migration summary is on xref:data-science/pandas/whats-new-and-migrating.adoc[What's New in 3.x and Migrating].

== Suggested learning path

. Install a supported environment with xref:data-science/pandas/installation-and-versions.adoc[Installing pandas and Understanding Its Versions], then follow xref:data-science/pandas/ten-minutes-to-pandas.adoc[10 Minutes to pandas].
. Learn the structures: xref:data-science/pandas/series.adoc[Series], xref:data-science/pandas/dataframe.adoc[DataFrame] and xref:data-science/pandas/index-objects.adoc[Index Objects].
. Practise selection with xref:data-science/pandas/indexing-and-selecting.adoc[Indexing and Selecting] and the semantics in xref:data-science/pandas/copy-on-write.adoc[Copy-on-Write].
. Load real data through the input and output pages, starting with xref:data-science/pandas/io-csv-and-text.adoc[CSV & Text Files].
. Clean it with xref:data-science/pandas/missing-data.adoc[Missing Data in pandas], xref:data-science/pandas/duplicates.adoc[Duplicate Labels and Rows in pandas] and xref:data-science/pandas/text-data-and-str-dtype.adoc[Text Data & the str Dtype in pandas].
. Summarise and reshape with xref:data-science/pandas/groupby.adoc[Group By: Split-Apply-Combine], xref:data-science/pandas/merge-and-join.adoc[Merge & Join in pandas] and xref:data-science/pandas/pivot-and-pivot-tables.adoc[Pivot & Pivot Tables in pandas].
. Add time with xref:data-science/pandas/time-series.adoc[Time Series and Dates] and xref:data-science/pandas/resampling-and-frequencies.adoc[Resampling and Frequencies].
. Scale up with xref:data-science/pandas/enhancing-performance.adoc[Enhancing Performance] and xref:data-science/pandas/scaling-to-large-datasets.adoc[Scaling to Large Datasets].
