= NumPy

:keywords: NumPy, NumPy 2.5, ndarray, dtype, broadcasting, indexing, ufuncs, linear algebra, random Generator, FFT, masked arrays, structured arrays, datetime64, StringDType, free-threading, NumPy 2 migration, array API, data science

*NumPy* is the array library that the rest of the Python scientific stack builds on: pandas, SciPy, scikit-learn and
Matplotlib all store and exchange their numbers as NumPy arrays. This sub-section is a practical reference to the
library, from the first `ndarray` to memory layout, threading and the C API. It belongs to the
xref:data-science/index.adoc[Data Science] section, which also holds the pandas and scikit-learn sub-sections, and a
condensed summary of the commands most used day to day is on the
xref:data-science/cheat-sheet.adoc#_numpy[NumPy part of the cheat sheet].

== Version baseline

Every page targets *NumPy 2.5*, and the facts were checked against the official documentation in October 2026.
Examples target Python 3.13 or 3.14 and were run on Python 3.13. NumPy 2.5 itself needs Python 3.12 or later.
Code written for NumPy 1.x often needs small changes; the
xref:data-science/numpy/numpy-2-migration.adoc[Migrating to NumPy 2.x] page lists them, and
xref:data-science/numpy/whats-new.adoc[What's New in NumPy 2.1 to 2.5] follows the releases one by one.

== How to read this sub-section

* New to NumPy: read xref:data-science/numpy/absolute-basics.adoc[The Absolute Basics of NumPy], then array creation,
  basic indexing, broadcasting and reductions, in that order.
* Coming from NumPy 1.x: start with xref:data-science/numpy/numpy-2-migration.adoc[Migrating to NumPy 2.x],
  xref:data-science/numpy/type-promotion.adoc[Type Promotion (NEP 50)] and
  xref:data-science/numpy/strings-and-stringdtype.adoc[Strings, Bytes and StringDType].
* Chasing speed or surprising results: the memory layout, copies and views, floating-point and threading pages explain
  most of them.
