This page covers the editors, IDEs and browser tools commonly used to build and debug web applications. Choose a
full IDE for deep framework integration, or a lightweight editor with extensions for speed and flexibility.

== Editors and IDEs

* https://code.visualstudio.com/[*VS Code*] -- a free, extensible editor with a large extension ecosystem for web
  development.
* https://www.jetbrains.com/webstorm/[*WebStorm*] -- the JetBrains IDE for JavaScript and TypeScript with built-in
  framework support.
* https://www.jetbrains.com/idea/features/[*IntelliJ IDEA Ultimate*] -- a full-stack IDE that includes web
  development features.
* https://www.sublimetext.com/[*Sublime Text*] -- a fast, lightweight text editor.
* https://zed.dev/[*Zed*] -- a high-performance, collaborative code editor.

== Browser DevTools

* https://developer.chrome.com/docs/devtools[*Chrome DevTools*] -- inspect the DOM, debug JavaScript, and profile
  network and performance in Chrome.
* https://firefox-source-docs.mozilla.org/devtools-user/[*Firefox DevTools*] -- Firefox's inspector, debugger and
  network tools, with strong CSS layout tooling.
* https://developer.apple.com/safari/tools/[*Safari Web Inspector*] -- Safari's tools for inspecting and debugging
  pages, including on iOS devices.
