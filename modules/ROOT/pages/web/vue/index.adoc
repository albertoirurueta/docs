Welcome to the Vue.js reference. https://vuejs.org/[Vue.js] is a progressive JavaScript framework for building
user interfaces: you describe the UI declaratively as a tree of components, and Vue's reactivity system keeps
the DOM in sync with the state each component reads. This section documents the **current Vue 3.x release
line**, using the Composition API with `<script setup>` throughout (the Options API appears only as a
labelled contrast), written and verified against https://vuejs.org/[the official documentation].

If you are new to Vue, start with xref:web/vue/getting-started.adoc[Getting Started] and
xref:web/vue/template-syntax.adoc[Template Syntax], then xref:web/vue/reactivity-fundamentals.adoc[Reactivity
Fundamentals] and xref:web/vue/components-basics.adoc[Components Basics], then work down the list or jump to
what you need.

== What's covered

=== Essentials

* xref:web/vue/getting-started.adoc[Getting Started] -- what Vue is, the progressive framework, the SFC shape,
  the Options and Composition API styles, the ways of using Vue, and `createApp` / `app.mount` / `app.config`.
* xref:web/vue/template-syntax.adoc[Template Syntax] -- text interpolation and `v-html`, attribute bindings
  with `v-bind`, directive arguments and modifiers, the `:` / `@` / `#` shorthands, and dynamic `class` and
  `style` bindings.
* xref:web/vue/reactivity-fundamentals.adoc[Reactivity Fundamentals] -- `ref()` and `reactive()`, ref
  unwrapping and the `reactive` caveats, `toRefs` / `toRef`, `nextTick`, and how the track / trigger
  dependency system works under the hood.
* xref:web/vue/computed-properties.adoc[Computed Properties] -- `computed()`, caching versus methods, writable
  computed with `get` / `set`, and `computed` versus `watch`.
* xref:web/vue/conditional-and-list-rendering.adoc[Conditional and List Rendering] -- `v-if` / `v-else` /
  `v-show`, `v-for` over arrays, objects and ranges, the `key` requirement, and the `v-if` + `v-for`
  precedence trap.
* xref:web/vue/event-handling.adoc[Event Handling] -- `v-on` / `@`, inline versus method handlers, and the
  event, key and mouse-button modifiers.
* xref:web/vue/form-input-bindings.adoc[Form Input Bindings] -- `v-model` on text, checkbox, radio and select
  inputs, what it desugars to, and the `.lazy` / `.number` / `.trim` modifiers.
* xref:web/vue/watchers.adoc[Watchers] -- `watch` and `watchEffect`, `deep` / `immediate` / `once`, callback
  flush timing, and `onWatcherCleanup`.
* xref:web/vue/template-refs.adoc[Template Refs] -- `useTemplateRef()` and the `ref` attribute, refs in
  `v-for`, function refs, and component refs with `defineExpose()`.
* xref:web/vue/lifecycle-hooks.adoc[Lifecycle Hooks] -- the lifecycle diagram, registering hooks in `setup`,
  and the Options API equivalents.
* xref:web/vue/components-basics.adoc[Components Basics] -- defining and registering components, passing props,
  listening to events, a first look at slots, and dynamic components.

=== Components in depth

* xref:web/vue/registration-and-props.adoc[Registration and Props] -- global versus local registration,
  `defineProps()` runtime and type-based declaration, prop validation, one-way flow, and reactive props
  destructure.
* xref:web/vue/component-events-and-v-model.adoc[Component Events and v-model] -- `defineEmits()` and declared
  events, `defineModel()`, `v-model` arguments and modifiers, and fallthrough attributes with `$attrs` and
  `inheritAttrs`.
* xref:web/vue/slots.adoc[Slots] -- default, named and scoped slots, the `#` shorthand, conditional and
  dynamic slot names, and the renderless component pattern.
* xref:web/vue/provide-inject.adoc[Provide / inject] -- `provide` / `inject`, app-level provide, typed
  injection keys, and keeping provided values reactive.
* xref:web/vue/async-components.adoc[Async Components] -- `defineAsyncComponent`, the loading and error states,
  and pairing with route-level code splitting and `<Suspense>`.
