= Web Development
:description: Landing page for the Web Development reference section, linking to the HTML & CSS Reference, Sass Reference, JavaScript Development, Bootstrap Reference, jQuery Reference, and React Reference documentation subsections.
:keywords: web development, HTML, CSS, SASS, SCSS, CSS preprocessor, JavaScript, ECMAScript, browser APIs, Bootstrap, Bootstrap 5, CSS framework, jQuery, jQuery 3, React, React 19, components, Hooks, DOM manipulation, front-end development, web development reference

A growing collection of web-development references -- practical, example-driven documentation on the core
technologies of the web.

== Sections

* xref:web/cors.adoc[What is CORS?] -- what Cross-Origin Resource Sharing is, how the browser and server
  negotiate it, and how to validate origins correctly on the backend.
* xref:web/accessibility.adoc[Web Accessibility] -- what web accessibility is, the WCAG A/AA/AAA conformance
  levels, legal accessibility standards in Spain, Europe, and the USA, and validation tools.
* xref:web/html-css/index.adoc[HTML & CSS Reference] -- structure, layout, styling, forms, and performance,
  covering modern HTML5 and CSS from the ground up, plus a downloadable cheat sheet.
* xref:web/sass/index.adoc[Sass Reference] -- the SASS/SCSS CSS preprocessor: syntax, variables, nesting,
  mixins, functions, and modules, plus a downloadable cheat sheet.
* xref:web/javascript/index.adoc[JavaScript Development] -- modern ECMAScript, core browser APIs, and the
  surrounding developer-tooling ecosystem, plus a downloadable cheat sheet.
* xref:web/bootstrap/index.adoc[Bootstrap Reference] -- the Bootstrap 5 CSS/JS framework: the grid system,
  components, utilities and the Utility API, customization, and JavaScript behavior, plus a downloadable cheat
  sheet.
* xref:web/jquery/index.adoc[jQuery Reference] -- DOM traversal/manipulation, events, effects, and AJAX with
  jQuery 3.x, when to prefer native APIs, plus a downloadable cheat sheet and a self-test questionnaire with
  verified answers.
* xref:web/react/index.adoc[React Reference] -- components and Hooks, state, effects, Suspense, forms and
  Actions, data fetching, SSR/SSG/RSC, and build and deployment with React 19, plus a downloadable cheat
  sheet.
