== Sections

* xref:web/cors.adoc[What is CORS?] -- what Cross-Origin Resource Sharing is, how the browser and server
  negotiate it, and how to validate origins correctly on the backend.
* xref:web/accessibility.adoc[Web Accessibility] -- what web accessibility is, the WCAG A/AA/AAA conformance

* xref:web/sass/index.adoc[Sass Reference] -- the SASS/SCSS CSS preprocessor: syntax, variables, nesting,
  mixins, functions, and modules, plus a downloadable cheat sheet.
* xref:web/javascript/index.adoc[JavaScript Development] -- modern ECMAScript, core browser APIs, and the
  surrounding developer-tooling ecosystem, plus a downloadable cheat sheet.
* xref:web/bootstrap/index.adoc[Bootstrap Reference] -- the Bootstrap 5 CSS/JS framework: the grid system,
  components, utilities and the Utility API, customization, and JavaScript behavior, plus a downloadable cheat
  sheet.
* xref:web/jquery/index.adoc[jQuery Reference] -- DOM traversal/manipulation, events, effects, and AJAX with

  verified answers.
* xref:web/react/index.adoc[React Reference] -- components and Hooks, state, effects, Suspense, forms and

* xref:web/angular/index.adoc[Angular Reference] -- components and templates, signals, the built-in control

* xref:web/aspnet/index.adoc[ASP.NET Reference] -- the minimal hosting model, the middleware pipeline, DI and

  downloadable cheat sheet.
* xref:web/tailwind/index.adoc[Tailwind Reference] -- the utility-first CSS framework: the utility-first
  workflow, states and variants, responsive design and container queries, dark mode, theme variables and the
  OKLCH palette, Preflight, the utility families, CSS-first customization with `@theme` / `@utility` /
  `@custom-variant`, arbitrary values, build and production, and a v3-to-v4 upgrade guide for Tailwind CSS v4,
  plus a downloadable cheat sheet.
* xref:web/typescript/index.adoc[TypeScript Reference] -- the typed superset of JavaScript: the type system and

  JavaScript interop and migration, plus a downloadable cheat sheet.
* xref:web/vue/index.adoc[Vue.js Reference] -- the progressive framework: reactivity and the Composition API

  Vue Router, Pinia, testing, SSR, and Vue with TypeScript, plus a downloadable cheat sheet.
* xref:web/vaadin/index.adoc[Vaadin Reference] -- the server-driven Java web framework: Flow (Java UI) and

  testing, and production deployment, plus a UI component libraries survey and a downloadable cheat sheet.
