A single-page, colour-coded summary of PHP web development with Laravel, written against Laravel 13.x (13.34.0) on PHP
8.3 to 8.5 (versions verified 2026-10-05) -- a plain PHP strip with the superglobals, output escaping, a PDO prepared
statement, session hardening, the upload checklist and PHP-FPM behind Nginx, the request lifecycle, the `laravel new`
