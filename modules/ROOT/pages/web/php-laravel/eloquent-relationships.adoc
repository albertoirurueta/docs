== Defining relationships

Each relationship is a method returning a relation object; Eloquent infers foreign keys from the names (`author_id`
for `belongsTo(Author::class)`, `book_id` for `hasMany(Review::class)`):

[source,php]
----
<?php
// app/Models/Author.php
namespace App\Models;

use Illuminate\Database\Eloquent\Attributes\Fillable;
use Illuminate\Database\Eloquent\Factories\HasFactory;
use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Relations\HasMany;
use Illuminate\Database\Eloquent\Relations\HasManyThrough;
use Illuminate\Database\Eloquent\Relations\MorphOne;

#[Fillable(['name'])]
class Author extends Model
{
    /** @use HasFactory<\Database\Factories\AuthorFactory> */
    use HasFactory;

    public function books(): HasMany                           // one-to-many
    {
        return $this->hasMany(Book::class);
    }

    public function reviews(): HasManyThrough                  // authors -> books -> reviews
    {
        return $this->hasManyThrough(Review::class, Book::class);
    }

    public function portrait(): MorphOne                       // one image, polymorphic
    {
        return $this->morphOne(Image::class, 'imageable');
    }
}
----

[source,php]
----
<?php
// app/Models/Book.php (the relationship methods)
namespace App\Models;

use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Relations\BelongsTo;
use Illuminate\Database\Eloquent\Relations\BelongsToMany;
use Illuminate\Database\Eloquent\Relations\HasMany;
use Illuminate\Database\Eloquent\Relations\HasOne;
use Illuminate\Database\Eloquent\Relations\MorphMany;

class Book extends Model
{
    public function author(): BelongsTo
    {
        return $this->belongsTo(Author::class);
    }

    public function reviews(): HasMany
    {
        return $this->hasMany(Review::class);
    }

    public function latestReview(): HasOne                     // has-one-of-many
    {
        return $this->hasOne(Review::class)->latestOfMany();
    }

    public function bestReview(): HasOne
    {
        return $this->hasOne(Review::class)->ofMany('rating', 'max');
    }

    public function tags(): BelongsToMany
    {
        return $this->belongsToMany(Tag::class)->withPivot('added_by');
    }

    public function loans(): HasMany
    {
        return $this->hasMany(Loan::class);
    }

    public function images(): MorphMany
    {
        return $this->morphMany(Image::class, 'imageable');
    }
}
----

[source,php]
----
<?php
// app/Models/Image.php and the morph map in AppServiceProvider::boot()
namespace App\Models;

use Illuminate\Database\Eloquent\Attributes\Fillable;
use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Relations\MorphTo;
use Illuminate\Database\Eloquent\Relations\Relation;

#[Fillable(['path', 'alt'])]
class Image extends Model
{
    public function imageable(): MorphTo                       // a Book or an Author
    {
        return $this->morphTo();
    }
}

Relation::enforceMorphMap([   // store 'book', not 'App\Models\Book'
    'book' => \App\Models\Book::class,
    'author' => \App\Models\Author::class,
    'user' => \App\Models\User::class,
]);
----

Source: https://laravel.com/framework/docs/13.x/eloquent-relationships#one-to-many[Laravel -- One to Many], https://laravel.com/framework/docs/13.x/eloquent-relationships#has-one-of-many[Has One of Many] and https://laravel.com/framework/docs/13.x/eloquent-relationships#custom-polymorphic-types[Custom Polymorphic Types]

* `+$book->author+` (a *dynamic property*) runs the query once and caches the result on the model;
  `+$book->author()+` returns the relation to keep building (`+$author->books()->where(...)+`).
* `latestOfMany()` and `ofMany('rating', 'max')` turn a one-to-many into a single related row selected by a
  subquery, so "latest review" needs no `+orderBy()->first()+` per book.
* `hasManyThrough()` reaches reviews of an author's books through `books.author_id` and `reviews.book_id`;
  `hasOneThrough()` is the single-row form.
* *Polymorphic* relations store the parent's type and ID (`imageable_type`, `imageable_id`, created by
  `+$table->morphs('imageable')+`). Without a morph map the type column holds the class name, which breaks every
  existing row when a model is renamed or moved; `enforceMorphMap()` stores short aliases and throws if a model
  without one is used. `morphToMany`/`morphedByMany` give polymorphic many-to-many (tags on books *and* authors).
* `$touches = ['book']` on `Review` updates the book's `updated_at` whenever a review is saved, useful for cache keys.

== Inserting and syncing related models

[source,php]
----
<?php
use App\Models\{Author, Book, Image, Review, Tag, User};

$ben = User::factory()->create(['name' => 'Ben Borrower']);
$kindred->reviews()->create(['user_id' => $ben->id, 'rating' => 3, 'body' => 'Harrowing.']);
$sower->reviews()->create(['user_id' => $ada->id, 'rating' => 4, 'body' => 'Prescient.']);
$butler->portrait()->create(['path' => 'portraits/butler.jpg', 'alt' => 'Octavia E. Butler']);
$kindred->images()->createMany([['path' => 'covers/kindred-1979.jpg'], ['path' => 'covers/kindred-2003.jpg']]);

$dystopia = Tag::firstOrCreate(['name' => 'dystopia']);
$sower->tags()->attach($dystopia, ['added_by' => 'ada']);
$changes = $sower->tags()->sync([$dystopia->id => ['added_by' => 'ada'], Tag::where('name', 'science fiction')->value('id')]);
echo 'sync: ', json_encode($changes), PHP_EOL;
echo 'toggle: ', json_encode($sower->tags()->toggle([$dystopia->id])), PHP_EOL;
$sower->tags()->attach($dystopia, ['added_by' => 'ben']);
echo 'pivot: ', $sower->tags()->where('name', 'dystopia')->first()->pivot->added_by, PHP_EOL;
----

[source,text]
----
sync: {"attached":[],"detached":[],"updated":[3]}
toggle: {"attached":[],"detached":[3]}
pivot: ben
----

Source: https://laravel.com/framework/docs/13.x/eloquent-relationships#inserting-and-updating-related-models[Laravel -- Inserting and Updating Related Models]

`create()` on a `hasMany` or `morphMany` fills the foreign key (and type) itself. `sync()` makes the pivot rows match
the list exactly and reports what changed: "science fiction" was already attached by the seeder, and passing pivot
attributes for `dystopia` counted as an update. `syncWithoutDetaching()` only adds, `toggle()` flips, `detach()`
removes, and `updateExistingPivot()` changes pivot columns. `attach()` does not check for duplicates: the composite
primary key on `book_tag` is what stops a second `attach()` of the same tag, so pivot tables need one.

== Reading relationships

[source,php]
----
<?php
use App\Models\{Author, Book, Image};

echo 'latestReview: ', $kindred->latestReview->body, '; bestReview: ', $kindred->bestReview->rating, PHP_EOL;
echo 'through: ', $butler->reviews()->count(), ' reviews of Butler books; Le Guin: ', $leGuin->reviews()->count(), PHP_EOL;
$img = Image::where('path', 'portraits/butler.jpg')->first();
echo 'morph: ', $img->imageable_type, ' #', $img->imageable_id, ' -> ', get_class($img->imageable), ' ', $img->imageable->name, PHP_EOL;

echo 'has(reviews, >=2): ', Book::has('reviews', '>=', 2)->pluck('title')->join(', '), PHP_EOL;
echo 'whereHas(rating 5): ', Book::whereHas('reviews', fn ($q) => $q->where('rating', 5))->pluck('title')->join(', '), PHP_EOL;
echo 'whereRelation: ', Book::whereRelation('tags', 'name', 'classic')->orderBy('title')->pluck('title')->join(', '), PHP_EOL;
echo 'doesntHave: ', Book::doesntHave('reviews')->orderBy('title')->pluck('title')->join(', '), PHP_EOL;
$withAgg = Author::withCount('books')->withAvg('reviews', 'rating')->orderBy('name')->get();
foreach ($withAgg as $a) { echo "  {$a->name}: {$a->books_count} books, avg rating ", $a->reviews_avg_rating === null ? 'n/a' : round($a->reviews_avg_rating, 2), PHP_EOL; }
----

----

through: 3 reviews of Butler books; Le Guin: 0
morph: author #1 -> App\Models\Author Octavia E. Butler
has(reviews, >=2): Kindred
whereHas(rating 5): Kindred
whereRelation: Kindred, The Dispossessed, The Lathe of Heaven

Source: https://laravel.com/framework/docs/13.x/eloquent-relationships#querying-relationship-existence[Laravel -- Querying Relationship Existence] and https://laravel.com/framework/docs/13.x/eloquent-relationships#aggregating-related-models[Aggregating Related Models]

The morph map shows in the data: `imageable_type` is `author`, not `App\Models\Author`, and Eloquent resolved it back
to the class. `withCount('books')` and `withAvg('reviews', 'rating')` add `books_count` and `reviews_avg_rating`
columns through subqueries, in the same query as the authors; `withSum`, `withMin`, `withMax` and `withExists` follow
the same naming. The average for Butler (5, 3 and 4) is 4; Le Guin has no reviews, so the average is `null`, not 0.
`whereHas()` with a closure constrains the related rows; `whereRelation('tags', 'name', 'classic')` is its short form,
and `whereMorphRelation()` does the same across polymorphic types.

== Eager loading

Reading a relationship inside a loop runs one query per model, the *N+1 problem*. Counting queries with
`DB::listen()` over the four books:

[source,php]
----
<?php
use App\Models\Book;

$queries = 0;
foreach (Book::all() as $b) { $b->author->name; }
echo 'lazy author per book: ', $queries, ' queries', PHP_EOL;
$queries = 0;
foreach (Book::with(['author', 'reviews' => fn ($q) => $q->where('rating', '>=', 4)])->get() as $b) { $b->author->name; $b->reviews->count(); }
echo 'with(author, reviews>=4): ', $queries, ' queries', PHP_EOL;
$books = Book::all(); $queries = 0;
$books->loadMissing('author'); $books->loadMissing('author');
echo 'loadMissing twice: ', $queries, ' query', PHP_EOL;
----

[source,text]
----
lazy author per book: 5 queries
with(author, reviews>=4): 3 queries
loadMissing twice: 1 query
----

Source: https://laravel.com/framework/docs/13.x/eloquent-relationships#eager-loading[Laravel -- Eager Loading] and https://laravel.com/framework/docs/13.x/eloquent-relationships#constraining-eager-loads[Constraining Eager Loads]

One query for the books plus one per book makes 5; `with()` loads each relationship in one `+where ... in (...)+` query
whatever the number of books, so two relationships cost 3 queries in total. The closure constrains the eager load
(only reviews rated 4 or more are loaded into `+$book->reviews+`, which then no longer means "all reviews").
`load()` eager-loads on models already fetched, `loadMissing()` only what is not loaded yet, `with('author:id,name')`
selects specific columns (the key must be included), and `$with = ['author']` on the model eager-loads by default.
Detecting and preventing N+1 in a whole application is on
xref:web/php-laravel/query-performance-and-n-plus-1.adoc[Query Performance and N+1].

== Associating and touching

[source,php]
----
<?php
use App\Models\Review;

$review = Review::where('body', 'Harrowing.')->first();
$before = $sower->fresh()->updated_at;
sleep(1);
$review->book()->associate($sower)->save();
echo 'associate: review now on ', $review->book->title, '; touched parent: ', var_export($sower->fresh()->updated_at->gt($before), true), PHP_EOL;
// associate: review now on Parable of the Sower; touched parent: true
----

Source: https://laravel.com/framework/docs/13.x/eloquent-relationships#updating-belongs-to-relationships[Laravel -- Updating Belongs To Relationships] and https://laravel.com/framework/docs/13.x/eloquent-relationships#touching-parent-timestamps[Touching Parent Timestamps]

`associate()` sets the foreign key (and the cached relation) on the child, `dissociate()` sets it to `null`; nothing is
written until `save()`. Because `Review` lists `book` in `$touches`, saving it updated *Parable of the Sower*'s
`updated_at`. On a `hasMany`, `chaperone()` sets the inverse relation on each loaded child (`+$review->book+` without a
query), and `+withAttributes([...])+` on a scoped relationship both filters by and fills those attributes when creating.

== Where older books and tutorials are outdated

* *`+orderBy('created_at', 'desc')->first()+` per parent for "latest child"* is `latestOfMany()` (Laravel 8), which
  eager-loads in one query.
* *Class names in `+*_type+` columns* (the default in Stauffer ch. 5) make renames painful; `enforceMorphMap()`
  (Laravel 8) stores stable aliases.
* *`withCount()` only* is joined by `withSum`, `withAvg`, `withMin`, `withMax` and `withExists` (Laravel 8).
* *`+whereHas('tags', fn ($q) => $q->where('name', ...))+` for every lookup* has the shorter `whereRelation()`
  (Laravel 8).
* *Manually setting `+$review->setRelation('book', $book)+` in loops* is `chaperone()` (Laravel 11).
