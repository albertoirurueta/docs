Welcome to the jQuery reference. https://jquery.com/[jQuery] is a JavaScript library that gives the browser
DOM a terse, chainable, cross-browser API for selecting elements, changing them, handling events, animating,
and making AJAX requests. It was near-universal on the web for a decade; today the native platform covers
almost all of it, so this section documents jQuery 3.x for **reading, maintaining, and migrating** existing
code, and every page ends with the modern native equivalent.

If you are new to the library, start with xref:web/jquery/getting-started.adoc[Getting Started with jQuery]
and xref:web/jquery/selectors.adoc[jQuery Selectors], then work down the list or jump to what you need.

== What's covered

=== Core

* xref:web/jquery/getting-started.adoc[Getting Started with jQuery] -- what jQuery and the `$` function are,
  the wrapped set vs. raw DOM nodes, why and when *not* to use it, adding it via download or CDN with
  Subresource Integrity, and the document-ready pattern.

=== Selecting & traversing

* xref:web/jquery/selectors.adoc[jQuery Selectors] -- basic, hierarchy, and attribute selectors, plus the
  jQuery-only filter/form/state pseudo-selectors and which of them are non-standard and slow.
* xref:web/jquery/traversal-and-chaining.adoc[Traversal and Chaining] -- moving up, down, and sideways in the
  DOM; filtering and iterating a set; and method chaining with the `.end()` / `.addBack()` stack.

=== Changing the page

* xref:web/jquery/dom-manipulation.adoc[DOM Manipulation] -- reading/writing content, inserting elements
  inside and outside a target, wrapping, removing vs. detaching, cloning, replacing, and creating elements.
* xref:web/jquery/css-attributes-dimensions.adoc[CSS, Classes, Attributes and Dimensions] -- classes and
  inline styles, the `.attr()` vs. `.prop()` distinction, and the dimension and position/scroll methods.
* xref:web/jquery/effects-and-animation.adoc[Effects and Animation] -- show/hide, fade, slide, the
  general-purpose `.animate()`, and the per-element effects queue.

=== Behaviour

* xref:web/jquery/events.adoc[Event Handling] -- binding with `.on()` / `.off()` / `.one()`, the jQuery event
  object, event delegation for dynamic elements, and programmatic and namespaced events.
* xref:web/jquery/data-and-utilities.adoc[Element Data and Utility Functions] -- `.data()`, `.index()`,
  getting raw nodes out of a set, and the `jQuery.*` static helpers with their native replacements.

=== Talking to the server

* xref:web/jquery/ajax.adoc[AJAX] -- `jQuery.ajax()` and its shorthands, the jqXHR promise and its callbacks,

=== Beyond jQuery

* xref:web/jquery/plugins-and-modern-usage.adoc[Plugins and Modern Usage] -- writing a well-behaved `$.fn`
  plugin, an orientation to jQuery UI/Mobile and common plugins, and migrating off jQuery with

* xref:web/jquery/interactive-list-project.adoc[Worked Example: An Interactive List] -- one self-contained
