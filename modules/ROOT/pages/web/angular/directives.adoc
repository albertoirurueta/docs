= Directives
:description: Attribute directives with @Directive and host bindings, structural directives and the asterisk shorthand desugaring to ng-template, ng-container, and the built-in attribute directives and directive composition API.
:keywords: Angular directives, attribute directive, structural directive, ng-template, ng-container, TemplateRef, ViewContainerRef, NgClass, NgStyle, NgModel, NgOptimizedImage, hostDirectives, directive composition API

A **directive** is a class that attaches behaviour to an element. Components are directives with a template;
plain directives have none. Angular has two kinds: **attribute directives** change the appearance or behaviour
of an existing element, and **structural directives** add or remove elements from the DOM. See
https://angular.dev/guide/directives[Directives].

== Attribute directives

Declare one with `@Directive`, give it an attribute `selector`, and bind to its host element with the `host`
metadata or the `+host+` decorators. Signal `input()` reads a bound value; `@HostListener`-style entries in
`host` react to events. Directives are standalone by default and are added to a component's `imports`.

[source,typescript]
----
import { Directive, ElementRef, inject, input } from '@angular/core';

@Directive({
  selector: '[appHighlight]',
  host: {
    '(mouseenter)': 'onEnter()',
    '(mouseleave)': 'onLeave()',
    '[style.transition]': '"background-color 150ms"',
  },
})
export class HighlightDirective {
  private readonly el = inject(ElementRef<HTMLElement>);

  // <p [appHighlight]="'gold'"> -> the directive's own value
  readonly appHighlight = input<string>('yellow');

  private onEnter(): void {
    this.el.nativeElement.style.backgroundColor = this.appHighlight();
  }

  private onLeave(): void {
    this.el.nativeElement.style.backgroundColor = '';
  }
}
----

[source,html]
----
<p [appHighlight]="'gold'">Hover me</p>
----

Prefer binding through `host` metadata or `@HostBinding` / `@HostListener` over touching `nativeElement`
directly, so the directive stays testable and server-side-render safe. See
https://angular.dev/guide/directives/attribute-directives[Attribute directives].

== Structural directives

A structural directive is written with the `*` shorthand. Angular **desugars** `+*+` onto an
`<ng-template>` that wraps the host element, and the directive decides whether and how often to render that
template.

[source,html]
----
<!-- what you write -->
<section *appUnless="isLoading">Content</section>

<!-- what Angular expands it to -->
<ng-template [appUnless]="isLoading">
  <section>Content</section>
</ng-template>
----

`<ng-container>` is a grouping element that produces **no DOM node** -- useful to host a structural directive
without adding a wrapper, or to place several `@for` / `@if` blocks side by side. See
https://angular.dev/guide/templates/ng-container[ng-container] and
https://angular.dev/guide/templates/ng-template[ng-template].

[source,html]
----
<ng-container *appUnless="isLoading">
  <h2>{{ title() }}</h2>
  <p>No wrapper element is emitted around these two.</p>
</ng-container>
----

Write one by injecting `TemplateRef` (the content to stamp out) and `ViewContainerRef` (where to stamp it).

[source,typescript]
----
import { Directive, TemplateRef, ViewContainerRef, effect, inject, input } from '@angular/core';

@Directive({ selector: '[appUnless]' })
export class UnlessDirective {
  private readonly tpl = inject(TemplateRef<unknown>);
  private readonly vcr = inject(ViewContainerRef);

  readonly appUnless = input.required<boolean>();

  constructor() {
    effect(() => {
      this.vcr.clear();
      if (!this.appUnless()) {
        this.vcr.createEmbeddedView(this.tpl);
      }
    });
  }
}
----

The built-in `@if` / `@for` / `@switch` control flow (see
xref:web/angular/control-flow-and-defer.adoc[Control flow and @defer]) replaces `*ngIf` / `*ngFor` /
`*ngSwitch` for everyday branching and lists; custom structural directives remain useful for reusable
rendering rules. See https://angular.dev/guide/directives/structural-directives[Structural directives].

== Built-in attribute directives

Import these from `@angular/common`. With the built-in control flow they are needed less often, but they are
still current:

[cols="1,3",options="header"]
|===
| Directive | Use

| https://angular.dev/api/common/NgClass[`NgClass`] | Toggle several CSS classes from an object or array: `[ngClass]="\{ active: isActive() }"`. For a single class prefer `[class.active]="isActive()"`.
| https://angular.dev/api/common/NgStyle[`NgStyle`] | Set several inline styles from an object: `[ngStyle]="\{ color: c() }"`. For one property prefer `[style.color]="c()"`.
| https://angular.dev/api/forms/NgModel[`NgModel`] | Two-way bind a form field in template-driven forms (`[(ngModel)]`). See xref:web/angular/forms.adoc[Forms].
| https://angular.dev/api/common/NgOptimizedImage[`NgOptimizedImage`] | Apply the `ngSrc` attribute to `<img>` for automatic lazy-loading, `srcset` generation, and LCP prioritisation (`priority`).
|===

[source,html]
----
<button [ngClass]="{ primary: kind() === 'primary', danger: kind() === 'danger' }">Go</button>
<div [ngStyle]="{ 'font-size.px': size(), color: color() }">Sized text</div>

<img ngSrc="/assets/hero.jpg" width="1200" height="600" priority alt="Hero" />
----

[source,typescript]
----
import { NgClass, NgStyle, NgOptimizedImage } from '@angular/common';

@Component({
  selector: 'app-banner',
  imports: [NgClass, NgStyle, NgOptimizedImage],
  templateUrl: './banner.html',
})
export class Banner { /* ... */ }
----

== Directive composition API

`hostDirectives` lets a component or directive **apply other directives to its own host element**, optionally
re-exposing their inputs and outputs. It composes behaviour without inheritance or wrapper elements.

[source,typescript]
----
import { Directive, Component, input } from '@angular/core';

@Directive({
  selector: '[appTooltip]',
  host: { '(mouseenter)': 'show()', '(mouseleave)': 'hide()' },
})
export class Tooltip {
  readonly appTooltip = input<string>('');
  show(): void { /* ... */ }
  hide(): void { /* ... */ }
}

@Component({
  selector: 'app-icon-button',
  hostDirectives: [
    { directive: Tooltip, inputs: ['appTooltip: tooltip'] }, // re-expose as `tooltip`
  ],
  template: '<button><ng-content /></button>',
})
export class IconButton {}
----

[source,html]
----
<app-icon-button tooltip="Save">💾</app-icon-button>
----

Host directives must be **standalone**, and the list is static (it cannot be built at runtime). See
https://angular.dev/guide/directives/directive-composition-api[Directive composition API].
