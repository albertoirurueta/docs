Welcome to the Vaadin reference. https://vaadin.com/[Vaadin] is an open-source Java web framework for building
business web applications without hand-writing HTML or JavaScript: you describe the UI as a server-side tree of
components, and Vaadin keeps a set of Web Components in the browser in sync with it over an automatic
client--server channel. This section documents the **current Vaadin release line** -- Vaadin 24 LTS and the
latest Vaadin 25.x -- using **Flow** (the Java UI model) throughout, with **Hilla** (React + TypeScript) shown
where it differs, written and verified against https://vaadin.com/docs/latest/[the official documentation].

If you are new to Vaadin, start with xref:web/vaadin/getting-started.adoc[Getting Started] and
xref:web/vaadin/architecture.adoc[Architecture], then xref:web/vaadin/components-overview.adoc[Components
Overview], xref:web/vaadin/layouts.adoc[Layouts] and xref:web/vaadin/data-binding.adoc[Data Binding], then work
down the list or jump to what you need.

== What's covered

=== Fundamentals

* xref:web/vaadin/getting-started.adoc[Getting Started] -- what Vaadin is, the Flow and Hilla models and the
  Web Components they share, open-source versus commercial editions, creating and running a project, the
  project structure, dev mode and Copilot, and the Vaadin 24 / 25 baselines.
* xref:web/vaadin/architecture.adoc[Architecture] -- the server-side component tree and the client engine,
  `UI` / `VaadinSession` / `VaadinService`, the state-sync channel, the thread model and the session lock, and
  request handling.
* xref:web/vaadin/components-overview.adoc[Components Overview] -- the `Component` model and the `Has*` mixins,
  enabled and visible state, a grouped tour of the 40+ built-in components, and which ones are commercial.
* xref:web/vaadin/layouts.adoc[Layouts] -- `VerticalLayout` / `HorizontalLayout` and the flexbox model,
  sizing and alignment, `FlexLayout`, `FormLayout`, `SplitLayout`, `AppLayout`, and `Composite`.

=== Input, forms and data

* xref:web/vaadin/input-components.adoc[Input Components] -- the data-entry fields, the `HasValue` contract,
  value-change modes, and the shared required / helper-text / prefix / suffix features.
* xref:web/vaadin/data-binding.adoc[Data Binding] -- `Binder` and `BeanValidationBinder`, `Converter` and
  `Validator`, `readBean` / `writeBean` / `writeBeanIfValid`, and buffered versus unbuffered binding.
* xref:web/vaadin/grid.adoc[The Grid Component] -- columns and renderers, in-memory `setItems` versus a lazy
  `DataProvider`, selection, item details and styling, the `Grid` editor and `GridPro`, and `TreeGrid`.
* xref:web/vaadin/forms-crud-and-master-detail.adoc[Forms, CRUD and Master-Detail] -- assembling a bound form,
  a master-detail view, the `CRUD` component, `ConfirmDialog`, and optimistic locking.

=== Navigation and interaction

* xref:web/vaadin/routing-and-navigation.adoc[Routing and Navigation] -- `@Route` and `RouterLink`, route
  parameters and templates, the `BeforeEnter` / `BeforeLeave` / `AfterNavigation` lifecycle, `RouterLayout`,
  page titles, error views, and a `SideNav` menu.
* xref:web/vaadin/interaction-and-overlays.adoc[Interaction and Overlays] -- buttons and shortcuts, `MenuBar`
  and `ContextMenu`, `Notification`, `Dialog`, `Popover`, `Tooltip`, the `Tabs` / `Accordion` / `Details`
  containers, and drag and drop.
* xref:web/vaadin/server-push.adoc[Server Push] -- `@Push` and the transports, `UI.access` and the session
  lock, background work with `VaadinExecutor`, broadcasting to many UIs, and the `@Poll` alternative.

=== Client side and extensibility

* xref:web/vaadin/element-api-and-web-components.adoc[The Element API and Web Components] -- reaching the DOM
  from Java, DOM events, `executeJs` and `@ClientCallable`, and integrating a web component with `@Tag` /
  `@NpmPackage` / `@JsModule`.
* xref:web/vaadin/custom-components.adoc[Building Custom Components] -- `Composite`, extending a component,
  building from an element, a value-bearing `CustomField`, and packaging an add-on.
* xref:web/vaadin/hilla-and-react-views.adoc[Hilla and React Views] -- `@BrowserCallable` endpoints and the
  generated client, file-based routing, `@vaadin/react-components`, Hilla forms, endpoint security, reactive
  endpoints and signals, and mixing Flow with Hilla.

=== Styling and design

* xref:web/vaadin/theming-and-styling.adoc[Theming and Styling] -- the theme folder and `@Theme`, Base / Lumo
  / Aura, Lumo CSS custom properties and the dark variant, theme and component variants, utility classes, and
  styling internals with `::part()`.
* xref:web/vaadin/responsive-design-and-pwa.adoc[Responsive Design and PWA] -- responsive `FormLayout` and
  `AppLayout`, Lumo breakpoint utilities, `@PWA` and the service worker, Web Push, and the Designing Apps
  guidance.

=== Integration and backend

* xref:web/vaadin/spring-boot-integration.adoc[Spring Boot Integration] -- the starter, `@SpringComponent` and
  the Vaadin scopes, injecting services, a Spring Data JPA CRUD, and the `vaadin.*` properties.
* xref:web/vaadin/jakarta-ee-and-cdi.adoc[Jakarta EE and CDI] -- the `vaadin-cdi` add-on and its scopes,

* xref:web/vaadin/data-persistence.adoc[Data Persistence] -- Spring Data JPA, jOOQ and Flyway, a lazy `Grid`

* xref:web/vaadin/rest-and-services.adoc[REST and Services] -- a service layer, exposing a `@RestController`
  alongside Flow, calling an external API off the UI thread, and endpoint versus REST.

=== Security

* xref:web/vaadin/security.adoc[Security] -- `VaadinWebSecurity` over Spring Security, route protection with

* xref:web/vaadin/configuration-and-dev-tools.adoc[Configuration and Dev Tools] -- the `vaadin.*` properties,

* xref:web/vaadin/advanced-topics.adoc[Advanced Topics] -- lifecycle listeners, a custom `ErrorHandler` and
