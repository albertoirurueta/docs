A single-page, colour-coded summary of React and Next.js, written against Next.js 16.3 (16.3.8) and React 19.3
(19.3.0) with Node.js 20.9 or later (versions verified 2026-10-03) -- React core (JSX, components and props, state and
events, the Hooks table, effects and cleanup, context, refs, Suspense, `lazy` and `use`, the Actions Hooks
`useActionState`, `useFormStatus` and `useOptimistic`, the React Compiler and the rules of React), the project and
CLI (`create-next-app`, `next dev`, `build`, `start`, `upgrade` and `typegen`), the file-conventions table and
environment variables, routing (segments, dynamic and catch-all routes, route groups, parallel and intercepting
routes, `<Link>`, `useRouter` and the navigation Hooks, `redirect` and `notFound`), a rendering strip comparing CSR,
SSR, SSG, ISR, PPR and streaming with their App Router and Pages Router APIs, Server and Client Components and the
boundary rules, a hydration box with the sequence and the top mismatch causes and fixes, data fetching, Server
Actions, the caching layers with the `cacheLife` profiles and the revalidation APIs (both the *Cache Components* and
the *previous* model), Route Handlers and Proxy, metadata, images and fonts, authentication and data security,
testing, deployment and output modes, and a strip of what changed since older tutorials -- handy for quick
memorization or as a xref:attachment$nextjs-cheat-sheet.pdf[downloadable PDF] desk reference.
