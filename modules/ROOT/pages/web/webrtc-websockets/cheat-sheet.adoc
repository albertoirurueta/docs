handshake, frame header and close codes, the browser API, reconnection and heartbeats, one strip per server stack, the
WebRTC offer and answer sequence, perfect negotiation, media constraints, data-channel options, simulcast, `getStats`,
mesh versus SFU versus MCU, TURN credentials, media servers, XMPP essentials, chat, videoconference and game

the baseline of the section as checked on 2026-10-24: RFC 6455 with RFC 8441 and RFC 9220, the W3C WebRTC 1.0
Recommendation with JSEP in RFC 9429, mediasoup 3.31.0, LiveKit 1.13.10, Janus 1.4.3, `socket.io` 4.8.4, python-socketio
