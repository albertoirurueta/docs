= Appendix: CSS Property Reference

include::partial$html-css-disclaimer.adoc[]

This appendix is a quick-reference table of everyday CSS properties, grouped by purpose. Cross-check anything
here against https://developer.mozilla.org/en-US/docs/Web/CSS[MDN's CSS reference] before relying on it in
production. It is scoped to the everyday properties *not* already covered in depth by other
pages in this section: layout (`display: flex`/`grid` internals, positioning) is covered in
xref:web/html-css/layout.adoc[], the box model (`margin`, `padding`, `width`/`height`, `box-sizing`, borders as
layout boxes) is covered in xref:web/html-css/box-model.adoc[], selectors and the cascade are covered in
xref:web/html-css/selectors-specificity.adoc[], custom properties and media queries are covered in
xref:web/html-css/variables-media-queries.adoc[], and transitions/animations are covered in
xref:web/html-css/transitions.adoc[] and xref:web/html-css/animations.adoc[]. What remains here is typography,
color and background, border/visual-effect properties, display-value/overflow/visibility behavior, list
styling, and cursor.

== Typography

=== font-family

`font-family` sets a prioritized, comma-separated list of font names for an element's text. The browser uses
the first listed font it has available, falling back to the next in line -- the last entry should generally
be a generic family (`serif`, `sans-serif`, `monospace`, and similar) so there is always a fallback even if none
of the named fonts are installed.

[source,css]
----
body {
  font-family: "Helvetica Neue", Arial, sans-serif;
}
----

=== font-size

`font-size` sets the size of an element's text, accepting absolute units (`px`), relative units (`em`, `rem`),
or viewport-relative units (`vw`).

[source,css]
----
h1 {
  font-size: 2rem;
}

p {
  font-size: 16px;
}
----

=== font-weight

`font-weight` sets the boldness of text, either as a keyword (`normal`, `bold`) or a numeric value from `100`
(thinnest) to `900` (boldest) -- numeric values give finer control when a font family ships multiple weights.

[source,css]
----
strong {
  font-weight: bold;
}

.subheading {
  font-weight: 600;
}
----

=== line-height

`line-height` sets the height of a line box, which controls the vertical spacing between lines of text. A
unitless value (such as `1.5`) is generally preferred over a fixed length, since it scales proportionally with
the element's own `font-size` rather than staying fixed.

[source,css]
----
p {
  line-height: 1.5;
}
----

=== text-align

`text-align` sets the horizontal alignment of inline content (text and inline elements) within its containing
block.

[source,css]
----
.centered-heading {
  text-align: center;
}

blockquote {
  text-align: justify;
}
----

=== text-decoration

`text-decoration` adds or removes decorative lines on text, most commonly used to remove the default underline
from links or add an underline/strikethrough elsewhere.

[source,css]
----
a {
  text-decoration: none;
}

.discounted-price {
  text-decoration: line-through;
}
----

=== text-transform

`text-transform` changes the capitalization of text at render time without altering the underlying markup.

[source,css]
----
.section-label {
  text-transform: uppercase;
}
----

=== letter-spacing

`letter-spacing` adds (or, with a negative value, removes) extra horizontal space between characters.

[source,css]
----
.tracking-wide {
  letter-spacing: 0.05em;
}
----

== Color and background

=== background-color

`background-color` sets the solid background color painted behind an element's content and padding (and its
border area, unless `background-clip` says otherwise).

[source,css]
----
.card {
  background-color: #f5f5f5;
}
----

=== background-image

`background-image` sets one or more images (or gradients) to paint behind an element's content, layered on top
of any `background-color` and layered with each other in the order listed, first on top.

[source,css]
----
.hero {
  background-image: url("hero-banner.jpg");
}

.gradient-card {
  background-image: linear-gradient(to right, #ff7e5f, #feb47b);
}
----

=== background-position

`background-position` sets where a `background-image` is placed within its background positioning area,
accepting keywords (`center`, `top left`) or length/percentage offsets.

[source,css]
----
.hero {
  background-image: url("hero-banner.jpg");
  background-position: center top;
}
----

=== background-size

`background-size` sets the rendered size of a `background-image`, either as explicit lengths/percentages or the
keywords `cover` (scale to fully cover the element, cropping if needed) and `contain` (scale to fit entirely
within the element).

[source,css]
----
.hero {
  background-image: url("hero-banner.jpg");
  background-size: cover;
}
----

=== background-repeat

`background-repeat` controls whether and how a `background-image` tiles when it is smaller than its background
area.

[source,css]
----
.tile-pattern {
  background-image: url("pattern.png");
  background-repeat: repeat;
}

.icon-background {
  background-image: url("watermark.png");
  background-repeat: no-repeat;
}
----

=== opacity

`opacity` sets the transparency of an entire element -- including its content, background, and border -- as a
value from `0` (fully transparent) to `1` (fully opaque). Unlike a transparent color value, `opacity` affects
every descendant as a group and cannot make one part of the element more transparent than another.

[source,css]
----
.disabled-button {
  opacity: 0.5;
}
----

== Borders and visual effects

=== border-radius

`border-radius` rounds an element's corners, accepting one value (all four corners) or up to four values
(top-left, top-right, bottom-right, bottom-left).

[source,css]
----
.card {
  border-radius: 8px;
}

.pill-button {
  border-radius: 999px;
}
----

=== box-shadow

`box-shadow` adds one or more drop shadows around an element's border box, specified as horizontal offset,
vertical offset, optional blur radius, optional spread radius, and color.

[source,css]
----
.card {
  box-shadow: 0 2px 8px rgba(0, 0, 0, 0.15);
}
----

=== outline

`outline` draws a line around an element, outside its border, that does not participate in the box model (it
does not affect layout or take up space). It is most commonly seen on the default browser focus indicator, and
should be overridden rather than removed outright for accessibility reasons.

[source,css]
----
.custom-focus:focus-visible {
  outline: 2px solid dodgerblue;
  outline-offset: 2px;
}
----

=== filter

`filter` applies graphical effects -- blur, brightness, contrast, grayscale, and more -- to an element before
it is composited onto the page.

[source,css]
----
.thumbnail:hover {
  filter: brightness(1.1);
}

.decorative-icon {
  filter: grayscale(100%);
}
----

== Display and overflow

=== display (values overview)

`display` sets an element's fundamental rendering behavior. This appendix only summarizes the common values;
`flex` and `grid` layout mechanics are covered in detail in xref:web/html-css/layout.adoc[].

* `block` -- the element generates a block-level box: it starts on its own line and stretches to fill the
  available width by default (`div`, `p`, `section` are block by default).
* `inline` -- the element flows within surrounding text, does not start on a new line, and ignores explicit
  `width`/`height` (`span`, `a`, `strong` are inline by default).
* `inline-block` -- flows inline like `inline`, but accepts `width`, `height`, and vertical margin/padding like
  `block`.
* `flex` / `inline-flex` -- establishes a flex formatting context for the element's children; see
  xref:web/html-css/layout.adoc[].
* `grid` / `inline-grid` -- establishes a grid formatting context for the element's children; see
  xref:web/html-css/layout.adoc[].
* `none` -- removes the element from rendering entirely, as if it were not in the document (it takes up no
  space and is not reachable by screen readers).

[source,css]
----
.badge {
  display: inline-block;
  padding: 2px 8px;
}

.visually-removed {
  display: none;
}
----

=== visibility

`visibility` hides an element while still reserving its layout space, unlike `display: none`, which removes
the space entirely.

[source,css]
----
.placeholder-until-loaded {
  visibility: hidden;
}
----

=== overflow

`overflow` controls how content that does not fit an element's box is handled -- clipped, scrollable, or left
to spill out. `overflow-x` and `overflow-y` set the behavior per axis independently.

[source,css]
----
.scroll-panel {
  overflow: auto;
  max-height: 300px;
}

.clip-container {
  overflow: hidden;
}
----

== Lists

=== list-style

`list-style` is a shorthand controlling how `<li>` markers are rendered: the marker type (`list-style-type`,
e.g. `disc`, `decimal`, `none`), an optional custom marker image (`list-style-image`), and marker position
(`list-style-position`, `inside` or `outside`).

[source,css]
----
.plain-list {
  list-style: none;
}

.custom-bullets {
  list-style: square inside;
}
----

== Miscellaneous

=== cursor

`cursor` sets which mouse cursor is shown when the pointer is over an element, communicating whether it is
clickable, disabled, resizable, and so on.

[source,css]
----
.clickable-card {
  cursor: pointer;
}

.disabled-button {
  cursor: not-allowed;
}
----
