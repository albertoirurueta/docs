== Worked example

A small card that combines the semantic structure, the box model, Flexbox, a custom property, a transition and a
focus style from the boxes above:

[source,html]
----
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Card</title>
  <style>
    :root { --accent: #0b5fff; }
    * { box-sizing: border-box; }
    .cards { display: flex; flex-wrap: wrap; gap: 1rem; padding: 1rem; }
    .card { flex: 1 1 14rem; padding: 1rem; border: 2px solid var(--accent); border-radius: 8px; }
    .card a { color: var(--accent); transition: color 0.2s ease-in-out; }
    .card a:hover, .card a:focus-visible { color: #b00020; }
  </style>
</head>
<body>
  <main class="cards">
    <article class="card">
      <h2>First card</h2>
      <p>Cards share the row and wrap when it is too narrow.</p>
      <a href="#first">Read more</a>
    </article>
    <article class="card">
      <h2>Second card</h2>
      <p>The border stays inside the width thanks to border-box.</p>
      <a href="#second">Read more</a>
    </article>
  </main>
</body>
</html>
----
