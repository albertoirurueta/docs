Welcome to the HTML & CSS reference. This section is organized by topic, from document structure through
styling, layout, interactivity, and performance, so you can jump straight to what you need, or work through it
top to bottom as a refresher.

== What's covered

* xref:web/html-css/html-structure.adoc[HTML5 structure and semantics] -- the HTML5 content-type taxonomy,
  document metadata, and the semantic structural elements (`header`/`main`/`section`/`article`/`nav`/`aside`/
  `footer`), each with typical attributes and examples.
* xref:web/html-css/seo.adoc[SEO implications of HTML structure] -- how semantic markup helps search engines
  understand a page, title/meta tags, heading hierarchy, internal linking, and canonical URLs.
* xref:web/html-css/layout.adoc[Layout: float, flexbox & grid] -- how each layout mode arranges elements,
  responsive/resize behavior, and scroll behavior, with axis and track diagrams.
* xref:web/html-css/positioning.adoc[CSS positioning] -- `static`/`relative`/`fixed`/`absolute`/`sticky` and how
  each displaces (or doesn't displace) surrounding content, plus `z-index` stacking.
* xref:web/html-css/box-model.adoc[The box model] -- the content/padding/border/margin nesting, box-sizing, and
  a labeled diagram of the four layers.
* xref:web/html-css/selectors-specificity.adoc[Selectors & specificity] -- selector types, pseudo-classes/
  elements, combinators, the specificity algorithm, and modern additions (nesting, `:has()`, `@layer`, `@scope`).
* xref:web/html-css/variables-media-queries.adoc[CSS custom properties and media queries] -- `--custom-property`
  syntax and scoping, responsive breakpoints, and `prefers-reduced-motion`.
* xref:web/html-css/theming.adoc[Light and dark theming with CSS] -- color models, the HSL color wheel, and
  light/dark theming techniques including `color-scheme` and `light-dark()`.
* xref:web/html-css/transitions.adoc[CSS transitions] -- the full transition property table, shorthand ordering,
  and `@starting-style` for first-render transitions.
* xref:web/html-css/animations.adoc[CSS animations, keyframes & performance] -- the `animation` shorthand,
  `@keyframes`, worked examples, and how to keep animations smooth and GPU-friendly.
* xref:web/html-css/svg-styling-animation.adoc[SVG styling & animation] -- styling inline SVG with CSS and
  animating SVG properties such as `stroke-dashoffset`.
* xref:web/html-css/forms.adoc[Forms and form styling] -- form controls, key attributes, custom input/select/
  file-input styling, and drag-and-drop file uploads.
* xref:web/html-css/forms-accessibility-validation.adoc[Forms: accessibility and validation] -- label
  association, keyboard navigation, and native and JavaScript-driven form validation.
* xref:web/html-css/performance-loading.adoc[Runtime loading performance] -- Core Web Vitals, critical-CSS
  inlining, lazy loading, and responsive image techniques.
* xref:web/html-css/performance-build-optimization.adoc[Build-time performance optimization] -- minification,
  bundling/code-splitting, DOM-size reduction, and asset compression.
* xref:web/html-css/appendix-html-elements.adoc[Appendix: HTML element reference] -- text-level semantics,
  lists, tables, embedded/media, and interactive elements not already covered above.
* xref:web/html-css/appendix-css-properties.adoc[Appendix: CSS property reference] -- typography, color/
  background, borders/effects, display/overflow, and other common properties not already covered above.
* xref:web/html-css/cheat-sheet.adoc[Cheat sheet] -- a one-page, downloadable PDF summary of the essentials
  above for quick memorization.
