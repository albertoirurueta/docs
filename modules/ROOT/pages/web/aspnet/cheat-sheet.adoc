= ASP.NET Core Cheat Sheet
:description: A single-page, printable ASP.NET Core quick reference for .NET 10 -- the dotnet CLI, a minimal Program.cs, middleware order, DI lifetimes, configuration and options, Minimal API CRUD, controllers, routing, Razor Pages, Tag Helpers, Blazor, SignalR, EF Core, authentication and authorization, error handling, caching and rate limiting, integration testing, and publish/Docker -- with links to every detailed page in this section.

A single-page, colour-coded summary of the ASP.NET Core essentials -- the `dotnet` CLI, a minimal `Program.cs`
(builder -> services -> middleware -> `Run`), the recommended middleware order, a custom-middleware skeleton, DI
lifetimes and registration, configuration and the Options pattern, a Minimal API `MapGroup` CRUD with
`TypedResults` and an endpoint filter, a controller action, route-template syntax and constraints, a Razor Page
`PageModel`, key Tag Helpers, a Blazor component with `@rendermode` and `EditForm`, a SignalR hub and JS
client, `AddDbContext` with an async LINQ query and a migration command, authentication and policy-based
authorization, `UseExceptionHandler` with `AddProblemDetails`, structured `ILogger` calls, output caching and
rate limiting, a `WebApplicationFactory<Program>` integration-test skeleton, `dotnet publish` with a
multi-stage `Dockerfile`, and a UI-component-libraries box -- handy for quick memorization or as a printable
desk reference.
