= E2E Testing in the Browser Cheat Sheet
:description: A single-page, printable quick reference for end-to-end browser testing with Playwright, Cypress and Selenium -- architectures and a tool chooser, a side-by-side command table, cross-browser setups, visual testing options, CI snippets and Docker images, AI agent commands and prompts, a browser-agent security checklist and a strip of what changed recently.
:keywords: E2E testing cheat sheet, Playwright cheat sheet, Cypress cheat sheet, Selenium cheat sheet, browser testing quick reference, printable E2E reference, WebDriver BiDi, CDP, toHaveScreenshot, Playwright MCP, Playwright Test Agents, cy.prompt, Chrome DevTools MCP, browser agent security

include::partial$e2e-testing-disclaimer.adoc[]

A single-page, colour-coded summary of the end-to-end browser testing essentials -- the architectures at a glance and a
tool chooser, a side-by-side command table for Playwright, Cypress and Selenium (install, run headed and headless, pick
a browser, locate, click and fill, wait and assert, mock the network, log in once, screenshots, video and traces,
debugging, parallelism and retries), cross-browser setups, visual testing options and a determinism checklist, CI
snippets and Docker images, AI agent commands and a script-less prompt template, a security checklist for browser
agents, and a strip of what changed recently -- handy for quick memorization or as a printable desk reference through
the xref:attachment$e2e-testing-cheat-sheet.pdf[downloadable PDF]. It reflects the baseline of the section as checked
on 25 October 2026: Playwright 1.64, Cypress 16.2, Selenium 4.51, WebDriver BiDi Working Draft of 8 October 2026,
the MCP specification 2026-07-28 and Chrome DevTools MCP 1.12. The section home page is
xref:web/e2e-testing/index.adoc[E2E Testing in the Browser].
