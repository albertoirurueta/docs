Welcome to the JavaScript reference. This section covers modern ECMAScript, core browser JavaScript APIs, and
the surrounding developer-tooling ecosystem, organized by topic so you can jump straight to what you need or
work through it top to bottom as a refresher.

== What's covered

=== Language reference

* xref:web/javascript/legacy-features.adoc[Legacy features to avoid] -- `var`'s scoping/hoisting pitfalls,
  prototype-based inheritance patterns superseded by `class`, and other legacy patterns modern code no longer
  needs.
* xref:web/javascript/lexical-structure.adoc[Lexical structure] -- comments, literals, identifiers,
  `let`/`const` syntax, semicolon insertion, and Unicode notes.
* xref:web/javascript/types.adoc[Types, values & conversions] -- numbers (incl. `BigInt`), strings, booleans,
  `null`/`undefined`, `Symbol`, and type conversion/coercion rules.
* xref:web/javascript/arrays.adoc[Arrays & typed arrays] -- array literals, sparse arrays, array-like objects,
  the array method reference, and typed arrays/`ArrayBuffer`/`DataView` for binary data.
* xref:web/javascript/functions-expressions-operators.adoc[Functions, expressions & operators] -- the full
  operator reference and function fundamentals (declarations, expressions, arrow functions, IIFEs).
* xref:web/javascript/iterators-generators.adoc[Iterators & generators] -- the iterator protocol, `for...of`,
  custom iterables, generator functions, and delegating generators.
* xref:web/javascript/statements.adoc[Statements] -- conditionals, loops, and loop-control statements.
* xref:web/javascript/objects-destructuring.adoc[Objects & destructuring] -- object literals, property access,
  enumeration, spread, and object/array destructuring.
* xref:web/javascript/function-parameters-namespaces.adoc[Function parameters & namespaces] -- default/rest
  parameters, destructured parameters, the legacy `arguments` object, and pre-ES6 namespacing patterns.
* xref:web/javascript/classes.adoc[Classes] -- `class` declarations, private fields/methods, static members,
  getters/setters, abstract-class patterns, and subclassing with `extends`/`super`.
* xref:web/javascript/modules.adoc[Modules] -- ES module `export`/`import` syntax, module scoping, and CommonJS
  contrasted with ES modules.
* xref:web/javascript/stdlib-collections.adoc[Standard library: collections] -- `Set`/`Map`/`WeakSet`/`WeakMap`
  and when to prefer them over plain objects/arrays.
* xref:web/javascript/stdlib-regexp.adoc[Standard library: regular expressions] -- regex syntax, flags, groups,
  and the `RegExp`/`String` methods that use them.
* xref:web/javascript/stdlib-dates-errors-json.adoc[Standard library: dates, errors & JSON] -- the `Date`
  object, the `Error` class hierarchy and custom errors, `try`/`catch`/`finally`, and `JSON.stringify`/`parse`.
* xref:web/javascript/stdlib-intl.adoc[Standard library: internationalization] -- `Intl.NumberFormat`,
  `DateTimeFormat`, `Collator`, and `PluralRules`.
* xref:web/javascript/stdlib-utilities.adoc[Standard library: console, URL & timers] -- the `console` API,
  `URL`/`URLSearchParams`, and the timer functions.
* xref:web/javascript/stdlib-metaprogramming.adoc[Standard library: metaprogramming] -- property descriptors,
  object extensibility controls, and the `Reflect`/`Proxy` APIs.
* xref:web/javascript/async-javascript.adoc[Asynchronous JavaScript] -- callbacks, `Promise`, `async`/`await`,
  async iteration, a worked `fetch()` example, and the microtask-queue timing model.
* xref:web/javascript/exception-handling.adoc[Exception handling] -- `throw`/`try`/`catch`/`finally` mechanics,
  custom `Error` subclasses, and exception handling in `async`/`await` and Promise chains.

=== JavaScript in the browser

* xref:web/javascript/browser-dom-basics.adoc[Web programming basics] -- the `window`/`document` globals,
  querying/creating/removing elements, and reading/writing content and attributes.
* xref:web/javascript/browser-events.adoc[Events] -- registering handlers, the capturing/target/bubbling
  phases, and event delegation.
* xref:web/javascript/browser-css.adoc[Accessing CSS from JavaScript] -- inline/computed styles, `classList`,
  and CSS animation/transition lifecycle events.
* xref:web/javascript/browser-geometry-scrolling.adoc[Document geometry & scrolling] -- `getBoundingClientRect`,
  the offset/client/scroll dimension family, and controlling scroll position.
* xref:web/javascript/browser-animations.adoc[Animations via JavaScript] -- `requestAnimationFrame`, the Web
  Animations API, and animating SVG from JS.
* xref:web/javascript/browser-canvas-webgl.adoc[Canvas, WebGL & Three.js] -- the 2D canvas API, an introduction
  to WebGL, and a Three.js quick start.
* xref:web/javascript/browser-audio-video.adoc[Audio & video APIs] -- `HTMLAudioElement`/`HTMLVideoElement`
  playback, audio recording, and captions.
* xref:web/javascript/browser-location-navigation-history.adoc[Location, navigation, history & geolocation] --
  `window.location`, the History API for SPA routing, and the Geolocation API.
* xref:web/javascript/browser-storage.adoc[Storage] -- cookies, `localStorage`/`sessionStorage`, and
  `IndexedDB`.
* xref:web/javascript/browser-networking.adoc[Networking] -- the full `fetch()` API, Server-Sent Events,
  WebSockets, and WebRTC.
* xref:web/javascript/browser-workers.adoc[Web Workers] -- dedicated/shared workers, message passing, and
  service workers.
* xref:web/javascript/browser-web-components.adoc[Web Components] -- custom elements, lifecycle callbacks, the
  Shadow DOM, and `<template>`/`<slot>`.
