= Layout
:description: Tailwind CSS v4 layout utilities -- display, box-sizing, isolation, float and clear, object-fit, overflow and overscroll, position and inset, visibility and z-index, aspect-ratio, multi-column, and table utilities.
:keywords: Tailwind CSS layout, display, hidden, box-sizing, isolation, float, clear, object-fit, object-position, overflow, overscroll-behavior, position, inset, z-index, aspect-ratio, columns, break-inside, box-decoration-break, container, border-collapse, border-spacing, table-fixed, caption-side

include::partial$ai-disclaimer.adoc[]

Tailwind exposes the CSS layout primitives -- the `display` mode, the positioning scheme, overflow behaviour,
fragmentation, and table rendering -- as single-purpose utility classes. This page covers the ones that decide
*where a box sits and how it is sized*; flex and grid tracks have their own page
(xref:web/tailwind/flexbox-and-grid.adoc[]).

== Display and the box

`display` is set with https://tailwindcss.com/docs/display[display] utilities: `block`, `inline-block`,
`inline`, `flex`, `inline-flex`, `grid`, `inline-grid`, `table` (and the `table-row` / `table-cell` family),
`contents`, `flow-root`, and `hidden` (which is `display: none`). Combine with variants to toggle layout per
breakpoint or state.

[source,html]
----
<!-- hidden on mobile, flex from md up -->
<nav class="hidden md:flex gap-4">...</nav>

<!-- contents removes the wrapper box but keeps its children in the parent's grid -->
<div class="contents">
  <span>a</span><span>b</span>
</div>
----

https://tailwindcss.com/docs/box-sizing[box-sizing] is `box-border` (the Preflight default, `border-box`) or
`box-content`. https://tailwindcss.com/docs/isolation[isolation] -- `isolate` / `isolation-auto` -- creates a
new stacking context so `z-index` and `+mix-blend-*+` on descendants stay contained.

[source,html]
----
<div class="isolate">
  <div class="relative z-10 mix-blend-multiply">...</div>
</div>
----

=== Float and clear

https://tailwindcss.com/docs/float[float] gives `float-start`, `float-end`, `float-left`, `float-right`, and
`float-none`; https://tailwindcss.com/docs/clear[clear] gives `clear-start`, `clear-end`, `clear-left`,
`clear-right`, `clear-both`, and `clear-none`. Use `flow-root` on the container (or a grid/flex layout) instead
of a clearfix hack.

[source,html]
----
<article class="flow-root">
  <img class="float-start me-4 mb-2 w-32 rounded" src="/thumb.jpg" alt="">
  <p>Text wraps around the floated thumbnail; flow-root contains the float.</p>
</article>
----

=== Replaced-element fit

https://tailwindcss.com/docs/object-fit[object-fit] (`object-contain`, `object-cover`, `object-fill`,
`object-none`, `object-scale-down`) and https://tailwindcss.com/docs/object-position[object-position]
(`object-center`, `object-top`, `object-bottom-right`, ..., or an arbitrary `object-[25%_75%]`) control how an
`<img>` or `<video>` fills its box.

[source,html]
----
<img class="h-48 w-full object-cover object-top" src="/hero.jpg" alt="">
----

== Overflow and overscroll

https://tailwindcss.com/docs/overflow[overflow] utilities come in three axes: `overflow-auto`,
`overflow-hidden`, `overflow-clip`, `overflow-visible`, `overflow-scroll`, plus the `+overflow-x-*+` and
`+overflow-y-*+` variants. https://tailwindcss.com/docs/overscroll-behavior[overscroll-behavior] --
`overscroll-auto`, `overscroll-contain`, `overscroll-none` (and `-x` / `-y`) -- stops scroll chaining from a
nested pane to the page.

[source,html]
----
<div class="h-64 overflow-y-auto overscroll-contain rounded border p-4">
  <!-- long content; wheel/touch scroll stays inside this pane -->
</div>
----

== Position and inset

https://tailwindcss.com/docs/position[position] utilities are `static`, `relative`, `absolute`, `fixed`, and
`sticky`. Offsets use https://tailwindcss.com/docs/top-right-bottom-left[top / right / bottom / left]: the
logical `+inset-*+`, `+inset-x-*+`, `+inset-y-*+`, `+start-*+`, `+end-*+` and the physical `+top-*+`, `+right-*+`,
`+bottom-*+`, `+left-*+`. Values follow the spacing scale, accept fractions (`inset-1/2`), `full`, `auto`, an
arbitrary `top-[3px]`, and **negative** values with a leading dash (`-top-4`, `-inset-x-2`).

[source,html]
----
<div class="relative">
  <span class="absolute -top-2 -right-2 z-10 rounded-full bg-red-500 px-2 text-xs text-white">9</span>
  <img src="/avatar.jpg" alt="" class="size-16 rounded-full">
</div>

<header class="sticky top-0 inset-x-0 z-40 bg-white/80 backdrop-blur">...</header>
----

https://tailwindcss.com/docs/visibility[visibility] (`visible`, `invisible`, `collapse`) hides a box while
keeping its space; https://tailwindcss.com/docs/z-index[z-index] is `z-0` ... `z-50`, `z-auto`, a negative
`-z-10`, or an arbitrary `z-[999]`.

== Aspect ratio, columns, and fragmentation

https://tailwindcss.com/docs/aspect-ratio[aspect-ratio]: `aspect-video` (16/9), `aspect-square` (1/1),
`aspect-auto`, the theme-driven `aspect-<name>`, or an arbitrary `aspect-[4/3]`.

[source,html]
----
<iframe class="aspect-video w-full rounded" src="https://www.youtube.com/embed/..."></iframe>
<div class="aspect-square bg-slate-200"></div>
<div class="aspect-[4/3] bg-slate-200"></div>
----

https://tailwindcss.com/docs/columns[columns] sets a CSS multi-column count or width: `columns-2`,
`columns-3xs` ... `columns-7xl`, `columns-auto`, or `columns-[16rem]`. Control breaks with
https://tailwindcss.com/docs/break-before[break-before], https://tailwindcss.com/docs/break-after[break-after],
and https://tailwindcss.com/docs/break-inside[break-inside] (`break-inside-avoid`,
`break-inside-avoid-column`, ...), and keep a decorated inline box intact across a fragmentation break with
https://tailwindcss.com/docs/box-decoration-break[box-decoration-break] (`box-decoration-slice` /
`box-decoration-clone`).

[source,html]
----
<div class="columns-2 gap-8 md:columns-3">
  <p class="break-inside-avoid">Each paragraph stays in one column...</p>
  <p class="break-inside-avoid">...instead of splitting across the gap.</p>
</div>
----

== The `container` utility in v4

In Tailwind v4 https://tailwindcss.com/docs/container[container] is *only* a `max-width` that steps up with
each breakpoint (`width: 100%` below `sm`, then `max-width` locked to each breakpoint's min-width). The v3
`theme.container` config -- with its `center` and `padding` keys -- **no longer exists**. To centre the
container or give it gutters, redefine it as a custom utility with `+@utility container { ... }+`:

[source,css]
----
@import "tailwindcss";

@utility container {
  margin-inline: auto;
  padding-inline: 1rem;

  @media (width >= theme(--breakpoint-sm)) {
    padding-inline: 2rem;
  }
}
----

Now `<div class="container">` is centred with responsive padding, and the breakpoint `max-width` steps still
apply. Often a plain `mx-auto max-w-6xl px-4` wrapper is simpler than touching `container` at all.

== Worked example: a sticky header and a hero with an image overlay

Two pieces of the Acme page (see xref:web/tailwind/worked-example.adoc[]) need positioning: the header should stay
at the top while the page scrolls, and the hero should put a headline over a photograph. Both reduce to the same
question -- *which box is the offsets measured from?*

[mermaid]
....
flowchart TD
    Q["How should the box be placed?"] --> N{"Leave normal flow?"}
    N -->|"no"| ST["static: the default, offsets ignored"]
    N -->|"nudge it from where it sits"| RE["relative: offset from its own spot, keeps its space"]
    N -->|"take it out of flow"| M{"Measured from what?"}
    M -->|"nearest positioned ancestor"| AB["absolute: also makes a relative parent useful"]
    M -->|"the viewport"| FI["fixed: stays put while scrolling"]
    N -->|"scroll normally, then stick"| SK["sticky: relative until the offset is reached"]
....

*The sticky header.* `sticky top-0` keeps the header in the flow, where it takes up its height, until the scroll
position reaches the offset, and then pins it to the top of its scrolling container. Give it a `+z-*+` value so that
content scrolling underneath does not paint over it, and a translucent background with `backdrop-blur` if the
content should show through.

[source,html]
----
<header class="sticky top-0 z-20 flex items-center justify-between border-b border-gray-200
               bg-white/80 px-6 py-4 backdrop-blur">
  <a href="/" class="text-lg font-bold">Acme</a>
  <nav class="hidden gap-6 text-sm font-medium sm:flex">...</nav>
</header>
----

A sticky element sticks only within its parent: once the parent scrolls out of view the header goes with it, so
put the header directly in `body` (or in a tall wrapper), and do not place `overflow-hidden` on an ancestor, which
turns that ancestor into the scroll container and stops the header sticking to the viewport.

*The image overlay.* The wrapper is `relative` so it becomes the containing block for the absolutely positioned
children. The image fills it with `absolute inset-0` and `object-cover`; a gradient layer is pinned to the bottom
edge with `inset-x-0 bottom-0`; the text sits above both. `isolate` creates a stacking context so the `-z-10`
image stays inside the wrapper instead of dropping behind the page background.

[source,html]
----
<div class="relative isolate aspect-video overflow-hidden rounded-xl">
  <img src="/hero.jpg" alt="" class="absolute inset-0 -z-10 size-full object-cover">
  <div class="absolute inset-x-0 bottom-0 bg-linear-to-t from-black/60 p-6">
    <h2 class="text-2xl font-bold text-white">Ship your site faster</h2>
  </div>
</div>
----

`aspect-video` reserves a 16 by 9 box before the image has loaded, so the page does not jump. All of these classes
build as written with Tailwind 4.3 (`sticky`, `inset-0`, `-z-10`, `isolate`, `aspect-video`, `bg-linear-to-t`
with `from-black/60`, `size-full`, `object-cover`); an unknown class is silently ignored by the engine, so the
quickest check that you spelled one correctly is to look for its rule in the generated CSS.

=== Stacking contexts in one picture

`+z-*+` only compares boxes inside the *same stacking context*. A context is created by `isolate`, by any
positioned box with a `+z-*+` other than `auto`, by `opacity` below 1, by transforms, filters and several other
properties. The practical rule: if a `z-50` dropdown still appears behind something, an ancestor of one of the two
boxes has created a context, and the number does not matter any more.

[mermaid]
....
flowchart TD
    ROOT["root stacking context"] --> HDR["header, z-20"]
    ROOT --> HERO["hero wrapper, isolate"]
    HERO --> IMG["image, -z-10: inside the wrapper"]
    HERO --> TXT["text block, z-auto"]
    ROOT --> MENU["dropdown, z-50"]
....

Here the image's `-z-10` is only compared with its sibling text inside the hero, never with the header. Remove
`isolate` and the image would join the root context and slip behind a background set on `body`.

=== Columns for text, grids for things

`columns-2 gap-8` flows a long list or article into newspaper columns, and `break-inside-avoid` on each item stops a
card being split across two columns. Use columns for content that reads as one stream, and the grid
(xref:web/tailwind/flexbox-and-grid.adoc[]) for items that must line up in rows.

[source,html]
----
<ul class="columns-1 gap-8 sm:columns-2 lg:columns-3">
  <li class="mb-4 break-inside-avoid rounded-lg border border-gray-200 p-4">...</li>
</ul>
----

== Tables

https://tailwindcss.com/docs/border-collapse[border-collapse] toggles `border-collapse` / `border-separate`.
With `border-separate`, https://tailwindcss.com/docs/border-spacing[border-spacing] sets the gap:
`border-spacing-2`, `border-spacing-x-4`, `border-spacing-y-0`, or an arbitrary `border-spacing-[3px]`.
https://tailwindcss.com/docs/table-layout[table-layout] is `table-auto` (size to content) or `table-fixed`
(honour the first row's / colgroup's widths). https://tailwindcss.com/docs/caption-side[caption-side] places
the `<caption>` with `caption-top` or `caption-bottom`.

[source,html]
----
<table class="table-fixed border-collapse border border-slate-300 w-full">
  <caption class="caption-bottom py-2 text-sm text-slate-500">Table 1. Quarterly totals</caption>
  <thead>
    <tr>
      <th class="border border-slate-300 p-2 w-1/2">Region</th>
      <th class="border border-slate-300 p-2">Total</th>
    </tr>
  </thead>
  <tbody>
    <tr><td class="border border-slate-300 p-2">North</td><td class="border border-slate-300 p-2">1,204</td></tr>
  </tbody>
</table>

<!-- separated borders with a controlled gap -->
<table class="border-separate border-spacing-2">
  <tr><td class="rounded bg-slate-100 p-2">A</td><td class="rounded bg-slate-100 p-2">B</td></tr>
</table>
----

For the underlying CSS behind these utilities -- the box model, positioning schemes, stacking contexts, and
table rendering -- see xref:web/html-css/layout.adoc[].
