xref:backend/media-optimization/index.adoc[Media Optimization for the backend]. This sub-section is the other half: how a web
page asks for the right variant, shows something useful while it loads, and plays video that adapts to the connection. It is
current as of 2026-10-07, and each page names the versions it was checked against.
