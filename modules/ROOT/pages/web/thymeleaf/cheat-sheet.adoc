A single-page, colour-coded summary of the Thymeleaf essentials, written against Thymeleaf 3.1.5, Spring Boot 4.1.1
(Spring Framework 7.0.9), Layout Dialect 4.0.1, htmx 2.0 and `htmx-spring-boot` 5.2.0 (versions verified 2026-10-07)
-- dependencies, template locations, template modes and the `+spring.thymeleaf.*+` properties, the five expression types
and the basic objects, literals, operators and preprocessing, one line per utility object, the `th:*` attributes by
purpose with their precedence order, iteration status and truthiness, fragments, `th:remove` values and the Layout
Dialect, comments, blocks and inlining, Spring forms and `+#fields+`, internationalization, conversion and links,
Spring Security, fragment rendering and htmx, reactive rendering, testing, the dialect and processor types, a
template-security strip, and a strip of what changed since older tutorials -- handy for quick memorization or as a
xref:attachment$thymeleaf-cheat-sheet.pdf[downloadable PDF] desk reference.
