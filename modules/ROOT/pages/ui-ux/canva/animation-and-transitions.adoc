== Where animation lives in the editor

Motion is controlled by the Animate button on the toolbar above the editor. Select a page or element, choose Animate, and an animation panel opens in the side panel. Its tabs depend on what you selected: Page for the current page, Element for selected elements and Text for a selected text box. Hover an option to preview it and click to apply it. The available styles depend on whether you selected text, a graphic, a shape, a photo or a video. Transitions live elsewhere: they are set between page thumbnails (see <<transitions>>).

== The animation options in detail

[cols="2,5", options="header"]
|===
| Option | What it does

| Page, Element and Text tabs | Animate the current page, the selected elements or a selected text box
| General and Suggested animations | Ready-made styles; the list changes with the type of the selected element
| Add-on effects | Extra effects you can combine with General or Suggested animations to see which mix suits the design
| Speed presets | Slow, Medium and Fast, or precise intro and outro durations through the duration controls for selected animations
| Appear on click | Elements appear when you click during a presentation; Click order under Presentation settings sets the sequence
| Create an Animation | Draw a custom movement path by dragging the element; adjust Movement Style, Presentation settings and Add-on effects, then select Done (or Delete path)
| Remove animation | Clears the animation or motion effect from the selection
|===

Limits stated in the Help Center: each animation can be at most 10 seconds long, and a design can contain at most 50 animations that you created yourself. No keyboard shortcut for animation is documented in the article, so on macOS and Windows alike you reach it through the Animate button.

=== Fade a video clip in or out

Select the video clip, choose Animate, and under General select Fade, then choose On enter, On exit or Both and adjust the speed. This fades the picture only; to fade the sound use Audio tools and set Fade in or Fade out.

Source: https://www.canva.com/help/animate-designs/[Canva Help Center: Apply, change, or remove animations]

== Magic Animate

Magic Animate uses AI to choose an animation for the whole design in a few seconds. On the toolbar select Animate, open the Page tab, choose Magic Animate and pick a style under Recommended style; the Alternative styles offer other looks, and Remove Magic Animation clears it from the entire design. It works best on a computer but is also available on mobile. If you subscribe to a premium plan and cannot see it, check the design type: it is offered only for presentation, social media and video designs. Because the result is applied to every element at once, review the timing afterwards (see <<timing>>) and prefer manual animation when you need a specific reading order.

Source: https://www.canva.com/help/using-magic-animate/[Canva Help Center: Apply animations instantly]

[#timing]
== Element timing and click order

Animations on a page play in a sequence, and the order and length can be changed in two ways.

* *Show element timing.* Select an animated element, choose More in the floating toolbar, then Show element timing. Timing tiles appear in the thumbnail area below the editor. Drag the tiles to change which element appears first, and drag the handles left or right to change each duration in seconds.
* *Click order.* If you turned on Appear on click, open Presentation settings, choose Click order and drag the elements into the order in which they should appear on each click.

[#transitions]
== Page transitions

A page transition animates the change from one page to the next in a presentation, video or exported animated design. Show page thumbnails with the Pages button at the bottom of the editor, hover between two thumbnails (or choose More on a thumbnail) and select Add transition. Hover a transition to preview it, click to apply it, then adjust the Duration (seconds) slider or number field, which accepts values from 0.1 to 2.5 seconds, and the direction where the style offers one. To change a transition later, click the icon between the two pages. In video designs the procedure differs: you add transitions between clips on the main track of the timeline, and the article notes that transitions are not available in page mode for video designs.

== Shader animations for video

For video clips, the Animate panel has a Featured section with shader animations that add glowing, moving or textured effects. Examples listed by the Help Center are Shake Zoom (intensity slider), Whip Slide (speed slider), Old TV and Chroma Wave. Choose where to apply it, On enter, On exit or Both, and use Remove animation to undo. They need a supported MP4 file and the latest Canva version.

Source: https://www.canva.com/help/shader-animation/[Canva Help Center: Shader animations for videos]

== Reduce motion and accessibility

Reduce motion limits animation when designs are viewed or presented, which helps people with motion sensitivities or vestibular disorders. When it is on, animations are reduced, and transitions, background animations, masks and overlays are removed. You can turn it on in three places:

* for all designs, from the homepage profile icon, then Settings, Accessibility and the Reduce motion when you view and present designs dropdown (Reduce motion on or Use my system preferences)
* for one editor session, from File, Accessibility, Reduce motion
* from a public view link, by hovering at the bottom of the page, choosing More and then Reduce motion

It is a per-account setting and does not affect collaborators. It affects playback only, not editing or exporting, so animations may still appear in downloaded video files. Design with that in mind: keep motion short, avoid flashing and give essential information a static form.

Source: https://www.canva.com/help/reduce-motion-settings/[Canva Help Center: Reduce motion settings for animations and transitions]

== Exporting animated designs

Animated designs download as video or GIF, can be shared directly to social media or scheduled. Select Share, then Download, and choose a file type.

.Paths from an animated design to a file or shared post, and what Reduce motion changes
image::ui-ux-canva-animation-and-transitions-export-and-reduce-motion.svg["Diagram from an animated design through Share to a downloaded MP4 video or GIF and to direct sharing, with a panel explaining that Reduce motion changes playback only",width=720]

[cols="1,3,2", options="header"]
|===
| File type | Settings | Limits stated by the Help Center

| MP4 video | Quality 480p, 720p, 1080p or 4K (4K on desktop only); pages All, This Page or Custom | Free: up to 30 minutes and 1920 x 1080; Pro, Teams, Nonprofits and Education: up to 2 hours and 3840 x 2160
| GIF | Size 0.2x to 1x or a typed value; optional transparent background | Free: up to 1 minute and 1280 x 720; paid and Education: up to 2 minutes and 1920 x 1080
|===

On Free, changing the MP4 quality or resolution from the default shows an upgrade prompt; keep the default to download without upgrading. If you used premium or paid audio, verify its license when downloading before posting. The broader download options are on xref:ui-ux/canva/downloading-and-file-formats.adoc[Downloading and File Formats], and full video editing on xref:ui-ux/canva/video-editor-audio-and-captions.adoc[Video Editor, Audio and Captions].

Source: https://www.canva.com/help/download-as-video/[Canva Help Center: Downloading designs as video or GIF]

== Desktop and mobile

The Animate panel, Magic Animate and Create an Animation have desktop and mobile instructions in the Help Center, and Magic Animate is described as best on a computer. Precise tools such as element timing tiles and click-order dragging are easier with a pointer. The 4K MP4 option is desktop only.

== Procedure: animate the Bookshelf launch post

. Open the "Book of the week" post and select the book cover.
. Choose Animate, hover the styles on the Element tab to preview them, apply one subtle style and pick the Medium speed.
. Select the title and apply a text animation from the Text tab; select the call-to-action pill and apply an animation with Appear on click if it should wait for a presenter.
. Choose Show element timing and drag the tiles so that the cover appears first, then the title, tagline and pill; shorten any bar that lasts too long.
. Check the result with Preview, add a transition if the post has several pages, then select Share, Download, choose MP4 video or GIF and download.

== Common pitfalls

* Animating everything at once makes the reading order unclear; animate the one thing that should be seen first.
* A Magic Animate style is applied to the whole design; review timing afterwards.
* Transitions are not offered in Docs, and in video designs they are set on the timeline.
* Reduce motion does not change exports, so a viewer may still receive motion in a downloaded video.
* A single animation cannot exceed 10 seconds.
