The running example is *Bookshelf*, the book catalogue and reading-list app designed in the xref:ui-ux/figma/index.adoc[Figma sub-section]. Its launch campaign starts with a written brief, and that brief is a Canva Doc. This page builds it: it chooses a page type, structures the brief with headings, a table and a divider, drafts parts of the text with Canva AI, collects feedback in suggestion mode, and shares the result as a PDF, a DOCX file or a web page.

== The anatomy of a doc

A doc is made of the same top bar as any other design (File menu, Share and the other header actions), a side panel, a floating toolbar that follows the text cursor and the selection, and a page of blocks. A block is a paragraph, a heading, a table, a column layout, an image, a banner, a design block or an embed. You add most blocks with *Quick actions*: type `/` on an empty line, or select the plus icon next to the text cursor, and search for what you need.

== Page types and page breaks

When you create a doc from the homepage (Create, then Docs) you either start from a doc template or from a blank doc in one of these sizes:

[cols="1,3", options="header"]
|===
| Page type | Behaviour

| Digital | Screen-oriented pages sized to the content
| Pageless | One continuous canvas with no page edges; page breaks, if you add them, size pages to the content
| A4 (21 x 29.7 cm) | Fixed paper page
| Letter (8.5 x 11 in) | Fixed paper page
| Legal (8.5 x 14 in) | Fixed paper page
| A3 (29.7 x 42 cm) | Fixed paper page
|===

To change the type later, open the File menu and select Page setup. In fixed formats, content flows onto a new page automatically so that the document fits a traditional print layout. You can also break pages by hand in any format: select the plus icon next to the text cursor, or type `/Page break`, and choose Page break. In the Digital and Pageless formats a manual break creates pages sized to the content; in fixed formats it moves the following content to a new page of that set size. The Help Center warns that breaks may not behave correctly when a page holds too much content, and that after downloading you may find content that does not fit the page, so check the exported file.

A banner is a header or a styled page break. Add one from Elements, then Banner, and edit it later from the toolbar with Edit. An image, video, design or layout can also be set as a full-page cover: select the item, open More in the toolbar (or right-click) and choose Set as full page. Full-page covers work best in paged docs, where they take over the first page. In Digital and Pageless docs they are only visible once you add page breaks, and in fixed formats the cover may leave whitespace or be clipped at the page height.

== Structure and layout blocks

[cols="1,3,3", options="header"]
|===
| Block | How to add it | Notes

| Headings | Type `/` then H1 to H5 or Body, or the plus icon | The heading styles are Title, Subtitle, Heading, Subheading and Section header
| Dates | Plus icon, then Date, or `/date`, `/today`, `/tomorrow`, `/yesterday` | The date can be recoloured with the text colour control
| Divider | Plus icon, then Divider, or type three dashes | Colour and style are set from the toolbar
| Table | Elements, then Tables, or type `/table` and choose rows and columns | Format border, colour and size; select several cells with Shift and click
| Columns | `/column`, then Columns, 2 Columns, 3 Columns or 4 Columns | Columns offers right sidebar, left sidebar and three columns with sidebars
| Side by side | Drag one element next to another until the blue placement indicator appears | Up to four elements; drag the divider to change widths; narrow screens stack the content
| Highlight blocks | Elements, then Highlight blocks | Pre-styled blocks for notes, information and warnings
| Design blocks | Quick actions, then Design, or `/Design` | Design a header or diagram from scratch or from a template; edit later with Edit in the toolbar
| Dropdowns | `/`, then Dropdown | Presets are Status, Rating, Effort, Timing, Approval and Priority; custom dropdowns cannot be saved as presets
| Mentions | `@` or `/mention` | Covered under collaboration below
|===

Dividers deserve a note on shortcuts: the three-dash shortcut works the same on macOS and Windows because it is typed text. Pressing Tab in front of a sentence or paragraph indents it, the same as the Indent button. For paragraph, line and letter spacing select the paragraph and use Advanced settings in the text toolbar; for the whitespace between blocks such as images and layouts select the block and use Spacing in the editor toolbar. The word count, character count and estimated reading time are found under File, Settings, Word Count, and only the owner or an editor of the doc can see them.

To keep a long brief navigable, open *Outline* from the bottom of the editor. It lists the headings of the doc hierarchically next to the side panel, and selecting Outline again closes it.

Elements such as photos, videos, audio, shapes, graphics, lines, stickers, charts and tables can be resized up to the full width of the page. The Elements tab search box can also generate new content from your prompt with Generate. The Canva photo editor works on images in a doc, but the Help Center states that Magic Grab is not yet available in Docs.

== Embedding designs

To place another Canva design in a doc, paste the design link. Double-click the embedded design to interact with it. If a message says that the design is public because of an active embed link, unpublish the design to restrict access and then create a new embed link. In the Bookshelf brief this is how the "Book of the week" post and the launch deck appear inside the document, so reviewers see the real design rather than a screenshot.

Source: https://www.canva.com/help/add-format-content/[Canva Help Center: Add and format content in Canva Docs]

== Writing with Canva AI

The Canva AI tab in the editor side panel generates, refines and summarises text in a doc. The Help Center lists these uses: generate text in a blank doc, continue or build on existing text, refine text by improving, rewriting, expanding or changing the tone, summarise a long document, and polish formatting with markdown, colour, bold and italics. It can use the content of the doc as context, pull context from your other Canva designs, search the web for live information through Web Research, and apply formatting automatically to what it generates. According to the article it is available on Free, Pro, Business, Enterprise and Nonprofits accounts, in English, Arabic, Chinese (Simplified and Traditional), Dutch, French, German, Hindi, Indonesian, Italian, Japanese, Polish, Portuguese, Spanish, Thai, Turkish and Vietnamese, and it is not yet available to everyone. For quick edits to short content the same article points to Magic Write.

Good prompts name the audience, the tone and the purpose. If a result is slow, shorten the prompt or split it; if the tone is off, say exactly which tone you want, and check whether a Brand Voice setting is influencing the output by turning it off temporarily. Outputs vary between runs, so regenerate when a result is close but not right. The assistant itself is covered on xref:ui-ux/canva/canva-ai-assistant.adoc[the Canva AI assistant page] and the single-purpose tools on xref:ui-ux/canva/magic-studio-tools.adoc[Magic Studio Tools].

Source: https://www.canva.com/help/canva-writing-assistant/[Canva Help Center: Use Canva AI to generate, refine, and summarize docs]

== Collaborating in a doc

* *Mentions.* Type `@` followed by a name, or use `/mention`. Select Send notification to notify the person by email and on their homepage. If the button is not available, give the person access to the design first.
* *Following.* Select a collaborator's avatar in the toolbar to keep your view in sync with theirs across pages; Stop ends it. Following ends automatically if the person stays disconnected for two minutes, and when a presenter has started Spotlight and requires everyone to follow, you cannot stop until they select Release.
* *Suggestion mode.* Open the Editing dropdown above the editor and select Suggesting. Adding, deleting or replacing text, changing formatting such as font size or bold, and adding, deleting or moving elements are tracked as suggestions, shown highlighted in blue. Select a suggestion and use the check icon to accept it or the cross icon to reject it. Resolved suggestions appear under the comment icon, with the filter set to Resolved. Suggestions are different from comments, which are covered on xref:ui-ux/canva/collaboration-comments-and-version-history.adoc[Collaboration, Comments and Version History].
* *Sharing.* Select Share, choose the permission in the dropdown and copy the link; the access choices are Can edit, Can comment and Can view. See xref:ui-ux/canva/sharing-and-permissions.adoc[Sharing and Permissions].

Source: https://www.canva.com/help/share-publish-docs/[Canva Help Center: Collaborate, share, and publish your Canva Docs]

=== Transform a design into a doc

Resize includes Transform into Doc, which converts any design into a doc in the format you choose. Open Resize in the top menu, select Transform into Doc, open More and choose a format: Executive summary, Creative blog post, Presentation outline, Content marketing ideas, LinkedIn post, Marketing video script, Detailed project plan, Professional email memo, All text, Poem or Song lyrics. Then select Transform into Doc and Open Doc; a copy opens in a new tab and the original design is kept. You can transform into a doc one design at a time, while resizing to several design types at once. The article lists Canva Pro, Canva Teams, Canva Education and Canva for Nonprofits for Resize; Teams has been replaced by Canva Business for new sign-ups, so check the pricing page for your own plan. Administrators can control access to Magic features for a team or class. See xref:ui-ux/canva/resize-bulk-create-and-translate.adoc[Resize, Bulk Create and Translate].

Source: https://www.canva.com/help/transform-to-doc/[Canva Help Center: Transform your designs into a doc]

== Scrollables

Scrollables turn a static doc into an interactive scrolling experience with animations that play as the reader scrolls. They can be shared as a public view link or a website, and the Help Center says they are rolling out gradually. Create one from the homepage Templates tab by searching for Scrollable Design, or inside a doc through Quick actions (or `/`), then Scrollable Design, then Create new scroll animation, and select Save when done. From the Design tab you can also pick a template under Docs with Scrollables. Scroll-driven transitions can currently be enabled only for banner designs: select a banner, choose Settings in the floating toolbar and turn on Scroll-driven transition.

Limits to remember: scrollables can only be added in a doc, whiteboards, sheets and docs cannot be added as scrollable designs, importing an existing design adds only its first 20 pages, a PDF export contains only the first page, videos are muted by default, and the look differs between web and mobile because the background adapts to the design ratio.

Source: https://www.canva.com/help/scrollable-designs/[Canva Help Center: Scrollables in Canva Docs]

== Desktop and mobile

The Help Center documents the same procedures for desktop and for the mobile app, so the slash menu, page setup and sharing steps above apply in both. The visible differences are layout ones: narrow screens stack side-by-side content vertically, scrollables look different on web and on mobile, and the Follow feature is described for desktop. See xref:ui-ux/canva/desktop-mobile-and-offline.adoc[Desktop, Mobile and Offline].

== Procedure: write and share the Bookshelf launch brief

.Write the brief, draft with Canva AI, collect suggestions and share
image::ui-ux-canva-docs-storyboard-brief.svg["Five-step storyboard: create a doc and pick a size, type a slash to add headings and tables, draft with Canva AI, review in suggestion mode, then download or publish",width=720]

. From the homepage select Create, then Docs, and choose a blank doc in the A4 size. If the brief should read on screen only, choose Pageless instead; you can change it later under File, Page setup.
. Type the title, then type `/` and add an H2 heading named "Goals". Repeat for "Audience" and "Channels".
. Under "Channels" type `/table`, choose three columns and four rows, and list Instagram post, Instagram story, LinkedIn banner and YouTube thumbnail with their launch dates. Type `/date` to add dated entries.
. Type three dashes to add a divider, then `/Page break` to start the "Plan" page.
. Open the Canva AI tab in the side panel and ask for "a 100-word summary of the Goals section for a book-club audience, friendly tone". Insert the result and edit it.
. Paste the link of the "Book of the week" design to embed it, and open Outline to confirm the headings read as a table of contents.
. Switch Editing to Suggesting, change a sentence and watch it appear as a blue suggestion; accept or reject it with the check or cross icon.
. Type `@` and a teammate's name, select Send notification, and set access to Can comment.
. Select Share, then Download, choose DOCX or PDF Standard and the size, and select Download. Open the file and check that no page overflows.

Source: https://www.canva.com/help/create-canva-docs/[Canva Help Center: Create, layout, and structure Canva Docs]

== Pitfalls

* A fixed paper format with a page full of content may export with content that does not fit; check the downloaded file.
* A full-page cover in a Pageless doc is invisible until you add page breaks.
* A missing Send notification button means the person has no access yet.
* Public embeds keep a design public; unpublish before restricting access.
* A doc cannot be exported as PPTX, and the Docs to Decks conversion is gone.
* Custom dropdowns are not saved as presets; add the options again in another doc.
