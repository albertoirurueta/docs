This page was checked against the official Canva Help Center on 2026-11-07. It covers text in the Canva editor (web, desktop app and mobile apps): adding a text box, formatting it, controlling spacing, resizing and wrapping it, linking it, bending it with effects, picking and uploading fonts and building a type scale you can reuse. All of it is generally available. Basic text, formatting and the ten built-in text effects are available on every plan (Free, Pro, Business, Enterprise, Education and Nonprofits). Three things depend on your subscription or account. The extended font library and font uploads are tied to paid plans, and per the Help Center to Canva for Education and Canva for Nonprofits as well. The advanced text apps (TypeStudio, TypeCraft, TypeExtrude, TypeCutOut, TypeLettering and TypeGradient) are listed as included in paid plans. Grab Text is available on eligible plans and design types, and the article points to the AI-access rules; the tiers (Standard, Premium and Ultra) are explained on xref:ui-ux/canva/plans-pricing-and-ai-allowance.adoc[Plans, Pricing and AI Allowance]. Prices are not repeated here; see https://www.canva.com/pricing/.

Canva moves controls between releases, so this page names controls by label and shortcut, and its drawings are schematic sketches of a generic editor, not screenshots. The editor itself is described on xref:ui-ux/canva/editor-tour.adoc[Editor Tour].

The running example is *Bookshelf*, the book catalogue and reading-list app designed in the xref:ui-ux/figma/index.adoc[Figma sub-section]. Its launch campaign needs a "Book of the week" Instagram post whose headline is readable, on-brand and a little playful. The type decisions behind it, a title style, a body style and a caption, are the same ones made in Figma on xref:ui-ux/figma/text-and-typography.adoc[Text and Typography]; the principles of hierarchy and contrast are on xref:ui-ux/figma/ux-process-and-design-thinking.adoc[UX Process and Design Thinking] and are not repeated here.

== Text in one picture

Every text element in Canva is a text box. Selecting a text box shows a toolbar with the controls that apply to text, and white pill handles at the left and right edges that change its width. Because the toolbar is the quick actions toolbar of the redesigned editor, its exact layout depends on the window width and on what is selected; more controls sit behind the ellipsis on narrow windows.

. Font size is a field with minus and plus buttons.

== Adding and editing text

In a design, press T to add a text box (on macOS and Windows alike, because it is a single-key shortcut), or open the Text tab in the side panel and choose a text style or a font combination. Double-click a text box to edit its content, and click outside it to finish. To duplicate a box, use Duplicate on the floating toolbar or Command + C and Command + V (Ctrl + C and Ctrl + V on Windows); to delete it, use Delete on the toolbar or press Delete on macOS or Backspace on Windows.

In Canva Docs the model differs: type / or select the plus icon next to the cursor and search for H1 to H5 or Body. The heading styles are named Title, Subtitle, Heading, Subheading and Section header, and the Docs-only shortcuts Option + Command + 1 to 5 apply them (Option + Command + 0 applies body text). Highlighting a selection uses the Highlight colour button of the toolbar, with a No color tile to remove it.

The Text tab also holds Dynamic text. Selecting Page numbers there adds numbers that update when you add, hide, delete or move pages; you choose the format (Numbers only, Page and number, or Page X of Y), choose the pages and select Apply properties to all pages. Whiteboards, Sheets, Docs and Websites do not support automatic page numbers.

=== Desktop versus mobile

On a phone you tap the page to start typing, tap a text box and then Edit on the toolbar below the editor, and double-tap a box to edit its content. The keyboard toolbar above the on-screen keyboard carries the text tools. Pill handles also work by tapping and dragging. Several advanced controls, such as Kerning and Ligatures, are described by the Help Center for desktop.

Source: https://www.canva.com/help/add-and-edit-text/[Canva Help Center: Add and edit text] and https://www.canva.com/help/automatic-page-numbers/[Canva Help Center: Automatic page numbers]

== Formatting: font, size, colour and emphasis

The format controls are the ones in the toolbar. To change the font, select the text, select the font name and choose a font; the search box filters by language and price through its filter icon. To change the weight, select the icon beside the font in the font list and pick a weight. Font size is set with the field or the minus and plus buttons. Text colour opens the colour panel. Bold, italics, underline and strikethrough are toggles, alignment offers left, centre, right and justify, and the List button offers bullet and numbered lists. The aA button changes between lowercase and uppercase.

Canva can blend up to 10 colours in a gradient on one text box (gradients are supported in Canva Docs only in Design Blocks and Banners). The Help Center describes saving formatted text as a template or Brand Kit element, not as a named text style; to copy formatting to another text box, select the formatted text and use the Format painter. In effect, "text styles" in Canva are the brand fonts you set as heading, subheading and body in the Brand Kit, which is covered on xref:ui-ux/canva/brand-kit-and-brand-voice.adoc[Brand Kit and Brand Voice].

== Spacing, kerning and ligatures

Spacing is set from the icon-only Advanced settings button of the text toolbar, which opens a Spacing popup with Letter spacing and Line spacing. Line spacing defaults to 1.4 and can be reduced to a minimum of 0.5; letter spacing defaults to 0, and Canva does not label any value as single spacing. In Canva Docs and Canva Email, Advanced settings also exposes Paragraph spacing, a slider or value for the space before and after paragraphs.

Under Advanced settings, More settings, you find Text position (Subscript, Superscript, None) and, on the Advanced tab, Typography toggles for Kerning and Ligatures, with a Change all button. Kerning adjusts the space between particular character pairs that look awkward, such as "AV" or "To", and ligatures are special glyphs that combine two or more characters into one. Kerning is not yet supported when exporting text animations; if an animated headline looks different after export, switch kerning off and export again.

== Resizing, wrapping and linking

To make text wrap, change the width of the box, not its font size: drag a white pill handle to the left or right and lines break earlier or later. Hold Option (macOS) or Alt (Windows) while dragging a handle to resize from both sides at once. If lines do not lengthen when you widen the box, a manual line break is the cause and must be removed; a box must also not be grouped with other elements. The limitations are firm: text does not flow automatically across several text boxes, and it does not wrap around a graphic or image placed on top of it, so wrapping around artwork is done by hand with several boxes.

To add a hyperlink, select the text box (or double-click and highlight just the words), open More on the floating toolbar and choose Link, or press Command + K. You can link to a web address, to another page of the same design or to one of your recent designs; Edit link lets you change the text, the link and the display mode. Links stay clickable only when you download the design as a PDF or present it. They do not work in PNG, JPG or MP4 downloads, or when you post a design to social media, which matters for the Bookshelf Instagram post: link the profile, not the image.

Source: https://www.canva.com/help/hyperlinks/[Canva Help Center: Add hyperlinks]

== Vertical text

For Chinese, Japanese and Korean text Canva provides a Vertical text button on the toolbar, which switches the box to a traditional vertical layout and back. It appears only when the text is in one of those languages and the design type is supported (for example presentations and posters, not Canva Docs or Canva Sheets). To make vertical text without typing in a supported language, use Translate in the editor to convert the text first. The Help Center article lists the option for desktop.

Source: https://www.canva.com/help/vertical-text-in-canva/[Canva Help Center: Use vertical text in Canva]

== Text effects

The Effects button on the text toolbar opens the effects panel. The Help Center groups the effects in three categories, and the panel's controls adjust intensity, colour, direction and transparency for the ones that have them.

[cols="1,3", options="header"]
|===
| Category | Effects

| Style | Drop, Glow, Echo, Outline, Background, Splice
| Color | Hollow, Glitch, Neon
| Shape | Curve
|===

.The ten text effects drawn on the word Book
image::ui-ux-canva-text-and-typography-effects-gallery.svg["Ten tiles showing the word Book with each effect: Drop, Glow, Echo, Outline, Background, Splice, Hollow, Glitch, Neon and Curve, labelled by category",width=720]

To apply an effect, select the text box, choose Effects, choose an effect and adjust its sliders. To change its colour, use the effect colour option next to Effects in the toolbar or in the effects panel; both give the same controls. To remove it, select Remove effect at the bottom of the panel (on mobile the choice is called None). If hyperlinks on text with effects stop working, the Help Center has a separate fix article.

=== Effects and gradients

Gradient text and effects interact. According to the Help Center, Shadow, Glow, Curve and Echo show the full gradient range, while Neon, Hollow, Glitch and Splice may show only the first gradient colour, and some effects can override the gradient. For the best result apply the effect first and the gradient second, use solid colours for complex effects such as Neon or Glitch, and export as PNG or JPG; PDF and SVG exports may not show gradients correctly.

=== Advanced text apps

The Text tab also lists apps for advanced effects: TypeStudio (pro-style lettering), TypeCraft (warp and distort), TypeExtrude (depth), TypeCutOut (text filled with a background image), TypeLettering (customisable effects) and TypeGradient (gradients). The Help Center says these apps are included in paid plans and may not be available in every design type; where they are missing, use the built-in effects.

Source: https://www.canva.com/help/text-effects/[Canva Help Center: Enhance text with effects]

=== Curve a headline for the Bookshelf post

. Open the *Book of the week* Instagram post and select the headline text box.
. Select Effects on the text toolbar.
. In the panel, open the Shape group and choose Curve.
. Drag the intensity slider (or type a value) until the arc follows the top of the cover.
. Apply the brand colour with the effect colour option if the effect added one, then click outside the box.

== TypeCraft

TypeCraft bends, warps and twists text more freely than Curve. It is an app: you connect it to your Canva account the first time. Open it from Apps on the homepage (then Use in existing design or Use in new design) or from Apps in the editor side panel, search for TypeCraft and select Open. Type the text, choose a font and a style, set a colour, drag the dot points to reshape the text (Reset shape starts over) and select Add element to design. Like the other text apps it is listed as included in paid plans.

Source: https://www.canva.com/help/customize-text-with-typecraft/[Canva Help Center: Customize text with TypeCraft]

== Grab Text

Grab Text turns text that appears inside a photo into editable text boxes. Select the photo, choose Edit on the editor toolbar, open Tools, select See all, scroll to the bottom and select Grab Text. Select the text to process (drag over several lines) and choose Grab. It works best on flat, straight text photographed from directly overhead. Selecting a specific region is not yet available on iOS.

Limits to expect: bold, italic and underline are not preserved; rotated or arched text, non-Latin alphabets and multi-page files are not supported; adjusted transparency can make grabbed text look odd; and Grab Text matches the nearest font and position, so you may need to reformat. It is unavailable in China, Canva Docs, Video and the Photo Editor outside the Editor. Undo, or select Grab Text again, to restore the image. Use it for your own images only, such as a scan of your own press sheet; text from other people's work stays theirs.

Source: https://www.canva.com/help/using-grab-text/[Canva Help Center: Selecting and changing the text in your photos with Grab Text]

== Fonts

Choosing a font is the single largest typographic decision, so Canva offers three routes: the font library (some fonts are for paid plans, which you can filter by price), fonts in your Brand Kit and uploaded fonts. Fonts in the Brand Kit appear under Brand in the Text tab and the font list, and uploaded fonts appear under Uploaded fonts.

=== Upload a font

Uploading is for team owners, administrators and brand designers on paid plans (per the Help Center, Pro, Business, Education and Nonprofits). Canva supports OTF, TTF and WOFF files, up to 500 fonts per Brand Kit and up to 18 styles per font family. Your fonts must be licensed for embedding or they may not upload, and you may upload only fonts you are licensed to use (see the Terms of Use). Upload the regular, bold and italic files if you want the B and I buttons to work; with only the regular file those buttons are greyed out. Fonts uploaded before July 2023 must be re-uploaded with the extra styles to be grouped automatically.

. From the homepage side panel select Brand, and pick the Brand Kit to customise if you have several.
. Go to Fonts and select Add to category, then Upload a font.
. Drag the Bookshelf font file into the window, or choose files and select Open.
. Confirm and wait for the upload to finish.
. In a design select a text box, open the font name on the toolbar and pick the font under Uploaded fonts (scroll down if needed).

.Storyboard: upload the Bookshelf font and use it
image::ui-ux-canva-text-and-typography-storyboard-brand-font.svg["Storyboard of five panels: open Brand, choose Fonts then Upload a font, drop the font file and confirm, select text and pick the font under Uploaded fonts, and the post set in the brand font",width=720]

If an uploaded font seems to be missing, it may be in a different Brand Kit; switch kits from the Brand Kit name. To make a font the heading, subheading or body font of the brand, set it in the Brand Kit as described on xref:ui-ux/canva/brand-kit-and-brand-voice.adoc[Brand Kit and Brand Voice].

Source: https://www.canva.com/help/upload-fonts/[Canva Help Center: Upload and use Brand Kit fonts]

=== Colour and font combinations

To try readymade pairings, select the page background or thumbnail, choose Edit on the floating toolbar and open Styles. Pick a colour palette, a font set, an image palette or a combination, optionally select Apply to all pages, and use Shuffle for variations. Styles changes colours and fonts across the pages; it does not copy artwork or layout. Try styles early, because a design with many slides may not offer suggestions. In presentations, layouts are still applied to pages one at a time. The template side of Styles is on xref:ui-ux/canva/templates-layouts-and-magic-design.adoc[Templates, Layouts and Magic Design].

Source: https://www.canva.com/help/color-and-font-combinations/[Canva Help Center: Find color palettes and font combinations]

== A type scale for Bookshelf posts

A type scale is a short list of sizes that each have a job, so you never pick a size by eye. A common approach is a fixed ratio between steps; the example here uses 1.5 from body up to title. The Canva roles line up with the heading names of the Text tab: Title, Subtitle, Heading, Subheading and Body. Keep the scale in a Brand Kit or a brand template so that every Bookshelf post inherits it, limit yourself to one or two font families and use weight (not another typeface) for emphasis. For pairing and legibility ideas see the Canva Learn guides on typography and font pairing.

== Common pitfalls

* Fonts that switch back unexpectedly, do not apply or change after download are usually caused by a browser extension or plugin (the Help Center names Speechify as one that sends fonts back to Arimo). Try the Canva desktop app, a private window or disabling extensions.
* A hyperlink on text works in PDF downloads and in present mode only, not in PNG, JPG, MP4 or social posts.
* Dragging the pill handles does not change the font size; use them, not the font size, to wrap lines.
* Effects may not combine with gradients as expected; apply the effect first and export as PNG or JPG.
* Grab Text does not keep bold, italic or underline, and does not read arched or non-Latin text.
* Bold and italic buttons are greyed out on an uploaded font if only the regular file was uploaded.
* Do not upload a font you are not licensed to embed; the upload may fail and it breaks the Terms of Use.
* A text effect, TypeCraft or an uploaded font may export differently, so check the downloaded file, not only the editor.

Source: https://www.canva.com/help/font-editing-issues/[Canva Help Center: Font editing issues]

* Fonts uploaded before July 2023 need re-uploading with bold and italic files to be grouped automatically.
