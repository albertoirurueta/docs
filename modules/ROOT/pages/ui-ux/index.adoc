*User interface (UI) design* is the craft of the surface people see and touch: layout, typography, colour, components,
icons and motion. *User experience (UX) design* is wider: it covers who the users are, which tasks they want to
finish, how the product is structured, how it behaves and whether it actually helps. UI is therefore a part of UX, and
a beautiful interface can still deliver a poor experience if the flow behind it is wrong.

The xref:ui-ux/overview.adoc[overview] compares UI and UX design, walks through the UX process from discovery to iteration and surveys the design tools landscape.
