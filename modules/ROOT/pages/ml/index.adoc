*Machine learning* builds programs that improve at a task by learning from data instead of following hand-written rules.
This section explains how that works and how to do it with the main Python frameworks. The general pages cover the
ideas that apply everywhere: problem framing, the mathematics, optimisation, generalisation, neural-network
architectures, hardware, deployment and responsible use. Three framework sub-sections then go deep into PyTorch,
TensorFlow with Keras 3 and scikit-learn.

The xref:ml/overview.adoc[overview] states the scope of the section and where it ends, the targeted versions, the learning path and reading order, and a map from every concept to the page that covers it.
