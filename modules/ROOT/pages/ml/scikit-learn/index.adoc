*scikit-learn* is the standard library for classic machine learning in Python. Within the
xref:ml/index.adoc[ML (Machine Learning)] section it is the tool for tabular data and small to medium problems, where
a well-tuned linear model, tree ensemble or kernel method often beats a neural network and is much cheaper to train. The
full tour of the library, from installation and the estimator API to pipelines, validation and model persistence, lives
in the xref:data-science/scikit-learn/index.adoc[Data Science scikit-learn sub-section]. This sub-section does not repeat
it: it adds the models and practices that are specific to machine learning and shows where scikit-learn hands over to
deep-learning frameworks.

[discrete]
=== The names

The library is called *scikit-learn*, written with a hyphen and no capital letters apart from the start of a sentence. It
is imported as *sklearn* and installed with pip as scikit-learn. People often write "Sci-kit learn" or "SciKit-Learn";
those spellings are not the project name. The "scikit" part comes from SciKits, add-on toolkits for SciPy, a family that
also includes scikit-image. Search for scikit-learn, but write sklearn in import statements, and note that the old
pip package name sklearn is not the library.

=== Where older books are outdated

Books and tutorials written for scikit-learn 0.x or early 1.x still circulate, and much of their code no longer runs. The table maps the
usual old idioms to what scikit-learn 1.9.1 provides; every name in the right-hand column was checked on 1.9.1.

[cols="2,2,3",options="header"]
|===
|Old code |Status |Current replacement

|`sklearn.cross_validation` (`train_test_split`, `cross_val_score`, `KFold`)
|Deprecated in 0.18, removed in 0.20
|`sklearn.model_selection`, same function and class names. See xref:data-science/scikit-learn/cross-validation.adoc[Cross-Validation].

|`sklearn.grid_search` (`GridSearchCV`, `RandomizedSearchCV`)
|Deprecated in 0.18, removed in 0.20
|`sklearn.model_selection.GridSearchCV` and `RandomizedSearchCV`. See xref:data-science/scikit-learn/hyperparameter-search.adoc[Hyperparameter Search].

|`sklearn.lda.LDA`
|Removed in 0.19
|`sklearn.discriminant_analysis.LinearDiscriminantAnalysis`. See xref:ml/scikit-learn/discriminant-analysis.adoc[Discriminant Analysis].

|`sklearn.preprocessing.Imputer`
|Deprecated in 0.20, removed in 0.22
|`sklearn.impute.SimpleImputer` (no `axis` argument; it always imputes per column). See xref:data-science/scikit-learn/imputation.adoc[Imputation].

|`+OneHotEncoder(categorical_features=[...])+`
|Deprecated in 0.20, removed in 0.22
|`OneHotEncoder` on the categorical columns only, selected with `sklearn.compose.ColumnTransformer`; `sparse=` is now `sparse_output=`. See xref:data-science/scikit-learn/categorical-encoding.adoc[Categorical Encoding].

|`sklearn.datasets.fetch_mldata`
|Removed in 0.22 (mldata.org is gone)
|`sklearn.datasets.fetch_openml`. See xref:data-science/scikit-learn/datasets.adoc[Datasets].

|`sklearn.datasets.load_boston`
|Removed in 1.2 for an ethical problem in the data; importing it raises `ImportError` with an explanation
|`fetch_california_housing`, or the Ames housing data through `+fetch_openml(name="house_prices", as_frame=True)+`.

|`LogisticRegression(multi_class="ovr")` or `multi_class="multinomial"`
|Deprecated in 1.5, removed in 1.8
|Plain `LogisticRegression()`, which is multinomial for more than two classes; wrap it in `sklearn.multiclass.OneVsRestClassifier` for one-vs-rest. See xref:ml/scikit-learn/multiclass-and-multioutput.adoc[Multiclass & Multioutput].

|`np.infty` (also `np.Inf`, `np.NaN`) in parameter grids and thresholds
|Removed in NumPy 2.0
|`np.inf` and `np.nan`.

|`pickle.dump` / `pickle.load` of a model, often shown with no warning
|Still works, but loading a pickle (or a joblib file) can execute arbitrary code, and a model only loads reliably with the same scikit-learn version
|`joblib.dump` / `joblib.load` for files you created yourself; `skops.io` (which lists untrusted types with `get_untrusted_types` before loading) for files from elsewhere; ONNX through skl2onnx for serving without scikit-learn. Only load pickle or joblib files from a source you trust. See xref:data-science/scikit-learn/model-persistence.adoc[Model Persistence] and xref:ml/scikit-learn/exporting-to-onnx.adoc[Exporting to ONNX].

|`SVC(probability=True)`
|Deprecated in 1.9, removal planned for 1.11; 1.9.1 emits a `FutureWarning`
|`CalibratedClassifierCV(SVC(), ensemble=False)` from `sklearn.calibration`, or a model with native probabilities such as `LogisticRegression`. See xref:data-science/scikit-learn/calibration.adoc[Calibration].
|===
