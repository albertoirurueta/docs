This page holds the conceptual material of the xref:ml/index.adoc[ML (Machine Learning)] section: its scope, the versions every page targets, the learning path and reading order, and the map from concepts to pages. The general concept pages (for example xref:ml/what-is-machine-learning.adoc[What Is Machine Learning?] and xref:ml/neural-network-fundamentals.adoc[Neural Network Fundamentals]) stay at the section level and are linked from the learning path and the concept-to-page map below.

== Scope and neighbouring sections

The section stops where other sections of this site take over.

* xref:data-science/index.adoc[Data Science] covers the project workflow around a model: acquisition, cleaning,
  exploration, statistics, feature engineering, evaluation and reproducibility, with NumPy, pandas and scikit-learn
  sub-sections. This section builds on those pages and links back to them instead of repeating them. The
  xref:ml/scikit-learn/index.adoc[scikit-learn sub-section here] holds only the material that goes beyond them.
* xref:ai/index.adoc[Artificial Intelligence] covers model-centred and application topics such as large language models,
  agents, retrieval, Hugging Face and LangChain. The bridge page
  xref:ml/attention-and-transformers.adoc[Attention & Transformers: the Bridge to LLMs] ends where those pages begin.
* Databases, deployment infrastructure and other engineering topics live in their own sections.

== Targeted versions

The pages target the versions below, checked on 2026-10-30. Examples on the general pages were run on 2026-11-01 on
Python 3.13 with these library versions on a CPU-only machine; each page says which of its examples need hardware or
services (GPUs, several machines, Docker, large downloads) and were therefore not run. Anything labelled upcoming is not
yet released and is described from the project's own announcements.

[cols="2,1,3",options=header]
|===
|Component |Version |Notes

|Python
|3.13
|3.13 is the newest Python that every library here supports: TensorFlow 2.21 ships wheels for Python 3.10 to 3.13 only,
while PyTorch 2.15, scikit-learn 1.9 and Keras 3.15 require Python 3.11 or later (PyTorch 2.14 was the last release with
Python 3.10 wheels). On Python 3.10, pip silently resolves older releases instead, for example Keras 3.12.4, the newest
Keras whose metadata still allows 3.10.

|PyTorch
|2.15.0
|Released on 2026-10-28. See xref:ml/pytorch/index.adoc[PyTorch].

== Reading order

. Start with xref:ml/what-is-machine-learning.adoc[What Is Machine Learning? AI vs ML vs DL],
  xref:ml/types-of-learning.adoc[Types of Learning] and
  xref:ml/problem-framing-and-ml-projects.adoc[Problem Framing & the ML Project Lifecycle].
. Learn the foundations in xref:ml/math-for-machine-learning.adoc[Math for ML],
  xref:ml/information-theory-and-losses.adoc[Loss Functions & Information Theory],
  xref:ml/gradient-descent-and-optimization.adoc[Gradient Descent & Optimization] and
  xref:ml/generalization-and-regularization.adoc[Generalization, Bias–Variance & Regularization].
. Survey the non-deep methods in xref:ml/classic-algorithms-overview.adoc[Classic ML Algorithms at a Glance] and
  xref:ml/tabular-data-and-gradient-boosting.adoc[Tabular Data: Gradient Boosting vs Deep Learning].
. Move to neural networks with xref:ml/neural-network-fundamentals.adoc[Neural Network Fundamentals],
  xref:ml/backpropagation-and-autodiff.adoc[Backpropagation & Automatic Differentiation] and
  xref:ml/training-deep-networks.adoc[Training Deep Networks], then the architecture pages.
. Pick a framework with xref:ml/choosing-a-framework.adoc[Choosing a Framework] and work through the
  xref:ml/pytorch/index.adoc[PyTorch], xref:ml/tensorflow/index.adoc[TensorFlow] or
  xref:ml/scikit-learn/index.adoc[scikit-learn] sub-section.
. Finish with hardware, distributed training, compression, deployment, interpretability and fairness, and keep the
  xref:ml/glossary.adoc[glossary] and the xref:ml/cheat-sheet.adoc[ML Cheat Sheet] open while you work.
