= PyTorch
:description: Landing page for the PyTorch sub-section -- what PyTorch is, the 2.15 baseline released on 2026-10-28, a learning path, the status of the surrounding libraries (TorchServe and torchtext archived, TorchScript deprecated, torchaudio in maintenance), a map of every PyTorch page and a bibliography of official sources.
:keywords: PyTorch, torch, tensors, autograd, nn.Module, DataLoader, torch.compile, torch.export, FSDP2, DDP, DTensor, torchvision, torchao, ExecuTorch, ONNX, PyTorch 2.15

include::partial$ai-disclaimer.adoc[]

*PyTorch* is a Python deep-learning framework built around tensors, automatic differentiation and a define-by-run style:
the code you write is the computation that runs. This sub-section of the xref:ml/index.adoc[ML (Machine Learning)]
section documents it page by page, from installation and tensors to compiling, exporting and distributing models.
The general pages of the section explain the ideas; these pages show how PyTorch implements them.

== Version baseline

[cols="2,3",options="header"]
|===
|Item |Value checked on 2026-10-30

|PyTorch
|2.15.0, released on 2026-10-28. All pages target this release.

|Python
|Examples were run on Python 3.13 with PyTorch 2.15 on 2026-10-31, on a CPU-only machine (macOS arm64, where Apple MPS is the accelerator). Distributed examples ran as CPU processes under `torchrun` with the Gloo back end. Examples that need a CUDA GPU, FFmpeg or a mobile toolchain say so on their page and were not executed. PyTorch 2.15 no longer ships Python 3.10 wheels.

|torchvision
|0.29.2, the release that matches PyTorch 2.15; see xref:ml/pytorch/torchvision.adoc[torchvision].

|Installation
|pip is the supported route; conda is no longer an official channel. See xref:ml/pytorch/installation.adoc[Installation & Versions].
|===

=== Library status

The PyTorch ecosystem changed a lot between older books and 2.15. This table summarises the status of the pieces most
often met in older material; the details are on xref:ml/pytorch/legacy-and-deprecated.adoc[Legacy APIs & Migration] and
xref:ml/pytorch/ecosystem.adoc[Ecosystem].

[cols="2,2,3",options=header]
|===
|Component |Status |What to use instead

|TorchServe
|Archived
|Serve exported models with a general-purpose server, or ONNX Runtime; see xref:ml/deploying-and-serving-models.adoc[Deploying & Serving ML Models].

|torchtext
|Archived
|Hugging Face tokenizers and datasets, or your own data pipeline.

|TorchScript
|Deprecated
|torch.export, AOTInductor and the ONNX exporter; see xref:ml/pytorch/torch-export.adoc[torch.export].

|torchaudio
|Maintenance
|Audio decoding and encoding moved to TorchCodec; see xref:ml/pytorch/torchaudio-and-torchcodec.adoc[torchaudio (Maintenance) & TorchCodec].

|ExecuTorch
|Part of PyTorch Core
|The route to phones and embedded boards; see xref:ml/pytorch/executorch.adoc[ExecuTorch for Mobile & Edge].

|conda channel
|Deprecated
|Install with pip; see xref:ml/pytorch/installation.adoc[Installation & Versions].
|===
