*TensorFlow* is Google's machine-learning platform: tensors and automatic differentiation in TensorFlow Core, the
Keras high-level API, the tf.data input pipeline, SavedModel for saving and serving, and a set of deployment tools. This
sub-section of the xref:ml/index.adoc[ML (Machine Learning)] section documents it page by page, with most of the weight
on Keras 3, which is how most people use it today.

== Version baseline and the 2026 maintenance focus

In 2026 TensorFlow is in a maintenance-focused phase: releases concentrate on stability, security fixes and
compatibility rather than new high-level features, new research code is more often written in PyTorch or JAX, and
several former companions are archived, renamed or moved (TensorFlow Lite is now LiteRT, TensorFlow Addons is archived
and TF Hub moved to Kaggle Models). The page xref:ml/tensorflow/ecosystem-and-status.adoc[Ecosystem & Project Status]
gives the current status of each component, and xref:ml/tensorflow/migrating-from-tf1.adoc[Migrating from TensorFlow 1]
lists what is outdated in older books.

== Keras inside TensorFlow

Keras 3 is a multi-backend library that can run on TensorFlow, JAX or PyTorch. With the TensorFlow backend it is the
standard high-level API of TensorFlow: models are built with Sequential, Functional or subclassed APIs, trained with
compile and fit, and saved in the .keras format or exported as a SavedModel. The legacy tf.keras namespace and the
separate tf_keras package keep Keras 2 behaviour for old code. The pages
xref:ml/tensorflow/keras-overview.adoc[Keras 3 Overview: keras, tf.keras & tf_keras],
xref:ml/tensorflow/keras-multi-backend.adoc[Keras Multi-Backend] and
xref:ml/tensorflow/migrating-keras-2-to-3.adoc[Migrating from Keras 2 to Keras 3] explain how the pieces relate.
