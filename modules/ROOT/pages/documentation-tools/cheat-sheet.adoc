= Documentation Tools Cheat Sheet
:description: A single-page, printable quick reference for Antora 3.2.1, Docusaurus 3.10.2, Zensical 0.0.72 and DocFX 2.81.0 -- a tool chooser, install, serve and build commands, minimal configuration, layout, link and admonition syntax, diagrams and math, versioning, search, theming entry points, GitHub Pages recipes and the Antora UI bundle -- with a downloadable PDF version.
:keywords: documentation tools cheat sheet, Antora cheat sheet, Docusaurus cheat sheet, Zensical cheat sheet, DocFX cheat sheet, docs as code quick reference, Antora UI bundle, npx gulp bundle, docusaurus.config.ts, zensical.toml, docfx.json, antora-playbook.yml, GitHub Pages, printable reference

include::partial$documentation-tools-disclaimer.adoc[]

A single-page, colour-coded summary of the four documentation tools of this section -- a "which tool" chooser with a
mini feature matrix, one column per tool (install, create, serve and build, minimal configuration, project layout,
link syntax, admonitions, diagrams and math, versioning, search, theming entry point and the GitHub Pages recipe), a
strip for the Antora UI bundle and a strip of what changed recently. It reflects Antora 3.2.1, Docusaurus 3.10.2,
Zensical 0.0.72 (alpha) and DocFX 2.81.0, checked on 2026-10-26, and is available as a
xref:attachment$documentation-tools-cheat-sheet.pdf[downloadable PDF].
