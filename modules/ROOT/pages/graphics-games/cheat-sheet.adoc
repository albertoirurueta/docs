A single-page index of quick links to every general page of this section, grouped like the section itself, for jumping straight to the topic you need instead of paging through the navigation.

image::download-cheat-sheet-pdf.svg["Download the Graphics & Games Cheat Sheet (PDF)",width=320,xref=attachment$graphics-games-cheat-sheet.pdf]

The xref:attachment$graphics-games-cheat-sheet.pdf[downloadable PDF] is a separate, single A4 page meant for printing. It states the version baseline of the section (OpenGL 4.6 and OpenGL ES 3.2, WebGL 2, Metal 4, Vulkan 1.4, Unity 6.3 LTS and Unreal Engine 5.8, checked on 5 November 2026) and covers:

* the six libraries at a glance: version, language and licence;
* the pipeline-stage strip, with the stage names of each API;
* the coordinate-space chain, with clip depth, Y direction and handedness per API;
* the MVP formula and the perspective-matrix template;
* the quaternion and slerp formulas;
* the Blinn-Phong and glTF PBR terms;
* the sRGB and linear conversion;
* texture filtering, mipmaps and compressed formats by platform;
* the shading language, intermediate representation and API matrix;
* the asset formats: glTF, OpenUSD, FBX and OBJ;
* fixed-timestep loop pseudocode;
* the OpenXR object chain, from instance to swapchain;
* translation layers;
* a profiler for each platform;
* a mini decision tree for choosing an API or engine;
* short notes on the GPU and API model, meshes, blending and post-processing, physics, audio and input, and the advanced pipeline stages.
