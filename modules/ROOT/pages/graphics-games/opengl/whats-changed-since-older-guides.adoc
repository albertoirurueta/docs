= What Has Changed Since the Older OpenGL Guides
:description: Row-by-row corrections for the seven OpenGL books and course notes this sub-section was checked against (SuperBible 4th edition, the OpenGL ES 2.0 and 3.0 Programming Guides, the GLSL 1.50 specification, OpenGL ES 2 for Android, the Wrox iOS and Android book and the Spanish GLUT notes), with what each says, what is current, the date of the change and the page to read.
:keywords: outdated OpenGL guides, OpenGL SuperBible, glBegin glEnd, fixed function pipeline, GLUT, GLFW, OpenGL ES 2.0, OpenGL ES 3.2, ANGLE, Eclipse ADT, Android Studio, GLSL 1.50, GLSL 4.60, macOS OpenGL deprecation, corrections

include::partial$ai-disclaimer.adoc[]

Most of what the classic OpenGL books teach about the ideas is still right: the pipeline, the transformation chain, textures,
blending, depth testing and the structure of a shader have not changed. What has changed is the vocabulary of the API calls,
the tools used to build and debug a program, and the platforms that run it. This page lists, book by book, the statements that
are out of date and what to do today, so that you can keep reading the books for their ideas and use this sub-section for
current practice. The facts were checked in November 2026 against desktop OpenGL 4.6 with GLSL 4.60, OpenGL ES 3.2 with GLSL
ES 3.20 and EGL 1.5. For the changes that affect all graphics libraries, not only OpenGL, see
xref:graphics-games/whats-changed-since-older-guides.adoc[What Has Changed Since the Older Guides].

The books are listed in the xref:graphics-games/index.adoc#bibliography[section bibliography] and have the short names used in
the tables: SB4 (_OpenGL SuperBible_, 4th edition, 2007), ES2PG (_OpenGL ES 2.0 Programming Guide_, 2008), ES3PG (_OpenGL ES
3.0 Programming Guide_, 2nd edition, 2014), GLSL150 (_The OpenGL Shading Language, Version 1.50_, 2009), BRO (_OpenGL ES 2 for
Android_, 2013), MAR (_Game and Graphics Programming for iOS and Android with OpenGL ES 2.0_, 2012) and APU (the Spanish course
notes _Apuntes de OpenGL y GLUT_).

== The corrections, book by book

=== SB4: OpenGL SuperBible, 4th edition (2007)

[cols="1,3,3,1,2",options=header]
|===
|Chapters |What the book says |What is current |Date |Read more

|Part I, 1 to 14
|Geometry is drawn in immediate mode with `glBegin` and `glEnd`, transformations use the matrix stack, and lighting and texture coordinate generation are fixed-function state.
|Removed from the core profile in OpenGL 3.1 and 3.2, and not available in macOS core contexts. Use OpenGL 4.6 core (4.1 on macOS) with shaders, vertex array objects and a maths library such as GLM.
|2009
|xref:graphics-games/opengl/hello-triangle.adoc[Hello Triangle], xref:graphics-games/opengl/coordinate-systems-and-transforms.adoc[Coordinate Systems and Transforms], xref:graphics-games/opengl/lighting-blinn-phong.adoc[Lighting with Blinn-Phong]

|Introduction and 15
|OpenGL 2.1 is called the latest version.
|The latest version is 4.6, first released in 2017; the specification text was last revised on 5 May 2022. No 4.7 or 5.0 exists.
|2017 (revision 2022)
|xref:graphics-games/opengl/versions-profiles-and-extensions.adoc[Versions, Profiles and Extensions], xref:graphics-games/opengl/opengl-in-2026.adoc[OpenGL in 2026]

|2
|The examples use GLUT for the window and the event loop, and the tools are those of the 2007 desktop.
|GLUT is no longer maintained. Use GLFW or SDL with a loader generated by glad2, built with CMake.
|Since the 2010s
|xref:graphics-games/opengl/getting-started-desktop.adoc[Getting Started on the Desktop], xref:graphics-games/opengl/contexts-windows-and-loaders.adoc[Contexts, Windows and Loaders]

|12
|Picking uses the selection and feedback render modes.
|Both modes left the core profile with the fixed-function pipeline. Pick with an ID buffer or by casting a ray into the scene.
|2009
|xref:graphics-games/opengl/text-ui-and-input.adoc[Text, UI and Input]

|20
|Apple's window-system glue is AGL and `NSOpenGL` on Mac OS X.
|OpenGL has been deprecated on macOS since 10.14 and is capped at version 4.1 core; Metal is the native API.
|2018
|xref:graphics-games/opengl/opengl-es-on-ios-and-macos.adoc[OpenGL ES on iOS and macOS]

|21
|Mesa supports only OpenGL 1.5.
|Mesa provides OpenGL 4.6 through hardware drivers, the llvmpipe software renderer and Zink on top of Vulkan.
|Since the 2010s
|xref:graphics-games/opengl/embedded-and-linux.adoc[OpenGL on Embedded Devices and Linux]

|22
|The OpenGL ES section predates ES 3.x.
|OpenGL ES 3.2 is the last version; ES 1.x is deprecated.
|2015
|xref:graphics-games/opengl/glsl-es-and-portability.adoc[GLSL ES and Shader Portability], xref:graphics-games/opengl/egl.adoc[EGL]
|===

== What to keep from the books

* The explanations of the pipeline, of coordinate spaces, of texture filtering, of blending and of depth testing remain correct;
  only the function names around them have changed.
* The structure of the book projects (an event loop, an initialisation function, a draw function) still maps to the render loop
  of xref:graphics-games/opengl/getting-started-desktop.adoc[Getting Started on the Desktop].
* The ES guides are still the best long-form description of the ES 3.0 feature set; combine them with the pages on
  xref:graphics-games/opengl/glsl-es-and-portability.adoc[GLSL ES and Shader Portability] and
  xref:graphics-games/opengl/debugging-and-tools.adoc[Debugging and Tools] for current tooling.
* Where a book and the Khronos reference pages disagree, follow the reference pages.
