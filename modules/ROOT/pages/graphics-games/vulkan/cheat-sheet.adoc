A single-page index of quick links to every page in this sub-section, grouped like the sub-section itself, for jumping straight
to the topic you need instead of paging through the navigation.

The xref:attachment$graphics-games-vulkan-cheat-sheet.pdf[downloadable PDF] is a separate, single A4 page meant for printing. It
states the version baseline this sub-section targets (Vulkan 1.4, headers 1.4.367, SDK 1.4.363.0 and Roadmap 2026, all checked on
1 November 2026) and covers:

* the version baseline, with the tools, the Apple layers, Android and Vulkan SC;
* the object hierarchy from the instance to the queue, the command pool and the command buffer;
* the minimal frame loop: acquire, record with a barrier, begin rendering and draw, submit, present, and pacing with a timeline
  semaphore or a fence;
* the image layout transition table with the synchronization2 stage and access pairs, and the barrier recipe;
* memory-type selection and the VMA usage flags;
* the descriptor options: sets, dynamic offsets, push descriptors, push constants, indexing, buffer device address, descriptor
  buffers and the descriptor heap;
* the shader toolchain commands for `glslc`, `dxc -spirv`, `slangc` and `spirv-val`;
* the features promoted in each version from 1.1 to 1.4, and the legacy to modern replacements;
* validation and debugging, the draw, dispatch and trace commands, the platform notes and the key URLs.
