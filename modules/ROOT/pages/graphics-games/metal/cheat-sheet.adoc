A single-page index of quick links to every page in this sub-section, grouped like the sub-section itself, for jumping straight
to the topic you need instead of paging through the navigation.

The xref:attachment$graphics-games-metal-cheat-sheet.pdf[downloadable PDF] is a separate, single A4 page meant for printing. It
states the version baseline this sub-section targets (Metal 4, MSL 4.1 and Xcode 27, all checked on 1 November 2026) and covers:

* the version matrix, with the hardware that runs Metal 4 and the toolchain it needs;
* the Metal 4 frame loop from device and queue through the per-frame allocator, command buffer, encoder and argument table to
  commit and present;
* the map from the `MTL` types to the `MTL4` types, and a quick syntax reference for MSL with address spaces, attributes and
  function constants;
* the storage modes and when to use each, the load and store actions with the tile-based deferred rendering tips, and the compute
  dispatch;
* resource binding with argument buffers, `gpuResourceID`, residency sets and heaps;
* the steps of ray tracing, the mesh-shader pipeline, the MetalFX options and their inputs;
* the debugging and profiling tools, the porting tools and a strip of deprecations.
