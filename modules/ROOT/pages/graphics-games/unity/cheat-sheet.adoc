* an Input System snippet;
* physics: Rigidbody, raycasts, trigger and collision callbacks and the FixedUpdate rule;
* serialisation attributes;
* the render-pipeline decision;
* lighting and texture compression;
* UI Toolkit against uGUI;
* animation: `SetFloat`, `SetTrigger`, Cinemachine and Timeline;
* a map of the patterns;
* a minimal DOTS `ISystem` with Burst;
* Build Profiles, Web and WebGPU, IL2CPP and platform defines;
* a profiling checklist, migration gotchas from 2020 and 2021 tutorials, and Editor shortcuts.
