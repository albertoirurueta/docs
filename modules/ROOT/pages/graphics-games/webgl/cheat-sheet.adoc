A single-page index of quick links to every page in this sub-section, grouped like the sub-section itself, for jumping straight
to the topic you need instead of paging through the navigation.

The xref:attachment$graphics-games-webgl-cheat-sheet.pdf[downloadable PDF] is a separate, single A4 page meant for printing. It
states the version baseline this sub-section targets (WebGL 2 with GLSL ES 3.00, three.js r187 and the WebGPU drafts, all
checked on 1 November 2026) and covers:

* the versions and the browser support baseline, with ANGLE;
* context creation with its attributes, and the minimal draw recipe from shader to program, buffer, vertex array object,
  uniforms and draw call;
* a mini pipeline diagram, the GLSL ES 1.00 against 3.00 keyword map with precision, and the state order for viewport,
  depth, blending and culling;
* textures (formats, immutable storage, mipmaps, filtering, wrapping and cross-origin images) and a framebuffer snippet with
  multiple render targets and multisampling;
* the twelve most useful extensions, a context-loss handler skeleton and a ten-item performance checklist;
* the three.js skeleton with an import map, the core classes, the colour-management defaults and glTF loading with Draco and
  KTX2;
* the old to new three.js API table, the `WebGPURenderer` and TSL quick start, and the WebGPU against WebGL concept map with
  the 2026 support grid.
