= Graphics & Games
:description: Landing page for the Graphics & Games section -- what graphics APIs and game engines are, the six libraries covered (OpenGL, WebGL, Metal, Vulkan, Unity and Unreal Engine), the version baseline, a learning path through the general pages, the shared Bookshelf scene and assets, a coverage map and the bibliography.
:keywords: graphics, game development, graphics API, game engine, OpenGL, OpenGL ES, GLSL, WebGL, three.js, WebGPU, Metal, Vulkan, SPIR-V, Unity, Unreal Engine, rendering pipeline, shaders, PBR, glTF, OpenXR, scene graph, learning path, bibliography

include::partial$ai-disclaimer.adoc[]

Every image on a screen, from a spinning cube in a browser to a game with millions of triangles per frame, is drawn by a
GPU that is driven through software. This section explains how that software is layered and how to use it. It starts with
the ideas that every graphics and game library shares: the GPU, the rendering pipeline, the mathematics of transforms and
rotations, meshes, textures, lighting, colour, shading languages, scene graphs, the game loop and the basics of
augmented reality. Later parts of the section go deep into six libraries: OpenGL, WebGL, Metal, Vulkan, Unity and Unreal
Engine.

The xref:graphics-games/overview.adoc[overview] defines graphics APIs, rendering frameworks and game engines, gives the targeted versions, the learning path and reading order through the general pages, the shared Bookshelf scene and assets, the cheat sheets, and a concept-to-page map and coverage map of every page of the section.

== Sections

* xref:graphics-games/overview.adoc[Overview] -- graphics APIs and game engines, targeted versions, learning path, reading order, cheat sheets, the shared Bookshelf scene and a concept-to-page map of the general pages.
* xref:graphics-games/comparison.adoc[Comparison] -- the six libraries side by side with dated metrics, scores and recommendations by purpose.
* xref:graphics-games/opengl/index.adoc[OpenGL] -- desktop OpenGL 4.6, OpenGL ES 3.2, GLSL and EGL, from a first triangle to a small game, and how to port to Vulkan, Metal and WebGPU.
* xref:graphics-games/webgl/index.adoc[WebGL] -- 3D graphics in the browser, the three.js framework on top of it, and WebGPU as the successor API.
* xref:graphics-games/metal/index.adoc[Metal] -- Apple's graphics and compute API (Metal 4, MSL 4.1) for iOS, iPadOS, macOS, tvOS and visionOS.
* xref:graphics-games/vulkan/index.adoc[Vulkan] -- the explicit, cross-platform Khronos API (Vulkan 1.4) for desktop, mobile and embedded GPUs.
* xref:graphics-games/unity/index.adoc[Unity] -- a general-purpose game engine with C# scripting and the Universal Render Pipeline (Unity 6.3 LTS).
* xref:graphics-games/unreal-engine/index.adoc[Unreal Engine] -- a game engine with {cpp} and Blueprint scripting, Nanite and Lumen (Unreal Engine 5.8).
