Welcome to the Redis reference. https://redis.io/[Redis] is an *in-memory data structure server*: it keeps its
primary copy of the keyspace in RAM for sub-millisecond latency, persists it to disk through RDB snapshots and/or
an AOF write log, and layers a growing set of multi-model capabilities -- JSON documents, a full-text and vector
Query Engine, streams, probabilistic and time-series structures -- on top of the classic string/list/set/hash/
sorted-set primitives. Examples throughout this section target Redis Open Source 8.10 (specifically 8.10.2) as
the baseline, with client examples against Jedis 8 and Lettuce 7.7; the Spring Boot pages layer in Spring Boot
4.1, Spring Data Redis 4.1, Spring AI 2.0, Redis OM Spring 1.0, Spring Session 4.1 and Testcontainers 2.0, and
Redis Insight 3.8 is used for interactive browsing throughout. All of these were re-checked as current, stable
lines at the time of writing: Redis Open Source's own release notes confirm 8.10.2 as its latest patch, and the
Spring ecosystem's June 2026 train shipped Spring Boot 4.1 alongside matching 4.1.x releases of Spring Data
Redis, Spring Session and (per its own changelog) Testcontainers 2.0.5, with Spring AI reaching its 2.0 general
availability the same week -- the one point worth flagging is Redis OM Spring, which has since moved on to an
actively maintained `2.0.x` line upstream; this section keeps its examples on the `1.0.x` baseline the rest of
these pages were written and verified against, so annotation names and package layout stay consistent from page
to page, and readers adopting Redis OM Spring fresh should check its current reference documentation for any
`2.0.x` API differences.

== Redis release timeline

Redis's licence has moved twice in the versions this section covers: the 7.4 line left the permissive
BSD-3-Clause license behind for the source-available RSALv2/SSPLv1 pair, and the 8.0 line added the
OSI-approved AGPLv3 as a third licensing option -- marketed as "Redis Open Source" -- with the Linux Foundation
taking on governance of the project alongside Redis Ltd. The Linux Foundation separately forked the last
BSD-licensed release (7.2.4) as https://valkey.io/[Valkey], covered on this section's
xref:database/redis/redis-software-cloud-kubernetes-and-valkey.adoc[Redis Software, Cloud, Kubernetes & Valkey]
page.

[cols="1,2,3,2", options="header"]
|===
| Release | Date | Headline features | Licence / packaging

| 7.2
| Aug 2023
| Sharded pub/sub, `OBJECT FREQ` improvements, and the last release before Redis Stack modules (JSON, Search,
  TimeSeries, Bloom) began merging into core.
| BSD-3-Clause -- the last fully permissive release; later forked by the Linux Foundation as Valkey 7.2.4.

| 7.4
| Mar 2024
| Hash field TTLs (`HEXPIRE`/`HPERSIST` and friends), client-side caching improvements.
| Relicensed away from BSD to a dual RSALv2/SSPLv1 source-available license -- no longer OSI-approved open
  source; this is the release that triggered the Valkey fork.

| 8.0
| May 2025
| Redis Stack's JSON, Query Engine (Search), Time Series and probabilistic (Bloom/Cuckoo/HyperLogLog/Top-K)
  capabilities merged into Redis proper for the first time, plus a claimed I/O-threading performance jump.
| Added AGPLv3 as a third licensing option ("Redis Open Source"), restoring OSI-approved open-source status
  under joint Redis Ltd./Linux Foundation stewardship.

| 8.2
| 2025
| Database-scoped management roles and data-path command auditing groundwork on the Enterprise/Software side,
  plus continued Query Engine and vector-search refinement on the Open Source side.
| AGPLv3/RSALv2/SSPLv1 tri-license continues.

| 8.4
| Jul 2026
| New `DELEX`/`DIGEST` commands, atomic compare-and-set/compare-and-delete `SET` extensions, `MSETEX`, and an
  `XREADGROUP ... CLAIM` min-idle-time enhancement for consuming idle pending and new stream entries together.
| Tri-license continues.

| 8.6
| 2026
| Disk-based search indexing (preview), an Active-Active database upgrade API, and a JSON string-reuse
  mechanism for Active-Active deployments.
| Tri-license continues.

| 8.8
| 2026
| Incremental Query Engine, vector-search and operational hardening on the 8.x line ahead of 8.10.
| Tri-license continues.

| 8.10
| Sep 2026
| The current baseline for this section (patch 8.10.2); primarily a security and stability release -- see
  xref:database/redis/getting-started.adoc[Getting Started] for the full round trip against it.
| Tri-license continues.
|===

== How to read this section

Start with xref:database/redis/getting-started.adoc[Getting Started] and

xref:database/redis/query-engine-search-and-aggregations.adoc[]), then

xref:database/redis/probabilistic-and-time-series.adoc[probabilistic & time-series structures]. Next,
xref:database/redis/pipelining-transactions-and-scripting.adoc[pipelining, transactions & scripting] covers
programmability, followed by the operations cluster --
xref:database/redis/persistence-and-primary-database.adoc[persistence],
