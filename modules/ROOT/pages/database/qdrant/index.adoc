= Qdrant Reference
:description: Landing page for the Qdrant reference -- the open-source, self-hostable vector similarity search engine written in Rust: collections and points, HNSW vector indexing and quantization, payload filtering, hybrid and sparse search, CRUD and batch operations, distributed clustering and storage, security and administration, RAG integration patterns, and a downloadable cheat sheet.
:keywords: qdrant, vector database, vector similarity search, hnsw, rag, embeddings, collections, points, payload, filtering, hybrid search, sparse vectors, quantization, clustering, qdrant cheat sheet

Welcome to the Qdrant reference. https://qdrant.tech/[Qdrant] is an *open-source, self-hostable vector similarity
search engine* written in Rust: it stores high-dimensional vectors alongside a JSON payload in collections, indexes
them with an HNSW approximate-nearest-neighbor graph, and exposes both a REST and a gRPC API (with official Python
and Java clients, among others) for filtered similarity search, hybrid dense/sparse retrieval, and the
retrieval step of Retrieval-Augmented Generation pipelines.

If you are new to Qdrant, read xref:database/qdrant/getting-started.adoc[Getting Started] first, then
xref:database/qdrant/collections-and-points.adoc[Collections & Points] and
xref:database/qdrant/vector-indexing-and-hnsw.adoc[Vector Indexing & HNSW], followed by
xref:database/qdrant/filtering-and-payload-indexing.adoc[Filtering & Payload Indexing],
xref:database/qdrant/hybrid-and-sparse-search.adoc[Hybrid & Sparse Search],
xref:database/qdrant/crud-and-batch-operations.adoc[CRUD & Batch Operations],
xref:database/qdrant/clustering-and-storage.adoc[Clustering & Storage],
xref:database/qdrant/security-and-administration.adoc[Security & Administration], and finally
xref:database/qdrant/rag-integration-patterns.adoc[RAG Integration Patterns]. Everything after the first two
pages builds on those foundations.

== What's covered

* xref:database/qdrant/getting-started.adoc[Getting Started] -- Qdrant as a vector similarity search engine
  written in Rust, running it via Docker or Qdrant Cloud, and a first create-collection/upsert/search round-trip
  over REST and the Python client.
* xref:database/qdrant/collections-and-points.adoc[Collections & Points] -- collections (fixed vector size and
  distance metric) and points (id + vector + payload), plus named vectors and multivectors.
* xref:database/qdrant/vector-indexing-and-hnsw.adoc[Vector Indexing & HNSW] -- how Qdrant builds and tunes its
  HNSW index per collection or named vector, exact search, and scalar/product/binary quantization.
* xref:database/qdrant/filtering-and-payload-indexing.adoc[Filtering & Payload Indexing] -- payload indexes
  (keyword, integer, geo, text), the must/should/must_not boolean filter model, and filtered HNSW search.
* xref:database/qdrant/hybrid-and-sparse-search.adoc[Hybrid & Sparse Search] -- named sparse-vector configs,
  Reciprocal Rank Fusion via the Query API's prefetch mechanism, and prefetch + cross-encoder re-ranking.
* xref:database/qdrant/crud-and-batch-operations.adoc[CRUD & Batch Operations] -- upserting, retrieving, and
  deleting points individually or in batches, and paging through a collection with the scroll API.
* xref:database/qdrant/clustering-and-storage.adoc[Clustering & Storage] -- sharding and replication, Raft-based
  cluster consensus, on-disk vs. in-memory storage trade-offs, and snapshots.
* xref:database/qdrant/security-and-administration.adoc[Security & Administration] -- static API keys, TLS,
  Qdrant Cloud role-based access control, and the `/metrics` and `/telemetry` endpoints.
* xref:database/qdrant/rag-integration-patterns.adoc[RAG Integration Patterns] -- chunking and embedding a
  corpus, storing chunks as points with metadata payloads, and wiring retrieval up via LangChain or LlamaIndex.
* xref:database/qdrant/cheat-sheet.adoc[Cheat Sheet (PDF)] -- a single-page, printable summary of everything in
  this section, with a downloadable PDF.
