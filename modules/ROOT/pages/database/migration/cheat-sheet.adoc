A single A4 page to print or keep beside the migration runbook, with the baseline date 2026-11-09 and Debezium
3.7.1.Final (connectors on Java 17 or later, Debezium Server and the Operator on Java 21 or later), Kafka 4.x in KRaft
mode and the Bookshop pipeline from Oracle AI Database 26ai Free (`FREEPDB1`, schema `BOOKSHOP`) to PostgreSQL 18. Every
value on the sheet is taken from the pages of this section, which explain it in full. It covers:

image::download-cheat-sheet-pdf.svg["Download the cheat sheet (PDF)",width=320,xref=attachment$database-migration-cheat-sheet.pdf]

* the five phases of a CDC migration, with the system that owns the writes, the direction of the change stream and the
  rollback path in each, from xref:database/migration/migration-patterns-with-cdc.adoc[Migration Patterns with CDC];
* the record key, the value envelope (`before`, `after`, `source`, `op`, the timestamps and `transaction`) and the
  `c`, `u`, `d`, `r`, `t` and `m` operation codes, from
  xref:database/migration/change-event-structure.adoc[Anatomy of a Change Event];
* the database prerequisites in one entry each for Oracle, PostgreSQL, MySQL and MariaDB, SQL Server and MongoDB, from
  xref:database/migration/oracle-connector.adoc[Oracle Connector],
  xref:database/migration/postgresql-connector.adoc[PostgreSQL Connector],
  xref:database/migration/mysql-and-mariadb-connectors.adoc[MySQL & MariaDB Connectors],
  xref:database/migration/sql-server-connector.adoc[SQL Server Connector] and
  xref:database/migration/mongodb-connector.adoc[MongoDB Connector];
* a minimal `bookshop-oracle-source` configuration with the JSON converter and schemas enabled,
  `decimal.handling.mode=string`, `provide.transaction.metadata=true` and the signal table
  `FREEPDB1.BOOKSHOP.DEBEZIUM_SIGNAL`, from xref:database/migration/oracle-connector.adoc[Oracle Connector] and
  xref:database/migration/best-practices.adoc[Best Practices];
* every `snapshot.mode` value with its deprecated aliases, from
  xref:database/migration/initial-snapshots.adoc[Initial Snapshots], and the `execute-snapshot` signal SQL with the
  `INSERT` and `DELETE` grant on the signal table that the official grant list leaves out, from
  xref:database/migration/signaling-and-notifications.adoc[Signaling & Notifications];
* the essentials of the `bookshop-pg-mirror-sink` JDBC sink (`insert.mode=upsert`, `primary.key.mode=record_key`,
  `delete.enabled=true`, `schema.evolution=none`, a connection URL that ends in `?stringtype=unspecified`, and the
  dead-letter queue switch), from xref:database/migration/jdbc-sink-connector.adoc[JDBC Sink Connector];
* `ExtractNewRecordState` with every `delete.tombstone.handling.mode` value, from
  xref:database/migration/event-flattening.adoc[Event Flattening], and the `EventRouter`, `Filter` and
  `ToLogicalTopicRouter` transformations with predicates, from
  xref:database/migration/single-message-transformations.adoc[Debezium Transformations] and
  xref:database/migration/outbox-event-router.adoc[Outbox Event Router];
* the Kafka Connect REST commands, including `+PUT /connectors/{name}/stop+` and the `GET`, `PATCH` and `DELETE`
  `/offsets` endpoints that need the connector in the `STOPPED` state, and exactly-once source support, from
  xref:database/migration/offsets-restarts-and-exactly-once.adoc[Offsets, Restarts & Exactly-Once];
* the metrics to watch during a migration (snapshot progress, `MilliSecondsBehindSource`, queue capacity, long Oracle
  transactions, errors, safe restart), from
  xref:database/migration/monitoring-logging-and-tracing.adoc[Monitoring, Logging & Tracing];
* the write cut-over checklist (freeze, drain, final reconciliation, reconfigure forward capture, write guard, start
  reverse replication, route writes, smoke test) and loop prevention, from
  xref:database/migration/cut-over-and-reverse-replication.adoc[Cut-over & Reverse Replication] and
  xref:database/migration/best-practices.adoc[Best Practices];
* the properties renamed or removed up to Debezium 3.7 (`topic.prefix`, `+schema.history.internal.*+`, `no_data`,
  `recovery`, `delete.tombstone.handling.mode`, `mongodb.connection.string`, `ToLogicalTopicRouter`, the `hybrid`
  mining strategy, and the removal of continuous mining and the Cassandra 3 connector).
