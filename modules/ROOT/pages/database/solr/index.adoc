Welcome to the Apache Solr reference. https://solr.apache.org/[Apache Solr] is a *standalone search server
built on Apache Lucene*: it stores documents indexed into cores or, in a distributed deployment, *collections*
sharded and replicated across a cluster, exposes JSON, XML and CSV over an HTTP API, analyzes text into an
inverted index for relevance-ranked full-text search, and layers request handlers, query parsers, faceting,
highlighting and streaming/SQL capabilities on top. This section documents the current Solr line as a
database-developer reference -- the search-server model, schema and analysis, indexing and querying, relevance,
the SolrCloud distributed model and operations, security and deployment, and the SolrJ client -- written and
verified against https://solr.apache.org/guide/solr/latest/[the Apache Solr Reference Guide].

If you are new to Solr, read xref:database/solr/getting-started.adoc[Getting Started] first, then
xref:database/solr/core-concepts-and-architecture.adoc[Core Concepts & Architecture] and
xref:database/solr/schema-and-fields.adoc[Schema & Fields], followed by
xref:database/solr/query-basics-and-parameters.adoc[Query Basics & Parameters]. Everything after that builds on
those foundations. For the closest comparison, see the sibling
xref:database/elasticsearch/index.adoc[Elasticsearch Reference] and, for the full write-up,
xref:database/solr/solr-vs-elasticsearch.adoc[Solr vs. Elasticsearch].

For the relational and document-database baselines this section contrasts with, see the sibling
xref:database/sql/index.adoc[SQL Reference], xref:database/mongodb/index.adoc[MongoDB Reference] and
xref:database/couchbase/index.adoc[Couchbase Reference], which the Solr pages cross-link rather than restate.
For where a dedicated search engine fits alongside a primary store, see
xref:database/choosing-the-right-database.adoc[Choosing the Right Database].

* xref:database/solr/schema-and-fields.adoc[Schema & Fields] -- `schema.xml` vs. the managed schema and

* xref:database/solr/field-types.adoc[Field Types] -- `StrField`/`TextField`, the current `point`-based

  stemming, ICU folding, phonetic matching, and multilingual strategies.
