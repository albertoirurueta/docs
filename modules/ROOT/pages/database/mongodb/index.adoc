Welcome to the MongoDB reference. https://www.mongodb.com/[MongoDB] is a *general-purpose, document-oriented
database*: it stores records as JSON-like BSON documents rather than as rows in fixed tables, gives each
collection a flexible schema, exposes a rich Query API and an aggregation pipeline instead of SQL, and scales
horizontally by sharding a collection across many servers. This section documents the current MongoDB server
line as a database-developer reference -- the data model, the CRUD and aggregation surface, indexing, schema
design, transactions and change streams, replication and sharding, storage, security and operations, and the
drivers -- written and verified against https://www.mongodb.com/docs/manual/[the MongoDB Server Manual].

If you are new to MongoDB, read xref:database/mongodb/getting-started.adoc[Getting Started] first, then
xref:database/mongodb/documents-and-bson.adoc[Documents, BSON & Data Types] and
xref:database/mongodb/databases-and-collections.adoc[Databases, Collections & Schema Control], followed by the
three CRUD pages -- xref:database/mongodb/crud-insert-and-write-concern.adoc[Inserting Data, Bulk Writes & Write
Concern], xref:database/mongodb/crud-query.adoc[Reading Data with the Query API], and
xref:database/mongodb/crud-update-and-delete.adoc[Updating & Deleting Documents]. Everything after that builds on
those foundations.

For the relational baseline this section contrasts with, see the sibling xref:database/sql/index.adoc[SQL
Reference], which the MongoDB pages cross-link rather than restate.

* xref:database/mongodb/crud-query.adoc[Reading Data with the Query API] -- `find` / `findOne`, the query filter
