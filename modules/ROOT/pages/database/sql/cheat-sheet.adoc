== Worked example

The statements below combine a transaction with a savepoint, a grouped `SELECT` using `WHERE` and `HAVING`, and a
window function. They were run on SQLite, which starts a transaction with `BEGIN` and takes the date as a plain
ISO-8601 string; other products use `START TRANSACTION` and `+DATE '2015-01-01'+`.

[source,sql]
----
CREATE TABLE employees (id INTEGER PRIMARY KEY, name TEXT, department_id INTEGER,
                        salary INTEGER, hire_date TEXT);
INSERT INTO employees VALUES
  (1, 'Ana', 10, 5000, '2016-03-01'), (2, 'Ben', 10, 4200, '2018-07-15'),
  (3, 'Cy',  20, 6100, '2015-01-10'), (4, 'Di',  20, 5900, '2020-09-01'),
  (5, 'Eli', 30, 3000, '2012-05-05');

BEGIN;
UPDATE employees SET salary = salary + 100 WHERE department_id = 10;
SAVEPOINT raise_dept_20;
UPDATE employees SET salary = salary * 2 WHERE department_id = 20;
ROLLBACK TO raise_dept_20;   -- undoes only the department 20 change
COMMIT;                      -- keeps the department 10 raise

SELECT department_id, COUNT(*) AS employee_count, AVG(salary) AS average_salary
FROM employees
WHERE hire_date >= '2015-01-01'
GROUP BY department_id
HAVING COUNT(*) > 1
ORDER BY average_salary DESC;

SELECT name, department_id, salary,
       RANK() OVER (PARTITION BY department_id ORDER BY salary DESC) AS dept_rank
FROM employees
ORDER BY department_id, dept_rank;
----

The first query prints one row per department with more than one qualifying employee; the second keeps every row
and adds the rank inside its department:

[source,text]
----

-------------  --------------  --------------

10             2               4700.0

Ana   10             5100    1
Ben   10             4300    2
Cy    20             6100    1
Di    20             5900    2
Eli   30             3000    1
----
