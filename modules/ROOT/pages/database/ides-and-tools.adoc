= Database IDEs & Tools
:description: The graphical clients and tools commonly used to browse and query databases, grouped by engine family.
:keywords: database, IDE, client, tools, DBeaver, DataGrip, Sequel Ace, TablePlus, pgAdmin, MySQL Workbench, MongoDB Compass, Redis Insight, Neo4j, Kibana, Qdrant

include::partial$database-ides-and-tools-disclaimer.adoc[]

This page lists the graphical clients and tools commonly used to explore schemas, run queries and inspect data
across the database engines covered on this site. Pick a cross-engine client when you work with several engines, and
the engine's own tool when you need its full feature set.

== Cross-engine clients

* https://dbeaver.io/[*DBeaver*] -- a universal database client with support for many relational and non-relational
  engines.
* https://www.jetbrains.com/datagrip/[*DataGrip*] -- the JetBrains database IDE with smart SQL completion and
  refactoring.
* https://sequel-ace.com/[*Sequel Ace*] -- a macOS client for MySQL and MariaDB databases.
* https://tableplus.com/[*TablePlus*] -- a native client for several relational and key-value engines.

== SQL

* https://www.pgadmin.org/[*pgAdmin*] -- the administration and development platform for PostgreSQL.
* https://www.mysql.com/products/workbench/[*MySQL Workbench*] -- the visual tool for designing, querying and
  administering MySQL.

Azure Data Studio has been retired; see
https://learn.microsoft.com/en-us/azure-data-studio/whats-happening-azure-data-studio[the official announcement]
for details and recommended alternatives.

== Document

* https://www.mongodb.com/products/tools/compass[*MongoDB Compass*] -- the graphical client for exploring and
  querying MongoDB. See xref:database/mongodb/drivers-and-tooling.adoc[MongoDB Drivers and Tooling] for details.

== Key-value

* https://redis.io/insight/[*Redis Insight*] -- a visual tool for browsing keys and running commands against Redis.

== Graph

* https://neo4j.com/docs/browser-manual/current/[*Neo4j Browser*] -- the query console for running Cypher and
  visualizing results.
* https://neo4j.com/docs/bloom-user-guide/current/[*Neo4j Bloom*] -- a visual exploration tool for Neo4j graphs.

== Search

* https://www.elastic.co/docs/explore-analyze/query-filter/tools/console[*Kibana Dev Tools*] -- a console for
  sending requests to Elasticsearch from Kibana.

== Vector

* https://qdrant.tech/documentation/web-ui/[*Qdrant dashboard*] -- the built-in web interface for inspecting
  collections and running queries in Qdrant.
