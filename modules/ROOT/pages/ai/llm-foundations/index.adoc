= LLM Foundations & Prompting
:description: Landing page for the LLM Foundations & Prompting reference -- how large language models actually work (tokenization, transformer architecture, training, sampling, context, reasoning, multimodality, limitations), prompt and context engineering, and choosing among today's models.

Examples across this sub-section target Python 3.12 with the current `anthropic` and `openai` Python SDKs
(`anthropic` 1.8.x), Hugging Face `transformers` 5.17 (with `tokenizers` 0.23.2) and `tiktoken` 0.14.0, TRL 1.14,
DSPy 3.4.0, Ollama 0.34 serving `llama3.1:8b` (and the thinking-capable `qwen3:8b`), and Java 21 with Spring Boot
4.1 / Spring AI 2.0.1, calling the hosted models `claude-sonnet-5`, `claude-haiku-4-5`, `claude-opus-5-5` and
`claude-fable-5-1`, alongside OpenAI's current flagship line (`gpt-6-luna`, `gpt-6-sol`, `gpt-6-astra`), with
`gpt-6-sol` as the OpenAI model the reasoning and general examples call. This baseline was checked and
re-verified as current against each vendor's own documentation on 2026-09-28; every page states any narrower
version it targets in its own intro, and this landing page's baseline is the one to trust if an individual page
and this page ever appear to disagree after a later update.

Most pages reuse *DocsAssistant*, the same running example the
xref:database/vector-rag/index.adoc[Vector Databases & RAG] section uses: an agent that answers questions about
this site's own AsciiDoc pages, using one embedding model and one chat model across every stack so the examples
stay interoperable (see that page's scenario table for the exact models, corpus and indexes). This sub-section
picks the story up one level below retrieval: what the chat model itself is, how it turns text into tokens and
those tokens into an answer, how to prompt it well, and how to choose which model to call in the first place.

== Reading order

The 19 pages below build up in three stages, plus a cheat sheet. *How LLMs work* explains the model itself, from
what an LLM is down to why it sometimes gets things wrong. *Prompt and context engineering* covers how to talk to
that model reliably, and how to manage what occupies its context window as an application grows. *Choosing
models* is about picking among today's actual models and estimating what a call will cost. Read them in order if
you are new to LLMs; jump straight to a page if you already know the basics and need one topic.

*How LLMs work*

* xref:ai/llm-foundations/what-is-an-llm.adoc[What Is an LLM?] -- language model to LLM to foundation model, the
  three-layer AI stack, and what self-supervised pre-training on next-token prediction actually produces.
* xref:ai/llm-foundations/tokens-and-tokenization.adoc[Tokens & Tokenization] -- BPE and byte-level tokenizers,
  chat templates, counting tokens, and the token-to-cost-and-latency formula.
* xref:ai/llm-foundations/transformer-architecture.adoc[Transformer Architecture] -- the decoder-only forward
  pass, self-attention, RoPE, MQA/GQA, MoE and Mamba-style alternatives.
* xref:ai/llm-foundations/training-pipeline.adoc[How LLMs Are Trained] -- pre-training, scaling laws, SFT,
  preference tuning (RLHF, DPO) and RL for reasoning (RLVR/GRPO).
* xref:ai/llm-foundations/sampling-and-decoding.adoc[Sampling & Decoding] -- temperature, top-k/top-p, stop
  sequences, logprobs, and which parameters reasoning models ignore.
* xref:ai/llm-foundations/context-windows-and-memory.adoc[Context Windows & Memory] -- the context window as
  working memory, the KV cache, long-context degradation, and prompt caching economics.
* xref:ai/llm-foundations/reasoning-models.adoc[Reasoning Models] -- extended thinking, effort and budget
  parameters, and when reasoning is worth its extra latency and cost.
* xref:ai/llm-foundations/multimodal-models.adoc[Multimodal Models] -- ViT patches, CLIP, and native image/PDF
  and audio input and output.
* xref:ai/llm-foundations/hallucinations-and-limitations.adoc[Hallucinations & Limitations] -- why models
  hallucinate, related failure modes, and the mitigations that actually help.
