was written on 2026-10-01 against LangChain 1.4.3 with FastAPI 0.142.2, Spring AI 2.0.1 on Spring Boot 4.1.1, the AI SDK

printing. It states the version baseline and covers:

* the channel-agnostic core, the `ask(conversationId, userId, text)` contract and the responsibilities of an adapter;
* the channel matrix: streaming support and the gate (approval, window or policy) of each channel;
* SSE, WebSocket and NDJSON compared, with the FastAPI, Spring WebFlux and Node/Express streaming snippets;
* the AI SDK UI Message Stream parts and the AG-UI event groups;
* the ready-made UIs and the rules for an embeddable widget;
* the WebRTC data channel signalling steps;
* the XMPP XEPs table;
* the Teams routes decision table;
* the WhatsApp 24-hour window, template and AI-policy rules;
* the Apple Messages for Business flow;
* the Slack, Telegram and Google Chat streaming models, and RCS Business Messaging;
* the operations checklist.

The one idiom the whole sheet builds on -- the channel adapter acknowledges quickly and hands the core a stable
identity and conversation id -- as the core contract (explained on
xref:ai/conversational-channels/channel-agnostic-architecture.adoc[Channel-Agnostic Architecture]):

.The channel-agnostic core contract
[source,text]
----
ask(conversationId, userId, text) -> stream of { token | citation | done }
----
