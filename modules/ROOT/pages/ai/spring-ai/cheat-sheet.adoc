A minimal DocsAssistant chat endpoint, the idiom most of the sheet builds on (it is explained on
xref:ai/spring-ai/chatmodel-and-chatclient.adoc[ChatModel & ChatClient]):

.The core ChatClient idiom
[source,java]
----
package com.example.docsassistant;

import org.springframework.ai.chat.client.ChatClient;
import org.springframework.stereotype.Service;

@Service
public class PortableDocsAssistant {

    private final ChatClient chatClient;

    public PortableDocsAssistant(ChatClient.Builder builder) {
        this.chatClient = builder
                .defaultSystem("You answer questions about the Irurueta documentation.")
                .build();
    }

    public String ask(String question) {
        return chatClient.prompt()
                .user(question)
                .call()
                .content();
    }
}
----

Source: https://docs.spring.io/spring-ai/reference/api/chatclient.html[Spring AI -- ChatClient API].
