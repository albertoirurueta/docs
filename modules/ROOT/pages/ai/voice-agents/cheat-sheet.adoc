A single-page index of quick back-links to every page in this sub-section, grouped the same way as the navigation. It was
written on 2026-10-01 against LangChain 1.4.3 with FastAPI 0.142.2, Spring AI 2.0.1 on Spring Boot 4.1.x, Pipecat 1.12.0,
LiveKit Agents 1.8.3, OpenAI `gpt-live-1` and the Realtime API (`gpt-realtime-2.1`), `gemini-3.8-live`, the ElevenLabs
Python SDK 2.70.0, Twilio ConversationRelay and Media Streams, and Asterisk 23.5, 22.11 and 20.21; the full list is the
xref:ai/voice-agents/index.adoc#_version_baseline[version baseline] on the landing page.

The xref:attachment$ai-voice-agents-cheat-sheet.pdf[downloadable PDF] is a separate, single A4 page meant for printing. It
states the version baseline and covers:

* the cascaded, speech-to-speech and hybrid architectures, and the latency budget formula;
* the turn-taking checklist: VAD, endpointing, barge-in and echo;
* speech-to-text and text-to-speech providers and local models, with their licences;
* audio formats and resampling for telephone, browser and model paths;
* the realtime API transports of OpenAI, Gemini Live and Azure Voice Live;
* the ElevenLabs custom LLM setup;
* Pipecat and LiveKit Agents skeletons;
* the Twilio ConversationRelay and Media Streams message tables;
* the Asterisk ARI External Media, AudioSocket and `chan_websocket` transports;
* the Spring AI audio interfaces (`TranscriptionModel`, `TextToSpeechModel`);
* the production checklist.

The one formula the whole sheet builds on -- the time from the end of the caller's sentence to the first audible word of a
cascaded pipeline (explained on xref:ai/voice-agents/voice-architectures.adoc[Voice Architectures]):

[stem]
++++
T_{resp} \approx T_{net} + T_{eot} + T_{TTFT}^{LLM} + T_{TTFB}^{TTS}
++++

https://docs.pipecat.ai/[Pipecat documentation] for the stage metrics, and
https://docs.spring.io/spring-ai/reference/api/audio/speech.html[Spring AI -- Text-To-Speech (TTS) API].
