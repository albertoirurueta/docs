The one idiom the whole sheet builds on -- the ACL filter comes from the verified identity and is ANDed with anything
the question adds -- in its LangChain form (explained on
xref:ai/rag-systems/access-control-and-privacy.adoc[Access Control & Privacy]):

.The ACL-filtered retriever
[source,python]
----
def retriever_for(vector_store, readable_acls: list[str], extra: dict | None = None):
    acl = {"acl": {"$in": readable_acls}}                      # from the verified token, never from the prompt
    flt = {"$and": [acl, extra]} if extra else acl
    return vector_store.as_retriever(search_kwargs={"k": 6, "filter": flt})
----

Source: https://docs.langchain.com/oss/python/integrations/vectorstores/pgvector[LangChain -- PGVector] (metadata
filtering).
