A single-page index of quick back-links to every page in this sub-section, grouped the same way as the navigation. It was
written on 2026-10-01 against vLLM 0.30.0, SGLang 0.5.21, KServe 0.21.0, LiteLLM 1.103.2, MLflow 3.16.1, Langfuse 4.49.0,
LangSmith SDK 0.14.2 with `openevals` 0.2.0 and `agentevals` 0.0.9, Arize Phoenix 20.18.0, RAGAS 0.4.3, DeepEval 4.2.7,
OpenTelemetry Python 1.45.0 with the GenAI semantic conventions at Development stability, Spring AI 2.0.1, LangChain 1.4.3,
Prometheus 3.15.0 and Grafana 13.2.3; the full list is the xref:ai/llmops/index.adoc#_version_baseline[version baseline] on
the landing page.

The xref:attachment$ai-llmops-cheat-sheet.pdf[downloadable PDF] is a separate, single A4 page meant for printing. It states
the version baseline and covers:

* the lifecycle loop and the three maturity levels;
* the metric catalogue with formulas (pass@k, BLEU, ROUGE, BERTScore, embedding similarity, perplexity, nDCG@k, MRR,
  Cohen's kappa, Elo, RAG metrics);
* the judge rubric, the judge bias checklist and comparative evaluation (Elo, Bradley-Terry);
* eval-set rules and sample-size arithmetic;
* the CI gate: Wilson lower bound, paired sign test and a gate snippet;
* online-evaluation sampling and feedback;
* serving metrics (TTFT, TPOT, goodput, MBU) and autoscaling signals;
* release patterns: shadow, canary, A/B, blue-green and the rollback ladder;
* the OpenTelemetry `gen_ai.*` attributes and metrics;
* the observability platform comparison;
* alert rules and drift measures;
* the cost formula and its levers;
* the governance checklist.

xref:ai/llmops/cost-management.adoc[Cost Management]:

[stem]
++++
C_{req} = n_{in}\,p_{in} + n_{c}\,p_{c} + n_{out}\,p_{out}
++++
