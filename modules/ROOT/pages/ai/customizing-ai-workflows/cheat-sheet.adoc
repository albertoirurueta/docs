1.0.88 (`@github/copilot`) and Claude Code 2.1.283, all re-verified as current on 2026-09-28 -- and covers:

* the surfaces decision table (always-on rules → instructions, a reusable procedure → a skill or prompt file, an

  capability → MCP);
* the file locations for both tools, including custom commands and their `$ARGUMENTS` / `$0` placeholders;
* the `SKILL.md` and agent frontmatter reference;
* the hook events and exit codes;
* the permission rule syntax and permission modes;
* the plugin layout;
* the 12 optimisation techniques;
* the skill-testing checklist;
* the security checklist.
