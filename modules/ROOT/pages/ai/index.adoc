= AI
:description: Landing page for the AI reference -- a practical, vendor-neutral guide to using and building with large language models, from prompting and AI-assisted coding through agents, MCP, RAG and local models, to channels, voice, operations and security.
:keywords: AI, LLM, large language models, agents, MCP, RAG, LangChain, Spring AI, LLMOps, AI security, prompt engineering, AI-assisted development

include::partial$ai-disclaimer.adoc[]

This section is a practical, vendor-neutral guide to *using* and *building with* large language models: from
prompting and AI-assisted coding, through agents, the Model Context Protocol and command-line agent tooling, to
retrieval-augmented generation, local and on-device models, conversational and voice channels, and finally the
operations and security concerns of running all of this in production. It is written for developers of Python,
Java/Spring, Node, mobile and desktop applications who want working examples against current, official
documentation rather than a marketing overview of any one vendor's product.

Each sub-section states and dates its own version baseline in its own landing page -- the model IDs, SDK
versions and framework releases it was written and verified against -- because these move fast and a single
site-wide baseline would go stale unevenly across 15 sub-sections. Check the sub-section's own index before
relying on a version number quoted deeper in one of its pages.

== Sub-sections

* xref:ai/llm-foundations/index.adoc[LLM Foundations & Prompting] -- how LLMs work under the hood, and how to
  prompt and manage context for them reliably.
* AI-Assisted Development -- using AI coding assistants and Claude Code day to day: autocomplete, chat, agentic
  coding and code review. (planned)
* Customizing AI Workflows -- shaping an AI assistant's behavior with custom instructions, skills, hooks and
  automation. (planned)
* AI Agents -- agent loops, planning, tool use and multi-agent orchestration. (planned)
* Model Context Protocol (MCP) -- exposing tools and resources to LLMs over a standard protocol. (planned)
* Building CLIs for AI Agents -- designing command-line tools that agents can drive reliably. (planned)
* Running LLMs Locally -- serving open-weight models on your own hardware. (planned)
* Hugging Face & On-Device Models -- fine-tuning, quantization and running models on-device. (planned)
* LangChain -- building LLM applications end to end with the LangChain / LangGraph ecosystem. (planned)
* Spring AI -- building LLM applications end to end with Spring AI on the JVM. (planned)
* RAG Systems in Production -- productionizing retrieval-augmented generation beyond the fundamentals. (planned)
* Conversational Channels -- deploying assistants to chat, email and messaging channels. (planned)
* Voice Agents -- speech-to-text, text-to-speech and real-time voice agent pipelines. (planned)
* LLMOps & Evaluation -- evaluating, monitoring and operating LLM applications in production. (planned)
* AI Security & Responsible AI -- prompt-injection defenses, guardrails and responsible-AI practice. (planned)
