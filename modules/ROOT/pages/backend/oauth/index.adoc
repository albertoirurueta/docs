Welcome to the OAuth reference. OAuth is a *delegated authorization* framework: it lets a user grant an
application limited access to their data on another service, without ever handing that application their
password. It is *not* an authentication protocol on its own -- that is what OpenID Connect adds on top of it,
and confusing the two is the most common and most expensive mistake in this area.

This section is *protocol-first*. It documents what the specifications actually say -- OAuth 1.0a
(https://datatracker.ietf.org/doc/html/rfc5849[RFC 5849]), OAuth 2.0
(https://datatracker.ietf.org/doc/html/rfc6749[RFC 6749]) as amended by the Security Best Current Practice
(https://datatracker.ietf.org/doc/html/rfc9700[RFC 9700]), the in-progress *OAuth 2.1* consolidation, OpenID
Connect Core 1.0, and the surrounding extension RFCs -- with real HTTP requests and responses rather than
library calls. Only the last three pages map all of that onto Spring Boot; for the equivalent mapping onto
Quarkus (`quarkus-oidc` and `quarkus-smallrye-jwt`), see
xref:backend/quarkus/security-jwt-oidc-and-keycloak.adoc[JWT, OIDC and Keycloak] in the
xref:backend/quarkus/index.adoc[Quarkus Reference].

If you are new to OAuth, read xref:backend/oauth/getting-started.adoc[Getting Started with OAuth] first, then
xref:backend/oauth/flows-overview.adoc[Choosing an OAuth Flow],
xref:backend/oauth/authorization-code-and-pkce.adoc[Authorization Code and PKCE] and
xref:backend/oauth/access-and-refresh-tokens.adoc[Access and Refresh Tokens]. Everything after that builds on
those foundations.

For the Spring Boot services this protocol secures, see the sibling
xref:backend/springboot/index.adoc[SpringBoot Reference] -- in particular
xref:backend/springboot/spring-security.adoc[Spring Security] and
xref:backend/springboot/spring-security-authorization-server.adoc[Authorization Server & Social Login], which
this section links to rather than duplicating. For securing a GraphQL surface, see
xref:backend/graphql/authorization.adoc[GraphQL Authorization].

== What's covered

=== Foundations

* xref:backend/oauth/getting-started.adoc[Getting Started with OAuth] -- the problem OAuth solves, the four
  roles, confidential vs. public clients, the endpoints, and a complete authorization-code round-trip.
