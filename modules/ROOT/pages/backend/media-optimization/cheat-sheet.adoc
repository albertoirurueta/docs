A single-page index of quick back-links to every page in the backend Media Optimization sub-section, grouped the same way as
the xref:backend/media-optimization/index.adoc[sub-section index], so you can jump straight to the detail behind a line of
the printed sheet.

The xref:attachment$media-optimization-backend-cheat-sheet.pdf[downloadable PDF] is a separate, single A4 page meant for
printing. It states the baseline date (2026-10-07) and covers:

* the format comparison table (lossy or lossless, alpha, animation, status and licence), the default AVIF, WebP and JPEG
  set, and quality starting points;
* variant widths, storage key naming, cache headers, metadata stripping and the libvips, cwebp and avifenc commands;
* the BlurHash string layout and the key equations for encoding, quantisation and decoding, with the `punch` caveat;
* the FFmpeg command set for H.264, HEVC, AV1, VP9, capped CRF, covers, thumbnails, sprite sheets and HLS;
* the H.264 and HEVC bitrate ladder from the Apple HLS Authoring Specification, with keyframe and segment rules;
* streaming and private delivery notes (CMAF, signed cookies, DRM);
* a library picker for Java, Python, Node.js, .NET and Rust with maintenance status and licence flags; and
* the upload pipeline and security checklist.
