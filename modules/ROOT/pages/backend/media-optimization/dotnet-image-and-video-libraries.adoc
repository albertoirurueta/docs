== Image libraries

[cols="1,1,3", options="header"]
|===
| Library | Licence | Notes

| https://docs.sixlabors.com/[ImageSharp] (SixLabors.ImageSharp)
| Six Labors Split License
| Fully managed code, no native dependencies. JPEG, PNG, GIF, BMP, TIFF and WebP. No AVIF or HEIC. Under the Six Labors Split License a commercial licence is needed above US$1M revenue. Read the license text for the exact terms before you ship it in a product.

| https://github.com/mono/SkiaSharp[SkiaSharp]
| MIT
| Bindings to Google's Skia, with native assets per platform. JPEG, PNG and WebP encode, plus drawing. Fast and widely used.

| https://github.com/kleisauke/net-vips[NetVips]
| MIT
| Bindings to libvips, with the native library in a companion package. The best throughput and the widest format support, including AVIF and HEIC when libvips is built with libheif.

If the product is closed source and earns more than the ImageSharp threshold, the practical choices are paying for the
licence, or using SkiaSharp or NetVips, which are MIT.

=== ImageSharp

[source,bash]
----
dotnet add package SixLabors.ImageSharp
----

[source,csharp]
----
using SixLabors.ImageSharp;
using SixLabors.ImageSharp.Formats.Jpeg;
using SixLabors.ImageSharp.Formats.Webp;
using SixLabors.ImageSharp.Processing;

public static async Task MakeVariantsAsync(string input, string outDir)
{
    foreach (var width in new[] { 320, 640, 1280 })
    {
        using var image = await Image.LoadAsync(input);
        image.Mutate(x => x
            .AutoOrient()                                      // apply EXIF orientation
            .Resize(new ResizeOptions { Size = new Size(width, 0), Mode = ResizeMode.Max }));
        image.Metadata.ExifProfile = null;                     // drop EXIF, including GPS
        await image.SaveAsync($"{outDir}/w{width}.webp", new WebpEncoder { Quality = 78 });
        await image.SaveAsync($"{outDir}/w{width}.jpg", new JpegEncoder { Quality = 80 });
    }
}
----

Reference: https://docs.sixlabors.com/articles/imagesharp/index.html[ImageSharp documentation].

=== SkiaSharp

[source,csharp]
----
using SkiaSharp;

public static void MakeWebp(string input, string output, int width)
{
    using var original = SKBitmap.Decode(input);
    var height = (int)Math.Round(original.Height * (double)width / original.Width);
    using var resized = original.Resize(new SKImageInfo(width, height), new SKSamplingOptions(SKFilterMode.Linear, SKMipmapMode.Linear));
    using var image = SKImage.FromBitmap(resized);
    using var data = image.Encode(SKEncodedImageFormat.Webp, 78);
    using var stream = File.OpenWrite(output);
    data.SaveTo(stream);
}
----

SkiaSharp does not apply EXIF orientation automatically for bitmaps. Use `SKCodec.EncodedOrigin` to find the rotation and
draw the bitmap on a rotated canvas. Reference: https://learn.microsoft.com/en-us/dotnet/api/skiasharp[SkiaSharp API documentation].

=== NetVips

[source,bash]
----
dotnet add package NetVips
dotnet add package NetVips.Native
----

[source,csharp]
----
using NetVips;

// Thumbnail() shrinks on load, so it is much cheaper than load-then-resize.
using var image = Image.Thumbnail("original.jpg", 640, size: Enums.Size.Down);
image.Webpsave("w640.webp", q: 78, strip: true);
image.Heifsave("w640.avif", q: 60, compression: Enums.ForeignHeifCompression.Av1, strip: true);
----

Reference: https://kleisauke.github.io/net-vips/[NetVips documentation] and the
https://www.libvips.org/API/current/[libvips API].

== BlurHash in .NET

[cols="1,3", options="header"]
|===
| Package | Notes

| https://github.com/MarkusPalcer/blurhash.net[Blurhash.ImageSharp, Blurhash.SkiaSharp and Blurhash.Core (blurhash.net)]
| Encoder and decoder with one package per imaging library. Pick the one that matches your image library.

| https://github.com/Bond-009/BlurHashSharp[BlurHashSharp.SkiaSharp and BlurHashSharp.ImageSharp]
| Encoder only. `BlurHashEncoder.Encode(xComponent, yComponent, stream)` reads an encoded image from a stream or a path, and
  there is an overload that resizes the image before encoding.
|===

[source,csharp]
----
using BlurHashSharp.SkiaSharp;

await using var stream = File.OpenRead("original.jpg");
string hash = BlurHashEncoder.Encode(4, 3, stream);       // 4 x 3 components, 28 characters
----

Resize to about 64 pixels before encoding when your library lets you, see
xref:backend/media-optimization/blurhash-algorithm.adoc[the BlurHash page].

=== FFMpegCore: probe, transcode and snapshot

[source,bash]
----
dotnet add package FFMpegCore
----

[source,csharp]
----
using FFMpegCore;
using FFMpegCore.Enums;
using System.Drawing;

GlobalFFOptions.Configure(new FFOptions { BinaryFolder = "/usr/bin" });

var info = await FFProbe.AnalyseAsync("input.mov");            // reject unreasonable input first
var duration = info.Duration;

await FFMpegArguments
    .FromFileInput("input.mov")
    .OutputToFile("720p.mp4", overwrite: true, options => options
        .WithVideoCodec(VideoCodec.LibX264)
        .WithConstantRateFactor(22)
        .WithAudioCodec(AudioCodec.Aac)
        .WithVideoFilters(filter => filter.Scale(-2, 720))
        .WithFastStart())
    .ProcessAsynchronously();

FFMpeg.Snapshot("input.mov", "cover.jpg", new Size(720, -1), TimeSpan.FromSeconds(duration.TotalSeconds * 0.1));
----

This follows the examples in the https://github.com/rosenbjerg/FFMpegCore#readme[FFMpegCore README]. System.Drawing
`Size` is used by the snapshot helper, and `FFMpegCore.Extensions.SkiaSharp` offers an in-memory variant.

=== Xabe.FFmpeg

[source,csharp]
----
using Xabe.FFmpeg;

FFmpeg.SetExecutablesPath("/usr/bin");
IMediaInfo info = await FFmpeg.GetMediaInfo("input.mov");
IVideoStream video = info.VideoStreams.First()!.SetCodec(VideoCodec.h264).SetSize(VideoSize.Hd720);
IConversion conversion = FFmpeg.Conversions.New().AddStream(video).AddStream(info.AudioStreams.First()!)
    .SetOutput("720p.mp4");
await conversion.Start();
----

Reference: https://xabe.net/[Xabe.FFmpeg]. For fine control of the encoder options, give FFmpeg the argument list directly
(`AddParameter`).

== ASP.NET Core upload endpoint with BackgroundService and Channel

For small workloads in one process, a bounded `Channel<T>` read by a `BackgroundService` is a simple in-memory queue.
It is lost when the process restarts, so it is suited to images that can be regenerated, not to the only copy of a job.

[source,csharp]
----
using System.Threading.Channels;

public record ProcessMedia(Guid Id, string Path);

public sealed class MediaQueue
{
    private readonly Channel<ProcessMedia> _channel = Channel.CreateBounded<ProcessMedia>(100);
    public ValueTask EnqueueAsync(ProcessMedia job) => _channel.Writer.WriteAsync(job);
    public IAsyncEnumerable<ProcessMedia> ReadAllAsync(CancellationToken ct) => _channel.Reader.ReadAllAsync(ct);
}

public sealed class MediaWorker(MediaQueue queue, IServiceScopeFactory scopes, ILogger<MediaWorker> logger) : BackgroundService
{
    protected override async Task ExecuteAsync(CancellationToken stoppingToken)
    {
        await foreach (var job in queue.ReadAllAsync(stoppingToken))
        {
            try
            {
                using var scope = scopes.CreateScope();
                var processor = scope.ServiceProvider.GetRequiredService<IMediaProcessor>();
                await processor.ProcessAsync(job, stoppingToken);       // idempotent: skip if already READY
            }
            catch (Exception ex) when (ex is not OperationCanceledException)
            {
                logger.LogError(ex, "Media job {Id} failed", job.Id);
            }
        }
    }
}

// Program.cs
var builder = WebApplication.CreateBuilder(args);
builder.Services.AddSingleton<MediaQueue>();
builder.Services.AddHostedService<MediaWorker>();
builder.Services.AddScoped<IMediaProcessor, MediaProcessor>();
builder.WebHost.ConfigureKestrel(o => o.Limits.MaxRequestBodySize = 10 * 1024 * 1024);

var app = builder.Build();

app.MapPost("/images", async (IFormFile file, MediaQueue queue) =>
{
    if (file.Length is 0 or > 10 * 1024 * 1024)
        return Results.BadRequest("Invalid size");
    var id = Guid.NewGuid();
    var path = Path.Combine(Path.GetTempPath(), id.ToString());
    await using (var stream = File.Create(path))
        await file.CopyToAsync(stream);
    await queue.EnqueueAsync(new ProcessMedia(id, path));
    return Results.Accepted($"/images/{id}", new { id, status = "queued" });
}).DisableAntiforgery();

app.Run();
----

Reference: https://learn.microsoft.com/en-us/aspnet/core/fundamentals/host/hosted-services[Background tasks with hosted services in ASP.NET Core]
and https://learn.microsoft.com/en-us/dotnet/core/extensions/channels[System.Threading.Channels]. `IFormFile` binding in minimal
APIs requires `DisableAntiforgery()` for a public API in .NET 8 and later. Keep the CSRF decision explicit for your own
authentication model.

=== A queue-backed alternative

When jobs must survive restarts, scale across instances or be retried, replace the channel with a broker and keep the
same processor:

* *Azure Service Bus or Storage Queues* with the Azure SDK, see xref:cloud/azure/media-optimization.adoc[the Azure page].
* *Amazon SQS* with the AWS SDK for .NET, see xref:cloud/aws/media-optimization/video-on-demand-pipeline.adoc[the AWS pipeline].
* *RabbitMQ or Kafka* with the official clients, see xref:backend/messaging/index.adoc[messaging].
* A library such as Hangfire or Quartz.NET for persisted background jobs, see xref:backend/scheduling/index.adoc[scheduling].

Publish a job from the endpoint, run a worker as a separate deployment, and give it the idempotency, retry and
dead-letter settings described in xref:backend/media-optimization/upload-pipelines-queues-and-jobs.adoc[upload pipelines].
