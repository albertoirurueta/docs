Welcome to the Quarkus reference. Quarkus is a **Kubernetes-native Java framework** built for GraalVM and the
JVM alike: it moves as much work as possible -- classpath scanning, bean discovery, proxy generation,
configuration metadata -- from application startup into an *augmentation* build step, so the resulting
application starts in milliseconds, uses a fraction of the memory of a traditionally-bootstrapped Java
application, and compiles cleanly to a native executable. That trade -- accepting a *closed-world* assumption
about what the application will do at runtime, in exchange for build-time speed and density -- is the thread
that runs through every page in this section.

If you are new to Quarkus, read xref:backend/quarkus/getting-started.adoc[Getting Started with Quarkus] first,
then xref:backend/quarkus/architecture-and-build-time.adoc[Build-Time Augmentation and the Closed World] to
understand *why* it behaves the way it does, then
xref:backend/quarkus/cdi-and-the-programming-model.adoc[CDI and the Programming Model (ArC)] and
xref:backend/quarkus/configuration.adoc[Configuration] for the two mechanisms every other page assumes. From
there, read the rest of this section as needed for the technology you are integrating.

Quarkus sits alongside, not in place of, several existing references in this repository. For the Java
framework most directly comparable to it, see the sibling xref:backend/springboot/index.adoc[SpringBoot
Reference] -- xref:backend/quarkus/quarkus-vs-spring-boot.adoc[Quarkus vs. Spring Boot] maps the two
concept-for-concept and xref:backend/quarkus/spring-compatibility.adoc[Spring API Compatibility Extensions]
covers migrating existing Spring code, while xref:backend/quarkus/java-or-kotlin.adoc[Java or Kotlin for
Quarkus?] mirrors the SpringBoot section's own language comparison. Quarkus does not re-document the
technologies it integrates: for JPA/Hibernate fundamentals see the
xref:backend/hibernate/index.adoc[Hibernate Reference] (Quarkus's own pages cover only what
xref:backend/quarkus/hibernate-orm-and-jpa.adoc[Hibernate ORM in Quarkus] and
xref:backend/quarkus/panache.adoc[Panache] add on top); for GraphQL schema design, pagination, security and
federation see the xref:backend/graphql/index.adoc[GraphQL Reference] (Quarkus adds only the SmallRye server and
client bindings on xref:backend/quarkus/graphql.adoc[GraphQL with SmallRye]); and for the OAuth/OIDC protocols
themselves -- flows, tokens, JWTs, the Security BCP -- see the xref:backend/oauth/index.adoc[OAuth Reference]
(Quarkus adds only the `quarkus-oidc`/`quarkus-smallrye-jwt` bindings on
xref:backend/quarkus/security-jwt-oidc-and-keycloak.adoc[JWT, OIDC and Keycloak]).
