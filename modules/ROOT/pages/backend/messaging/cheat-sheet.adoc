RabbitMQ name), the delivery-semantics table with the configuration that produces each guarantee, the Kafka
architecture one-liners (topic/partition/offset/ISR/KRaft) and the key producer/consumer/share-consumer
properties, the RabbitMQ AMQP model (exchange types and routing behaviour, queue properties) and the queue-type
table, ack/confirm one-liners for both brokers, the Kafka vs. RabbitMQ decision mini-table, the essential CLI
commands, the Docker one-liners for running both brokers locally, and the Spring class mapping and
`spring.kafka.*` / `spring.rabbitmq.*` / `spring.cloud.stream.*` property essentials -- handy for quick
memorization or as a printable desk reference.
