= PDF Generation
:description: Generating PDF documents from a Java backend: iText and JasperReports, PDF file structure and standards, tables, fonts, images, PDF/A and PDF/UA, PAdES digital signatures, editable AcroForms, barcodes and QR codes, reports from databases, alternatives and migration.
:keywords: PDF generation, iText, JasperReports, PDFBox, PDF/A, PDF/UA, PAdES, digital signature, AcroForm, barcode, QR code, VeriFactu, Spring Boot, bibliography, cheat sheet

include::partial$pdf-generation-disclaimer.adoc[]

Almost every business backend ends up producing PDF files: invoices, statements, contracts, tickets and monthly reports.
This section describes how a Java service does that, from the structure of a PDF file to programmatic layout with
iText, template-driven reports with JasperReports, signing with PAdES, fillable forms and barcodes. Versions and dates
are re-verified when each page is written and are stated as of the date checked.

== Running scenario: Bookshelf Billing

Every page uses the same example, the back office of the Bookshelf store used by the Python sections. It is a Spring Boot 4
service on Java 21 that produces:

* customer invoices with iText, each carrying a VeriFactu-style QR code and a PAdES signature;
* a monthly sales report grouped by category, with charts and a crosstab, built with JasperReports from PostgreSQL;
* an editable customer onboarding form (AcroForm) that is returned signed.

No page uses real certificates, keys, tax identifiers or customer data. Signing examples use a test certificate authority
generated on the page, timestamps come from a public test time-stamping authority, and tax-authority examples target
pre-production endpoints only.

=== Books

Three books were consulted for the concepts they cover and the order in which they present them. They are cited and
linked to their official pages. No text, code listing, figure or dataset from them is reproduced, and they were not used as the source of any code
example. All three predate the versions above, and the pages say in prose where a book is outdated and show the
current approach (the findings are collected in xref:backend/pdf-generation/whats-changed-and-migration.adoc[What's
Changed and Migration]).

  978-1-932394-79-5. Targets iText 1.4 and the `com.lowagie` packages, on JDK 1.4 and PDF 1.6.
  https://www.manning.com/books/itext-in-action[Publisher page]. A second edition exists (Manning, 2010, for iText 5),
  https://www.manning.com/books/itext-in-action-second-edition[publisher page]; it was not consulted.
