= PDF Generation Cheat Sheet
:description: A single-page, grouped index of quick back-links to every backend PDF Generation page, with a downloadable one-page printable PDF.
:keywords: PDF generation cheat sheet, iText, JasperReports, PAdES levels, PDF/A, PDF/UA, AcroForm, QR code error correction, licences, migration, printable reference

include::partial$pdf-generation-disclaimer.adoc[]

A single-page index of quick back-links to every page in the backend PDF Generation section, grouped the same way as
the xref:backend/pdf-generation/index.adoc[section index], so you can jump straight to the detail behind a line of the
printed sheet.

The xref:attachment$pdf-generation-cheat-sheet.pdf[downloadable PDF] is a separate, single A4 page meant for printing.
It states the baseline date (2026-10-09) and covers:

* the iText module map and document lifecycle;
* layout elements, tables, page events and fonts;
* the JasperReports lifecycle, bands, expressions, data sources and PDF exporter configuration;
* PDF/A and PDF/UA;
* the PAdES baseline levels with one-liners for iText, PDFBox and EU DSS;
* AcroForm field types, the iText form builders and the JasperReports field properties;
* the barcode classes and the QR error-correction levels;
* the licences of iText, its add-ons, JasperReports and the other libraries; and
* a migration table from the APIs used by the older books to the current ones.
