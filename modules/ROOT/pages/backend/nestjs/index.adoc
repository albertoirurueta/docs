== What NestJS is

NestJS is a server-side framework for Node.js, written in TypeScript, that brings an Angular-inspired architecture to
the back end: applications are organized into modules, behaviour is attached with decorators, and collaborating
objects are wired together by a dependency injection container. Nest itself is deliberately platform-agnostic. It
runs on top of an HTTP platform adapter (Express by default, Fastify as the alternative), and the same building
blocks serve REST controllers, GraphQL resolvers, WebSocket gateways and microservice message handlers.

It is not Next.js, which is a React framework for rendering pages; the two are often combined, and
xref:backend/nestjs/nestjs-vs-nextjs.adoc[NestJS vs Next.js] explains the difference and how they fit together.

This section is for developers who:

* know TypeScript or JavaScript (see the xref:programming-languages/typescript/index.adoc[TypeScript Reference]) and
  want to build structured, testable server applications
* come from Spring Boot, ASP.NET Core, Angular or FastAPI and want the same ideas (modules, DI, filters, guards) in
  the Node.js ecosystem
* need the current idioms (the ESM project template, Vitest, Standard Schema validation, the post-restructure official
  documentation) rather than the patterns in older tutorials and books

== The Bookshelf scenario

Every example builds one small, original service, _Bookshelf_, the same domain used by the FastAPI and Kubernetes
sections so that stacks can be compared:

* `books`, `authors` and `reviews` with full CRUD over a versioned REST API and a code-first GraphQL API
* users with sign-in and authorization policies
* cover-image uploads to file storage, a live "new review" feed over Server-Sent Events and a WebSocket chat per book
* a `notifications` microservice reached over RabbitMQ (with Kafka, NATS and gRPC variants shown)
* a BullMQ queue for review-moderation emails
* PostgreSQL through TypeORM (with Prisma and Drizzle variants), MongoDB for an activity feed and Redis for caching

The final layout is a Nest monorepo with `apps/bookshelf-api`, `apps/notifications`, `libs/common` and `libs/database`,
shown on xref:backend/nestjs/project-structure-and-workspaces.adoc[Project Structure & Workspaces].
