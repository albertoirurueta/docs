lifecycle, pipes and validation, exception filters, dynamic modules and lifecycle hooks, configuration, data access
and caching, HTTP features, authentication and authorization, OpenAPI, GraphQL, WebSockets, microservices, CQRS and
reliability packages, testing, production, and a strip of what changed since older tutorials -- handy for quick
