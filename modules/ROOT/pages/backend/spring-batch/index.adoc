Welcome to the Spring Batch reference. https://spring.io/projects/spring-batch[Spring Batch] is a *lightweight
framework for finite, bounded bulk processing*: it reads a large but known quantity of input, does something to
each item, and writes the result -- transactionally, restartably, and with a full audit trail in a
`JobRepository`. Its domain language is a `Job` made of `Step`s, and its workhorse is the chunk-oriented step
built from an `ItemReader`, an `ItemProcessor` and an `ItemWriter`. It is deliberately *not* a scheduler: when a
job runs is left to cron, Quartz, an enterprise scheduler or a Kubernetes `CronJob`.

If you are new to Spring Batch, read
xref:backend/spring-batch/getting-started.adoc[What Spring Batch is & running a first job] first, then
xref:backend/spring-batch/jobs-instances-and-parameters.adoc[Jobs, instances & parameters] -- which explains why
parameters decide identity and how restart works -- followed by
xref:backend/spring-batch/chunk-oriented-processing.adoc[Chunk-oriented processing]. Everything after that
builds on those three.

For the Spring Boot integration specifically -- the `spring-boot-starter-batch` dependency, the auto-configured
job repository and datasource, the `spring.batch.*` properties and the `JobLauncherApplicationRunner` -- see the
shorter sibling page xref:backend/springboot/spring-batch.adoc[Spring Batch (SpringBoot Reference)], which these
pages cross-link rather than restate. For the persistence and SQL baselines the reader and writer pages build
on, see xref:backend/springboot/spring-data-jpa.adoc[Spring Data JPA],
xref:backend/hibernate/index.adoc[Hibernate Reference] and xref:database/sql/index.adoc[SQL Reference].
