Welcome to the Spring Batch reference. https://spring.io/projects/spring-batch[Spring Batch] is a *lightweight
framework for finite, bounded bulk processing*: it reads a large but known quantity of input, does something to
each item, and writes the result -- transactionally, restartably, and with a full audit trail in a
`JobRepository`. Its domain language is a `Job` made of ``Step``s, and its workhorse is the chunk-oriented step
built from an `ItemReader`, an `ItemProcessor` and an `ItemWriter`. It is deliberately *not* a scheduler: when a
job runs is left to cron, Quartz, an enterprise scheduler or a Kubernetes `CronJob`.

[NOTE]
====
Some surfaces (Spring Cloud Task and Spring Cloud Data Flow orchestration, the deployer-based partition handler, and JSR-352) are linked, not documented in depth.
====

xref:backend/spring-batch/getting-started.adoc[What Spring Batch is & running a first job] first, then
xref:backend/spring-batch/jobs-instances-and-parameters.adoc[Jobs, instances & parameters] -- which explains why
parameters decide identity and how restart works -- followed by

For the Spring Boot integration specifically -- the `spring-boot-starter-batch` dependency, the auto-configured

*Deliberately out of scope.* This section is about Spring Batch itself: its domain language, the job repository, steps, readers, processors and writers, fault tolerance, scaling, observability and testing, on the 6.0 line. The following topics appear in most books on the subject but live elsewhere on this site, or are intentionally not covered:

* *JSR-352 (`jakarta.batch`), the XML job specification language and the Spring Batch XML namespace* -- linked, not documented in depth; the history is in xref:backend/spring-batch/getting-started.adoc[What Spring Batch is & running a first job], and everything here is the Java API of 6.0.

* *When a job runs: cron, Quartz and enterprise schedulers* -- Spring Batch is not a scheduler. * *JUnit 4 style batch tests* -- support was removed in 6.0 and is intentionally not covered; xref:backend/spring-batch/testing.adoc[Testing batch jobs] is JUnit Jupiter only.

== Version baseline

This section documents **the current Spring Batch line** -- **6.0.x**, on **Spring Framework 7** and **Spring Boot 4.1.x**, with a **Java 17+** baseline -- as published at https://docs.spring.io/spring-batch/reference/[the Spring Batch reference documentation].
No specific patch version is pinned.
