This guide builds an OAuth 2.1 and OpenID Connect authorization server with Spring, one feature at a time, by reading
the code of a working example: https://github.com/albertoirurueta/irurueta-auth-server[irurueta-auth-server]. Every page
explains one slice of the system, shows the real code through tagged regions of the example (nothing is pasted that does
not run), and ends with the tests that prove it and the limits of what the example does.

The example is a *learning project*: it is built and tested in CI, but it is *never deployed*, so every address, port
and credential in these pages is a local development value.

== What you build

Four applications share one PostgreSQL server. The *authorization server* signs people in, with any of eight methods,
and issues tokens. The *BFF* is the only client of a browser application and keeps the tokens out of the browser. The
*resource server* validates bearer tokens, and the *service client* calls it with no user at all. The
xref:backend/springboot/authorization-server-from-scratch/architecture.adoc[Architecture] page walks through the figure.

image::springboot-authz-architecture.svg["Components and trust boundaries of the example: the browser, the BFF, the authorization server, the resource server, the service client, PostgreSQL and the external identity providers, mail and SMS services",width=900]

== Features

=== Sign-in methods

Each method can be offered on the login page as a primary factor, as a second factor, or both. The `amr` column is the
https://www.rfc-editor.org/rfc/rfc8176[RFC 8176] value that the tokens report.

|`pwd`
|xref:backend/springboot/authorization-server-from-scratch/password-storage.adoc[Storing Passwords Securely]

|TOTP and recovery codes
|Second factor
|A custom `AuthenticationFilter` and `AuthenticationProvider` that grant a factor authority
|`otp`

== Prerequisites

* *Java*: a JDK between 21 and 25 and, for the integration tests and the local services, *Docker*. Maven itself is
optional because the repository ships the Maven wrapper.
* *Spring*: Spring Boot 4.1, with Spring Security 7.1 and Spring Authorization Server. If you have never used them, start
with xref:backend/springboot/spring-security.adoc[Spring Security] and
xref:backend/springboot/spring-security-authorization-server.adoc[Authorization Server & Social Login].
* *OAuth*: you should know what an authorization code, a token and a scope are. The
xref:backend/oauth/getting-started.adoc[OAuth Reference: Getting Started] page covers that in a few minutes.

== Clone and run the example

[source,bash]
----
git clone https://github.com/albertoirurueta/irurueta-auth-server.git
cd irurueta-auth-server
./mvnw -pl auth-server/boot -am spring-boot:run -Dspring-boot.run.profiles=dev
----

Start the `resource-server` and the `bff` the same way, then open http://localhost:8080. The
xref:backend/springboot/authorization-server-from-scratch/project-setup.adoc[Project Setup] page gives the full run order,
the profiles, the seeded demo user and clients, and how to run the tests. The example's own documentation, with its
installation guide, is in the
xref:irurueta-auth-server::installation.adoc[irurueta-auth-server documentation].
