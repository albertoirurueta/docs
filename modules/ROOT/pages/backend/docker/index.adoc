Welcome to the Docker reference. *Docker* packages an application with everything it needs to run into an
*image* -- a stack of read-only filesystem layers plus a configuration, standardised by the Open Container
Initiative -- and runs that image as an isolated process called a *container* on any host with a container engine.
The same image is built once, tested, pushed to a registry and pulled unchanged into every environment, from a
developer laptop through CI to production, which is why Docker has become the default unit of packaging and
deployment for backend services.

The examples in this section are written and verified against Docker Engine 29.8.x, Docker Compose v5.5.x,
Buildx 0.37.x with BuildKit 0.33.x and the `docker/dockerfile:1` frontend, and Docker Desktop 4.91 or later; the
Java pages add Testcontainers for Java 2.0.5, Spring Boot 4.1.x and Java 25, and the CI pages use the current
majors of the official GitHub Actions (`actions/checkout@v7`, `actions/setup-java@v6`, `docker/*` actions such as
`docker/build-push-action@v7`).
