= Grafana Guide: Tables
:description: Step-by-step guide to Grafana 13.3: turn an instant Prometheus query of the Bookshelf request rate by route into a table panel, then organize and rename its columns, draw the values as gauges, override one column, add a column filter and a footer, and sort the result.
:keywords: Grafana, table, table panel, instant query, transformations, Organize fields by name, cell type, gauge cell, field override, column filter, table footer, Prometheus, Bookshelf, step by step, guide

Checked on 2026-11-11 against Grafana 13.3.x.

== What you build

You add a table panel called *Requests per second by route* to the dashboard *Bookshelf (guides)*. It lists the four routes of
the Bookshelf service with the request rate of each one, drawn as a gauge bar, with friendly column names, a column filter, a
footer that adds up the rates, and a header you can click to sort the rows.

image::monitoring-alerting-grafana-guide-g8-15-result.svg["Finished table panel Requests per second by route in view mode: the columns Route and Requests per second with a gauge bar for each of four routes, sorted from the highest rate, and a footer row with the sum of the four rates",width=900]

== Before you start

* Start the Grafana profile of the xref:backend/monitoring-alerting/hands-on-lab.adoc[hands-on lab] and wait about a minute:
+
[source,bash]
----
cd lab
docker compose --profile grafana up -d
----
* Open http://localhost:3000, sign in as `admin` with the password `admin`, and click *Skip* when Grafana 13.3 asks you to
  update the default password.
* Do the guide xref:backend/monitoring-alerting/grafana/guide-first-dashboard.adoc[Create a dashboard and the first panel]
  first: it creates the folder *Guides* and the dashboard *Bookshelf (guides)* that this guide extends. The previous guide,
  xref:backend/monitoring-alerting/grafana/guide-stat-gauge-and-bar-gauge.adoc[Stat, gauge and bar gauge], is helpful but not required.
* The data source *Prometheus* is provisioned by the lab and is the default data source. The load generator sends traffic to
  the Bookshelf service in its default mode, which gives the query something to list.
* The guide was checked on Grafana Enterprise 13.3.0 (the free image, no licence key). Editing dashboards needs the *Editor* or *Admin* role of the organization; `admin` has it.
* The figures are drawings of the Grafana 13.3 user interface, not screenshots, so small details can differ from your screen.
  A highlighted box with a number marks the control of the step with the same number.

== Steps

The panel editor used here is the one shown in the map of the
xref:backend/monitoring-alerting/grafana/guide-first-dashboard.adoc[first dashboard guide]; come back to that map when a control is not where a figure shows it.
You work in one panel editor from the query to the last option, and save once at the end.

=== Open the dashboard and add a panel

. In the left navigation, click *Dashboards*, open the folder *Guides* and click *Bookshelf (guides)*.
. Click *Edit* at the top right.
+
image::monitoring-alerting-grafana-guide-g8-01-open-dashboard.svg["Dashboard Bookshelf (guides) in view mode with the navigation docked: callout 1 marks the Dashboards item of the navigation and callout 2 marks the Edit button of the toolbar",width=900]
. In the toolbar, click *Add*.
. In the *Add* pane of the right sidebar, click the *Panel* tile.
+
image::monitoring-alerting-grafana-guide-g8-02-add-panel.svg["Dashboard Bookshelf (guides) in edit mode with the Add pane of the right sidebar open: callout 3 marks the Add button of the toolbar and callout 4 marks the Panel tile of the Add pane",width=900]
. In the *Panel* pane that replaces the *Add* pane, click *Edit visualization*.
+
image::monitoring-alerting-grafana-guide-g8-03-edit-visualization.svg["Dashboard in edit mode after the Panel tile was clicked: a new panel called New panel and the Panel pane of the sidebar with the Edit visualization button marked by callout 5",width=900]

=== Query the request rate by route

[start=6]
. At the bottom of the panel editor, check that the *Queries* tab is selected and that *Data source* shows *Prometheus*.
. In query *A*, click *Code* in the *Builder* / *Code* switch.
+
image::monitoring-alerting-grafana-guide-g8-04-code-mode.svg["Panel editor with an empty New panel on the Queries tab: callout 6 marks the Prometheus data source picker and callout 7 marks the Code option of the Builder and Code switch",width=900]
. Click inside the query editor first, so that it has the focus, then type the query, which sums the request rate of the Bookshelf service by route:
+
[source,promql]
----
sum by (uri) (rate(http_server_requests_seconds_count{application="bookshelf"}[1m]))
----
. Below the editor, click the *Options* line to open it, then open the *Format* list and choose *Table*. A table needs one row per route, not one line per series.
. In the same row, open the *Type* list and choose *Instant*, so that the query returns the latest value of each route instead of a whole time range.
. Click *Run queries*.
+
image::monitoring-alerting-grafana-guide-g8-05-query-typed.svg["Panel editor in Code mode: the query that sums the request rate by uri is typed in the editor (callout 8), the opened Options row shows Format set to Table (callout 9) and Type set to Instant (callout 10), and Run queries is marked by callout 11",width=900]

=== Show the data as a table

[start=12]
. In the right column, click the *All visualizations* tab, then click *Table* ("Supports many column styles"). The *Suggestions* tab offers a *Table* card as well.
+
image::monitoring-alerting-grafana-guide-g8-06-pick-table.svg["Panel editor after Run queries: the preview shows the result as a table with the columns Time, uri and Value, and the All visualizations tab of the right column lists Table with the description Supports many column styles, marked by callout 12",width=900]
. The right column becomes the options pane, headed *Table*. Open *Panel options* and type `Requests per second by route` in *Title*.
+
image::monitoring-alerting-grafana-guide-g8-07-panel-title.svg["Panel editor with the Table options pane: under Panel options the Title field holds Requests per second by route and is marked by callout 13",width=900]

=== Organize and rename the columns

[start=14]
. At the bottom of the editor, click the *Transformations* tab.
. Click *Add transformation*.
+
image::monitoring-alerting-grafana-guide-g8-08-transformations-tab.svg["Panel editor on the Transformations tab: the tab is marked by callout 14 and the empty state offers the Add transformation button, marked by callout 15",width=900]
. In the drawer *Add another transformation*, find *Organize fields by name* in the alphabetical list and click it.
+
image::monitoring-alerting-grafana-guide-g8-09-pick-organize.svg["The Add another transformation drawer with an alphabetical list of transformations: the row Organize fields by name is marked by callout 16",width=900]
. In the transformation, switch off the field *Time*, which the table does not need. The *Time* column disappears from the preview.
. On the row of the field `uri`, type `Route` as its new name.
. On the row of the field `Value`, type `Requests per second` as its new name.
+
image::monitoring-alerting-grafana-guide-g8-10-organize-fields.svg["The Organize fields by name transformation: the Time field is switched off (callout 17), the uri field is renamed to Route (callout 18) and the Value field is renamed to Requests per second (callout 19); the preview shows a table with two columns",width=900]

=== Draw the values as gauges

[start=20]
. In the options pane, open *Cell options*.
. Open *Cell type* and choose the gauge type. Every numeric column is drawn as a bar; the text column *Route* keeps plain text.
. Open *Standard options* and type `0` in *Min*.
. Type `10` in *Max*, so that a bar is full at 10 requests per second.
+
image::monitoring-alerting-grafana-guide-g8-11-gauge-cells.svg["Panel editor with the Table options pane: Cell options is marked by callout 20, its Cell type is set to the gauge type (callout 21), and under Standard options Min is 0 (callout 22) and Max is 10 (callout 23); the preview draws the second column as gauge bars",width=900]

=== Override one column

[start=24]
. At the end of the options pane, click *Add field override*.
. Choose the matcher that selects a field by its name, then pick the field `Route`.
. Add an override property, choose *Column width* and type `240`. The column of the routes is now narrower than the default; the override changes this column only.
+
image::monitoring-alerting-grafana-guide-g8-12-field-override.svg["Options pane scrolled to its end: the Add field override button is marked by callout 24, the new override selects the field Route (callout 25) and sets the property Column width to 240 (callout 26)",width=900]

=== Add a filter and a footer, then sort

[start=27]
. In the options pane, open *Table* and switch on *Column filter*. Every header gets a filter icon.
. Open *Table footer* and set *Calculation* to the calculation that adds up the values, so that the footer shows the total request rate.
+
image::monitoring-alerting-grafana-guide-g8-13-filter-and-footer.svg["Panel editor with the Table options pane: the Column filter toggle is switched on (callout 27) and under Table footer the Calculation is set to the one that adds up the values (callout 28); the preview shows filter icons in the column headers and a footer row with the sum of the four rates",width=900]
. Click *Save* in the header of the editor. The 13.3 panel editor has no *Apply* button.
. In the *Save dashboard* drawer, click *Save*.
. Click *Back* to return to the dashboard.
. Click *Exit edit*. If Grafana 13.3.0 shows the dialog *Unsaved changes*, click *Save* and click *Save* again in the drawer, as in the xref:backend/monitoring-alerting/grafana/guide-first-dashboard.adoc[first dashboard guide].
. In the dashboard, click the header *Requests per second* to sort the rows by rate; click it again to reverse the order.
. Click the filter icon in the header *Route* to keep only some of the routes.
+
image::monitoring-alerting-grafana-guide-g8-14-sort-and-filter.svg["Dashboard Bookshelf (guides) in view mode: the table is sorted by the header Requests per second, marked by callout 33, and the filter icon in the header Route is marked by callout 34",width=900]

== Check the result

Open *Dashboards* → *Guides* → *Bookshelf (guides)*. The panel *Requests per second by route* must show one row for each of the routes
`+/api/books+`, `+/api/books/{id}+`, `+/api/search+` and `+/api/loans+`, a bar and a number in the second column, and a footer row under the last route.

To see the numbers move, send errors and press *Refresh* after a minute:

[source,bash]
----
curl -X POST localhost:8090/mode/failing
----

Restore normal traffic afterwards, and check the mode of the load generator at any time:

[source,bash]
----
curl -X POST localhost:8090/mode/normal
curl localhost:8090/
----

== Variations

* Draw the numbers with a coloured background instead of a bar: in *Cell options*, open *Cell type* and choose the coloured background type, then set the colours in *Thresholds*.
* Show a small chart in each row: the sparkline cell type needs one time series per row, which the transformation *Time series to table* prepares from a range query.
* Link a row to a detail dashboard: add a link under *Data links and actions* and pick the cell type that shows data links. The guide on thresholds, value mappings, overrides and data links builds one.
* Page the rows instead of scrolling: switch on *Enable pagination* under *Table*.

== What can go wrong

[cols="2,3,3",options="header"]
|===
|Symptom |Cause |Fix

|The table has one row per time step, or no *Route* column to rename
|*Format* is still *Time series* or *Type* is *Range*, so the query returns series and not one row per route.
|Open the *Options* line under the query, set *Format* to *Table* and *Type* to *Instant*, and run the query again.

|The table is empty or says *No data*
|The query was typed before the editor had the focus, or the lab started less than a minute ago.
|Click in the editor, select all with Ctrl+A (Cmd+A on macOS), type the query again, and press *Run queries* after a minute.

|The renamed column titles are not shown
|The transformation was added but the names were typed on a different row, or the editor was left before the field lost the focus.
|Open the *Transformations* tab and check the name typed on the row of each field.

|All bars are full, or all are almost empty
|*Min* and *Max* are not set, so Grafana scales the bars to the data.
|Under *Standard options*, type `0` in *Min* and `10` in *Max*.

|*Exit edit* keeps showing *Unsaved changes*
|Grafana 13.3.0 raises the dialog even after a save.
|Click *Save*, and *Save* again in the drawer; the dialog does not return once edit mode has closed.
|===

== Clean up

Keep the panel: the guide on thresholds, value mappings, overrides and data links extends it. To remove it, open the
dashboard, click *Edit*, open the menu of the panel and delete it, then save the dashboard.
