= Grafana Guide: Reuse, Versions and Sharing
:description: Step-by-step guide to Grafana 13.3: turn the request rate panel of Bookshelf (guides) into a library panel, reuse and unlink it, read the JSON model, compare and restore versions, export and import the dashboard, share it internally and externally, and publish a snapshot.
:keywords: Grafana, library panel, unlink, version history, restore, JSON model, export, import, share internally, share externally, snapshot, dashboard, Bookshelf, step by step, guide

include::partial$ai-disclaimer.adoc[]

Checked on 2026-11-11 against Grafana 13.3.x.

== What you build

You make a reusable library panel called *guide-request-rate* from the request rate panel of the dashboard *Bookshelf (guides)*, use it a second time on the same dashboard and unlink the copy again.
You then read the JSON model of the dashboard, look at its saved versions and restore one, export the dashboard as code, see where an import starts, copy a link to it, look at the warning of an external share, and publish a snapshot.

image::monitoring-alerting-grafana-guide-g15-14-result.svg["The finished dashboard Bookshelf (guides) in view mode with two panels titled Requests per second by status, one of them reused from the library panel guide-request-rate and the other unlinked from it, and the Share button of the toolbar",width=900]

== Before you start

* Start the Grafana profile of the xref:backend/monitoring-alerting/hands-on-lab.adoc[hands-on lab] and wait about a minute:
+
[source,bash]
----
cd lab
docker compose --profile grafana up -d
----
* Open http://localhost:3000, sign in as `admin` with the password `admin`, and click *Skip* when Grafana 13.3 asks you to update the default password.
* Do the previous guide, xref:backend/monitoring-alerting/grafana/guide-layout-annotations-and-links.adoc[Rows, tabs, layouts, annotations and links], or at least
  xref:backend/monitoring-alerting/grafana/guide-first-dashboard.adoc[Create a dashboard and the first panel], which creates the dashboard *Bookshelf (guides)* and its panel *Requests per second by status*.
* The data source *Prometheus* is provisioned by the lab and is the default data source, so there is nothing to add.
* The guide was checked on Grafana Enterprise 13.3.0 (the free image, no licence key). Editing dashboards and creating library panels needs the *Editor* or *Admin* role of the organization; `admin` has it.
* Creating, reusing and unlinking a library panel, the list of versions with its compare and restore controls, and the import page were not opened when the guide was checked.
  The steps name them without describing their exact layout, and the figures draw them in a simplified way. Follow the labels of your screen.
* The figures are drawings of the Grafana 13.3 user interface, not screenshots, so small details can differ from your screen.
  A highlighted box with a number marks the control of the step with the same number.

== Steps

=== Make a library panel

A library panel is stored once and can be used on many dashboards; a change to it shows up everywhere it is used.

. In the left navigation, click *Dashboards* → *Guides* → *Bookshelf (guides)*.
. Click *Edit* at the right of the toolbar.
+
image::monitoring-alerting-grafana-guide-g15-01-open-dashboard.svg["Dashboard Bookshelf (guides) in view mode with the navigation docked: callout 1 marks the Dashboards item of the navigation and callout 2 marks the Edit button of the toolbar",width=900]
. Open the menu of the panel *Requests per second by status* (the three dots of its header, *Menu for panel Requests per second by status*) and choose the entry that turns the panel into a library panel.
+
image::monitoring-alerting-grafana-guide-g15-02-panel-menu.svg["Dashboard in edit mode with the panel Requests per second by status: the three dots of the panel header, the menu of the panel, are marked by callout 3",width=900]
. In the dialog that opens, name the library panel `guide-request-rate`, choose the folder *Guides* and confirm the dialog.

=== Reuse the library panel and unlink the copy

[start=5]
. Click *Add* at the left of the toolbar to open the *Add* pane.
. Click the *Panel* tile ("Drag or click to add a panel"). Grafana adds an empty panel called *New panel*.
. In the new panel, click *Use library panel*.
+
image::monitoring-alerting-grafana-guide-g15-03-use-library-panel.svg["Dashboard in edit mode with the request rate panel and a new empty panel called New panel: the buttons Configure visualization, Use saved query and Use library panel are shown, and Use library panel is marked by callout 7",width=900]
. In the list that opens, choose *guide-request-rate*. The panel now draws the same chart as the first one.
. In a second browser tab, open *Dashboards* → *Library panels* (the address is `http://localhost:3000/library-panels`). The list holds *guide-request-rate* in the folder *Guides*, and shows where it is used.
+
image::monitoring-alerting-grafana-guide-g15-04-library-panels-page.svg["Library panels page of Grafana 13.3 with the Dashboards group of the navigation open: callout 9 marks the entry Library panels, and the page lists the library panel guide-request-rate in the folder Guides",width=900]
. Back in the first tab, open the menu of the second panel and choose the entry that unlinks the library panel. The panel becomes an ordinary panel with its own copy of the settings, and changes to the library panel no longer reach it.
. Click *Save* in the toolbar. The *Save dashboard* drawer opens.
. In *Message*, type `Library panel reused`.
. Click *Save* in the drawer. Each save creates a version of the dashboard, which the next phases use.

=== Open the dashboard settings

[start=14]
. In the icon strip of the right sidebar, click *Options*. The *Dashboard* pane opens.
. Click *View all settings* at the top of the pane.
+
image::monitoring-alerting-grafana-guide-g15-05-view-all-settings.svg["Dashboard in edit mode with the Dashboard pane of the Options icon open in the right sidebar: callout 14 marks the Options icon of the icon strip and callout 15 marks the View all settings button at the top of the pane",width=900]

=== Read the JSON model

[start=16]
. Click the *JSON Model* tab. The editor shows the whole dashboard as JSON. Dashboards made in Grafana 13.3 use the v2 resource schema: the first lines read `"apiVersion": "dashboard.grafana.app/v2"` and `"kind": "Dashboard"`, followed by `metadata` and `spec`. Do not edit the text here; only read it.
+
image::monitoring-alerting-grafana-guide-g15-06-json-model.svg["Dashboard settings with the JSON Model tab selected and marked by callout 16: the editor shows the start of the JSON of the dashboard, with apiVersion dashboard.grafana.app/v2, kind Dashboard, metadata and spec",width=900]

=== Compare and restore a version

[start=17]
. Click the *Versions* tab. It lists the saved versions of the dashboard; the newest one carries your message `Library panel reused`.
+
image::monitoring-alerting-grafana-guide-g15-07-versions-tab.svg["Dashboard settings with the Versions tab selected and marked by callout 17: the body holds the list of saved versions of the dashboard, drawn as empty rows",width=900]
. Select two versions in the list and use the control that compares them. Grafana shows what changed between the two.
. Choose an older version and use the control that restores it, then confirm. Restoring does not delete the newer versions; it saves the old content as the newest version, so you can restore the newer one again the same way.

=== Export and import the dashboard

[start=20]
. Click the breadcrumb *Bookshelf (guides)* to leave the settings.
. Click *Exit edit*. If Grafana 13.3.0 shows the dialog *Unsaved changes*, click *Save* and, in the drawer that opens, *Save* again.
. In the right sidebar of the dashboard, click *Export* → *Export as code*. The drawer *Export dashboard* ("Copy or download a file containing the definition of your dashboard") shows the same JSON as the model. The toggle *Share dashboard with another instance* prepares the file for another Grafana; leave it off here, and use the controls of the drawer to copy or download the file.
+
image::monitoring-alerting-grafana-guide-g15-08-export-as-code.svg["Dashboard in view mode with the drawer Export dashboard open: it says Copy or download a file containing the definition of your dashboard, offers the toggle Share dashboard with another instance and the Advanced options, and shows the JSON of the dashboard, which is marked by callout 22",width=900]
. Close the drawer, then click *Dashboards* in the left navigation, *New* at the top right and *Import dashboard*.
+
image::monitoring-alerting-grafana-guide-g15-09-import-dashboard.svg["Dashboards page of Grafana 13.3 with the New menu open: callout 23 marks Import dashboard in the menu, between New dashboard and New folder",width=900]
. The import page takes a file or the pasted JSON. You can stop here and go back to *Bookshelf (guides)*. To import the file you exported as a copy, give the copy another title, such as `Bookshelf (guides) copy`, and a different UID when the page asks, because the original has the same ones; then choose the folder *Guides* and import it.

=== Share the dashboard

[start=25]
. Back in the dashboard in view mode, click *Share* at the right of the toolbar.
. Click *Share internally*.
+
image::monitoring-alerting-grafana-guide-g15-10-share-menu.svg["Dashboard in view mode with the Share menu open: callout 25 marks the Share button of the toolbar and callout 26 marks Share internally, the first of the entries Share internally, Share externally and Share snapshot",width=900]
. In the drawer under *Link settings*, switch on *Lock time range*. The link then opens with the time range you have now instead of the current one.
. Click *Copy link*. Paste it into another browser tab to check that it opens the dashboard.
+
image::monitoring-alerting-grafana-guide-g15-11-share-internally.svg["Share internally drawer with Link settings: the toggle Lock time range is switched on and marked by callout 27, the toggles Shorten link and the Theme choice follow, and the Copy link button is marked by callout 28",width=900]
. Close the drawer and click *Share* → *Share externally*. Read the checkbox *I understand that this entire dashboard will be public.* It is the price of a public dashboard: anyone with the link can see all of it, without signing in.
. Do not tick the checkbox. Click *Cancel*.
+
image::monitoring-alerting-grafana-guide-g15-12-share-externally.svg["Share externally drawer: Link access is set to Anyone with the link, the checkbox I understand that this entire dashboard will be public is marked by callout 29, and the Cancel button next to Accept is marked by callout 30",width=900]

=== Take a snapshot

A snapshot is a frozen copy of the data the panels show now. It does not need the data source afterwards.

[start=31]
. Click *Share* → *Share snapshot*.
. In *Snapshot name*, type `Bookshelf guides snapshot`.
. In *Expires in*, choose `1 Hour`.
. Click *Publish snapshot*. Do not use *Publish to snapshots.raintank.io*, which sends the data to an external service.
+
image::monitoring-alerting-grafana-guide-g15-13-share-snapshot.svg["Share snapshot drawer: the Snapshot name field holds Bookshelf guides snapshot (callout 32), Expires in is set to 1 Hour (callout 33) and the Publish snapshot button is marked by callout 34, above the buttons Publish to snapshots.raintank.io and Cancel and the link View all snapshots",width=900]
. Open the link of the published snapshot, or *Dashboards* → *Snapshots*, to see it. Its panels keep the values of the moment you published it, whatever the load generator does later.

== Check the result

The dashboard must show two panels with the request rate; the library panel *guide-request-rate* must be listed at *Dashboards* → *Library panels*; the *Versions* tab must list the versions you saved; the copied link must open the dashboard; and *Dashboards* → *Snapshots* must list *Bookshelf guides snapshot*.

To see that the snapshot is frozen while the dashboard is live, force errors, wait a minute and press *Refresh* on the dashboard, then compare it with the snapshot. Restore normal traffic afterwards:

[source,bash]
----
curl -X POST localhost:8090/mode/failing
curl -X POST localhost:8090/mode/normal
----

== Variations

* Reuse the library panel on a second dashboard (*Use library panel* in an empty panel) to see that a change of the library panel reaches both.
* Export the dashboard as an image instead of code, with *Export* → *Export as image*, for a report.
* Provision the exported JSON from a file, as the reference page on observability as code describes, to keep the dashboard under version control.

== What can go wrong

[cols="2,3,3",options="header"]
|===
|Symptom |Cause |Fix
|The panel menu has no entry for library panels
|The dashboard is not in edit mode, or the panel is already a library panel.
|Click *Edit* first. For a panel that is already a library panel, the menu offers the unlink entry instead.

|*Use library panel* lists nothing
|The library panel was not created, or you are in another organization.
|Open *Dashboards* → *Library panels* and check that *guide-request-rate* exists; repeat the first phase if it does not.

|The import reports that the dashboard already exists
|The file has the same UID or title as the dashboard in the folder.
|Change the title and the UID on the import page, or choose another folder.

|The external share cannot be confirmed
|You did not tick the checkbox that confirms the public share.
|That is the intended safeguard: click *Cancel* unless you really want a public dashboard.

|The snapshot shows no data
|The dashboard had no data in its time range when you published it.
|Wait for traffic, press *Refresh*, and publish the snapshot again.
|===

== Clean up

Keep the dashboard and the library panel: the following guides use the dashboard. Delete the snapshot from *Dashboards* → *Snapshots*, and remove an imported copy by deleting that dashboard from its settings.
To remove everything else the lab stores, stop the profile with `docker compose --profile grafana down -v`, which also deletes the volumes.
