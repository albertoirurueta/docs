Welcome to the Hibernate reference. *Hibernate ORM* is the reference implementation of *Jakarta Persistence*
and the object/relational mapping engine most Java backend services build their data-access layer on. This
section is framework-agnostic -- plain Jakarta Persistence and native Hibernate, with Spring Boot wiring noted
only where it matters -- and goes considerably deeper than
xref:backend/springboot/hibernate.adoc[Hibernate (JPA & ORM)]'s conceptual overview, which stays the right
starting point for a first orientation before diving into this section.

If you are new to Hibernate, start with xref:backend/hibernate/getting-started.adoc[Getting Started], then
xref:backend/hibernate/architecture.adoc[Architecture] and
xref:backend/hibernate/entities-and-identifiers.adoc[Entities and Identifiers], then work down the list or jump
to what you need.

*Deliberately out of scope.* This section is about Hibernate ORM and the Hibernate projects built on it, working against relational databases through Jakarta Persistence. The following topics appear in books on Hibernate (the two Hibernate OGM books consulted for this section, and the general Hibernate and JPA books) but live elsewhere on this site, or are intentionally not covered:

* *Hibernate OGM and mapping MongoDB documents through JPA* (the Hibernate OGM `+persistence.xml+` datastore provider, JP-QL translated to MongoDB queries, entity-to-document mapping rules, and the e-commerce model built on them) -- Hibernate OGM is a retired project, so it is intentionally not covered here; the document model, embedding versus referencing and the query surface are in xref:database/mongodb/index.adoc[MongoDB Reference] and xref:database/mongodb/data-modeling.adoc[Data Modeling], and object mapping for MongoDB today is in xref:backend/springboot/spring-data-mongodb.adoc[Spring Data MongoDB].
* *Full-text queries over a non-relational store with Hibernate Search and Lucene* -- the relational case is covered in xref:backend/hibernate/hibernate-search-fundamentals.adoc[Hibernate Search Fundamentals] and xref:backend/hibernate/hibernate-search-backends.adoc[Hibernate Search Backends]; the engine underneath is in xref:database/lucene/index.adoc[Lucene Reference].
* *Application-server deployments and their JTA setups* (a standalone JTA manager on Tomcat, built-in JTA on GlassFish or JBoss AS, EJB bean-managed and container-managed transactions, Seam and Spring on an application server) -- intentionally not covered as deployment recipes; the model itself (resource-local versus JTA, contextual sessions, synchronizations) is in xref:backend/hibernate/transactions.adoc[Transactions], and the current framework equivalents are in xref:backend/springboot/transaction-isolation-and-locking.adoc[Transaction Isolation and Locking] and xref:backend/quarkus/datasources-and-transactions.adoc[Quarkus Datasources and Transactions].
* *Moving a database-backed application to a cloud platform* (hosted database services, PaaS gears, application-server cartridges) -- not covered; see xref:database/migration/cloud-and-managed-services.adoc[Cloud and Managed Services], xref:backend/quarkus/kubernetes-and-openshift.adoc[Quarkus on Kubernetes and OpenShift] and xref:backend/kubernetes/index.adoc[Kubernetes].
* *Spring Data repositories on top of Hibernate* -- the integration points are in xref:backend/hibernate/spring-boot-integration.adoc[Hibernate & Spring Boot Integration]; the repository abstraction itself is in xref:backend/springboot/spring-data-jpa.adoc[Spring Data JPA].
* *XML mapping files (`+hbm.xml+`), the `javax.persistence` namespace and pre-Hibernate-6 query APIs* -- intentionally not covered; every page uses annotations and `jakarta.persistence`, and the official migration guide listed in the bibliography is the reference for upgrading old mappings.
* *Conversations and extended persistence contexts* (long-lived sessions spanning several requests, as in Seam) -- intentionally not covered; the session-per-request scope and `merge` of detached state in xref:backend/hibernate/persistence-context-and-lifecycle.adoc[Persistence Context and Lifecycle] are the recommended alternative.
* *Rarely used mapping features* (`+@Any+`/`+@ManyToAny+` polymorphic references, composite user types, custom collection types) -- intentionally not covered; the User Guide chapters linked in the bibliography document them.
* *Database design, indexing and SQL tuning* -- the database side of every mapping on these pages is in xref:database/sql/index.adoc[SQL Reference] and xref:database/diagnosing-slow-queries.adoc[Diagnosing Slow Queries]; Hibernate-side diagnosis is in xref:backend/hibernate/performance-and-statistics.adoc[Performance and Statistics].

== Version baseline

This section documents **Hibernate ORM 7.4.x** (User Guide, Introduction, Query Language Guide, Data Repositories Guide), **Jakarta Persistence 3.2**, **Hibernate Search 8.4.x**, and the Hibernate Validator / Hibernate Reactive references -- **which are the references these pages are written and verified against**.
The three local books listed under <<_bibliography,Bibliography>> predate Jakarta Persistence 3.2 and Hibernate ORM 6/7 (the `javax.persistence` -> `jakarta.persistence` namespace change, the ORM 6 query-engine rewrite, the Hibernate Search 6+ Elasticsearch backend), so **the official documentation above wins on any discrepancy**.

== What's covered

=== Getting started

* xref:backend/hibernate/getting-started.adoc[Getting Started] -- Hibernate and Jakarta Persistence, adding
  Hibernate to a Maven/Gradle build, `persistence.xml` vs. programmatic bootstrap (four routes compared), a runnable
  "Hello, Hibernate" example on H2, reading the startup log, logging SQL and bound parameters, and the
  most-used `hibernate.properties` settings. See also
  xref:backend/quarkus/hibernate-orm-and-jpa.adoc[Hibernate ORM in Quarkus] for Quarkus's own
  no-`persistence.xml` bootstrapping model.
* xref:backend/hibernate/spring-boot-integration.adoc[Hibernate & Spring Boot Integration] -- how
  `spring-boot-starter-data-jpa` wires Hibernate in, why Spring Data JPA does not supersede Hibernate (a
  comparison table of what each layer is responsible for), Hibernate's own limitations inside a Spring Boot
  application, and where database model evolution is tracked.

=== Architecture & domain model

* xref:backend/hibernate/architecture.adoc[Architecture] -- the object/relational paradigm mismatch in depth,
  Hibernate's layered architecture, `SessionFactory`/`Session` vs. `EntityManagerFactory`/`EntityManager`,
  `StatelessSession` (compared with `Session` side by side), persistence units, dialect detection, and the
  data-navigation mismatch measured as an N+1 statement count.
* xref:backend/hibernate/entities-and-identifiers.adoc[Entities and Identifiers] -- `@Entity`/`@Table`, access
  strategies, `@GeneratedValue` strategies, composite keys, `@NaturalId`, `@MapsId`, and `equals()`/`hashCode()`
  guidance -- with identity versus sequence insert timing and pooled sequences observed in SQL, composite key
  column order, a custom generator with `@IdGeneratorType`, and a primary-key `equals()` failure demonstrated.
* xref:backend/hibernate/basic-and-embeddable-types.adoc[Basic and Embeddable Types] -- `@Basic`, `@Enumerated`,
  `AttributeConverter`, `@Embeddable`/`@Embedded`, JSON/LOB mapping, geospatial types with Hibernate Spatial,
  `java.time` and time zones (with what each `hibernate.timezone.default_storage` setting stores on H2 and
  PostgreSQL), `@Nationalized`, and `@Immutable`; a worked `Book` mapping shows the columns and raw values
  Hibernate writes.
* xref:backend/hibernate/associations.adoc[Associations] -- `@ManyToOne`, `@OneToMany`, `@OneToOne`,
  `@ManyToMany`, owning vs. inverse side, bidirectional sync, cascading, orphan removal, and `@OnDelete` -- with the SQL of each association shape, the inverse-side bug, and
  `List` versus `Set` on a many-to-many observed.
* xref:backend/hibernate/collections.adoc[Collections] -- `List`/`Set`/`Map`/sorted collections,
  `@ElementCollection`, ordering annotations, bag vs. list semantics, and SQL array columns -- with a measured cost of removing one element from each
  collection kind and `MultipleBagFetchException` reproduced.
* xref:backend/hibernate/inheritance-mapping.adoc[Inheritance Mapping] -- `SINGLE_TABLE`, `JOINED`,
  `TABLE_PER_CLASS`, `@MappedSuperclass`, and polymorphic query cost -- the DDL and the polymorphic and concrete
  queries of one hierarchy under each strategy.

=== The persistence context

* xref:backend/hibernate/persistence-context-and-lifecycle.adoc[Persistence Context and Lifecycle] -- the
  identity map and first-level cache, the four entity states, `EntityManager` operations, `merge()` semantics,

  `getReference` traced in SQL.
* xref:backend/hibernate/flushing-and-dirty-checking.adoc[Flushing and Dirty Checking] -- automatic dirty
  checking, flush modes, auto-flush, flush ordering (including the unique-constraint replace trap), and `@DynamicUpdate`/`@DynamicInsert`, with
  the SQL of each shown and native-query flushing compared between the JPA and native APIs.
* xref:backend/hibernate/transactions.adoc[Transactions] -- resource-local vs. JTA, the Hibernate transaction
  API, session-per-request, and rollback interaction with the persistence context -- rollback-only transactions, synchronizations, the
  `SessionFactory` helpers, and what `getCurrentSession()` does under each configuration.
* xref:backend/hibernate/locking.adoc[Locking] -- optimistic locking with `@Version`, `@OptimisticLocking`,
  pessimistic locking modes, and lock scope/timeout hints -- the version-check SQL, the `ALL` and `DIRTY` locking types compared, and
  the pessimistic SQL per database (H2 and PostgreSQL).
* xref:backend/hibernate/fetching-and-n-plus-1.adoc[Fetching and N+1] -- lazy vs. eager, proxies and bytecode
  enhancement, `JOIN FETCH`, entity graphs, `@BatchSize`, subselect fetching, and DTO projections.
