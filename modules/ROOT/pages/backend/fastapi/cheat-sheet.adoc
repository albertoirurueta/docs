A single-page, colour-coded summary of the FastAPI essentials, written against FastAPI 0.142.2, Pydantic 2.13,
Starlette 1.7 and Python 3.10+ (versions verified 2026-10-02) -- how to install and run an app (`fastapi dev` and
`fastapi run`, `/docs`, `/redoc` and `/openapi.json`), path operation decorators and `async def` versus `def`,
every parameter source declared with `Annotated` (Path, Query, Body, Header, Cookie, Form and File), Pydantic v2
models and the v1 to v2 renames, return types, `response_model`, errors and response classes, streaming with JSON
Lines and Server-Sent Events, `Depends` and `yield` dependencies, OAuth2 with PyJWT and pwdlib, middleware, CORS
and proxy flags, SQLModel, settings, lifespan and `BackgroundTasks`, `APIRouter` and project layout, OpenAPI
metadata, WebSockets, static files, templates and `frontend()`, testing, deployment, and a strip of what changed
since older tutorials -- handy for quick memorization or as a
xref:attachment$fastapi-cheat-sheet.pdf[downloadable PDF] desk reference.
