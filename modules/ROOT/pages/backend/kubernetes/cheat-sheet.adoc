= Kubernetes Cheat Sheet
:description: A single-page, printable Kubernetes 1.37 quick reference -- architecture one-liners, local clusters, kubectl essentials, the object skeleton, workloads and rollout commands, probes, Services, DNS, Ingress versus Gateway API, NetworkPolicy, ConfigMaps and Secrets, storage, resources and QoS, scheduling, autoscaling, security, Kustomize, Helm, CRDs and operators, a troubleshooting table and a strip of what changed since older tutorials.
:keywords: Kubernetes cheat sheet, Kubernetes quick reference, kubectl cheat sheet, printable Kubernetes reference, kubectl commands, Kubernetes YAML, Helm cheat sheet, Kustomize, Gateway API, NetworkPolicy, RBAC, troubleshooting Kubernetes

include::partial$kubernetes-disclaimer.adoc[]

A single-page, colour-coded summary of the Kubernetes essentials -- the control-plane and node components, local
clusters with kind and minikube and kubeconfig contexts, the everyday `kubectl` commands with output formats and
selectors, the object skeleton with labels and annotations, the workload kinds and rollout commands, probes and
graceful shutdown, the Service types, DNS name format and the Ingress versus Gateway API comparison, a default-deny
NetworkPolicy, ConfigMap and Secret creation and consumption, volumes and PV / PVC / StorageClass, requests, limits
and QoS classes, scheduling controls and PodDisruptionBudgets, autoscaling, RBAC and `securityContext` hardening
with Pod Security Admission labels, Kustomize and Helm essentials, CRDs and operators, a troubleshooting table and a
strip of what changed since older tutorials -- handy for quick memorization or as a printable desk reference
through the xref:attachment$kubernetes-cheat-sheet.pdf[downloadable PDF]. It reflects Kubernetes 1.37, kubectl
1.37, kind 0.33, Helm 4.3, Kustomize 5.8 and Gateway API 1.6.
