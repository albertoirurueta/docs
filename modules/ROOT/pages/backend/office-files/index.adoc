Business backends constantly exchange spreadsheets and Word documents with their users: a catalogue exported to Excel,
a nightly loans report, a letter generated from a template, a product list uploaded by an operator. This section is a
practical, example-driven guide to doing that on a Java server with Apache POI. Versions and dates are re-verified when
each page is written and stated as of the date checked.

== Running scenario: Bookshelf

Every page uses the same example, the back office of the Bookshelf store used by other sections, so readers can compare
approaches. The files involved are:

* `books-inventory.xlsx`: the catalogue export, with a styled header, number and date formats, totals formulas, an
  auto-filter, a frozen header row, a data-validation column and a chart.
* `loans-report.xlsx`: a large streaming export of every loan.
* `loan-letter.docx` and `monthly-report.docx`: Word documents with headings, a table, an image, a header and footer and
  page numbers, generated from scratch and from a template.
* `books-import.xlsx`: a catalogue upload with header mapping, per-row validation and an annotated error workbook
  returned to the user.
* `book-request-form.docx`: a Word form from which tables and content controls are extracted.

No example uses real secrets, passwords or personal data; encryption examples read the password from configuration.

== Export path and import path

The section is organised around two directions of data flow.

* *Export path.* The server builds a workbook or a document from its own data and sends it to the user, or stores it:
  styles, formulas, layout, streaming large result sets and download endpoints.
* *Import path.* The user uploads a file that the server must treat as untrusted input: type detection, reading
  cells and runs, event-based reading of large files, validation, error reporting and security limits.

Word and Excel are the focus. PowerPoint (HSLF and XSLF), Outlook (HSMF), Visio (HDGF and XDGF) and Publisher (HPBF)
are POI components too; they are described only in one table on the introduction page.
