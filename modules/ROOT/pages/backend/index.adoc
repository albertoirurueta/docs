A growing collection of backend-development references -- practical, example-driven documentation on the core
technologies of server-side application development, from the Java language itself to the Spring Boot framework.

== Sections

* xref:programming-languages/java/index.adoc[Java Reference] -- the Java language and its standard library: language
  fundamentals, object-oriented programming, records and sealed classes, pattern matching, generics, the
  Collections Framework, streams, `java.time`, I/O and NIO.2, concurrency and virtual threads, the module
  system, and unit testing with JUnit 5 and Mockito, plus a downloadable cheat sheet.
* xref:programming-languages/python/index.adoc[Python Reference] -- the Python language and its standard library:
  language fundamentals, dynamic typing, collections, functions, iterators and generators, modules and packaging,
  files and context managers, object-oriented Python, dataclasses and enums, decorators and metaclasses, type
  hints, concurrency and `asyncio`, virtual environments, and testing with pytest, plus a downloadable cheat sheet.
* xref:backend/fastapi/index.adoc[Python FastAPI] -- building HTTP APIs with FastAPI on Starlette and Pydantic v2
  through one running Bookshelf API: path operations and parameters validated with `Annotated`, request bodies and
  response models, errors, streaming (JSON Lines and Server-Sent Events), dependency injection with `yield`,
  OAuth2/JWT security with PyJWT and pwdlib, SQLModel and other data stores, settings and lifespan, `APIRouter`
  project structure, OpenAPI and Swagger UI, WebSockets, static files and templates, testing with `TestClient`,
  and deployment with the `fastapi` CLI, Docker and Kubernetes, plus a downloadable cheat sheet.
* xref:web/django/index.adoc[Django] (in Web Development) -- the batteries-included Python web framework, including
  REST APIs with Django REST framework and Django Ninja.
* xref:programming-languages/typescript/index.adoc[TypeScript Reference] -- TypeScript as the language behind
  Node.js back ends: the type system, generics, decorators and metadata, modules and tooling, and the strict-mode
  configuration that NestJS projects rely on, plus a downloadable cheat sheet.
* xref:backend/nestjs/index.adoc[NestJS] -- building structured Node.js back ends with NestJS 12 on TypeScript
  through one running Bookshelf service: modules, providers and dependency injection, the request pipeline (middleware,
  pipes, guards, interceptors and exception filters), configuration, TypeORM, Prisma, Drizzle and Mongoose, caching and
  queues, authentication and authorization, OpenAPI, code-first GraphQL, WebSockets, microservices and CQRS,
  resilience, testing with Vitest and Jest, and production concerns such as health checks, observability and
  deployment, plus a downloadable cheat sheet.
* xref:backend/hibernate/index.adoc[Hibernate Reference] -- Hibernate ORM as the Jakarta Persistence provider:
  entities, associations and inheritance mapping, the persistence context and entity lifecycle, locking,
  fetching and the N+1 problem, HQL/JPQL and the Criteria API, second-level caching, schema generation, Envers
  auditing, multitenancy, Hibernate Search (Lucene vs. Elasticsearch backends), Hibernate Reactive and Data
  Repositories, and Bean Validation with Hibernate Validator, plus a downloadable cheat sheet.
* xref:backend/springboot/index.adoc[SpringBoot Reference] -- Spring Data across SQL, MongoDB, Couchbase, and
  Neo4j, transaction isolation and locking, local and distributed caching, REST and gRPC APIs, Spring Security (annotations, the security context,
  OAuth2/OIDC authorization server and social login), server-side web UI frameworks, Kafka messaging,
  scheduling, observability (Micrometer, OpenTelemetry, Prometheus, Grafana), reactive programming with
  Project Reactor, concurrency alternatives (virtual threads, Kotlin coroutines), resilience (see the Resilience section), developer productivity tools
  (Lombok, MapStruct), testing (JUnit, Mockito, Testcontainers,
  JMeter), contract-first API development (OpenAPI, protobuf, AsyncAPI, Avro), Maven quality plugins,
  hexagonal/DDD architectural patterns, and Java vs. Kotlin guidance, plus a downloadable cheat sheet.
* xref:backend/resilience/index.adoc[Resilience] -- resilience with Resilience4j and Bucket4j: making a Spring Boot
  service that calls other services fault tolerant with Resilience4j (CircuitBreaker, Retry, RateLimiter, Bulkhead and
  TimeLimiter, fallbacks and composition, Spring Boot configuration, observability, Spring Cloud CircuitBreaker, Gateway
  and OpenFeign, testing and production tuning), and local and distributed token-bucket rate limiting and API quotas
  with Bucket4j (Redis, JDBC and cache-grid backends, Spring Boot integration with or without the community starter,
  Spring Cloud Gateway), with a comparison of the two, plus two downloadable cheat sheets.
* xref:backend/graphql/index.adoc[GraphQL Reference] -- GraphQL as a query language and runtime: the schema
  and type system, execution and resolvers, pagination, security and demand control, and federation, with
  dedicated Spring for GraphQL (Java) and Strawberry/Ariadne (Python/FastAPI) integration coverage plus
  configuring Apollo Client, urql, Relay and other clients, and a downloadable cheat sheet.
* xref:backend/spring-batch/index.adoc[Spring Batch Reference] -- finite, bounded batch processing: the
  `Job`/`Step`/`JobRepository` domain model, configuring and running jobs, chunk-oriented and tasklet steps,
  fault tolerance (skip & retry), `ItemReader`/`ItemProcessor`/`ItemWriter`, scaling and partitioning, Spring
  Batch Integration, observability, cloud-native batch, and testing, plus a downloadable cheat sheet.
* xref:backend/scheduling/index.adoc[Scheduling] -- timed and recurring work in Spring Boot services: standard
  `@Scheduled`/`TaskScheduler` with ShedLock compared with Quartz 2.5, Quartz with Spring Boot (jobs, triggers, cron,
  misfires, calendars, listeners), persistent job stores on PostgreSQL, MySQL/MariaDB, Oracle, SQL Server, embedded
  SQL, MongoDB and Redis, clustering, dynamic scheduling, observability, testing and production practices, plus a
  downloadable cheat sheet.
* xref:backend/oauth/index.adoc[OAuth Reference] -- OAuth as a protocol rather than a framework binding: OAuth
  1.0a and its evolution into OAuth 2.0 and the OAuth 2.1 draft, access/refresh/ID tokens and the JOSE family,
  every grant type from authorization code with PKCE to the device grant and token exchange, the native-app and
  single-page-app profiles, the Security BCP, sender-constrained tokens (DPoP and mTLS), PAR/JAR and the FAPI
  profiles, OpenID Connect with discovery, logout and social login, passwordless and multi-factor
  authentication methods, and how all of it maps onto Spring Security 7, plus a downloadable cheat sheet.
* xref:backend/quarkus/index.adoc[Quarkus Reference] -- Quarkus, the Kubernetes-native Java framework built on
  build-time augmentation and the closed-world assumption: CDI (ArC), configuration and Dev Services, Quarkus
  REST and the reactive/web stack, Panache and reactive data access, Mutiny and messaging with Kafka, security
  and OIDC/Keycloak, observability, testing, packaging, native images with GraalVM and Kubernetes/OpenShift
  deployment, a Quarkus vs. Spring Boot comparison, and Java vs. Kotlin guidance, plus a downloadable cheat
  sheet.
* xref:backend/messaging/index.adoc[Messaging Reference] -- asynchronous, broker-mediated communication between
  services: messaging models and patterns and delivery guarantees, Apache Kafka (architecture, producers,
  consumers, share groups, reliability and exactly-once, Kafka Streams, and Kafka Connect), RabbitMQ (the AMQP
  0-9-1 model, queue types, routing patterns, reliability/dead-lettering, and AMQP 1.0), a Kafka vs. RabbitMQ
  comparison, and Spring Boot integration (Spring for Apache Kafka, Spring AMQP, and Spring Cloud Stream), plus
  a downloadable cheat sheet.
* xref:backend/architecture/index.adoc[Architecture] -- the two halves of designing a backend system:
** xref:backend/architecture/decisions-and-migrations/index.adoc[Architecture Decisions and Migration Paths] --
   whether and how to split a system in the first place: monolith vs. modular monolith vs. microservices,
   layering backend and frontend behind an API gateway or BFF, migration paths from a legacy stack, a monolith,
   or a single-tenant install, and how to start a new project, plus a downloadable cheat sheet.
** xref:backend/architecture/architectural-patterns/index.adoc[Architectural Patterns] -- domain-driven design
   applied to microservices: strategic design and tactical building blocks (entities, value objects, aggregates,
   repositories), why distributed transactions don't work across services, sagas, domain events and event
   storming, the transactional outbox pattern, CQRS, and event sourcing, plus a downloadable cheat sheet.
* xref:backend/docker/index.adoc[Docker] -- how Docker works and how to use it: the platform and its
  architecture (the Engine, containerd and runc, the OCI specifications), images and builds (Dockerfiles, the build
  cache and multi-stage builds, BuildKit and Buildx, supply-chain security), running containers (storage,
  networking, resources, logging and debugging), Docker Compose, registries, security and orchestration, and the
  Java/Spring Boot loop (Spring Boot images, Compose for local development, Testcontainers integration tests run
  locally and in GitHub Actions, and CI/CD image builds), plus a downloadable cheat sheet.
* xref:backend/kubernetes/index.adoc[Kubernetes] -- how Kubernetes works and how to deploy and operate backend
  services on it: architecture and the object model, kubectl and local clusters with kind, workloads (Pods, probes,
  Deployments, StatefulSets, DaemonSets, Jobs and CronJobs, autoscaling), Services, DNS, Ingress, Gateway API and
  NetworkPolicy, ConfigMaps, Secrets and persistent storage, resources, scheduling, RBAC and Pod security,
  Kustomize, Helm, GitOps and operators, observability, debugging, cluster administration, and the complete
  Bookshelf application, plus a downloadable cheat sheet.
