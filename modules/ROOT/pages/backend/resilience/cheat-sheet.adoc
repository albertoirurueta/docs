= Spring Boot Resilience Cheat Sheet
:description: Two single-page, printable quick references for the Resilience section. The Resilience4j 2.4.x / Spring Boot 4.1.x sheet covers failure modes and the pattern-selection table, dependencies for Boot 4 and Boot 3, the CircuitBreaker state machine with its key properties and defaults, Retry backoff formulas, RateLimiter, Bulkhead and TimeLimiter, the application.yml skeleton and customizers, annotations, fallback signatures and the default aspect order, Actuator endpoints, health statuses and meters, Spring Cloud CircuitBreaker, Gateway and OpenFeign, Spring Framework 7 @Retryable and @ConcurrencyLimit, testing tips, anti-patterns and Resilience4j versus Bucket4j. The Bucket4j 8.21.x sheet covers when to use Bucket4j, dependencies, the token-bucket formula and refill styles, the Bucket API, TokensInheritanceStrategy, ProxyManager and the backends, a manual Spring Boot filter with 429 and Retry-After, the community starter, Spring Cloud Gateway, metrics, testing and the production checklist. Both link to every page in this section.

The Resilience section comes with two single-page, colour-coded summaries, one per library:

* xref:attachment$resilience-cheat-sheet.pdf[Spring Boot Resilience (Resilience4j) Cheat Sheet], written against
  Resilience4j 2.4.x, Spring Boot 4.1.x, Spring Framework 7.0.x and Java 21 (verified on 4 October 2026): the failure
  modes and which pattern answers which, the Boot 4 and Boot 3 dependencies, the CircuitBreaker state machine with its
  key properties and defaults, one row each for Retry, RateLimiter, Bulkhead and TimeLimiter, the `application.yml`
  skeleton and the customizers, the annotations with the fallback-signature rule and the default aspect order, the
  Actuator endpoints, health statuses and key meter names, Spring Cloud CircuitBreaker, Gateway and OpenFeign
  one-liners, Spring Framework 7 `@Retryable` and `@ConcurrencyLimit` against Resilience4j, testing tips, the
  anti-patterns list, and a Resilience4j versus Bucket4j mini-table.
* xref:attachment$resilience-bucket4j-cheat-sheet.pdf[Spring Boot Bucket4j Cheat Sheet], written against Bucket4j
  8.21.x, Spring Boot 4.1.x, Spring Framework 7.0.x and Java 21, with the community `bucket4j-spring-boot-starter`
  0.20.0-RC1 (0.14.0 for Spring Boot 4.0) and Spring Cloud Gateway 5.0.3 (verified on 5 October 2026): when to use
  Bucket4j or Resilience4j, the dependencies, the token-bucket formula and the refill styles, the Bucket API one-liners,
  `TokensInheritanceStrategy`, the `ProxyManager` skeleton with the backend table, client-side settings, expiration and
  optimizations, a manual Spring Boot filter with 429, `Retry-After` and a ProblemDetail, the starter YAML and
  `@RateLimiting`, the Gateway Web MVC and WebFlux limiters, metrics, testing tips, and the anti-patterns and
  checklist.
