A single-page, colour-coded summary of the PrestaShop subsection: the supported versions with the PHP and Symfony matrix, the
install and Docker variables, the module skeleton (main class, install and uninstall, hooks and the upgrade script), the
common hooks, the service and route files with an admin controller skeleton, the CQRS command and query buses, the
ObjectModel and Db safety rules, the theme files and theme.yml, the Webservice and Admin API calls, the bin/console and cache
commands and a security hardening checklist. It reflects PrestaShop 9.2.0 (released 2026-09-30) and the 8.2.8 extended-support
release, checked on 2026-10-27, and is available as a xref:attachment$ecommerce-prestashop-cheat-sheet.pdf[downloadable PDF].
