= Magento Cheat Sheet
:description: A single-page, printable quick reference for Magento Open Source and Adobe Commerce 2.4.9 and Mage-OS 3.6.0 -- editions, versions and end-of-support dates, requirements, installation, bin/magento commands, module skeleton, di.xml, plugins and events, declarative schema and patches, Luma themes, REST and GraphQL with tokens, out-of-process options and a security checklist -- with a downloadable PDF version.

A single-page, colour-coded summary of the Magento subsection: what each edition allows (Magento Open Source, Mage-OS,
Adobe Commerce on-premises, on Cloud and as a Cloud Service), the release lines with their end-of-support dates and
the Cloud enforcement deadlines, the system requirements, installation with Composer, the everyday `bin/magento`
commands, the module skeleton, `di.xml`, plugins and observers, declarative schema and patches, a Luma child theme, the
REST and GraphQL endpoints with the token types, the out-of-process building blocks, a security checklist and a short
list of test, upgrade and performance reminders. It reflects *Magento 2.4.9* (generally available 2026-05-12) and
*Mage-OS 3.6.0* (2026-10-14), checked on 2026-10-27, and is available as a
xref:attachment$ecommerce-magento-cheat-sheet.pdf[downloadable PDF].
