commands for themes, apps and Hydrogen, the theme folder layout, a Liquid quick reference, the section and block schema
skeleton, a `shopify.app.toml` skeleton, authentication (token exchange, scopes, expiring tokens), the Admin GraphQL
request and its rate limits, the Storefront API headers, Function targets and limits, checkout extension targets,
webhooks including the compliance topics, and the deprecation timeline. It reflects Shopify CLI 5.0.0, Admin and
Storefront API version 2026-10 (latest stable), Dawn 16.0.0, Horizon 4.3.0 and Hydrogen 2026.10.2, checked on
2026-10-27, and is available as a xref:attachment$ecommerce-shopify-cheat-sheet.pdf[downloadable PDF].
