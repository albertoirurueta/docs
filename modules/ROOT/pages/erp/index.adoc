= ERP
:description: Landing page for the ERP reference -- what an enterprise resource planning system is, how on-premise and cloud ERP differ, and the SAP documentation of this site: SAP S/4HANA, SAP BTP, CAP, Finance, Human Resources and the step-by-step guides, with an overview, a glossary, cheat sheets and a bibliography.
:keywords: ERP, enterprise resource planning, SAP, SAP S/4HANA, SAP BTP, SAP SuccessFactors, finance, human resources, master data, cloud ERP, on-premise ERP, CAP, ABAP

include::partial$ai-disclaimer.adoc[]

An ERP (enterprise resource planning) system is the business software in which a company keeps its orders, purchasing, stock, accounts and staff records together, so that one posting in sales shows up in finance without anyone typing it twice. This section explains what ERP is and then documents one product family in depth: SAP, with its general usage, its application and service development, Finance and Human Resources. Everything is written for readers with no prior SAP knowledge, and the step-by-step guides can be followed on a normal computer without an SAP account. The ABAP language, in which most SAP code is written, is documented in the xref:programming-languages/abap/index.adoc[ABAP] section under Programming Languages.
