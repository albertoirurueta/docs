Human resources software keeps the data about the people who work for a company: who they are, which job they hold, when
they work, and how they are paid. SAP has offered this in several forms over the years, and a newcomer meets all of them
in job descriptions, project plans and documentation: SAP ERP HCM, SAP HCM for SAP S/4HANA (short name H4S4), SAP
SuccessFactors and Employee Central Payroll. This page puts the options side by side in plain words, shows the
maintenance dates that SAP has published, and explains the core hybrid model in which cloud and on-premise HR software
work together. After reading it you can tell which product a document is talking about and which later page of this
section applies to your situation. It is written against SAP S/4HANA 2025 FPS02 (on premise and Private Edition) for
SAP HCM for SAP S/4HANA, and SAP SuccessFactors release 2H 2026 (2611) for the cloud side. For SAP S/4HANA Cloud Public Edition the integration page cited below
points to SAP Master Data Integration instead of the add-on described here.

== Key terms

* xref:erp/sap/human-resources/glossary.adoc#hcm[HCM]: Human Capital Management, the SAP name for its human resources software.
* xref:erp/sap/human-resources/glossary.adoc#h4s4[H4S4]: the short name for SAP HCM for SAP S/4HANA, the HCM feature set that runs inside SAP S/4HANA.
* xref:erp/sap/human-resources/glossary.adoc#compatibility-pack[Compatibility pack]: a temporary way to keep using an older SAP feature inside SAP S/4HANA.
* xref:erp/sap/human-resources/glossary.adoc#successfactors[SuccessFactors]: SAP's cloud suite for human resources.
* xref:erp/sap/human-resources/glossary.adoc#employee-central[Employee Central]: the core human resources application of SAP SuccessFactors.
* xref:erp/sap/human-resources/glossary.adoc#core-hybrid[Core hybrid]: a setup in which Employee Central holds the core HR data and SAP HCM for SAP S/4HANA runs payroll or time management.

== The example used in this section

Every page of this section uses one made-up business, Example Trading Co. (company code `EX01`, currency EUR, the same
company as in the finance pages). Its employees are Ana Torres (personnel number `00001234`, Sales Manager, hired
01.03.2024), Ben Okoye (`00001235`, Sales Clerk, hired 01.09.2024) and Chloe Martin (`00001236`, Warehouse Clerk, hired
15.01.2025). All codes and values are invented for this site; none is an SAP-delivered value. On this page the example
answers one question: where does the record of Ana Torres live? The answer depends on the option chosen, as the
following sections show.

== The product options

SAP has described several ways to run HR. The table lists them with only what the official pages read for this page
state; where a page states nothing, the cell says so.

[cols="2,3,3",options="header"]
|===
|Option |What it is |What the official pages say

|SAP ERP HCM (classic)
|The HR part of SAP ERP 6.0, the classic product from which companies move to SAP S/4HANA.
|SAP ERP 6.0 belongs to SAP Business Suite 7, whose mainstream maintenance runs through the end of 2027 and whose optional extended maintenance runs from 2028 through the end of 2030.

|SAP S/4HANA Human Resources compatibility pack
|The way to keep running the old HCM functions inside SAP S/4HANA before release 2025.
|With SAP S/4HANA 2025 the business function for SAP HCM for SAP S/4HANA is active by default, so it is no longer possible to run SAP HCM in SAP S/4HANA in compatibility mode. SAP Note 3091160 describes the differences to H4S4.

|SAP HCM for SAP S/4HANA (H4S4)
|A modernized HCM feature set inside SAP S/4HANA on premise or Private Edition.
|"You need a separate license to use SAP HCM for SAP S/4HANA." The page says it provides a modernized feature set that will be enhanced by new features in future.

|SAP SuccessFactors Employee Central
|Cloud software for core HR: employee data, organizational structure and related processes.
|Described as the application that holds core HR data in the core hybrid model, which can send employee data and organizational objects to SAP S/4HANA.

|Employee Central Payroll
|A cloud payroll that SAP offers together with Employee Central.
|SAP publishes best practices for it, titled "SAP Best Practices for Employee Central Payroll based on SAP Human Capital Management for SAP ERP HCM", which shows that it builds on the SAP ERP HCM payroll.
|===

Licensing needs a word of care. The only licensing statement read on the official pages for this page is the one for H4S4:
a separate license. For any other option, the contract with SAP decides, and this page does not state terms. The SAP
Notes that the H4S4 page points to (3443536, 2269324 and 3091160) need an SAP login and were not read for this page.

== Where Ana's record lives in each option

In classic SAP ERP HCM and in H4S4, Ana Torres's personnel record sits in the SAP system itself: her personnel number
`00001234`, her place in the organizational structure and her monthly basic pay of 4,000.00 EUR are master data of that
system. In a pure SuccessFactors setup, the same facts live in Employee Central, in the cloud, and payroll may run in
Employee Central Payroll. In the core hybrid model, Employee Central owns the core record and the SAP S/4HANA system
receives a copy that it needs to run payroll. The next section describes that model.

== The core hybrid model

SAP's integration guide defines the core hybrid option in these words: "You use Employee Central for core HR in
combination with the SAP Human Capital Management solution for SAP S/4HANA for payroll or time management processes."
Employee data and organizational objects are replicated from Employee Central to SAP S/4HANA through SAP Cloud
Integration, which the guide calls the middleware. The add-on that does this, SFSF EC S4 HCM INTEGRATION (ECS4HCM), is
intended for SAP S/4HANA on premise and Private Edition. For Cloud Public Edition the guide says to use SAP Master Data
Integration, and it adds that Master Data Integration replicates only the workforce person, which is not enough to
support HR processes such as payroll.

== The timeline of dates SAP has published

The timeline shows only dates that an official page states. Most entries are announcements and maintenance commitments, not
release dates of HR software.

[mermaid]
----
timeline
  title Published SAP dates that affect HR systems
  2020 : February announcement, S/4HANA maintenance commitment until the end of 2040
  2025 : SAP S/4HANA 2025, business function for H4S4 active by default
       : February announcement, ERP private edition transition option
  2027 : End of mainstream maintenance for Business Suite 7
  2028 : Optional extended maintenance starts, transition option for purchase
  2030 : End of optional extended maintenance
  2031 : Transition option usage begins, runs to the end of 2033
  2040 : End of the S/4HANA maintenance commitment
----

How to read the dates:

* The SAP News article of 4 February 2020 states a maintenance commitment for SAP S/4HANA until the end of 2040, mainstream maintenance for Business Suite 7 core applications through the end of 2027, and three years of optional extended maintenance from the start of 2028 through the end of 2030 at a premium of two percentage points.
* The SAP News article of February 2025 states that the SAP ERP, private edition transition option, an optional subscription for very large, complex customers, will be available for purchase starting in 2028 and will be active for usage from 2031 to 2033.
* No official page read for this page states a separate end date for H4S4. The 2040 commitment is stated for SAP S/4HANA, and H4S4 is described only as a separately licensed feature set, so this page does not claim an H4S4 end date.

Sources: https://news.sap.com/2020/02/sap-s4hana-maintenance-2040-clarity-choice-sap-business-suite-7/[SAP News, February 2020] and https://news.sap.com/2025/02/sap-erp-private-edition-transition-option-navigate-complex-rise-with-sap-transformations/[SAP News, February 2025]

== Which option fits which question

* A document that mentions personnel areas, infotypes or the payroll driver describes classic SAP ERP HCM or H4S4. Later pages of this section teach those with Ana, Ben and Chloe.
* A document that mentions Employee Central, the Metadata Framework or OData APIs describes SuccessFactors.
* A document that mentions replication, middleware or ECS4HCM describes the core hybrid model.
* A project that starts after SAP S/4HANA 2025 plans for H4S4 or SuccessFactors, because compatibility mode is no longer possible.

The choice itself belongs to the company and its contract with SAP; this page only explains what the options are.

== What older books show, and what has changed

The book SAP ERP HCM: Technical Principles and Programming, 1st edition (2013), by Dirk Liepold and Steve Ritter, teaches
HCM as a part of SAP ERP: reading HR data with logical databases and direct table access, working with infotypes,
interfaces such as IDoc/ALE, data conversion, authorizations, and employee and manager self-services. It was written
before SAP S/4HANA and before SAP HCM for SAP S/4HANA existed, so it knows no H4S4, no compatibility pack and no core
hybrid model. Its technical content about infotypes and personnel administration remains the background to H4S4, which
SAP describes as a modernized feature set, but a reader should check every detail against the current product
assistance and not assume that the 2013 behavior is unchanged. The publisher's page lists a later edition of the book.

== Summary

* SAP offers HR as classic SAP ERP HCM, H4S4, SuccessFactors Employee Central and Employee Central Payroll.
* H4S4 needs a separate license, and from SAP S/4HANA 2025 it is active by default, so compatibility mode is no longer possible.
* SAP has published maintenance dates through the end of 2027, 2030 and 2040, and a transition option window of 2031 to 2033.
* The core hybrid model keeps core HR in Employee Central and runs payroll or time management in SAP HCM for SAP S/4HANA.
* This page states no H4S4 end date and no licensing terms beyond the H4S4 license statement.
