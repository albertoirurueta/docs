SAP Cheat Sheet

This content was generated with the assistance of AI and should be verified against the official documentation before being relied on in production.

A one-page reference for everyday SAP work. It condenses the general SAP pages, at the release baseline of the section index (S/4HANA 2025 FPS02, Public Edition 2608, CAP @sap/cds 10.2, SAPUI5 1.154). Every code and command below is taken from the page named at the end of its section, where it is explained and, for commands, was run. Check against help.sap.com before relying on any of it.

SAP GUI and transaction codes

/nmb01      end the current task and open a new transaction
/o SE80     open a transaction in a new session
/o          list your sessions
/i          close this session
/nend       confirm, then log off
/nex        log off at once, no confirmation

Clients, landscape and transports

  • SAP recommends a three-system group of development, quality assurance and production (DEV, QAS, PRD).

  • Table T000 is the client control table; SCC4 is the code of the client settings; MANDT is the client key column.

  • SE09 and SE01 show transport requests, STMS runs the Transport Management System, and S_TRANSPRT is the authorization object for transports.

  • Public Edition uses the Adaptation Transport Organizer, BTP content uses SAP Cloud Transport Management, and SAP Cloud ALM orchestrates but does not move transports.

Details: Clients and the System Landscape and Transports and Change Management.

Users, roles and authorizations

  • SU01 creates users and assigns roles; PFCG builds roles, their menu and their authorizations.

  • SU53 shows the last failed authorization check, SUIM lists users, roles and critical authorizations, and ST01 is the authorization trace.

  • Public Edition: business roles made of business catalogs, narrowed by restriction types.

  • SAP BTP: role templates, grouped into role collections, assigned to users or groups.

Details: Users, Roles and Authorizations.

Architecture and the virtual data model

  • Presentation tier: SAP Fiori launchpad and SAP GUI (which talks DIAG). Application tier: ABAP server with SAP Gateway. Database tier: SAP HANA.

  • View prefixes: I_ interface view, C_ consumption view, P_ private view, and further prefixes such as R_, A_ and E_.

  • Build only on released views (stability contracts C0, C1 and C2).

Details: Architecture and the Virtual Data Model.

OData and SAP Gateway

$metadata
$filter=amount gt 50
$select
$orderby=ID
$top=5
$skip=10
$count=true
$expand=items
$batch

  • SEGW builds V2 services and /IWFND/MAINT_SERVICE publishes them; V4 uses service groups and /IWFND/V4_ADMIN.

  • Writes to SAP Gateway need a CSRF token fetched with x-csrf-token: fetch.

Details: OData and SAP Gateway.

Integration with RFC, BAPI and IDoc

  • The ALE chain of settings: destination (SM59), port (WE21), partner profile (WE20), process codes (WE41 or WE42).

  • WE02 displays IDocs and WE19 helps to test.

  • A BAPI is an RFC-capable function module; commit with BAPI_TRANSACTION_COMMIT. ABAP Cloud uses communication arrangements instead of SM59.

  • Prefer OData and events for new interfaces.

Details: RFC, BAPI, IDoc and SOAP Integration.

BTP and CAP commands

npm i -g @sap/cds-dk
cds init expenses --nodejs
cds watch
cds version
cds env get requires.auth.kind
cds add hana,xsuaa,mta
cds up
mbt build -t gen --mtar mta.tar
cf deploy gen/mta.tar -f
cf login --sso
cf target
cds add kyma

A global account holds subaccounts (one region each) and optional directories; Cloud Foundry gives an org with spaces, Kyma gives clusters with namespaces.

Details: CAP Getting Started, Deploying CAP: HANA, XSUAA and MTA, SAP BTP Account Model and Cloud Foundry and Kyma Environments.

SAPUI5 and Fiori elements

npx ui5 serve --port 8127
npx ui5 build --dest ../dist
Annotation Effect

@UI.LineItem

list report columns

@UI.SelectionFields

filter bar fields

@UI.HeaderInfo

object names and title

@UI.Facets

object page sections

@UI.FieldGroup

fields inside a section

An app is a component with a manifest.json that declares models, libraries and routes; views are XML and code loads with sap.ui.define.

Details: SAPUI5 and OpenUI5 Basics and SAP Fiori Elements.

Extensibility and deployment options

  • Three kinds of extension: key user (low-code), developer (ABAP in the S/4HANA stack) and side-by-side (on SAP BTP). Start with key user extensibility for small changes.

  • Clean core levels A to D map to ABAP Test Cockpit results of no finding, information, warning and error.

  • Public Edition is multi-tenant (upgrades in February and August), Private Edition is single-tenant (RISE with SAP), and on premise is customer operated.

  • Paths from SAP ERP: new implementation, system conversion or selective data transition.

Details: Extensibility and Clean Core and Deployment Options.
