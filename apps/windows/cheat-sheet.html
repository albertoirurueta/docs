A single A4 page that summarises the Windows Apps section for quick memorization or as a printable desk reference. It contains:

  • XAML — the x: directives, markup extensions, clr-namespace: mapping, resource lookup and StaticResource versus DynamicResource.

  • WPF — panels and layout rules, a dependency property and attached property snippet with value precedence, routed events and command types, the anatomy of a Binding (modes, UpdateSourceTrigger, RelativeSource, ElementName), converters, collection views and templates, validation, styles, templates and triggers, the Fluent ThemeMode, and the Dispatcher and async rules.

  • MVVM — the layers diagram, the toolkit snippet (partial-property [ObservableProperty], [RelayCommand], the messenger) and the Generic Host startup snippet.

  • Other stacks — the WinUI 3 deltas (x:Bind, NavigationView, AppWindow) and the Windows Forms deltas (dark mode, async APIs), one line each.

  • Shipping — the publish matrix (framework-dependent, self-contained, single-file, ReadyToRun, trimming and Native AOT per stack), MSIX and signing essentials, the distribution-channel table, the dotnet publish and wingetcreate commands, the CI/CD steps and the .NET Framework migration checklist.
