Hybrid Apps: IDEs & Tools

This content was generated with the assistance of AI and should be verified against the official documentation before being relied on in production.

This page lists the editors and tools most commonly used to build React Native, Flutter and Ionic apps, with a link to each product’s official page. Hybrid projects are written in an editor of choice, but running on a device or emulator still needs the native toolchains: Android Studio for Android and Xcode for iOS. This site has dedicated sections for React Native, Flutter and Ionic.

Editors

  • VS Code — a widely used editor for TypeScript and JavaScript projects.

  • WebStorm — JetBrains' IDE for JavaScript and TypeScript with built-in framework support.

  • React Native Tools — a VS Code extension for debugging and running React Native apps.

  • Ionic VS Code extension — a VS Code extension for creating, running and managing Ionic projects.

Native toolchains

  • Android Studio — provides the Android SDK, emulator and build tools needed to run hybrid apps on Android.

  • Xcode — provides the iOS SDK, Simulator and signing tools needed to run hybrid apps on Apple devices; it requires a Mac.

  • Android Emulator — runs virtual Android devices for testing.

  • React Native environment setup — the official guide to installing the native toolchains and simulators for React Native.

React Native and Expo tooling

  • Expo — the framework and toolchain recommended for new React Native projects.

  • Expo Go — a sandbox app for running Expo projects on a physical device without a native build.

  • Expo Dev Client — a custom development build that includes your own native code.

Flutter and Dart tooling

  • Flutter SDK — the Flutter framework, the Dart SDK and the flutter command-line tool for creating, running, testing and building apps.

  • Flutter for VS Code — the Dart Code extension that adds Flutter editing, debugging and hot reload to VS Code; it installs the Dart extension too.

  • Flutter for Android Studio — the Flutter plugin for Android Studio and IntelliJ IDEA, with project wizards, run and debug support and hot reload.

  • Flutter DevTools — a suite of debugging and performance tools for Dart and Flutter: widget inspector, performance, CPU, memory and network views.

Ionic and Capacitor tooling

  • Ionic Framework — a UI toolkit for building mobile apps with web technologies.

  • Ionic CLI — the command-line tool for creating, serving and building Ionic projects.

  • Capacitor — a native runtime that packages web apps for Android and iOS and gives them access to device APIs.
