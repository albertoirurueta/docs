Ionic and Capacitor

This content was generated with the assistance of AI and should be verified against the official documentation before being relied on in production.

Ionic Framework is a UI component library for mobile-first web apps, and Capacitor is the native runtime that wraps a web app in an Android or iOS project and exposes device features through plugins. Together they let a web team ship a store app from a normal Angular, React or Vue codebase: the UI runs in the platform WebView and calls native code over a bridge. This subsection is a reference for web developers moving to mobile and for mobile developers evaluating the approach. The examples use Angular with standalone components and signals.

Running example

Every page builds Trailhead, a hiking journal: a searchable trail list loaded from a REST API (https://api.example.com/v1), a trail detail page, favourites, a "log a hike" flow that attaches a camera photo and a GPS position, and an offline cache of the trails. The app id is com.example.trailhead. The same app is built with Flutter in Flutter and Dart.
