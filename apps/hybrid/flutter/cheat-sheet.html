Flutter Cheat Sheet

This content was generated with the assistance of AI and should be verified against the official documentation before being relied on in production.

A compact reference for Flutter 3.47.9 (stable) with Dart 3.13.7 and the Trailhead example packages: go_router 18.1.4, flutter_riverpod 3.5.0, dio 5.11.1, drift 2.35.4, shared_preferences 2.5.6, camera 0.12.2, geolocator 14.1.2, json_serializable 6.15.2 and mocktail 1.0.5. For explanations and complete examples, follow the page links at the end.

CLI Commands

Command Purpose

flutter doctor

Check the toolchain and report missing pieces.

flutter create trailhead

Create a new project.

flutter pub add dio

Add a dependency (use dev: prefix for dev dependencies).

flutter pub get

Fetch dependencies listed in pubspec.yaml.

flutter run -d <device-id>

Run on a device; press r for hot reload and R for hot restart.

flutter devices

List connected devices and emulators.

flutter analyze

Static analysis.

dart format .

Format all Dart files.

dart run build_runner build

Run code generators (json_serializable, drift).

Routing with go_router

Call Meaning

context.pop()
