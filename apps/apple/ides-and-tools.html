Apple Platforms IDEs & Tools

This content was generated with the assistance of AI and should be verified against the official documentation before being relied on in production.

This page lists the IDEs and tools most commonly used to build native apps for Apple platforms, with a link to each product’s official page. Xcode is required to build, sign and submit apps, so other editors are used alongside it rather than instead of it.

IDEs

  • Xcode — Apple’s IDE for iOS, iPadOS, macOS, watchOS, tvOS and visionOS, with the interface editor, SwiftUI previews, the debugger and the SDKs.

Simulation, profiling and distribution

  • Simulator — runs simulated Apple devices on a Mac for testing apps without physical hardware.

  • Instruments — Apple’s profiling tool for time, memory, energy and network analysis.

  • Xcode Cloud — Apple’s continuous integration and delivery service, built into Xcode and App Store Connect.

  • TestFlight — distributes beta builds to internal and external testers.

Editors with extensions

  • VS Code Swift extension — Swift language support for Visual Studio Code, useful for Swift packages and server-side code; building and signing apps still goes through Xcode.

Discontinued products

  • AppCode — JetBrains' IDE for Swift and Objective-C, now discontinued; Xcode is the recommended replacement.
