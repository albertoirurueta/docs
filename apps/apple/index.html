Apple Platforms

This content was generated with the assistance of AI and should be verified against the official documentation before being relied on in production.

Welcome to the Apple Platforms reference. It documents how to build native apps for Apple devices — iPhone, iPad, Mac, Apple Watch and Apple Vision Pro — with Apple’s own tools, frameworks and language: Xcode, Swift, SwiftUI and the system frameworks underneath. The result runs directly on each platform’s UI toolkit and system services, with no cross-platform layer in between.

This section documents the 27 releases: iOS, iPadOS, macOS, watchOS and visionOS 27, built with Xcode 27 and Swift 6.4. Every example targets a deployment minimum of 26, the previous year’s releases, so an app built this way still runs on devices that have not updated yet; APIs that exist only in the 27 SDKs are called out as "new in 27" in the prose and guarded with if #available(iOS 27, macOS 27, watchOS 27, visionOS 27, *) in code. Apple’s operating systems use year-based version numbers since 2025, so the releases after 18 are 26 (2025) and 27 (2026); there is no iOS 19. macOS 26 is Tahoe and macOS 27 is Golden Gate.

SwiftUI is the primary UI framework on every page, because it is the only one that runs on all five platforms. UIKit (iOS, iPadOS, tvOS and visionOS) and AppKit (macOS) are documented where an app still needs them: for existing codebases, for features SwiftUI does not cover yet, and for mixing the two. This section does not re-explain the Swift language itself — for optionals, generics, protocols, macros, result builders, concurrency and the rest, see the Swift Reference, and for the Objective-C side of mixed codebases, the Objective-C Reference.

How Apple app development got here

Year What changed

2008

The iPhone SDK opened the phone to third-party apps, written in Objective-C against Cocoa Touch and its UI framework, UIKit — the mobile sibling of the Mac’s Cocoa and AppKit. The App Store launched the same year.

2014

Swift was introduced as a safer, modern language for Apple platforms, able to mix with Objective-C in the same app target.

2019

SwiftUI brought a declarative UI framework that runs on every Apple platform, with state-driven views instead of view controllers and manual updates.

2021

Swift concurrency arrived: async/await, structured tasks and actors, with @MainActor for UI code and SwiftUI’s .task modifier tying work to a view’s lifetime.

2023

The Observation framework (@Observable) replaced ObservableObject as the way to drive SwiftUI from model data, SwiftData added Swift-native persistence, and visionOS was announced.

2025

Operating system versions became year-based, jumping to 26 on every platform. The 26 releases introduced the Liquid Glass design language across all platforms and the Foundation Models framework for on-device Apple Intelligence.

2026

The 27 releases: in Xcode 27 @State is a macro, ContentBuilder replaces the type-specific result builders, apps built with the 27 SDK must adopt the UIKit scene-based life cycle, and Swift 6.4 ships with Xcode 27.

Much of what older books, tutorials and forum answers describe predates this timeline: NavigationView, ObservableObject-first data flow, app-delegate-only life cycles, completion-handler concurrency, ClockKit complications and pre-Liquid Glass bar styling. These pages document the current approach and name the older one only where a reader is likely to meet it in an existing codebase.

The FieldNotes app

Every code example across these pages is a slice of one running app, FieldNotes: a notes app that keeps notes grouped into notebooks, with tags, pinning, search and, later in the section, persistence, sync, widgets, Siri and Shortcuts actions, and on-device summaries. It lives in one Xcode project, FieldNotes.xcodeproj, with a multiplatform FieldNotes app target for iOS, iPadOS, macOS and visionOS, a separate FieldNotesWatch target for watchOS, a FieldNotesWidgets widget extension and a FieldNotesTests target for Swift Testing. Its bundle identifiers start with com.example.fieldnotes, and the app and its extensions share data through the App Group group.com.example.fieldnotes.

The code is split into local Swift packages: FieldNotesKit holds the FieldNotesModel module (the Note and Notebook types) and the FieldNotesServices module (the @Observable NoteStore and the service protocols such as NoteSyncing and SummaryGenerating), and FieldNotesUI holds the shared views and styles. The FieldNotesApp entry point creates the store once and injects it into the environment; ContentView is a three-column NavigationSplitView of notebooks, notes and the selected note, and the macOS and visionOS builds add a Settings window, a menu bar extra and an immersive map space. The data, system and device pages then grow it further: SwiftData persistence with CloudKit sync behind a NotePersisting layer, a pinned-notes widget, a Control Center control and a field-trip Live Activity, App Intents for Siri and Shortcuts, on-device summaries with Foundation Models, location and photo attachments, Keychain and passkey sign-in, and a FieldNotes Pro subscription. The platform, quality and distribution pages finish it: resizable note windows and keyboard commands on iPad, a tag inspector utility window and a menu bar extra on the Mac, a watch app that talks to the phone through WatchConnectivity and shows a next-field-trip complication, and a field-site volume on Apple Vision Pro; FieldNotesTests and FieldNotesUITests targets driven by the FieldNotes.xctestplan test plan; and a release pipeline that signs, uploads to TestFlight, notarizes the Mac build and runs in Xcode Cloud. Because every page extends the same codebase, the pages compose into one coherent app rather than a set of unrelated snippets.

Consulted reference books

These were consulted for the concept narrative and the practitioner’s perspective, never as the source of any code example. They are copyrighted works and are not reproduced here; their publisher pages are linked instead.

  • Bello, Antonio, Bill Morefield, Audrey Tam & Sarah Reichelt. SwiftUI by Tutorials, 4th edition. Kodeco (raywenderlich.com), November 2021 — see the publisher’s book page, with the official code bundle at kodecocodes/sui-materials. The narrative source for the SwiftUI views, layout, navigation, controls, drawing and animation, accessibility and macOS/multiplatform material, targeting Xcode 13.1 and Swift 5.5; it teaches ObservableObject/@StateObject and the deprecated NavigationView, both predating the @Observable macro and NavigationStack, and uses XCTest rather than Swift Testing.

  • Cacheaux, René & Josh Berlin. Advanced iOS App Architecture. Kodeco (raywenderlich.com), 2019 — see the publisher’s book page, with the official code bundle at kodecocodes/arch-materials. The narrative source for the MVVM and Redux-style architecture material in App Architecture the Apple Way, targeting Xcode 10.2 and Swift 5; its manual view-controller wiring and hand-rolled Redux state management are UIKit-era and predate the @Observable macro, which now provides much of the same state plumbing for free.

  • Cacheaux, René & Josh Berlin. Advanced iOS App Architecture, 2022 edition. Kodeco (raywenderlich.com), 2022 — see the publisher’s book page, with the official code bundle at kodecocodes/arch-materials. The updated edition of the above, additionally consulted for UIKit and AppKit Essentials and State and Data Flow with Observation, targeting Xcode 13.2.1 and Swift 5.5.2; its proprietary "Elements" layering pattern is a book-specific construct, not a documented Apple or industry-standard architecture, and is not reproduced here.

  • Catalan, Juan C. SwiftUI Cookbook, 3rd edition. Packt Publishing, December 2023. ISBN 978-1-80512-173-2 — see the publisher’s book page, with the official code bundle at PacktPublishing/SwiftUI-Cookbook-3rd-Edition. The narrative source for recipes across SwiftUI layout, lists, navigation, controls, drawing, persistence, security, widgets and multiplatform material, targeting Xcode 15 and Swift 5.9; it is the only book in this library that covers the @Observable macro, though it still leads with ObservableObject first.

  • Clayton, Craig & Donny Wals. Complete iOS 12 Development Guide. Packt Publishing, March 2019. ISBN 978-1-83864-379-9 — see the publisher’s book page, with the official code bundle at PacktPublishing/Complete-iOS-12-Development-Guide. The narrative source touched by the largest number of pages in this section — app architecture, concurrency, UIKit, Core Data, networking, background execution, notifications, App Intents, Apple Intelligence, location, camera, health, AR and distribution — targeting Xcode 10, Swift 4.2 and iOS 12; its GCD-only concurrency, pre- BGTaskScheduler background fetch, SiriKit intents extension and Core ML/Vision-only machine learning chapters are all superseded by the current APIs this section documents.

  • Ferrer García, Raúl. iOS Architecture Patterns. Apress, 2023. ISBN 978-1-4842-9068-2 (print), 978-1-4842-9069-9 (ebook) — see the publisher’s book page, with the official code repository at Apress/iOS-Architecture-Patterns. Consulted in its entirety for the MVC/MVP/MVVM/VIPER/VIP architecture comparison in App Architecture the Apple Way; its description of The Composable Architecture is a 2023 snapshot of a fast-evolving third-party library and is likely dated.

  • Gardner, Scott, Shai Mishali, Florent Pillet & Marin Todorov. Combine: Asynchronous Programming with Swift. Kodeco (raywenderlich.com), 2019 (updated 2020) — see the publisher’s book page, with the official code bundle at kodecocodes/comb-materials. Consulted in its entirety for Swift Concurrency in Apps, targeting Xcode 11 and the iOS 13 SDK; it presents Combine as the async solution for SwiftUI apps, a framing this section’s == Where Combine Stands section replaces with async/await/AsyncSequence as the default and Combine as a still-supported, no-longer-primary tool.

  • Grosch, Scott. watchOS With SwiftUI by Tutorials. Kodeco (raywenderlich.com), 2021 — see the publisher’s book page, with the official code bundle at kodecocodes/wos-materials. Consulted in its entirety for watchOS: App Structure, Connectivity, Workouts and the Smart Stack, plus its background-execution, notifications, widgets, health and security chapters, targeting Xcode 13.1 and Swift 5.5; it predates the Double Tap gesture, the Smart Stack, the @Observable macro, passkeys and WidgetKit-based complications, still describing complications through the superseded ClockKit framework.

  • Moon, Keith, Chris Barker, Daniel Bolella & Nathan Lawlor. Swift Cookbook, 3rd edition. Packt Publishing, May 2024. ISBN 978-1-80323-958-3 — see the publisher’s book page, with the official code bundle at PacktPublishing/Swift-Cookbook-Third-Edition. The narrative source for recipes touching concurrency, networking, UIKit interop, testing, ObservableObject-based observation, Apple Intelligence, AR and visionOS, targeting Swift 5.9; it predates Swift 6 strict-concurrency checking, uses XCTest rather than Swift Testing, and its visionOS chapter predates matured native volumetric APIs.

  • Neuburg, Matt. iOS 15 Programming Fundamentals with Swift, 8th edition. O’Reilly Media, October 2021. ISBN 978-1-098-11850-1 (print), 978-1-098-11849-5 (ebook) — see the publisher’s book page, with the official code repository at mattneub/Programming-iOS-Book-Examples. The narrative source for App Structure and Life Cycle and parts of Mixing Swift, Objective-C and C++ in an App and UIKit and AppKit Essentials, targeting Xcode 13 and Swift 5.5; its life-cycle chapter is UIApplicationDelegate-only and predates the scene-based life cycle, and its nib-file material predates SwiftUI-first guidance.

  • Pillet, Florent, Junior Bontognali, Marin Todorov & Scott Gardner. RxSwift: Reactive Programming with Swift, 1st edition. Kodeco (raywenderlich.com), 2017 — see the publisher’s book page, with the official code bundle at kodecocodes/rxs-materials. Consulted for the app-architecture, UIKit-table-view, networking, location and gesture material it parallels, targeting Xcode 8 and Swift 3.x; RxSwift/RxCocoa is a third-party reactive library whose adoption has declined sharply since Combine and async/await became available, so this section documents Apple’s own tools instead.

  • Sahar, Ahmad. iOS 17 Programming for Beginners, 8th edition. Packt Publishing, October 2023. ISBN 978-1-83763-056-1 (print), 978-1-83763-989-2 (ebook) — see the publisher’s book page, with the official code bundle at PacktPublishing/iOS-17-Programming-for-Beginners-Eighth-Edition. The narrative source for a broad span of beginner-level material — getting started, Xcode projects, SwiftUI views, lists, UIKit interop, SwiftData, preferences, networking, location, camera, visionOS, signing and App Store Connect — targeting Xcode 15, Swift 5.9 and iOS 17; its distribution chapter centres on the manual archive-and-upload flow to App Store Connect and introduces Xcode Cloud only briefly.

  • Scalzo, Giordano & Edgar Nzokwe. SwiftUI Cookbook, 2nd edition. Packt Publishing, October 2021. ISBN 978-1-80323-445-8 — see the publisher’s book page, with the official code bundle at PacktPublishing/SwiftUI-Cookbook-2nd-Edition. The narrative source for recipes across Xcode projects, concurrency, multiplatform apps, SwiftUI layout and navigation, Core Data, widgets, macOS and security, targeting Xcode 13 and iOS 15; its widget recipes predate widget interactivity and Live Activities, and its NavigationView-based navigation predates NavigationStack.

  • Selander, Derek. Advanced Apple Debugging & Reverse Engineering. Kodeco (raywenderlich.com), November 2017 — see the publisher’s book page, with the official code bundle at kodecocodes/dbg-materials. Consulted in its entirety for Debugging with Xcode and LLDB and, for its malloc/leak-logging chapter, Performance and Instruments, targeting Xcode 9.1 and 2017-era LLDB; its Python-scripting-API chapters need adaptation for the Python 3 LLDB shipped with Xcode 27, and its DTrace chapters describe a technique largely blocked today by System Integrity Protection, for which Instruments is Apple’s modern replacement.

  • Tsadok, Avi. The Ultimate iOS Interview Playbook, 1st edition. Packt Publishing, August 2023. ISBN 978-1-80324-631-4 (print), 978-1-80324-720-5 (ebook) — see the publisher’s book page. Consulted narrowly for its Apple-specific chapters — Swift packages and modularization, app architecture, UIKit interop, Core Data and preferences, and SwiftUI state and data flow — with no fixed target Xcode/Swift/iOS version; its interview and career-process chapters, and its generic (non-Apple) design-pattern review, are out of scope for this section.

On any discrepancy between this documentation and Apple’s docs, Apple’s current official documentation is authoritative; every code example in this section’s 48 pages targets Xcode 27, Swift 6.4 and the 27-generation SDKs (iOS/iPadOS/macOS/watchOS/visionOS 27) and was verified against that toolchain directly — not transcribed from any of the consulted books.
