Media Optimization in Apps

This content was generated with the assistance of AI and should be verified against the official documentation before being relied on in production.

Native SDKs often lack a full image pipeline: SwiftUI’s AsyncImage has no dedicated image cache, no prefetching and no downsampling, and a plain ImageView or Image decodes whatever it is given. This sub-section documents the libraries that fill the gap on each platform, how to show a BlurHash while an image loads, how to play adaptive video, and how to compress and upload media from the device. It is current as of 2026-10-07. This is the native and cross-platform app home of the topic: the server side that produces the variants is in Media Optimization for the backend, and the browser side is in Media Optimization for the web. The pages share one running example with the backend and web sections: the book cover b81f (2400 by 3600 pixels, AVIF, WebP and JPEG variants 320, 640 and 1280 pixels wide, and a BlurHash of 28 characters) and the video 42 with its 360p to 1080p ladder. Each page picks a variant for a 160 by 240 point tile from that JSON, and the Swift and Node programs behind the numbers on the pages were run, while the Kotlin, Dart and TypeScript code follows the official API documentation.

Deliberately out of scope. This section is about getting media that already exists in the right variants onto the screen, playing it, and sending new media back. The following topics appear in most native app books but live elsewhere on this site, or are intentionally not covered:

  • Camera capture, pickers and photo library permissions — see Apple: Camera, Media and Photos, Android: Camera, Location, Sensors and Media and React Native: Device Capabilities. Only what the picker returns is used here.

  • Photo filters, Core Image and editing — not covered; this section resizes and re-encodes, and does not edit content.

  • Audio playback and recording — not covered beyond the audio track inside a video; the platform media pages above start there.

  • Image layout and views (ImageView, SwiftUI Image, content modes) — see Android: Views and Layouts, SwiftUI controls, text and images and React Native: Images and Icons.

  • Concurrency (threads, async and await, coroutines) — see Apple: Concurrency in Apps and Android: ViewModel, Lifecycle and Coroutines; the pages use them without teaching them.

  • Background work and services — see Apple: Background Execution and Android: Background Work and Services; only the upload side is repeated here.

  • Networking basics and JSON — see Apple: Networking, Android: Retrofit, OkHttp and Ktor and React Native: Networking and Data Fetching.

  • Persisting media and offline sync (Core Data, Room, files, offline queues) — see Apple: Core Data, CloudKit and iCloud, Android: Local Storage and Files and React Native: Storage and Offline; this section only covers HTTP caches of downloaded media.

  • Permissions and privacy prompts — see Android: Permissions, Privacy and Security and Apple: Security and Privacy.

  • Cross-platform framework basics — see Kotlin Multiplatform and React Native; the hybrid frameworks are documented in Flutter and Dart and Ionic and Capacitor.

  • Producing the variants (encoding, formats, upload pipelines, thumbnails) — see Media Optimization for the backend and upload pipelines.

  • Browsers — see Media Optimization for the web.

  • DRM, live streaming and video calls — FairPlay, Widevine, WebRTC and live ingest are not covered; this section plays on-demand video only.

  • Managed image and video services — see AWS, Google Cloud and Azure.

What’s covered

Page What it covers

Android: Coil, Glide and BlurHash

Coil 3 caches and network artifacts, variant selection, sample-size and memory arithmetic, a cover grid, Glide modules and DiskCacheStrategy, Fresco, and a BlurHash placeholder.

Android Video with Media3

ExoPlayer for HLS and DASH, track selection limits for metered networks, a lifecycle-aware player, SimpleCache sizing, Transformer compression with a bitrate target and cover frames.

iOS: Kingfisher, Nuke and BlurHash

KFImage, DownsamplingImageProcessor, Nuke pipeline and LazyImage, cache configuration, a cover grid with variant selection, a Swift BlurHash decoder, SDWebImage, and the limits of AsyncImage.

iOS Video with AVFoundation

AVPlayer with HLS and rendition limits, AVAssetImageGenerator with rotation and tolerance, AVAssetExportSession presets and progress, and background uploads of parts.

React Native and expo-image

expo-image with blurhash and thumbhash, variant selection by pixel ratio, a cover grid, caching, compression before upload, react-native-blurhash, react-native-fast-image and react-native-video.

Kotlin Multiplatform and Flutter

Coil 3 multiplatform with shared variant selection, KMP BlurHash, expect and actual video players, cached_network_image with a cache manager and flutter_blurhash.

Device-Side Compression and Uploads

When to compress on the phone, ImageIO downsampling and encoding, HEIC and HEVC from iOS, multipart and resumable uploads with retries, and background workers.

Cheat Sheet (PDF)

A one-page summary of the libraries per platform, placeholder and cache settings.
