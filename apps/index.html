Apps

This content was generated with the assistance of AI and should be verified against the official documentation before being relied on in production.

A growing collection of application-development references — practical, example-driven documentation for building apps on specific platforms — natively on Android, on Apple platforms (iOS, iPadOS, macOS, watchOS and visionOS), on Windows, as command-line and terminal programs, and cross-platform on Android and iOS with Kotlin Multiplatform and React Native.

Sections

  • Android — native Android development end to end, starting with the Kotlin language itself: project setup and Gradle, the classic View/Fragment UI toolkit, Jetpack Compose, recommended app architecture and the migration path from Views to Compose, data and networking (Room, DataStore, Retrofit, Ktor, Coil/Glide, Hilt), system integration (background work, notifications, permissions, camera/location/ sensors), testing and debugging, and building, signing and publishing to Google Play and Maven Central, plus a downloadable cheat sheet.

  • Kotlin Multiplatform — sharing Kotlin code between Android, iOS, desktop and the web with Kotlin 2.4 and Compose Multiplatform: project structure and source sets, the AGP 9 Android plugin, expect/actual, coroutines and shared view models, Ktor, SQLDelight, Room 3 and Koin, integrating with Swift and SwiftUI, sharing the UI with Compose Multiplatform on every platform, testing, publishing libraries and apps, CI, and adopting KMP in existing apps, plus a book cross-check and a downloadable cheat sheet.

  • Apple Platforms — building native apps for every Apple device with Swift, SwiftUI and Xcode: projects and tooling, SwiftUI and design, data and system integration, platform-specific features, testing and performance, and shipping to the App Store, plus downloadable cheat sheets.

  • React Native — building Android and iOS apps from one TypeScript codebase with React: the core components, styling and Flexbox layout, navigation, state and networking, storage, offline and security, debugging, testing and performance, native modules, and shipping to the stores, plus a downloadable cheat sheet.

  • Windows Apps — building Windows desktop applications with C# 14 on .NET 10: XAML, WPF, layout, dependency properties, commands, data binding, styles and templates, the MVVM pattern with the MVVM Toolkit, dependency injection and testing, WinUI 3 and the Windows App SDK, Windows Forms, and publishing and distributing with .NET publish options, MSIX, signing, the Microsoft Store, WinGet, App Installer, ClickOnce and CI/CD, plus a downloadable cheat sheet.

  • CLI — building command-line and terminal (TUI) applications for Windows, macOS and Linux: terminals, TTYs and pseudo-terminals, escape sequences, the POSIX and Win32 process and console models, native programs in C, C++, Swift, Objective-C, .NET, Go, Rust and on the JVM and Kotlin, TUI libraries (Ratatui in depth, Bubble Tea, Textual, Terminal.Gui, ncurses and FTXUI), prompts, shells and completions, services, native binaries, signing, notarization and packaging, and testing, plus a downloadable cheat sheet.

  • Media Optimization — images and video in apps: Coil, Glide and Media3 on Android, Kingfisher, Nuke and AVFoundation on iOS, expo-image and react-native-video, Kotlin Multiplatform and Flutter, BlurHash placeholders, and device-side compression and background uploads, plus a downloadable cheat sheet.

  • Hybrid Apps — full references for Flutter with Dart and for Ionic with Capacitor (widgets, the native bridge and plugins, navigation, data, platform integration, testing, building and releasing, with a running example and cheat sheets), plus editors, native toolchains (Android Studio and Xcode), emulators and simulators, and Expo tooling for hybrid and cross-platform apps.
