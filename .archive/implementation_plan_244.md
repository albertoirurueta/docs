## Per-page contract (applies to every page task)

Start with `= Title`, `:description:`, `:keywords:`, then the part's disclaimer include (`data-science-disclaimer.adoc`,
`data-science-numpy-disclaimer.adoc`, `data-science-pandas-disclaimer.adoc` or `data-science-scikit-learn-disclaimer.adoc`);
intro stating the targeted versions and the check date; a detailed concept explanation covering every relevant option and
pitfalls; complete, runnable code examples (`[source,python]`, `bash`) each followed by a `Source:` link to the official
page it derives from; outdated book or older-tutorial statements as prose or tables with dates, never reproduced; unreleased
items labelled "upcoming"; figures and Mermaid diagrams from the issue's candidate list where they help (SVG named
`data-science-<part>-<topic>.svg`, quoted alt text when it contains a comma, `.Title` caption, one line at column 0);
inline code containing `->`, `=>`, `*`, `**`, `{`, `__`, `'` or `...` as a `` `+...+` `` passthrough (`pass:c[...]` if it
contains `+`); Mermaid stereotypes as `&lt;&lt;x&gt;&gt;`; no `NOTE`/`TIP`/`WARNING`/`CAUTION` admonitions; cross-links to
the existing Python, R, FastAPI, AI and database pages where the issue says; end with `== References` listing official
sources. Run the CLAUDE.md greps on each page as it is written.
