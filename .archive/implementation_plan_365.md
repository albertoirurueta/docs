## Per-page contract (applies to every page task)

Start with `= Title`, `:description:`, `:keywords:`, `include::partial$ui-ux-canva-disclaimer.adoc[]`; an intro with the
check date (2026-11-07, re-verified at writing time), the product(s), the plan(s) needed (Free / Pro / Business /
Enterprise / Education / Nonprofits; no prices), AI tier where relevant (Standard / Premium / Ultra) and GA / beta /
research-preview status; a detailed explanation (what and why, where it lives in the current editor with a figure, every
relevant option, shortcuts for macOS and Windows, desktop vs mobile differences, pitfalls, recent changes with dates);
numbered procedures on the *Bookshelf* launch scenario, each illustrated by a storyboard figure and followed by a
`Source:` link to the official page (`canva.com/help`, `canva.dev`, newsroom, Design School, Learn, pricing, policies;
third-party tools link their own official pages); code examples (`[source,typescript]`, `tsx`, `json`, `bash`,
`javascript`, `html`) only where the concept is code, each followed by its source link, with no real tokens
(`CANVA_CLIENT_ID` / `CANVA_CLIENT_SECRET` from the environment); outdated book statements as prose or table rows with
dates (never reproduced); conflicting or unverifiable facts resolved against the live page or omitted; the disclaimer is
the only admonition; figures are original SVGs named `ui-ux-canva-<page>-*.svg` (≥2 per page, ≥4 per ★ page, one
storyboard when a procedure is taught; PNG only for real screenshots of own *Bookshelf* designs or raster effects, no
Canva logo/icons/templates/stock/help-centre images, no imitation of Canva's identity) with descriptive alt text (quoted
when it contains a comma), a `.Title` caption, one line at column 0 with blank lines around; inline-code passthroughs
and Mermaid entity rules per `CLAUDE.md`; end with `== References` listing only the official sources (and, where used,
the books' publisher pages). Run the `CLAUDE.md` source greps on each page as it is written. Cross-page `xref:` targets
inside `ui-ux/canva/` may not exist until their group lands; xref errors are checked in the final verification group.
