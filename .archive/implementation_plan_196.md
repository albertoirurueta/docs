# Implementation Plan: Programming Languages Comparative

## Task summary

Source: GitHub issue #196
Base branch: main

Add one large comparative page, `modules/ROOT/pages/programming-languages/comparative.adoc` ("Programming Languages
Comparative"), under **Guides & References / Programming Languages**. It compares the 21 languages already documented on
the site (JavaScript, TypeScript, Python, Java, Kotlin, C, C++, Objective-C, C#, Visual Basic, Swift, PHP, Rust, Groovy,
Scala, Go, Ruby, Fortran, COBOL, R, MATLAB) plus extra languages (Pascal/Delphi, Perl, Ada, Lisp, Assembly, Dart, Julia,
Zig, Elixir, Lua, Haskell, Mojo, SQL, Bash), with the inclusion criteria stated. Metrics: popularity (current and over
time), ecosystem, performance (CPU, memory, energy, execution model), learning curve, security and safety, versatility
and platforms, job market, and other metrics. Every number carries a cited source and date. The page has time-series,
radar, bar and scatter SVG charts, a Bibliography, and a closing per-purpose recommendations section.

Choices made with the user:
- **Charts are generated static SVGs.** Raw CSV data and a dependency-free Node generator are committed under
  `scripts/language-charts/` so charts can be regenerated when new data is published. Output goes to
  `modules/ROOT/images/`. No new Antora extension, so no `package.json` or CI change. Mermaid is still allowed for
  simple diagrams such as a timeline, validated with `npm run validate:mermaid`.
- **Data policy: cite or mark n/a.** Only sourced values are shown. Gaps are shown as `n/a` or as an explicitly labelled
  estimate. Qualitative scores (learning curve and similar) follow a documented rubric on the page.

Open clarifications: none
