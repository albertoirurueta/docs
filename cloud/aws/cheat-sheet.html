A single-page index of quick back-links to every page in this section, grouped the same way as the section itself — handy for jumping straight to the topic you need instead of paging through the full navigation. The section overview is AWS (Amazon Web Services).

The downloadable PDF is a separate, single A4 page meant for printing. It states the version baseline this section targets (AWS CLI 2.37, CDK CLI 2.1143, SAM CLI 1.166 and Kubernetes 1.36 on EKS) and covers:

  • the account and identity hierarchy (organization, organizational unit, account, IAM Identity Center), Regions and Availability Zones, plus the core aws CLI essentials (configure sso, sso login, login, --query / --output, profiles);

  • the compute decision table across EC2, Lightsail, ECS Express Mode, ECS on Fargate, Lambda, EKS and App Runner, with the matching ECS and Fargate commands (task and execution roles, services, deployments), Lambda commands (functions, aliases, concurrency), ECR push and scan commands, and EKS create, access and upgrade commands (Auto Mode, access entries, Pod Identity, Gateway API);

  • S3 (storage classes, Block Public Access, presigned URLs, lifecycle, static hosting) and CloudFront (origin access control, cache policies, invalidation);

  • database create commands for RDS, Aurora, DynamoDB, DocumentDB, OpenSearch and ElastiCache, IAM authentication and managed master passwords, and an engine-to-AWS-option map;

  • Secrets Manager, Parameter Store and KMS (create, rotate, reference syntax) and AppConfig (profiles, deployments, the Kubernetes ConfigMap pattern);

  • networking essentials (VPC, subnets, gateways, security groups, endpoints), the load balancer decision tree, API Gateway types and key settings, and Client VPN and Site-to-Site VPN;

  • email with SES (identities, DKIM, sandbox exit, sending), monitoring (CloudWatch, Logs Insights, OpenTelemetry) and cost management (budgets, Cost Explorer, support plans); and

  • a retirements-and-renames strip with dates for services and versions being phased out.
