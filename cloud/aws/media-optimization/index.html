Media Optimization on AWS

This content was generated with the assistance of AI and should be verified against the official documentation before being relied on in production.

This sub-section covers image processing, video transcoding, covers and thumbnails, and streaming on AWS, with examples for the AWS CLI, Python, Node.js, Java and .NET. It uses the Bookshelf names of the AWS section (region us-east-1, account 111122223333 and the bookshelf-uploads bucket as placeholders) and is current as of 2026-10-07. The concepts and the self-hosted alternative are in Media Optimization for the backend.
