What’s New

This documentation was generated with the assistance of AI. Please report any inaccuracies.

1.12.0

  • ⚠️ Changed defaults: gravity-norm accelerometer calibrators (KnownGravityNorm, KnownBiasAndGravityNorm, KnownPosition, KnownBiasAndPosition and their robust variants) and norm-based magnetometer calibrators now default to commonAxisUsed = true (upper-triangular model, observable from norm constraints). The general mode is still available but is only defined up to a rotation. Easy gyroscope calibrators (EasyGyroscopeCalibrator, KnownBiasEasyGyroscopeCalibrator and their robust variants) now default to commonAxisUsed = false and estimateGDependentCrossBiases = false, as in the paper.

  • ⚠️ TriadStaticIntervalDetector now uses the variance-norm statistic of imu_tk instead of the standard-deviation norm, so the meaning of every thresholdFactor, instantaneousNoiseLevelFactor and absolute threshold changes (k_reference ~ k^2): DEFAULT_THRESHOLD_FACTOR goes from 2.0 to 4.0 and DEFAULT_INSTANTANEOUS_NOISE_LEVEL_FACTOR from 2.0 to 9.0. Detection uses a centred window, so status changes are delayed by half a window (getDetectionDelaySamples()).

  • 🐛 Fixed gyroscope sequence generation: sequences need a valid static interval on both sides, dynamic intervals around a too short static interval are joined, the "after" gravity vector is the average of the whole following static interval, and the initialization period is the first static average; flush() generates the last pending sequence when a recording ends at rest. MagnetometerMeasurementsGenerator only averages samples classified as static. Static averages now report the standard deviation of the mean (sigma/sqrt(N)), norm-based calibrators fit the squared norm with standard deviation 2*g*sigma, gyroscope sequences carry BodyKinematicsSequence.getGravityDirectionStandardDeviation(), the easy gyroscope calibrators use a three-component residual fitted with LevenbergMarquardtMultiVariateFitter, and windowed noise estimators use the number of samples actually in the window.

  • 🔗 These changes affect irurueta-navigation-inertial-extra (#29), whose optimizers depend on the detector factors and calibrator defaults.

  • ♻️ Updated internal dependencies: irurueta-numerical 1.7.1, irurueta-geometry 1.6.2 and irurueta-navigation 1.8.3. The easy gyroscope calibrators now use the JacobianEstimator of irurueta-numerical with a minimum step.

1.11.0

  • 🐛 The filtered estimators (INSLooselyCoupledKalmanFilteredEstimator, INSGNSSLooselyCoupledKalmanFilteredEstimator and INSGNSSTightlyCoupledKalmanFilteredEstimator) now follow Groves' reference algorithms: every IMU sample is integrated with the ECEF inertial navigation equations, and each Kalman epoch uses the INS-propagated solution as its predicted state and applies the closed-loop correction back to it.

  • 🐛 INSGNSSLooselyCoupledKalmanFilteredEstimator uses the GNSS least-squares solution as the Kalman measurement at its own timestamp; INSGNSSTightlyCoupledKalmanFilteredEstimator re-orthonormalises the attitude after each epoch, initialises the receiver clock offset and drift from the least-squares solution, and no longer loses IMU samples provided before the first GNSS measurements.

  • 🐛 ECEFKinematicsEstimator and ECIKinematicsEstimator are now the exact inverse of ECEFInertialNavigator / ECIInertialNavigator (Earth-rotation term and gravity evaluated at the start of the interval).

  • 🐛 The epoch gate of the filtered estimators accepts fixes/measurements arriving exactly one epoch interval after the previous epoch, and the first epoch propagates the covariance over the time elapsed since the first IMU sample.

  • ✨ New INSLooselyCoupledKalmanFilteredEstimator.updatePositionAndVelocity(…​) overloads, which provide a position and velocity fix and run a Kalman filter epoch with it.

  • ✨ New getLastKinematicsTimestamp() and getLastKinematicsTimestampAsTime(…​) on INSLooselyCoupledKalmanFilteredEstimator and INSGNSSTightlyCoupledKalmanFilteredEstimator.

  • ♻️ Behaviour change with unchanged signatures: update / updateBodyKinematics only integrate IMU samples and no longer run a Kalman epoch (their return value tells whether the sample was integrated); updateMeasurements runs the epoch itself. INSLooselyCoupledKalmanFilteredEstimator.propagate is deprecated in favour of updatePositionAndVelocity.

  • 📚 Documentation improvements: new calibration algorithms page (least squares, Levenberg-Marquardt, robust estimation and the Tedaldi et al. static-interval method), additional diagrams and equations across the calibration, estimator, navigator and WMM pages, and a more complete bibliography. No changes to library source.

1.10.2

  • ♻️ Updated internal dependencies to their latest patch versions: irurueta-numerical 1.6.1, irurueta-geometry 1.6.1, irurueta-units 1.4.1, irurueta-algebra 1.4.1 and irurueta-navigation 1.8.2. No changes to this library’s own source.

1.10.1

  • 🐛 Fixed flaky test assertions in magnetometer calibrator tests; no functional changes to library source.
