Worked example

The requests below create an index with an english-analyzed title, bulk-index three documents, and run a match query combined with a range filter. They were run against a single-node Elasticsearch 9 container with security disabled.

PUT /books
{
  "settings": { "number_of_shards": 1, "number_of_replicas": 0 },
  "mappings": { "properties": {
    "title": { "type": "text", "analyzer": "english" },
    "year":  { "type": "integer" } } }
}

POST /books/_bulk?refresh=true
{ "index": { "_id": "1" } }
{ "title": "The Left Hand of Darkness", "year": 1969 }
{ "index": { "_id": "2" } }
{ "title": "A Wizard of Earthsea", "year": 1968 }
{ "index": { "_id": "3" } }
{ "title": "Darkness at Noon", "year": 1940 }

GET /books/_search?filter_path=hits.total,hits.hits._id,hits.hits._source
{
  "query": { "bool": {
    "must":   { "match": { "title": "darkness" } },
    "filter": { "range": { "year": { "gte": 1960 } } } } }
}

Both titles match "darkness", but the filter drops the 1940 book, so one hit remains:

{
  "hits": {
    "total": { "value": 1, "relation": "eq" },
    "hits": [
      { "_id": "1", "_source": { "title": "The Left Hand of Darkness", "year": 1969 } }
    ]
  }
}

A metric aggregation over the same index, GET /books/_search?size=0&filter_path=aggregations with { "aggs": { "avg_year": { "avg": { "field": "year" } } } }, returns {"aggregations":{"avg_year":{"value":1959.0}}}.
