Database IDEs & Tools

This content was generated with the assistance of AI and should be verified against the official documentation before being relied on in production.

This page lists the graphical clients and tools commonly used to explore schemas, run queries and inspect data across the database engines covered on this site. Pick a cross-engine client when you work with several engines, and the engine’s own tool when you need its full feature set.

Cross-engine clients

  • DBeaver — a universal database client with support for many relational and non-relational engines.

  • DataGrip — the JetBrains database IDE with smart SQL completion and refactoring.

  • Sequel Ace — a macOS client for MySQL and MariaDB databases.

  • TablePlus — a native client for several relational and key-value engines.

SQL

  • pgAdmin — the administration and development platform for PostgreSQL.

  • MySQL Workbench — the visual tool for designing, querying and administering MySQL.

Azure Data Studio has been retired; see the official announcement for details and recommended alternatives.

Document

  • MongoDB Compass — the graphical client for exploring and querying MongoDB. See MongoDB Drivers and Tooling for details.

Key-value

  • Redis Insight — a visual tool for browsing keys and running commands against Redis.

Graph

  • Neo4j Browser — the query console for running Cypher and visualizing results.

  • Neo4j Bloom — a visual exploration tool for Neo4j graphs.

Search

  • Kibana Dev Tools — a console for sending requests to Elasticsearch from Kibana.

Vector

  • Qdrant dashboard — the built-in web interface for inspecting collections and running queries in Qdrant.
