Worked example

The commands below create a core with the default configset, index three documents with a hard commit, and query them. They were run against the solr:9 Docker image.

docker run -d --name solr -p 8983:8983 solr:9 solr-precreate books

curl "http://localhost:8983/solr/books/update?commit=true" \
  -H 'Content-Type: application/json' \
  -d '[{"id":"1","title":"The Left Hand of Darkness"},
       {"id":"2","title":"A Wizard of Earthsea"},
       {"id":"3","title":"Darkness at Noon"}]'

curl --get "http://localhost:8983/solr/books/select" \
  --data-urlencode 'q=title:darkness' \
  --data-urlencode 'fl=id,title' \
  --data-urlencode 'sort=id asc' \
  --data-urlencode 'indent=true'

The query matches the two titles containing "darkness" and returns this response (header trimmed). The default configset guesses field types, so title comes back as a multi-valued array:

{
  "response":{
    "numFound":2,
    "start":0,
    "numFoundExact":true,
    "docs":[{
      "id":"1",
      "title":["The Left Hand of Darkness"]
    },{
      "id":"3",
      "title":["Darkness at Noon"]
    }]
  }
}
