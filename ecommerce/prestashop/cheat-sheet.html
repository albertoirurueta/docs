Cloud deployment

The summary printed in the PDF for running PrestaShop on many pods in the cloud on Amazon EKS (checked on 2026-10-29); each row is explained on the pages above.

Topic Rule

Database

RDS for MySQL 8.4 (Aurora MySQL 3); parameters.php reads the environment; TLS through a DbPDO override; separate migration user; checked on PrestaShop 9.2.0 and 8.2.8.

State placement

Shared EFS for img/, upload/, download/ and the theme settings; var/cache and var/logs per pod; sessions in Valkey (session.save_path); SQL cache on Memcached (CacheMemcached); PS_SMARTY_LOCAL 1; the same cookie keys on every pod; admin folder renamed at build; code and modules baked into the image.

Cron

One CronJob (pocketcoffee-cron, concurrencyPolicy: Forbid) calling module cron URLs or bin/console commands; web pods schedule nothing.

Release steps

Pre-upgrade Job pocketcoffee-migrate: prestashop:module upgrade <name>; a core upgrade is an image rebuild plus a database upgrade; cache:warmup --env=prod per pod; maintenance mode; RDS snapshot first.

Key commands

php bin/console prestashop:config get PS_SSL_ENABLED --env=prod, prestashop:module:list, cache:warmup --env=prod, kubectl -n pocketcoffee rollout status deployment/pocketcoffee-web, helm upgrade pocketcoffee ./pocketcoffee-prestashop.
