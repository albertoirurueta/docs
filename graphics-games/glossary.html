Glossary

This content was generated with the assistance of AI and should be verified against the official documentation before being relied on in production.

This glossary lists 139 terms used by the general pages of the Graphics & Games section. Each entry gives a short definition and links to the page that explains the concept in depth. Terms are sorted alphabetically.

Term Meaning Explained on

6DoF

Six degrees of freedom: three of position and three of orientation.

Augmented and Mixed Reality Basics

Acceleration structure

A GPU-built tree of geometry, usually a BVH, that ray tracing traverses to find the nearest hit quickly.

Advanced Pipeline Stages

Accessor

A glTF object that describes how to read typed values (component type, count, offset) out of a buffer view.

Scene Graphs and Asset Formats

Accumulator

The leftover simulation time carried between frames in a fixed-timestep loop.

The Game Loop and Frame Timing

Alpha blending

Combining a new fragment with the colour already in the target using the fragment alpha as a weight.

Transparency, Blending and Post-processing

Alpha to coverage

Turning a fragment alpha into a multisample coverage mask so cut-outs such as leaves anti-alias.

Transparency, Blending and Post-processing

Ambient occlusion

An approximation of how much ambient light reaches a point, darkening creases and contact areas.

Shadows and Global Illumination

Anchor

A pose that an AR system keeps fixed to the real world while its tracking estimate improves.

Augmented and Mixed Reality Basics

ANGLE

A library that implements OpenGL ES (and EGL) on top of Direct3D, Vulkan, Metal and OpenGL.

Cross-Platform Translation Layers

Anisotropic filtering

Texture filtering that takes more samples along the direction of a stretched pixel footprint to keep oblique surfaces sharp.

Textures, Sampling & Mipmaps

Archetype

In an ECS, the set of component types an entity has; entities of one archetype are stored together.

Entity Component System

Axis-angle

A rotation described by a unit axis and an angle around it.

Rotations & Quaternions

Back-face culling

Discarding triangles whose winding shows their back to the camera.

Meshes & Vertex Data

Bind group

The WebGPU object that groups the buffers, textures and samplers a pipeline reads.

Explicit vs Implicit Graphics APIs

Blinn-Phong

A specular model that uses the half vector between light and view directions.

Lighting & Shading Models

Bloom

A post-process that blurs bright areas and adds them back so highlights glow.

Transparency, Blending and Post-processing

BRDF

The bidirectional reflectance distribution function: how much light a surface reflects from one direction to another.

Lighting & Shading Models

Broad phase

The collision stage that quickly rules out pairs of objects that cannot touch.

Physics, Audio and Input Basics

BVH

Bounding volume hierarchy: a tree of nested bounding boxes used to accelerate ray queries and culling.

Advanced Pipeline Stages

Cascaded shadow maps

Several shadow maps for consecutive slices of the view frustum, trading resolution against distance.

Shadows and Global Illumination

Choreographer

The Android API that delivers a callback in step with the display refresh.

The Game Loop and Frame Timing

Clip space

The 4D space that vertex shaders output to, before the perspective divide.

Coordinate Spaces and Transforms

Clipping

Removing or cutting the parts of primitives that lie outside the view volume.

The Rendering Pipeline

Collider

A simple shape attached to an object that the physics engine uses to detect contact.

Physics, Audio and Input Basics

Command buffer

A recorded list of GPU commands that is submitted to a queue for execution.

GPU Architecture Basics

Compute shader

A shader that runs outside the graphics pipeline, as general parallel work over a grid of threads.

Advanced Pipeline Stages

Cube map

A texture with six square faces addressed by a direction vector.

Textures, Sampling & Mipmaps

Culling

Skipping objects or primitives that cannot contribute to the image, for example outside the view frustum.

Scene Graphs and Asset Formats

Deferred shading

Rendering surface attributes to a G-buffer first and lighting them in a later pass.

Transparency, Blending and Post-processing

Delta time

The time elapsed since the previous frame, used to scale movement.

The Game Loop and Frame Timing

Depth bias

A small offset applied to shadow-map depth comparisons to avoid self-shadowing.

Shadows and Global Illumination

Depth buffer

A per-pixel record of the nearest surface, used by the depth test to resolve visibility.

The Rendering Pipeline

Descriptor set

The Vulkan object that binds resources to a pipeline layout.

Explicit vs Implicit Graphics APIs

Display P3

A wide-gamut RGB colour space used by Apple devices and many HDR displays.

Color Spaces, HDR and Tone Mapping

Draco

A geometry compression format used by the glTF extension KHR_draco_mesh_compression.

Scene Graphs and Asset Formats

Draw call

One command that asks the GPU to render a set of vertices with the current state.

Performance and Profiling

Draw-call batching

Merging draw calls that share state to reduce CPU cost.

Performance and Profiling

Early-Z

A hardware optimisation that rejects fragments by depth before running the fragment shader.

The Rendering Pipeline

ECS

Entity component system: an architecture that stores data as components processed by systems.

Entity Component System

Entity

In an ECS, an identifier that groups components and carries no data of its own.

Entity Component System

Euler angles

A rotation described by three successive angles about coordinate axes.

Rotations & Quaternions

Fixed timestep

A simulation that always advances by the same step, independent of the frame rate.

The Game Loop and Frame Timing

Forward+ shading

Forward shading with a per-tile list of lights so many lights can be shaded cheaply.

Transparency, Blending and Post-processing

Fragment

A candidate pixel produced by rasterisation, before the per-fragment tests decide whether it is written.

The Rendering Pipeline

Fragment shader

The program that computes the colour of each fragment; called a pixel shader in Direct3D.

The Rendering Pipeline

Frame pacing

Delivering frames to the display at even intervals.

The Game Loop and Frame Timing

Frame time

The duration of one frame, the unit used for budgeting instead of frames per second.

Performance and Profiling

Frames in flight

Frames the CPU has recorded while the GPU is still working on earlier ones.

Explicit vs Implicit Graphics APIs

Fresnel

The increase in reflectivity at grazing angles, approximated in real time by the Schlick formula.

Lighting & Shading Models

Frustum

The truncated pyramid of space that a perspective camera sees.

Vectors, Matrices and Homogeneous Coordinates

FXAA

Fast approximate anti-aliasing: an edge-smoothing post-process on the final image.

Transparency, Blending and Post-processing

G-buffer

The set of render targets that hold surface attributes in deferred shading.

Transparency, Blending and Post-processing

Game engine

A framework that adds an editor, asset pipeline, physics, audio, scripting and packaging above a graphics API.

Graphics APIs vs Game Engines

Gaussian splatting

A scene representation made of many oriented, soft 3D Gaussians rendered by splatting.

Scene Graphs and Asset Formats

Geometry shader

An optional stage that can emit new primitives; usually avoided for performance.

Advanced Pipeline Stages

Gimbal lock

The loss of one degree of freedom when two Euler rotation axes line up.

Rotations & Quaternions

GLB

The single-file binary container form of glTF.

Scene Graphs and Asset Formats

glTF

The Khronos transmission format for 3D scenes (version 2.0), also standardised as ISO/IEC 12113.

Scene Graphs and Asset Formats

Gouraud shading

Lighting computed per vertex and interpolated across the triangle.

Lighting & Shading Models

GPU timer

A query that measures how long the GPU spent on a range of commands.

Performance and Profiling

Handedness

Whether the coordinate axes follow the right-hand or left-hand rule.

Coordinate Spaces and Transforms

HDR

High dynamic range: image data and displays that go beyond the 0 to 1 range of standard output.

Color Spaces, HDR and Tone Mapping

Hit test

A ray cast from the screen into the tracked world that returns planes or feature points.

Augmented and Mixed Reality Basics

HLSL

The High-Level Shading Language of Direct3D.

Shading Languages Landscape

Homogeneous coordinates

Coordinates with an extra component w that lets one matrix express translation and projection.

Vectors, Matrices and Homogeneous Coordinates

Image-based lighting

Lighting a surface from an environment image such as a cube map.

Lighting & Shading Models

Immediate mode

An API in which the application issues drawing commands every frame.

Index buffer

A buffer of integers that selects vertices to form primitives, so shared vertices are stored once.

Meshes & Vertex Data

Input assembly

The stage that reads vertex and index buffers and builds primitives.

The Rendering Pipeline

Instancing

Drawing many copies of one mesh in a single call, each with its own per-instance data.

Meshes & Vertex Data

Interleaved vertex buffer

A layout where all attributes of one vertex are adjacent in memory.

Meshes & Vertex Data

Interpolation (game loop)

Blending between the last two simulation states to draw a position between steps.

Interpolation (render)

Blending a per-vertex value across a primitive for each fragment, perspective-correct in 3D.

KTX 2.0

The Khronos texture container that holds mip chains and Basis Universal or GPU-compressed data.

Textures, Sampling & Mipmaps

Lambert

A diffuse model where brightness is proportional to the cosine of the angle to the light.

Lighting & Shading Models

Level of detail

Using a cheaper version of a model or texture as it gets farther away.

Meshes & Vertex Data

Linear colour

Colour values proportional to physical light intensity, the space in which lighting maths is correct.

Look-at

A function that builds a view or rotation from an eye position, a target and an up direction.

Rotations & Quaternions

Mesh shader

A compute-like stage that generates meshlets and replaces input assembly and vertex shading.

Advanced Pipeline Stages

Meshlet

A small cluster of triangles processed together by a mesh shader.

Advanced Pipeline Stages

Metallic-roughness

The glTF PBR material model with base colour, metallic and roughness parameters.

Lighting & Shading Models

Mipmap

A pre-filtered, smaller version of a texture; the full set is called a mip chain.

Mixed reality

Experiences where virtual objects are anchored in and interact with the real environment.

Model matrix

The matrix that moves an object from its local space to world space.

MoltenVK

MSAA
