Graphics & Games

This content was generated with the assistance of AI and should be verified against the official documentation before being relied on in production.

Every image on a screen, from a spinning cube in a browser to a game with millions of triangles per frame, is drawn by a GPU that is driven through software. This section explains how that software is layered and how to use it. It starts with the ideas that every graphics and game library shares: the GPU, the rendering pipeline, the mathematics of transforms and rotations, meshes, textures, lighting, colour, shading languages, scene graphs, the game loop and the basics of augmented reality. Later parts of the section go deep into six libraries: OpenGL, WebGL, Metal, Vulkan, Unity and Unreal Engine.

The overview defines graphics APIs, rendering frameworks and game engines, gives the targeted versions, the learning path and reading order through the general pages, the shared Bookshelf scene and assets, the cheat sheets, and a concept-to-page map and coverage map of every page of the section.

Sections

  • Overview — graphics APIs and game engines, targeted versions, learning path, reading order, cheat sheets, the shared Bookshelf scene and a concept-to-page map of the general pages.

  • Comparison — the six libraries side by side with dated metrics, scores and recommendations by purpose.

  • OpenGL — desktop OpenGL 4.6, OpenGL ES 3.2, GLSL and EGL, from a first triangle to a small game, and how to port to Vulkan, Metal and WebGPU.

  • WebGL — 3D graphics in the browser, the three.js framework on top of it, and WebGPU as the successor API.

  • Metal — Apple’s graphics and compute API (Metal 4, MSL 4.1) for iOS, iPadOS, macOS, tvOS and visionOS.

  • Vulkan — the explicit, cross-platform Khronos API (Vulkan 1.4) for desktop, mobile and embedded GPUs.

  • Unity — a general-purpose game engine with C# scripting and the Universal Render Pipeline (Unity 6.3 LTS).

  • Unreal Engine — a game engine with C++ and Blueprint scripting, Nanite and Lumen (Unreal Engine 5.8).
