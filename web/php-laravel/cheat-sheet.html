Worked example

The plain PHP strip in practice: a PDO prepared statement with named placeholders and htmlspecialchars() on output. The hostile title is stored as typed and escaped only when printed. It ran on PHP 8.4 with SQLite in memory.

<?php
declare(strict_types=1);

$pdo = new PDO('sqlite::memory:', options: [PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION]);
$pdo->exec('CREATE TABLE books (id INTEGER PRIMARY KEY, title TEXT NOT NULL)');

$stmt = $pdo->prepare('INSERT INTO books (title) VALUES (:title)');
foreach (['Dune', "O'Reilly <script>alert(1)</script>"] as $title) {
    $stmt->execute(['title' => $title]);
}

$find = $pdo->prepare('SELECT id, title FROM books WHERE title LIKE :q ORDER BY id');
$find->execute(['q' => '%e%']);

foreach ($find->fetchAll(PDO::FETCH_ASSOC) as $row) {
    printf("<li>#%d %s</li>\n", $row['id'], htmlspecialchars($row['title'], ENT_QUOTES | ENT_SUBSTITUTE, 'UTF-8'));
}

Output:

<li>#1 Dune</li>
<li>#2 O&#039;Reilly &lt;script&gt;alert(1)&lt;/script&gt;</li>
