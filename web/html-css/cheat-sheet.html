HTML & CSS Cheat Sheet

This content was generated with the assistance of AI and should be verified against the official documentation before being relied on in production.

A single-page, color-coded summary of the most commonly used HTML5 elements and CSS techniques covered by this reference — handy for quick memorization or as a printable desk reference. Each box groups one topic (HTML5 structure, the box model, Flexbox/Grid basics, selectors and specificity, transitions and animation, and form accessibility) with its most essential syntax and a compact example. The Selectors and specificity box also covers .a.b (one element with both classes) versus .a .b (a descendant); see Class selectors compared for the full explanation.

For the full syntax, every option, and additional examples, see the dedicated pages: HTML5 Structure and Semantics, SEO, Layout: Float, Flexbox & Grid, Positioning, The Box Model, Selectors & Specificity, Variables & Media Queries, Theming, Transitions, Animations, SVG Styling & Animation, Forms, Forms: Accessibility & Validation, Performance: Loading, Performance: Build Optimization, Appendix: HTML Elements, and Appendix: CSS Properties.

Worked example

A small card that combines the semantic structure, the box model, Flexbox, a custom property, a transition and a focus style from the boxes above:

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Card</title>
  <style>
    :root { --accent: #0b5fff; }
    * { box-sizing: border-box; }
    .cards { display: flex; flex-wrap: wrap; gap: 1rem; padding: 1rem; }
    .card { flex: 1 1 14rem; padding: 1rem; border: 2px solid var(--accent); border-radius: 8px; }
    .card a { color: var(--accent); transition: color 0.2s ease-in-out; }
    .card a:hover, .card a:focus-visible { color: #b00020; }
  </style>
</head>
<body>
  <main class="cards">
    <article class="card">
      <h2>First card</h2>
      <p>Cards share the row and wrap when it is too narrow.</p>
      <a href="#first">Read more</a>
    </article>
    <article class="card">
      <h2>Second card</h2>
      <p>The border stays inside the width thanks to border-box.</p>
      <a href="#second">Read more</a>
    </article>
  </main>
</body>
</html>
