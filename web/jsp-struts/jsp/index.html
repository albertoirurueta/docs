JSP, EL & JSTL

This content was generated with the assistance of AI and should be verified against the official documentation before being relied on in production.

Part I of the section covers Jakarta Pages 4.0, Jakarta Expression Language 6.0 and Jakarta Standard Tag Library 3.0 (API 3.0.2, implementation 3.0.1) on Jakarta Servlet 6.1, running on Apache Tomcat 11.0.26 and Java 21; the versions were verified on 2026-10-08. It builds bookshelf-jsp, the servlet and JSP variant of the Bookshelf scenario described on the section landing page, and it needs only the servlet foundations of Servlet Fundamentals. Part II, Apache Struts, uses the same pages as the view layer of its actions.

Figure 1. Part I builds the left-hand variant of the Bookshelf: a front servlet forwards to JSP views that render with EL and JSTL

What Part I covers

JSP is the oldest part of the stack and the part that every Java web framework of its generation still uses as a view. Part I explains how a page becomes a servlet, every element of its syntax, the Expression Language that replaced scriptlets, the five tag libraries of JSTL, and how to write your own tags. It then builds applications from those parts: a Model 2 application with a front controller, forms with validation and sessions, Spring MVC with JSP views, Jasper configuration for development and production, security and testing. The status of each technology is stated on its page: scripting elements and the SQL and XML libraries of JSTL are legacy, jsp:plugin and isThreadSafe are removed, and the EL and JSTL libraries are the current way to write a view.

Everything from Jakarta EE 9 on uses jakarta.* packages, and Tags 3.0 renames the tag library URIs to jakarta.tags.* (jakarta.tags.core, jakarta.tags.fmt, jakarta.tags.functions, jakarta.tags.sql, jakarta.tags.xml). Maven coordinates

The container supplies the Servlet, Pages and EL APIs, so a WAR compiles against them with provided scope. Tomcat does not ship JSTL, so the API and the implementation are added with default scope and travel inside the WAR.

The specification page of Pages lists its API as jakarta.pages:jakarta.pages-api, which does not exist on Maven Central; the artifact that does is jakarta.servlet.jsp:jakarta.servlet.jsp-api, as above. The JSTL implementation is still 3.0.1 (2023-01-19).

Reading order

The pages build on each other; read them in this order the first time and use them as a reference afterwards.

  1. Core JSP: lifecycle and translation first, then syntax, directives, implicit objects and scopes, scripting elements (to read legacy code), standard actions, composition, errors, encoding, JSP documents and configuration.

  2. Expression Language: the basics, then operators, lambdas and streams, static access, records and Optional, and configuration.

  3. JSTL: core, iteration, URLs, i18n, formatting, functions and the legacy SQL and XML libraries.

  4. Custom tags: simple tags, classic tags, the TLD and EL functions, and tag files.

  5. Building applications: Model 2 with servlets, forms and sessions, Spring MVC, Jasper, security, and testing and debugging.
