Atmosphere

This content was generated with the assistance of AI and should be verified against the official documentation before being relied on in production.

Atmosphere is a Java framework for real-time web applications whose defining idea is that the application code does not know which transport a client uses. A class annotated with @ManagedService receives text from WebSocket, Server-Sent Events (SSE), HTTP streaming and long-polling clients through the same @Message method, and a Broadcaster delivers a message to every subscribed connection in the format its transport needs. The client library, atmosphere.js, opens the best transport the network allows and falls back when a proxy or firewall refuses the WebSocket upgrade.

This page was checked on 2026-10-24. The baseline is Atmosphere 4.0.76 (Maven Central and the GitHub release of 2026-10-22), which needs JDK 21 and a Servlet 6.0 container (Jakarta EE 10), with atmosphere.js 5.0.52, the Spring Boot starter built against Spring Boot 4.1.1 (the examples were run on 4.1.2 with Tomcat 11.0.27), the Quarkus extension built against Quarkus 3.39.5, and Jetty 12.1.12 as the embedded container. The Jakarta WebSocket API that Atmosphere compiles against is 2.2.0. Every example below was built and run: the Java servers in Docker containers (maven:3.9.16-eclipse-temurin-21 to build, eclipse-temurin:21.0.12.1_1-jre to run), the clients with Node.js 24.21.0, ws 8.22.0 and atmosphere.js 5.0.52, and the browser checks in headless Chrome 155.0.8059.85.

How the three applications of this section use it:

  • Chatterbox is the natural fit. Rooms are broadcasters, presence and history exist as a Room API, and the fallback transports keep the chat working behind proxies that refuse WebSocket. This page implements the complete Chatterbox wire protocol of Message Design and Serialization on an Atmosphere endpoint.

  • Huddle can use an Atmosphere endpoint as its signalling channel: offers, answers and ICE candidates are small JSON messages sent to one participant with Broadcaster.broadcast(message, resource). Atmosphere carries no media, so the audio and video still go through WebRTC (see Signaling and Perfect Negotiation).

  • Pixel Arena is a poor fit. Atmosphere delivers text through a pub/sub abstraction and has no tick loop, snapshot or interpolation support. Binary frames exist (@WebSocketHandlerService), but a game server is better served by the stacks in Choosing a WebSocket Stack. Use Atmosphere for the lobby and chat around the game if the rest of the system is Java.

What Atmosphere is, and where it came from

The core types are small. AtmosphereServlet boots an AtmosphereFramework. Each connection becomes an AtmosphereResource, a transport-neutral handle with write, suspend, resume and close. A Broadcaster is a named pub/sub channel that holds a set of resources. An AtmosphereHandler receives requests and state changes, and @ManagedService is a convenience that generates the handler from annotations. AtmosphereInterceptor classes sit between the transport and the handler like servlet filters.

The project is old by web standards. Maven Central has atmosphere-runtime 1.0.0 from September 2012 and 2.0.0 from September 2013, the release that introduced the annotation model used here. The 3.x line followed (3.0.0 in February 2022, the last 3.0.13 in October 2024), and 2.7.15 was still published in October 2024. 4.0.0 was released on 2026-02-20 as a JDK 21 rewrite, and 4.0.76 is the current patch release. The documentation moved from atmosphere.github.io/docs/ to async-io.live/docs/, and the old address now answers with a permanent redirect.

Atmosphere 4 also repositions itself as a runtime for AI agents (annotations such as @Agent and @AiEndpoint, MCP, A2A and AG-UI support, a dozen pluggable model runtimes). This page covers only the real-time core, which those features build on. The agent side belongs with the AI agents section of this site and with the Atmosphere documentation.

The annotation model

@ManagedService turns a plain class into an endpoint. It has seven attributes:

Attribute Meaning

path

URL pattern, with template variables such as /chat/{room}. Each distinct path value gets its own Broadcaster, named after the path.

listeners

AtmosphereResourceEventListener classes that see transport-level events.

broadcaster

the Broadcaster class. DefaultBroadcaster is the default and supports every transport; SimpleBroadcaster is lighter and meant for WebSocket-only use; RedisBroadcaster and KafkaBroadcaster cluster (see below).

interceptors

interceptors appended to the default set (lifecycle, message-size tracking, heartbeat, suspend tracking).

atmosphereConfig

key=value strings handed to the handler, for example the maximum inactivity time of a connection.

broadcasterCache

cache that replays missed messages to a reconnecting client; UUIDBroadcasterCache by default.

broadcastFilters

filters that transform or drop a message before delivery.

Methods carry the lifecycle annotations:

Annotation Called when

@Ready

the connection is suspended and can receive messages. It may return a value that goes only to the connecting client.

@Message

a message arrives. A returned value is broadcast to every subscriber of the endpoint’s Broadcaster, unless @DeliverTo narrows it to RESOURCE (the sender) or widens it to ALL broadcasters.

@Disconnect

the connection closed. AtmosphereResourceEvent.isClosedByClient() and isCancelled() tell a clean close from a lost connection.

@Heartbeat

the client sent a heartbeat.

@Resume

a suspended request resumed, typical for long-polling.

@Get, @Post, @Put, @Delete

an HTTP request arrives, before the connection is suspended.

Two details cost time in practice. First, by default Atmosphere creates a new instance of the class for every connection; @Singleton (the Atmosphere annotation in org.atmosphere.config.service, not jakarta.inject.Singleton) makes one instance serve all of them, which is what an endpoint that keeps shared state needs, and then the state must be thread-safe. Second, @Message accepts either one parameter (the decoded message) or two (the AtmosphereResource first, then the message). The two-parameter form, visible in the 4.0.76 sources of ManagedAtmosphereHandler, is the way to know which connection sent a frame in a singleton; a third parameter is ignored with a warning.

Injection uses jakarta.inject.Inject and Named: @Inject @Named("/chat") Broadcaster gives the endpoint’s own broadcaster, @Inject BroadcasterFactory the registry, and AtmosphereResource and AtmosphereResourceEvent the current connection and event. Encoders and decoders (Encoder<T, String>, Decoder<String, T>) turn the wire text into domain objects and back, and are injectable too.

Broadcasters

A Broadcaster is created per path by @ManagedService, or on demand from the BroadcasterFactory:

Broadcaster API in a nutshell
Broadcaster room = factory.lookup("/rooms/general", true);   // find or create by id
room.addAtmosphereResource(resource);                        // subscribe a connection
room.broadcast(message);                                     // everyone subscribed
room.broadcast(message, resource);                           // one connection
room.broadcast(message, someSetOfResources);                 // a subset
room.removeAtmosphereResource(resource);                     // unsubscribe

Source: Atmosphere tutorial: Broadcaster and Pub/Sub

Broadcasts are asynchronous and return a Future<Object>. In Atmosphere 4 delivery runs on virtual threads and DefaultBroadcaster uses ReentrantLock rather than synchronized, so a broadcast to thousands of subscribers does not pin carrier threads. Order is preserved: broadcast("A") then broadcast("B") reach every client as A then B, unless the init parameter org.atmosphere.cpr.Broadcaster.supportOutOfOrderBroadcast is set to true. The factory is thread-safe and can be called from a scheduled task, a Kafka consumer or a REST controller, which is how server-side code pushes to browsers. factory.findBroadcaster(id) returns an Optional and is preferred over lookup.

Three companions matter:

  • BroadcasterCache keeps messages for a client that briefly disconnected and replays them when the same resource uuid returns. It is a per-node, in-memory buffer, not a shared log.

  • BroadcastFilter (and PerRequestBroadcastFilter for per-subscriber decisions) transforms or drops a message. On the managed path the encoder runs first, so a filter receives a RawMessage or the encoded String, not your domain type. A filter that only tests instanceof ChatMessage compiles, registers and never fires.

  • RawMessage wraps content that is already encoded. A plain object broadcast through a Broadcaster is, in 4.0.76, passed through the endpoint’s @Message pipeline for each subscriber (the source logs a recursion warning for it), so broadcast pre-encoded JSON as new RawMessage(json). The Chatterbox server below does so for every fan-out.

A Broadcaster also has a scope (REQUEST, APPLICATION by default, VM) and scheduling helpers (delayBroadcast, scheduleFixedBroadcast).

Transports and the fallback chain

The same endpoint serves several transports. Which one a connection uses is decided by the client:

Transport How it works Direction

WebSocket

one full-duplex TCP connection after an HTTP upgrade

both

SSE

a long-lived text/event-stream response; the client sends with ordinary POST requests

server to client

Streaming

the server keeps writing into an open HTTP response

server to client

Long-polling

the client asks, the server holds the request until data exists, answers, and the client asks again

repeated request and response

WebTransport over HTTP/3

bidirectional QUIC streams through a Netty sidecar on a UDP port; optional and off by default

gRPC

atmosphere.js implements the client side. It is told a primary transport and one fallbackTransport, and the fallback is single-level and client-driven: when the primary fails, the client fires transportFailure once and continues with the fallback.

flowchart TD A["subscribe with transport websocket and fallbackTransport sse"] --> B{"WebSocket upgrade succeeds?"} B -- yes --> W["stay on WebSocket"] B -- "no: 400 from a proxy, blocked Upgrade, 1006" --> T["transportFailure handler fires"] T --> F["open the fallback: sse, streaming or long-polling"] F --> G{"fallback succeeds?"} G -- yes --> O["open handler reports the fallback transport"] G -- no --> E["error handler"]

The client attaches protocol parameters to every request, as headers or query parameters: X-Atmosphere-Transport (websocket, sse, long-polling, streaming, webtransport or close), X-Atmosphere-tracking-id (zero on the first request; the server assigns a uuid), X-Atmosphere-Framework (the client version) and, when the client enables the protocol handshake, X-atmo-protocol=true. With TrackMessageSizeInterceptor, which is part of the managed-service defaults, each message written to an HTTP transport is prefixed with its length so that several messages in one chunk can be split again. WebTransport is optional: the project’s reference describes a Netty HTTP/3 sidecar enabled with atmosphere.web-transport.enabled=true in Spring Boot, and a client that asks for transport: 'webtransport' with a WebSocket fallback. The examples on this page do not enable it; the standard itself is covered in WebTransport and Media over QUIC.

The fallback transports are the reason Atmosphere needs sticky sessions behind a load balancer: a long-polling or streaming client talks to the node that holds its suspended request, whereas a WebSocket connection is pinned by the connection itself. See Proxies, Load Balancers and Deployment. For the HTTP side of these techniques in general, Server-Sent Events and Long Polling has the protocol detail.

Chatterbox on Atmosphere

The first complete example is the Chatterbox server. It implements protocol v1 of Message Design and Serialization: the envelope with v, type, id, room, ts and payload, the hello handshake with a one-time ticket, join and leave, message, edit, react, typing, receipt, presence and history, the ack and error answers with the protocol’s error codes, per-room seq numbers, idempotent client ids, the 20 per second token bucket, the close codes 4401, 4403, 4408, 4426 and 4429, and the Origin allow-list. It is a single @ManagedService on /ws: one socket per user and many rooms over it, the way the other servers in this section work. Each room is a Broadcaster named /rooms/<room>, so fan-out is broadcast and the typing, presence and receipt envelopes that must skip the sender use broadcast(message, subset).

Design

  • State. A Conn per connection (keyed by the resource uuid), a Room per room (sequence counter, event log for replay, message index for history, reaction set, member connections), and a per-user cache of the last 1000 acks for idempotency. All of it lives in memory in one JVM; the clustering section explains what changes with several nodes.

  • Threading. Container threads call the endpoint concurrently, so the shared maps are concurrent and each room’s sequence assignment, log append and broadcast happen under that room’s monitor. That makes broadcast order equal to seq order.

  • Timers. A single scheduled executor closes a connection that did not say hello within 5 seconds (4408), pings every connection with WebSocket.sendPing and closes one that was silent for twice the heartbeat (4408), and broadcasts offline presence after the grace period.

  • Replies. Answers go to the sending connection with AtmosphereResource.write(String), and fan-out goes through the room Broadcaster with RawMessage.

Server code

Main starts Jetty with the Jakarta WebSocket container and registers AtmosphereServlet. The order matters: the WebSocket container must be configured before the Atmosphere servlet initialises, or the JSR 356 endpoints cannot be added. The init parameters are the production-relevant part of this class:

  • useWebSocket=true and maxTextMessageSize=16384 enable the transport and cap a frame at the protocol’s limit.

  • requireSameOrigin=false switches off Atmosphere’s built-in same-origin check, replaced here by an explicit allow-list (the security section explains the default).

  • HeartbeatInterceptor.heartbeatFrequencyInSeconds=0 turns off Atmosphere’s own heartbeat. With the default of 60 seconds the server writes a padding text frame (the character X) to every WebSocket client, which a JSON-only protocol cannot parse. This was reproduced by setting the interval to 2 seconds and reading the frames.

  • allow1005disconnectEvent=true makes a close frame without a status code fire @Disconnect (see the pitfalls).

  • cors.allowedOrigins gives the CORS interceptor the same allow-list; without it the interceptor logs that it is "echoing all Origin headers".

Main.java
package example.chatterbox;

import org.atmosphere.cpr.ApplicationConfig;
import org.atmosphere.cpr.AtmosphereServlet;
import org.eclipse.jetty.ee10.servlet.ServletContextHandler;
import org.eclipse.jetty.ee10.servlet.ServletHolder;
import org.eclipse.jetty.ee10.websocket.jakarta.server.config.JakartaWebSocketServletContainerInitializer;
import org.eclipse.jetty.server.Server;
import org.eclipse.jetty.server.ServerConnector;

public final class Main {
    public static void main(String[] args) throws Exception {
        int port = Integer.parseInt(System.getenv().getOrDefault("PORT", "8080"));
        Server server = new Server();
        ServerConnector connector = new ServerConnector(server);
        connector.setPort(port);
        server.addConnector(connector);

        ServletContextHandler context = new ServletContextHandler("/");
        // The Jakarta WebSocket container must exist before AtmosphereServlet initialises.
        JakartaWebSocketServletContainerInitializer.configure(context,
                (servletContext, container) -> container.addEndpoint(PlainEcho.class));

        ServletHolder atmosphere = new ServletHolder(AtmosphereServlet.class);
        atmosphere.setInitParameter(ApplicationConfig.ANNOTATION_PACKAGE, "example.chatterbox");
        atmosphere.setInitParameter(ApplicationConfig.WEBSOCKET_SUPPORT, "true");
        atmosphere.setInitParameter(ApplicationConfig.WEBSOCKET_MAXTEXTSIZE, "16384");
        // Replace Atmosphere's built-in same-origin check with an explicit allow-list.
        atmosphere.setInitParameter(ApplicationConfig.WEBSOCKET_REQUIRE_SAME_ORIGIN, "false");
        String origins = System.getenv().getOrDefault("ALLOWED_ORIGINS", "https://chat.example.test");
        atmosphere.setInitParameter("chatterbox.allowedOrigins", origins);
        atmosphere.setInitParameter(ApplicationConfig.CORS_ALLOWED_ORIGINS, origins);
        atmosphere.setInitParameter(ApplicationConfig.ATMOSPHERE_INTERCEPTORS, OriginInterceptor.class.getName());
        // Treat a close frame without status code (1005) as a disconnect so @Disconnect fires.
        atmosphere.setInitParameter(ApplicationConfig.ALLOW_WEBSOCKET_STATUS_CODE_1005_AS_DISCONNECT, "true");
        // Atmosphere's own heartbeat writes a padding frame that is not Chatterbox JSON: switch it off.
        atmosphere.setInitParameter(ApplicationConfig.HEARTBEAT_INTERVAL_IN_SECONDS, "0");
        atmosphere.setInitOrder(1);
        atmosphere.setAsyncSupported(true);
        context.addServlet(atmosphere, "/*");
        ServletHolder tickets = new ServletHolder(new Tickets());
        tickets.setInitParameter("allowedOrigins", origins);
        context.addServlet(tickets, "/tickets");

        server.setHandler(context);
        server.start();
        server.join();
    }
}

The ticket servlet stands in for your login: a real application issues the ticket from an authenticated HTTP request (cookie or session) and the browser then redeems it in hello, because the browser WebSocket API cannot set an Authorization header. A ticket is one-time and expires after 30 seconds. See Authentication and Authorization for the trade-offs of cookies, query-string tickets and first-message tokens.

    }

    private static final Map<String, Ticket> TICKETS = new ConcurrentHashMap<>();

    @Override
    protected void doPost(HttpServletRequest req, HttpServletResponse resp) throws IOException {
        String user = req.getParameter("user");
        if (user == null || !user.matches("[a-z0-9]{1,32}")) {
            resp.sendError(400, "user must match [a-z0-9]{1,32}");
            return;
        }
        String origin = req.getHeader("Origin");
        if (origin != null && getInitParameter("allowedOrigins") != null
                && List.of(getInitParameter("allowedOrigins").split(",")).contains(origin)) {
            resp.setHeader("Access-Control-Allow-Origin", origin); // the page may live on another origin
            resp.setHeader("Vary", "Origin");
        }
        String ticket = UUID.randomUUID().toString();
        TICKETS.put(ticket, new Ticket(user, req.getParameter("name") == null ? user : req.getParameter("name"),
                System.currentTimeMillis() + TTL_MS));
        resp.setContentType("application/json");
        resp.getWriter().write("{\"ticket\":\"" + ticket + "\"}");
    }

    /** Redeems a ticket once; returns null when it is unknown, used or expired. */
    static Ticket redeem(String ticket) {
        Ticket t = ticket == null ? null : TICKETS.remove(ticket);
        return t != null && t.expiresAt() > System.currentTimeMillis() ? t : null;
    }

The Origin allow-list is an AtmosphereInterceptor with FIRST_BEFORE_DEFAULT priority, so it runs before everything else. A request without an Origin header comes from a non-browser client and passes, as the protocol requires; those clients rely on the ticket. On a WebSocket the upgrade has already completed when interceptors run, so the refusal is a close frame with the application code 4403, not an HTTP 403.

/** Allow-list for the Origin header; requests without Origin (non-browsers) pass and rely on the ticket. */
public final class OriginInterceptor extends AtmosphereInterceptorAdapter {
    private Set<String> allowed = Set.of();

    @Override
    public void configure(AtmosphereConfig config) {
        String list = config.getInitParameter("chatterbox.allowedOrigins", "");
        allowed = Arrays.stream(list.split(",")).map(String::trim).filter(s -> !s.isEmpty())
                .collect(Collectors.toSet());
    }

    @Override
    public PRIORITY priority() {
        return PRIORITY.FIRST_BEFORE_DEFAULT;
    }

    @Override
    public Action inspect(AtmosphereResource r) {
        String origin = r.getRequest().getHeader("Origin");
        if (origin == null || allowed.contains(origin)) {
            return Action.CONTINUE;
        }
        if (r.getResponse().getAsyncIOWriter() instanceof WebSocket ws) {
            ws.close(4403, "origin not allowed");
        }
        return Action.CANCELLED;
    }

    static String ulid() {

        long time = System.currentTimeMillis();
        for (int i = 9; i >= 0; i--) {
            out[i] = ALPHABET[(int) (time & 31)];
            time >>>= 5;

@Singleton
@ManagedService(path = "/ws")
public class ChatterboxEndpoint {

    private static final ObjectMapper JSON = JsonMapper.builder().build();
    private static final int MAX_FRAME_BYTES = 16384;
    private static final int HEARTBEAT_MS = Integer.getInteger("chatterbox.heartbeatMs", 20_000);
    private static final long GRACE_MS = Long.getLong("chatterbox.graceMs", 15_000);
    private static final int ACK_CACHE = 1000;

    /** Per-connection state, keyed by the AtmosphereResource uuid. */
    private static final class Conn {
        final AtmosphereResource resource;
        String userId;
        String name;
        String status = "online";
        volatile boolean helloDone;
        volatile long lastSeen = System.currentTimeMillis();
        double tokens = 40;
        long refilled = System.nanoTime();
        int rateErrors;
        long firstRateError;
        final Set<String> rooms = ConcurrentHashMap.newKeySet();

        Conn(AtmosphereResource resource) {
            this.resource = resource;
        }
    }

    private static final class Room {
        final String name;
        final Broadcaster broadcaster;
        long seq;
        final List<ObjectNode> events = new ArrayList<>();
        final Map<String, ObjectNode> messages = new LinkedHashMap<>();
        final Set<String> reactions = new HashSet<>();
        final Set<Conn> conns = ConcurrentHashMap.newKeySet();

        Room(String name, Broadcaster broadcaster) {
            this.name = name;
            this.broadcaster = broadcaster;
        }
    }

    private final Map<String, Conn> conns = new ConcurrentHashMap<>();
    private final Map<String, Room> rooms = new ConcurrentHashMap<>();
    private final Map<String, Map<String, ObjectNode>> acked = new ConcurrentHashMap<>();
    private final ScheduledExecutorService timers = Executors.newSingleThreadScheduledExecutor();

    @Inject
    private BroadcasterFactory factory;

    public ChatterboxEndpoint() {
        timers.scheduleAtFixedRate(this::sweep, HEARTBEAT_MS, HEARTBEAT_MS, TimeUnit.MILLISECONDS);
    }

    @Ready
    public void onReady(AtmosphereResource r) {
        Conn c = new Conn(r);
        conns.put(r.uuid(), c);
        timers.schedule(() -> {
            if (!c.helloDone && conns.containsKey(r.uuid())) {
                close(c, 4408, "hello timeout");
            }
        }, 5, TimeUnit.SECONDS);
    }

    @Disconnect
    public void onDisconnect(AtmosphereResourceEvent event) {
        log.debug("disconnect {} cancelled={} closedByClient={}", event.getResource().uuid(), event.isCancelled(), event.isClosedByClient());
        Conn c = conns.remove(event.getResource().uuid());
        if (c == null) {
            return;
        }
        c.rooms.forEach(name -> rooms.get(name).conns.remove(c));
        if (c.userId != null) {
            timers.schedule(() -> goOfflineIfGone(c), GRACE_MS, TimeUnit.MILLISECONDS);
        }
    }

    @Message
    public void onFrame(AtmosphereResource r, String frame) {
        Conn c = conns.get(r.uuid());
        if (c == null) {
            return;
        }
        c.lastSeen = System.currentTimeMillis();
        if (frame.getBytes(StandardCharsets.UTF_8).length > MAX_FRAME_BYTES) {
            close(c, 4413, "frame too large");
            return;
        }
        JsonNode in;
        try {
            in = JSON.readTree(frame);
        } catch (JacksonException e) {
            error(c, null, null, "bad_request", "frame is not JSON", false);
            return;
        }
        String id = text(in, "id");
        String type = text(in, "type");
        String roomName = in.path("room").isString() ? in.path("room").stringValue("") : null;
        JsonNode payload = in.path("payload");
        if (!in.path("v").isInt() || !payload.isObject() || type == null || id == null) {
            error(c, id, roomName, "bad_request", "v, type, id and payload are required", false);
            return;
        }
        if (in.path("v").intValue() != 1) {
            error(c, id, roomName, "unsupported_version", "only v1 is supported", false);
            close(c, 4426, "unsupported version");
            return;
        }
        if (!takeToken(c)) {
            error(c, id, roomName, "rate_limited", "slow down", true);
            return;
        }
        if (!c.helloDone && !type.equals("hello")) {
            error(c, id, roomName, "unauthorized", "send hello first", false);
            close(c, 4401, "unauthorized");
            return;
        }
        Map<String, ObjectNode> cache = c.userId == null ? null
                : acked.computeIfAbsent(c.userId, k -> new LinkedHashMap<>());
        if (cache != null) {
            ObjectNode previous;
            synchronized (cache) {
                previous = cache.get(id);
            }
            if (previous != null) {
                ObjectNode copy = previous.deepCopy();
                ((ObjectNode) copy.get("payload")).put("dup", true);
                write(c, copy);
                return;
            }
        }
        switch (type) {
            case "hello" -> hello(c, id, payload);
            case "join" -> join(c, id, roomName, payload);
            case "leave" -> leave(c, id, roomName);
            case "message" -> message(c, id, roomName, payload);
            case "edit" -> edit(c, id, roomName, payload);
            case "react" -> react(c, id, roomName, payload);
            case "typing" -> relay(c, "typing", roomName, JSON.createObjectNode()
                    .put("userId", c.userId).put("state", payload.path("state").asString("stop")));
            case "receipt" -> receipt(c, id, roomName, payload);
            case "presence" -> presence(c, id, payload);
            case "history" -> history(c, id, roomName, payload);
            default -> error(c, id, roomName, "bad_request", "unknown type " + type, false);
        }
    }

Part 2 holds one method per envelope type. join adds the connection to the room Broadcaster, acknowledges with the member list and lastSeq, replays missed events when since is set, and announces presence to the others. message checks membership, text length and replyTo, assigns seq and broadcasts under the room lock; ack also stores the answer in the idempotency cache, which is what turns a retry with the same id into dup: true.

    private void hello(Conn c, String id, JsonNode p) {
        if (c.helloDone) {
            error(c, id, null, "conflict", "already said hello", false);
            return;
        }
        Tickets.Ticket t = Tickets.redeem(p.path("token").asString(null));
        if (t == null) {
            error(c, id, null, "unauthorized", "invalid or expired ticket", false);
            close(c, 4401, "unauthorized");
            return;
        }
        c.userId = t.userId();
        c.name = t.name();
        c.helloDone = true;
        ObjectNode reply = JSON.createObjectNode().put("ref", id).put("userId", c.userId).put("name", c.name)
                .put("sessionId", Ids.ulid()).put("heartbeatMs", HEARTBEAT_MS).put("maxFrameBytes", MAX_FRAME_BYTES)
                .put("resumed", false);
        reply.putArray("rooms");
        write(c, envelope("hello", null, reply));
    }

    private void join(Conn c, String id, String roomName, JsonNode p) {
        if (!validRoom(c, id, roomName)) {
            return;
        }
        Room room = rooms.computeIfAbsent(roomName, n -> new Room(n, factory.lookup("/rooms/" + n, true)));
        boolean first = c.rooms.add(roomName);
        room.conns.add(c);
        room.broadcaster.addAtmosphereResource(c.resource);
        ObjectNode result = JSON.createObjectNode();
        ArrayNode members = result.putArray("members");
        Set<String> seen = new HashSet<>();
        for (Conn m : room.conns) {
            if (seen.add(m.userId)) {
                members.addObject().put("userId", m.userId).put("name", m.name).put("status", m.status);
            }
        }
        long lastSeq;
        synchronized (room) {
            lastSeq = room.seq;
            result.put("lastSeq", lastSeq);
            ack(c, id, roomName, null, false, result);
            if (p.path("since").isIntegralNumber()) {
                long since = p.path("since").longValue();
                room.events.stream().filter(e -> e.path("payload").path("seq").longValue() > since)
                        .forEach(e -> write(c, e));
            }
        }
        if (first) {
            relay(c, "presence", roomName, JSON.createObjectNode().put("userId", c.userId).put("name", c.name)
                    .put("status", c.status));
        }
    }

    private void leave(Conn c, String id, String roomName) {
        Room room = roomName == null ? null : rooms.get(roomName);
        if (room == null || !c.rooms.remove(roomName)) {
            error(c, id, roomName, "not_found", "not a member of " + roomName, false);
            return;
        }
        room.conns.remove(c);
        room.broadcaster.removeAtmosphereResource(c.resource);
        ack(c, id, roomName, null, false, JSON.createObjectNode());
        relay(c, "presence", roomName, JSON.createObjectNode().put("userId", c.userId).put("name", c.name)
                .put("status", "offline"));
    }

    private void message(Conn c, String id, String roomName, JsonNode p) {
        Room room = memberRoom(c, id, roomName);
        if (room == null) {
            return;
        }
        String text = p.path("text").asString(null);
        if (text == null || text.isEmpty() || text.length() > 4000) {
            error(c, id, roomName, "bad_request", "text must be 1..4000 characters", false);
            return;
        }
        if (p.path("attachments").isArray() && p.path("attachments").size() > 5) {
            error(c, id, roomName, "bad_request", "at most 5 attachments", false);
            return;
        }
        synchronized (room) {
            String replyTo = p.path("replyTo").isString() ? p.path("replyTo").stringValue("") : null;
            if (replyTo != null && !room.messages.containsKey(replyTo)) {
                error(c, id, roomName, "not_found", "replyTo is not a message of this room", false);
                return;
            }
            long seq = ++room.seq;
            ObjectNode body = JSON.createObjectNode();
            body.putObject("from").put("userId", c.userId).put("name", c.name);
            body.put("text", text);
            body.set("replyTo", replyTo == null ? JSON.nullNode() : JSON.valueToTree(replyTo));
            body.set("attachments", p.path("attachments").isArray() ? p.path("attachments") : JSON.createArrayNode());
            body.put("seq", seq).put("edited", false);
            ObjectNode env = envelope("message", roomName, body);
            env.put("id", id);
            room.events.add(env);
            room.messages.put(id, env);
            room.broadcaster.broadcast(new RawMessage(JSON.writeValueAsString(env)));
            ack(c, id, roomName, seq, false, JSON.createObjectNode());
        }
    }

    private void edit(Conn c, String id, String roomName, JsonNode p) {
        Room room = memberRoom(c, id, roomName);
        if (room == null) {
            return;
        }
        synchronized (room) {
            ObjectNode target = room.messages.get(p.path("target").asString(""));
            if (target == null) {
                error(c, id, roomName, "not_found", "unknown target", false);
                return;
            }
            if (!target.path("payload").path("from").path("userId").asString("").equals(c.userId)) {
                error(c, id, roomName, "forbidden", "only the author may edit", false);
                return;
            }
            String text = p.path("text").asString("");
            if (text.isEmpty() || text.length() > 4000) {
                error(c, id, roomName, "bad_request", "text must be 1..4000 characters", false);
                return;
            }
            long seq = ++room.seq;
            ((ObjectNode) target.get("payload")).put("text", text).put("edited", true);
            ObjectNode body = JSON.createObjectNode().put("target", p.path("target").asString()).put("text", text)

            ObjectNode env = envelope("edit", roomName, body);
            env.put("id", id);
            room.events.add(env);
            room.broadcaster.broadcast(new RawMessage(JSON.writeValueAsString(env)));
            ack(c, id, roomName, seq, false, JSON.createObjectNode());
        }
    }

    private void react(Conn c, String id, String roomName, JsonNode p) {
        Room room = memberRoom(c, id, roomName);
        if (room == null) {
            return;
        }
        synchronized (room) {
            String target = p.path("target").asString("");
            if (!room.messages.containsKey(target)) {
                error(c, id, roomName, "not_found", "unknown target", false);
                return;
            }
            String emoji = p.path("emoji").asString("");
            String op = p.path("op").asString("add");
            String key = target + "|" + c.userId + "|" + emoji;
            if (emoji.isEmpty() || !(op.equals("add") || op.equals("remove"))) {
                error(c, id, roomName, "bad_request", "emoji and op (add or remove) are required", false);
                return;
            }
            if (op.equals("add") ? !room.reactions.add(key) : !room.reactions.remove(key)) {
                error(c, id, roomName, op.equals("add") ? "conflict" : "not_found",
                        op.equals("add") ? "already reacted" : "no such reaction", false);
                return;
            }
            long seq = ++room.seq;
            ObjectNode body = JSON.createObjectNode().put("target", target).put("emoji", emoji).put("op", op);
            body.putObject("from").put("userId", c.userId);
            body.put("seq", seq);
            ObjectNode env = envelope("react", roomName, body);
            env.put("id", id);
            room.events.add(env);
            room.broadcaster.broadcast(new RawMessage(JSON.writeValueAsString(env)));
            ack(c, id, roomName, seq, false, JSON.createObjectNode());
        }
    }

    private void receipt(Conn c, String id, String roomName, JsonNode p) {
        Room room = roomName == null ? null : rooms.get(roomName);
        if (room == null || !c.rooms.contains(roomName)) {
            return;
        }
        long upTo = p.path("upTo").longValue();
        if (upTo > room.seq) {
            error(c, id, roomName, "bad_request", "upTo is beyond the last seq", false);
            return;
        }
        relay(c, "receipt", roomName, JSON.createObjectNode().put("userId", c.userId)
                .put("kind", p.path("kind").asString("read")).put("upTo", upTo));
    }

    private void presence(Conn c, String id, JsonNode p) {
        String status = p.path("status").asString("online");
        if (!status.equals("online") && !status.equals("away")) {
            error(c, id, null, "bad_request", "status must be online or away", false);
            return;
        }
        boolean changed = !status.equals(c.status);
        c.status = status;
        ack(c, id, null, null, false, JSON.createObjectNode());
        if (changed) {
            for (String r : c.rooms) {
                relay(c, "presence", r, JSON.createObjectNode().put("userId", c.userId).put("name", c.name)
                        .put("status", status));
            }
        }
    }

    private void history(Conn c, String id, String roomName, JsonNode p) {
        Room room = memberRoom(c, id, roomName);
        if (room == null) {
            return;
        }
        int limit = Math.max(1, Math.min(100, p.path("limit").asInt(50)));
        long before = p.path("before").isIntegralNumber() ? p.path("before").longValue() : Long.MAX_VALUE;
        ObjectNode result = JSON.createObjectNode();
        ArrayNode page = result.putArray("messages");
        synchronized (room) {
            List<ObjectNode> older = room.messages.values().stream()
                    .filter(m -> m.path("payload").path("seq").longValue() < before).toList();
            int from = Math.max(0, older.size() - limit);
            older.subList(from, older.size()).forEach(page::add);
            boolean hasMore = from > 0;
            result.put("hasMore", hasMore);
            if (hasMore) {
                result.put("next", older.get(from).path("payload").path("seq").longValue());
            } else {
                result.putNull("next");
            }
        }
        ack(c, id, roomName, null, false, result);
    }

        return true;

    private Room memberRoom(Conn c, String id, String roomName) {
        Room room = roomName == null ? null : rooms.get(roomName);
        if (room == null || !c.rooms.contains(roomName)) {
            error(c, id, roomName, "forbidden", "join the room first", false);
            return null;
        }
        return room;
    }

    /** Sends typing, receipt and presence envelopes to the other members of a room. */
    private void relay(Conn from, String type, String roomName, ObjectNode body) {
        Room room = rooms.get(roomName);
        if (room == null) {
            return;
        }
        Set<AtmosphereResource> others = new HashSet<>();
        room.conns.stream().filter(m -> m != from).forEach(m -> others.add(m.resource));
        if (!others.isEmpty()) {
            room.broadcaster.broadcast(new RawMessage(JSON.writeValueAsString(envelope(type, roomName, body))), others);
        }
    }

    private void goOfflineIfGone(Conn gone) {
        boolean stillHere = conns.values().stream().anyMatch(m -> gone.userId.equals(m.userId));
        if (!stillHere) {
            gone.rooms.forEach(r -> {
                Room room = rooms.get(r);
                if (room != null) {
                    ObjectNode body = JSON.createObjectNode().put("userId", gone.userId).put("name", gone.name)
                            .put("status", "offline");
                    room.broadcaster.broadcast(new RawMessage(JSON.writeValueAsString(envelope("presence", r, body))));
                }
            });
        }
    }

    private void sweep() {
        long now = System.currentTimeMillis();
        for (Conn c : conns.values()) {
            if (now - c.lastSeen > 2L * HEARTBEAT_MS) {
                close(c, 4408, "heartbeat timeout");
            } else if (c.resource.getResponse().getAsyncIOWriter() instanceof WebSocket ws) {
                try {
                    ws.sendPing(new byte[0]);
                } catch (RuntimeException e) {
                    log.debug("ping failed", e);
                }
            }
        }
    }

    private boolean takeToken(Conn c) {
        long now = System.nanoTime();
        c.tokens = Math.min(40, c.tokens + (now - c.refilled) / 1e9 * 20);
        c.refilled = now;
        if (c.tokens >= 1) {
            c.tokens -= 1;
            return true;
        }
        long ms = System.currentTimeMillis();
        if (ms - c.firstRateError > 10_000) {
            c.firstRateError = ms;
            c.rateErrors = 0;
        }
        if (++c.rateErrors >= 10) {
            close(c, 4429, "rate limited");
        }
        return false;
    }

    private static String text(JsonNode n, String field) {
        return n.path(field).isString() ? n.path(field).stringValue("") : null;
    }

    private static ObjectNode envelope(String type, String room, ObjectNode payload) {
        ObjectNode env = JSON.createObjectNode().put("v", 1).put("type", type).put("id", Ids.serverId());
        if (room == null) {
            env.putNull("room");
        } else {
            env.put("room", room);
        }
        env.put("ts", System.currentTimeMillis());
        env.set("payload", payload);
        return env;
    }

    private void ack(Conn c, String ref, String room, Long seq, boolean dup, ObjectNode result) {
        ObjectNode body = JSON.createObjectNode().put("ref", ref).put("ok", true);
        if (seq == null) {
            body.putNull("seq");
        } else {
            body.put("seq", seq.longValue());
        }
        body.put("dup", dup);
        body.set("result", result);
        ObjectNode env = envelope("ack", room, body);
        Map<String, ObjectNode> cache = acked.computeIfAbsent(c.userId, k -> new LinkedHashMap<>());
        synchronized (cache) {
            cache.put(ref, env.deepCopy());
            if (cache.size() > ACK_CACHE) {
                cache.remove(cache.keySet().iterator().next());
            }
        }
        write(c, env);
    }

    private void error(Conn c, String ref, String room, String code, String message, boolean retryable) {
        ObjectNode body = JSON.createObjectNode();
        if (ref == null) {
            body.putNull("ref");
        } else {
            body.put("ref", ref);
        }
        body.put("code", code).put("message", message).put("retryable", retryable);
        write(c, envelope("error", room, body));
    }

    private void write(Conn c, JsonNode env) {
        try {
            c.resource.write(JSON.writeValueAsString(env));
        } catch (RuntimeException e) {
            log.debug("write to {} failed: {}", c.resource.uuid(), e.getMessage());
        }
    }

    /** Closes with an application code after a short delay, so the error frame written just before drains first. */
    private void close(Conn c, int code, String reason) {
        timers.schedule(() -> {
            if (c.resource.getResponse().getAsyncIOWriter() instanceof WebSocket ws) {
                ws.close(code, reason);
            }
        }, 100, TimeUnit.MILLISECONDS);
    }
}

What this server leaves out

The server is deliberately single-node and in-memory. Compared with the full protocol it differs in these points:

  • Resume. hello always answers resumed: false; a reconnecting client rejoins its rooms with since, which the server honours by replaying the events with a greater seq. The 120 second session memory of the protocol is not kept.

  • Idempotency window. The ack cache holds the last 1000 ids per user with no 24 hour expiry.

  • Binary frames. A binary frame reaches @Message as garbled text and is answered with bad_request; the protocol’s close 4400 is not sent.

  • Oversize frames. Jetty enforces maxTextMessageSize itself and closes with 1009 instead of the protocol’s 4413. The endpoint’s own 4413 check is a second line of defence.

  • No subprotocol. See the browser client below.

  • Persistence. History lives in the room object; a restart empties it. Attachments are echoed, not validated or stored.

// Needs Node.js 22 or later (global fetch, crypto) and the ws package: npm install ws@8.22.0
import WebSocket from 'ws';

const BASE = process.env.CHATTERBOX_URL ?? 'http://localhost:8080';
const ORIGIN = 'https://chat.example.test';
const sleep = (ms) => new Promise((resolve) => setTimeout(resolve, ms));
const newId = () => crypto.randomUUID().replaceAll('-', '').slice(0, 26).toUpperCase();

async function connect(user) {
  const { ticket } = await (await fetch(`${BASE}/tickets?user=${user}`, { method: 'POST' })).json();
  const ws = new WebSocket(BASE.replace('http', 'ws') + '/ws', { origin: ORIGIN });
  const inbox = [];
  ws.on('message', (data) => inbox.push(JSON.parse(data.toString())));
  await new Promise((resolve) => ws.on('open', resolve));

  const client = {
    ws,
    send(type, room, payload, id = newId()) {
      ws.send(JSON.stringify({ v: 1, type, id, room, ts: 0, payload }));
      return id;
    },
    async next(predicate) {
      for (let i = 0; i < 150; i++) {
        const at = inbox.findIndex(predicate);
        if (at >= 0) return inbox.splice(at, 1)[0];
        await sleep(20);
      }
      throw new Error(`${user}: timed out waiting, inbox=${JSON.stringify(inbox)}`);
    },

    async request(type, room, payload, id = newId()) {
      client.send(type, room, payload, id);
      return client.next((e) => (e.type === 'ack' || e.type === 'error') && e.payload.ref === id);
    },
  };
  client.send('hello', null, { token: ticket, client: 'demo/1.0' });
  await client.next((e) => e.type === 'hello');
  return client;
}

The browser client

The browser side is ordinary WebSocket code. Two differences from the other servers in this section follow from how Atmosphere registers its endpoint, and both were confirmed in Chrome 155:

  • No subprotocol. Jetty logs "Client requested Subprotocols on endpoint with none supported". The protocol version is carried by the v field of every envelope instead.

  • Reading the close code. A page served from an origin outside the allow-list does connect, then receives 4403.

    }

    public void onDisconnect(AtmosphereResource r) {
        log.info("{} left {}", r.uuid(), room);
    }

        return line; // the return value is broadcast to everyone on /chat/{room}

Rooms and presence: the Room API

Atmosphere 4 adds a higher-level abstraction on top of broadcasters. A Room has a name, member identity (RoomMember with an id that survives reconnects, unlike the connection uuid), presence events, optional message history, direct messages to one member, virtual members (bots) and an authorizer. RoomManager.getOrCreate(framework) returns the registry; room.join(resource, member), room.broadcast(message, senderToExclude), room.sendTo(message, targetUuid), room.enableHistory(n) and room.onPresence(listener) are the main calls.

RoomProtocolInterceptor bridges clients to rooms with a small JSON protocol (this is what the useRoom hooks of atmosphere.js for React, Vue and Svelte and the AtmosphereRooms class speak): the client sends join, leave, broadcast, direct and typing messages, and receives join_ack with the member list, presence, message and typing. The endpoint needs only the interceptor and the room setup:

Durable sessions

Without durable sessions a server restart forgets room memberships and broadcaster subscriptions. The DurableSessionInterceptor gives a connection a token (the response header X-Atmosphere-Session-Token), saves its rooms and broadcasters in a SessionStore when it disconnects, and restores them when a client presents the token as a header or as the query parameter X-Atmosphere-Session-Token. Three stores ship: in-memory (development), SQLite for a single node and Redis for a cluster.

The Spring Boot variant below enables it with a SessionStore bean and one property. It was verified through a real restart: an ann client got a token, joined the lobby room and disconnected; the JVM was restarted; ann reconnected with the token, sent no join, and still received the presence and message events that bo produced in the room. Four conditions came out of the experiment:

  • In 4.0.76 the property atmosphere.durable-sessions.enabled=true is required. With only the SessionStore bean no interceptor was installed and no token header was issued, although the tutorial text suggests the bean is enough.

  • Restoration re-joins only broadcasters and rooms that exist when the client reconnects. A path-template endpoint creates its Broadcaster lazily, so after a restart it is not there yet; the sample’s pattern is to create the rooms at startup (see RoomsConfig below).

  • The token is issued in a response header. The response of a WebSocket upgrade cannot be read by a browser, and the upgrade response captured with ws carried no such header. Obtain the token from an HTTP request (an SSE or long-polling connection, or any request that passes through Atmosphere) and present it on the WebSocket as a query parameter, which is what the verification did.

  • Durable sessions restore subscription state; they do not replay missed messages. That is the job of the BroadcasterCache, or, as in Chatterbox, of the application’s own seq and history.

Clustering with Redis or Kafka

One Broadcaster exists per node. A broadcast on node A reaches only the connections on node A, so with several nodes the fan-out needs a relay. Atmosphere ships it as a Broadcaster class: RedisBroadcaster (Lettuce, Redis pub/sub) and KafkaBroadcaster extend DefaultBroadcaster, publish every broadcast to the external system and deliver what arrives from other nodes locally. Each instance has a random node id, sent with the message, so a node ignores its own messages coming back. The Hazelcast and JGroups clusterings, and the JMS, RabbitMQ and XMPP broadcasters, stopped at 2.6.5 (October 2021); Redis and Kafka are the options for 4.x.

RelayChat.java
package example.relay;

import org.atmosphere.config.service.ManagedService;
import org.atmosphere.config.service.Message;
import org.atmosphere.plugin.redis.RedisBroadcaster;

/** One broadcaster per room; RedisBroadcaster publishes every broadcast to Redis so other nodes deliver it too. */
@ManagedService(path = "/relay/{room}", broadcaster = RedisBroadcaster.class)
public class RelayChat {
    @Message
    public String onMessage(String text) {
        return text;
    }
}

The Redis URL is an init parameter (org.atmosphere.redis.url, Lettuce syntax: redis://, rediss:// for TLS or redis-sentinel://). Two warnings come from the experiment. Having atmosphere-redis on the classpath is enough to make RedisBroadcaster the default for every endpoint (the startup log says "This broadcaster will be used by default"), so a project that only wants Redis for one endpoint should keep the dependency out of the other deployables. And the relay carries broadcasts, not state: the seq counters, event logs and idempotency cache of the Chatterbox server above live in one JVM, so a clustered Chatterbox must also move them to a shared store (Redis INCR for seq, a stream or sorted set for history). See Scaling WebSockets and the Redis reference.

Security

  • Origin. Browsers do not apply the same-origin policy to WebSocket handshakes and send cookies, so every endpoint needs an Origin check or Cross-Site WebSocket Hijacking is possible. Atmosphere 4.0.76 enforces same origin by default (org.atmosphere.websocket.requireSameOrigin, default true): a mismatched Origin is accepted at the HTTP level and the socket is then closed with code 1003 (observed with ws sending an Origin header). A request without an Origin passes, since only browsers send it. A page on one origin talking to an API on another needs the check turned off and an allow-list of your own, as the example does.

  • CORS interceptor. It is installed by default and, without org.atmosphere.cpr.cors.allowedOrigins, echoes any Origin back, which the startup log flags for production. Set the list.

  • Authentication. Use a one-time ticket, a cookie or session, never a long-lived token in the URL. Enabling HttpSession support (atmosphere.session-support, or the SessionSupport listener) is required if the endpoint reads the servlet session. The interceptor chain is the place for an authentication check; return Action.CANCELLED.

  • Output encoding. HTML sanitization was switched off for the WebSocket transport in 4.0.11 because it corrupted JSON frames, while HTTP transports still sanitize write calls. Escape message text in the page (textContent, not innerHTML) whatever the transport.

  • Size and rate. Set maxTextMessageSize; the example’s 16384 bytes closed an oversize frame with 1009 from Jetty. Rate-limit per connection, as the example does, or with an interceptor that returns CANCELLED. Atmosphere’s BackpressureInterceptor (org.atmosphere.backpressure.highWaterMark, policy drop-oldest, drop-newest or disconnect) protects against slow consumers.

  • Admin endpoints. With atmosphere-admin on the classpath the Spring Boot starter registers /api/admin/*; writes are off by default and need a feature flag, a principal and an authorizer. Do not expose it publicly.

  • TLS. Terminate it at the proxy or the container and use wss://. See Security for the cross-stack checklist.

Common errors and pitfalls

  • @Disconnect never runs for some clients. A close frame without a status code arrives as 1005, which Atmosphere treats as a timeout instead of a disconnect unless org.atmosphere.websocket.WebSocketProtocol.allow1005disconnectEvent=true. Chrome 155 sent 1005 for ws.close() with no arguments and 1000 for ws.close(1000), and the ws library does the same, so ordinary clients are affected. Without the setting the example’s presence and room cleanup silently did not run.

  • Garbage frames of X every minute. The default HeartbeatInterceptor writes a padding character to the connection even on WebSocket. A JSON-only client breaks; set heartbeatFrequencyInSeconds to 0 and run an application heartbeat.

  • The browser refuses the socket when you pass a subprotocol. Atmosphere does not negotiate one. Omit the argument.

  • An endpoint keeps no state. Without @Singleton the class is instantiated for each connection, so instance fields are per connection.

  • A broadcast comes back as an inbound message. A non-RawMessage broadcast runs through @Message; wrap pre-encoded text in RawMessage. Even a targeted broadcast on the endpoint’s own broadcaster re-entered the handler in the experiment above.

  • Filters never fire. On the managed path a BroadcastFilter sees the encoded message, not your domain class.

  • Nothing works on Quarkus. quarkus.atmosphere.load-on-startup is zero or negative, or quarkus.atmosphere.packages is missing.

  • No endpoints found on Spring Boot. atmosphere.packages is not set.

  • jakarta.inject.Singleton ignored. The annotation is org.atmosphere.config.service.Singleton.

  • JSON through the fallback transports comes back as ". A direct write is sanitized on HTTP transports; send through a broadcast of a RawMessage that does not re-enter the endpoint.

  • Restart loses rooms although durable sessions are configured. The property atmosphere.durable-sessions.enabled is false by default and the rooms must exist before the client reconnects.

  • Some clients cannot connect and the CORS list looks right. The CORS interceptor also judges same-origin POST requests from the fallback transports.

  • Order on the wire. The ack of a message and its broadcast can arrive in either order; clients must sort by seq.

Atmosphere compared with plain Jakarta WebSocket and with Spring

Jakarta WebSocket 2.2 (the specification of Jakarta EE 11, API 2.2.0) is the standard Java server API: a @ServerEndpoint class with @OnOpen, @OnMessage, @OnClose and @OnError, a Session per connection, text, binary and partial messages, path parameters, encoders and decoders, and subprotocol and extension negotiation. Atmosphere is built on top of it for its WebSocket transport. The two can share one server; this @ServerEndpoint was added to the Jetty project of this page and answered on /plain while Atmosphere served /ws:

PlainEcho.java
package example.chatterbox;

import jakarta.websocket.OnClose;
import jakarta.websocket.OnMessage;
import jakarta.websocket.OnOpen;
import jakarta.websocket.Session;
import jakarta.websocket.server.ServerEndpoint;
import java.io.IOException;
import java.util.Set;
import java.util.concurrent.ConcurrentHashMap;

/** The same fan-out written against plain Jakarta WebSocket 2.2: no transports, no broadcaster, but subprotocol negotiation. */
@ServerEndpoint(value = "/plain", subprotocols = "chatterbox.v1")
public class PlainEcho {
    private static final Set<Session> SESSIONS = ConcurrentHashMap.newKeySet();

    @OnOpen
    public void onOpen(Session session) {
        session.setMaxTextMessageBufferSize(16384);
        SESSIONS.add(session);
    }

    @OnMessage
    public void onMessage(String text) throws IOException {
        for (Session s : SESSIONS) {
            if (s.isOpen()) {
                s.getAsyncRemote().sendText(text); // note: no per-session send queue, see the pitfalls
            }
        }
    }

    @OnClose
    public void onClose(Session session) {
        SESSIONS.remove(session);
    }
}

Fan-out written directly over the Session set (as PlainEcho does) has a classic problem: nothing queues the messages of a slow client or decides what to drop, so depending on the container the loop blocks or the memory grows, and every server has to invent its own policy. Broadcasters and BackpressureInterceptor exist to solve that. For the Spring side see Spring WebFlux WebSockets, and for STOMP on the Servlet stack the Thymeleaf SSE and WebSocket page.

Version and specification notes

  • Atmosphere. 4.0.0 on 2026-02-20; 4.0.76 on 2026-10-22; there were 76 patch releases in eight months. The project’s changelog is the authoritative history. Pin the version and read the release notes when you upgrade; this page’s observations (the default-on same-origin check, the 1005 handling, the property for durable sessions) are behaviours of 4.0.76.

  • Jakarta. Jakarta WebSocket 2.1 belongs to Jakarta EE 10 and 2.2 to Jakarta EE 11. The Jetty ee10 modules used here resolved jakarta.websocket-api 2.1.1 while Atmosphere compiles against 2.2.0.

  • Protocol standards. The WebSocket protocol is RFC 6455; browsers may send close codes 1000 and 3000 to 4999 only, so 1005 and 1006 never travel on the wire from a page, although a client that sends no code is reported as 1005. See The WebSocket Protocol.
