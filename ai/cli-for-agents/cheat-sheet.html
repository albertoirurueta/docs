A short worked example that combines three of the rules above: data on stdout and messages on stderr, a JSON document with a schemaVersion, and a usage error that exits with code 2. The docsctl function below is a stand-in that mimics the running example so the snippet can be run as it is; the consumer discards stderr and reads only the JSON.

docsctl() {
  if [ "$1" != search ] || [ -z "$2" ]; then
    echo "docsctl: usage: docsctl search QUERY" >&2
    return 2
  fi
  echo "searching for $2" >&2
  printf '{"schemaVersion":1,"results":[{"id":"irurueta-algebra::matrix-inversion.adoc"}]}\n'
}

docsctl search matrix 2>/dev/null | python3 -c 'import json,sys; print(json.load(sys.stdin)["results"][0]["id"])'
docsctl search 2>/dev/null
echo "exit code: $?"
irurueta-algebra::matrix-inversion.adoc
exit code: 2
