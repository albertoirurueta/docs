A short worked example of the Wilson lower-bound CI gate: the same 92% observed pass rate fails a threshold of 0.85 on a 50-item golden set and passes on larger sets, because the gate compares the lower end of the confidence interval, not the point estimate. It uses only the Python standard library.

from math import sqrt
def wilson_lower(passed, total, z=1.96):
    p = passed / total
    d = 1 + z * z / total
    centre = p + z * z / (2 * total)
    margin = z * sqrt(p * (1 - p) / total + z * z / (4 * total * total))
    return (centre - margin) / d

threshold = 0.85
for passed, total in [(46, 50), (184, 200), (368, 400)]:
    lo = wilson_lower(passed, total)
    verdict = "PASS" if lo >= threshold else "FAIL"
    print(f"{passed}/{total} observed={passed/total:.3f} lower={lo:.3f} {verdict}")
46/50 observed=0.920 lower=0.812 FAIL
184/200 observed=0.920 lower=0.874 PASS
368/400 observed=0.920 lower=0.889 PASS
