Operations — Running Local LLMs in Production.

A short worked example of the sizing formulas from Hardware Sizing: an 8B model with 32 layers, 8 KV heads of dimension 128, quantized to Q4_K_M (4.89 bits per weight), a 32k context, an FP16 KV cache, one sequence and 1 GiB of overhead.

GIB = 1024**3
params, layers, kv_heads, head_dim = 8.0e9, 32, 8, 128
context = 32768

weights = params * (4.89 / 8) / GIB                                  # P x b
kv = 2 * layers * kv_heads * head_dim * context * 2.0 / GIB          # 2 L n_kv d_h T b B
print(f"weights {weights:.1f} GiB, KV cache {kv:.1f} GiB, total {weights + kv + 1:.1f} GiB")
weights 4.6 GiB, KV cache 4.0 GiB, total 9.6 GiB

At a 32k context the KV cache is almost as large as the weights, which is why the context length matters as much as the quant type when choosing a GPU.
