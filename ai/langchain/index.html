LangChain

This content was generated with the assistance of AI and should be verified against the official documentation before being relied on in production.

This sub-section was written against langchain 1.4.3, langchain-core 1.6.5, langchain-classic 1.0.8, langgraph 1.2.12 and langsmith 0.14.1 on Python 3.12, langchain 1.5.14 and @langchain/langgraph 1.4.18 on npm, and LangChain4j 1.20.2 on Java 21, with the full list in the version baseline below, all read from PyPI, npm, Maven Central and the official documentation on 2026-09-29. Where an individual page and that baseline ever disagree after a later update, the baseline is the one to trust. Every Python snippet on the pages was executed against the real packages, using scripted fake chat models because no Ollama server was available, so the printed outputs are exactly what the code prints and not what a real model would say; the few snippets that need an account or a network service (a LangSmith workspace, a hosted model) say on their page that they were not run.

"LangChain" now names a family of libraries and services rather than one package: langchain (agents, models, tools and middleware), langchain-core (the shared interfaces), langgraph (a durable, stateful execution runtime), deepagents (a batteries-included agent harness), langsmith (tracing, evaluation and deployment), and, beside the Python libraries, an independent JavaScript port and an independent Java library with its own release cadence. This page is the map of that family, the version table, a suggested reading order for each kind of reader, and the bibliography that all the pages draw on.

Python, JavaScript and LangChain4j

The three libraries solve the same problems — talk to a model, give it tools, remember a conversation, put a person in the loop, connect MCP servers, observe and test the result — but they are separate code bases. Python is the reference implementation and the primary language of this sub-section; the other two get one or two pages each.

LangChain.js

LangChain4j and LangChain4j Agents & MCP

Choose by the language your application is written in, not by the framework: all three call the same model providers, all three can use MCP servers, and an agent written in one can be exposed to the others over HTTP or MCP. LangChain4j is an independent open-source project, not a port of the Python code, so class names differ, and its agentic module is experimental and versioned as a beta.

Version baseline

Every version below was read from the package registries and the official documentation on 2026-09-29. Each page repeats the subset it uses in its own lead paragraph.

Area Versions

Python

Python 3.12; langchain 1.4.3, langchain-core 1.6.5, langchain-classic 1.0.8, langgraph 1.2.12, langsmith 0.14.1, langchain-mcp-adapters 0.3.2, langchain-ollama 1.1.0, deepagents 0.7.19, openevals 0.2.0 and agentevals 0.0.9.

JavaScript

Node.js 24 with langchain 1.5.14, @langchain/core 1.2.13 and @langchain/langgraph 1.4.18; the other npm packages are listed on LangChain.js.

Java

Java 21; LangChain4j 1.20.2 for the stable modules and 1.20.2-beta30 for the agentic, MCP, pgvector and Spring Boot starter modules; the Quarkiverse quarkus-langchain4j extension 1.14.0. See LangChain4j for the module list.

Models and stores

Ollama with llama3.1:8b for chat and nomic-embed-text for embeddings, and the pgvector store of PostgreSQL & pgvector — the same as the rest of the AI section. The hosted models used elsewhere (claude-sonnet-5, claude-opus-5-5, claude-haiku-4-5, gpt-6-sol) are drop-in replacements.

Material written before the 1.0 release in October 2025, including all the books in the bibliography, describes an older package layout. The differences that matter, each flagged where it appears on the pages:

  • chains, the hub, langchain.retrievers.* and the indexing API moved to langchain-classic, and text splitters come from langchain-text-splitters;

  • create_agent with middleware replaces hand-built ReAct graphs and create_react_agent;

  • human approval is now interrupt() with Command(resume=…​), or HumanInTheLoopMiddleware on an agent, rather than hand-built graphs with static breakpoints;

  • the tracing variables are LANGSMITH_TRACING and LANGSMITH_API_KEY, not LANGCHAIN_TRACING_V2;

  • LangGraph Platform is now LangSmith Deployment, its server is the Agent Server, and LangGraph Studio is LangSmith Studio;

  • LangChain4j moved from the 0.3x line to 1.x, with the experimental agentic module and the MCP client added.
