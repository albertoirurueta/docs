User interface

This documentation was generated with the assistance of AI. Please report any inaccuracies.

The library’s only user-facing element is the GestureBitmapView component. The repository’s app/ module is a sample application with a single screen that hosts the view full screen (see Sample app).

Screens

Screen Purpose Entry point

MainActivity (sample app)

Displays app/src/main/res/drawable-nodpi/image.jpeg in a full-screen GestureBitmapView with the default settings.

Launcher activity of the app module.

Components

Component Purpose Used by

GestureBitmapView

View used to display a bitmap allowing gestures to change view zooming, panning and rotation.

MainActivity (sample app); GestureBitmapViewActivity (instrumented tests).

Accessibility

The repository’s .ui-quality.yml sets accessibility: enforce: automated accessibility checks run with the UI tests and violations fail them. Screenshots are captured in left-to-right and right-to-left directions and in light and dark themes.

Navigation between screens is described in Navigation flows.
